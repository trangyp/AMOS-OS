# AMOS OS Audit — Phase47 Kernel Route Revalidation and BCI Research MECE/Lifecycle Closure

## Objective

Continue from the active Phase45 authority while preserving the concurrently created Phase46
Observability branch. Resolve the remaining Phase45 Kernel navigation mismatch, remove BCI research
ownership duplication, deepen benchmark comparability, and close the explicit BCI post-trial /
end-of-support / explant lifecycle architecture gap using Drive/arXiv and current external research.

## Concurrency

Two distinct Phase46 branches existed by finalization:
- `PHASE46_SKILL_WORKFLOW_PAYLOAD_AND_ORCHESTRATION_REPAIR`, which had advanced the authority pointer;
- `PHASE46_OBSERVABILITY_ARCHITECTURE_AND_EVIDENCE_TOPOLOGY_EXPANSION`, created independently.

Phase47 preserves both as concurrent Phase46A/Phase46B lineage and does not treat the shared numeric
label as stable artifact identity.

## F47-01 — Phase45 semantic contracts did not occupy the historical target paths

Phase45 correctly created source-bound specifications:
- `02_KERNEL/K_ABSOLUTE_LOGIC.md`
- `02_KERNEL/K_CAUSAL_CLOSURE.md`
- `02_KERNEL/K_EVENT_BUS.md`
- `02_KERNEL/K_PROVENANCE.md`

However the unresolved registry targets were path-qualified:
- `02_KERNEL/01_META_LOGIC/K_ABSOLUTE_LOGIC`
- `02_KERNEL/03_CAUSAL/K_CAUSAL_CLOSURE`
- `02_KERNEL/04_STATE/K_EVENT_BUS`
- `02_KERNEL/08_PROVENANCE/K_PROVENANCE`

Creating root-level semantic owners alone did not guarantee exact path resolution.

### Repair
Created four compatibility folders/routes preserving the historical/current paths while linking to
the Phase45 root semantic owners. The compatibility files are redirects, not duplicate semantic owners.

Updated the active unresolved-reference registry:
- `RESOLVED_NAVIGATION`: 29 -> 33
- `ACTIVE_GAP_ROUTED`: 14 -> 10
- `ARCHIVE_ONLY_GAP`: 10 unchanged
- `STALE_UNREFERENCED`: 36 unchanged
- `STALE_REFERRER`: 12 unchanged
- preserved anchors: 101 unchanged

The count status records this as a bounded Phase47 delta revalidation, not a new full graph proof.

`RESOLVED_NAVIGATION != IMPLEMENTED_RUNTIME`.

## F47-02 — BCI research had overlapping active SOTA ownership

Three BCI research capsules had overlapping frontier/evidence responsibilities. This risked stale or
contradictory current-state claims.

### Repair
Created `22_RESEARCH/BCI_RESEARCH_MOC.md` with one primary owner per research function:
1. frontier architecture/evidence;
2. reliability/security/lifecycle;
3. benchmark comparability;
4. lifecycle-governance architecture handoff.

Marked `BCI_STATE_OF_ART_RESEARCH_CAPSULE_2026-09-03.md` as
`SUPERSEDED_RESEARCH_SYNTHESIS` while preserving it as lineage.

Updated `22_RESEARCH_MOC.md` and C04 domain routing to the new BCI MOC.

## F47-03 — BCI benchmark comparison remained under-specified

Raw accuracy, WER, R², bit rate and task-success values were not safely comparable across modality,
population, calibration, online/offline status, language-model contribution, duration and independence.

### Repair
Created `AMOS_C04_BCI_BENCHMARK_COMPARABILITY_MATRIX_2026-09-04.md` with:
- a typed cross-study record;
- E0-E8 evidence-maturity ladder;
- compatibility gates before ranking;
- leakage/optimism checks;
- Pareto rather than scalar SOTA evaluation;
- explicit treatment of foundation-model, speech, home-use, fUSI, neuromorphic and telemetry regimes.

Current evidence also adds `NeuroPB` (arXiv:2608.04389) as a competing scaling path using pretrained
behavioral representations rather than assuming universal neural foundation-model dominance.

## F47-04 — post-trial / end-of-support / explant governance lacked a domain contract

Phase45 identified lifecycle support as a gap, but Research prose alone did not provide an architectural
owner.

### Repair
Created `C04_BCI_LIFECYCLE_GOVERNANCE_CONTRACT.md` under C04 domain architecture.

It defines ten lifecycle states:
active support; maintenance/update; degraded support; transfer/handover; post-trial continuation;
planned deactivation; abandonment risk; explant evaluation; explant/retained dormant implant; terminal
data/model disposition.

It also defines ownership handoffs to C09/Operating Model, Control Plane, Security, Memory/Knowledge,
Operations, Observability, Interfaces/Tools and Research.

## Conclusion

**CONDITIONAL / COMPLETE FOR THE RECORDED PHASE47 SCOPE.**

14 to 10 under a bounded revalidation, removes overlapping BCI research ownership, adds a benchmark
comparability layer, and creates an explicit post-trial/end-of-support/explant architecture.

It does not establish deployed BCI safety, clinical effectiveness, legal obligations, universal
foundation-model superiority, or production AMOS runtime enforcement.
