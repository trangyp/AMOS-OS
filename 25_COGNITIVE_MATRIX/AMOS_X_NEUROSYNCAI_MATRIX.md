## 133. Confidence Ceiling Rule

$$C(C) \le \min_i C(P_i)$$

for load-bearing premises $P_i$, unless independent revalidation exists.

Example:

```text
architecture documentation confidence = high
biological mechanism confidence = uncertain
```

Then a biological mechanism conclusion cannot inherit the architectural documentation confidence.
