## 96. Local Routing

A single row may be reasoned about locally when:

the phase is unambiguous;

the ALU assignment is unambiguous;

the operator is unambiguous;

the transformation contract is unambiguous;

no cross-row dependency changes the conclusion.

______________________________________________________________________

## 97. Escalation

Escalate beyond one row when:

a later phase depends materially on an earlier phase;

an invariant spans several ALUs;

operator domains/codomains interact;

a proof capsule spans multiple transformations;

a route conflict exists;

runtime state couples multiple ALUs.

______________________________________________________________________

## 98. Atomic Multi-Route Reasoning

If one conclusion requires:

P + D + R + C + F + M

then the reasoning should treat the dependency set coherently rather than selecting incompatible states from different versions or regimes.

This is an AMOS reasoning principle, not evidence that ULK literally implements distributed atomic transactions.

______________________________________________________________________

## 99. Version Consistency

A multi-route conclusion should not silently combine:

P from version A

D from version B

R from version C

when those versions are incompatible.
