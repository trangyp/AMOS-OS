## 1. Canonical Definition & Recursive Tree Topology

The **Universe Structure Tree (UST)** defines the canonical 7-level structural hierarchy linking raw physical reality to emergent, governed synthetic evolution:

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                       UST 7-TIER UNIVERSE STRUCTURE TREE                    │
├─────────────────────────────────────────────────────────────────────────────┤
│ Level 1: P1 — REALITY / ENVIRONMENT (Substrate, Physics, Biophysics)        │
│   │                                                                         │
│   ▼                                                                         │
│ Level 2: P2 — SENSE / EVIDENCE (Observations, Sensor Readings, Modalities)  │
│   │                                                                         │
│   ▼                                                                         │
│ Level 3: P3 — KNOWLEDGE / MEMORY (Episodic, Semantic, Procedural Stores)    │
│   │                                                                         │
│   ▼                                                                         │
│ Level 4: P4 — COGNITION / MODELS (Reasoning DAGs, Causal & World Models)    │
│   │                                                                         │
│   ▼                                                                         │
│ Level 5: P5 — GOVERNANCE / AUTHORITY (Commit Gates, Policies, Verification) │
│   │                                                                         │
│   ▼                                                                         │
│ Level 6: P6 — EXECUTION / AGENCY (Runtime, Specialized Agents, Tool Calls)  │
│   │                                                                         │
│   ▼                                                                         │
│ Level 7: P7 — EVOLUTION / LEARNING (Allostatic Feedback, Model Updates)     │
│   │                                                                         │
│   └───────────────────────────────────↺ (Recursive Feedback to P2/P3/P4)    │
└─────────────────────────────────────────────────────────────────────────────┘
```

> **The UST Invariant Law:** A higher level cannot redefine or invalidate the lower levels upon which it structurally depends:
$$\text{Level}(k) \succ \text{Level}(k-1) \implies \operatorname{Grounding}(\text{Level}(k)) \subseteq \operatorname{State}(\text{Level}(k-1))$$
