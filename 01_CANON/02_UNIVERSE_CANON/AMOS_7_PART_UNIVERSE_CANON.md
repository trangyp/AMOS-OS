# AMOS 7-Part Universe Canon

**Origin architect / steward:** Trang Phan

> **Status:** `ACTIVE_CANON_CANDIDATE`  
> **AMOS Core target:** `v4.4`  
> **Conclusion class:** `AMOS_MODEL`

## 0. Purpose

The **AMOS 7-Part Universe Canon** defines a canonical seven-part decomposition for reasoning about a complete AMOS operating universe.

It provides a stable conceptual partition between:

1. **Reality / Environment**
2. **Sense / Evidence**
3. **Knowledge / Memory**
4. **Cognition / Models**
5. **Governance / Authority**
6. **Execution / Agency**
7. **Evolution / Learning**

The seven parts are not merely repository folders.

They are semantic responsibility classes used to prevent incompatible concerns from collapsing into one undifferentiated system.

```text
REALITY
↓
SENSE
↓
KNOWLEDGE
↓
COGNITION
↓
GOVERNANCE
↓
EXECUTION
↓
EVOLUTION
↺
```

The architecture is recursive rather than strictly linear.

Every transition remains subject to provenance, scope, regime, authority, and integrity constraints.

## 2. Core Separation Laws

The seven parts are intentionally non-equivalent.

```text
REALITY != OBSERVATION
OBSERVATION != KNOWLEDGE
KNOWLEDGE != COGNITION
COGNITION != AUTHORITY
AUTHORITY != EXECUTION
EXECUTION != VALIDATION
VALIDATION != CANON
```

Additional AMOS firewalls apply:

```text
SOURCE_CLAIM != VERIFIED
MODEL != FACT
MODEL != AUTHORITY
MEMORY != CANON
TOOL != PERMISSION
CAPABILITY != AUTHORITY
PROPOSAL != COMMIT
STRUCTURAL_SIMILARITY != CAUSATION
UNKNOWN/GAP != PASS
```

These distinctions are load-bearing.

## 3. P1 — Reality / Environment

### Definition (P1)

`P1_REALITY` represents the target environment about which AMOS receives information or upon which an authorized system may act.

It may include:

```text

DIGITAL ENVIRONMENT
SOCIAL ENVIRONMENT
ECONOMIC ENVIRONMENT
INSTITUTIONAL ENVIRONMENT
LEGAL / REGULATORY ENVIRONMENT
INFORMATION ENVIRONMENT
SYSTEM ENVIRONMENT
```

P1 is not equivalent to the system's representation of reality.

```text
REALITY
!=
INTERNAL_MODEL_OF_REALITY
```

---

### Boundary

AMOS may have access only to observations of P1.

Therefore:

```text
UNOBSERVED_REALITY
→
UNKNOWN/GAP
```

unless supported through valid inference.

Inference remains inference.
