## 1. Canonical Definition

The **UBI 4-Domain Architecture** defines the four irreducibly coupled modal domains that constitute genuine biological and synthetic living intelligence:

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                    UBI FOUR MODAL INTELLIGENCE DOMAINS                      │
├──────────────────────────────┬──────────────────────────────────────────────┤
│ 1. NBI: Neurobiological      │ 2. NEI: Neuro-Electromagnetic & Emotional    │
│    - Spiking neural networks │    - Large-scale phase synchrony             │
│    - STDP synaptic plasticity│    - Affective valence/arousal/dominance     │
│    - Dendritic computation   │    - Dipole resonance & field coupling       │
├──────────────────────────────┼──────────────────────────────────────────────┤
│ 3. SI: Somatic Intelligence  │ 4. BEI: Bioelectromagnetic Intelligence      │
│    - Visceral interoception  │    - Resting membrane potentials (Vmem)      │
│    - Autonomic/vagal balance │    - Gap-junction syncytial gradients        │
│    - Metabolic energy budget │    - Morphogenetic pattern memory & repair   │
└──────────────────────────────┴──────────────────────────────────────────────┘
```

> **Law of Modal Completeness:** An autonomous cognitive organism cannot achieve stable long-horizon survival through symbolic reasoning ($\text{NBI}$) alone. It requires the homeostatic constraint of somatic allostasis ($\text{SI}$), affective coherence ($\text{NEI}$), and bioelectric self-repair ($\text{BEI}$).
