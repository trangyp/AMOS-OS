# P3 — Knowledge & Memory Plane

STATUS: PROPOSED_SPECIFICATION
epistemic_class: AMOS_MODEL
canonical_status: CONDITIONAL
updated: 2026-08-26

## 1. Scope
Durable storage, retrieval, staleness, and consolidation of what the system has learned.

## 2. Canonical questions
- What deserves persistence, at what confidence?
- When does stored knowledge expire or need revalidation?

## 3. Laws
- **P3-1 Typed Persistence**: entries carry provenance + confidence + epoch (KM-1..4).
- **P3-2 Memory Is MODEL**: stored state is a claim about the past; validators outrank memory.
- **P3-3 Consolidation Requires Diversity**: promotion to durable knowledge needs multi-source support.

## 4. Boundaries
Vault/files are externalized memory substrate, not cognition.
