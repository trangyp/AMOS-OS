## 2. Reality-Contact Layer

To prevent the cognitive organism from confusing simulated scenarios with real-world state, every entity and property in the world model is tagged with an explicit **Reality Contact Classification**:

| Reality Status | Definition | Validation Requirement | Epistemic Ceil |
| :--- | :--- | :--- | :--- |
| **OBSERVED** | Confirmed by verified sensor or direct tool execution in current epoch | Recent timestamp + verified exit code | `OBSERVATION` |
| **MEASURED_PROXY** | Inferred from indirect instrument readings or secondary indicators | Calibration curve + error bounds | `DERIVED` |
| **INFERRED** | Deduced from structural causal rules applied to observed entities | Causal model proof closure | `AMOS_MODEL` |
| **SIMULATED** | Generated by forward state transitions within an isolated sandbox | Declared model assumptions | `SIMULATION` |
| **FORECAST** | Projected trajectory into a future timeline $t > t_{now}$ | Probability distribution + horizon | `PROJECTION` |
| **COUNTERFACTUAL** | Evaluated under hypothetical premises known to differ from reality | Explicit branch identity | `COUNTERFACTUAL` |

## 3. Mathematical State Representation

The world state $\mathcal{W}(t)$ is represented as an attributed dynamical graph:

$$\mathcal{W}(t) = \langle \mathcal{V}(t), \mathcal{E}(t), \mathcal{R}(t), \Theta(t) \rangle$$

Where:
* $\mathcal{V}(t)$: Set of typed entities (Agents, Tools, Files, External Systems, Resources).
* $\mathcal{E}(t)$: Set of directed, typed relations (Dependencies, Control, DataFlow, PhysicalAccess).
* $\mathcal{R}(t)$: Active environmental regime (e.g., Development, Sandbox, Production, Degraded).
* $\Theta(t)$: Global parameter vector (Time, Latency, Available Budget, System Entropy).
