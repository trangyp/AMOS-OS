# SOTA Organoid Intelligence 2026

**Date:** 2026-09-04
**Epistemic class:** SOURCE_CLAIM (peer-reviewed + preprints)
**Confidence ceiling:** 0.85 (early-stage research, computation not yet demonstrated at scale)

## 1. Bio-adaptive Processing Unit (Scientific Reports 2026)

- **Platform:** Two-reservoir Brain-on-Chip with microtunnel connections
- **Cells:** Ngn2+ hiPSC-derived cortical neurons
- **Routing:** 1200 µm axonal extension, directed A→B propagation (85-90%)
- **Velocity:** 0.75 m/s median propagation (IQR 0.46-1.00)
- **Limitation:** Routing and readout demonstrated, but NOT computation
- **AMOS binding:** `05_COGNITIVE_ORGANISM` — physical platform for bio-digital hybrid

## 2. Living Intelligence via Organoid-AI Integration (Eng Med 2026)

- **Concept:** Closed-loop organoid + AI for human-level cognitive models
- **Properties:** Self-organizing neural networks, dynamic activity, plasticity
- **Goal:** Biohybrid platforms for learning, memory, task-specific computation
- **AMOS binding:** `05_COGNITIVE_ORGANISM` · `13_MODELS` — hybrid bio-AI architecture

## 3. Simulated OI Architecture — Stable Learning (IEEE IDCIoT 2026)

- **V1.0 Problem:** "Fragile learning" — initial gains followed by rapid decay
- **V2.0 Solution:** Momentum-based learning + lateral inhibition → stable plateau
- **Insight:** Architectural features for memory stabilization are critical
- **AMOS binding:** `13_MODELS` — biological computing architecture patterns

## 4. Brainoware — 3D Organoid Computing (bioRxiv)

- **Properties:** Nonlinear dynamics, fading memory, spatiotemporal stimulation
- **Capability:** Learns from training data, solves nonlinear equations
- **Interface:** Multielectrode array (MEA) for I/O
- **AMOS binding:** `05_COGNITIVE_ORGANISM` — biological reservoir computing

## 5. Cortical Labs — Code-Deployable Biological Computer (2026)

- **Claim:** "World's first code-deployable biological computer"
- **Positioning:** "Nvidia of neural computing"
- **Capability:** Neural cultures display sentience-like behavior
- **AMOS binding:** `14_TOOLS` — unified digital-biological programming interface
