## Naming Conventions

- **Paper agents**: `amos-{domain}-{function}-{qualifier}-agent.json`
- **No `.md` suffix in `depends_on_workflows`**: list the bare workflow name.
- **Skill/agent/workflow triplet**: each paper has exactly one of each, with the same base name.
- **MECE grouping**: one group per primary subject; no agent appears in more than one group.
