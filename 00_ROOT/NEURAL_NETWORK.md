# 0. Purpose

This note is the central graph hub for the AMOS OS vault.

Its purpose is to make the vault render as a connected, navigable knowledge network instead of a collection of isolated folders.

The conceptual topology is:

```text
ROOT
↓
PLANES
↓
SYSTEMS
↓
SUBSYSTEMS
↓
COMPONENTS
↓
CLAIMS / MODELS / STATE
↓
PROVENANCE / DEPENDENCIES / EVIDENCE
```

In Obsidian graph view, this note acts as a high-connectivity routing node between the major architectural planes.

This is a **vault topology model**.

It is not a claim that the filesystem or graph behaves like a literal biological neural network.

Hard boundary:

```text
KNOWLEDGE GRAPH
!=
BIOLOGICAL NEURAL NETWORK
```

The AMOS Full Brain OS source should be used as a structural orchestration model rather than proof of literal consciousness or biological cognition.

# 67. Final Network Law

```text
ROOT
↓
MAP
↓
PLANE
↓
SUBSYSTEM
↓
COMPONENT
↓
CLAIM / STATE / MODEL

EVIDENCE / PROVENANCE
```

The primary invariant is:

> **The AMOS Neural Network connects knowledge without flattening ownership, authority, provenance, epistemic class, or implementation state.**

> **A graph edge means only the relationship explicitly assigned to it; visual proximity is not proof of dependency, causation, or equivalence.**

> **The vault should remain highly navigable but selectively connected: enough linkage to preserve context and lineage, not so much that every node becomes semantically indistinguishable from every other node.**

> **Missing structural nodes remain `UNKNOWN/GAP` or explicit placeholders until source-backed content exists.**
