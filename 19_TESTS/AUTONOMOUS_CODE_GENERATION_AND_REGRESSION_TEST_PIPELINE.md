## 2. Metamorphic Relations & Mathematical Testing Laws

### 2.1 Metamorphic Invariance Formula
Let $f: \mathcal{X} \to \mathcal{Y}$ be the target computational function. For metamorphic input transformation $g: \mathcal{X} \to \mathcal{X}$, there exists output relation $h: \mathcal{Y} \to \mathcal{Y}$ such that:

$$\forall x \in \mathcal{X}, \quad f(g(x)) = h(f(x))$$

- **CRDT Join Monotonicity**: $f(S_1 \cup S_2) \ge f(S_1)$
- **Vector Clock Consistency**: If $e_1 \prec e_2$, then $V(e_1) < V(e_2)$ under arbitrary permutation of non-causally dependent intermediate events.
- **Kelly Sizing Invariance**: Scale invariance under linear currency re-denomination: $f^*(\lambda \mathbf{P}) = f^*(\mathbf{P})$.

### 2.2 Mutation Fault Injection & Kill Ratio
For mutant programs $\mathcal{M} = \{m_1, m_2, \dots, m_K\}$ generated by syntactically perturbing code operators:

$$\text{Mutation Score} = \frac{|\{m_i \in \mathcal{M} \mid \text{TestSuite}(m_i) = \text{FAIL}\}|}{|\mathcal{M}|} \ge 0.90$$
