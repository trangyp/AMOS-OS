# Learning and Memory Fractal Architecture

> Source: `_00_Cosmo brain/memory/learning_memory_architecture.md`
> Epistemic class: SOURCE_CANON

## Core Law

Learning is the reduction of memory entropy through attention, meaning, repetition, feedback, retrieval, and transfer.

## L/M/H Scale

- **L (low learning)**: weak attention, poor encoding, high entropy, low recall
- **M (functional but shallow)**: recognition without reliable recall or transfer
- **H (deep learning)**: strong encoding, retrieval, transfer, validation, and identity integration

## Fractal Scales

signal → word → concept → chunk → lesson → skill → habit → identity → lifelong_system

## Key Formulas

- **AC (attention_capture)** = relevant_signal / total_signal
- **AS (attention_stability)** = sustained_attention / time_required
- **AL (attention_leak)** = irrelevant_signal / attention_capacity
- **ES (encoding_strength)** = attention × meaning × emotion × repetition
- **SE (semantic_encoding)** = meaning_links / new_information

## Composition

Learning + Memory = Attention + Encoding + Consolidation + Retrieval + Feedback + Transfer + Entropy + Validation + Identity
