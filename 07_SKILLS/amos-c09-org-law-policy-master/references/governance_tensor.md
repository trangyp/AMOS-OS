# Governance Tensor

> Source: `_00_Cosmo brain/governance/GOVERNANCE_TENSOR.md`
> Epistemic class: SOURCE_CANON

## Governance Tensor Formula

```
G = T[object, mutation_class, capability, authority, scope, evidence_threshold,
      consequence_radius, reversibility, approval_state, rollback_requirement,
      constitutional_constraints, lineage]
```

## Gate Formula

```
MayAct = Capability ∧ Authority ∧ ScopeFit ∧ EvidenceGate ∧ ConstraintPass
```

**Capability alone is insufficient.** All five conditions must hold for an action to proceed.

## Tensor Dimensions

1. **object**: The entity being acted upon
2. **mutation_class**: M0-M5 classification of the mutation
3. **capability**: The declared capability for the action
4. **authority**: The authority token granting permission
5. **scope**: The scope regime in which the action is valid
6. **evidence_threshold**: Minimum evidence required for the action
7. **consequence_radius**: Blast radius of the action's effects
8. **reversibility**: Whether the action can be undone
9. **approval_state**: Current approval status
10. **rollback_requirement**: Whether rollback is required
11. **constitutional_constraints**: Constitutional law constraints
12. **lineage**: Provenance and ancestry of the action
