# Recursive Structured Claim Framework

For each important claim create the smallest sufficient proof capsule.

## Capsule
- Claim
- Class: VERIFIED / DERIVED / MODEL / CONDITIONAL / COMPETING / UNKNOWN
- Load-bearing premises
- Evidence and provenance
- Scope and regime
- Freshness
- Dependencies
- Competing explanations
- Falsifiers
- Sensitivity threshold
- Confidence ceiling
- Action implication

## Confidence
`Conf(claim) <= min(Conf(load_bearing_premises))`
unless an independently validated path supports a higher ceiling.

## Reuse
Reuse a capsule only if:
- dependencies remain valid,
- scope/regime still match,
- evidence is fresh enough,
- no stronger contradiction appeared.

If one premise fails, invalidate only dependent descendants.
