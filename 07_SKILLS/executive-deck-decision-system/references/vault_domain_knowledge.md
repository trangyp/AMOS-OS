Hệ thống không sụp vì "xấu", mà vì **tổng gain của vòng khuếch đại** vượt **tổng damping của vòng ổn định**.

$$LGD = \frac{\sum \text{(Amplifying loop gains)}}{\sum \text{(Damping loop gains)}}$$

$$LGD > 1 \Rightarrow dao động / cascade$$

$$\rho(A) = \max |\lambda_i|$$

$$LVR = \frac{\tau_{policy/enforcement}}{\sigma_{noise}}$$

$$LVR \uparrow \Rightarrow overshoot$$

# Executive System Model — G–N–D–C–B Dynamical Architecture

Formalized control-system abstraction. Applies to: nervous systems, individuals, institutions, civilizations, financial systems, power grids, ecologies.

---

## I. Core State Variables

$$S(t) = [G(t), N(t), D(t), C(t), B(t)]$$

| Variable | Meaning |
|----------|---------|
| G | Gain (reactivity / amplification factor) |
| N | Noise (unstructured perturbation) |
| D | Damping (stabilization capacity) |
| C | Connectivity (coupling density between nodes) |
| B | Buffer (stored resilience / reserve capacity) |

---

## II. Fundamental Stability Equation

Load:

$$L(t) = G(t) \cdot N(t)$$

Stabilization capacity:

$$R(t) = D(t) + B(t)$$


Universal across scales.

---

## III. Dynamic Evolution Laws

### 1. Gain Dynamics

$$\frac{dG}{dt} = \alpha C - \beta D$$

Gain increases with connectivity, decreases with damping.

### 2. Noise Accumulation

$$\frac{dN}{dt} = \gamma C + \delta G - \epsilon D$$

Noise increases with connectivity and gain, decreases with damping.

### 3. Damping Degradation

$$\frac{dD}{dt} = -\lambda N + \mu B$$

Noise erodes damping; buffer replenishes damping.

### 4. Buffer Depletion

$$\frac{dB}{dt} = -\eta L + \theta S_{external}$$

Buffer decreases when absorbing load; increases via external stabilization.

### 5. Connectivity Expansion

$$\frac{dC}{dt} = \kappa T - \rho F$$

Connectivity increases with technology, decreases with fragmentation.

---

## IV. Phase Transition Threshold

Critical tipping condition:

$$G \cdot N > D + B$$

When crossed:

1. Nonlinear cascades begin
2. Local failures propagate
3. System enters runaway amplification
