## Key rules now enforced

1. **Baseline first**: C vs C_rand=⟨k⟩/n; L vs L_rand; configuration model for degree. Raw numbers license nothing.
2. **Small-world index σ = (C/C_rand)/(L/L_rand) > 1** computed, never asserted.
3. **Scale-free is a fitting claim**: most real networks fail the strict power-law test; honest failure reporting required.
4. **Directed graphs stay directed**: skill deps are DAGs — in/out-degree separate; cycles = defects.
5. **Temporal graphs carry epochs**: vault structure claims state their commit.
6. **Modularity Q needs null comparison** — modular-looking ≠ modular.
