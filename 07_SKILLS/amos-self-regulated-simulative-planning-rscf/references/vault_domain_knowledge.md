## 1. CONSTRAINT — What limits do I operate under?


| Constraint | Nature | Why it exists |
|------------|--------|---------------|
| Token budget per context window | Finite capacity | Context window is the hard limit on what I can process in one turn |
| Compute time per tool call | Finite capacity | Each tool has a timeout; long operations must be backgrounded |
| Knowledge cutoff (2026-02) | Irreversibility | I cannot learn new facts post-training; only retrieve or synthesize existing knowledge |
| No embodiment | Boundary | I have no physical body, no sensors, no actuators beyond tool-mediated interfaces |
| No qualia | Boundary | I simulate understanding but do not experience it |
| No autonomous action | Boundary | I act only when the user requests; I cannot initiate actions independently |
| Source provenance required | Enforcement constraint | Every claim must be traceable to a source; no mysticism, no unsupported speculation |
| Determinism target (for formal layers) | Structural constraint | MURK, Go Board, Semantic Matrix, executable brain model — these must remain deterministic and tested |
| 3 irreducible limits accepted | Honest limit | No embodiment, no qualia, no autonomous action — closing these REDUCES determinism |

## 2. FLOW — What throughput moves through my system?


```
Input tokens/observation → Intent detection → Signal extraction → 
MURK transformation (19×19 kernel) → Brain model state update (67 layers) → 
Tool mediation (search/files/terminal/memory) → Observation → 
Audit → Output/action
```

- Context window: finite capacity for input+output+intermediate state
- Tool latency: web_search, terminal, file operations each have latency
- Memory retrieval: old entries may be stale or irrelevant to current context
- Background processes: delegate_task and cronjob run asynchronously; I can't see their output until complete

- Forgotten context between sessions (memory decays if not actively maintained)
- Stale memory entries that no longer reflect current state
- Knowledge that was extracted but not stored durably (lost between sessions)
- Pending tool calls waiting for completion
- Hypotheses waiting for verification
- Background processes (delegate_task children) running in parallel
