## Three large systems
- **AMOS BRAIN** — Expression Translation · Personality · Omni Kernel · Brain Core · Omniverse Brain · Super Mind (cognition/emotion/consciousness)
- **AMOS RUNTIME** — OS Kernel · RSCF · H/M/L · provenance · memory · competing hypotheses · firewalls · repair/replay/audit
- **AMOS CONTROL/BODY** — capability manifests · read sets · authorization · semantic transactions · tools · state stores · commit/rollback

## Five primary Full Brain OS components (preserve hierarchy; do NOT replace with runtime abstraction)
`FullBrainOS = { B_core, K_omni, B_omniverse, P_personality, T_expression, G_gap }`
- `brain_core` = capability/intelligence (26 engines: UBI BEI/NBI/NEI/SI/UBI + domain C01–C12 + fabrication/tech)
- `omni_kernel` = structural coordination / routing / governance / safety / integration / evaluation
- `omniverse_brain` = large-scale representation of domains, states, observers, scenarios, systems, fabrication
- `personality` = expression/interaction characteristics (not domain cognition)
- `expression_translation` = front door (RAW EXPRESSION → ... → LOGIC-READY AMOS INPUT); NOT a domain engine
- `gap_management` = constrains system by known limitations

## Expression Translation is the front door
RAW EXPRESSION → Expression_Classify → Intent_Extraction → Meaning_Core → Structural_Logic_Map
(actors/systems/variables/constraints/time/direction) → Emotion_to_Signal → Symbolism_to_Structure →
Expression_Normalise → LOGIC-READY AMOS INPUT. Boundary: Human representation ≠ Internal reasoning representation.

## Brain Core = engine ecosystem (NOT one engine)
`AMOS_UBI_FULL_SUPER_STACK`. 26 engines: Biological/human (BEI,NBI,NEI,SI,UBI_Super) · Fabrication/tech
(AUTOMATION_ENGINE_v2, SUPER_CODE, SUPER_FACTORY, SUPER_Design, Tech_Engine_vInfinity_MAX) · Domain
(C01_meta_logic … C12_earth_ecology) · Canon/high-depth variants (C_CANON_SUPER_CLEAN_x100k, etc. — preserve as distinct).

## Omni Kernel = kernel architecture / coordination field (NOT "a kernel")
Clusters: Root · Meta-cognition · Math foundations · Human/society · Machine architecture · UBI stack ·
Planetary stack · System kernels · + governance/routing/safety/blueprints/integration_matrix/evaluation.
Dynamic routing → activate MINIMUM relevant region, then integrate (not "run whole brain").
Integration graph is graph-shaped (hierarchy + network + routing).

## Omniverse Brain = world/system model (Agent layer is DOWNSTREAM inside it)
Ten layers: Foundational Law (ULK_CORE, QCLS_CORE, METRIC_OF_INTEGRITY) → Physical & Quantum → Information &
Complexity → Biological & Consciousness (UBI_CORE, HUMAN_STATE, EMOTION, C04) → Social & Institutional
(MULTI_AGENT, CRISIS, GOVERNANCE_AND_POLICY) → Planetary & Ecological (PSI_CORE, TSS_TPE, RESOURCE/INFRA) →
Temporal & Scenario → Multiverse & Modality → Observer & Perspective → Agent & Fabrication.
TSS/TPE/PSI appear as capability + placement + semantic function simultaneously → one object, many relations.

## Super Mind OS = separate compatible plane (do NOT silently nest under Full Brain OS)
Cognition (COGNITION_INFINITY_KERNEL) + Emotion (MEGA_HUMAN_ENGINE) + Consciousness
(SUPER_CONSCIOUSNESS_Engine_vInfinity). Cognition layers: Meta Logic → Structural Reasoning → Cognitive
Infrastructure → Multi-possibility → Biological Logic → Integration. Relation to Full Brain OS: **compatible/
integrable**, not parent-child.

## Omega Infinity Stack = meta-orchestration plane
System Kernel · Domain Engine · Expression/Interface · Execution/Fabrication · Audit/Expansion — confirms
kernel/engine/expression/execution/audit are distinct dimensions.

## AMOS OS Kernel v4.4 = reasoning runtime (does NOT overwrite Full Brain OS)
Perceive → Route → Admit → Plan → Schedule → Execute → Observe → Repair → Audit → Finalize.
Owns typed state, RSCF, proof graphs, memory, provenance, authority, transactions, replay, finalization.

## RSCF = epistemic substrate (not prose)
Objects: claim/class/premises/evidence/provenance/scope/regime/freshness/dependencies/competing hypotheses/
falsifiers/confidence ceiling. State kinds: OBSERVATION, SOURCE_CLAIM, DERIVED, MODEL, DECISION, UNKNOWN.

## Infrastructure Control Plane = below cognition, above effects (do NOT replace Omni Kernel governance)
Omni Kernel governance = cognitive routing/kernel selection/priorities/integration.
Control Plane = mutable state/authority/provenance/freshness/effect authorization/semantic tx/commit/rollback.
Authority gate: FreshAuthority AND CausallyPrior AND EffectBound AND EligibleAtCommit.
KNOWING HOW ≠ BEING PERMITTED.

## Skills are deployment artifacts, not the AMOS ontology
AMOS Engine ≠ host Skill · AMOS Kernel ≠ host Tool · AMOS Agent ≈ host Agent only partially.
Deployment bindings are DEPLOYMENT, not definitions.

## Eight independent axes
1 Cognitive organization · 2 Capability granularity · 3 Cognitive mode (EXPLORE/DIAGNOSE/DESIGN/AUDIT/MEASURE) ·
4 Scale (H/M/L) · 5 Epistemic state · 6 Execution · 7 Governance · 8 Deployment.

## Kernel / Engine / Agent placement
Full Brain OS → {Omni Kernel (kernel field), Brain Core (engine field)} → capability space → Agents (when
goal-ownership/authority/planning/independence required). Primitive kernel → composite engine → bounded agent.
NOT a universal linear hierarchy.
