# Fractal State Skill

## Purpose
Manages the fractal state of the AMOS organism across multiple scales.
Provides H/M/L (High/Medium/Low) progressive disclosure for efficient
access to broad knowledge without scanning everything.

## Process
1. Determine the appropriate scale level (H/M/L)
2. Load capsule-first summary at the chosen level
3. Expand recursively only when deeper detail is needed
4. Track information gain at each expansion
5. Stop when information gain falls below threshold

## Usage
Use when context is large or many subsystems exist.
Apply for fast access to broad knowledge.
