## Phase 1: Foundational Writing Principles (v1.0)
**GOAL**: Build highest-level Vietnamese writing system for corporate leadership, national planning, strategic negotiation, tech markets, executive comms. Focus: clarity, precision, logic flow, real impact, persuasion of senior leadership.

### 10 Foundational Principles
1. **Structure-first**: Objective → Arguments → Evidence → Conclusion. Never write without structure.
2. **Every sentence answers a question. Every paragraph solves a problem.**
3. **Write for clarity/decision, not "beauty"**: rõ, hiểu, ra quyết định.
4. **Executive tone**: trọng tâm, đẳng cấp, súc tích, không rườm rà.
5. **No emotion, no flowery language**: phẳng, chuẩn, gọn.
6. **Logic priority**: cause→effect, root cause→solution→action.
7. **Short words, short sentences, short points — but deep.**
8. **Always close the loop**: open issue → process → action conclusion.
9. **Signature style**: sắc, thẳng, sạch nhiễu, trọng lượng.
10. **Zero waste**: no extra words, lines, or ideas.

### Universal Writing Structure (8 Rules)
- Rule 1: Every doc starts with "What problem does this solve?"
- Rule 2: 40% diagnosis — 40% solution — 20% recommendation
- Rule 3: 3-part structure: Context — Problem — Solution (always works)
- Rule 4: Long docs = 7 sections: objective, current state, gap, root cause, options, impact, implementation conditions
- Rule 5: For busy leaders: What? Why? How? When? Who? Cost?
- Rule 6: For tech teams: Standards, requirements, changes, risks, timeline, metrics
- Rule 7: For government: Systemic benefit, safety, standards, social impact, national strategy alignment
- Rule 8: For foreign partners: Clear, transparent, data-driven, logical, no circularity

## Phase 2: Strategic National & Corporate Leadership (v2.0_PHASE2)
**GOAL**: Elevate to national strategy and corporate executive level. 40 cognitive layers: reader psychology, persuasion models, information gravity, power positioning, ambiguity removal, rhythm/flow, density management, high-authority voice, risk engineering, actionability, tech leadership writing.

### Key Sections (12)
| Section | Focus |
|---------|-------|
| SECTION_10_READER_PSYCHOLOGY | Leaders read to decide, not understand. Patience decreases with rank. Focus: benefit, risk, cost, timeline, responsibility, feasibility. |
| SECTION_11_DECISION_GRAVITY_ENGINE | Every sentence must have gravity (data, impact, comparison, urgency). Zero weak words: "maybe", "perhaps", "hope". |
| SECTION_12_EXECUTIVE_PERSUASION_MODEL | Persuade = show you see more, clearer, further. Logic/impact/risk, not emotion. Always 3 impacts: financial, operational, human. Always 2 options: standard + fast. |
| SECTION_13_DIAGNOSTIC_WRITING | Open with systemic diagnosis. Diagnosis > solution. Structure: root cause → manifestation → impact → risk of inaction. |
| SECTION_14_SYSTEMIC_EXPLANATION | 3 objects: process, people, data. Clear causality chains: A → B → C. No unnecessary technical detail. |
