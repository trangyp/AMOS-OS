# Adversarial Validation — part 2

For consequential conclusions:
1. construct strongest supported conclusion
2. seek contradiction using a genuinely different path
3. test correlated provenance
4. test stale premises
5. test scope leakage
6. test hidden dependency
7. test causal overreach
8. test a stronger alternative explanation
9. test sensitivity to the smallest flipping premise

If challenge succeeds:
downgrade, condition, preserve COMPETING, or return UNKNOWN/GAP.
