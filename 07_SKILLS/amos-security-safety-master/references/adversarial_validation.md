## Adversarial Validation — part 2

For consequential conclusions:

1. construct strongest supported conclusion
1. seek contradiction using a genuinely different path
1. test correlated provenance
1. test stale premises
1. test scope leakage
1. test hidden dependency
1. test causal overreach
1. test a stronger alternative explanation
1. test sensitivity to the smallest flipping premise

If challenge succeeds:
downgrade, condition, preserve COMPETING, or return UNKNOWN/GAP.
