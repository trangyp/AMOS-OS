## 100. Canonical Definition

$$
\boxed{
\textbf{
Intelligence is recursive distinction under constraint:
it represents possibilities,
removes inadmissible states,
manages residual uncertainty,
searches or predicts within what remains,
selects and validates an outcome,
and uses the consequences to modify future distinction.
}
}
$$

The integrity condition is:

$$
\boxed{
\textbf{
Constraint validity is more important than constraint quantity.
}
}
$$

because:

$$
\boxed{
\text{False Constraint}
\rightarrow
\text{Correct Possibility Removed}
\rightarrow
\text{Efficiently Wrong Reasoning}
}
$$

The recursive-observer extension is:

$$
\boxed{
\textbf{
The system performing the distinction may itself be changed by the consequences of previous distinctions.
}
}
$$

Therefore:

$$
\boxed{
O_{t+1}\neq O_t
}
$$

can be a legitimate adaptive-system model without implying literal identity between AMOS symbolic architecture and biological neural organization.

## 101. Terminal Epistemic Boundary

The framework supports a powerful structural synthesis.

It does not license collapsing the participating domains into one mechanism.

Therefore the terminal AMOS rule is:

$$
\boxed{
\textbf{
Preserve the shared structure without erasing the differences that make each domain what it is.
}
}
$$

Or operationally:

```text
DISTINGUISH
    ↓
REPRESENT
    ↓
CONSTRAIN
    ↓
PRESERVE VALID POSSIBILITIES
    ↓
MANAGE UNCERTAINTY
    ↓
SEARCH ONLY WHERE NECESSARY
    ↓
SELECT
    ↓
VALIDATE
    ↓
LEARN
    ↓
UPDATE THE OBSERVER
    ↺
```
