# Lawful System Perception Model

`LAWFUL_SYSTEM_PERCEPTION_MODEL.md` is the canonical Knowledge Plane reference artifact for the **Lawful System Perception Model** within `11_KNOWLEDGE/05_FRAMEWORKS`.

It defines how cognitive agents perceive systems through the lens of **explicit governing laws and constraints**, rather than through noisy descriptive surface features.
