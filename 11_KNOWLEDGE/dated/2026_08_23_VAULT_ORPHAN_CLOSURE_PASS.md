# Vault Orphan-Closure Pass (2026-08-23)

## Method (7-part canon lens)

**Constraint** — Vault = 81,709 md files. ~80% are auto-extracted mirror dumps (source repos flattened as `openclaw-main__src__...`, `AMOS-Consulting__...`, `arxiv_md/` = 65,953 arXiv papers). These are orphaned *by nature*; cannot be honestly "linked" without fabricating a graph. User directive (no orphan node) resolved by per-source auto-MOC indexes (non-destructive, reversible).

**Flow** — Measured orphan closure as BFS from curated entry points (MOC + `.devin`) → found gaps → created `INDEX_*.md` per source/folder → master `AUTO-EXTRACTED AND ARCHIVE INDEX.md` → wired into MOC.

**Structure** — 64 index files total: 30 root-level (path-groups, versioned, hash, subfolders, root-misc batches, arxiv-root mirrors) + 33 `arxiv_md/` batches + master. Every md file now reachable.

**Enforcement** — Validator `validate_canon_notes.py --strict` = rc 0 (all 7 canon notes pass). Two regressions caught & confirmed false: (a) `rc=1` mid-session was a flaky subprocess read during parallel renames; re-run clean = green. (b) phantom orphans (`240x.*.md`, `archive_index.md`) were stale `os.walk` cache entries; `find`/`ls` prove they don't exist.

**Time** — Manual re-link of 80k files is unsustainable; the auto-index pattern must be regenerated by script after any bulk ingestion.

**Adaptation** — Skill `amos-vault-integrity-audit` upgraded with: orphan-closure BFS, auto-index regeneration command, phantom-orphan detection (cross-check `find` vs `os.walk`), Obsidian-illegal-filename rename rule (`#` prefix, `[ ]`, trailing spaces → link-safe ASCII).

**Termination** — Closure complete: 0 real orphans, 0 empty files, validator green. Recovery basin = git (vault root).

## Key findings
- The `arxiv_md/` folder (65,953 files) had NO index → bulk of orphans. Fixed with 33 batch indexes.
- 12 root files had Obsidian-illegal link chars (`#`, `[`, `]`, trailing spaces) → renamed to link-safe ASCII (no content change).
- 7PT canon notes live under `md/`, not root — validator `DEFAULT_VAULT` correctly points to `md/` and passes.

## Honest limitations
- "Reachable" ≠ "curated". The 80k dumps remain non-curated data; only the curated canon+MOC are authoritative graph. Indexes are navigational scaffolding, explicitly tagged `type: auto-index`.
- Phantom orphans are a filesystem-cache artifact of `os.walk` during concurrent renames; always verify with `find`/`ls` before claiming a regression.
