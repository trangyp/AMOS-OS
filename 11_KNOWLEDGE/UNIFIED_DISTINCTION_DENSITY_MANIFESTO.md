For any system X, there exists a distinction space D_X such that:

- Distinctions are the primitive generators of structure

### Axiom 2 (State Space Generation)
The state space S_X of system X is generated by distinctions:
- |S_X| = 2^{N_Δ(X)}

### Axiom 3 (Resource Conservation)

- Total distinction content is conserved in closed systems

### Axiom 4 (Invariant Preservation)

- J(T(X)) = J(X) for valid transformations T
- Invariant-preserving compression defines intelligence

## 2. Definitions

### Definition 2.1 (Distinction Space)
Let D_X be the set of all admissible distinctions for system X.

### Definition 2.2 (Distinction Count)
N_Δ(X) := |D_X| = number of admissible distinctions in X

### Definition 2.3 (Effective Distinction Content)
For state space S_X with probability distribution p(s):
```
H_Δ(X) := -∑_{s∈S_X} p(s) log₂ p(s)
```
This is Shannon entropy interpreted as effective distinction content.

### Definition 2.4 (Compressed Distinction Content)
```
K_Δ(X) := min_M (L(M) + L(X|M))
```
The minimum description length of system X under model M.

### Definition 2.5 (Resource Measure)
μ(X) is a resource measure depending on domain:
- Volume for physical systems
- Time for temporal processes  
- Energy for thermodynamic systems
- Memory for computational systems
- Sample count for statistical systems

### Definition 2.6 (Unified Distinction Density)
For λ ≥ 0, the unified distinction density is:
```
ρ_Δ(X) := (1/μ(X)) (H_Δ(X) + λ K_Δ(X))
```
