# Source / Model / Empirical Boundary

The AMOS corpus contains:
- canonical/source-defined architecture
- formalizations
- symbolic equations
- conceptual runtime specifications
- reported benchmark records
- empirical/scientific references in some domains

Preservation does not equal validation.

Before external factual use:
1. identify claim class
2. identify source
3. identify whether equation is standard math, source model, or empirical result
4. verify external scientific/legal/financial facts when needed
5. preserve AMOS terminology without silently upgrading model claims into laws
