EXTENSIONAL REALIZABILITY AND CHOICE FOR DEPENDENT
TYPES IN INTUITIONISTIC SET THEORY
EMANUELE FRITTAION
Abstract. In [16], we introduced an extensional variant of generic realizability [21],
where realizers act extensionally on realizers, and showed that this form of realizability
provides inner models of CZF (constructive Zermelo-Fraenkel set theory) and IZF (intu-
itionistic Zermelo-Fraenkel set theory), that further validate ACFT (the axiom of choice
in all ﬁnite types). In this paper, we show that extensional generic realizability validates
several choice principles for dependent types, all exceeding ACFT. We then show that
adding such choice principles does not change the arithmetic part of either CZF or IZF.
1. Introduction
In this paper, we prove that extensional generic realizability [16] validates the natural
extension of ACFT (the axiom of choice in ﬁnite types) and RDCFT (relativized dependent
choice in ﬁnite types) to transﬁnite dependent types. By routinely combining extensional
generic realizability with a Beeson-style forcing construction, along the lines of [14, Section
5], we also show that T augmented with such choice principles is conservative over T for
arithmetic sentences, for a host of intuitionistic set theories T. In particular, we extend
Friedman and Scedrov’s result [14] that IZF augmented with CACFT (ﬁnite type countable
choice) and DCFT (ﬁnite type dependent choice) is arithmetically conservative over IZF.1
Generic realizability2 is distinguished by its treatment of unbounded quantiﬁers: a
realizer of ∀x ϕ(x) (resp. ∃x ϕ(x)) must be a realizer of ϕ(x) for every x (resp. some x).
This strain of realizability goes back to Kreisel and Troelstra’s realizability for theories
of elementary analysis with species variables [20, Section 3.7].
A direct descendant of
Kreisel and Troelstra’s realizability was applied to nonextensional theories of higher order
arithmetic and set theory by Friedman [13] and Beeson [5, 7]. McCarty [21, 22] developed
a version of generic realizability that applies directly to the extensional set theory IZF. He
also employed, inspired by Feferman [11], arbitrary partial combinatory algebras, rather
than just natural numbers. Whereas McCarty’s approach is geared towards IZF, it was
shown in [27] that CZF suﬃces for a formalization of generic realizability, thus providing
a self-validating semantics for CZF and other fragments of IZF.

The basic plan for interpreting choice via extensional generic realizability can be easily
described as follows. Consider the ΠΣI case. We start out with a realizability universe
Vext(A), which is built on top of a given partial combinatory algebra A. We then construct
an extensional type structure on A (Deﬁnition 4.3). In particular, types are elements of
A. Next, we single out nice sets of Vext(A) of the form Xσ, where σ runs over all types
(Deﬁnition 4.9). We think of these sets as the extensions of the corresponding types. With
this identiﬁcation in mind, we show that ACσ,τ and RDCσ hold in Vext(A) (Theorem 4.17
and Theorem 4.18). Finally, we prove that every ΠΣI-set of Vext(A) is nicely represented
(Theorem 4.14 and Theorem 4.16). Niceness is captured by a suitable notion of being
injectively presented in Vext(A) (similar notions can be encountered in [2, 3, 24, 25, 26]).
It will be crucial to work with extensional type structures.

2.2. Countable and dependent choice. The full axiom of choice AC is known to imply
forms of excluded middle [10]. For example, CZF + AC + separation = IZF + AC = ZFC
(cf. [4]). Nevertheless, countable choice and several forms of dependent choice are deemed
constructively acceptable.
Note that RDC is an axiom of Myhill’s CST (constructive
set theory) [23], which provides a standard set-theoretical framework for Bishop-style
constructive mathematics [8]. Dependent choice also features in Brouwer’s intuitionistic
analysis (cf. [31]).
Countable choice (ACω): if ∀n ∈ω ∃y ϕ(n, y), then there exists a function f with
dom(f) = ω such that ∀n ∈ω ϕ(n, f(n)), for all formulae ϕ.
Dependent choice (DC): if ∀x ∃y ϕ(x, y), then for every x there is a function f with
dom(f) = ω such that f(0) = x and ∀n ∈ω ϕ(f(n), f(n + 1)), for all formulae ϕ.
Limited dependent choice (DC†): if X is a set and ∀x ∈X ∃y ∈X ϕ(x, y), then for
every x ∈X there is a function f : ω →X such that f(0) = x and ∀n ∈ω ϕ(f(n), f(n+1)),
for all formulae ϕ.
Relativized dependent choice (RDC): if ∀x (ψ(x) →∃y (ψ(y) ∧ϕ(x, y))), then for
every x such that ψ(x), there is a function f with dom(f) = ω such that f(0) = x and
∀n ∈ω ϕ(f(n), f(n + 1)), for all formulae ψ and ϕ.
Limited relativized dependent choice (RDC†): if X is a set and ∀x ∈X (ψ(x) →
∃y ∈X (ψ(y)∧ϕ(x, y))), then for every x ∈X such that ψ(x), there is a function f : ω →X
such that f(0) = x and ∀n ∈ω ϕ(f(n), f(n + 1)), for all formulae ψ and ϕ.
