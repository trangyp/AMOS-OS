Abstract
We find that event features extracted by large language models (LLMs) are effective for
text-based stock return prediction. Using a pre-trained LLM to extract event features
from news articles, we propose a novel deep learning model based on structured event
representation (SER) and attention mechanisms to predict stock returns in the cross-
section. Our SER-based model provides superior performance compared with other
existing text-driven models to forecast stock returns out of sample and offers highly
interpretable feature structures to examine the mechanisms underlying the stock return
predictability. We further provide various implications based on SER and highlight the
crucial benefit of structured model inputs in stock return predictability.
JEL Classification: G11, G12, G13, G14
Keywords: large language models, structured event representation, textual analysis,
stock return predictability, attention model.

Introduction
Text data has become an increasingly important source of information in finance.
Un-
like structured data, text data contains rich and high-dimensional information that reflects
both the current states of assets and expectations about future investment opportunities
(Gentzkow, Kelly, and Taddy, 2019; Hassan et al., 2025). The typical method to extract
textual information is to transform text data either into sentiment features representing emo-
tional polarity (e.g., Tetlock, 2007; Tetlock, Saar-Tsechansky, and Macskassy, 2008; Tetlock,
2010; Loughran and McDonald, 2011; Jegadeesh and Wu, 2013; Hassan et al., 2019; Ke,
Kelly, and Xiu, 2022), or into low-dimensional semantic vectors using pretrained language
models (e.g., Chen, Kelly, and Xiu, 2022; Bybee, Kelly, and Su, 2023; Tan, Wu, and Zhang,
2023; Cong et al., 2025; Jha, Liu, and Manela, 2025). These derived representations are
then linked to asset returns to capture latent state variables embedded in financial language
that help explain cross-sectional and time-series variations in asset prices.
The existing approaches, however, are limited to interpretability. The process of map-
ping an article to a numerical vector is inherently opaque, and leaves it unclear how the
model derives such representations or what the vectors signify. This opacity poses a par-
ticular challenge for text-driven return prediction, where it is essential to understand not
only the predictive outcomes but also the underlying mechanisms linking textual content to
expected returns. Without interpretability, it becomes difficult to evaluate the reliability of
the extracted information and to justify subsequent decisions based on these model outputs.
To address this limitation, in this paper, we propose an alternative approach beyond
traditional semantic representations: structured event representation (SER). Our key
innovation lies in using large language models (LLMs) not merely as embedding tools but
as controllable extractors that identify key events from unstructured text data. Specifically,
we integrate task-specific prompt design, in-context exemplars, external knowledge graphs,
and post-extraction validation to build an LLM-based event-identification framework. With

this framework, we are able to transform an article into multiple event triplets (i.e., subject-
action-object) and treat them as the basic features for model input. By examining these
human-readable events, we can learn how they are mapped to stock returns and conduct
attribution analyses for our model.
Taking advantage of the SER structure, we propose a novel modeling architecture that
can effectively link SERs to stock returns. First, we introduce a stock-specific representation
which encodes firm-level characteristics relevant to stock returns. More importantly, such
a stock-level representation can interact with event representation in our model, so that we
can account for heterogeneous event effects, reflecting the fact that identical events often
generate asymmetric market reactions across firms. For example, Donald Trump’s election
victory may benefit traditional-energy companies while hurt clean-energy stocks. Second,
because multiple events can occur at the same time with varying levels of importance, we
allow the model to differentially weight events to capture their heterogeneous effects on stock
returns. This is achieved through an attention mechanism that dynamically assigns weights
to events (Vaswani et al., 2017), thereby enabling the model to place greater emphasis on
events that are more informative for return estimation. Finally, we use the aggregated event
representations to predict stock returns through a multi-layer perceptron (MLP), optimized
using mean squared error (MSE) loss.
We empirically validate our model on a return prediction task for U.S. stocks using
newspaper data with full texts. In particular, we first process all newspaper data into events
(i.e., each SER with subject, action, and object), and then train the designed attention
model with SERs as inputs to forecast stock returns. Out-of-sample results consistently
demonstrate that structuring textual information into event representations yields markedly
stronger predictive performance across both daily and weekly horizons. The model deliv-
ers an annualized return of 10.93% with a Sharpe ratio of 0.78 for daily predictions and
5.23% with a Sharpe ratio of 0.63 for weekly predictions, substantially outperforming both

Our research is closely related to the literature in text-driven asset pricing. There are
primarily two approaches to incorporating text data into asset pricing models. The first
approach focuses on analyzing the correlation between document word characteristics and
expected returns, such as sentimental polarity (Tetlock, 2007; Tetlock, Saar-Tsechansky,
and Macskassy, 2008; Tetlock, 2010; Loughran and McDonald, 2011; Jegadeesh and Wu,
2013; Jeon, McCurdy, and Zhao, 2022).

stock market responses to text data, although their performance is limited in recent periods.

could be prone to bias. Furthermore, the sentiments expressed by different media outlets
regarding the same event may vary significantly, introducing substantial noise and potential
bias (Ashtiani and Raahemi, 2023; Goldman, Gupta, and Israelsen, 2024).
Another way to extract word characteristics in text data is topic modeling, which clusters
texts into different topic categories through their word distributions.1 For instance, Bybee

While these semantic feature-based approaches have achieved promising predictive per-
formance, they often suffer from limited interpretability, because words or entire articles
are transformed into dense vector representations and are thus inherently opaque. Such a
transformation process abstracts away the original linguistic and economic meaning of the
text, making it difficult to directly link model inputs to outcomes (e.g., stock returns). Even
when some generative LLMs can be instructed to provide explanations, the resulting de-
scriptions constitute post-hoc rationalizations rather than faithful accounts of the model’s
actual inference (Parcalabescu and Frank, 2024). Moreover, Bybee (2023) shows that LLM-
generated expectations exhibit systematic belief distortions akin to well-known biases in
human expectation formation, thereby limiting their reliability as direct forecasting tools.
Taken together, these limitations underscore the need for an approach that preserves the
rich information contained in textual data while also ensuring transparency in how predic-
tive signals are generated. Motivated by this gap, our study proposes a framework that
incorporates both interpretable features and an interpretable predictive model. Our method
extracts structured and event-level features with clear economic semantics (i.e., SER), in-
tegrates them into a novel model architecture and uses a gradient-based interpretability
method to link predicted outcomes directly to the most influential events. In summary,
we propose a new event-driven framework that combines LLM-extracted structured events
with deep learning prediction and gradient-based interpretation. The study bridges the gap
between high-dimensional textual data and interpretable financial forecasting, highlighting
the value of event-centric analysis in asset pricing.

Methodology
2.1
Event Extraction through Large Language Model
Our goal is to develop a modeling architecture that can effectively predict asset returns
through structured event information from text data. The first step is to design a reliable
method for extracting events from unstructured text and transforming them into structured
representations suitable for prediction. In this section, we outline an LLM-based framework
for event extraction in Figure 1. LLMs have been extensively applied to diverse text under-
standing and generation tasks (Bybee, 2023; Jha et al., 2024; Zhou, 2025). By inputting raw
text, such as news, firm announcements, reports, or other information disclosures, into an
LLM, we can use a simple prompt like “please extract the events in this article” to obtain
relevant outputs. However, such na¨ıve prompting is inadequate to produce consistent and
structured representations of events for effective downstream prediction.
Figure 1 about here
There are several challenges in employing LLMs to extract targeted event features. First,
it’s essential to clearly specify the format of the event representation. This format should
be concise, structured, and informative, while also being suitable for use as input to the
subsequent stock prediction model. Second, the same event may be scattered in different
places, and the associated entities are often expressed inconsistently across multiple articles
(e.g., ‘Donald Trump’ and ‘President Trump’, ‘stock growth’ and ‘stock profit’). If these se-
mantically identical mentions are treated as different inputs, the same economic information
becomes fragmented across surface forms, weakening the model’s ability to learn meaningful
patterns. Consolidating these variants into unified entity representations is therefore essen-
tial to preserve signal strength and ensure comparability across time and firms. Finally,
despite detailed prompt specifications, there remains the risk that LLMs produce content
unrelated to the prompt instruction, a phenomenon known as hallucination (Bai et al., 2024).
8


## Page 10


To address these challenges and design effective prompts, we draw on insights from re-
search in prompt engineering, an emerging research area in computer science that explores
strategies for improving LLM performance through prompt design. Following this spirit,
we design a prompt template tailored to each challenge in order to obtain structured and
effective event representations. To address the first challenge, defining a structured format
for event representation, we require the LLM to express each extracted event as a triplet
consisting of (subject-action-object). This triplet structure allows the model to retain the
core elements of an event, while filtering out narrative details that introduce noise but rarely
contribute predictive value. By compressing linguistically diverse descriptions into a unified
and comparable representation, the triplet format enables economically similar events to be
treated consistently across articles and over time, which is crucial for downstream prediction
and analysis (Deng et al., 2019; Lee and Ram, 2024). Recent research demonstrates that
LLMs, when guided by carefully crafted prompts, can be steered to generate outputs that
adhere to this triplet-based representation rather than producing unstructured free text (Iga
and Silaghi, 2024; Kommineni, K¨onig-Ries, and Samuel, 2024). Building on this insight, we
design the following format requirements in our prompts to obtain structured representations
of event features:
“The output should be a JSON-formatted sequence of events. Specifically, each event
should include the following keys with corresponding values: ‘subject’, ‘action’, ‘object’, and
‘context’. The ‘subject’ key must contain the text of the extracted subject entity. The ‘action’
key must include the verb or action connecting the subject to the object. The ‘object’ key
should represent the text of the entity which is the object of the action. The ‘context’ key
must provide additional context information about the event in the original article.”
Specifically, the first three elements (‘subject’, ‘action’, and ‘object’) form a triplet repre-
senting an event, and ‘context’ provides the location information of the event in the original
text, which can facilitate a post-hoc check of the quality of extracted events as well as

interpretable analysis.
For the second challenge, we need to ensure that event entities referring to the same
real-world object are marked consistently, even when expressed in different surface forms.
To implement this requirement, we draw on traditional entity linking techniques (Baigang
and Yi, 2023), which commonly rely on open-source knowledge graphs to assign canonical
URLs as identifiers. Among these resources, DBpedia is one of the most widely used knowl-
edge bases for linking textual mentions to standardized entity entries (Deng et al., 2019).2
Accordingly, we require the LLM to return such DBpedia URL for every subject and object,
thereby providing a standardized identifier across instances. This design helps mitigate in-
consistency issues: even when different words are used, the same entity will be mapped to
the same DBpedia link. A further advantage is that the same event reported across multiple
articles can be represented in a uniform way, which facilitates the later merging of duplicates.
At this stage, the final event representation format is established, as illustrated in Figure 1.
Each event is represented through six attributes: subject, subject link, action, object, object
link, and context.
Finally, to mitigate potential hallucinations, we include selected examples into the prompt,
pairing raw textual materials as inputs with their corresponding structured event represen-
tations as outputs. This process, known as in-context learning, enables LLMs to grasp task
patterns through analogy, which has been shown to effectively improve the quality of the out-
put (Dong et al., 2022). Additionally, we implement a post-processing validation to ensure
the reliability of the generated results. This validation is conducted through the LLM-based
judge, which evaluates each output against predefined requirements, such as whether the
output conforms to the required subject–action–object triplet structure, whether all neces-
sary event fields are present, and whether the extracted content is semantically consistent
with the input text. Outputs that fail this validation are either automatically corrected or

and Samuel, 2024).
2.2
Stock Return Prediction through LLM-extracted Events
Having outlined the procedure for extracting structured events from textual signals, we now
turn to the central task of predicting stock returns using these representations. Our objective
in this section is to construct a deep learning framework that links event-based features
to expected returns.
Specifically, we consider two related prediction tasks, daily return
prediction and weekly return prediction.
While both tasks share a unified formulation,
model architecture, and training strategy, they differ slightly in the design of the feature
aggregation module. These differences, together with the common framework, are described
in detail below.

2.2.1
Task Formulation
Given the set of events {xevent}N,i,t associated with stock i during time window t, our ob-
jective is to predict the expected return ˆyi,t+1 in the subsequent time window t + 1. In
the daily return prediction task, t corresponds to a single trading day, while in the weekly
return prediction task, t denotes one trading week. Accordingly, t + 1 represents the next
day or the next week in the two tasks, respectively. The set {event}N,i,t contains N events
linked to stock i within time window t, with each event represented in the structured format
illustrated in Figure 1.
In addition to event features, we introduce a stock-identifier representation as part of
the model input. This input provides a compact numerical encoding of each stock (e.g.,
a ticker or PERMNO), allowing the model to process a large universe of stocks within a
unified latent space.3 It enables the model to learn latent firm-level characteristics, such as
differences in business exposure, industry positioning, or other firm-level patterns that are
not fully captured by observable firm features. More importantly, existing text-based return
prediction studies typically rely on textual features alone and implicitly assume homoge-
neous responses across stocks. In practice, however, identical events often have markedly
different implications for different firms. For example, the same event may benefit some firms
while adversely affecting others, depending on their underlying exposures and connections
to the entities involved. With the stock-level representation, our model can allow for such
stock-specific representations to interact with event representations, thus accommodating
heterogeneous event responses and enabling the same event signal to translate into different
return effects across stocks.
Formally, we include a stock identifier, stock IDi, as an auxiliary input to indicate the
target stock, which is then mapped into a continuous embedding space (in Section 2.2.2).

2.2.2
Feature Embedding
To map the inputs into expected returns, the first step is to transform both textual and
identifier features into vector representations. This step consists of two modules: the event
encoder (denoted as ①in Figure 2) and the stock ID encoder (denoted as ②in Figure 2),
which vectorize the two types of inputs, respectively.
For the vectorization of events {event}N,i,t, we adopt the TransE method, which is a
widely used model for entity-relation learning (Bordes et al., 2013; Deng et al., 2019). Specif-
ically, it transforms entities and relations into a shared low-dimensional embedding space,
where relationships are simulated through simple geometric operations such as vector ad-
dition.
Unlike generic text embeddings, TransE preserves the directional and relational
semantics of a triplet. Although it is originally developed for knowledge-graph completion,
this relational modeling makes it naturally suited for encoding our SER triplets in a scal-
able and structure-preserving manner. Building on the work of Deng et al. (2019), we use

TransE to convert the events extracted by LLM into embedding representations. Prior to
the embedding process, we standardize event representations in order to facilitate efficient
and consistent modeling, including merging entities or actions with identical references and
removing duplicates. An entity (subject or object) or action is then converted into a to-
ken, so that each event triplet (subject-action-object) is transformed into a concise triplet
(entity token, action token, entity token). Every token is then represented by a trainable
M-dimensional vector e ∈RM. Consequently, each event is transformed into a triplet of
vectors: {event}N,c,t →{(esubject, eaction, eobject)}N,c,t. These vectorized event representations
are subsequently processed by the TransE model, which learns embeddings by optimizing
spatial relationships such that the sum of the subject and action vectors is close to the object
vector in the embedding space, preserving the semantic meaning of events.

After constructing event-level representations {zevent}N,i,t and stock-specific representations

this purpose, we implement this aggregation via the multi-head self-attention mechanism
(Vaswani et al., 2017; Devlin et al., 2018; Cong et al., 2021). Attention mechanisms have
garnered significant attention in the field of natural language processing due to their effec-
tiveness across various tasks. Intuitively, an attention mechanism provides a data-driven way
to assign different weights to multiple inputs based on their relevance, so that a compact
and informative representation can be derived for such inputs. Specific to our context, the
attention mechanism allows our model, in the process of further aggregating event signals
and stock information, to weight the events differentially to account for their heterogeneous
importance across stocks.

Consistent with standard deep learning practice, our SER-based framework (see Figure 2)

threshold comfortably covers the majority of firm-period observations in our dataset. Such

embedding layers (entity and action embeddings) are re-initialized and trained from scratch

these events into broader event topics (Section 4.3) to uncover higher-level patterns in in-

At the entity level, the importance scores derived from the embeddings of subjects and

model’s predictions. This score reflects how strongly a specific entity influences the model’s
output. To capture both direction and strength, we consider two variants: (1) the absolute
importance, which measures the overall magnitude of influence regardless of sign, and (2) the
polarity importance, which distinguishes between positive and negative effects on predicted
returns. These entity-level importance measures form the basis for the subsequent analysis
of entity-heterogeneity in Section 4.4.

granularity offered by SER. Because each event is expressed as an exact triplet (subject-

4.3
Event-Topic-Heterogeneity Effect
Following the individual event analysis, we next examine how different types of news events
exert distinct impacts on stock returns. Building on the gradient based attribution frame-
work introduced in Section 4.1, we extend the same interpretability method to the event
level, where each event’s contribution to the model’s prediction is quantified through its gra-
dient based importance score and then aggregated by topic type to evaluate the influence of
different event categories. Unlike conventional article level topic modeling (e.g., Bybee et al.,
2024), which clusters entire news articles based on overall word distributions, our approach
conducts topic modeling at the event level, namely grouping individual events extracted
from news articles into latent thematic categories and providing a more fine grained level
of analysis of textual information. This event-centered analysis enables us to identify which
categories of events, such as financial disclosures, executive changes, or policy actions, carry
34


## Page 36


the greatest predictive weight and how their informational effects differ across time horizons,
thereby linking textual event structures to interpretable market dynamics.
As a first step of the analysis, we categorize each event into a latent topic type, enabling
us to analyze importance patterns across broader thematic groupings of news events. Each
news event extracted by the LLM contains a context sentence that encapsulates the original
news fragment. We apply latent Dirichlet allocation (LDA) to cluster these event contexts
into interpretable topics.
LDA is a probabilistic generative model that represents each document (i.e., an event’s
context sentence in our case) as a mixture of latent topics, where each topic is characterized
by a distribution over words. The model intuitively captures the notion that different doc-
uments may touch upon multiple themes, and that certain terms tend to co-occur within
the same thematic context. This makes LDA particularly suitable for modeling news texts,
which often blend various angles (e.g., policy, finance, corporate behavior). A critical hy-
perparameter of LDA is the number of topics. To select this parameter systematically, we
follow the approach of Bybee et al. (2024) and choose the number of topics that maximizes
the Bayes factor within a predefined range. The Bayes factor evaluates how well a model
with a given number of topics explains the data relative to simpler models, balancing model
fit against overfitting. Based on this criterion, we select 250 topics.
After training the LDA model, we manually assign human-readable labels to each topic
based on its most probable terms. While we take inspiration from the label conventions used
in Bybee et al. (2024), our data exhibits a different topical structure due to differences in
corpus composition and market context. Therefore, we refine and adapt labels accordingly,
in some cases creating entirely new labels to capture distinctive themes in our dataset. Full
details of the topic selection process and resulting topic distributions are provided in the
Online Appendix OA.4.
Based on the obtained topic labels for each event, we then evaluate which event topics

## Page 37


exert the greatest influence on the model’s predictions. To this end, we build on the gradient
based attribution method introduced in Section 4.1. Specifically, we aggregate the local
importance scores of all events belonging to each LDA-derived topic, thereby quantifying
the relative contribution of each event type to predicted returns. Formally, the analysis
proceeds in three steps:
• First, for each input sample, we compute the gradient-based importance scores for
individual events, capturing how much each event contributes to the model’s predicted
return.
• Second, since every event has been assigned to a topic label by LDA based on its
context sentence, we aggregate the importance scores across all samples by topic type
and compute the average score of events within each topic.
• Finally, the aggregated topic-level importance scores are used to identify and rank the
most influential event topics in both daily and weekly prediction settings, allowing for a
direct comparison of how temporal horizons affect the model’s informational focus (e.g.,
financial disclosures, executive moves, regulatory actions, and consumer sentiment).

4.5
Entity-based Stock Comovement
Building on the entity-level interpretability analysis in Section 4.4, we further examine
whether the most influential entities identified by the LLM act as common information
hubs that trigger collective market reactions. The idea echoes the connected stocks per-
43


## Page 45


spective of Anton and Polk (2014), who demonstrate that firms jointly held by the same
investors tend to move together because shared ownership propagates correlated trading and
attention. In a similar spirit, we explore an information-side counterpart of this mechanism:
when multiple firms are recurrently linked to the same entities in news, they may become
“information-connected” responding in tandem to new developments about those entities.
Since entity-related information shocks dissipate quickly, in this analysis we restrict attention
to only daily comovement patterns, aligning with the short-horizon nature of event-driven
return adjustments.
Specifically, we focus on entity-induced comovement, where firms exposed to news involv-
ing the same key entity exhibit synchronous return patterns. Such comovement reflects the
propagation of entity-specific information through economic linkages, supply-chain connec-
tions, or correlated investor sentiment, thereby translating the model’s textual understand-
ing into tangible cross-sectional dependencies in stock prices. In this sense, entity-driven
comovement represents the information-side counterpart of ownership-driven connectedness,
capturing how common attention and belief shocks transmit across firms that share salient
informational anchors.
To assess this mechanism, we select the top-ranked entities from the daily prediction
model as focal entities and identify the TOP-K stocks with the highest historical exposure
to each focal entity, measured by their co-occurrence frequency in past event news. These
stocks represent firms most consistently associated with a given entity in the news corpus,
making them the most likely to react collectively when that entity reappears in subsequent
events. We then evaluate whether these high-exposure portfolios exhibit stronger return
comovement during event windows related to the same entity.

suggest that the LLM-identified entities not only capture predictive textual signals but also
correspond to real channels of information diffusion and correlated belief formation in finan-
cial markets. Conceptually, this mechanism represents an information-based counterpart to
the ownership-driven connectedness documented by Anton and Polk (2014), highlighting that
common exposure to news about the same entities can synchronize investor expectations just
as shared ownership synchronizes trading flows. These findings position our SER represen-
tations as a promising tool for event studies. Because our SERs provide a standardized and
economically meaningful decomposition of news into subject–action–object structures, they
allow researchers to identify, group, and quantify firm-level exposures to specific informa-
tional triggers in a systematic way. This structured representation enables a scalable form
of event classification and cross-firm impact tracing, offering a new pathway for studying
information diffusion beyond traditional hand-coded or keyword-based approaches.
5
Conclusion
This paper introduces a powerful and interpretable event-driven framework for stock return
prediction by utilizing large language models (LLMs) to extract structured event represen-
tation (SER) with attention-based deep learning. The approach not only achieves superior
out-of-sample performance compared to existing textual methods but also bridges the gap
between high-dimensional text data and interpretable financial analysis. By explaining how
specific entities and event types influence market outcomes, our SER-based model offers
50


## Page 52


insights into the economic mechanisms underlying stock return predictability. Our study
highlights the critical value of structured and human-readable input features in enhancing
both the accuracy and interpretability of text-based predictive models, paving the way for
more trustworthy and mechanistically grounded financial forecasting.
While we focus on stock return predictability by newspaper data, the framework can
be easily applied to other assets, such as options, bonds, and cryptocurrencies, and other
text data, including firms’ annual reports, social media, and earnings conference calls. In
addition to asset returns, our framework can also be applied to many other topics in finance,
such as corporate investment decisions, investors’ trading motivations, and analysts’ beliefs,
which we leave for future research.

OA.1
Constructing Dataset for Event-Driven Return
Prediction
This appendix outlines the processing procedures used to construct the news–event–return
datasets employed in the empirical return predicting.
OA.1.1
News Articles Preprocessing
1. Sample collection.
Given the news data collected primarily from ProQuest and
complemented with Factiva, we begin by retaining all news articles published between
January 1, 2003 and December 31, 2023.
2. Duplicate removal. For each publication date, we compute cosine similarity across
article texts and drop an article when its similarity with an earlier article exceeds 0.9.

OA.4
Event Topic Modeling
This section introduces the details of the event topic modeling procedure used to categorize
extracted events into latent thematic groups. The purpose of this analysis is to capture
broader semantic structures underlying news events and to examine how entity importance
and market responses vary across different thematic domains. Each event is represented by
a context field, which is a sentence extracted from the original news article that contains the
identified event, providing rich textual information for topic clustering.
We employ a latent Dirichlet allocation (LDA) model to uncover the latent topic distribu-
tions among these event contexts. LDA is a probabilistic generative model that represents
each document (in this case, an event sentence) as a mixture of topics, with each topic
characterized by a distribution over words. This approach effectively captures the notion
that news narratives often involve multiple intertwined themes, such as policy intervention,
financial performance, or corporate behavior.
A key hyperparameter of LDA is the number of topics. To determine this systematically,
we follow the model selection procedure of Bybee, Kelly, and Su (2023), which evaluates
model fit across alternative topic numbers using the Bayes factor to balance explanatory
power and model complexity. As shown in Figure OA.1, the Bayes factor increases steadily
before stabilizing around 250 topics, which we adopt as the optimal number for event-level
clustering.

This figure illustrates the optimization procedure for determining the number of topics in the event-
level latent Dirichlet allocation (LDA) model. Each event is represented by its context sentence
extracted through the LLM-based preprocessing pipeline, and LDA is applied to cluster these event
contexts into coherent thematic topics. The Bayes factor, following the model selection procedure
of Bybee, Kelly, and Su (2023), measures the relative model fit across different topic counts while
penalizing overfitting. The figure plots the Bayes factor values for topic numbers ranging from
100 to 280, showing that model fit improves substantially up to around 250 topics and stabilizes
thereafter. Accordingly, we select 250 topics as the optimal volume for event topic modeling.
