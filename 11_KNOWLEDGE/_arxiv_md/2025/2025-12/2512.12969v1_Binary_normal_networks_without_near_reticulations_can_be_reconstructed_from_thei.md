BINARY NORMAL NETWORKS WITHOUT NEAR RETICULATIONS
CAN BE RECONSTRUCTED FROM THEIR ROOTED TRIPLES
ANDREW FRANCIS AND CHARLES SEMPLE
Abstract. Normal networks are an important class of phylogenetic networks that have
compelling mathematical properties which align with intuition about inference from ge-
netic data. While tools enabling widespread use of phylogenetic networks in the biolog-
ical literature are still under mathematical, statistical, and computational development,
many such results are being assembled, and in particular for normal phylogenetic net-
works. For instance, it has been shown that binary normal networks can be reconstructed
from the sets of three- and four-leaf rooted phylogenetic trees that they display. It is
also known that one can reconstruct particular subclasses of normal networks from just
the displayed rooted triples. This applies, for instance, to rooted binary phylogenetic
trees and to binary level-1 normal networks. In this paper we address the question of
how much of the class of binary normal networks can be reconstructed from just the
rooted triples that they display. We find that all except those with substructures that
we call “near-sibling reticulations” and “near-stack reticulations” can be reconstructed
just from their rooted triples. This goes some way to answering the natural question of
how much information can be extracted from a set of displayed rooted triples, which are
arguably the simplest substructure that one may hope for in a phylogenetic object.
1. Introduction
A significant challenge for the widespread adoption of phylogenetic networks for bio-
logical inference is the difficulty in reconstructing them from available data. Such data
typically includes alignments of genetic sequence, either at the whole genome level or,
more commonly, at the gene level. Such alignments can readily produce small substruc-
tures such as a rooted triple. Much of the difficulty lies in combining these substructures
in a meaningful way. We can always reconstruct a phylogenetic network that infers, for
example, each of the rooted triples in a given collection by simply choosing a network
that infers all possible rooted triples. But this is neither meaningful nor informative.
Thus we need to constrain the phylogenetic network that we reconstruct. One way to
do this is to restrict the reconstructed network to a certain class. This is not unusual,
as most current reconstruction methods in computational biology restrict to the class
of phylogenetic trees. Furthermore, for the purposes of consistency, the substructures
that we use for reconstruction need to have the property of being able to determine the
phylogenetic networks of interest.
In the last twenty years, a wild assortment of classes of phylogenetic networks have
been introduced and studied. Amongst these classes, normal and tree-child networks

have arguably been the most prominent. Introduced by Willson [9, 10] and Cardona et
al. [4], respectively, these two classes of phylogenetic networks are sufficiently complex
to capture reticulate evolution but also sufficiently constrained to be meaningful. They
also have the compelling biological property of “visibility”, which allows the present to
‘see’ all past speciation and reticulation events from extant species. However, of these
two classes, normal networks are more adaptable to reconstruction [5]. For example,
unlike tree-child networks, normal networks are reconstructable from the small subtrees
that they infer [7]. The purpose of this paper is to investigate this adaptability in the
context of rooted triples, the first step in establishing a general method for taking a given
collection of rooted triples and outputting a normal network that is representative of the
initial data.
For a binary phylogenetic network N, let R(N) denote the set of rooted triples displayed
by N. It is well known that if T is a rooted binary phylogenetic tree, then R(T) determines
T (see, for example, [8]). In particular, we have the following theorem.
Theorem 1.1. Let T1 and T2 be two rooted binary phylogenetic X-trees. Then R(T1) =
R(T2) if and only if T1 ∼= T2.
While not difficult to prove, Theorem 1.1 underlies many so-called supertree methods.
These methods take as input a collection (of not necessarily compatible) rooted phylo-
genetic trees on overlapping leaf sets and output a single rooted phylogenetic tree that
“best” represents the input collection. For an excellent overview of supertree methods,
see [1]. Furthermore, Theorem 1.1 justifies the use of rooted triples in the input col-
lection, as the “true” tree (at least theoretically) is recoverable from the rooted triples
it displays. More generally than trees, if N is a binary level-1 normal network, then
R(N) determines N [6]. However, not surprisingly, if N is an arbitrary binary normal
network, then N cannot typically be determined by R(N) alone (see, for example, the
counterexample given by Lemma 3.1).
While rooted triples alone are insufficient, it has recently been shown that displayed
trees with at most four leaves are nevertheless sufficient for determining an arbitrary
binary normal network. Let Q(N) denote the set of 4-leaf caterpillars, that is, rooted
binary phylogenetic trees on 4 leaves with exactly one cherry, displayed by a binary
normal network N. The next theorem is established in [7, Theorem 2].
Theorem 1.2. Let N1 and N2 be two binary normal networks on X. Then R(N1) =
R(N2) and Q(N1) = Q(N2) if and only if N1 ∼= N2.
Using an explicit example, it is shown in [7] that the inclusion of 4-leaf caterpillars is
necessary in the statement of Theorem 1.2. This begs the question to what extent are
such caterpillars necessary? In this paper, we consider this question. More particularly,
we investigate which binary normal networks are determined by the set of rooted triples
they display?
Let u and v be reticulations of a binary phylogenetic network N. If there is a tree
vertex in N such that one of its children is a tree vertex, and this tree vertex is a parent
of u, and the other child is v, then we say that u and v are near-sibling reticulations.
Furthermore, if the unique child of u is a tree vertex and this tree vertex is a parent of v,
then we say that u and v are near-stack reticulations. These concepts are illustrated in

whether excluding near-stack reticulations is also necessary in the statement. We discuss
this further in the last section. For now, we make the following conjecture.
Conjecture 1.4. Let N1 and N2 be two binary normal networks on X with no near-
sibling reticulations. Then R(N1) = R(N2) if and only if N1 ∼= N2.
The paper is organised as follows. The next section contains some necessary prelim-
inaries including formal definitions. Section 3 reviews and establishes some properties
of normal networks. In particular, we show that having no near-sibling reticulations in
the statement of Theorem 1.3 is a necessary condition. The proof of Theorem 1.3, which
follows the model of the proof of Theorem 1.2, relies on being able to recognise cherries
and reticulated cherries of a binary normal network N with no near reticulations using
only the set R(N) of rooted triples displayed by N. This recognition is established in
Section 4, while the proof of Theorem 1.3 is given in Section 5. We end the paper with
a discussion in Section 6.
2. Preliminaries
Throughout the paper X denotes a non-empty finite set.
Phylogenetic networks and trees.
A binary phylogenetic network N on X is an
acyclic directed graph with (i) a single vertex of in-degree 0, which has out-degree 2 and
is called the root, (ii) |X| vertices of in-degree 1 and out-degree 0 labelled bijectively by
the elements in X, and (iii) all other vertices having either in-degree 1 and out-degree 2,
3


## Page 4


called tree vertices, or in-degree 2 and out-degree 1, called reticulations. The set X is
the leaf set of N, and the elements in X are called leaves. Furthermore, the arcs directed
into a reticulation are called reticulation arcs. For technical reasons, if |X| = 1, then the
acyclic directed graph consisting of a single vertex labelled by the element in X is a binary
phylogenetic network on X. For a vertex u of N, the cluster set of u, denoted by Cu, is the
subset of X consisting of the leaves of N that are descendants of u (those leaves for which
there is a directed path from u). A rooted binary phylogenetic X-tree is a phylogenetic
network on X with no reticulations. A rooted triple is a binary phylogenetic tree T on
three leaves. If the leaf set of a rooted triple T is {x, y, z} and z is adjacent to the root,
then we denote T by xy|z or, equivalently, yx|z. Since all phylogenetic networks and
phylogenetic trees considered in this paper are rooted and binary, we refer to a rooted
binary phylogenetic network and a rooted binary phylogenetic tree as a phylogenetic
network and phylogenetic tree, respectively.
Let N1 and N2 be two phylogenetic networks on X with vertex sets V1 and V2, re-
spectively. Then N1 is isomorphic to N2 if there is bijective map φ : V1 →V2 such that
φ(x) = x for all x ∈X, and (u, v) is an arc of N1 if and only if (φ(u), φ(v)) is an arc
of N2.
Tree-child and normal networks. A phylogenetic network N is tree-child if every
non-leaf vertex has at least one child that is a tree vertex or a leaf. Equivalently, each
vertex v of N has a tree path to a leaf, that is, a path from v to a leaf whose non-terminal
vertices are tree vertices. A reticulation arc (u, v) is a shortcut if there is a (directed)
path from u to v that does not traverse (u, v). A normal network is a tree-child network
without shortcuts. Tree-child and normal networks were introduced in [4] and [9, 10],
respectively.
Tree-child networks and normal networks have the important property that every vertex
is “visible”. A vertex u of a phylogenetic network on X is visible if there is a leaf ℓ
such that every path from the root of N to ℓtraverses u, in which case ℓverifies the
visibility of u. The visibility set of u, denote by Vu, is the subset of X consisting of
those leaves that verify the visibility of u. Observe that Vu ⊆Cu and that Cu −Vu is
not necessarily empty. It turns out that visibility characterises the class of tree-child
networks. The next lemma is well known and gives this characterisation as well as the
other characterisation that is central to this paper. Its proof is an almost immediate
consequence of the definition. A pair of reticulations in a phylogenetic network are sibling
reticulations if they share a parent and stack reticulations if one of the reticulations is a
parent of the other reticulation.
Lemma 2.1. Let N be a phylogenetic network. Then the following statements are equiv-
alent:
(i) N is tree-child.
(ii) Every vertex of N is visible.
(iii) N has no sibling and no stack reticulations.
Let u and v be reticulations of a phylogenetic network N. Repeating the definitions
given in the introduction, if there is a tree vertex of N whose two children are v and a
tree vertex parent of u, then u and v are near-sibling reticulations. Furthermore, if the
child of u is a tree vertex and a parent of v, then u and v are near-stack reticulations. A

phylogenetic network with no near-sibling and no near-stack reticulations is said to have
no near reticulations.
Let N be a phylogenetic network on X, and let {a, b} ⊆X. We say that {a, b} is a
cherry of N if a and b have the same parent. Furthermore, {a, b} is a reticulated cherry if
the parent pb of b is a reticulation and the parent pa of a is a parent of pb, in which case
b is the reticulation leaf of the reticulated cherry. Observe that pa is necessarily a tree
vertex. The next lemma shows that every tree-child network contains either a cherry or
a reticulated cherry [3, Lemma 4.1].
Lemma 2.2. Let N be a tree-child network on X. If |X| ≥2, then N contains either a
cherry or a reticulated cherry.
Displaying and embedding phylogenetic trees. Let N be a phylogenetic network
on X, and let T be a phylogenetic X′-tree, where X′ ⊆X. We say N displays T if
there is a subdigraph N ′ of N such that, up to suppressing vertices of in-degree one and
out-degree one, T is isomorphic to N ′, in which case the arc set of N ′ is an embedding of
T in N.
In this paper, it is the embedding of rooted triples that is of interest. Let N be a
phylogenetic network, and suppose that Exyz is an embedding of the rooted triple xy|z
in N. If e is an arc of N, we say that Exyz uses e if e ∈Exyz. Similarly, if u is a vertex
of N, we say that Exyz uses u if u is an end vertex of an arc in Exyz. Extending this
terminology, let f be an arc of xy|z. If the arcs of Exyz corresponding to f use an arc
e of N, we say f uses e in Exyz. Similarly, if v is a vertex of N and the arcs of Exyz
corresponding to f use v, we say f uses v in Exyz.
3. Properties of Normal Networks
We begin this section by showing that the condition of having no near-sibling retic-
ulations is a necessary condition in the statement of Theorem 1.3. Let N be a normal
network on X, and suppose that u and v are near-sibling reticulations of N, where a
parent t of v is a grandparent of u, as shown in the left of Figure 2. Let s denote the
parent of u that is a child of t, and let w denote the child of s that is not u. Since N
is normal, w is either a tree vertex or a leaf. Let N ′ be the phylogenetic network on X
obtained from N by deleting (s, w), suppressing s, subdividing the edge (t, v) with a new
vertex s′, and adjoining w to this new vertex with a new edge. This operation on N is
illustrated in Figure 2 and we say that N ′ has been obtained from N by a nearest neigh-
bour interchange relative to {u, v}. Certainly, N is not isomorphic to N ′ and, provided
(t, u) is not a shortcut in N ′, it is easily checked that, as N is normal, N ′ is also normal.
Note that if (t, u) is a shortcut in N ′, then v is an ancestor of u, that is, u and v are
comparable in N (and N ′). The next lemma shows that we cannot distinguish N and

Section 6.

4. Detecting Cherries and Reticulated Cherries From Rooted Triples
A key part of proving Theorem 1.3 is to show that if N is a normal network with no
near reticulations, then cherries and reticulated cherries are recognisable using only the
rooted triples of N. The next lemma [7, Lemma 2] shows that cherries are recognisable
from the set of rooted triples of an arbitrary normal network.
Lemma 4.1. Let N be a normal network on X with {a, b} ⊆X. Then {a, b} is a cherry
of N if and only if, whenever xy|z ∈R(N) and a, b ∈{x, y, z}, we have {a, b} = {x, y}.
For the proof of Theorem 1.3, in addition to recognising reticulated cherries {a, b} in
a normal network with no near reticulations, where b is the reticulation leaf, we need to

Lemma 4.3. Let N be a normal network on X with no near reticulations. Let {a, b} ⊆
X and let Wb be a candidate set for b. Then {a, b} is a reticulated cherry of N with
reticulation leaf b, and Vgb = Wb, where gb is the grandparent of b that is not the parent
of a, if and only if ab|x ∈R(N) for all x ∈X −{a, b}.
Proof. For the forward direction, if {a, b} is a reticulated cherry, then, by Lemma 3.2(i),
ab|x ∈R(N) for all x ∈X−{a, b}. For the backward direction, suppose that ab|x ∈R(N)
for all x ∈X −{a, b}. We first show that the parent pb of b is a reticulation.
Suppose to the contrary that pb is a tree vertex. Let v denote the child of pb that is not
b. Over the next several sub-lemmas, we deduce consequences of the assumption that pb
is a tree vertex. The first is that this implies that v is a reticulation.
4.3.1. v is a reticulation.
If v is a leaf, then v = a; otherwise, ab|v ̸∈R(N), a contradiction. But if v = a, then,
{a, b} is a cherry and we cannot have bc|a ∈R(N), where c ∈Wb, contradicting (W1) for
Wb. So v is not a leaf.
Suppose instead that v is a tree vertex. Since N is normal, there is a tree path from
v to a leaf, say ℓ. If a ̸= ℓ, then either aℓ|b ∈R(N) or bℓ|a ∈R(N) but ab|ℓ̸∈R(N), a

5. Reconstructing Normal Networks From Rooted Triples
In this section, we prove Theorem 1.3. We begin with a lemma that allows us to use
induction for its proof.
Lemma 5.1. Let N be a normal network on X with no near reticulations, and let {a, b}
be a reticulated cherry of N with reticulation leaf b. Let N ′ be the phylogenetic network
obtained from N by deleting b and its parent, and suppressing the resulting two vertices
of degree 2. Then N ′ is a normal network on X −{b} with no near reticulations.
Proof. It follows by [2, Lemma 3.2] that N ′ is normal.
To see that N ′ has no near
reticulations, suppose to the contrary that u and v are either near-sibling or near-stack
reticulations of N ′. Let pa and pb denote the parents of a and b, respectively, in N and
let gb denote the parent of pb that is not pa. Say u and v are near-sibling reticulations
of N ′, where the parent pv of v is the parent of a parent pu of u. Then, as N has no
near reticulations, to obtain N from N ′ it follows that gb subdivides one (pv, pu), (pu, u),
and (pv, v) in N.
If gb subdivides either (pu, u) or (pv, v), then either u and pb or v
and pb are sibling reticulations in N, a contradiction. If gb subdivides (pv, pu), then v
and pb are near-sibling reticulations in N, another contradiction. So u and v are not
near-sibling reticulations. Now say u and v are near-stack reticulations of N ′, where
the child of u is a parent pv of v. Since N has no near reticulations, to obtain N from
N ′, the vertex gb subdivides either (u, pv) or (pv, v) in N. But then either u and pb are
near-stack reticulations or v and pb are sibling reticulations, respectively, in N. This last
contradiction implies that N ′ has no near reticulations, thereby completing the proof of
the lemma.

6. Discussion
The capability to reliably reconstruct an explicit phylogenetic network from a set of
genetic sequences is a key missing element preventing their widespread use in biological
applications. Acquiring this capability involves two logical steps.
The first step is obtaining results that show phylogenetic networks can be reconstructed
given particular information (and preferably giving a procedure for doing so). The second
step is being able to tell when one has the right information in the first place.
For
instance, the present paper has shown that a certain class of phylogenetic networks can
be reconstructed from the sets of rooted triples that they display. But it hasn’t give
a straightforward method to determine whether a given set of rooted triples might be
displayed by a network of that class.
Another way to view these two steps is in terms of mathematical maps. In showing
that a class N of phylogenetic networks can be reconstructed from the rooted triples
it displays, we are effectively showing that the map from N to the power set of rooted
triples is injective. In doing that, we also show how to reconstruct the pre-image of the
set of rooted triples. The second step would be to describe the image of this map, so that
we have a bijection between the class of normal networks without near reticulations, and
a well-described subset of the power set of the rooted triples.
The second step is crucial for applications: a scientist who gathers a set of genetic
sequences does not a priori know whether their data evolved on a normal network without
near reticulations.
Ideally, they would be able to compute the set of rooted triples
represented by their data, and be able to tell from those rooted triples whether they have
the capability to reconstruct. With the results in this paper, the test for whether a given
set of rooted triples is the (complete) set of rooted triples displayed by a normal network,
N say, with no near reticulations, would involve finding a cherry or a set Wb among the
rooted triples, performing a cherry or reticulated cherry reduction, and repeating until it
were no longer possible. A more practical test, and one not requiring the complete set of
rooted triples displayed by N, would be better.

## Page 16


In this paper, we have shown that normal networks without near reticulations can be
reconstructed from the set of rooted triples they display. Thus, excluding near-sibling and
near-stack reticulations is sufficient for reconstruction, but are these exclusions also nec-
essary for reconstruction? As illustrated in [7, Figure 1], it is not possible for all normal
networks to be reconstructed from their rooted triples. In particular, Lemma 3.1 shows
that, if N is a normal network with a pair of near-sibling reticulations u and v, and u and
v are non-comparable, then N cannot be distinguished by rooted triples alone. Hence,
excluding non-comparable near-sibling reticulations is necessary for reconstruction. This
leaves open two questions: (i) To what extent is excluding comparable near-sibling retic-
ulations necessary for reconstructing normal networks and (ii) is excluding near-stack
reticulations necessary for reconstruction?
For (ii), if N is a normal network and N
has no near-sibling reticulations, we have Conjecture 1.4. However, if N is allowed to
have comparable near-sibling reticulations, then the conjecture is false as the following
example highlights.
