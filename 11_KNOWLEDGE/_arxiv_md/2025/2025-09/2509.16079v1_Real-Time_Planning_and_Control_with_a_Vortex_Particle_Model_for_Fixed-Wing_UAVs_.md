Real-Time Planning and Control with a Vortex Particle Model for
Fixed-Wing UAVs in Unsteady Flows
Ashwin Gupta1, Kevin Wolfe2, Gino Perrotta2, and Joseph Moore1,2
Abstract— Unsteady aerodynamic effects can have a profound
impact on aerial vehicle flight performance, especially during
agile maneuvers and in complex aerodynamic environments.
In this paper, we present a real-time planning and control
approach capable of reasoning about unsteady aerodynamics.
Our approach relies on a lightweight vortex particle model,
parallelized to allow GPU acceleration, and a sampling-based
policy optimization strategy capable of leveraging the vor-
tex particle model for predictive reasoning. We demonstrate,
through both simulation and hardware experiments, that by
replanning with our unsteady aerodynamics model, we can
improve the performance of aggressive post-stall maneuvers
in the presence of unsteady environmental flow disturbances.
I. INTRODUCTION
For more than two decades, the research community
has sought to improve the flight control performance of
uncrewed aerial vehicles (UAVs). Early research explored
control strategies for autonomous helicopter control using
nonlinear model predictive control (NMPC) [1], and later
on, more aggressive maneuvering with multi-rotor UAVs [2].
More recently, researchers have explored control strategies
for agile fixed-wing control [3], [4], as well as hybrid VTOL
aircraft [5]. While researchers have investigated many dif-
ferent types of control strategies, from model-based control
[6] to reinforcement learning [7], most of these approaches
have leveraged a quasi-static, lumped parameter model of the
aerodynamics.
However, as the performance envelopes of UAVs continue
to increase, unsteady aerodynamic effects will start to play a
more important role. This is particularly true for applications
like urban air mobility, where vortex shedding off of nearby
structures lead to an unsteady environmental flow field [8],
or landing in the turbulent wake of a ship [9].
In this paper, we propose a control algorithm that can
reason about unsteady aerodynamic effects as produced by
the vehicle aerodynamics themselves as well as the environ-
ment. Our approach constructs a lightweight computational
fluid-dynamics model, known as a particle vortex model,
to explicitly model the unsteady flow field. To enable real-
time planning, we parallelize both the vortex model and the
dynamics rollouts. To address the challenges with model
differentiability, we leverage a stochastic trajectory optimiza-
tion approach, model predictive path integral control (MPPI),
and build a local trajectory tracking controller directly from
samples.

Through simulation and hardware experiments, we eval-

Because our vortex particle model represents the fluid state
using point vortices, a planarized ring vortex disturbance can
be naturally added to the fluid state. To evaluate our approach
in hardware, we use a large vortex cannon to generate a
ring vortex to disturb the flow. We detect this vortex using
offboard pressure sensors local to the perch site, and we
show improved perching performance in the presence of an
unsteady environmental disturbance.
Our primary contributions are:
• A parallelized vortex particle model suitable for real-
time planning.
• A framework for real-time planning and control with a
low-fidelity vortex particle model.
• Simulation and hardware experiments demonstrating
improved maneuver performance for a perching UAV
in unsteady aerodynamic environments.
II. RELATED WORK
Model-based controllers have achieved impressive perfor-
mance for both fixed-wing and multi-rotor UAVs relying pri-
marily on quasi-steady, lumped-parameter models [10], [11].
Fixed-wing UAV controllers have demonstrated aggressive,
post-stall maneuvering [4] while relying on quasi-steady flat
plate models, while quadcopter control can achieve acrobatic
maneuvers using simple, differentially flat models [2]. In
[12], researchers leverage the unsteady lumped parameter
high angle-of-attack model proposed in [13] to create a
higher fidelity fixed-wing UAV model.

A. Linear Control with CFD
To further increase the fidelity of the models used for
aircraft control, researchers have explored leveraging compu-
tational fluid dynamics (CFD). Because CFD is not compu-
tationally efficient enough to run online, most approaches
have focused on fitting model parameters to data gener-
ated offline. In particular, researchers have sought to fit
dynamic derivatives associated with unsteady aerodynamic
effects [14], [15]. While most approaches have explored
grid-based CFD approaches, recently [16] explored using a
vortex particle method (VPM). While more computationally
efficient than grid-based CFD, this approach also relied on
an offline generation of a local time-varying linear policy.
B. Model-Predictive Control with Unsteady Models
In recent years, model predictive control has proven to be
an effective approach for controlling UAVs under challenging
conditions (e.g., [4], [17]). In some cases, researchers have
sought to incorporate unsteady flow models into a MPC
framework. [18] and [19] modeled turbulent flows and ship
wakes with stochastic models and leveraged stochastic MPC
to enable shipboard landings. [20] integrated a high-fidelity
aerodynamics model and CFD-based wake model to achieve
MPC-based landing with an autonomous rotorcraft. In [21],
the authors leveraged reduced-order modeling technique to
incorporate a CFD-based model into MPC for glideslope
tracking in a ship airwake.
C. Machine Learning Approaches
Machine learning has also proven to be a useful tool to
capture complex, unsteady aerodynamic effects. Researchers
have used machine learning to augment aerodynamics mod-
els using real-world data, for both multi-rotor UAVs [22] and
fixed-wing UAVs [23]. Researchers have also used CFD to
fit improved aerodynamics models. In [24], authors propose
a novel learning framework for learning a latent space
to learn higher fidelity models from data. [25] builds on
this model to apply model-based reinforcement learning to
control airfoil in a highly disturbed flow. Several approaches
leveraged specialized flow sensing combined with reinforce-
ment learning to enable control in unsteady environmental
flows in hardware. [26] introduced a fast-response hot-wire
anemometer to improve quadcopter control performance via
reinforcement learning. [27] and [28] have explored the use
of full particle image velocimetry (PIV) with reinforcement
learning to improve performance in unsteady flow fields.
In this paper, we present an approach for real-time plan-
ning and control that leverages a computationally lightweight
vortex particle model “in-the-loop” to improve performance
in highly disturbed flows. To our knowledge, this is the first
demonstration of using a CFD model in-the-loop for real-
time control on a UAV.
III. APPROACH
We introduce a lightweight fluid dynamics model com-
prised of a set of vortex particle elements that specify the
flow field and are transported with the flow themselves. We
provide a massively parallel algorithm to enable faster than
real-time trajectory sampling through the fluid dynamics. Us-
ing parallel rollouts, we can generate new motion plans mid-
maneuver and synthesize local, time-varying, linear feedback
policies for our planned trajectories.

B. Vortex Particle Model
The fluid dynamics of the glider system (Re < 30000, Ma
< 0.3) can be modeled with reasonable fidelity by potential
flow theory for irrotational and incompressible flows. The
Navier-Stokes continuity condition is reduced to Laplace’s
equation, and any vorticity in the flow is discretized as
a singular point impulse such that each vortex element
induces a velocity field according to a Biot-Savart kernel
(7) of strength Γ [29]. Discrete vortex elements both specify
the flow field and are convected with the flow itself. This
Lagrangian discretization scheme affords us faster than real-
time computation in contrast with the conventional Eulerian
schemes in CFD. In this work we limit our consideration to
two dimensional velocity fields, but note that VPMs can be
extended to three dimensions.

2) Disturbance Model: The disturbance considered in this
work is a vortex ring, which is simply modeled as two
additional vortices of equal magnitude but opposite sign
injected into the wake and convected with the rest of the
particles.
In order to prevent non-physical interaction with the
airfoil, the disturbance is terminated at boundary of the
chord. This is achieved by line-line intersection check with
the chord line inflated by 2 percent in the direction opposite
of the normal and the line formed by the two ring vortices.
3) Vortex State Management: To prevent the accumulation
of an excessive number of wake particles, we combine
particles when the total number exceeds a predetermined
threshold. The two oldest particles are merged into a single
particle at their average position, and the strength of the new
particle is equal to the sum of their strengths. This preserves
the total circulation in the flow.
Vortex shedding is not enabled until the glider exceeds a
critical angle of attack where the flow detaches. In our work,
this value is chosen to match the empirical acceleration data
for the glider, but more principled approaches for computing
a leading edge suction parameter to modulate shedding
exist [32]. When shedding is disabled, the dimension of
the boundary condition enforcement system reduces to only
Nbound unknowns, and the Kelvin condition can be excluded.

E. Nonlinear Model Predictive Control
Non-blocking replanning is achieved with a background
single-producer single-consumer (SPSC) worker thread that
is responsible for the following:
1) Wait on a condition variable for a new replan request
containing the current wake state, current policy, and
projection horizon
2) Project the current vortex state forward in time using
the current closed loop policy to compensate for the
replanning time
3) Fork the current vortex state, evaluate parallel dynam-
ics rollouts with randomized inputs warm started from
the previous policy, and apply MPPI reweighting
4) Optimize the time varying linear system and integrate
the TVLQR Riccati Equation to build the new policy
Note that we require the current wake state of the glider. This
is achieved by maintaining a vortex model instance that is
stepped with the the observed rigid body state at each main
loop update. The main thread is only responsible for check-
ing if a new policy is available, atomically swapping to the
new policy, and triggering the next replan, while providing
the current wake state. These operations are fast (on the order
of microseconds) as to not inhibit the rate of local linear
feedback. This process is summarized in Fig. 3, and in the
algorithm block 2 and 3. Let K = {(H0, ξ0, τ 0), ...} denote

released, and the time of impact is measured at each sensor
to obtain a velocity estimate of 7.5 m/s for the gust. It should
be noted that this is an extremely significant disturbance in
the context of our setup since the glider velocity along the
trajectory is always less than 7 m/s. We assume the vortex
cores are separated by the diameter of the cutout in the
cannon. The vorticity can be computed using (8) for the
regularized kernel. During experiments, only one offboard
pressure sensor is used, and the vorticity, separation, and
height relative to the sensor are held constant at the values
recorded from the offline measurement. When the pressure
sensor detects a 15 pascal increase from the baseline reading,
the position of the vortex is injected into the vortex model.
