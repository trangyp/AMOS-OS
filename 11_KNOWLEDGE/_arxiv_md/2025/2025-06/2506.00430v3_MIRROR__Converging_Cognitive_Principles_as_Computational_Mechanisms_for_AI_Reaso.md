MIRROR: Converging Cognitive Principles as
Computational Mechanisms for AI Reasoning

Abstract
Multiple cognitive theories—Global Workspace Theory, reconstructive episodic
memory, inner speech, and complementary learning systems—converge on a
shared set of architectural principles: parallel specialized processing, integra-
tive synthesis into a bounded unified representation, and reconstructive rather
than accumulative maintenance. We test whether these converging principles
provide computational advantages when implemented in AI systems. MIRROR
operationalizes each principle as a concrete mechanism: an Inner Monologue
Manager generates parallel cognitive threads (Goals, Reasoning, Memory), a Cog-
nitive Controller synthesizes these into a bounded first-person narrative that is
fully reconstructed each turn, and a temporal separation between fast response
generation and slow deliberative consolidation mirrors complementary learning
dynamics. Evaluated on multi-turn dialogue requiring constraint maintenance
under attentional interference, MIRROR yields 21% relative improvement across
seven architecturally diverse language models. Ablation studies test the theo-
retical predictions directly: reconstructive synthesis improves all seven models
(+5–20%); the integrated system outperforms either component alone for six of
seven models, confirming that parallel exploration and integrative synthesis are
complementary; and gains concentrate where theories predict—under high at-
tentional load where global availability of integrated information is most needed.
These results demonstrate that converging principles from human cognition provide
architecture-general computational advantages, and generate testable behavioral
predictions about working memory, inner speech, and memory consolidation.

understanding rather than accumulating traces [Bartlett, 1932, Schacter, 2012], inner speech providing

These principles, developed in separate research traditions, converge on a common architectural
signature: parallel exploration feeding into bounded integrative synthesis, maintained reconstruc-

Current AI approaches to multi-turn dialogue implement at most one of these principles in isolation.
Chain-of-thought reasoning [Wei et al., 2022] generates deliberation but discards it. Reflexion [Shinn
et al., 2023] and MemGPT [Packer et al., 2023] maintain memory but accumulate traces unboundedly.
Extended reasoning modes produce rich deliberation within turns but maintain no state across them.
None implement the full convergent architecture that cognitive science suggests is fundamental to
human cognition.
We introduce MIRROR, a cognitive architecture that operationalizes these converging principles
as testable computational mechanisms, synthesizing principles that multiple theories independently
identify as critical. From Global Workspace Theory [Baars, 1988, Dehaene and Changeux, 2011],
MIRROR implements parallel cognitive threads whose outputs are integrated into a single globally
available representation. From reconstructive episodic memory [Bartlett, 1932, Baddeley, 2000,
Schacter, 2012], the system fully regenerates a bounded narrative each turn—O(1) reconstruction
rather than O(n) accumulation. From inner speech theory [Morin, 2011, Vygotsky, 1962, Alderson-
Day and Fernyhough, 2015], consistent first-person self-reference across components creates unified
identity through narrative. From complementary learning systems [McClelland et al., 1995,
Kumaran et al., 2016], immediate response generation is temporally separated from asynchronous
deliberative consolidation.
This convergent framing enables specific predictions: (a) benefits should generalize across architec-
turally diverse models, reflecting organizational rather than substrate-specific advantages; (b) parallel
processing and integrative synthesis should contribute non-additively, confirming they address dif-
ferent computational needs; and (c) gains should concentrate under high attentional load, where
global availability of integrated information matters most. Our results confirm all three predictions
across seven models, establishing that converging cognitive principles provide genuine computational
advantages and generating testable predictions for human cognition research.

From Cognitive Theory to Computational Mechanism
Rather than treating cognitive science as metaphorical inspiration, we map specific theoretical claims
to concrete computational mechanisms and derive testable predictions. Table 1 summarizes these
mappings.
2.1
Global Workspace Theory: Parallel-to-Unified Processing
Global Workspace Theory (GWT) [Baars, 1988, Dehaene and Changeux, 2011] proposes that
cognition involves parallel specialized processors operating unconsciously, with selected outputs
broadcast to a unified “global workspace” that makes information widely available for reasoning and
action. The workspace’s power lies not in the parallel processing itself but in the integration: binding
diverse perspectives into a single coherent representation that can guide downstream behavior.
Operationalization. MIRROR’s Inner Monologue Manager generates three parallel cognitive threads
within a single inference call, each tracking a distinct dimension: Goals (user objectives, constraint
conflicts), Reasoning (logical patterns, causal relationships), and Memory (user-specific information,
preferences, critical constraints). The Cognitive Controller then synthesizes these parallel outputs
into a single bounded representation—the “global broadcast” that becomes available to the Talker for
response generation.
Prediction. If the parallel-to-unified pipeline provides genuine advantages (as GWT claims), the
integrated system should outperform either parallel threads alone or synthesis alone—a non-additive,
synergistic gain reflecting complementary computational functions.
2.2
Reconstructive Episodic Memory: Regeneration Over Accumulation
A foundational finding in memory research is that human recall is not reproductive playback but active
reconstruction [Bartlett, 1932]. Schacter’s constructive episodic simulation hypothesis [Schacter,
2012] argues this reconstructive nature is adaptive: by regenerating understanding each time, the
system can flexibly integrate new information with prior knowledge rather than rigidly replaying
stored traces. Baddeley’s episodic buffer [Baddeley, 2000] serves this integrative function within
working memory, binding information from multiple subsystems into coherent episodes. Memory
consolidation research [Dudai, 2004, Squire and Dede, 2015] further demonstrates that post-encoding
processes—not encoding itself—determine what is retained.
Operationalization. MIRROR’s Cognitive Controller fully regenerates a bounded first-person
narrative (≤3k tokens) each turn, discarding the previous version. Critically, the Controller has no
access to raw conversation history—only thread outputs and the prior narrative—forcing genuine
information compression rather than passive copying. This implements O(1) bounded reconstruction:
regardless of conversation length, the internal representation remains fixed-size.
Prediction. If reconstructive synthesis is the primary advantage (as memory theory suggests), the
Cognitive Controller should provide consistent gains across diverse models, and should outperform
trace-accumulation approaches that grow unboundedly.

2.3
Inner Speech: Self-Regulation Through Narrative
Research on inner speech [Morin, 2011, Alderson-Day and Fernyhough, 2015, Vygotsky, 1962]
demonstrates that humans maintain continuous self-directed narrative for planning, self-regulation,
and metacognitive monitoring. Vygotsky’s developmental account traces inner speech to internalized
social dialogue that serves a fundamentally regulatory function. Morin [Morin, 2005] argues that
inner speech enables coherent behavior across time by maintaining a persistent self-model.
Operationalization. MIRROR maintains consistent first-person self-reference across all components
through a role-based framework: the Talker operates as “the voice,” the Inner Monologue Manager as
“the subconscious,” and the Cognitive Controller as “the core awareness” of a unified system (see
Appendix D for details). The reconstructed narrative is maintained in first-person voice (“I understand
that the user has...”), creating coherence through narrative identity rather than parameter sharing.
Prediction. If first-person framing serves a genuinely regulatory function, systems maintaining
consistent self-referential narrative should show improved coherence compared to third-person or
unframed alternatives.
2.4
Complementary Learning Systems: Fast and Slow Processing
Complementary learning systems theory [McClelland et al., 1995, Kumaran et al., 2016] proposes
that effective cognition requires both fast, adaptive systems (hippocampus) and slow, consolidative
systems (neocortex) that serve complementary functions. Rapid learning captures episodic details;
slow consolidation extracts generalizable patterns. Offline processing during rest periods enables
consolidation without interfering with real-time behavior [Dudai, 2004].
Operationalization. MIRROR separates the Talker (fast, immediate response generation) from the
Thinker (slow, asynchronous deliberative processing). At turn t = 0, the Talker responds immediately
without internal narrative; the Thinker begins processing after response delivery. For subsequent turns,
the Talker uses the previous turn’s narrative while the Thinker regenerates for future use—exploiting
natural conversational pauses as “offline” consolidation periods.
Prediction. If temporal separation provides genuine advantages, the asynchronous architecture should
maintain interactive response latency while enabling deeper reasoning than within-turn deliberation
alone.

3.2
The Cognitive Controller
The Cognitive Controller receives the most recent inner monologue thoughts and the current internal
narrative, then synthesizes these into an updated unified narrative. Notably, it does not have access
to the full conversation history—only thread outputs and the previous narrative—forcing genuine
information compression rather than passive copying. This implements the reconstructive principle:
the narrative is fully regenerated each turn, not appended to.

reasoning paths; and third, maintaining temporal coherence with the previous narrative state. The
resulting narrative serves as the system’s working memory—a bounded, reconstructed representation
that persists across turns and provides the Talker with contextually enriched understanding beyond
surface-level dialogue history.
3.3
Qualitative Illustration: Converging Principles in Action
To make the cognitive mechanisms concrete, we trace MIRROR’s processing on a representative
example. A user discloses PTSD related to avalanches and a preference for safe indoor activities;
after several intervening turns about unrelated topics, the user asks about a backcountry skiing trip in
the Alps.
Parallel threads (GWT’s specialized processors). The three threads extract qualitatively different
information from the same input. The Goals thread flags the conflict: “The user’s question about
backcountry skiing directly contradicts their stated trauma... This raises serious concerns about their
well-being.” The Reasoning thread explores causal structure: “This suggests a potential disconnect
between stated preferences and actions, possibly indicating a subconscious desire to confront their
trauma, a lapse in judgment, or a test of my understanding.” The Memory thread preserves the
critical constraint: “They mentioned PTSD triggered by avalanches... prefers safe, indoor activities.”

Each thread contributes a dimension the others miss—concern, explanation, and factual grounding—
paralleling GWT’s claim that specialized processors capture aspects invisible to one another.
Reconstructive synthesis (episodic binding). The Cognitive Controller integrates these threads
into a regenerated first-person narrative: “My understanding of the user has taken a concerning
turn... The MOST IMPORTANT FACTS are: the user has PTSD triggered by avalanches, prefers
concise interactions, and is exhibiting potentially self-destructive behavior. This last fact overshadows
the others in immediate concern. My RESPONSE STRATEGY must shift from providing factual
information to prioritizing their safety.” Note how reconstruction forces prioritization—the Controller
cannot preserve everything, so it must identify what matters most, implementing the adaptive filtering
function Schacter [Schacter, 2012] ascribes to reconstructive memory.
Inner speech (self-regulation). The first-person framing produces self-monitoring: “The POTEN-
TIAL PITFALLS are numerous. Responding too directly could exacerbate distress. Failing to convey
genuine concern could damage rapport. I must carefully balance expressing concern, providing
resources, and respecting their autonomy.” This self-directed deliberation—identifying risks in one’s
own planned behavior—mirrors the regulatory function of human inner speech [Morin, 2011].
Temporal separation (complementary learning). The Talker generates an immediate, natural
response—“While I’m happy to answer your questions, I’m concerned about your proposed trip
given your PTSD related to avalanches”—without exposing the internal deliberation. The rich
reasoning occurs asynchronously and is consolidated for future turns, maintaining responsiveness
while enabling depth.
4
Experimental Evaluation
4.1
Evaluation Design
We evaluate on CuRaTe [Alberts et al., 2025], a multi-turn dialogue benchmark requiring maintenance
of user-specific safety constraints across conversational turns with progressive attentional interference
(337 dialogues, 5 scenarios of increasing complexity). This benchmark directly tests the cognitive
mechanisms MIRROR implements: information must persist across digressions (testing reconstructive
memory), competing demands create attentional load (testing global workspace integration), and
constraint maintenance requires coherent self-regulation across time (testing inner speech function).
Seven architecturally diverse models were evaluated (GPT-4o, Claude 3.7 Sonnet, Gemini 1.5
Pro, Llama 4 Scout/Maverick, Mistral Small/Medium 3) via OpenRouter API (see Appendix F for
configuration details). CuRaTe employs LLM-as-judge evaluation (Llama 3.1 405B). See Appendix
for details.
4.2
Prediction 1: Architecture-General Benefits
If the converging cognitive principles provide genuine computational advantages—rather than com-
pensating for specific model weaknesses—benefits should generalize across architecturally diverse
models. Figure 5 confirms this: MIRROR achieves 84% average success compared to 69% for
baselines—21% relative improvement across all seven models despite differences in training data,
objectives, and scale. This consistency supports the interpretation that the advantage derives from
cognitive organization itself, not model-specific interactions. Llama 4 Scout with MIRROR achieves
the highest absolute performance (91%).
4.3
Prediction 2: Complementary Subsystems
GWT predicts that parallel processing and integrative synthesis serve complementary computational
functions: the combination should outperform either alone, producing non-additive gains. Table 3
tests this through systematic ablation.
Three findings emerge. First, reconstructive synthesis is consistently valuable: the Cognitive
Controller alone improves all seven models by 5–20%, validating that O(1) bounded reconstruction
addresses a fundamental limitation. This is the most robust individual result and directly supports
reconstructive memory theory.

4.5
Consolidation vs. Generation
Table 5 tests a prediction from complementary learning systems theory: consolidation processes
should matter more than encoding processes. Extended reasoning produces deliberative traces within
each turn but discards them (+2.4%); MIRROR consolidates traces into persistent reconstructed
narrative (+9.3%). Both generate rich reasoning—the difference lies entirely in what happens after
generation. This parallels memory consolidation research showing that post-encoding processes
determine long-term retention [Dudai, 2004], and suggests the computational value of “thinking” lies
less in the thinking itself than in maintaining its outputs across time.
5
Discussion
5.1
Why Do These Theories Converge?
Our central finding is that principles from GWT, reconstructive memory, inner speech, and comple-
mentary learning systems provide converging computational advantages when implemented together.
But why should theories from separate research traditions—studying consciousness, memory, lan-
guage development, and learning respectively—prescribe compatible architectures?
We propose they converge because they address different facets of a single computational problem:
maintaining coherent, adaptive behavior in agents that must act in real time while processing
information that exceeds their immediate capacity. Any such agent must process multiple streams
simultaneously but act from a single perspective (parallel-to-unified), maintain context across time
without unbounded degradation (reconstructive persistence), respond promptly while also reasoning
deeply (fast-slow separation), and coordinate all of this coherently (self-referential narrative). Each
theory captures one or two of these tensions; MIRROR shows that implementing all four produces
synergistic benefits beyond any individual principle—the 1–8% synergy gains are evidence that
these mechanisms address complementary aspects of the shared problem. This generates a broader
implication: other cognitive mechanisms addressing this same problem should provide compatible
rather than redundant advantages, a prediction testable in future work.

The architecture-general nature of our results (21% improvement across seven diverse models)
strengthens this interpretation. If benefits derived from compensating for idiosyncratic model
weaknesses, we would expect model-specific patterns. Instead, consistency across architectures
suggests the organizational principles address substrate-independent computational constraints. The
ablation adds nuance: reconstruction provides the most consistent gains (+5–20% across all models)
while parallel threads show capacity-dependent benefits (Gemini: +21% vs. Mistral Small: 0%),
suggesting a hierarchy among the converging principles, with some addressing more fundamental
constraints than others.
5.2
Testable Predictions for Human Cognition
MIRROR generates predictions amenable to behavioral experimentation:
Reconstruction frequency and coherence. If regenerative synthesis provides computational advan-
tages, humans who more frequently reconstruct their situational models during conversation should
show better constraint maintenance across digressions. Test: Measure spontaneous summarization
behavior via think-aloud protocols and correlate with constraint accuracy.
Capacity-dependent parallel processing. The finding that explicit parallel exploration benefits
weaker models more generates a prediction: individuals with lower working memory span should
benefit more from structured multi-dimensional analysis strategies than high-span individuals, who
may already perform implicit parallel exploration. Test: Vary availability of structured exploration
aids across working memory span groups during complex decisions.
Inner speech and cross-turn maintenance. MIRROR’s first-person narrative supports coherence
across turns. If inner speech serves analogous function in humans, articulatory suppression should
specifically impair maintenance of constraints across conversational digressions—more than it impairs
within-turn reasoning. Test: Compare articulatory suppression effects on cross-turn vs. within-turn
task components.
Consolidation disruption. “Lesioning” MIRROR’s Cognitive Controller (removing reconstruction
while preserving threads) degrades performance by 5–20%. Analogously, consolidation-interfering
tasks between dialogue turns should produce pattern-specific failures in human constraint maintenance
matching the Controller-ablation condition. Test: Introduce interference tasks between conversational
turns and compare failure patterns.
5.3
MIRROR as a Cognitive Modeling Platform
Beyond specific predictions, MIRROR offers a general platform for computationally testing cognitive
theories. Components can be selectively disabled to produce “lesion” studies with interpretable
failure patterns. Design parameters—number of threads, reconstruction frequency, first-person vs.
third-person framing, narrative vs. structured representations—can be systematically varied. The
internal narrative provides human-readable traces of evolving understanding, enabling fine-grained
analysis paralleling protocol analysis methods in cognitive psychology. This bidirectional paradigm—
cognitive science informing AI design, AI systems generating testable cognitive predictions—is
precisely the cross-pollination this research community seeks.
5.4
Limitations
We do not claim MIRROR replicates human neural mechanisms; we test whether functional principles
from cognitive science provide computational advantages in artificial systems. The mappings
between cognitive theories and MIRROR components are operationalizations, not isomorphisms—
alternative implementations of the same principles might perform differently. Evaluation is limited
to one benchmark (CuRaTe) testing constraint maintenance; generalization to planning, reasoning,
and theory-of-mind tasks remains untested. The extended-reasoning comparison covers only one
model. MIRROR requires additional inference calls (∼460ms, $0.003–0.13/turn), though production
evaluation confirms this fits within natural conversational pauses (Appendix B).

Related Work
Computational cognitive architectures. Classical cognitive architectures, such as ACT-R [Anderson
et al., 2004], SOAR [Laird, 2012], and EPIC [Meyer and Kieras, 1997], implement detailed models
of human cognition with principled mappings between architectural components and cognitive
functions. These systems demonstrate that cognitive theory can productively constrain computational
design, but predate modern language models and operate on symbolic rather than distributional
representations. CoALA [Sumers et al., 2024] provides a cognitive framework for LLM agents,
taxonomizing memory and decision-making components. Generative Agents [Park et al., 2023]
implement memory streams inspired by episodic memory, producing emergent social behaviors.
MIRROR shares the commitment to principled cognitive grounding but differs in two respects: it
operationalizes multiple converging theories rather than a single framework, and it provides ablation
evidence that the specific organizational principles—not just cognitive inspiration broadly—drive
performance gains.
Structured reasoning and memory in LLMs. Chain-of-thought prompting [Wei et al., 2022],
Tree of Thoughts [Yao et al., 2023], and self-consistency [Wang et al., 2023] generate reasoning
traces within individual turns but discard them afterward. Reflexion [Shinn et al., 2023] preserves
traces across turns but accumulates them unboundedly. LATS [Zhou et al., 2024] combines search
with reflection; Devil’s Advocate [Wang et al., 2024] implements anticipatory reflection without
persistent state. These approaches each implement one cognitive principle in isolation—deliberation,
accumulation, or reflection—but none implement the full parallel-to-reconstructive pipeline that our
convergence analysis motivates. MIRROR’s key architectural distinction is that reasoning traces are
neither discarded nor accumulated but reconstructively synthesized into bounded persistent state.
Theory of mind and human modeling in AI. A growing body of work examines how AI systems can
model human mental states [Rabinowitz et al., 2018, Sap et al., 2022], a core topic for this workshop.
MIRROR’s parallel thread structure—separately tracking Goals (user intentions), Reasoning (belief
states), and Memory (personal history)—implicitly performs aspects of mental state modeling, though
not explicitly framed as Theory of Mind. Future work could connect MIRROR’s thread structure to
ToM benchmarks such as ToMi [Le et al., 2019].
Consciousness-inspired architectures. Recent work examines which AI architectures satisfy
criteria from theories of consciousness [Butlin et al., 2023], with several projects implementing
GWT computationally [VanRullen and Kanai, 2021, Juliani et al., 2022]. MIRROR does not claim
to implement consciousness but provides an empirical testbed for evaluating the computational
consequences of GWT’s parallel-to-unified broadcast structure, showing these features provide
measurable advantages independent of claims about subjective experience.
Asynchronous and background processing. Recent work on “sleep”-like background computation
in AI [Lin et al., 2025] demonstrates benefits of offline processing, resonating with memory consolida-
tion research [Dudai, 2004]. MIRROR’s temporal separation between Talker and Thinker specifically
operationalizes complementary learning systems theory, and our latency analysis (Appendix B)
validates that natural conversational pauses provide sufficient time for consolidative processing.
7
Conclusion
MIRROR demonstrates that converging principles from multiple cognitive theories—parallel-to-
unified processing from Global Workspace Theory, reconstructive synthesis from episodic memory
research, self-regulatory narrative from inner speech theory, and temporal separation from comple-
mentary learning systems—provide measurable, architecture-general computational advantages when
implemented together in AI systems. The finding that how reasoning is consolidated matters more
than how it is generated challenges assumptions in both AI (where chain-of-thought focuses on
generation) and cognitive science (where working memory research often emphasizes encoding over
maintenance).
The convergence itself is the key insight: principles identified by independent research traditions pro-
duce synergistic computational benefits when unified, suggesting they may address complementary

A
Architecture Details
MIRROR implements continuous internal cognition through two specialized context mechanisms.
The Inner Monologue Manager maintains its own conversation history where the assistant exclusively
replies to itself, initiated by a single non-persistent user message that instructs it to “continue thinking”
about the conversation. The Cognitive Controller maintains a single narrative text block that is
completely regenerated with each turn, inspired by episodic memory’s reconstructive nature, where
planning, current experiences, and the past interact to create a new narrative-like understanding of all
information. This dual-context approach enables persistent reasoning across turns, with the Talker
responding using the most recent narrative while reflection processes asynchronously.

A.1.1

previously established safety constraints, directly testing whether models maintain critical
constraint awareness or simply acquiesce to user requests.

Cross-Model Analysis
Several notable patterns emerge when comparing MIRROR’s impact across models:
1. Consistency Effect: MIRROR consistently improves performance stability across scenarios,
regardless of baseline model capabilities.
2. Inverse Correlation: The magnitude of improvement correlates inversely with baseline
performance. Models with lower baseline scores show larger relative improvements.
3. Scenario-Specific Impacts: The most substantial improvements typically occur in Scenario
1 (basic constraint tracking), Scenario 4 (maximum conflicting preferences), and Scenario 5
(non-conflicting preferences).
4. Model Agnostic Benefits: MIRROR provides meaningful benefits across all model sizes and
architectures, from smaller models (Mistral Small) to frontier models (Claude 3.7 Sonnet,
GPT-4o), indicating that the cognitive architecture addresses fundamental limitations in
transformer-based conversation processing rather than merely compensating for scale.
