Abstract—In many kinds of infinite-state systems, the cover-
ability problem has significantly lower complexity than the reach-
ability problem. In order to delineate the border of computational
hardness between coverability and reachability, we propose to
place these problems in a more general context, which makes it
possible to prove complexity dichotomies.
The more general setting arises as follows. We note that for
coverability, we are given a vector t and are asked if there is a
reachable vector x satisfying the relation x ≥t. For reachability,
we want to satisfy the relation x = t. In the more general setting,
there is a Presburger formula φ(t, x), and we are given t and
are asked if there is a reachable x with φ(t, x).
We study this setting for systems with one counter and binary
updates: (i) integer VASS, (ii) Parikh automata, and (i) standard
(non-negative) VASS. In each of these cases, reachability is
NP-complete, but coverability is known to be in polynomial time.
Our main results are three dichotomy theorems, one for each
of the cases (i)–(iii). In each case, we show that for every φ,
the problem is either NP-complete or belongs to AC1, a circuit
complexity class within polynomial time. We also show that it is
decidable on which side of the dichotomy a given formula falls.
For (i) and (ii), we introduce novel density measures for sets of
integer vectors, and show an AC1 upper bound if the respective
density of the set defined by φ is positive; and NP-completeness
otherwise. For (iii), the complexity border is characterized by a
new notion of uniform quasi-upward closedness. In particular, we
improve the best known upper bound for coverability in (binary
encoded) 1-VASS from NC2 (as shown by Almagor, Cohen, P´erez,
Shirmohammadi, and Worrell in 2020) to AC1.
I. INTRODUCTION
Reachability and coverability problems. Deciding reacha-
bility is one of the most fundamental tasks in the verification
of infinite-state systems. Here, we are given a configuration t
of some infinite-state system and want to decide whether there
is a run from an initial configuration that arrives in t. While
reachability algorithms are powerful tools, the complexity of
reachability is often exceedingly high. For example, in vector
addition systems with states (VASS), which feature a set of
non-negative counters that can be incremented and decre-
mented, the reachability problem is Ackermann-complete [10,
19, 20]. Moreover, even in VASS with one counter (and binary-
encoded updates), reachability is already NP-complete [17].
In contrast to reachability, deciding coverability is usually
much more efficient. In this setting, there is an ordering ≤on
the set of configurations, and we want to know whether for the
given configuration t, there is a reachable configuration x with
x ≥t. For example, in VASS, coverability is EXPSPACE-
complete (thus considerably lower than the Ackermann com-
plexity of reachability) [22, 24]. In well-structured transition
systems, reachability is often undecidable (e.g. in VASS with
resets [11]), whereas coverability is decidable under mild
assumptions [1, 14]. In fixed-dimensional VASS—where the
number d of counters is fixed—the complexity of reachability
is still far from understood, but known to be non-elementary in
dimension 8 [9]. Coverability, however, is PSPACE-complete
in every dimension d ≥2 [4, 13, 25]. In 1-VASS (i.e. VASS
with one counter), coverability is known to be in NC2 [3],
a circuit complexity class within polynomial time. In systems
with one integer counter (i.e. that is allowed to go below zero),
a classic result is that coverability is even in AC1 (see Foot-
note 2), a subclass of NC2 [27]; this is in stark contrast to the
NP-completeness of reachability for both integer 1-VASS and
standard 1-VASS. Moreover, deciding coverablity is usually
sufficient for practical verification tasks. Thus, coverability is
both pratically relevant and admits significantly more efficient
algorithms.
What makes coverability easier? Reachability and cover-
ability are similar decision problems: In each setting, we
are given a vector t ∈Zd and are asked whether we can
reach a configuration x that relates to t in a particular way.
For reachability, we have the relation “x = t”, whereas for
coverability, we have “x ≥t”. This viewpoint raises the
question: What makes the relation “x ≥t” so much more
amenable to analysis than “x = t”? Therefore, we propose
to study reachability problems as above, where the relation
between t and x is specified by an arbitrary—but fixed!—
formula in Presburger arithmetic, the first-order theory of the
structure ⟨Z; +, ≤, 0, 1⟩. Presburger arithmetic can define the
relations “x = t” and “x ≥t”, and its expressiveness is well-
understood. This makes it a promising candidate to explore
the space around reachability and coverability.
Understanding the complexity of Presburger target sets.
More precisely (but still informally), we want to understand
the following type of reachability problems. For each fixed
formula φ of Presburger arithmetic and a class C of counter
systems, we define the φ-reachability problem as follows. We
are given (i) a system from C with d counters and (ii) a

In this setting, our goal is to understand how the complexity

Our contributions. We initiate this line of research by study-
ing φ-reachability in systems with one counter (with binary
encodings). As mentioned above, in this context, reachability
is usually NP-complete, whereas for coverability, polynomial-
time algorithms are available. Our main results are three com-
plexity dichotomies for Presburger target sets, each regarding
one model of one-dimensional counter systems. Specifically,
we consider the following models of computation1:
• 1-dim. Z-VASS: Updates and configurations are integers.
• 1-dim. Parikh automata: All updates (and hence also
configurations) are natural numbers.
• 1-dim. VASS: Updates are integers, but only natural num-
bers are valid in configurations.
Each of our three dichotomies shows that for every φ, φ-
reachability for the respective model is either in AC1 or is
NP-complete, and provides a characterization for the respec-
tive formulas. Since we always have d = 1, the formula φ
always defines a subset of S ⊆Zp+1; the first p components
refer to parameter vectors t ∈Zp, and the right-most compo-
nent carries the counter values x ∈Z.
One-dimensional Z-VASS and Parikh automata. For 1-
dim. Z-VASS and for 1-dim. Parikh automata, the resulting
decision problems are denoted ReachZ(S) and ReachN(S), re-
spectively. We obtain dichotomies based on density measures.
We introduce two density measures for subsets S ⊆Zp+1:
the local density of S, denoted D(S), and the local+ density,
denoted D+(S). Here, D(S) and D+(S) are real numbers
in [0, 1]. We show that if D(S) > 0, then ReachZ(S) is in
AC1, and otherwise, ReachZ(S) is NP-complete. Similarly,
if D+(S) > 0, then ReachN(S) is in AC1, and otherwise,
ReachN(S) is NP-complete.
Our local density measures are similar in spirit to (but
different from) the Shnirel’man density from Additive Number
Theory [23] (see Remark III.1). Intuitively, D(S) measures the
probability of hitting S when randomly picking a point in an
interval (or arithmetic progression) centered at a point in S.
One-dimensional VASS. For 1-VASS (we also refer to this
setting as “VASS semantics”), we denote φ-reachability as
ReachVASS(S). We show that if S is “uniformly quasi-upward
closed” (defined precisely in Section III), then ReachVASS(S)
is in AC1. Moreover, in all other cases, ReachVASS(S) is NP-
complete. In particular, we show that coverability in 1-VASS
is in AC1 (with a surprisingly simple algorithm!), improving
upon the previously best-known upper bound of NC2.

more subtle than expected. For example, for S1 = {(t, x) ∈

Key ingredients. Our results rely on several novel con-
cepts and new algorithmic techniques. Our contributions for
Z-VASS and Parikh automata are substantially more challeng-
ing than for 1-VASS. The case of Parikh automata can be
deduced from the one for Z-VASS, making the Z-VASS setting
the most involved result of this work. The first difficulty lies
within concrete sets S ⊆Zp+1 for which it is not clear whether
it is solvable in polynomial time. For example, consider
S1 = {(t, x) ∈Z1+1 | t ≥0, x ∈[t, 2t]}.
Then the complexity of ReachN(S) is not clear: The inter-
val [t, 2t] is finite, and thus coverability techniques are not
applicable. The interval is also “too wide” (compared to its
distance from 0) to reduce, for example, to subset sum. One
of our new algorithmic approaches is to construct a semiring
(defined by a set of equations) for S such that reachability
in ReachN(S) can again be decided in polynomial time (and
even in AC1) via repeated matrix squaring. The semiring
construction also applies to more complicated settings where
S contains multiple intervals, such as S′ ⊆Z2+1, the set of
all ⟨s, t, x⟩where
s, t ≥0, x ∈[s + t, s + 2t] ∪[s + 3t, 2s + 4t].
More generally, it applies whenever x is constrained to belong
to a “ρ-chain of intervals”, where each interval’s distance to
the next (or to zero) is at most ρ times its own length. In S′,
the interval [s + t, s + 2t] has length t, and distance t to the
next interval [s + 3t, 2s + 4t]. The latter, in turn, has length
s + t, and has distance s + 3t ≤3(s + t) from zero.
Second, using ideal decompositions from WQO theory, we
show that whenever D(S) > 0, then S decomposes into
ρ-chains of intervals. Conversely, we show that if D(S) = 0,
then subset sum reduces to ReachZ(S).
Third, we show that for every semilinear S ⊆Zp+d, both
ReachZ(S) and ReachN(S) reduce in logspace to the case
of acyclic automata. This even applies to higher dimensions
d, and is crucial for applying matrix squaring logarithmically
many times. The reduction relies on Eisenbrand & Shmonin’s
Carath´eodory theorem for integer cones [12].
For the VASS semantics, the AC1 upper bounds rely on
a new AC1 procedure for coverablity in 1-VASS, improving
upon the previously best-known upper bound of NC2. The
procedure is surprisingly simple and although we claim that
our contributions for Z-VASS are the most technically chal-
lenging, the correctness of our dichotomy for 1-VASS is not
obvious. It relies on viewing coverability as computing weights
for a weighted automaton over a newly introduced semiring.

II. PRELIMINARIES
We use boldface for vectors, and square brackets to index
vectors. For example, if v ∈Zk, then v = ⟨v[1], . . . , v[k]⟩.
Given u ∈Zk1 and v ∈Zk2, we use the shorthand ⟨u, v⟩to
denote the vector ⟨u[1], . . . , u[k1], v[1], . . . , v[k2]⟩∈Zk1+k2.
A Z-weighted automaton A = ⟨Q, T, q0, q1⟩is an automa-
ton where Q is a finite set of states, T ⊆Q×Z×Q is a finite
set of transitions, and q0, q1 ∈Q are the initial and final state,
respectively. Here, for a transition ⟨q, w, r⟩∈T, the number
w is the weight of the transition. Transition weights are always
encoded in binary.
We define three semantics. A configuration is a pair ⟨q, x⟩
for some q ∈Q and x ∈Z. For configurations ⟨q, x⟩, ⟨r, y⟩,
we write ⟨q, x⟩−→Z ⟨r, y⟩if there a transition ⟨q, w, r⟩∈T
with y = x + w. Moreover, ⟨q, x⟩−→VASS ⟨r, y⟩means
⟨q, x⟩−→Z ⟨r, y⟩and also x, y ≥0. Finally, ⟨q, x⟩−→N ⟨r, y⟩
means ⟨q, x⟩−→VASS ⟨r, y⟩and also x ≤y. These step
relations are called integer semantics (−→Z), natural semantics
(−→N), and VASS semantics (−→VASS). By
∗−→Z, we denote the
reflexive, transitive closure of −→Z (analogously for
∗−→VASS
and
∗−→N).
The decision problems we study are parameterized by a set
S ∈Zp+1 of vectors. The input will consist of a Z-weighted
automaton and a vector t ∈Zp, and we want to know whether
we can reach a number in the set
S[t] := {x ∈Z : ⟨t, x⟩∈S}.
With this, we can define the decision problems. Let S ⊆Zp+1.
Then ReachZ(S) is the following problem.

Presburger arithmetic is the first-order theory of the struc-

We assume basic familiarity with circuit complexity (how-
ever, no circuit complexity is needed to see that our AC1
procedures work in polynomial time). We will work with ACi,
the class of decision problems solvable by polynomial-sized
unbounded fan-in Boolean circuits of depth (log n)i (for input
size n), and sometimes NCi, the class of problems decidable
by polynomial-sized bounded fan-in circuits of depth (log n)i
(for input size n). Finally, TCi is the class of problems solvable
by polynomial-sized unbounded fan-in circuits with Boolean
gates and majority gates, of depth (log n)i (for input size n).

AC0 ⊆TC0 ⊆NC1 ⊆L ⊆NL ⊆AC1 ⊆TC1 ⊆NC2.
We will not mention details explicitly, but our AC1 upper
bounds refer to (deterministic) logspace uniform AC1. In
our algorithms, the only knowledge we use is that additions
and comparisons of pairs of binary-encoded integers can be
computed in AC0 [27, Thm 1.15].

C. VASS Semantics
To state our dichotomy for when VASS semantics are used,
we need some terminology. For δ ≥1, we say that A ⊆N is
δ-upward closed if A+δ ⊆A, where A+δ := {x+δ | x ∈A}.
For M ≥0 and δ ≥1, we say that A ⊆N is ⟨δ, M⟩-upward
closed if there is a set F ⊆N with |F| ≤M such that A ∪F
is δ-upward closed. Further, A is quasi-upward closed if there
are δ ≥1 and M ≥0 such that A is ⟨δ, M⟩-upward closed.
A set S ⊆Zp × N is uniformly quasi-upward closed if there
are δ ≥1 and M ≥0 such that for every t ∈Zp, the set S[t]
is ⟨δ, M⟩-upward closed.

B. Making automata acyclic
We now show that for ReachZ(S), we may assume that the
input automaton is acyclic. Let AcReachZ(S) be the problem
ReachZ(S) where the input must be an acyclic automaton.
Theorem V.3. For each semilinear S ⊆Zp+k, the problem
ReachZ(S) reduces in logspace to AcReachZ(S).
Proof sketch. First, one can construct a polynomial-sized ex-
istential Presburger formula for the set of vectors over the
transitions that correspond to a run reaching S (because the
Parikh image of an NFA admits a polynomial-sized existential
Presburger formula [26, Thm. 1]). By solution size bounds for
integer programming, this yields an exponential bound ℓon
the length of a shortest run. This means, it suffices to construct
an acyclic automaton A′ that simulates at least those runs of
the input automaton A that are of length ≤ℓ. By standard
arguments about rearranging cycles, it suffices to do this for
the set of runs that are concatenations of short q-cycles for
some state q. Here, a short q-cycle is a cycle of length at
most n (the number of states of A) that start and end in q.
A Carath´eodory-type result about integer cones by Eisen-
brand and Shmonin [12, Thm. 1] implies that the counter effect
of such a concatenation can be produced by a concatenation
that uses ≤r distinct short q-cycles, for some polynomial r.
Again by integer programming solution sizes (and our bound
ℓ), we may assume this modified concatenation to contain each
of the q-cycles at most m times, for some exponential m.
To simulate such a concatenation, we build an acyclic gadget
that, for each j ∈[0, ⌈log m⌉] in sequence, guesses a short
q-cycle on-the-fly, and multiplies its effect by 2j. Picking
different q-cycles for different j is possible, but also yields
runs consistent with A. Using the gadget r times in a row
simulates all concatenations as above. See Appendix C.IV.
C. Unbounded isolation
On the way to prove Theorem III.2, we will characterize
the modulo-free sets of local density zero using the notion of
“unbounded isolation”. This is also used in Theorem III.8.
We say that S ⊆Zp+1 has unbounded isolation if there
exists an ℓ≥1 such that for every δ ≥1, there exists a
t ∈Zp and an x ∈Z such that:
(a) S[t] ∩[x, x + ℓ−1] ̸= ∅,
(b) S[t] ∩[x −δ, x −1] = ∅, and
(c) S[t] ∩[x + ℓ, x + ℓ+ δ] = ∅.
In other words, we can find an interval I of size ℓ(namely,
[x, x + ℓ−1]) such that I contains a point in S[t] and on
either side of I, there is an interval of size δ that does not
intersect S[t]. Intuitively, I is isolated in the sense that it is
neighbored by δ-sized empty intervals. A proof (and a sketch)
of the following lemma can be found in Appendix C.V
Lemma V.4. Suppose S ⊆Zp+1 has unbounded isolation.
Then ReachZ(S) is NP-hard.
The conditions of unbounded isolation are directly express-
ible in Presburger arithmetic. Thus, we obtain:
Lemma V.5. Given a modulo-free Presburger formula for
S ⊆Zp+1, it is decidable whether S has unbounded isolation.

Interval notation: It will be convenient to use notations
for distance and length of intervals. For two disjoint intervals
I, J ⊆Z, let d(I, J) be the minimum distance between a
point in I from a point in J. By |I|, we denote the length of I
(i.e. the difference between the largest and smallest point). For
disjoint intervals I and J, we write I < J if the numbers in I
are smaller than those in J. We observe a triangle inequality
for intervals: If I, J, K are pairwise disjoint intervals, then
d(I, J) ≤d(I, K) + |K| + d(K, J). This is trivial if K is
infinite. If K is finite and wlog I < J, then one can check this
by considering all possible arrangements: K, I, J and I, K, J,
and I, J, K. A central notion in our proof is the notion of a
ρ-chain of intervals—a sufficient condition for the existence
of a polynomial-time (even AC1) algorithm for reachability.
Definition V.6 (ρ-chain of intervals). Let ρ ≥1 be a constant.
A sequence I1, . . . , Im+1 of intervals is called a ρ-chain of

(A1) I1, . . . , Im, Im+1 are pairwise disjoint,
(A2) |I1| ≤|I2| ≤· · · ≤|Im|,
(A3) for every i ∈[1, m], d(Ii, Ii+1) ≤ρ · |Ii|, and
(A4) for every i ∈[2, m + 1], either
(i) Ii > Ij for all j ∈[1, i −1], or
(ii) Ii < Ij for all j ∈[1, i −1].
Roughly speaking, Condition (A4) requires that for every
interval Ii, all smaller intervals I1, . . . , Ii−1 are either to the

Proposition V.9. Suppose S ⊆Zp+1 is a modulo-free set.
Then the following are equivalent:
(1) S has positive local density.
(2) S does not have unbounded isolation.
(3) S is a finite union of transformed building blocks.
The implications “(1)⇒(2)” and “(3)⇒(1)” are mostly
straightforward. For the latter, one can observe that trans-
formed building blocks have positive local density. Intuitively,
this is because when starting from a point in some interval
I in a ρ-chain of intervals, the distance to the next interval
J in the chain is always at most ρ times the length of
I. Therefore, we “collect enough points” during I to get
us over the gap to J, while maintaining a probability of
roughly ≥1/(ρ + 1) of hitting I. Once we reach J, we
then collect more points from J that will then get us over
the next gap, etc. Furthermore, for S, S′ ⊆Zp+1, we have
D(S ∪S′) ≥min(D(S), D(S′)), so that a positive density of
the constituents yields a positive density of the entire union.

done by repeated squaring: If n = 2k, then one can compute

semiring, since each squaring can be performed in AC0, doing
this logarithmically many times leads to an AC1 procedure.

B. Coverability in AC1: The algorithm
We now show that coverability in 1-VASS is in AC1. This
improves on the NC2 upper bound shown by Almagor, Cohen,
P´erez, Shirmohammadi, and Worrell [3, Theorem 23]. Their
algorithm, roughly speaking, maintains a set of paths, and
expands this set ⌈log n⌉times (for n states). After k steps,
the current set Pk of paths is large enough so that anything
that can be covered in ≤2k steps, can also be covered using
Pk. To prevent exponential growth, the set is pruned each time.
This involves operations on paths in NC1 in each step, hence
NC2 overall. Our algorithm can be viewed as decomposing
the paths in Pk so that it suffices to store a single number for
each piece. Then each step is in AC0, yielding AC1 overall.
We first describe our algorithm as a simple combinatorial
procedure. Its correctness is not obvious, but will be proven
afterwards via an algebraic description. A coverability table
T(p, q), for each pair of states p, q, is a list of pairs of
natural numbers ⟨u1, v1⟩, . . . , ⟨um, vm⟩such that ⟨p, u⟩can
cover ⟨q, v⟩if and only if there is an i with u ≥ui and
vi +(u−ui) ≥v. We will show that in AC1, given an acyclic
1-VASS, we can compute a coverability table T(p, q) in AC1.
Computing coverability tables for acyclic 1-VASS in AC1
suffices for deciding coverability in (not necessarily acyclic)
1-VASS in AC1 for the following reason. Let A be a 1-VASS
with n states Q. Consider the acyclic 1-VASS A′ that is
obtained from A by simulating runs of length at most n. More
precisely, let Q′ ⊆{qℓ: q ∈Q and ℓ∈[0, n]} be the states
of A′; the idea is that there are n + 1 copies of each state q
in A and, for k, ℓ∈[0, n], the state qℓin A′ can be reached
from pk if there is a run from p to q of length exactly ℓ−k
in A. Note that ⟨p, u⟩can cover ⟨q, v⟩in A if and only if
(i) for some ℓ∈[0, n], ⟨p0, u⟩can cover ⟨qℓ, v⟩in A′, or
(ii) there is a state r ∈Q, ℓ∈[0, n], and an entry ⟨ui, vi⟩
in the coverability table T(r0, rℓ) of A′ such that ⟨p0, u⟩
can cover ⟨rℓ, ui⟩in A′ and vi > ui, and q is reachable
from r in the underlying finite automaton.
Let us now see how to compute T(p, q) in AC1. Suppose we

sum w1+· · ·+wm, or (ii) if some partial sum w1+· · ·+wi is

VIII. CONCLUSION
We have provided dichotomies for the reachability problem
in systems with one counter and integer, natural, or VASS
semantics. This raises several further questions.
First, which complexities arise in higher dimension? For
fixed-dimensional VASS, even ordinary reachability is not
understood [8], meaning a full dichotomy for semilinear target
sets appears to be a longterm goal. For natural semantics,
there are concrete target sets S ⊆N0+2 (i.e., with p = 0)
where it is not clear whether ReachN(S) is in polynomial
time, such as S = {⟨x1, x2⟩∈N2 | x2 ∈[x1, 2x1]}. Thus,
NP vs. P dichotomies in higher dimension for integer and
natural semantics seem challenging as well.
This work reveals a variety of decision problems about
systems with one counter that can be solved in AC1. Here, AC1
seems to be a difficult barrier to break. Since at least 1990,
it is open whether the AC1 upper bound for the shortest-path
problem in automata weighted with naturals can be improved
(see [7, p. 13] and [6, p. 32]); and this is a special case of
coverability in both integer and VASS semantics.

I. Proof of Theorem IV.1
Theorem IV.1. Let S ⊆Zp+1 be semilinear. ReachZ(S),
ReachN(S), and ReachVASS(S) are in NP.
Proof. The result for ReachN(S) is a special case of the

Given a Z-weighted automaton and two states p, q, we can
construct, both for VASS semantics and for integer semantics,
a Presburger formula ψp,q(x, y) such that from a configuration
p(u), we can reach q(v) if and only if ψp,q(u, v) holds. For
VASS semantics, this follows from the fact that this can even
be done for one-counter automata [21]. For integer semantics,
a more general fact has been shown in [16, Corollary 10].

and t ∈Zp, we have reachability of S[t] if and only if
∃x: ψp,q(0, x) ∧φ(t, x), which is an existential Presburger
formula. Since determining the truth of existential Presburger
formulas is NP-complete, this completes the proof.

Indeed, if [S]B,b is ⟨δb, Mb⟩-upward closed for some δb ≥1
and Mb ≥0, then it is easy to observe that S is ⟨δ, M⟩-upward
closed, where δ is the product of all δb, and M is the sum of
all Mb.
This proves our claim.
It now remains to prove:
Claim E.7. Suppose T is modulo-free. Then T is not uniformly
quasi-upward closed if and only if T has unbounded gaps.
First, suppose T is not uniformly quasi-upward closed.
Since T is defined by a modulo-free Presburger formula, let
α1, β1, . . . , αm, βm : Zp →N ∪{∞} be the Presburger-
definable functions as per Lemma B.1. Recall that these
functions have the following two properties. Firstly, for all
t ∈Zp,
α1(t) ≤β1(t) ≤α2(t) ≤. . . ≤βm−1(t) ≤αm(t) ≤βm(t).
Secondly,
T[t] = (α1(t), β1(t)) ∪· · · ∪(αm(t), βm(t)).
(1) Suppose there is a t ∈Zp such that βm(t) ∈N. In that
case, T = [S]B,b clearly has unbounded gaps. Indeed,
there is even a single infinite gap; that is (βm(t), ∞).
(2) Suppose βm(t) = ∞for every t ∈Zp. Now consider,
for any given t ∈Zp, the “largest gap size”:
Mt =
max
i∈[1,m−1]{αi+1(t) −βi(t)}.
Now if the function t 7→Mt were bounded by some
M ≥0, then T[t] would be ⟨1, mM⟩-upward closed for
every t ∈Zp; this cannot be the case as we assumed that
S is not uniformly quasi-upward closed. Therefore, for
every M ≥0, there exist t ∈Zp and i ∈[1, m −1] such
that αi+1(t) −βi(t) ≥M. This means that T = [S]B,b
has unbounded gaps.
Conversely, if T has unbounded gaps, then it cannot be
⟨δ, M⟩-upward closed for any δ ≥1, M ≥0. This is true
because T[t] has a gap of size g := δ + M + 1, injecting any
set of M-many points into T will still leave a gap of δ + 1,
so that the result cannot be δ-upward closed. This completes
the proof of the second claim.
Together the two claims establish the lemma.
Finally, Lemma E.5 implies Theorem III.17, since it reduces
checking uniformly quasi-upward closedness to deciding the
unbounded gaps property. The latter, in turn, is directly ex-
pressible in Presburger arithmetic and thus decidable.
