Department of Computer Science, University of Helsinki, Finland

Abstract. In the String Matching in Labeled Graphs (SMLG) prob-
lem, we need to determine whether a pattern string appears on a given
labeled graph or a given automaton. Under the Orthogonal Vectors hy-
pothesis, the SMLG problem cannot be solved in subquadratic time
[ICALP 2019]. In typical bioinformatics applications, pattern matching
algorithms should be both fast and space-eﬃcient, so we need to deter-
mine useful classes of graphs on which the SLMG problem can be solved
eﬃciently.
In this paper, we improve on a recent result [STACS 2024] that shows
how to solve the SMLG problem in linear time on the compressed repre-
sentation of Wheeler generalized automata, a class of string-labeled au-
tomata that extend de Bruijn graphs. More precisely, we show how to re-
move the assumption that the automata contain no ǫ-transitions (namely,
edges labeled with the empty string), while retaining the same time and
space bounds. This is a signiﬁcant improvement because ǫ-transitions
add considerable expressive power (making it possible to jump to mul-
tiple states for free) and capture the complexity of regular expressions
(through Thompson’s construction for converting a regular expression
into an equivalent automaton). We prove that, to enable ǫ-transitions,
we only need to store two additional bitvectors that can be constructed
in linear time.
Keywords: Pattern matching · Wheeler automata · Burrows-Wheeler
transform · FM-index.

Introduction
Pattern matching is one of the fundamental problems in computer science. In
the 1970s, two elegant linear-time solutions were proposed. One solution is based
on the Knuth-Morris-Pratt (KMP) algorithm [26]; the other solution is based on
suﬃx trees [35]. Twenty years later, several authors extensively studied the String
Matching in Labeled Graphs (SMLG) problem, which is the natural generaliza-
tion of pattern matching to a graph setting [28,1,31,5,33,29]. Loosely speaking,
the SMLG problem can be deﬁned as follows: given a directed graph whose nodes
(or edges) are labeled with strings and given a pattern string, decide whether
the pattern can be read by following a path on the graph and concatenating
the labels encountered along the way. Since every text can be seen as a graph
consisting of a single path, the SMLG problem is a natural extension of the clas-
sical pattern matching problem. Unfortunately, the elegant and general solutions

based on the KMP algorithm and suﬃx trees do not admit a simple generaliza-

of all labels in the graph. In the (approximate) variant where one allows errors

lowed in the pattern. Recently, some conditional lower bounds showed that the
SMLG problem is inherently more complex than the classical pattern matching
problem. Equi et al. [18,19] showed that, given an arbitrary graph, the SMLG
cannot be solved in O(me1−ǫ) or O(m1−ǫe) time (for every ǫ > 0), unless the
Orthogonal Vectors hypothesis is not true.
Due to the sheer increase in the amount of data (and in particular of genomic
data), in applications (and especially in bioinformatics) we need algorithms that
are both fast and space-eﬃcient. A polynomial algorithm for the SMLG problem
running in O(me) time cannot be satisfactory, so the SMLG problem has been
restricted to classes of graphs on which it can be solved more eﬃciently. For
example, the SMLG problem can be solved in linear time on Elastic Founder
graphs under some non-restrictive assumptions [20,34]. Elastic Founder graphs
are used to represent multiple sequence alignments (MSA), a central model of
biological evolution.
We mentioned that we also strive for space-eﬃcient algorithms. The pat-
tern matching problem on texts has been revolutionized by the invention of the
Burrows-Wheeler Transform [9] and the FM-index [22], which allow solving pat-
tern matching queries eﬃciently on compressed text, thus establishing a new
paradigm in bioinformatics. Over the last decade, these ideas were extended to
labeled graphs and automata. On the popular class of Wheeler automata, the
SMLG problem can be solved in linear time while only storing a compressed
representation of the Wheeler automaton [23,3]. Note that a labeled graph and
an automaton are essentially the same object: an automaton is simply a labeled
graph with an initial state and a set of ﬁnal states. However, we will generally
speak of automata rather than graphs because the results in this area often have
relevant applications in formal language theory, and because some (algorithmic)
properties of labeled graphs are tied to determinism. For example, the power-
set construction applied to a Wheeler non-deterministic automaton leads to a
linear blow-up in the number of states of the equivalent deterministic automa-
ton, and the equivalent deterministic automaton is Wheeler [3]; on arbitrary
non-deterministic automata, the blow-up can be exponential. A special case of
Wheeler automata are de Bruijn graphs [8], which are used to perform Eulerian
sequence assembly [25,32,7].

of ǫ-transitions because the empty string has length equal to zero.

bounds in Theorem 1 even in the presence of ǫ-transitions, without imposing any
restrictions on the automaton A. More precisely, we will show that we only need
to store two additional bitvectors. Intuitively, these bitvectors capture the range
of states that we can reach by following ǫ-transitions. We also show that these
bitvectors can be built in linear time (Theorem 2). In addition to proving the
result in [13] in full generality, supporting ǫ-transitions provides some speciﬁc
advantages.

Preliminaries
First deﬁnitions Let V be a set. We say that a (binary) relation ≤on V is a
partial order if ≤is reﬂexive, antisymmetric and transitive. For every u, v ∈V ,
we write u < v if (u ≤v)∧(u ̸= v). A partial order ≤is a total order if for every
u, v ∈V we have (u ≤v) ∨(v ≤u). We say that U ⊆V is ≤-convex if, for every
u, v, z ∈V , from u < v < z and u, z ∈U we obtain v ∈U.
Let Σ be a ﬁnite alphabet. We denote by Σ∗the set of all ﬁnite strings on Σ,
where ǫ ∈Σ∗is the empty string. For i ≥0, let Σi ⊆Σ∗be the set of all strings
of length i on the alphabet Σ. If α, β ∈Σ∗, we write α ⊣β if and only if α is a
suﬃx of β (equivalently, if and only if there exists β′ ∈Σ∗such that β = β′α).
If α ∈Σ∗and 0 ≤k ≤|α|, let p(α, k) and s(α, k) be the preﬁx and the suﬃx of
α of length k, respectively. We assume that there exists a ﬁxed total order ⪯on
the alphabet Σ (in our examples, we always assume a ≺b ≺c ≺. . . ), and ⪯is
extended co-lexicographically to Σ∗(that is, for every α, β ∈Σ∗we have α ≺β
if and only if the reverse string αR is lexicographically smaller than the reverse
string βR).
A generalized non-deterministic ﬁnite automaton (GNFA) is a 4-tuple A =
(Q, E, s, F), where Q is a ﬁnite set of states, E ⊆Q × Q × Σ∗is a ﬁnite set
of string-labeled edges, s ∈Q is the initial state and F ⊆Q is a set of ﬁnal
states (see Figure 1). Moreover, we assume that each u ∈Q is reachable from
the initial state and is co-reachable, that is, it is either ﬁnal or allows reaching a
ﬁnal state. This is a standard assumption because all states that do not satisfy
this requirement can be removed without changing the language recognized by
the automaton. We say that a GNFA A = (Q, E, s, F) is a GNFA without ǫ-
transitions if for every (u, v, ρ) ∈E we have ρ ̸= ǫ. A generalized deterministic
ﬁnite automaton (GDFA) is a GNFA without ǫ-transitions A = (Q, E, s, F) such
that for every pair of distinct edges (u, v, ρ), (u′, v′, ρ′) ∈E, if u = u′, then ρ is
not a preﬁx of ρ′ and ρ′ is a not a preﬁx of ρ (in particular, ρ ̸= ρ′).

Let A = (Q, E, s, F) be a GNFA. For r ≥0, we say that A is an r-GNFA if
each edge label has length at most r (namely, |ρ| ≤r for every (u, v, ρ) ∈E).
For U ⊆Q and ρ ∈Σ∗, let out(U, ρ) be the number of edges labeled with ρ
that leave states in U, and let in(U, ρ) be the number of edges labeled with ρ
that enter states in U. For every u ∈Q let λ(u) be the set of all strings in Σ∗
labeling an edge reaching u. Moreover, for every u ∈Q, let Iu be the set of
all strings that can be read from the initial state to u by concatenating edge
labels. In other words, for every α ∈Σ∗we have α ∈Iu if and only, for some
t ≥1, there exist u1, . . . , ut ∈Q and α1, . . . , αt−1 ∈Σ∗such that (i) u1 = s and
ut = u, (ii) (ui, ui+1, αi) ∈E for every 1 ≤i ≤t −1, and (iii) α = α1α2 . . . αt−1
(in particular, ǫ ∈Is). As observed in [13], if A = (Q, E, s, F) is a GDFA and
u, v ∈Q, with u ̸= v, then Iu ∩Iv = ∅.
Let A be a GNFA. The String Matching in Labeled Graphs (SMLG) problem
for GNFAs is deﬁned as follows: build a data structure that encodes A such that,
given a string α, we can eﬃciently compute the set of all states reached by a
path suﬃxed by α.
Our main result (Theorem 1) holds for polynomial alphabets (namely, σ ≤
eO(1)) in the word RAM model with words of size w ∈Θ(log N) bits, where N
is the input size.
Wheeler GNFAs Let A = (Q, E, s, F) be a GNFA. Let ⪯A be the relation on
Q such that, for every u, v ∈Q, we have u ⪯A v if and only if (∀α ∈Iu)(∀β ∈
Iv)(({α, β} ̸⊆Iu ∩Iv) →(α ≺β)). As observed in [13], in general ⪯A is only
a preorder, that is, it is a reﬂexive and transitive relation, but it need not be
antisymmetric. If A is a GDFA, we know that u ̸= v implies Iu ∩Iv = ∅, so
⪯A is a partial order, and it is the reﬂexive relation such that, for every distinct
u, v ∈Q we have u ≺A v if and only if (∀α ∈Iu)(∀β ∈Iv)(α ≺β).
Let A = (Q, E, s, F) be a GNFA. We say that A is Wheeler [13] if there
exists a total order ≤on Q such that:
– (Axiom 1) For every u, v ∈Q, if u ≤v, then u ⪯A v.
– (Axiom 2) s comes ﬁrst in the total order ≤.
– (Axiom 3) For every (u′, u, ρ), (v′, v, ρ′) ∈E, if u < v and ρ′ is not a strict
suﬃx of ρ, then ρ ⪯ρ′.
– (Axiom 4) For every (u′, u, ρ), (v′, v, ρ) ∈E, if u < v, then u′ ≤v′.
We say that ≤is a Wheeler order on A. (see Figure 1 for an example).
Notice that, if A is a GNFA without ǫ-transitions, then Axiom 2 follows from
Axiom 1 because ǫ ∈Is and for every u ∈Q \ {s} we have ǫ ̸∈Iu. Moreover,
if A is a GDFA, then Axioms 2, 3, 4 follow from Axiom 1 (see [13]). Lastly, if
A is a conventional NFA, then Axiom 1 follows from Axiom 2, 3, 4 (see [13])
and we retrieve the usual local deﬁnition of Wheeler NFA [3, Corollary 3.1]: a
(conventional) NFA is Wheeler if there exists a total order ≤on Q such that (i)
s comes ﬁrst in the total order ≤, (ii) for every (u′, u, a), (v′, v, b) ∈E, if u < v,
then a ⪯b and (iii) for every (u′, u, a), (v′, v, a) ∈E, if u < v, then u′ ≤v′.

Pattern Matching with ǫ-transitions
Let us show how to extend the results of Section 3 to arbitrary Wheeler GNFAs
(possibly with ǫ-transitions). First, let us show that Lemma 2 is not true if ǫ-
transitions are allowed. In Figure 1, for α = cba, the largest integer 0 ≤j ≤|Q|
such that the two conditions of Lemma 2 are true is 4 (note that |G≺(cb)| = 9,
f1 = 3, |G≺(c)| = 9, f2 = 2), but |G≺(α)| = 2 ̸= 4. This is due to the ǫ-
transitions (5, 3, ǫ) and (5, 4, ǫ) and intuitively, to obtain a correct variant of
Lemma 2, we need to remember the range of states that we can reach by following
ǫ-transitions in a backward fashion.
Let A = (Q, E, s, F) be a GNFA. Given u, v ∈Q, we say that there exists an
ǫ-walk from u to v if, for some t ≥1 there exist z1, z2, . . . , zt ∈Q such that (i)
z1 = u and zt = v and (ii) (zi, zi+1, ǫ) ∈E for every 1 ≤i ≤t −1 (in particular,
for every u ∈Q there exists an ǫ-walk from u to u).
We can now deﬁne Amax and Amin, the two crucial arrays to obtain our
result.
Deﬁnition 2. Let A = (Q, E, s, F) be a Wheeler GNFA, and let ≤be a Wheeler
order on A. Let Amax[1, |Q|] (Amin[1, |Q|], respectively) be the array such that,
for every 1 ≤i ≤|Q|, we have that Amax[i] (Amin[i], respectively) is the largest
(smallest, respectively) integer 1 ≤j ≤|Q| for which there exists an ǫ-walk from
Q[j] to Q[i].
Note that for every 1 ≤i ≤|Q| we have Amin[i] ≤i ≤Amax[i] because there
exists an ǫ-walk from Q[i] to Q[i]. In Figure 1 we have Amax[3] = Amax[4] = 5
and Amax[i] = i for i ̸∈{3, 4}.
We will use Amax and Amin to prove Theorem 1, but we will not explicitly
store Amax and Amin (which would require |Q| log |Q| bits per array), because
otherwise we could not achieve the space bound of e log σ(1 + o(1)) + O(e) bits

Theorem 2. Let A = (Q, E, s, F) be a Wheeler GNFA. Then, in O(e) time we
can build Amax and Amin.
Proof. We present only the proof for Amax because the proof for Amin is anal-
ogous. Consider an array A[1, |Q|]. At the beginning of the algorithm, we have
A[i] = i for every 1 ≤i ≤|Q|, and at the end of the algorithm we will have
A[i] = Amax[i] for every 1 ≤i ≤|Q|. We perform a depth-ﬁrst search on the
transpose of A (that is, we follow the edges in a backward fashion). In other
words, when we process a node u, we consider all nodes v such that for some
ρ ∈Σ∗we have (v, u, ρ) ∈E. At any time, every node is white, gray or black. A
white node can only become gray and a gray node can only become black. Every
node is white at the beginning of the algorithm, and every node is black at the
end of the algorithm.
The algorithm considers all nodes Q[i]. If Q[i] is white, we paint Q[i] gray and
we consider all j’s such that j ̸= i and (Q[j], Q[i], ǫ) ∈E. For every such node
Q[j], if Q[j] is black and A[j] > A[i], we set A[i] ←A[j], and if Q[j] is white,
we recursively process Q[j] and when the recursion is complete, if A[j] > A[i],
we set A[i] ←A[j]. After processing every j, we paint Q[i] black and we process
the next Q[i].
The algorithm runs in O(e) time because every edge is processed once. Note
that after a node Q[i] becomes black, the value A[i] is no longer updated. More-
over, when we consider all j’s such that j ̸= i and (Q[j], Q[i], ǫ) ∈E, no such j
can be gray by Property 1. As a consequence, by Property 2 we conclude that
at the end of the algorithm we have A[i] = Amax[i] for every 1 ≤i ≤|Q|, which
can be seen by considering all i’s in the order in which they become black.

Conclusions and Future Work
In this paper, we have shown how to achieve linear-time pattern matching on
arbitrary Wheeler GNFAs within compressed space (Theorem 1). To this end,
we have introduced two arrays Amax and Amin that can be built in linear time

Wheeler transform and the FM-index, including labeled trees [21], de Bruijn
graphs [8] and conventional Wheeler graphs [23,3], which have led to a fruitful
line of research [2,10,15,12,17,4].
There are several potential directions for future research. The ideas behind
Wheeler NFAs have been extended to arbitrary NFAs [16,11], so the next natural
step is to extend the same paradigm to arbitrary GNFAs (however, on arbitrary
NFAs and GNFAs we cannot achieve linear-time pattern matching because of
Equi et al.’s lower bound mentioned in the introduction). It is still an open
problem to characterize the class of all regular languages recognized by some
Wheeler GNFA, even though it is known that this class is strictly larger than the
class of all regular languages recognized by some Wheeler NFA [13]. Moreover,
in this paper we focused on ǫ-transitions, so it should be possible to extend the
results in [14] on the complexity of regular expression by leveraging Thompson’s
construction for converting a regular expression into an equivalent automaton
[24], which heavily relies on ǫ-transitions.
