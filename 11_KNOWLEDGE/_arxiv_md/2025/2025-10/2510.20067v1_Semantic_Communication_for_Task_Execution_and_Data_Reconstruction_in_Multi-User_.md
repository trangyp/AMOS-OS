Abstract—Semantic communication has gained significant at-
tention with the advances in machine learning. Most semantic
communication works focus on either task execution or data
reconstruction, with some recent works combining the two.
In this work, we propose a semantic communication system
for concurrent task execution and data reconstruction for a
multi-user scenario, which we formulate as the maximization
of mutual information. To investigate the trade-off between
the two objectives, we formulate a joint objective as a convex
combination of task execution and data reconstruction. We show
that under specific assumptions, the Structural Similarity Index
Measure (SSIM) loss can be obtained from the mutual infor-
mation maximization objective for data reconstruction, which
takes human visual perception into account. Furthermore, for
constant resource use, we show that by increasing the weight
of the reconstruction objective up to a certain point, the task
execution performance can be kept nearly constant, while the
data reconstruction can be significantly improved.
Index Terms—Semantic communication, muti-user, infomax,
deep learning, task execution and data reconstruction.
I. INTRODUCTION
W
ITH the recent advances of deep learning methods,
semantic communication is expected to play a key
role in the development of future communication systems of
6G and beyond [1]–[3]. Unlike Shannon’s goal of accurately
transmitting every bit of message, semantic communication
has the goal of accurately conveying the intended meaning
behind a message [4].
Most works on semantic communication can be grouped
into one of the two objectives: (i) Task execution, where a
single or multiple agents observe some data, with the goal
to execute a task at a remote location, meaning that all
observation data is not required to be transmitted [1], [5], [6].
(ii) Data reconstruction, where the goal is to fully reconstruct
all data, e.g., text, speech, or image data, according to a
semantic accuracy measure [1], [7].
However, in many scenarios, it might be advantageous if
both task execution and data reconstruction are possible. One
such example is shown in Fig. 1 with error detection in a
production line. If an error is missed and only identified at the
end of the production line, data reconstruction is required so
that a human expert can review the sensor data to localize the
fault. Furthermore, if the task changes or new data processing

Such scenarios were only recently investigated in [8] and
[9], where it was shown that if the communication system is
only optimized for task execution, reconstruction is only pos-
sible in a limited way, and vice versa. In [8] a semantic Joint
Source and Channel Coding (JSCC) communication system
optimized for image classification and image reconstruction at
the same time was proposed. The communication system is
designed by formulating optimization problems for both the
classification task and the image reconstruction, balanced by
a weighting factor. The former is formulated as a coding rate
reduction maximization problem, and the latter is formulated
as a Mean Square Error (MSE) or Structural Similarity Index
Measure (SSIM) minimization problem, where SSIM is an
image similarity measure aligned with human visual percep-
tion [10]. In [9] a semantic JSCC communication system for
image segmentation and image reconstruction at the same
time was proposed. The communication system is designed
by formulating a cross-entropy minimization problem for the
segmentation task and an MSE minimization problem for the
image reconstruction.
In contrast to [8], [9], we formulate a joint optimization
problem of maximizing the mutual information both for task
execution and data reconstruction to design our semantic
JSCC communication system. This way, we have a unified
optimization problem for both objectives, which is motivated
by information theory. As directly maximizing the mutual
information is intractable, a lower bound of the mutual infor-
mation is usually optimized instead [6]. However, for the data

Based on the above discussions, the main contributions are
summarized as follows:
• We propose a multi-user semantic communication system
for task execution and data reconstruction at the same time,
which we design by formulating an optimization problem
of maximizing mutual information.
• We show how the SSIM loss can be obtained from the
optimization problem of maximizing mutual information.
• Finally, we investigate the trade-off for the two objectives
of task execution and data reconstruction. Our simulation
results show that by increasing the weight for the data recon-
struction objective, and therefore lowering the weight for the
task execution, the data reconstruction can be significantly
improved without limiting the task execution performance
significantly. However, if the weight for the data reconstruc-
tion is too large, the task execution performance is limited.

III. SOLVING THE OPTIMIZATION PROBLEM
For our goal of solving (9), we iteratively update the
NN parameters {θ1, . . . , θN, ϕ, ψ} using stochastic gradient
descent based optimization with the reparametrization trick
[6], [11]. The gradients of the cross-entropy terms of the
optimization objective are obtained from the training data
samples using Monte-Carlo approximation.
To optimize the cross-entropy of the reconstruction decoder
qϕ(s|y) for image data, we have the problem of high dimen-
sionality. Even for small color images of size 32×32×3 with
8 bit resolution, e.g., as in the CIFAR-10 dataset [14], this
means that there are 28·32·32·3 discrete probability events of
qϕ(s|y), which are infeasible to estimate. Therefore, qϕ(s|y)
needs to be simplified. A simple way to reduce the complexity
is to approximate the discrete qϕ(s|y) by a parameterized
continuous distribution with a tractable number of parameters.

continuous distributions. We show how the MSE and SSIM

IV. SIMULATION RESULTS
We evaluate the proposed semantic communication system
for data reconstruction and task execution for an example
setting of image reconstruction and image classification using
the CIFAR-10 dataset consisting of color images of size
32 × 32 × 3 [14]. We consider a multi-user scenario with
N = 4 users, where each user has access to a non-overlapping
square quarter of the image, corresponding to an image of size
16 × 16 × 3. Each user independently encodes the data and
transmits over independent channels to a central receiver for
classification and image reconstruction.
We use the ResNet14 architecture [15] for the encoders
and the reconstruction decoder. Each encoder consists of one
convolution layer, six residual blocks and one fully connected
layer at the end with power normalization at the output. The
reconstruction decoder starts with two fully connected layers,
which are followed by a sequence of residual blocks: one
standard residual block, two transposed residual blocks for
upsampling, and another standard residual block. Finally, a
transposed convolution layer reconstructs the output image.
The classification decoder consists of three fully connected
layers1.
We train the NN parameters of the proposed semantic
communication system in an end-to-end manner according to
(19) for α ∈[0, 1] and β ∈[0, 1]. For the cases of α = 0 and
α = 1, the respective objective of data reconstruction and task
execution in (19) vanishes, meaning that the respective decoder
is not trained at all. To mitigate this problem, we first train
the whole system for 300 epochs. Then the encoder weights
are frozen and the two decoders are trained for another 300
epochs, which are independent of α, as discussed before for
(8). We use a batch size of 32 and a learning rate of 10−4.

balanced trade-off between PSNR and SSIM and classification

SSIM = 0.6. In comparison, for β = 0 and α = 0.9, the
classification accuracy remains 0.7 and PSNR = 18 dB, while
the SSIM decreases significantly to SSIM = 0.42.
V. CONCLUSION
We investigated a semantic communication system designed
for joint task execution and data reconstruction. As both
objectives cannot be optimally fulfilled at the same time,
a trade-off has to be made. We modeled this trade-off by
formulating a joint objective as a convex combination of both
objectives of task execution and data reconstruction.
Our findings show that data reconstruction quality can be
significantly improved without limiting task execution signif-
icantly for moderate weighting of data reconstruction with
α ≤0.9. This can be achieved by learning to transmit features
that preserve fine visual detail for data reconstruction while
still being as discriminative as possible for task execution.
Finally, it was shown under which assumptions we get the
SSIM loss from the mutual information maximization prob-
lem.
