Abstract
This paper presents massively parallel computation (MPC) algorithms in the strongly sub-
linear memory regime (aka, scalable MPC) for orienting and coloring graphs as a function of
its subgraph density. Our algorithms run in poly(log log n) rounds and compute an orientation
of the edges with maximum outdegree O(α log log n) as well as a coloring of the vertices with
O(α log log n) colors. Here, α denotes the density of the densest subgraph. Our algorithm’s
round complexity is notable because it breaks the eΘ(√log n) barrier, which applied to the pre-
viously best known density-dependent orientation algorithm [Ghaffari, Lattanzi, and Mitrovic
ICML’19] and is common to many other scalable MPC algorithms.

Introduction
We present the first poly(log log n)-round Scalable Massively Parallel Computation (MPC) algo-
rithms for low out-degree orientation and coloring as a function of subgraph density (or equivalently,
arboricity). We first review the context and state of the art, and then state our results.
1.1
Models and Basic Definitions
Massively Parallel Computation Model.
We work with the massively parallel computation
(MPC) model [KSV10a,GSZ11,BKS17,ANOY14], which has become de facto the standard theoret-
ical abstraction for large-scale distributed data processing frameworks such as MapReduce [DG08],
Hadoop [Whi12], Spark [ZCF+10] and Dryad [IBY+07]. We provide a brief definition next; please
see the recent book of Im et. al. [IKL+23] or the lecture notes of Ghaffari [Gha] for more.
The distributed system is composed of M machines, and the data is distributed among them
(arbitrarily). In the case of graph problems, this data is the input graph G = (V, E), for which
we also usually use the notations m = |E| and n = |V |. Each machine is assumed to have a local
memory capacity of S words. A word is simply O(log n) bits and can describe, for instance, a single
vertex or edge. We usually refer to the total summation of memories, which is simply MS, as the
global memory of the system. Trivially, we need that MS = Ω(m + n). Computation proceeds in
synchronous rounds. Per round, each machine can perform some computation on the data it holds
and then send some information to other machines. The only communication constraint is that the
total amount of data that one machine sends or receives, in a round, cannot exceed its memory
capacity S. The primary measure of interest is the round complexity of the algorithm.
The setting where S can be polynomially smaller than n — concretely S ≤nδ for a constant
δ ∈(0, 1) — has been called the strongly sublinear memory regime, and this indicates the most
challenging (and also the most desirable) domain for algorithm design. Algorithms in this regime
are frequently referred to as Scalable MPC algorithms, and this is the focus of the present paper.
LOCAL Model.
Many state-of-the-art (scalable) MPC algorithms for graph problems are de-
signed based on approaches in the more classic LOCAL model of distributed computing [Lin87,
Pel00]. So we briefly recall this model: the graph G = (V, E) represents an abstraction of the
computer network, with one computer per node, and it has an O(log n)-bit identifier. Per round,
each computer/node can send one message to each of its neighbors in G. At the start, each node
knows only its neighbors. At the end of the computation, each node should know its own part of
the output, e.g., its color in a coloring. Again the primary measure is the round complexity.
Densest Subgraph Density, and Abroricity.
The maximum subgraph density (often, simply
subgraph density) of a graph G is defined as α(G) = maxS⊆V {|E(S)|
|S| }, where E(S) denotes the set
of edges with both endpoints in S. A closely related measure is the graph’s arboricity λ(G), defined
as λ(G) = maxS⊆V {⌈|E(S)|
|S|−1 ⌉}, which is also equivalent to the the minimum number of forests into
which the edges E can be partitioned [NW61,NW64,Tut61]. Note that α(G) ≤λ(G) ≤α(G) + 1.
Low Out-degree Orientation.
We are interested in edge orientations with small maximum
outdegree. In any orientation, the maximum outdegree is lower bounded by the subgraph density
α(G). We want our outdegree bound to be close to this. Since α(G) and λ(G) are equal up to a
+1, our results can be stated in terms of either of these, and we use arboricity λ = λ(G) from now
on (also since the special case of λ = 1 nicely coincides with forests).

1.2
State of the Art in Scalable MPC and Distributed Algorithms
LOCAL Algorithms.
A simple LOCAL-model algorithm of Barenboim and Elkin [BE08] gives
an orientation of edges with outdegree at most (2+ε)λ, for any constant ε > 0, in O(log n) rounds:
per round, simultaneously remove all nodes of degree at most (2 + ε)λ in the remaining graph and
mark their edges as outgoing (if both endpoints of an edge are removed, orient the edge arbitrarily,
e.g., toward the higher identifier). This O(log n) round complexity is optimal: even when λ = 1,
computing any orientation with O(1) outdegree requires Ω(log n) rounds, as implied by a lower
bound of Linial [Lin87]. There are also algorithms [GS17,SV20] that computes ((1+ε)λ)-outdegree
orientation in poly(log n) rounds. One can easily run these LOCAL algorithms, and especially the
simple O(log n) round one, in scalable MPC. However, given the power of the MPC model and the
costly nature of each round in the large-scale computation world modeled by MPC, it is imperative
to obtain algorithms with a significantly lower round complexity.
Scalable MPC Algorithms.
Ghaffari, Lattanzi, and Mitrovic [GLM19, Section 4] presented a
scalable MPC algorithm that computes an oritentation with outdegree at most (2+ε)λ in eO(√log n)
1 rounds.2 This is based on a fast simulation of the above LOCAL algorithm, using sparsification
ideas in the style of the work of Ghaffari and Uitto [GU19]. We will later give more explanations
about this approach and its eΘ(√log n) bottleneck. To the best of our knowledge, this eO(√log n)
bound is state-of-the-art round complexity for scalable MPC orientation, in fact even if we allow
much higher maximum outdegree bounds, e.g. λ · poly(log n).
There is one notable exception to the above: in the special case of λ = 1—i.e., when G is simply
a forest—a recent scalable MPC algorithm of Grunau et al. [GLM+23] computes an orientation
with outdegree at most 2 in O(log log n) rounds. They used this (and extra properties of their
orientation) to present a 3-coloring for forests in O(log log n) rounds. This improved on a prior
4-coloring of Ghaffari et al. [GGJ20]. However, these algorithms appear to be inherently limited to
the case of forests and critically use that the local neighborhood around each node has no cycle. It
is unclear how one can apply these approaches even for the case of λ = 2.
Broader Context—LOCAL vs Scalable MPC, graph exponentiation, and sparisifcation.
There is a close connection between LOCAL algorithms and Scalable MPC algorithms. LOCAL
algorithms provide a natural starting point for devising scalable MPC algorithms, and often we
can hope to have much faster MPC algorithms, even exponentially faster. Let us elaborate. If
we temporarily ignore the local memory constraint, a T-round LOCAL algorithm would imply an
O(log T) round MPC algorithm, by what has been known as graph exponentiation [LW08]: we have
I = O(log T) iterations. In iteration i, we make each node learn all nodes within its distance 2i
(and their edges) by simply having each node send its (2i−1)-hop neighborhood, which it knows
from the previous iteration, to all of the nodes in its (2i−1)-hop neighborhood. In the end, once
(the machine holding) each node knows its T-hop neighborhood, it can simply simulate the LOCAL
algorithm on its own. We comment that subject to some technicalities3, this exponential speed-up
is the best that we can hope for [GKU19]. However, the catch is that this exponential speed-up is
doable only if the local neighborhoods are small enough to fit within the memory of one machine.

That is not always the case, e.g., for the T = Θ(log n)-round LOCAL orientation algorithm, the

Ghaffari and Uitto [GU19] introduced a sparsification technique for distributed algorithms, with
the aim of combatting this issue (in the context of maximal independent set and matching algo-
rithms). In simple terms, their sparsification reduces the size of the neighborhood relevant for
simulating (a part of) the LOCAL algorithm. Ghaffari et. al. [GLM19] adapted this technique to
low-outdegree orientation, showing that one can “simulate” each phase consisting of T ′ = Θ(√log n)
rounds of the T = O(log n)-round LOCAL model algorithm, by a Θ(T ′) round LOCAL algorithm
running on a randomly chosen subgraph that has maximum degree 2Θ(T ′) = 2Θ(√log n). Hence,
choosing constants right, the relevant Θ(T ′)-hop neighborhoods have size 2Θ((T ′)2) ≤nδ and thus
fit into local memory, opening the road for graph exponentian which takes only O(log(T ′)) MPC
rounds. Performing this repeatedly to run all the T/T ′ phases then makes the MPC round com-
plexity T/T ′ · log(T ′) = eO(√log n). This eO(√log n) bound is the state of the art complexity for
orientation in general graphs (even for much higher outdegree bounds, e.g., λ poly(log n)). Breaking
this round complexity is the primary objective of the present paper.
We also comment that this complexity is also the best known for scalable MPC algorithms of
maximal independent set and matching in general graphs [GU19], and improving that—e.g., to
poly(log log n)—is one of the central open problems in the MPC literature.
1.3
Our Results
We present a scalable MPC algorithm that computes an orientation with outdegree O(λ log log n)
in poly(log log n) rounds, as we formally state below.
Theorem 1.1. There is a randomized scalable MPC algorithm that given any undirected graph
G = (V, E) with n = |V | and m = |E|, runs in poly(log log n) rounds and computes an orientation
of the edges such that each node has outdegree at most O(λ log log n), with high probability. Here,
λ denotes the arboricity of the graph. The algorithm uses nδ memory per machine, where δ ∈(0, 1)
is an arbitrary positive constant, and eO(m + n) words of global memory. If λ is upper bounded by
(log n)O(log log n), the algorithm is deterministic.
The deterministic portion of the above algorithm, which is applicable when λ ≤(log n)O(log log n),
actually provides more structure, which will be used for our coloring results: it partitions the set
of vertices V into L = Θ(log n) layers H1, H2, . . . , HΘ(log n), such that each node v ∈Hi has at
most O(λ log log n) neighbors in Hi ∪· · ·∪HL. The orientation is implied simply by orienting edges
toward the higher layer (breaking ties arbitrarily, e.g., according to identifiers). Furthermore, the
layer sizes decay exponentially and we have |Hi| ≤n · exp(−Θ(i)). This is what is often called H-
partition [BE08,GLM+23]. Using these properties, as a concrete application, we obtain a similarly
fast scalable MPC algorithm for coloring graphs using O(λ log log n) colors for general λ:
Theorem 1.2. There is a randomized scalable MPC algorithm that given any undirected graph
G = (V, E) with n = |V | and m = |E|, runs in poly(log log n) rounds and computes a coloring of
the vertices with O(λ log log n) colors, with high probability. Here, λ denotes the arboricity of the
graph. The algorithm uses nδ memory per machine, where δ > 0 is an arbitrary positive constant,
and eO(m + n) words of global memory.
Discussion.
The two results above are notable primarily in breaking the eΘ(√log n) complexity
barrier discussed before. However, we note that our results come with the disadvantage of increas-
ing the outdegree bound slightly, from O(λ) to O(λ log log n). For certain settings, this can be

1.4
Technical Overview
Orientation
For a randomized orientation algorithm, it suffices to devise an algorithm for graphs
with arboricity λ ≤O(log n), if we are willing to lose a (1 + ε) factor in the outdegree for any
fixed constant ε > 0 which is certainly the case for us.
To get such a reduction from higher
arboricity graphs to these lower arboricity graphs, we randomly partition the edges of the graph
into λ/Θ(log n) parts. See Lemma 2.1 for details. So, from now on in this overview, let us focus
on graphs with λ = O(log n).
The base idea for our orientation is to “approximately simulate” the natural Θ(log n)-round
LOCAL process [BE08], but in merely poly(log log n) MPC rounds. Recall that the LOCAL al-
gorithm simply consists of L = Θ(log n) iterations, where per iteration i we remove all nodes of
degree d = O(λ) in the remaining graph and we place them in a layer Hi. This gives a partition
V = H1 ⊔H2 . . . ⊔HL, which will be our reference in the rest of this overview. An orientation with
outdegree at most d is implied by directing toward higher layers (ties broken with IDs).
As discussed before, the naive hope would be to speed up this Θ(log n)-round LOCAL algo-
rithm to Θ(log log n) rounds in MPC, by applying the graph exponentiation described above for
Θ(log log n) iterations and thus learning Θ(log n)-hop neighborhoods. However, this is not always
possible, since the neighborhood sizes can be large and would not fit in local memory.
On a high level, and ignoring some important aspects, our algorithm performs a variant of graph
exponentiation using certain pruned views of the local neighborhoods. This allows us to control the
growth of the neighborhood views for nearly all nodes of interest. However, for this to work out,
per exponentiation iteration, we prune some O(λ) edges from each node and allow their orientation
to be arbitrary. This results in our O(λ log log n) outdegree overall. Let us look closer into this.
We attempt to partially “simulate” the first L′ = O(δ log n/ log log n) rounds of the LOCAL
algorithm. In the partition V = H1 ⊔H2 . . . ⊔HL fixed above (which is of course not known to our
algorithms, but we use for algorithm intuition and analysis), let us drop all edges inside each layer,
i.e., edges (u, v) for u, v ∈Hi for some i ∈[1, L]. This is only O(λ) edges per node. Then, each
remaining directed path goes through layers monotonically. For each node v, the total number of
directed paths of length at most L′ starting from v is at most dL′ ≤nδ/3. Hence, with the exception
of at most n/nδ/3 nodes, each remaining node u has at most n2δ/3 directed paths of length at most
L′ ending in u. For such a node u, it seems that its incoming neighborhood up to distance L′ would
fit within the local memory of one machine, and thus one would hope that we should be able to
“perform” the part of the LOCAL model relevant to this node u. Of course, the catch is that this
is talking about neighborhood reachable only along incoming edges in a fixed orientation, which is
unknown to the algorithm. Without this distinction, when paths are allowed to intermix outgoing
and incoming edges, the number of paths reachable from one node can be very large.
Ideally, we would have liked to ignore learning neighborhoods and exponentiation along O(λ)
outgoing edges and let those edges be oriented arbitrarily. But we do not know which edges are
outgoing. We try to do something with a similar effect: intuitively, in the hypothetical scenario
that neighborhood size of v could be viewed as the summation of the neighborhoods along edges
to different neighbors (e.g., if the local neighborhood in consideration was simply a tree 4), we

distinct path that reaches it.
This gives a tree-like view of the paths connecting to the node.
There is now much care needed in how these tree views (and guarantees about them) relate to the
actual neighborhoods in the graph. We do attempt to summarize those aspects here, due to their
technical nature. We show that during each exponentiation, we can perform a pruning on these
tree-like local views, by iteratively moving from the leaves to the root and each time cutting away
the O(λ) heaviest subtrees for each node. This ensures that the non-pruned views fit into local
memory in MPC and allow us to perform the exponentiation. Given the O(log log n) iterations of
exponentiation, this translates to an O(λ log log n) outdegree. However, we need additional prop-
erties and arguments to show that, if we simulate the LOCAL algorithm based on these pruned
tree-like views, we can translate the guarantees to the original graph.
Coloring.
For coloring, suppose that we have already computed the L = Θ(log n)-layer partition
V = H1 ⊔H2 . . . ⊔HL with outdegree at most d = O(λ log log n), as discussed above. Also, let us
again focus on graphs with λ = O(log n), to which we can reduce the general case (this time by
random vertex partitioning, cf. Lemma 2.2).
From the viewpoint of the LOCAL model, we could color this graph in Θ(log n) phases,where
in each phase we do a degree + 1 list coloring on the graph induced by Hi. Each phase would take
eO(log5/3 log n) LOCAL rounds, thanks to the state of the art [HKNT22, GG24b]. So the overall
algorithm would take O(log n) · eO(log5/3 log n) rounds.
We simulate the above much faster in MPC: Suppose edges inside each layer are duplicated as
bidirectional edges, and edges across layers are directed toward the higher layer endpoint. Then,
one can see that in the above algorithm, the color of each node v ∈Hi is impacted only by nodes
reachable from v along directed paths of distance at most (L −i + 1) · eΘ(log5/3 log n). This allows
us to do exponentiation along outgoing edges, which will be small enough to fit local memory.
For instance, in one shot, we can make nodes in all the last Θ(log n/eΘ(log8/3 log n)) layers learn
all other nodes reachable from them, in only O(log log n) MPC rounds. For this, we perform a
directed graph exponentiation along outgoing edges. Then that can be used to locally simulate the
coloring of these eΘ(log n/(log8/3 log n)) layers. Repeating this for poly(log log n) iterations gives
the complete coloring.

Density-dependent coloring.
The ∆-dependent coloring mentioned above can be too relaxed
for many graphs of interest. The arboricity (or density) measure studied in this paper provides
a sharper bound for coloring in a wide range of graphs. As a simple example, in a star graph,
∆= Θ(n) and λ = 1, and we would of course want the number of colors to be closer to the latter.
If we are in the memory regime of MPC that each machine has memory eΩ(n), one can compute
a (2 + ε)λ orientation and (1 + ε)λ in O(1) rounds via simple random partitioning and gathering
the entire relevant subgraph in one machine. The problem in the scalable MPC is vastly different,
however. In the LOCAL model, the best known algorithms for coloring as a function of arboricity
are by Ghaffari and Lymouri [GL17] and compute a coloring with O(λ) colors in eO(log n) rounds.

Preliminaries
The following two Lemmas are folklore. They allow to reduce the effective arboricity to O(log n),
using simple random partitioning of the edges/vertices.
Lemma 2.1 (Edge Partitioning). Let G be a graph with at most n vertices and let k ∈N satisfying
k ≥λ(G). Let L := ⌈k/ log(n)⌉and G1, G2, . . . , GL be the L graphs that one obtains by partitioning
the edges into L parts uniformly at random. Then, with high probability maxi∈[L] λ(Gi) = O(log n).
Proof. Consider an orientation of the edges in G with out-degree O(λ(G)). Now, consider some fixed
vertex v. In expectation, the number of out-edges of v in each of the L partitions is O(λ(G))/L =
O(log n), and a Chernoff Bound implies that this bound holds with high probability. Hence, a
union boun implies that each node has O(log n) out-edges in each part with high probability, and
therefore maxi∈[L] λ(Gi) = O(log n) with high probability.

Lemma 2.2 (Vertex Partitioning). Let G be a graph with at most n vertices and let k ∈N satisfying
k ≥λ(G). Let L := ⌈k/ log(n)⌉and G1, G2, . . . , GL be the L vertex-induced subgraphs that one
obtains by partitioning the vertices into L parts uniformly at random. Then, with high probability
maxi∈[L] λ(Gi) = O(log n).
Proof. Consider an orientation of the edges in G with out-degree O(λ(G)). Now, consider some fixed
vertex v. In expectation, the number of out-neighbors that are in the same part as v is O(λ(G))/L =
O(log n), and a Chernoff Bound implies that this bound holds with high probability. Hence, a union

maxi∈[L] λ(Gi) = O(log n) with high probability.

Lemma 4.1 (Directed exponentiation). For any constant δ > 0, we have the following: Suppose
each node v has an information bundle Bv of bv ≤nδ/2 words, which others might be interested to
learn, and each node u is interested in receiving the information bundles from a list Lu of nodes.
Suppose also that (A) |Lu| ≤nδ/2 and (B) P
u∈V
P
v∈Lu |bv| = O(m + n). Then, there is an MPC
algorithm with nδ local memory and O(m+n) global memory that performs this task in O(1) rounds.
Proof sketch. First, we make each node v learn how many nodes u have v ∈Lu. For that, we apply
a constant-round sorting algorithm: v initiates two items (v.ID, −∞) and (v.ID, +∞) and each
node u that has v ∈Lu initiates an item (v.ID, u). Then, we sort all these items lexicographically,
using any standard constant round sorting algorithm [KSV10b, IKL+23, Gha]. The difference in
the ranks of the two items (v.ID, −∞) and (v.ID, +∞), which will be known to the machine that
holds v, tells v how many nodes u have v ∈Lu. Let this number be kv.
Second, for each v, we generate kv copies of the information bundle Bv, identified with numbers
1 to kv. We do this simultaneously for all v, in constant rounds, using a standard broadcast tree
for each of them that increases the number of copies of Bv from 1 to kv, per iteration by an nδ/2
factor. See e.g., [Gha, Section 1.3.2].
Third, we sort two things: (1) an item list (u, v) for each node u and each node v ∈Lu, indicating
that u wants to receive a copy of Bv. (2) an item list (v, i) for the ith copy of Bv generated above.
Then, we simply perform a matching where node u that has rank j in the first list contacts the
machine that holds rank j in the second list and receives the appropriate copy of Bv from it.
