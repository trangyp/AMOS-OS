Abstract
We present an algorithm that, given an index t, produces the t-th (lexicographically ordered) answer
of an MSO query over a string. The algorithm requires linear-time preprocessing, and builds a data
structure that answers each of these calls in logarithmic time. We then show how to extend this
algorithm for a string that is compressed by a straight-line program (SLP), also with linear-time
preprocessing in the (compressed encoding of the) string, and maintaining direct access in logtime
of the original string. Lastly, we extend the algorithm by allowing complex edits on the SLP after
the direct-access data structure has been processsed, which are translated into the data structure
in logtime. We do this by adapting a document editing framework introduced by Schmid and
Schweikardt (PODS 2022). This work improves on a recent result of dynamic direct access of MSO
queries over strings (Bourhis et. al., ICDT 2025) by a log-factor on the access procedure, and by
extending the results to SLPs.

Introduction
Evaluating queries built from monadic-second order logic (MSO) formulas is a well-studied
task in database theory and algorithmics for formal languages. A reason for this is that it
serves as a pivot to other formalisms. In particular, owing to the Büchi-Elgot-Trakhtenbrot
theorem [9], it is known that MSO over words is equivalent to finite state automata and
regular expressions. This equivalence also extends to trees, as MSO queries over trees are
equivalent to tree regular languages and visibly pushdown automata. The reach of the
task extends further, since the regex formulation means MSO evaluation has use in string
processing; the tree formulation means it has use in XML processing; and very relevantly,
MSO can be used to handle evaluation for regular spanners [14, 7, 23].
The base evaluation task is: given a MSO formula φ, a data string w, does w |= φ
hold? (understanding w as an ordered monadic structure in the typical sense). A natural
extension of this task is to instead query via a formula with open variables φ(x1, . . . , xk),
and to compute the assignments µ such that w |= φ(µ(x1), . . . , µ(xk)).
Naturally, by this extension, the set of answers can become much larger than the input
instance. To overcome this, a great deal of works have studied different ways of extracting
the answers without producing them all at once. In MSO evaluation, we find works that
explore the task of enumerating these answers one by one [3, 12, 1]; we also find ranked
enumeration, where the answers have to be produced in order [7]; and direct access, where
the set of answers is accessed on an arbitrary index [4, 17].
We identify two different tasks that share a name in the literature. First is random access:
for the set of answers S, the goal is to construct an index between 1 and |S| such that each
produces a different answer from the set. Second is ranked access: the task is the same

but there is an order on the answers, and the index follows this order. The naming in the
literature shows discrepancies and both tasks have also been named direct access [11, 8, 10, 5].
We highlight the fact that, as noted in [11], direct random access can simulate uniform
sampling and enumeration; whereas direct ranked access encompasses quantile queries (e.g.,
the median of the answers), ranked enumeration and top-k answering.
On top of the evaluation task, some works venture into the realm of incremental evaluation.
In other words, we allow changes in the data after it has been processed for the query. For
MSO queries, this has been abundantly explored in enumeration [2, 19, 21, 30, 24]. However,
as far as we know, only one work [6] has studied direct access for MSO on an editable string.
The present work studies an algorithm for efficient direct ranked access on MSO queries.
Further, we also consider a more complex setting: the string may have been compressed
as a grammar with a singleton language [28]. Encodings of this form are typically called
straight-line programs (SLP) [18]; they enjoy good compression bounds and have enticing
algorithmic properties [5, 25, 26, 27, 20]. Evaluation for MSO queries on SLP-compressed
strings (and trees) has been already considered for enumeration [29, 21, 30, 24], yet we believe
ours is the first work that approaches it from the angle of direct access.
Background
This work is an improvement of a result in [6]: an algorithm for dynamic direct
access for MSO queries on strings. Their result achieves logsquare-access with log-updates
on the size of the input string. In this work, we reduce the logsquare-access to a single log
factor, maintaining the log-updates. Further, we include an extension to SLP-compressed
strings which ends up appearing naturally due to the construction of the data structure. We
borrow various concepts and insights from this work.

Preliminaries
Let N = {0, 1, . . .}. Given sets A, B we use the notation BA for the set of functions f : A →B.
In particular, for a set A, we write NA×A to denote the matrices of natural numbers indexed
by pairs (a1, a2) ∈A × A. We also use the notation IA for the A × A identity matrix; i.e.,
IA(a1, a2) = 1 if a1 = a2 and IA(a1, a2) = 0 if a1 ̸= a2.
We use [1, n] = {1, . . . , n}. We use the symbol < to denote the standard order over N. If
a set A is totally ordered by some order ≼, we will use the word slice for a subset B ⊆A
that can be described by two elements al, ar ∈A such that B = {a | al ≼a ≼ar}.
We write ω < 3 for an exponent for binary matrix multiplication [31].
Strings and mappings
Given a finite alphabet Σ, a string over Σ (or just a string) is a
sequence w = a1 . . . an ∈Σ∗, where Σ∗denotes the set of finite sequences of elements in
Σ. For such a w, we define its length as n, which we write by |w|. The string of length
zero is denoted by ε, and we write Σ+ for Σ∗\ {ε}. For strings w1 and w2 we denote their
concatenation by w1 · w2. For a string w = a1 . . . an, for any 1 ≤i ≤j ≤n we use the
notation w[i, j] = ai . . . aj, and w[i] = w[i, i] = ai.

Fix an n. Given a finite set of variables X = {x1, . . . , xk}, a mapping of X onto w
is a function µ : X →[1, n]. Alternatively, we will define mappings as sets of the form
{x1 7→s1, . . . , xk 7→sk}, for s1 . . . , sk ∈[1, n]. A partial mapping is any subset of a mapping.
Partial mappings can be also understood as partial functions with domain X, of which the
total ones are simply mappings. Fix an order ≺over X such that x1 ≺· · · ≺xk. We extend
this order onto mappings as follows: Let µ1, µ2 : X →[1, n] be two mappings, then µ1 ≺µ2
iff µ1(x1) = µ2(x1), . . . , µ1(xi−1) = µ2(xi−1) and µ1(xi) ≺µ2(xi) for some i ∈[1, k].
Given an x ∈X and α ⊆[1, n], we call x Z⇒α a mapping rule. We say that a (partial)
mapping µ : X →[1, n] respects a set τ of mapping rules if for every rule x Z⇒α ∈τ it
holds that µ(x) ∈α. When α is a singleton set, we may simplify the notation and instead of
x Z⇒{s}, write it as x 7→s. For a fixed X, a mapping rule is functional if it mentions every
x ∈X. Two sets τ1, τ2 of mapping rules are equivalent if every mapping respects τ1 iff it
respects τ2. Observe that for every set of mapping rules, there is an equivalent functional one.

Straight-line programs.
A context-free grammar is a tuple G = (N, Σ, R, S0), where N
is a non-empty set of non-terminals, Σ is finite alphabet, S0 ∈N is the start symbol and
R ⊆N × (N ∪Σ)+ is the set of rules. As a convention, the rule (A, β) ∈R will be written as
A →β, and we will call Σ and N the set of terminal and non-terminal symbols, respectively. A
context-free grammar S = (N, Σ, R, S0) is a straight-line program (SLP) if R is a total function
from N to (N ∪Σ)+ and the directed graph (N, {(A, B) | (A, β) ∈R and B appears in β})
is acyclic. For every A ∈N, let R(A) be the unique β ∈(N ∪Σ)+ such that (A, β) ∈R, and
for every a ∈Σ let R(a) = a. We extend R to a morphism R∗: (N ∪Σ)∗→Σ∗recursively
such that R∗(u) = u when u is a string over Σ, and R∗(α1 . . . αn) = R∗ R(α1) · . . . · R(αn)

defined for each A ∈N. Then we define the string encoded by S as str(S) = R∗(S0).
We say that a context-free grammar G = (N, Σ, R, S0) is in Chomsky normal form if
rules in R are either of the form A →BC and A →a, for A, B, C ∈N or a ∈Σ.

Machine model
When dealing with an SLP S, it could be that the string w that it
represents has length 2|S|. In particular, it could happen that merely representing an index
in w requires a linear number of bits with respect to |S|.
We handle this by defining a function κ such that κ(T) describes the cost of an arithmetical
operation between numbers of value, and result, at most T. We will deal with numbers that
represent indices in JAK(w), so the largest value we may ever deal with is T ≤|w||X|. We
simply assume that every operation we perform has cost κ(|w||X|), and we omit this factor
from the presented bounds, noting here that it should be regarded as implicit.
Note that, for a string w, κ(|w|) can be assumed to be constant, and this matches the
typical assumptions of operating in constant-cost registers of size log n. However, this implies
that the bounds contain an extra |X| factor, which, in fact, was properly accounted for in [6].
We choose to keep the factor implicit nonetheless.

Direct access for MSO queries on strings
This section will be dedicated to proving the first main result in the paper.
▶Theorem 1. Fix a set of variables X. Let A be an unambiguous vset automata and let
w ∈Σ∗.
1. For a fixed order ≺over X, we can have direct (ranked) access on the set JAK(w) in
O(|Q|ω · |X|2 · log(|w|)) time after O(|Q|ω · |X| · |w|) preprocessing.
2. If ≺is given as input in the access phase, the problem requires O(|Q|ω · 2|X| · |w|)
preprocessing time, and the same direct (ranked) access bounds hold.
Structure of the solution.
First, we will describe a generic procedure to retrieve the t-th
answer of the set JAK(w) that assumes we can compute certain data from A and w. After
this, we define a collection of matrices that describe the logical information that we need
so we can retrieve this data. Then, we will describe a data structure that stores a succinct
version of these matrices. Lastly, we will describe the actual access phase, which uses a
caching strategy to both navigate the search space and compute the relevant data in the
same logtime pass.
Throughout the section, we will focus on proving item (1), which means that the order ≺
is globally fixed over X. We will assume that X = {x1, . . . , xk} and that x1 ≺. . . ≺xk. At
the end of the section, we will describe how to adapt the solution for item (2).
3.1
Template for the access phase
Let t be the queried index, and let µ∗be the t-th mapping in the set JAK(w). The access
phase consists in computing the values µ∗(x1), . . . , µ∗(xk) in order, one by one.
The access phase is described in Algorithm 1. The base idea is to find µ∗(x1) with a
binary search; then find µ∗(x2) with a binary search that assumes the value µ∗(x1) is fixed;
then µ∗(x3) with a binary search that assumes µ∗(x1) and µ∗(x2) are fixed; and so on. The
first binary search looks for µ∗(x1) by characterizing it as a value s1 that satisfies
♯JAK(w)⟨x1 Z⇒[1, s1 −1]⟩< t ≤♯JAK(w)⟨x1 Z⇒[1, s1]⟩.
In the algorithm, we assume that we have access to a function mid : [1, n] × [1, n] →[1, n]
that assigns a certain middle point m := mid(l, r) to every range (l, r); for now, we only
assume that this function is fixed at the beginning of the access phase, and that l ≤m < r.

The binary search in the algorithm iterates a range (l, r) that starts as (1, n) and is
always guaranteed to contain the target value s. As an invariant, we maintain the inequality
♯JAK(w)⟨x1 Z⇒[1, l]⟩< t ≤♯JAK(w)⟨x1 Z⇒[1, r]⟩. Each iteration decides whether to reduce
(l, r) into its first half (l, m) or into its second half (m + 1, r), where m = mid(l, r), by
counting how many answers in JAK(w) map x1 to the range (1, m). When the range reaches
size 1 (i.e., l = r), we have only one choice for s1 so we assign it to µ∗(x1). Then, we subtract
from t the number of answers that map x1 to a value lower than s1 and continue to look for
µ∗(x2). Subtracting this value from t lets us focus on the slice of JAK(w) that assumes that
x1 is mapped to s1. The rest of µ∗is computed the same way.

3.2
The M matrices
As a way to bridge the gap between the relevant slices of JAK(w) and the data structure that
we will present, we introduce a useful collection of matrices in NQ×Q.
First, we add some new features to mapping rules and their sets. We say that a mapping
rule x Z⇒α is inside [l, r] if α ⊆[l, r]. Also, we will compose functional sets τ1, τ2 of mapping
rules and define the operation τ1 · τ2 := {x Z⇒α ∪β | x Z⇒α ∈τ1 and x Z⇒β ∈τ2}. Observe
that if τ1 is a set of mapping rules inside [l, m] and τ2 is a set of mapping rules inside
[m + 1, r], then τ1 · τ2 is a set of mapping rules inside [l, r].
For 1 ≤l ≤r ≤n, and a set τ of mapping rules inside [l, r], we define this matrix in NQ×Q:
M⟨l, r : τ⟩(p, q) := |{ρ | ρ is an (l, r)-partial run of A over w from p to q s.t. µρ respects τ}|
The principle behind these matrices is to group the partial mappings that make up the
mappings in JAK(w) by three criteria: the range inside [1, n] that the partial mapping was
obtained from, the positions in [1, n] where the variables in X can appear, and the states
that delimit their respective partial runs.
In our running example, we highlighted runs ρ1, ρ2, ρ3 which render the first three
mappings in JAexK(w0). Let us look at one M matrix in particular: let τx1=1 := {x1 7→1}, and
let (l, r) = (1, 5). Then we find that M⟨1, 5 : τx1=1⟩(q0, q1) = 1, since there is one (1, 5)-partial
run over w0 from q0 to q1 (it can be obtained from ρ3); also, see that M⟨1, 5 : τ1⟩(q0, q2) = 2
since this counts the (1, 5)-partial runs obtained from ρ1 and ρ2.

Handling updates
In this section, we explain how the results of complex editing operations presented in [6] still

We will proceed in a similar fashion as [24], where the authors presented the editing
framework, and then briefly explained how the machinery in [30] was directly applicable to
their data structure.
As a disclaimer, we note that the results in this section only hold for strongly balanced
SLPs. In general, an SLP cannot be balanced with the strongness guarantee without possibly
incurring in a log n factor blowup in its size [15]. However, we note that the results hold for
strings with no further assumptions: we can represent a word by a strongly balanced SLP by
using the function defined in Section 3.

Edits on strings
We framed our results on edits solely for SLPs given that they can be trivially adapted for
words. However, we claim that the editing procedure on the string case can be simpler,
and, in particular, be done in a way that keeps the number of nodes in the data structure
unchanged. The idea would be to use classic results for editing AVL trees, as it is done in [6].
We defer further details to a future full version of this paper.
6
Conclusions and future work
We have presented a dynamic direct (ranked) access algorithm for MSO queries on strings and
SLP-compressed strings. We improve on [6] by shaving a log-factor in the access procedure,
and showing an extension to SLPs. We note that the PhD theses of Bagan [4] and Kazana [17]
both already had a version of direct access on MSO queries (even for trees), so the main
contribution of our work is in adding the dynamic aspect, and the extension to SLPs.
Something of a blind spot of our work with respect to Bourhis et. al.’s [6] is that we do
not say anything about query evaluation for semigroups—we actually did not see how our
result gives further insights here. It would be interesting to have a characterization of which
semigroups support log-time direct access and which do not by some lower bound.
For future work, we think that the main question is whether our techniques presented
here can be extended to dynamic direct access for MSO queries on trees. We believe this
to be possible, for example, via [19]. It would also prove technically challenging since this
framework does not preserve contiguity, which is crucial in our solution.
Also, there is a clear shortcoming in the fact that the SLP needs to be strongly balanced
to admit logtime updates. In particular, this means that it does not work for an arbitrary
SLP. We leave open the question of whether some weaker balancedness criterion for SLPs
could achieve this.
