Abstract
The problem of graph burning was firstly introduced as a model for dif-
ferent processes of social and network interactions. Recently, the authors
of the present paper developed methods of algebraic topology for investi-
gation of this problem. This approach is based on the new definition of
burning process which excludes the possibility to choose at any moment
vertex for burning from the set of vertices which are already burned at
this moment.
In this paper we continue to study such burning process using algebraic
topology methods. We prove the result about relations between burnings
of a graph and burnings of its spanning trees that is similar to the classical
case. Afterwards, we describe properties of trees burnings. In particular,
we prove that a burning of a tree defines a structure of a digraph on
the tree and investigate this structure. We introduce and study a strong
burning configuration space of a graph and new strong burning homology
which are similar to burning homology defined in our previous paper, but
arise from burning homomorphism.
Keywords: homology of graphs, simplicial homology, simplicial complex,
graph burning, digraph, path graph, burning time, tree, spanning tree, burning
homomorphism.

The definition of a burning process in [2, 3] allows that in time t a vertex
which is burned in time t + 1 can be also chosen to burn in time t + 1 (see

In [12] we introduced several filtrations of a graph, closely

the possibility to choose at the moment t + 1 vertex for burning from the set of
vertices which are already burned at this moment.
In this paper we continue to study burning process in the sense [12]. We start
with preliminaries in Section 2. In Section 3 we prove the result about relations
between burnings of a graph and burnings of its spanning trees that is similar
to [3, Theorem 2.4, Corollary 2.5]. The main result in this direction is given by
Theorem 3.2. But there is an essential difference between our proof and the proof
of [3, Theorem 2.4] as we note in Remark 3.3. Therefore, Theorem 3.2 reduces
investigation of graph burnings to burnings of trees.
In Section 4 we define
burning homomorphisms and discuss their existence on trees. In Section 5 we
describe possible end time of trees burnings and properties of burning sequences
in the case of burning homomorphisms. In particular, we obtain sharp lower and
upper bounds of the burning homomorphism’s end time for path graphs Pn, n ∈
N, Theorem 5.4. In Section 6 we prove that a burning of a tree defines a structure
of a digraph on the tree and investigate properties of this structure. We finish
with Section 7, where we introduce and study a strong burning configuration
space of a graph and a strong homology which are similar to burning homology
defined in [12].

Preliminaries
2.1
Basic notions of the graph theory
In this section, we recall basic notions of the graph theory, see e. g. [4, 6, 7, 8].
Definition 2.1. A graph G = (VG, EG) is a non-empty finite set VG of vertices
together with a set EG of non-ordered pairs {v, w} ∈EG of distinct vertices
v, w ∈VG called edges. Two different vertices are adjacent if they are connected
by an edge. A vertex is incident with an edge if the vertex is one of the endpoints
of that edge. All vertices which are incident to vertex v are called neighbors of
v.
Sometimes we will omit the subscript G from the set VG of vertices and from
the set EG of edges if the graph is clear from the context.
Definition 2.2. We say that a graph H is a subgraph of a graph G and we write
H ⊂G if VH ⊂VG and EH ⊂EG. A subgraph H ⊂G is an induced subgraph
if for any edge {v, w} ∈EG, such that v, w ∈VH we have {v, w} ∈EH. In this
case we write H ⊏G. For a subgraph H ⊂G we denote by bH ⊏G the induced
subgraph which has the same set of vertices as H.

Definition 2.4. (i) For n ≥1, a path in a graph G = (V, E) is an alternating

For n = 0, a path is given by a vertex v0 ∈V . The integer n is the length of

(ii) For n ≥3, a circuit in a graph G = (V, E) is an alternating sequence
v0, a1, v1, a2, . . . , vn−1, an, v0 = vn of vertices vi ∈V and edges ai ∈E such that
ai = {vi−1, vi} for i = 1, . . . , n and vi ̸= vj for all distinct i, j = 1, . . . , n. For

Definition 2.5. (i) A graph G = (V, E) is connected if for any two distinct
vertices v, w ∈V there is a path for which v0 = v is the origin and vn = w is
the end of the path.
(ii) A connected graph G is a tree if it is does not contain circuits.
(iii) A path graph Pn, where n is a positive integer, is a graph with the set
of vertices {1, . . . , n} and with the set of edges {i, i + 1} for i = 1, . . . , n −1.
Definition 2.6. Let G = (V, E) be a graph.
(i) A subgraph T of G is its subtree if it is a tree.
(ii) A subtree T = (VT , ET ) of G is its spanning tree if VT = V .
(iii) A tree Q is an ambient tree of G, if G is a subtree of Q.
The following lemma is well known and follows almost immediately from
definitions above.
Lemma 2.7. A graph T = (VT , ET ) is a tree if and only if for any two distinct
vertices v, w ∈VT there exists exactly one path v = v0, a1, v1, a2, . . . , vn = w.
Definition 2.8. For a graph G = (V, E), the distance dG(v, w) between two
vertices v, w ∈V is the number of edges in a shortest path connecting these
vertices. If there is no path connecting vertices v, w ∈V then we set dG(v, w) =
∞.
Definition 2.9. Let G = (VG, EG) be a graph and k ∈N.
(i) For an integer n ≥0, the n-th closed neighborhood of a vertex v ∈VG

Burning of a spanning tree
In this section we describe relations between burnings of a graph and burnings of
its spanning trees for the burnings defined in previous section. The main result of
this section is Theorem 3.2 , which states that any burning of a graph G defines
a burning of its spanning tree, which is in general not uniquely determined.
Recall that a spanning tree of a connected graph G is a subgraph tree which
contains all vertices of G.
The burning process in Definition 2.12 differs from the burning process de-
scribed in [3, Introduction]. In particular, as follows from our definition, the
distance between sources vi and vj satisfies condition d(vi, vj) ≥|i −j| + 1 in
contrast to the situation in [3] where d(vi, vj) ≥|i −j|. The proof of Theorem
3.2 below is similar to that given in [3] but there is an essential difference as we
note in Remark 3.3. At first, we state and prove a technical lemma.
Lemma 3.1. Let G = (V, E) be a connected graph and SG be a burning sequence
(v1, . . . , vn) of a burning (λ, SG) of G. Then for any vertex w ∈V we have
d(vk, w) ≥|λ(vk) −λ(w)|.
(3.1)
Proof. Let p be a path from the vertex vk to the vertex w of length d =
d(vk, w) which is finite, since the graph is connected. By Theorem 2.13, the
function λ is a graph map λ: G →PT where PT is a path graph. The restriction
of λ to the path p gives the path map λP : P →PT of the subgraph P ⊂G
which is generated by p. The graph P is a path graph of the length d and its
image is the path subgraph of PT. Hence the distance between images λ(vk)
and λ(w) of the vertices vk, w ∈VP is less or equal to the distance d(vk, w).
That is d(vk, w) ≥|λ(vk) −λ(w)|.

Remark 3.3. The key difference between Theorem 3.2 above and the theorem,
stated by Bonato and coauthors [3, Th. 2.4] is that in our settings all the trees
Tj are not empty. It is possible due to the fact that we do not allow a source vj
to be the vertex, which anyway would be burned at the step j from some other
source. Let us illustrate the difference with an example. Consider a path graph
P4 with the vertices 1, 2, 3, 4 and edges {i, i + 1}. By Bonato et al. the burning
sequence (1, 2, 3, 4) is allowed, which leads to T2, T3, T4 being empty. On the
contrast, in our setting the only allowed burning sequences up to isomorphism
are (1, 3), (2, 4) and (1, 4), for each of which both trees T1 and T2 are not empty.
We can omit the last step, i.e. the construction of spanning tree of G, at the
end of the proof of Theorem 3.2. Then we obtain the following result.

(v1, . . . , vn) of a burning (λ, SG) of G. Then there are trees Ti ⊂G, i = 1 . . . , n
such that V⊔Ti = V and SG is the burning sequence for a burning of the graph
H = T1 + T2 + · · · + Tn. Moreover, the corresponding burning map λ = λH is a
homomorphism.
Proof.
The fact that SG is the burning sequence of a burning of H =
(VH, EH) is clear. Assume there exists two adjacent vertices v, w ∈λH such that
λ(v) = λ(w). Be definition of H, v, w are in the same Ti and, hence, v, w ∈Mi.
Moreover, d(vi, v) + i = λ(v) = λ(w) = d(vi, w) + i, i.e. d(vi, w) = d(vi, v) and
v ∼w, which is impossible in a tree due to Lemma 2.7.

Digraphs structure on burned trees
Now we investigate a possibility to introduce a natural structure of a digraph
on a spanning tree of a burned graph.
We remind, that directed graph (digraph) G = (VG, DG) consists of a set
of vertices VG, and a set DG of ordered pairs (v, w) ∈DG of distinct vertices
v, w ∈VG called ordered edges.
Definition 6.1. For two digraphs G = (VG, DG) and H = (VH, DH) a digraph
map f : G →H is given by a map f : VG →VH such that (v, w) ∈DG implies
(f(v), f(w)) ∈DH or f(v) = f(w) ∈VH.
A digraph map f is a digraph
homomorphism if (f(v), f(w)) ∈DH for any (v, w) ∈DG.
Let G = (V, E) be a graph. A structure of digraph on G can be given by
equipping with an order each edge {v, w} ∈E.
Coming back to the burning we remind, that for any graph G = (V, E)
any burning map λ = λ(BT(G)) maps the graph onto path graph PT, whose
vertices, if denoted by 1, 2, . . . T correspond to the burning time of preimages.
Hence, in our settings a path graph P = Pn, n ∈N has a natural structure of
digraph defined by (i, i + 1) ∈DP for all i = 1, . . . , n −1.

A set B(G) of all burnings of any graph G and a configuration space ∆G which
is a simplicial complex associated with the set B(G) were defined in [12]. In this
section we define strong configuration burning space and corresponding strong
burning homology groups using a set of all burnings homomorphisms of a graph
and describe its relation to burning homology. We use standard definitions of
simplicial and graph constructions, see [5, 6, 9, 10, 11, 13]. Let us firstly recall
the most important concepts.
Definition 7.1. A simplicial complex ∆= (V, F) consists of a set V of vertices
and a set F of finite non-empty subsets of V which are called simplexes. A
simplex σ ∈F containing q + 1 (q ≥0) elements is called a q-simplex and the
number q is called the dimension of σ and we write (q = dim σ). The set F of
simplexes must satisfy the following two properties:
(i) for every vertex v ∈V the set {v} ∈F is a simplex,
(ii) if σ ∈F is a simplex then any non-empty subset τ ⊂σ is a simplex
which is called a face of σ.
A simplex σ ∈∆is maximal if it is not a face of any another simplex.
A simplicial complex is n-dimensional if it contains at least one n-dimen-
sional simplex but no (n + 1)-dimensional simplexes.
Definition 7.2. A simplicial complex ∆1 = (V1, F1) is a subcomplex of a sim-
plicial complex ∆= (V, F) if V1 ⊂V and F1 ⊂F.
A simplicial complex is called finite, if it has finite number of vertices. In
this paper we consider only finite simplicial complexes.
