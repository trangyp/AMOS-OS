HEXU LIU
Abstract. We generalize [CL24, Theorem 1.1] to stable minimal models. Given
a pair (V, C) that admits a stable minimal model with fixed dimension, fixed
coefficient set, and bounded relative volume, we study when the linear system
|m(KV + C)| induces an Iitaka fibration, assuming the Iitaka volume of KV + C
is sufficiently large.

1. Introduction
Throughout this paper, we work over the complex number field C.
Studying pluri-canonical linear systems is an important mission in birational ge-
ometry. By [HM06,Tak06,Tsu06], for every positive integer n there exists an optimal
constant rn depending only on n such that, for any smooth projective variety V of
general type and any integer m ≥rn, the m-canonical map ϕ|mKV | is birational. A
number of works, for example [Bom73, CC15, Che18], have computed the explicit
value of rn when n is small. A further challenge is to establish effective birationality
for varieties whose volumes are sufficiently large. By [CL24, Theorem 1.1], we know
that for any integer n > 1, there is a number K > 0 such that for any smooth pro-
jective variety V with vol(V ) > K, m-canonical map is birational for any m ≥rn−1.
A crucial ingredient of the proof is [CL24, Theorem 1.5], an extension theorem for
fibrations.
In this paper, we extend the results of [CL24] by establishing an effective Iitaka
fibration result for pseudo-effective pairs that admit a stable minimal model and
have sufficiently large Iitaka volumes. As a key step, we also generalize the extension
theorem [CL24, Theorem 1.5].
Here we recall the definitions of stable minimal models that will be used through-
out the article; we refer to [Bir23,Zhu25]. Our definition is slightly more general.
Definition 1.1. Let d > 0 be an integer, Φ ⊆[0, 1] be a set, u, v > 0 be two
real numbers. A klt (d, Φ, ≤u)-stable minimal model (X, B), A consists of a klt pair
(X, B) and a divisor A on X such that
(1) X is of dimension d, and the coefficients of B belong to Φ;
(2) KX + B is semi-ample and defines a contraction h : X →Z;
(3) A is an integral divisor that is big and semi-ample over Z with 0 ≤vol(A|F) ≤
u for a general fiber F of h : X →Z.
We say that ((X, B), A) is a klt (d, Φ, ≤u, ≤v(resp.=v, ≥v))-stable minimal model if
further
(4) Ivol(KX + B) ≤v (resp. =v, ≥v) holds.
We say that (X, B) admits a klt (d, Φ, ≤u, ≤v(resp.=v, ≥v))-stable minimal model
if there exists a klt (d, Φ, ≤u, ≤v(resp.=v, ≥v))-stable minimal model ((X′, B′), A′)
such that (X′, B′) is a weak lc model of (X, B) (for the definition of weak lc model,
see [Bir12, Definition 2.1]).
Using the methods of [BZ16, Bir21a, Zhu25], one obtains the following result on
effective Iitaka fibration indices for stable minimal models.
Theorem 1.2. Let n > 0 be an integer, Φ ⊆[0, 1] be a DCC set, u > 0 be a
real number. Then there exists an integer m0 > 0 such that the following holds.
Assume that (V, C) admits a klt (n, Φ, ≤u)-stable minimal model (see Section 2.7
for definitions). Then, for any positive integer m that is divisible by m0, the linear
system |⌞m(KV + C)⌟| defines an Iitaka fibration.
For any integer n > 0, DCC set Φ ⊆[0, 1] and real number u > 0, we denote by
r(n, Φ, u) the minimal integer m0 > 0 such that above theorem holds.

Our main result of this paper is to prove the following theorem on stable minimal
models with large Iitaka volumes.
Theorem 1.3. Let n > 1 be an integer and Φ ⊆[0, 1] be a DCC set, u, ϵ > 0 be
real numbers. Then, there exists a real number v > 0 that satisfies the following.
For any (V, C) that admits a klt (n, Φ, ≤u, ≥v)-stable minimal model (see Section
2.7) and (V, C) is ϵ-lc, for any m > 0 such that mC is integral and m is divisible by
r(k, Φ, u) for any 1 ≤k ≤n −1, the linear system |m(KV + C)| induces an Iitaka
fibration.
A key step toward the above main theorem is the following extension theorem for
stable-minimal-model-type and M2(t)-type fibrations. The relevant definitions are
given in Section 3.1.
Theorem 1.4. Let d > 0 be an integer, Φ ⊆[0, 1] be a DCC set, u, v, ϵ > 0 be real
numbers. Then, there exists a real number t > 0 that satisfies the following. Assume
that
(1) f : (V, C) →T admits a klt (d, Φ, ≤u, ≤v)-SMM-type fibration such that
(X, C|X) is ϵ-lc for a general fiber X; (see Definition 2.18)
(2) f : (V, C) →T satisfies contidion M2(t); (see Definition 3.3)
(3) (V, C) has a good minimal model.

where X1, X2 are two different general fibers.

the Zariski decomposition; see Section 2.8 for the definition.
Theorem 1.5. Let d > 0 be an integer, Φ ⊆[0, 1] be a DCC set, ϵ, u, v > 0 be real

We begin with an effective Iitaka fibration result.
Theorem 1.7. Let n > 0 be an integer and u > 0 be a real number. Then, there is
an integer s0 with the following property. For any smooth projective variety V such
that (V, 0) admits a klt (n, {0}, ≤u)-stable minimal model, the linear system |mKV |
induces an Iitaka fibration for any m ≥s0.
For any integer n > 0 and real number u > 0, let s(n, u) denote the minimal
integer s0 > 0 for which the above theorem holds. Note that s(n + 1, u) ≥s(n, u).
For varieties without boundaries and with large Iitaka volumes, we have the fol-
lowing result, which generalizes [CL24, Theorem 1.1].
Theorem 1.8. Let n > 0 be an integer and u > 0 be a real number. Then, there
exists a real number v > 0 that satisfies the following. Assume that
• V is a smooth projective variety;
• (V, 0) admits a klt (n, {0}, ≤u, ≥v)-stable minimal model.
Then, for any integer m > 0 such that either m is divisible by r(k, {0}, u) for any
1 ≤k ≤n −1, or m ≥s(n −1, u), the linear system |mKV | induces an Iitaka
fibration.
Remarks. Theorem 1.3 requires m to be divisible by r(k, Φ, u) for every 1 ≤k ≤
n −1 for the following reason. Although examples show r(k + 1, Φ, u) ≥r(k, Φ, u)
for all k ≥1, we do not know whether r(k + 1, Φ, u) is a multiple of r(k, Φ, u).
Consequently, our statement differs slightly from [CL24, Theorem 1.1].
The proof of Theorem 1.4 also refines the argument of [CL24, Theorem 1.5].
Instead of using the Hacon–McKernan extension theorem [HM06, Corollary 3.17] to
compare the fixed parts of the linear system before and after restriction, we control
the Negative part of Zariski decomposition directly via Theorem 1.5. Moreover,
the pair (V, C) is no longer of log general type, so Kawamata–Viehweg vanishing is
unavailable; we replace it by Koll´ar’s injectivity theorem, which in turn forces us to
assume the existence of good minimal models.
Theorem 1.5 analyses the restriction of the Zariski negative part. The main tools
are minimal-model-program techniques, boundedness of the base of a stable minimal
model, and a uniform lower bound on log-canonical thresholds; the approach is
inspired by [BH22,Bir19,Bir21b,Bir21a,Zhu25].

2.4. Pairs and Singularities.
Definition 2.6. A sub-pair (X, ∆) consists of a normal quasi-projective variety X
and a R-divisor ∆, such that KX + ∆is R-Cartier. If additionally ∆≥0, we say
that (X, ∆) is a pair. If additionally ∆is a Q-divisor, we say that (X, ∆) is a Q-pair.
If a pair (X, ∆) satisfies that X is a smooth variety and that components of ∆
has simple normal crossing support, then we say that (X, ∆) is log smooth.
Definition 2.7. Let (X, ∆) be a sub-pair. Let D be a prime divisor over X (i.e. D
is a prime divisor on a birational model of X). Let f : Y →X be a log resolution
of (X, ∆) such that D is a divisor on Y and write uniquely
KY + Γ = f ∗(KX + ∆).
We define the log discrepancy of the prime divisor D with respect to the sub-pair
(X, ∆) to be
a(D, X, ∆) := 1 −µD(Γ).
Fix a number ϵ > 0. We say (X, ∆) is sub-lc (resp. sub-klt, sub-ϵ-lc) if a(D, X, ∆) ≥0
(resp. > 0, ≥ϵ) for any prime divisor D over X. If, in addition, (X, ∆) is a pair,
we say (X, ∆) is lc (resp. klt, ϵ-lc). We say (X, ∆) is terminal if a(D, X, ∆) > 1 for
any prime divisor D that is exceptional over X.
Let (X, ∆) be a sub-klt sub-pair, D be an effective R-Cartier R-divisor on X and
x ∈X be a point (not necessarily closed). We define
lctx(X, ∆; D) := sup{a ∈R | (X, ∆+ aD) is lc near x},
and define
lct(X, ∆; D) := sup{a ∈R | (X, ∆+ aD) is lc everywhere}.
Let (X, ∆) be a sub-pair and take a log resolution f : Y →X. A non-klt place is a
prime divisor D over X with a(D, X, ∆) ≤0 and a non-klt center is the image of a
non-klt place on X. The non-klt locus of (X, ∆) is the union of all non-klt centers
of (X, ∆) which is denoted as Nklt(X, ∆). An irreducible component of Nklt(X, ∆)
is called a maximal non-klt center. An lc place is a prime divisor D over X with
a(D, X, ∆) = 0 and an lc center is the image of an lc place on X. We say that an lc
center G of (X, ∆) is a pure lc center if (X, ∆) is lc at the generic point of G. We
say that an lc center G is an exceptional lc center if there is a unique lc place over
X whose image is G, and this unique lc place is called the exceptional lc place.

X 99K X′. We say that the two sub-pairs are crepant if the pull-backs of KX + ∆

(3) DX′ is nef.
