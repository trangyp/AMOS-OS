Abstract
Time Series Event Detection (TSED) aims to
localize semantically meaningful events in time
series data, with critical applications in high-
stakes domains. Unlike statistical anomalies,
events are often defined by natural-language
descriptions with internal temporal-logic struc-
tures across multiple physical channels. How-
ever, in real-world settings, dense event annota-
tions are expensive to obtain, making purely
supervised learning difficult.
We introduce
Language-guided TSED, a setting where a
model is given textual event descriptions and
must ground them to intervals in multivariate
signals with little or no labeled data. To ad-
dress this problem, we propose Event Logic
Tree (ELT), a knowledge representation frame-
work that converts linguistic descriptions into
structured temporal logic over signal primitives.
Building on ELT, we present SELA, a neuro-
symbolic VLM agent framework that iteratively
grounds primitives from signal visualizations
and composes them under ELT constraints, pro-
ducing both event intervals and faithful tree-
structured explanations. We further release a
real-world benchmark across energy and cli-
mate domains with expert knowledge and an-
notations. Experiments show that SELA im-
proves over supervised fine-tuning and existing
zero/few-shot time series reasoning baselines.

Introduction
Time Series Event Detection aims to localize tem-
poral segments in multivariate signals where spe-
cific events occur. It is important in high-stakes
domains such as health (Supratak et al., 2017; Per-
slev et al., 2019) and energy production (Khaouja
et al., 2025).
Unlike time series classification,
which assigns a global label to a sequence (Mo-
hammadi Foumani et al., 2024), event detection
requires fine-grained localization at the segment
level. It is also different from anomaly detection,

which mainly targets statistical deviations (Zaman-
zadeh Darban et al., 2024). Events are semantically
defined processes, often involving cross-channel
temporal relations, such as “a sharp rise on chan-
nel A followed by a dip on channel B”.
Most existing approaches rely on supervised
learning, including CNN or Transformer-based
models (Perslev et al., 2019; Wu et al., 2023) and
fine-tuning time series foundation models (Khaouja
et al., 2025). However, in many industrial and
scientific settings, dense event annotations are ex-
pensive to obtain, while textual event descriptions
are often available from operational manuals or ex-
pert guidelines. This motivates a language-guided
setting: given a multivariate time series and tex-
tual descriptions of target events, the model should
ground the descriptions into event intervals without
large amounts of labeled data (Figure 1).

Problem Formulation
The objective is to detect all event instances in a
multivariate time series that match a set of linguis-
tic event descriptions.
Input.
The input consists of a multivariate time
series X ∈RT×C and a description set L =
{ℓe}e∈E, where T is the number of time steps, C
is the number of channels, E is the event type set,
and ℓe describes the signal pattern of event type e.

Each prediction is yk = (I(k), e(k)), where I(k) =
[t(k)

Objective.
Predictions are evaluated by match-

must identify the correct event type, i.e., e(i) = ˆe(j),
and align with the corresponding ground-truth in-
terval. Temporal alignment can be measured by
interval IoU or boundary deviation. Thus, the task
requires both event identification, determining what
event occurs, and temporal localization, determin-
ing when it occurs.
3
Event Logic Tree
To achieve accurate event detection with faithful
explanations, we need to explicitly model the in-
ternal structure of events. Based on the example
in Section 1, we define three desiderata for such a
logic structure:
D1. Hierarchical Representation.
The repre-
sentation should capture how atomic patterns re-
cursively form sub-patterns and finally the global
event.
D2. Semantic Quantification.
The representa-
tion should quantify how well a signal morphology
matches its linguistic semantics.
D3. Topological Elasticity.
The representation
should define events by their temporal-logic struc-
ture rather than absolute duration, allowing tem-
poral stretching or compression while preserving
logical validity.
To meet these requirements, we introduce Event
Logic Tree (ELT), a tree-structured representa-
tion that separates an event’s schema from its
instantiation. The schema is parsed from the tex-
tual description only and specifies the event logic

span the intervals of their children, and their co-

corresponding operators. Thus, the root node rep-

score reflecting both primitive-level grounding and
global temporal consistency. Formal instantiation
rules are provided in Appendix B.3.
To avoid physically invalid trees, ELT follows
three validity principles: constructive composition,
requiring each composite to add non-trivial struc-
ture; temporal compactness, preventing unbounded
unexplained gaps inside a composite event; and
physical exclusivity, preventing one channel from
supporting incompatible primitive states at the
same time. These principles constrain grounding
while preserving temporal elasticity; their formal
definitions are given in Appendix B.2.
Overall, ELT turns event detection into the con-
struction of an instantiated proof tree: primitives
provide signal-level evidence, operators organize
the evidence into event-level logic, and confidence
propagates from leaves to the root. We compare
ELT with existing time series symbolic representa-
tions in Appendix A.1.

The KITE Dataset Collection
We introduce the KITE (Knowledge-Infused Time
Series Events) benchmark, which is curated from
two real-world domains: energy and climate.
5.1
Data Collection
KITE comprises three sub-datasets:
1. Pressure Test:
Pressure Test is a critical well
exploration operation in the oil & gas industry. The

objective is to acquire underground pressure at dif-

pressure test jobs, sensors are installed at certain
depths in drilling wells for remote measurements.
We collected a dataset of 62 multivariate time se-
ries samples from 41 real underground pressure test

2. Liner Hanger:
The liner hanger installation

We created the Climate Haz-

Further details on event types and channels of

5.2
Data Annotation
In general, the mission of data annotation is to
obtain 1) the event labels (classes and boundaries),
and 2) the event descriptions in natural language.
For Pressure Test and Liner Hanger, the collected
data were annotated in two stages. First, two field
engineers with over 20 years of experience in the
oil & gas industry manually inspected every sample
using Insitu Pro, a professional time series anno-
tation software (Fries et al., 2024), to identify the
classes and boundaries of all events. Their results
were then cross-verified to resolve boundary dis-
agreements. In the second stage, the field engineers
documented textual guidance for event detection,
assisted by an experienced AI engineer.
For the Climate Hazard dataset, we first took
the event boundaries from the NWS Storm Events
database. However, the original timestamps re-
flect zone-level conditions rather than point-station
measurements, which can introduce timing offsets
at the individual station level, causing minor mis-

RQ 1. Benchmarking ELT Parsing
Experimental Setup.
We construct human-
authored ground-truth ELTs for eight events across
the three KITE datasets. We evaluate five models:
GPT-5.45, GPT-4.16, DeepSeek-V4 284B7, Qwen-

each event five times, yielding 200 parse runs in
total. A parse is considered valid if it forms a non-
empty binary tree that passes the backend syntax
check.
Evaluation Dimensions.
We first report the pass
rate (Pass), measuring the probability that a model
produces a valid tree schema that can pass the syn-
tax check of the SELA backend within a fixed
number of turns (20). Each valid parse is then com-
pared against the human-parsed schema along four
dimensions: Structural Fidelity (Struct), measur-
ing whether the tree topology is logically equiva-
lent to the ground truth; Primitive Coverage (Cov),
measuring whether all ground-truth primitives are
included; Primitive Accuracy (Acc), assessing
whether each predicted primitive is grounded in the
original description and penalising fabricated prim-
itives; and Semantic Alignment (Sem), measuring
how well each primitive’s description matches the
corresponding part of the original event description.
Scores are assigned on a 0–5 scale by two indepen-
dent VLM judges, Claude Opus-4.6 and GPT-5.5
Thinking, averaged and normalised to [0, 1], and
further checked through human validation. More
details on LLM judge prompts and judging cases

We introduce language-guided time series event

benchmark for this task.
To address its low-
resource and knowledge-intensive challenges, we
propose the Event Logic Tree and build SELA, a
zero-shot neuro-symbolic agent system that com-
bines ELTs with large vision-language models. Ex-

ELT-guided reasoning improves precise event lo-

human-in-the-loop verification.

Limitations
Although SELA demonstrates promising results on
KITE, two main limitations have to be discussed.
First, our current study mainly focuses on the role
of ELT-guided reasoning, while the effects of com-
munication and collaboration among agents remain
underexplored. Different coordination protocols
may influence evidence sharing, error correction,
and final localization quality. Second, although
KITE covers both energy and climate scenarios,
the experimental scope is still limited. Future work
should extend the evaluation to broader domains
and more diverse event-sequence data to further
validate the generality of the proposed framework.

A.1
Time Series Symbolic Representation
We analyze existing symbolic time series represen-
tation frameworks based on our desiderata (sum-
marized in Table 5).
(1) SAX (Lin et al., 2003; Malinowski et al.,
2013) and ABBA (Elsworth and Güttel, 2020) map
time series into string sequences with character
represents a specific amplitude. Moreover, the re-
peated sub-strings carry semantics but do not quan-
tify coherence (partially satisfying D2), and do not
allow hierarchical structure (failing D1) or complex
topological relationships (failing D3).
(2) Logical-Shapelets (Mueen et al., 2011) rep-
resents entire time series with a series of discrim-
inative sub-sequences , i.e., shapelets (satisfying
D3). Z-Time (Lee et al., 2024) improves the repre-
sentation by making the length variable (satisfying
D3). Both the shapelets and discrete representa-
tions of Z-Time carry limited semantic abstraction
(partially satisfying D2). Regarding structural mod-
eling, Logical-Shapelets only considers boolean
relations, and while Z-Time uses Allen’s algebra
(Allen, 1983), only limited hierarchy structures can
be represented by stacking temporal relation pairs.
Therefore, both approaches partially satisfy D1.
(3) Chronicle System (Dousson and Le Maigat,
2007) applies graph structure to represent tempo-
ral events, where each sub-event is considered as
a node in the graph, and STL (Maler and Nick-
ovic, 2004) represents events as recursive logical
formulas over signals intervals, both satisfying D1.
However, both systems model semantic coherence
as binary values (true/false) (partially satisfying
D2), and their reliance on actual interval durations
does not meet D3.
In summary, existing symbolic systems can
only make structured representations from time
series but not language, thus not satisfying the re-
quirements of L-TSED. In contrast, our proposed
ELT framework employs tree structures based on
Allen’s algebra and boolean operators to support
D1. The definition of tree schema and instantiation
on actual time series data are separated to satisfy
D3. ELT supports quantifying semantic coherence
with neural models over any combination of basic
time series signal attributes, satisfying D2.

A.2
Multimodal LLMs for Time Series
Reasoning
Though foundation models pre-trained on large-
scale time series data have shown promising perfor-
mance in low-resource settings, fine-tuning is still
necessary, and cross-modal reasoning is restricted
(Ansari et al., 2024; Liu et al., 2024; Goswami
et al., 2024). Recently, LLMs’ potential to serve
as few/zero-shot time series reasoners have been
widely explored. ChatTS (Xie et al., 2025) de-
signed an encoder with synthetic data to align time
series with language for QA tasks. However, the
domain gap between synthetic and real-world data
is difficult to bridge, and embedding time series can
still introduce the risk of hallucination. VL-Time
(Liu et al., 2025) visualizes time series data as fig-
ures to directly adopt vision-language reasoning
capabilities without extra TS-language alignment.
While it has shown advantages in classification,
visualization inevitably loses precision, and hallu-
cination is still a risk. Our approach employs active
visualization tools to overcome precision loss and
effectively mitigates hallucination with ELT repre-
sentations.

B.1
ELT Schema
The Event Logic Tree schema is parsed from tex-
tual descriptions only, independent of actual time
series data. One event corresponds to one tree.
Definition 1 (Node Schema). The Event Logic Tree
Schema is denoted as S. Any node in the schema
n ∈S belongs to two categories: primitives and
composites.
1. Primitive (Leaf Node)
: The atomic signal
patterns over single physical channels, denoted as
np = ⟨τ, c⟩, where:
• τ: The semantic predicate that describes sig-
nal morphology, which can be a compound

of basic time series attributes, e.g., “a steep

• c: The physical channel index where this

2. Composite (Internal Node).
The temporal-

• N = [n1, . . . , nk]: An ordered list of child

• op ∈{SEQ, SYNC, GUARD, OR}: The temporal-

B.2
Constitutive Axioms
Based on the definitions above, we establish three
axioms to serve as preconditions for valid schema
construction, and properly control the search space
during instantiation.
Axiom 1 (Constructive Composition). A composite
node must add structural meaning. Formally, for
any composite nϕ, |N| ≥2.
Remark.
Axiom 1 excludes bad structures with
self-nesting, and any logical NOT as composite with
a single child. We require all primitives to be de-
fined positively.
Axiom 2 (Temporal Compactness). The semantics
of any node must cover its full temporal span. Any
undefined gap inside the temporal spans of com-
posites must be bounded by a hyperparameter.
Remark.
Primitives are considered to be com-
pact by definition. For any composite, assuming
the compactness tolerance is 1, a composite whose
children are assigned disjoint intervals like [1, 2]
and [4, 6] will be prohibited by Axiom 2.
Axiom 3 (Physical Exclusivity). A physical chan-
nel c can only support one active primitive state at
any time point t.

K.1
Setup
To examine whether agent-assigned primitive con-
fidence µ faithfully reflects coherence between
a primitive description d and its instantiated sig-

modal similarity score s = simCLaSP(d, X[I, c])
using a CLaSP-style contrastive model (Ito et al.,
2025) trained on the SUSHI dataset11.
The
text encoder is a frozen multilingual-e5-large
(XLM-RoBERTa-Large, 560M parameters); the
signal encoder is a PatchTST-style Transformer
(patch size 16, dmodel = 256, 4 heads, 4 lay-

space via symmetric InfoNCE loss,
trained
on 1.4k SUSHI signal–description pairs (test
R@1 =
0.284 / 0.291, R@10 =
0.929 / 0.922,
