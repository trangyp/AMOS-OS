tropical (algebraic) geometry. We give strong characterizations of prime congruences con-

1. INTRODUCTION
Tropical geometry replaces algebraic varieties (the vanishing loci of polynomial equa-
tions) with tropical varieties (tropical vanishing loci of tropical polynomials), thus allowing
for the use of a broader range of (combinatorial) tools in the study of algebraic varieties.
While tropical geometry has been very successful in providing a new approach to classical
problems, those applications have been focused on using the combinatorics and geometry
and have ignored the underlying (semiring) algebra.
One way to endow tropical varieties (which are not necessarily tropicalizations of alge-
braic varieties) with algebraic structure is introduced in [14] wherein the authors define a
semiring analogue of the coordinate ring of a variety. As shown in [23], these coordinate
semirings carry the same information as that of particular ideals, which the authors call
tropical ideals, that are almost always not finitely generated. More precisely, let S be a sub-
semifield of the tropical semifield T, let M be a toric monoid, and let I be any subset of
S[M]. The variety of I is denoted V(I) and is defined in terms of a “tropical vanishing”
condition. Towards forming a corresponding coordinate semiring, we can form the bend
congruence Bend(I) of I; see Definition 2.8. The coordinate semiring is then defined to be
S[M]/ Bend(I). We can then recover the variety of I as HomS−alg(S[M]/ Bend(I), T) ∼=
V(I).
Coming from algebraic geometry, one may wonder why these congruences are necessary -
maybe we should just be quotienting by ideals, i.e., setting everything in the ideal equal to
0. If we do this, however, then affine space would only have finitely many subvarieties.
Moreover, different ideals would have the same quotients.
In analogue with classical algebraic geometry one would like to more deeply study the
connection between tropical varieties and their coordinate semirings. Our main tool for

1.2. Context in the literature. In recent years, there has been a lot of effort dedicated to
developing the necessary tools for commutative semiring algebra to understand the geom-
etry of tropical varieties; see [14], [23], [24], [9], [21], [20], [11], [32], [33], [18], [5], [19], [15],
[1]. One particular approach, introduced in [14], focuses on constructing an analogue of
a coordinate semiring which allows us to remember more information about the original
algebro-geometric objects and are able to define tropical objects intrinsically.
There are compelling results pointing to the power of semiring methods in tropical ge-
ometry.
Tropicalizations of ideals in polynomial rings, or equivalently the bend congruences of
such tropicalized ideals, have been shown to preserve more information than the tropical-
izations of the corresponding varieties. For example, the tropical variety retains the infor-
mation of the dimension and degree, whereas the whole Hilbert polynomial is determined
by the tropical ideal; see [14], [23], and [24]. Maclagan and the second author, in unpub-
lished work, give concrete ways to use tropical ideals to distinguish planar quadric curves
that have the same tropical variety.
A recent paper, [3], focuses on the tropicalization of the function field of the variety over
a discretely valued field and, extending a result of Baker and Rabinoff for curves, shows
that this is the same as the semifield of tropical rational functions. They also show that
this semifield is finitely generated. These results lead them to new proofs of the discretely
valued cases of a recent result by Ducros, Hrushovski, Loeser and Ye [7] and of the faithful
tropicalization theorem by Gubler, Rabinoff and Werner [17].
In [36] Tolliver provides an application to number theory – he gives a purely semiring-
theoretic proof for the extension of valuations of fields.

2. PRELIMINARIES
A semiring is a set R with two binary operations (addition + and multiplication · ) satisfy-
ing the same axioms as rings except the existence of additive inverses, as well as the axioms
that a · 0 = 0 and 0 · a = 0. In this paper, a semiring is always assumed to be commutative.
A semiring (R, +, ·) is a semifield if (R\{0R}, ·) is a group. A semiring R is called additively
idempotent if for all a ∈R we have that a + a = a.
Key assumption: All semirings will be assumed to be additively idempotent.
Any additively idempotent semiring comes with a partial order defined by a ≤b ⇐⇒
a + b = b. Both addition and multiplication preserve this partial order. One consequence of
this is the following well-known fact.
Lemma 2.1. Let A be an additively idempotent semiring, then it is zero-sum free, i.e., if a, b ∈A
with a + b = 0, then a = b = 0.
Proof. If a + b = 0, then a + a + b = a + 0 and so a + b = a implying that b ≤a and by
symmetry a ≤b. So a = b and a + b = a + a = a = 0.
□
We will denote by B the semifield with two elements {1, 0}, where 1 is the multiplicative
identity, 0 is the additive identity and 1 + 1 = 1. The tropical semifield, denoted T, is the set
R ∪{−∞} with the + operation defined to be the maximum and the · operation defined to
be the usual addition, with −∞= 0T.
In order to distinguish when we are considering a real number as being in R or being
in T we introduce some notation. For a real number a, we let ta denote the corresponding
element of T. In the same vein, given a ∈T, we write log(a) for the corresponding element
of R ∪{−∞}. This notation is motivated as follows. Given a non-archimedean valuation

2.1. Congruences.
Definition 2.2. Let A be a semiring and let a ∈A\{0}. We say that a is a cancellative element
if, for all b, c ∈A, whenever ab = ac then b = c. If all elements of A\{0} are cancellative,
then we say that A is a cancellative semiring.
Definition 2.3 (cf. Definition 2.3 and Proposition 2.10 in [20]). A congruence on a semiring A
is an equivalence relation on A that respects the operations of A. The trivial congruence on A
is the diagonal ∆⊆A × A, for which A/∆∼= A. We call a congruence C on A cancellative if
A/C is a cancellative semiring. We call a proper congruence P of an idempotent semiring A
prime if A/P is totally ordered and cancellative.
