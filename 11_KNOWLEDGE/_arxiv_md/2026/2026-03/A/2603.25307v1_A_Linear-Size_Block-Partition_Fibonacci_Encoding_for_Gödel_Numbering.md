A LINEAR-SIZE BLOCK-PARTITION FIBONACCI ENCODING
FOR G¨ODEL NUMBERING
ZOLT´AN S´OSTAI
Abstract. We construct an encoding of finite strings over a fixed finite alphabet as natural num-
bers, based on a block partition of the Fibonacci sequence. Each position in the string selects one
Fibonacci number from a dedicated block, with unused indices between blocks guaranteeing non-
adjacency. The encoded number is the sum of the selected Fibonacci numbers, and Zeckendorf’s
theorem [6, 4] guarantees that this sum uniquely determines the selection. The encoding is injec-
tive, the string length is recoverable from the code, and the worst-case digit count of the encoded
number grows as Θ(m) for strings of length m—matching the information-theoretic lower bound up
to a constant factor. We also prove that the natural right-nested use of Rosko’s [5] binary carryless
pairing for sequence encoding has worst-case Θ(2m) digit growth—an exponential blowup that the
block-partition construction avoids entirely.
1. Introduction
G¨odel’s incompleteness theorems [2] require encoding syntactic objects—symbols, formulas,
proofs—as natural numbers. The original encoding maps a sequence ⟨a1, . . . , am⟩to the product
2a1+1 · 3a2+1 · 5a3+1 · · · pam+1
m
,
where pi is the i-th prime and the +1 ensures positive exponents. The fundamental theorem of
arithmetic guarantees injectivity, and decoding reduces to factorization. This encoding produces
very large numbers: even short formulas yield codes of dozens or hundreds of digits.
Rosko [5] proposed an alternative based on Zeckendorf representations—unique decompositions
of natural numbers as sums of non-consecutive Fibonacci numbers [6, 4]. His “carryless pairing”
function is a pairing N2 →N that places the Zeckendorf supports of two inputs into disjoint
even/odd index bands. Encoding sequences of length m via right-nesting of this binary pairing
requires m −1 applications. We prove in §5.3 that this right-nested use has worst-case Θ(2m) digit
growth.
The present paper introduces a simpler construction: a block-partition encoding that par-
titions the Fibonacci sequence into contiguous blocks, one per string position, with single-index
gaps between blocks to ensure non-adjacency. Each symbol selects one Fibonacci number from its
position’s block, and the encoded number is the sum. No nesting is involved. The digit count of
the encoded number grows linearly in the string length.
The paper isolates the numeric coding layer of a G¨odel numbering: the injective mapping from
strings to natural numbers. The further machinery required for a full syntactic arithmetization—
substitution, concatenation, diagonalization—is not addressed here.

data compression [1], where each positive integer is represented by a binary string derived from its
Zeckendorf representation. Our construction is distinct: we encode strings over a formal alphabet

2.2. Zeckendorf’s theorem.
Theorem 2.1 (Zeckendorf [6], Lekkerkerker [4]). Every positive integer n has a unique represen-
tation as a sum of non-consecutive Fibonacci numbers:
n = Fe1 + Fe2 + · · · + Fes
where e1 > e2 > · · · > es ≥2 and ei −ei+1 ≥2 for all i.
The set Z(n) = {e1, e2, . . . , es} is called the Zeckendorf support of n. We define Z(0) = ∅.
The support of a positive integer is computed by the greedy algorithm: at each step, select the
largest Fibonacci number not exceeding the remainder, subtract it, and repeat.

4. Correctness
4.1. Non-adjacency.
Lemma 4.1 (Non-adjacency). For any nonempty string s = s1s2 · · · sm over a k-symbol alphabet,
the Fibonacci indices selected by the block-partition encoding are mutually non-consecutive.
Proof. Each position i selects exactly one index from block Bi. Within a single block, only one
index is selected, so no adjacency arises within a block.

4.2. Injectivity.
Theorem 4.2 (Injectivity). The block-partition encoding is injective on Σ∗: if s ̸= t, then ⌜s⌝̸=
⌜t⌝.
Proof. If one of s, t is the empty string and the other is not, then one code is 0 and the other is a
positive integer (since every nonempty string selects at least one Fe ≥F2 = 1).
If s and t are both nonempty with |s| = m < m′ = |t|, then the Zeckendorf support of ⌜t⌝contains
an index from block Bm or higher, while every index in Z(⌜s⌝) lies in blocks B0 through Bm−1.
These are distinct subsets of non-consecutive indices (by Lemma 4.1), so by Theorem 2.1 the sums
differ.
If |s| = |t| but s and t differ in at least one position j, then position j selects a different Fibonacci
index in s than in t. The remaining positions select identical indices. So the two Zeckendorf supports
differ, and by Theorem 2.1 the sums differ.
□
4.3. Valid codes and length recovery.
Definition 4.3 (Valid code). A natural number n is a valid code if n = 0 (encoding the empty
string) or if there exist m ≥1 and unique c1, c2, . . . , cm ∈{0, 1, . . . , k −1} such that
Z(n) =

2 + iβ + ci+1 : 0 ≤i < m

That is, the Zeckendorf support of n consists of exactly m indices, one from each block B0
through Bm−1, with no indices in gap positions. The image of the encoding ⌜·⌝is exactly the
set of valid codes.
Lemma 4.4 (Length recovery). For any valid code n, the length of the encoded string is recoverable:
if n = 0, then m = 0; if n > 0, then m = |Z(n)|.
Proof. For n > 0, Definition 4.3 requires Z(n) to consist of exactly m indices, one per block.
Therefore |Z(n)| = m. Equivalently, m = ⌊(emax −2)/β⌋+ 1 where emax = max Z(n), since the
largest index lies in Bm−1.
□

5. Complexity analysis
5.1. Code length.
Theorem 5.1 (Linear code length). For k ≥2 and m ≥1, the worst-case digit count L(m) =
max{digits(⌜s⌝) : s ∈Σm} satisfies L(m) = Θ(m).
Proof. The largest Fibonacci index used in encoding a string of length m is at most
emax = 2 + (m −1)β + (k −1) = mβ.
Every length-m code satisfies
F2+(m−1)β ≤⌜s⌝< Fmβ+1.
The lower bound holds because the code includes at least F2+(m−1)β from block Bm−1. The upper
bound holds because the sum of any set of non-consecutive Fibonacci numbers with indices up to e
is strictly less than Fe+1 (a standard property of Zeckendorf representations).
Taking logarithms, both bounds are Θ(mβ · log10 φ) = Θ(m).
For the 10-symbol alphabet
(β = 11), this gives approximately 2.3 digits per symbol.
□
5.2. Optimality.
Theorem 5.2 (Asymptotic optimality). For k ≥2, the block-partition encoding has asymptotically
optimal code length: L(m) = Θ(m), matching the information-theoretic lower bound.
Proof. There are km distinct strings of length m. Any injective map into N must use numbers
as large as km −1, requiring at least m · log10(k) digits. The block-partition encoding achieves
L(m) = Θ(m · (k + 1) · log10 φ). The ratio of the constant factors is
(k + 1) log10 φ
log10 k

For k = 10, this is 11 · 0.209/1 ≈2.3. Both bounds are linear in m; the block-partition encod-
ing incurs a constant-factor overhead of approximately 2.3 relative to an information-theoretically
optimal encoding.
□
5.3. Exponential blowup of right-nested carryless pairing. Rosko [5] defines a carryless
pairing function π : N2 →N.
His paper presents it as a binary pairing and sketches a k-ary
generalization, but does not develop a completed sequence encoding. The natural way to encode a
length-m sequence (a1, a2, . . . , am) using a binary pairing is right-nesting. Formally, define t1 = am
and tj+1 = π(am−j, tj) for j = 1, . . . , m −1. The final code is tm−1, requiring m −1 pairings. Let
Mj = max Z(tj) denote the largest Fibonacci index in the support after j pairings.
To avoid the issue that Z(0) = ∅(making Rosko’s pairing degenerate for zero inputs—in par-
ticular π(0, 0) = 0), we adopt the standard shift-by-one convention: symbol codes are drawn from
{1, 2, . . . , k} rather than {0, . . . , k −1}.
Proposition 5.3 (Exponential growth). Let codes be drawn from {1, . . . , k}. Right-nested encoding
of a length-m sequence via Rosko’s carryless pairing produces codes whose worst-case digit count is
Θ(2m).
Proof. In Rosko’s pairing π(x, y), the output’s Zeckendorf support occupies indices up to B(x) +
2 R(y) −1, where B(x) = 2 r(x) is the delimiter, r(x) = min{e : Fe > x} is the rank, and
R(y) = max Z(y). Since all symbol codes are positive, Z(ai) is nonempty and R(ai) is well-defined
for every symbol.

largest Fibonacci index is M4 = 245. By comparison, the block-partition encoding of a length-5

7. Conclusion
The block-partition Fibonacci encoding provides a simple, compact mapping from finite strings to
natural numbers, with worst-case code length growing linearly in the string length. The construction
rests on an elementary observation: partitioning the Fibonacci sequence into blocks with single-
index gaps ensures that any selection of one Fibonacci number per block yields a valid Zeckendorf
representation, and Zeckendorf’s theorem then guarantees unique decodability.
For sequence encoding over the same Zeckendorf foundation, the block-partition construction
achieves Θ(m) code length where the natural right-nested use of Rosko’s binary carryless pairing
produces Θ(2m) code length (Proposition 5.3), an exponential improvement.
Whether the additive character of this encoding can be exploited for theory-internal purposes—
such as establishing ∆0-definability of syntactic predicates in bounded arithmetic or enabling in-
completeness proofs in systems lacking multiplication—is a question we leave to future work.
