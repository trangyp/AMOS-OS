EDGAR A. BERING IV, JAKOB HEIKAMP, JACK KOHAV,
NIR LAZAROVICH, AND ZACHARY MUNRO
Abstract. We prove that any ascending chain of bounded rank
subgroups in the fundamental group of a compact 3-manifold sta-
bilizes. We use geometrization to reduce the proof to fundamental
groups of complete, finite-volume hyperbolic 3-manifolds. To han-
dle this case, we prove the following: In a toral relatively hyperbolic
group, any ascending chain of bounded rank, locally relatively qua-
siconvex subgroups stabilizes. We note this theorem is new even
for bounded rank, locally quasiconvex chains in hyperbolic groups.
1. Introduction
A group is Noetherian (or satisfies ACC) if every ascending chain of
subgroups stabilizes. Most groups of interest in geometric group theory
fail to be Noetherian because they contain nonabelian free subgroups.
However, it is still possible to achieve ascending chain conditions for
restricted classes of subgroups.
Definition 1.1. A group satisfies ωACC if any ascending chain of
uniformly bounded rank subgroups stabilizes.
Takahashi [21] and Higman [7] independently proved that free groups
satisfy ωACC. Kapovich and Myasnikov [11] gave a geometric proof of
this result using Stallings folds.
Shusterman [20] proved that limit
groups satisfy ωACC (this includes fundamental groups of compact
surfaces). We prove the following.
Theorem A. Fundamental groups of compact 3-manifolds satisfy ωACC.
Theorem B. In a toral relatively hyperbolic group, any ascending
chain of bounded rank, locally relatively quasiconvex subgroups stabi-
lizes.
We note that this theorem is new even for hyperbolic groups, which
are special case of toral relatively hyperbolic.

2. Preliminaries
2.1. Graph of groups. We recall definitions regarding graphs of groups.
For a more thorough introduction, the reader can consult Serre [19].
Definition 2.1 (Graphs). A graph A consists of a set of vertices V A,
a set of edges EA, maps e ↦e+ and e ↦e−from EA to V A, and a
fixed-point-free involution e ↦e−1 of EA such that (e−1)+ = e−for all
e ∈EA. A pair {e,e−1} is a geometric edge, and we denote the set of
geometric edges by EA.
The degree of v ∈V A is deg(v) = ∣{e ∈EA ∣e−= v}∣.
Definition 2.2 (Paths). A path p in A is a sequence (v0,e1,v1,...,en,vn)
such that
●vj ∈V A and ei ∈EA for each j = 0,...,n and i = 1,...n, and
●(ei)−= vi−1 and (ei)+ = vi for each i = 1,...,n.
The endpoints of p are the vertices v0, vn and are denoted p−, p+. A
path is determined by its edges, so we will sometimes specify a path
by a sequence (e1,...,en) such that (ei)+ = (ei+1)−for i = 1,...,n −1.
The length len(p) of p is the number of edges n.

Definition 2.16 (Peripheral components). A Pi-path is a path whose

A Pi-component of a path p is a non-trivial
maximal Pi-subpath of p. A vertex in the interior of a component is
inner, all other vertices are phase vertices. Two Pi-paths are connected
if their endpoints are connected by an edge in ̂Γ with a label in Pi. In
other words, they are connected if they belong to the same coset of Pi.
A Pi-component of a path p is isolated if it is not connected to any
other Pi-component.
Definition 2.17 (Non-backtracking). The path p is non-backtracking
if every Pi-component is isolated for each i.

●We can write p = a1p1a2 ...pn−1an and p′ = a1e1a2 ...en−1an

Definition 2.20. Let X be a finite, symmetric generating set of G,
and let P be a collection of subgroups of G. We say G is hyperbolic
relative to P if (G,P) satisfies the BCP property and ̂Γ is hyperbolic.
A parabolic subgroup is a subgroup conjugate to an element P ∈P, and
a peripheral coset is a coset of the form gP for some g ∈G,P ∈P. The
group G is toral relatively hyperbolic if it is torsion-free and hyperbolic
relative to a set of finitely generated free abelian subgroups.
