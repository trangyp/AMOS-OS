Abstract
In this paper, we study arbitrary models of the first-order theory of a
ring A where the additive group A is a finitely generated abelian group.
Following an earlier paper by this author, Alexei G. Myasnikov and Francis
Oger [9], we call these rings the FDZ-rings or FDZ-algebras. The rings
considered are not necessarily unitary, commutative, or associative. We
provide criteria for such rings to be quasi finitely axiomatizable (QFA)
or bi-interpretable with the ring of integers Z. We shall also describe all
rings elementarily equivalent to such a ring A given certain constraints on
A.

Introduction
In this paper, we extend the results of [9] and continue the program of devel-
oping a structure theory for arbitrary models of finite dimensional rings over
Z (FDZ-rings). Our motivation, at least partly, comes from the model theory
of finitely generated nilpotent groups: via the various types of “Mal’cev-like”
correspondences between rings and nilpotent groups, understanding elementary
equivalence classes on the ring side provides a route toward describing all groups
elementarily equivalent to a given finitely generated nilpotent group.
After recalling the relevant notions of first-order rigidity and quasi-finite
axiomatizability, we focus on bi-interpretability with the ring of integers. We
provide conditions that guaranty an FDZ-ring cannot be bi-interpretable with Z,
and we also offer sufficient conditions to ensure bi-interpretability. For the class
of super tame FDZ-rings, we provide a complete description of arbitrary models
of their complete first-order theory. Finally, we attempt such a characterization
for all FDZ-rings whose “maximal” scalar ring is bi-interpretable with the ring
of integers Z.
These models will be called abelian deformations of a tensor
completion of A over a ring elementarily equivalent to Z. We describe these
using certain symmetric 2-cocycles.
1.1
First-order rigidity and quasi-finite axiomatizability
We begin by fixing some notation and recalling some model-theoretic definitions
(we refer to [5] for details). For the remainder of this section, L is a countable
language and T is a complete L-theory with infinite models.
Definition 1.1. A finitely generated L-structure A is called first-order rigid if,
for any finitely generated L-structure B, first-order equivalence A ≡B implies
isomorphism A ≃B.
Definition 1.2. Fix a finite signature. An infinite finitely generated structure
is Quasi Finitely Axiomatizable (QFA) if there exists a first-order sentence ϕ of
the signature such that
• A |= ϕ
• If B is a finitely generated structure in the same signature and B |= ϕ then
A ∼= B.
Definition 1.3. Suppose that structures A, B in finite signatures are given, as
well as interpretations of A in B, and vise versa. Then an isomorphic copy eA
of A can be defined in A by “decoding” A from the copy of B defined in A.
Similarly, an isomorphic copy eB of B can be defined in B. An isomorphism
Φ : A ∼= eA can be viewed as a relation on A, and similarly for an isomorphism
B ∼= eB. We say that A and B are bi-interpretable (with parameters) if there
exist isomorphisms that are first-order definable.

1.2
Preliminaries on FDZ-rings
We call a ring any structure (A, +, ·) such that (A, +) is an abelian group and
(x, y) 7→x · y is bilinear. A ring is said to be a scalar ring if it is commutative,
associative, and unitary. We denote by N∗the set of strictly positive integers.
The reader is referred to [2] for the concepts of mathematical logic that
are used here. For each language L, two L-structures A and B are said to be
elementarily equivalent if they satisfy the same first-order sentences.
Any language L consists of relation symbols, constant symbols , and function
symbols. The L-structures can be interpreted in a language without function
symbols, replacing each function with the relation associated with its graph.
The notions of elementary equivalence for the two languages coincide.
For a pair of structures, for example, a scalar ring R and a R-module M, it
is convenient to use a language without function symbols and to interpret each
operation, for example, the action of R on M, as a relation on the disjoint union
of the two structures. We obtain the same notion of elementary equivalence if
we interpret each pair as a multi-based model, possibly with function symbols
(see [3]).
According to the definition given by Andr´e Nies in [6], for each finite language
L with function symbols, a finitely generated L-structure is said to be quasi-
finitely axiomatizable if it is characterized among finitely generated L-structures
by one sentence.
For each language L containing + and each L -structure M such that (M, +)
is an abelian group, we say that M is finite dimensional over Z or FDZ if
(M, +) is finitely generated. We say that M is FDZ-finitely axiomatizable if it
is characterized among FDZ L-structures by one sentence.
We note that for each structure M and each finite sequence x that generates
M (resp. (M, +)), the structure (M, x) is quasi-finitely (resp. FDZ-finitely)
axiomatizable if and only if there exists a formula φ(u) satisfied by x in M
such that for each finitely generated (resp. FDZ) structure N and each y which
satisfies φ in N, the map x →y induces an isomorphism from M to N.
In [9] the following statements have been proved:
Theorem 1.2. Consider an FDZ scalar ring R and a finite sequence r which
generates (R, +). Then (R, r) is FDZ-finitely axiomatizable.
Theorem 1.3. Consider an FDZ scalar ring R, an FDZ R-module M and some
finite sequences r and x which generate (R, +) and (M, +). Then (R, r, M, x)
is FDZ-finitely axiomatizable.

• Ann(A) = {x ∈R | xy = yx = 0 for each y ∈A},
• A2 = {x1y1 + · · · + xnyn | n ∈N and x1, y1, . . . , xn, yn ∈A},

• ∆(A) = Is(A2)
• K(A) = Ann(A) + ∆(A)
• L(A) = Is(Ann(A) + A2)
• M(A) = A/L(A) and
• N(A) = L(A)/K(A).
We say that A is regular if K(A) = L(A). Then, for each additive subgroup
A0 ⊂A such that Ann(A) = A0 ⊕(Ann(A) ∩∆(A)), there exists a subring
Af ⊂A containing ∆(A) such that A = Af ⊕A0. Such a subgroup A0 is called
an addition of A, and Af is called the corresponding foundation of A. We say
that A is tame if Ann(A) ⊂∆(A).
If A is not regular and an addition A0 exists, the corresponding Af is not
necessarily a subring. In that case, we refer to the quotient Af = A/A0 as the
foundation Af of A corresponding to A0.
The following result is a generalization of Theorem 1.2:
Theorem 1.5. Consider a tame FDZ ring A and a finite sequence x that gen-
erates (A, +). Then (A, x) is FDZ-finitely axiomatizable.
In contrast to the results above, we have the following:

Corollary 1.7. Each regular FDZ ring is first-order rigid among the FDZ rings.
