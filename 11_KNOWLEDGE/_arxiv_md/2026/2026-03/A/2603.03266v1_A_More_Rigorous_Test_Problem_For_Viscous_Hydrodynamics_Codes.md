ABSTRACT
We advocate for a more stringent test problem for codes that aim to solve the equations of viscous hy-
drodynamics. Specifically, we discuss a nonuniform-density version of the common (uniform-density)
Gaussian velocity shear test, where density gradients transverse to the direction of velocity shear cause
the velocity profile to drift over time. By employing a nonunifom density, this test provides a test
that the full viscous stress (and velocity shear) tensors are calculated correctly from the conserved
variables, and checks the correctness of the fluxes and source terms calculated therefrom.
In Appendix A, we present a detailed exposition of the Navier Stokes equations, particularly their
fluxes and source terms in a variety of common coordinate systems.
1. INTRODUCTION
A standard problem used to test codes designed to solve the Navier-Stokes equations is following the evolution of a
Gaussian velocity bump (e.g., D’Orazio et al. 2013; Duffell 2016; Stone et al. 2024), inspired by analogy to the classic
solution to the heat equation. However, this test is typically employed using a constant background density, which
can allow errors to slip into the computation of viscous evolutionary terms undetected or underappreciated. In the
following we discuss a more general analytical solution to the equations of viscous hydrodynamics and its application
as a test problem for numerical schemes.

errors achievable when using this problem to test the convergence of a particular code.
3. EXAMPLES
In the following we apply three different codes to this problem, testing the accuracy of the codes and highlighting
the ability of this test to identify errors passed over by the constant-density version of this test.
We construct an initial state by choosing an initial standard deviation σ0 and amplitude v0. The former, along with
the kinematic viscosity, determine an effective initial time t0 = σ2
0(2ν) and amplitude A = v0
√4νt0. In the following,
we have used v0 = 10−3, σ0 = 0.1, ν = 1. We set the initial location of the velocity Gaussian to x0 = 0.5 and ran
each simulation until t = 0.02. As an example, we have conducted a series of tests using both uniform and nonuniform
backgrounds, specifically κ = 0 and κ = 15.
For the sake of demonstration, we have implemented this test problem in two different codes, Athena++ (Stone
et al. 2020) and Disco. Our Athena++ simulations employed both Cartesian coordinates (with a uniform mesh) and
cylindrical polar coordinates (with a log-uniform radial mesh spacing). Our Disco simulations were all conducted in
cylindrical polar coordinates but used a grid linearly spaced in radius and with a variable number of cells in the ϕ
direction to achieve nearly-equal-aspect ratio cells; in Disco we used both the approximate viscous scheme described
in Duffell (2016) (“v2016”) and a complete shear viscosity as described in Dittmann & Ryan (2021).1 In each case we
used second-order Runge-Kutta time-stepping and second-order piecewise-linear reconstruction.
Figure 1 illustrates the vy profile for a variety of simulations at t = 0.02 for simulations employing κ = 15 density
profiles. As far as the eye can tell, Athena++ and Disco both agree quite well with each other (and the analytical
solution, as the center of the velocity bumps have shifted from x = 0.5 to x = 0.8), while Disco v2016 deviates
significantly.
Figure 2 illustrates the convergence, or lack thereof, of each code for both the κ = 0 and κ = 15 versions of this test
problem. Notably, each code performs adequately with a uniform-density-background, but the limitations of Disco
v2016 are revealed at κ ̸= 0. Only testing the κ = 0 case might leave one unduly confident in the accuracy of one’s
code, and thus κ ≫1 should be preferred.

4. SUMMARY
We hope that this more rigorous, “improved” even, Gaussian velocity shear problem will prove useful for testing
future numerical schemes. As illustrated above, it is more discriminating that the uniform-density version, in addition
to being an intrinsically more thorough test.
