Introduction
Significant research efforts have been dedicated to designing parameterized algorithms for planar
graphs, aiming for running times that depend subexponentially on the size of the solution or
on some other parameter of the input instance [12,14,16,17,19–21,26,29,33,34,38–43]. While
many of these algorithms employ problem-specific arguments, several useful general techniques
and design patterns have also been discovered. In some cases, these techniques generalize also
to bounded-genus or H-minor-free graphs.
The theory of bidimensionality gives a very clean win/win approach for certain problems,
where the answer for an instance with parameter k is trivial if treewidth is Ω(
√
k). However,
there is only a limited set of such problems and often natural generalizations of the problem
definition ruins this property; in particular, this is often the case for problems involving terminals
and directed graphs. Marx et al. [40] and Bandyapadhyay et al. [3] presented general techniques
for handling cycle hitting problems, where the task is to delete at most k edges/vertices such
that some property related to components or 2-connected components of the resulting graph is
satisfied (e.g., there is no cycle going through a terminal). However, this framework is inherently
about deletion-type problems, and can handle a problem only if the sought-after property of the
remaining graph can be described using constraints in a certain way.
Fomin et al. [27] presented a powerful technique that can be applied to many problems where
the solution is a connected pattern of size k. For such problems, using the following result as a
black box and an algorithm for solving bounded-treewidth instances delivers a subexponential
parameterized algorithm. An apex graph is a graph that can be made planar by deleting a vertex.
Note that K3,h is an apex graph and for every g ⩾0 there is an h such that graphs of Euler genus
at most g are K3,h-minor-free; thus the statement applies in particular to bounded-genus graphs.

In order to be able to use this approach for other algorithmic problems, the problem needs
to satisfy three main properties:
1. The problem can be solved in time 2 e
O(t)nO(1) on graphs of treewidth t.
2. The solution Z needs to be connected.
3. Validity of the solution Z depends only on G[Z] and is not affected by vertices outside Z.
The first point is not very restrictive: designing algorithms on bounded-treewidth graphs is quite
well understood, and the standard technique of dynamic programming on a tree decomposition
delivers such alogrithms. It is worth pointing out that these dynamic programming techniques
are very robust in the sense that different problem variations and extensions (colored graphs,
directed graphs, weights, etc.) can be usually achieved with little additional effort. On the other
hand, the second and the third points severely limits the range of problems that can be handled
by this approach. Requiring connectivity excludes problems such as finding many disjoint small
patterns, and defining the problem in terms of some property of G[Z] excludes in particular
domination-type problems and problems involving distances.
Another technique for subexponential algorithms for detecting subgraphs in planar graphs
was presented by Nederlof [43]. This work builds upon a key combinatorial result of Fomin
et al. [27], a certain type of duality between a chain of disjoint separators and almost-disjoint
paths (see Theorem 2.1 below). A crucial new insight of Nederlof [43] (see [43, Lemma 3.7])

allows easy reuse for other type of problems. Moreover, the algorithm works only on planar

Disjoint paths
In the Disjoint Paths problem, a graph G is given with k pairs of terminal
vertices (s1, t2), . . . , (sk, tk) and the task is to find k pairwise vertex-disjoint paths P1, . . . , Pk

Densest subgraph
Given a graph G and integer k, the Densest Sugraph problem asks for a set
S of k vertices such that G[S] has the maximum number of edges. On general graphs, the problem
is clearly at least as hard as k-Clique. As the problem can be solved in time 2O(t)|V (G)|O(1) if a
tree decomposition of width t is given [8], Theorem 1.2 can be used to obtain a subexponential
parameterized algorithm for this problem on H-minor-free graphs. Note that, even though the
problem asks for a “dense” subgraph, there is no reason to assume that G[S] is connected for
the optimal S. Hence it is essential again that Theorem 1.2 does not require connectivity.
Partial cover problems
Partial versions of optimization problems ask for a solution set
S of size k that potentially does not satisfy all the constraints, but maximizes the number of
satisfied constraints. This generalization can make the problem significantly harder: for example,
Partial Vertex Cover (find k vertices that cover at least ℓedges) is W[1]-hard parameterized
by k. However, the problem becomes FPT on planar and H-minor-free graphs and even admits
subexponential parameterized algorithms [2,29]. We point out that Theorem 1.2 can be also used
to obtain such algorithms, as the problem can be solved on tree decompositions using standard
techniques (for example, note that the number of edges covered by S is the total degree of S
minus the number of edges in G[S], thus techniques similar to Densest Subgraph are applicable).
This algorithm has the advantage of being easily generalizable to other problem variants, such
as vertices/edges having weights or colors etc.
One can generalize the Partial Vertex Cover problem the following way: instead of inter-
secting the maximum number of edges, we want to intersect the maximum number of cliques of
size c; clearly, c = 2 is the same as Partial Vertex Cover. For c > 2, the number of Kc-subgraphs
intersected by S cannot be determined from G[S] only, but it can be determined from G[NG[S]].

Distance constraints
One of our main contributions is that Theorem 1.3 for K3,h-minor-free
graphs allows us to express problems that involve distance constraints. Generalizing (Partial)
Dominating Set to its distance-d version was one example. But it is natural to consider distance
constraints in the context of other problems as well, for example:
• Find k copies of a fixed pattern P in G that are pairwise at distance at least d.
• Find vertex-disjoint paths of total length k connecting given terminal pairs such that the
paths are at distance at least d from each other.
• Find a cycle of length exactly k such that there is no “shortcut” of length at most d
connecting two vertices of the cycle with edges outside the cycle.
For such problems, if S is the solution of size k, then the validity of the solution cannot be
verified by knowing only G[S]: we need to know G[N d
G[S]] to verify the validity of the solution.
Therefore, the right way to think about the problem is the following:
1. We want to find two sets: a set S of size k, and a set S∗of unbounded size.
2. We want to find an assignment δ: S∗→{0, 1, . . . , d} such that δ(v) is the distance of v
from S.
3. We want to verify that S∗is exactly Nd
G[S].
4. We want to verify that G[S∗] shows that S is indeed a correct solution.
Theorem 1.3 gives us a set Z with S∗⊆Z and a tree decomposition of G[Z] such that every
bag contains e
O(
√
k) vertices of S∗. If we find the sets S and S∗, and the assignment δ, then we
can verify if S∗is indeed N d
G[S] (in particular, we need to verify that if δ(v) < d, then v has no
neighbor outside S∗). Then it is routine to verify that S satisfies the requirements.
Map graphs
A well-studied generalization of planar graphs are map graphs [11], which are
intersection graphs of a finite collection of simply connected and internally disjoint regions in
the plane. One way to describe a map graph is to take a planar graph G and a set N of faces;
the map graph M has vertex set N and two vertices are adjacent if the corresponding two faces
of N share a vertex. Despite the fact that map graphs can have arbitrary large cliques, some of
the algorithmic results for planar graphs can be generalized to map graphs [9–11,18,24,25,28].
Given G and N as above, let G′ be the bipartite planar graph where one side is N, the
other side is the set of vertices of G, and a face in N is adjacent in G′ to all its vertices. Then
x, y ∈N are adjacent in M if and only if they are distance two in the planar graph G′. Using this
equivalence, algorithmic problems on M can be rephrased as problems on the planar graph G′.
In particular, the graph M[S] can be determined from the graph G′[NG′[S]] (and, more generally,

2.1
Duality result
One of the main tools developed by Fomin et al. [27] (and used also by Nederlof [43]) is the
following duality theorem:
Theorem 2.1 (Theorem 9 in [27]). There is a polynomial-time algorithm that given a connected
graph G, a pair s, t ∈V (G) of different vertices, and positive integers p, q, outputs one of the
following structures in G:
• a chain (C1, . . . , Cp) of (s, t)-separators with |Cj| ⩽2q for each j ∈[p]; or
• a sequence (P1, . . . , Pq) of (s, t)-paths such that for every i ∈[q], at most 4p vertices of Pi
lie on other paths Pj, j ∈[q] −{i}.
In the first case, that (C1, . . . , Cp) is a chain of separators means that each Ci separates
{s} ∪C1 ∪. . . ∪Ci−1 from Ci+1 ∪. . . ∪Cp ∪{t}. In the second case, the vertices of Pi −{s, t}
that appear on other paths Pj are called public vertices, whereas all other vertices are private

In this overview, we describe the algorithm of Theorem 1.2 for bounded-genus graphs, which
