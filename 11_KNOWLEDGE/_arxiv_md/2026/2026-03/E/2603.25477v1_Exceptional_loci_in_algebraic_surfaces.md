1. Introduction
We work over C. Let S be a smooth connected projective surface, and let
B ⊂S be a reduced projective curve of the form B = B1 ∪. . . ∪Bn, with
Bi integral curves such that for all i ̸= j every point in Bi ∩Bj is a node of
B. The main focus of this article is Lang’s (algebraic) exceptional set, i.e.
(1)
E(B) := {C ⊂S : C integral curve, 2g(C) −2 + |ν−1
C (C ∩B)| ≤0},
where ν : Cν →C is the normalization and C is projective.
Remark 1.1. When B is ample, as it will be the case for most of our appli-
cations, then C ∩B is not empty. Hence if C ∈E(B) then C is necessarily
rational.
According to Lang and Vojta conjectures (see for example [Lan86, Voj87]),
the union of the curves in E(B) should coincide with the arithmetic excep-
tional set (the largest set containing all but finitely many integral points
for every finite extension of the base field, when S is defined over a number
field), and with the analytic exceptional set (the Zariski closure of the union
of all the images of non constant holomorphic maps C →S ∖B). Moreover,
if the pair (S, B) is of log general type, the set E(B) is conjectured to be
finite.

(1) if n ≥5 then E(B) is empty;

1.1. Brody Hyperbolicity. Theorem 1.2 also provides many examples of
Brody hyperbolic surfaces where the boundary divisor has (at least) three
irreducible components.
Recall that a complex analytic space Y is called Brody hyperbolic if every
holomorphic map C →Y is constant. The Green-Griffiths-Lang Conjecture
predicts that, if X is a complex algebraic variety of log general type, there
exists a proper closed subset Z, such that if f : C →X is a non-constant
holomorphic map, then f(C) ⊂Z. In this case we say that X is Brody hyper-
bolic modulo Z. In particular, X is Brody hyperbolic when X is hyperbolic
modulo Z = ∅.
In our setting the space under consideration is the complement S ∖B,
for S a smooth complex projective surface and B = B1 ∪· · · ∪Bn a reduced
projective curve such that every point of Bi ∩Bj is a node of B, for every
i ̸= j. The irreducible components Bi are called numerically parallel if there
exist ai ∈Z, i = 1, . . . , n, such that aiBi is numerically equivalent to ajBj,
for every i ̸= j.
If n ≥3, the pair (S, B) is of log general type, and the components Bi are
numerically parallel, then [RW25, Theorem 1] of Ru and Wang (extending
work of Noguchi Winkelman and Yamanoi in [NWY08]) implies that the
image of every non constant holomorphic map C →S ∖B is an algebraic
curve. This implies that the analytic exceptional set coincides with the alge-
braic exceptional set [E(B)]. Therefore we obtain the following consequence
of our Theorem 1.2.
Theorem 1.3. Let S and B = ∪n
i=1Bi be as above. Assume that the irre-
ducible components Bi of B are numerically parallel and very ample. The
following hold:
(1) if n ≥5 then S ∖B is Brody hyperbolic;
(2) if n = 4 then S ∖B is Brody hyperbolic modulo [E(B)] and if at
least 3 of the components of B are not primitive then S ∖B is Brody
hyperbolic;
(3) if n = 3 and at least two among the components of B are not prim-
itive then S ∖B is Brody hyperbolic modulo [E(B)], and if all com-
ponents of B are not primitive then S ∖B is Brody hyperbolic.

Remark 4.5. The hypotheses in Theorem 4.4 imply that (S, B) is of log
general type.
This follows from Fujita’s Conjecture for surfaces (a well-
known consequence of results of Reider [Rei88], see [Laz04, Section 10.4]).
Indeed, as at least one component of B is not primitive, we have KS + B =
KS + P4
i=1 Hi with Hi very ample for all i. Now Fujita’s Conjecture states
that KS + 4Hi is very ample, hence 4(KS + B) is also very ample, hence
KS + B is ample.
The same holds for Theorems 1.2 and 1.3, since this argument works if
we replace “4” with n ≥4.
