LINEAR THEORIES OF GLOBAL FIELDS WITH ABSOLUTE VALUES
ARNO FEHM AND PIERRE TOUCHARD
Abstract. We study the theory of a global field k as a k-vector space with a predicate for one
of the absolute values on k. For example, we prove that in this language a global field with an
ultrametric or real archimedean absolute value has a decidable theory, while with a complex
absolute value the theory is always undecidable. We also study the existential theories and
axiomatize k together with predicates for all non-complex absolute values on k simultaneously.
1. Introduction
The first-order theory of a global field (i.e. a finite extension of Q or of Fp(t)) in the language
of rings is always undecidable [Rob59, Rum80], and the decidability of its existential theory is
a famous open problem, see [Koe14]. We therefore investigate the theory of a global field in a
language with only (unary) scalar multiplication instead of (binary) multiplication (the so-called
linear theory, see e.g. [Dri81, Wei88, Stu00, GHW19, BF25]) but with additional arithmetic
structure. Namely, for a field k let Pk denote the set of places of k, i.e. equivalence classes of
nontrivial absolute values on k. Following number theory convention, we denote elements of
Pk by letters like p, and by |.|p a fixed absolute value in the equivalence class. A place p of a
global field is called finite if |.|p is ultrametric, and infinite otherwise; in the latter case, |.|p is
archimedean, and the completion ˆkp of k with respect to |.|p (with corresponding place ˆp) is
either isomorphic to C (p is complex) or R (p is real), cf. [EP05, Chapter 1]. We define on k the
relations
Lp(x, y)
:⇐⇒
|x|p ≤|y|p,
Mp(x, y, z)
:⇐⇒
|xy|p = |z|p.
Our first result deals with the full or existential theory of one place of a global field and its
completion, in a language with unary function symbols ·λ for scalar multiplication with λ ∈k:
Theorem 1.1. Let p ∈Pk be a place of a global field k.
(a) If p is finite, then
Th(k, +, 0, 1, (·λ)λ∈k, Lp, Mp) = Th(ˆkp, +, 0, 1, (·λ)λ∈k, Lˆp, Mˆp),
and this theory is decidable.
(b) If p is real, then
Th(k, +, 0, 1, (·λ)λ∈k, Lp) = Th(ˆkp, +, 0, 1, (·λ)λ∈k, Lˆp),
and this theory is is decidable. However, Th(k, +, 0, 1, (·λ)λ∈k, Lp, Mp) is undecidable, in
particular
Th(k, +, 0, 1, (·λ)λ∈k, Lp, Mp) ̸= Th(ˆkp, +, 0, 1, (·λ)λ∈k, Lˆp, Mˆp),
and Th∃(k, +, 0, 1, (·λ)λ∈k, Lp, Mp) is Turing-equivalent to Th∃(k, +, ·).
(c) If p is complex, then Th(k, +, Lp) is undecidable, in particular
Th(k, +, Lp) ̸= Th(ˆkp, +, Lˆp).
Moreover, if in addition k ∩Ri = {0} (where we view k as a subfield of ˆkp = C), then
Th∃(k, +, 1, (·λ)λ∈k, Lp) is decidable, and otherwise it is Turing-equivalent to Th∃(k∩R, +, ·).
