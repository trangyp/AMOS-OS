L1 ACTIONS AND EMBEDDINGS OF PROPERTY A SPACES
CHRIS GARTLAND, IGNACIO VERGARA, AND TIANYI ZHENG
Abstract. We provide several new characterizations of Property A for bounded degree
graphs.
In particular, we show that (X, d) has Property A if and only if there is a
proper gauge ω such that the Lipschitz free space LF(X, ω ◦d) is isomorphic to ℓ1. As
a consequence, all finitely generated groups with Property A admit proper uniformly
Lipschitz affine actions on ℓ1. Moreover, for groups with finite Nagata dimension, we
obtain actions with compression exponent 1. This result applies to higher rank lattices,
such as SL(3, Z). We also show that a countable discrete group coarsely embeds into L1
if and only if it admits a proper uniformly Lipschitz affine action on a subspace of L1.

1. Introduction
We say that a connected, bounded degree graph X has Property A if for every ε > 0,
there exist S < ∞and a mapping Θ : X →Prob(X) into probability measures on X such
that, for all x ∈X, the measure Θ(x) is supported in the ball BS(x) (where X is equipped
with the unweighted shortest path metric), and for all edges x ∼y ∈X, we have the
total variation distance bound ∥Θ(x) −Θ(y)∥TV < ε. Property A is a coarse invariant
introduced by Yu in [Yu00]. He proved that groups with Property A coarsely embed
into L1 and that groups coarsely embedding into L1 satisfy the coarse Baum–Connes
conjecture1. The definition of Property A given here is not Yu’s original definition but
is (by now) well-known to be equivalent to it. We refer the reader to [Wil09] for further
information on, and many other equivalent characterizations of, this fundamental coarse
invariant.

It was an open question for some time whether the converse to Yu’s theorem is true –
that is, whether the following question had a positive answer.
Question 1. If a connected, bounded degree graph coarsely embeds into L1, must it
have Property A?
It turns out that Question 1 has a negative answer. Arzhantseva, Guentner, and ˇSpakula
constructed in [AGˇS12] a counterexample using a sequence of Z2-homology covers of
graphs. Their example is actually defined as a disjoint union of finite graphs, but it can
be modified in order to obtain an infinite connected graph satisfying the same properties.
Later, Osajda [Osa20, §1.2] constructed a finitely generated group without Property A
but with the Haagerup property (a stronger, equivariant version of coarse embeddability
into L1). In this article, we are able to recover a complete characterization of Property A
in terms of L1-embeddings, in the spirit of Question 1. The idea is to ask for a stronger
type of embedding into L1 out of our bounded degree graph. This is facilitated by bringing
into the fold the Wasserstein-1 and Lipschitz free spaces. The Wasserstein-1 space W1(X)
is (the completion of) the set of finitely supported probability measures on X equipped
with a certain optimal transport metric, see [Vil08, Part I, §6] for the precise definition
and background. The Lipschitz free space LF(X) is (the completion of) the vector space
of finitely supported 0 total mass signed measures on X equipped with the Kantorovich
dual norm ∥µ∥LF = sup{|

Theorem A (Embedding-Theoretic Characterization of Property A). Let X be a con-
nected, bounded degree graph and d the shortest path metric on X. Then the following
are equivalent:
(1) X has Property A.
(2) There exists a proper gauge ω such that LF(X, ω ◦d) is isomorphic to ℓ1.
(3) There exists a metric space Y coarsely containing X such that W1(Y ) biLipschitzly
embeds into L1.

uniformly Lipschitz affine action on a subspace of L1 if and only if Γ coarsely embeds

If Γ is a finitely generated group with finite Nagata dimension (see §2.2.2), a condition
stronger than Property A, we can obtain a more quantitative form of properness. Let
(X, dX) be a metric space. Let us say that Γ admits uniformly Lipschitz actions on X with
compression exponent 1 if for some point x0 ∈X and for all ε > 0, there exists a uniformly
Lipschitz action of Γ on X and C, K < ∞with dX(x0, γ ·x0) ≥C−1dΓ(e, γ)1−ε −K for all
γ ∈Γ. If we can find such an action for ε = 0, we say that the action has undistorted or
quasi-isometrically embedded orbit. There are various constructions of uniformly Lipschitz
actions with undistorted orbits available in the literature when the group Γ exhibits some
tree-like geometry (e.g., [DM23, §6], [Gar25, Theorem E], [Ver24]). It turns out that in
the general setting of groups with finite Nagata dimension, the tree-like geometry can be
obtained by postcomposing the word metric with a gauge of the form ω(t) = t1−ε. This
tree-like geometry follows from results in [Gar25], and we are able to obtain the following
theorem – see Corollary 2.9 for the proof.
Theorem D (Nearly Undistorted Orbit). Let Γ be a finitely generated group. If Γ has
finite Nagata dimension, then Γ admits uniformly Lipschitz affine actions on ℓ1 with
compression exponent 1.
This result has the following notable consequence for higher rank lattices such as
SL(n, Z) (n ≥3).
Corollary E. Let G be a connected, semisimple Lie group of real rank at least 2, and let
Γ be an irreducible lattice in G. Then Γ admits uniformly Lipschitz affine actions on ℓ1
with compression exponent 1.
Proof. By [HP13, Corollary 7.13], the Nagata dimension of G is exactly dim(G). More-
over, by [LMR00, Theorem A], Γ biLipschitzly embeds into G.

Let Γ be a higher rank lattice as in Corollary E. By Oppenheim [Opp23] and de Laat–
de la Salle [dLdlS23], Γ always has a fixed point when acting by uniformly Lipschitz affine
maps on a uniformly convex Banach space, such as Lp for 1 < p < ∞. This should be
contrasted with the situation for isometric affine actions, where a finitely generated group
acts properly on L1 if and only if it acts properly on Lp for p ∈[1, 2] (see [Now15, Theorem
41]). In a way, this says that when relaxing the requirement of an affine action from being
isometric to being uniformly Lipschitz, Lp retains some rigidity for p ∈(1, ∞), while L1
becomes much more flexible.

2.2.3. Separation. Let (X, d) be a metric space. Given a partition P of X, we write P(x)

compact subspace of {0, 1}X×X in the natural way.
We say that X has controlled separation if there is a function ∆: (0, ∞) →[0, ∞),
called the separation control function, such that for every ε > 0, there exists a Radon
probability measure P on the set of ∆(ε)-bounded partitions of X such that, for every
x, y ∈M, PP(P(x) ̸= P(y)) ≤εd(x, y). By a simple compactness argument, it is easy
to see that a function ∆is a separation control function for X if and only if it is a
separation control function for every finite subset of X. If ∆can be chosen to satisfy

2.3. Proper gauges. Following [Kal04], we say that a function ω : [0, ∞) →[0, ∞) is
a gauge if ω is concave and limt→0+ ω(t) = ω(0) = 0. Gauges are necessarily continuous,
and they satisfy a number of useful inequalities such as
• s ≤t =⇒ω(s) ≤ω(t) (nondecreasing)
• ω(s + t) ≤ω(s) + ω(t) (subadditive)
• s ≤1 =⇒ω(st) ≥sω(t)
• s ≥1 =⇒ω(st) ≤sω(t)
We will be using these inequalities throughout the article.
The first two imply that
whenever d is a metric on a set X and ω is a gauge, ω ◦d is also a metric on X (inducing
the same topology as d).
We say that a gauge ω is proper if limt→∞ω(t) = ∞. Equivalently, ω : [0, ∞) →[0, ∞)
is a proper gauge if and only if ω is a concave homeomorphism. If (X, d) is a metric
space d and ω is a proper gauge, then the identity map between (X, d) and (X, ω ◦d) is a
coarse equivalence (because the map and its inverse are both coarse embeddings). Note
