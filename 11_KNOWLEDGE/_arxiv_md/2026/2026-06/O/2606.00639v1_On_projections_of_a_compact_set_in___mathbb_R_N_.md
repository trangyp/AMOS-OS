Introduction
L. Antoine constructed a Cantor set in plane such that all of its projections
coincide with those of a regular hexagon [3, 9, p. 272–273]. Other examples
with similar properties were described by Otto, A. Flores, G. N¨obeling [54];
see also [19], [28, Stat. 11].
For each N ⩾2, K. Borsuk constructed a Cantor set in RN such that its
projection into any (N −1)-plane contains a ball, equivalently, has dimension
(N −1) [9]. See also [6, Thm. 6.2]. Many papers strengthen and extend
Borsuk’s result, see e.g. [46], [33], [41], [35], [34].
In [16], J. Cobb described a Cantor set in R3 such that its projection
into any 2-plane is 1-dimensional, and posed a general question: for given
integers N > m ⩾k > 0, does there exist a Cantor set in RN such that its
projection into any m-plane has topological dimension k ? (We call these sets
briefly (N, m, k)-sets.) The case of m = k is answered positively by Borsuk’s
construction. For the cases (N, m, k = m−1) and (N, m = N −1, k), desired
sets were described in [26] and [4], correspondingly; both of these papers
extend Cobb’s method. Applying facts from the theory of tame and wild
Cantor sets, Frolkina obtained new wide series of (N, N −1, N −1)- and
(N, N −1, N −2)-sets [28], [30].
Definition 1.1. A zero-dimensional compactum X ⊂RN is called tame if
there is a homeomorphism h : RN ∼= RN such that h(X) is a subset of a
straight line. Otherwise, X is called wild.
Any zero-dimensional compactum in plane is tame [2, 75, p. 87–89], see
also [39, Cor. II.3.2, II.3.3] or [49, Chap. 13].

The first wild Cantor sets in R3 were described by L. Antoine in 1920–21
and by P.S. Urysohn in 1922–1923 (independently). Antoine’s construction

Using his (N, N −1, N −1)-set, Borsuk constructed a simple arc in RN

For N = 3 this answers a question of R. Fox. Moreover: analyzing Borsuk’s

Definition 1.2. A subset of RN is called a polyhedron if it is the union of
a finite collection of simplices. A compactum X ⊂RN homeomorphic to
a polyhedron is called tame if there exists a homeomorphism h of RN onto
itself such that h(X) is a polyhedron in RN; otherwise, X is wild.

2.1
Embedding dimension
We need Shtan’ko’s “embedding dimension” theory.
Definition 2.1. A pseudoisotopy of a space Y is a continuous map F :
Y × I →Y such that ft is a homeomorphism Y ∼= Y for each t ∈[0, 1), and
f0 = id. (That is, h1 need not be a homeomorphism.)
Definition 2.2. [59] For a non-empty compactum X ⊂RN, the dimension
of embedding is the smallest integer dem X = k ⩾0 with the property: for
each ε > 0 there is an ε-pseudoisotopy {ft} : RN →RN such that its support
lies in OεX and f1(X) is a k-dimensional polyhedron in RN.
The notation “dem” is an abbreviation for “dimension of embedding”.
We have dim X ⩽dem X. This number is not a topological invariant of X,
however, it is an invariant of the equivalence class of the embedding X ,→RN.
This means that dem X = dem h(X) for any homeomorphism h : RN ∼= RN
[59, Thm. 3]. Briefly, for dem X = k, the embedded compactum X behaves
“like” a k-dimensional polyhedron. This concept was introduced by Stan’ko
with the aim of extending the definition of tame and wild embeddings to
arbitrary compact sets. Previously, definitions of tameness and wildness were
available only for embeddings of polyhedra and zero-dimensional compacta.
For a Cantor set K ⊂RN, tameness is equivalent to the equality dem K =
0 [59, Remark 3], [39, Thm. I.4.2].
The demension of each wild Cantor set in RN equals N −2 [12], [59],
[20, Thm. 1.4], [18, Thm. 3.4.11] (for N = 4, see also [61], [5, p. 5], [56,
Thm. 2.5.1], [24], [25]).
The case of 1-dimensional compacta in R3 is special. In particular, any
embedding of a segment or circle in R3 is tame in the sense of Shtan’ko, i.e.,
its embedding dimension equals 1 [11, Satz 4] .
For details (in particular, other equivalent definitions of the dimension
dem) see [59], [20], [18, 3.4].

Theorems of Szpilrajn and V¨ais¨al¨a
In [51], N¨obeling proved that
dim X ⩽dimH X.
In [63, Thm. 2] (see also [37, Thm.
VII 2]), Szpilrajn strengthened this
showing that for a separable metric space X
if mn+1(X) = 0, then dim X ⩽n.
Moreover, for dim X ⩽n a typical continuous map f ∈C(X, I2n+1) satisfies
mq(f(X)) = 0 for any q > n, hence dimH f(X) ⩽n [63, Thm. 3, Cor. 4],
[37, Thm.VII 5]. The latter fact strengthens the classical Lefschetz–Menger–
N¨obeling–Pontryagin–Tolstowa embedding theorem [37, Thm. V 3]. It also
implies that dim X = inf{dimH Y }, where Y runs over all spaces homeomor-
phic to X [63, (ii), p. 89].
For any compactum X ⊂RN we have (see [18, Thm. 3.4.3] and [43,
6.15])
dim X ⩽dem X ⩽dimH X.
J. V¨ais¨al¨a proved an analogue of Szpilrajn’s theorem for dem. He showed
that for a compactum X ⊂RN the inequality dem X ⩽k is equivalent to
the existence of a homeomorphism f : RN ∼= RN with mk+1(f(X)) = 0.
Moreover, dem X ⩽dimH(f(X)) for each homeomorphism f : RN ∼= RN,
and this becomes an equality for some homeomorphism f [64], [18, Thm.
3.6.1, 3.6.2]. We can also control the size of the isotopy and its support [64,
p. 168, Remark].
