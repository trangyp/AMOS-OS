Abstract
We define and investigate some preliminary properties of an integral of vector
valued functions and its canonically associated indefinite capacity. More precisely,
we adapt the Dunford integral to the Choquet integration setting for Banach-valued
functions.
Keywords : Choquet integral, vector valued functions, Dunford integral, integration with
respect to capacities.
MSC : Primary 28B05, Secondary 46G10, 47H05.
1
Introduction
We try, in this note, to provide meaning for the integral of a Banach valued function
relatively to a capacity. We follow Choquet (1955); Dellacherie (1970), and many others,
integrating real valued functions relatively to capacities and establish a Dunford type
integral for vector valued functions. The intuition is somewhat disturbed by the fact that
an integral with respect to a capacity is not generally additive as long as the underlying
capacity is not. Thus, the integral of a vector valued function with respect to a capacity
cannot be defined canonically as an element of a bidual, like the Dunford integral in case of
measures. Hence, given a measurable space (Ω, A), we set simply, under some additional
conditions making the entities meaningful, the Dunford-Choquet integral of a function f
defined from (Ω, A), endowed with a capacity ν, into a Banach space X on every E ∈A
as a function :
If(E) :
X∗→IR

where, X∗is the dual of X and χE is the characteristic function of E. We establish some
properties showing that If behave well and as an indefinite integral, it defines a capacity
from A to the set of positively homogeneous functions on X∗inheriting some properties
from the considered capacity ν.

Integration of vector valued functions
Let Ωbe an arbitrary set and S a collection of subsets of Ωstable under union and
intersection. A capacity on (Ω, S ) is a set function ν : S →IR+ satisfying ν(∅) = 0. It is
said to be
• monotonic : iff for all A, B ∈S , with A ⊂B, ν(A) ≤ν(B).
• Sub-additive : iff for all A, B ∈S , A ∩B = ∅, ν(A ∪B) ≤ν(A) + ν(B).
• Sub-modular : iff for all A, B ∈S , ν(A ∪B) + ν(A ∩B) ≤ν(A) + ν(B).
• Super-additive : iff for all A, B ∈S , A ∩B = ∅, ν(A ∪B) ≥ν(A) + ν(B).
• Super-modular : iff for all A, B ∈S , ν(A ∪B) + ν(A ∩B) ≥ν(A) + ν(B).
• Continuous from below : iff for every sequence (An)n∈IN of subsets of S such that
An ⊂An+1 for every n ∈IN (increasing) and ∪n∈INAn = A ∈S ,
lim
n→+∞ν(An) = ν(A).
• Continuous from above : iff for every sequence (An)n∈IN of subsets of S such that
An ⊃An+1 for every n ∈IN (decreasing) and ∩n∈INAn = A ∈S , lim
n→+∞ν(An) = ν(A).
• Continuous : iff it is both continuous from above and from below.
For a sequence (An)n∈IN of subsets of S such that An ⊂An+1 for every n ∈IN and
∪n∈INAn = A, we write in the sequel, An ↑A, and for a sequence (An)n∈IN of subsets of S
such that An ⊃An+1 for every n ∈IN and ∩n∈INAn = A, we write An ↓A.

2) The results in (Denneberg, 1994) we used above, like the dominated convergence
theorems, are stated for monotonic capacities defined on the set P(Ω) of all subsets
of Ω. It is clear that theses results are still valid in our setting, since every monotonic
capacity on A ⊂P(Ω) extends, by the Zorn’s lemma to a monotonic capacity on
P(Ω) and obviously the corresponding integrals of A-measurable functions coincides.
To see how to obtain such extensions, consider a monotonic capacity ν on A and
set C = {(µ, Σ) : A ⊂Σ, µ monotonic on Σ and µ|A ≡ν}. Consider the following
ordering on C :
(µ1, Σ1) ≤(µ2, Σ2) ⇔Σ1 ⊂Σ2 and µ2|Σ1 ≡µ1.
This makes C a directed set. Consider a chain (µα, Σα) in C and set Σ = ∪αΣα and
define µ on Σ by µ|Σα = µα. Obviously (µ, Σ) ∈C . Hence, every chain in C has
an upper bound in C . Zorn’s Lemma guarantees that C has a maximal element,
denote it again (µ, Σ). Necessarily, Σ = P(A), otherwise, let A ∈P(Ω) \ Σ and set
¯µ(A) = inf{µ(E) : A ⊂E and E ∈Σ} and ¯µ ≡µ on Σ. Since, Ω∈A ⊂Σ, ¯µ(A) is
well defined. It is easy to see that (¯µ, Σ ∪{A}) ∈C and then (¯µ, Σ ∪{A}) is strictly
greater than (µ, Σ) contradicting the maximality of the last element and proves the
existence of the needed extension.
