Abstract
A static alpha eigenvalue capability was implemented in a modified version of the open-source
Monte Carlo radiation transport code OpenMC and validated against Rossi-α measurements
from 21 delayed-critical benchmark experiments and 33 subcritical configurations spanning
fast, intermediate, and thermal systems with 233U, HEU, IEU, LEU, and plutonium fuels.
The effective delayed neutron fraction was calculated using the k-prompt method, and the
prompt neutron lifetime was calculated using the iterated fission probability method, both
evaluated within the standard k-eigenvalue power iteration. The delayed-critical alpha eigen-
value was calculated from these quantities using the point kinetics equation αdc = −βeff/ℓp.
Agreement was generally within 10% for fast metal systems and within 5% for thermal
solution systems.
Subcritical extrapolation studies derived from the SHE-8 and STACY
benchmark families show that αdc remains stable as the system is driven subcritical.
Keywords:
OpenMC, Monte Carlo, alpha eigenvalue, Rossi-α, iterated fission probability
1. Introduction
The Rossi-α parameter characterizes the exponential rate of change in the prompt neu-
tron population of a fissioning system near delayed critical [1]. It is the prompt neutron
decay constant, equivalently the fundamental-mode alpha eigenvalue of the time-dependent
transport equation. Because it depends on both the effective delayed neutron fraction and
the prompt neutron lifetime, it is particularly sensitive to the energy spectrum of the system
and serves as a useful validation observable for Monte Carlo radiation transport calculations.
In this work, two forms of the alpha eigenvalue are distinguished. The delayed-critical
alpha eigenvalue, αdc = −βeff/ℓp, is the value at exact delayed critical regardless of the
system’s actual reactivity state, and is the quantity measured in Rossi-α experiments. The
static alpha eigenvalue, α = (kp −1)/ℓp, includes the effect of the system’s actual reactivity
and equals αdc only when keff = 1.
Kiedrowski et al. [2] implemented adjoint-weighted kinetics parameter tallies in MCNP5
using the iterated fission probability (IFP) method. Mosteller and Kiedrowski [3] subse-
quently developed a 13-benchmark Rossi-α validation suite that has become a standard

2. Theory and Implementation
The static alpha eigenvalue capability was implemented in a fork of OpenMC [7]. The
modified code is publicly available.1
The implementation calculates the prompt neutron
lifetime ℓp and the effective delayed neutron fraction βeff within the standard k-eigenvalue
power iteration, then calculates the alpha eigenvalue directly from these two quantities using
the point kinetics approximation. The prompt neutron generation time Λp is also calculated
for reporting purposes but is not used in the alpha eigenvalue calculation itself.
The point kinetics approximation assumes that the neutron flux is separable into spatial
and temporal components:
Ψ(r, ˆΩ, E, t) = ψ(r, ˆΩ, E) T(t),
(1)
where the temporal amplitude function takes the form T(t) = T(0) eαt.
Two quantities
are required to evaluate the prompt neutron decay constant: the effective delayed neutron
fraction βeff and the prompt neutron lifetime ℓp.
The effective delayed neutron fraction is calculated using the k-prompt method [8]:
βeff = keff −kp
keff
(2)
where keff is the effective multiplication factor that counts all fission neutrons and kp is the
prompt multiplication factor that counts only prompt fission neutrons. Both quantities are
tallied each active generation of the k-eigenvalue simulation, and the uncertainty on βeff is
propagated from the uncertainties on both keff and kp. The prompt multiplication factor is
equivalently
kp = keff(1 −βeff)
(3)
The prompt neutron lifetime ℓp is the mean time between a prompt neutron’s birth
and its next interaction that either produces a fission or removes it from the system. It is
calculated using the iterated fission probability (IFP) method [2, 9], which provides adjoint-
weighted kinetics parameters without requiring an explicit solution of the adjoint transport
equation. Each fission neutron carries a rolling genealogy window of NIFP = 10 generations,

4. Results
4.1. Alpha Eigenvalue Comparison
The comparison of measured and calculated αdc values is presented in Table 4 and Fig. 1.
For the six STACY thermal solution benchmarks, C/E ratios range from 0.988 to 0.996.
SHE-8 agrees to within 0.2% of the measured value. Among the fast metal systems, most
benchmarks agree within 5-10%, comparable to results reported by Mosteller [3] and Leppä-
nen [4]. The three Zeus benchmarks remain outliers, as discussed in Section 4.3.
For benchmarks whose calculated keff is close to unity, αdc and αstatic are nearly identical.
When keff departs from unity, the two diverge: αstatic reflects the actual reactivity state
of the model, while αdc projects to the delayed-critical condition regardless of the model’s
reactivity.

4.3. Note on the Zeus Benchmarks
The three Zeus benchmarks (Zeus-1, Zeus-5, and Zeus-6) are consistent outliers in the
Rossi-α validation suite. All three are copper-reflected HEU systems that were assembled
on the Comet vertical lift machine at the National Criticality Experiments Research Center.
Zeus-5 shows the largest discrepancy: the measured αdc is (−7.960 ± 0.080) × 104 s−1, while
the OpenMC value from this work is (−10.507±0.149)×104 s−1, consistent with Mosteller’s
MCNP value of (−10.760±0.070)×104 s−1. Zeus-1 and Zeus-6 show smaller but qualitatively
similar overpredictions. The source of this discrepancy is not well understood.
One observation is that the OpenMC model of Zeus-5 calculates keff = 1.00200, slightly
supercritical, and the corresponding αstatic at this reactivity state is (−7.482±0.182)×104 s−1,
which is substantially closer to the measured value than αdc. This pattern is also present,
to a lesser degree, in Zeus-1 and Zeus-6.
The recent CERBERUS experiment campaign [14] provides further context. CERBERUS
used the same HEU fuel plates and copper reflector as the original Zeus experiments, reconfig-
ured on the Comet vertical lift machine. Kostelac et al. measured the prompt neutron decay
constant via the cross power spectral density (CPSD) method using in-core 3He proportional
counters and ex-core organic scintillators at delayed critical and four subcritical states. The
extrapolated αdc values were −53,863±632 s−1 (3He) and −51,882±3,071 s−1 (scintillators),
while MCNP KOPTS with ENDF/B-VIII.0 yielded −62,544 ± 177 s−1, an overprediction of
approximately 18%. During the 3.5-hour delayed-critical measurement, operator interven-
tion was required multiple times to stabilize the diverging neutron population by adjusting
the platen position in increments of approximately 1 mil (0.0254 mm) [14].

5. Conclusions
Alpha eigenvalue and beta-effective calculations were performed for 21 delayed-critical
benchmark experiments and 33 subcritical configurations using a modified version of the
open-source Monte Carlo radiation transport code OpenMC. Beta-effective was calculated
using the k-prompt method, and the prompt neutron lifetime was calculated using the iter-
ated fission probability method. The delayed-critical alpha eigenvalue was calculated from
these quantities using the point kinetics approximation.
The calculated αdc values agree with experimentally measured Rossi-α values to within
1–5% for the six STACY thermal solution benchmarks, with C/E ratios ranging from 0.988
to 0.996. For fast metal systems such as Godiva, Big Ten, Jezebel, and the Flattop se-
ries, agreement is generally within 5–10%, comparable to previously published results from
MCNP5 and Serpent 2. The three Zeus copper-reflected benchmarks remain outliers, with
Zeus-5 showing a C/E of 1.32 for αdc.
Subcritical extrapolation studies for SHE-8 and the STACY series confirm that the IFP-
based kinetics parameters track the fundamental mode characteristics of the fissile material
rather than the boundary conditions. In both cases, αdc remains approximately constant as
the system is driven subcritical, while αstatic diverges linearly with subcriticality as expected
from the point kinetics approximation. For the STACY series, the calculated αstatic values
are in good agreement with the subcritical prompt neutron decay constants measured by
Tonoike et al. [12] using the pulsed neutron source method.
Comparison with previously published results from MCNP5, Serpent 2, and OpenMC(TD)
shows broad consistency across all four codes, with remaining differences attributable to dif-
ferences in nuclear data libraries and in the methods used to calculate the underlying kinetics
parameters.
