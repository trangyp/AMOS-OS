Abstract. We present a class of pairs of subsets of Rd for which the Fourier transform, when
restricted to these subsets, is an isometric isomorphism, and thus the Plancherel identity is satisfied.
The sets are invariant under translations by dual full-rank lattices.

We say that Ωtiles Rd by translations if there exists a set T ⊂Rd such that the translations
{Ω+ t : t ∈T } form a partition of Rd up to measure zero. The set T is then called a tiling set for
Ω, and we say that Ωtiles Rd with the set T .
If only the condition that the sets Ω+ t, t ∈T are mutually disjoint (up to measure zero) is
satisfied, (so the union ∪t(Ω+ t) is not necessarily the whole space Rd), then we say that Ωpacks
with T .
Fuglede then formulated his conjecture:
Conjecture 1.2. [Fuglede’s Conjecture] A measurable subset Ω⊂Rd of finite Lebesgue measure
is spectral if and only if it tiles Rd by translations.
In the same paper, Fuglede proved that his conjecture is true when the spectrum or the tiling set
is a lattice in Rd.
Theorem 1.3. Let Ωbe a measurable subset of Rd of finite measure and let A be some invertible
d × d matrix. Then Ωtiles Rd with the lattice AZd if and only if Ωhas spectrum the dual lattice
(AT )−1Zd.
The conjecture was later shown to be false in dimensions d ≥3 [Tao04, FMM06], but it is true
for convex domains [LM22].
In [Ped87], Steen Pedersen extended Fuglede’s result by removing both the regularity condition
and the finite-measure assumption. Naturally, the definition of a spectral set had to be adapted for
infinite-measure domains (since eλ is not square-integrable in that case).

4. Periodicity
According to [New77], if a finite subset Z tiles Z by translations, then it is periodic. We will use
this well known result to prove some invariance properties of subsets of R which tile with a finite
set.
Theorem 4.1. If a measurable subset Ωof R tiles R with a finite subset B of Z, then Ωis periodic,
i.e., Ω+ p = Ω, for some positive integer p.
Proof. Fix t ∈R. Denote
Tt = {n ∈Z : t + n ∈Ω}.
We claim that, for a.e. t ∈R, B ⊕Tt = Z.
Let n ∈Z. Excluding a set of measure zero of values of t, there is a unique b ∈B, such that
t+n ∈Ω+b. This implies that t+(n−b) ∈Ω, which means that n−b ∈Tt and n = b+(n−b) ∈B+Tt.
Thus B + Tt = Z.
If n = b′ + k′ with b′ ∈B and k′ ∈Tt then t + k′ ∈Ωand therefore t + n = t + k′ + b′ ∈Ω+ b′.
But we already have that t + n ∈Ω+ b, and therefore b = b′ hence also k′ = n −b′ = n −b. This
shows that B ⊕Tt = Z.
By [New77], Tt has a period Pt, bounded by 2max B−min B =: M (see also [CM99]). Denote by
p1, p2, . . . , pr all the numbers that appear as period Pt for any one of the sets Tt, t ∈R. Since these
numbers are all less than M, we have only finitely many possibilities. Take p = p1p2 . . . pr; then p
