Abstract. This paper extends a previous work in which the rank-2 co-Higgs bundles on a Hopf surface are
classified based on the data of the underlying vector bundle. The aim of the paper is to study the Poisson
3-folds that can be constructed from these co-Higgs bundles by describing their symplectic leaves.
1. Introduction
Poisson structures are geometric objects arising from the ideas of Hamiltonian mechanics where, using a
Poisson structure on the phase space, one can recover evolution equations for a system from the conserved
Hamiltonian, a function typically representing the total energy of the system. A Poisson structure on a
manifold also naturally gives rise to an even-dimensional foliation of the manifold into symplectic leaves
where the restriction of the Poisson structure is invertible. The dynamics given by a Hamiltonian on this
Poisson manifold are constrained to the symplectic leaves, so understanding this foliation gives insight into
conserved quantities of such dynamics. In this paper, we will investigate these symplectic foliations on a
particular family of Poisson manifolds: P1-bundles p : Y →X over a compact complex manifold X whose
fibres p−1(x) are co-isotropic. In other words, we look at Poisson structures on Y such that for any function
f ∈OX, the Hamiltonian flow with respect to p∗(f) preserves fibres of p. The Poisson structures of this type
can be studied in terms of rank-2 trace-free co-Higgs bundles on the base manifold X [Pol97]. This problem
has been studied in detail for the case when X is curve [BM05], leaving the case where X is a surface as the
next natural setting for this problem. Based on [Ray14], we expect the more interesting cases to occur for
X of Kodaira dimension −∞. In this paper, we will focus on the case where X is a Hopf surface as these
surfaces have some advantages in computational tractability over other Kodaira dimension −∞surfaces.
In Section 2 we discuss this correspondence between co-Higgs bundles and associated Poisson structures
in more detail, and describe a canonical factoring for a rank-2 trace-free co-Higgs bundle which will be used
for later results.
In Sections 3 and 4 we recall the classification of primary Hopf surfaces and the structure of flat bundles
of rank 1 and 2 on each class of Hopf surface following [Mal91, Mal93]. We provide additional details both
to aid in later computations and to correct some minor errors from the original referenced articles.

primary Hopf surface using our factorization from Section 2. In this section we also show that any non-zero

2. Co-Higgs bundles and Poisson structures
2.1. Complex Poisson manifolds. A Poisson structure on a complex manifold X consists of a Lie bracket
{·, ·} : OX × OX →OX satisfying the Leibniz rule {fg, h} = f{g, h} + g{f, h} for any open set U ⊆X
and functions f, g, h ∈OX(U). A Poisson structure can also be represented as a bivector π ∈H0(X, ∧2TX)
so that π(df, dg) = {f, g}. Conversely, a bivector σ corresponds to a Poisson structure if and only if the
Schouten bracket [σ, σ] ∈H0(X, ∧3TX) vanishes.
Given a Poisson bivector π, we can associate to any holomorphic function f a Hamiltonian vector field
Hf := ιdfπ. At any point x, the flows of the Hamiltonian vector fields Hf for all functions f defined near
x generate an immersed complex subvariety S so that π|S is invertible when viewed as a map from T ∗
X to
TX. We call S a symplectic leaf of π, since the inverse of π|S is a holomorphic symplectic form on S. These
symplectic leaves give a foliation of X, called the symplectic foliation associated to π.
2.2. Co-Higgs bundles. Let X be a compact complex manifold. A co-Higgs bundle on X consists of a pair
(E, Φ), where E is a holomorphic vector bundle on X, and Φ is a holomorphic section of End(E) ⊗TX called
the Higgs field so that Φ ∧Φ = 0 where the wedge product acts as the commutator on the End(E) factor
and as the vector field wedge product on the TX factor. Using the decomposition End(E) = OX ⊕End0(E)
into the identity and trace-free components, we can write any Higgs field Φ as IdE ⊗ξ + Φ0, where ξ is
a holomorphic vector field and Φ0 ∈H0(X, End0(E) ⊗TX). If ξ = 0, we say that the co-Higgs bundle is
trace-free. As shown in [Pol97] and [Ray11], to any rank-2 trace-free Higgs bundle (E, Φ) we can associate
a Poisson manifold (P(E), σΦ), where the Poisson structure σΦ is constructed from the bivector σΦ := Φ ∈

3. Hopf surfaces
A (primary) Hopf surface is a compact complex surface homeomorphic to S1 ×S3. A general Hopf surface
is described by four parameters a, b, λ ∈C, r ∈Z>0 with 0 < |a| ≤|b| < 1 and (a −br)λ = 0 as the quotient
of W = C2 \ {0} by the group of automorphisms generated by φ : (x, y) 7→(ax + λyr, by). We can separate
Hopf surfaces into five groups, each with different characteristic behaviour [Mal91]:
(1) (Classical) λ = 0 and a = b.

(2) (Resonant) λ = 0, r > 1, and a = br.
(3) (Hyper-resonant) λ = 0, and there are integers r1 > 1, r2 > 1 so that ar1 = br2 but ak1 ̸= bk2 for
integers k1, k2 when 1 ≤k1 < r1, 1 ≤k2 < r2.
(4) (Generic) λ = 0, ak1 ̸= bk2 for any positive integers k1, k2.
(5) (Exceptional) λ ̸= 0 and a = br.
We say that a Hopf surface is diagonal if it has λ = 0, in which case it belongs to one of the families (1)-(4).
Remark 3.1. If X(a,b,λ,r), X(a′,b′,λ′,r′) are two Hopf surfaces defined by parameters (a, b, λ, r) and (a′, b′, λ′, r′),
respectively, then X ≃X′ if and only if there is an isomorphism σ : W →W so that φ ◦σ = σ ◦φ′, where
φ = (x, y) 7→(ax + λyr, by) and φ′ = (x, y) 7→(a′x + λ′yr′, b′y).
Using this fact, we can easily check that two diagonal Hopf surfaces X(a,b,0,r) and X(a′,b′,0,r′) are isomorphic
if and only if {a, b} = {a′, b′}. We also get that the Hopf surface X(br,b,λ,r) is isomorphic to X(br,b,1,r) whenever
λ ̸= 0 using the map σ : (x, y) 7→(x, ty) for some t satisfying tr = λ.
Definition 3.2. Let X be a complex manifold with fundamental group Γ and universal cover γ : Y →X.
An r-dimensional factor of automorphy for X is a holomorphic map A : Γ × Y →GL(r, OY ) satisfying
A(λµ, y) = A(λ, µ · y)A(µ, y) for any λ, µ ∈Γ and y ∈Y , where µ · y is the action of µ by the corresponding
deck transformation. The vector bundle EA represented by a factor of automorphy A is the quotient of the
trivial vector bundle Y × Cr by the equivalence relation (y, v) ∼(λ · y, A(λ, y)v) for all λ ∈Γ.
Remark 3.3. For a Hopf surface X, which has universal cover W = C2 \ {0} and the fundamental group Z,
any factor of automorphy A : Z × W →GL(2, OW ) is completely determined by A|{1}×W . In the sequel we
will write factors of automorphy for X as sections of GL(r, OW ).
