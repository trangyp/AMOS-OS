Abstract
The Loewner order on Hermitian matrices is a partial order that com-
pares matrices in terms of positive semidefiniteness. The Loewner order
plays a key role in many fields such as optimization, numerical linear
algebra, control theory, operator theory, and quantum information.
A
fundamental difficulty is that two or more Hermitian matrices do not nec-
essarily have a unique minimal upper bound (or maximal lower bound).
In this paper, we propose an iterative method to exactly compute a min-
imal upper bound for any finite collection of n × n Hermitian matrices.
It is shown that the algorithm terminates in at most n iterations. The
exactitude of the algorithm is proved using standard results from finite-
dimensional linear algebra. A self-contained proof of an algebraic char-
acterization of minimality originally explored by Stott is provided. We
illustrate the algorithm in examples and also provide an implementation
of the algorithm in Python.

Introduction
The notion of Hermitian matrices is a fundamental topic in mathematics and
physics named after French mathematician Charles Hermite. One of the most
important properties of Hermitian matrices is that all eigenvalues are real num-
bers. As a consequence, the concept of positive (semi)definiteness is well-defined
for Hermitian matrices. Their structure is exploited in different fields of ap-
plied mathematics such as semidefinite programming [20], Cholesky factorization
[9, 15], the conjugate gradient method [11], preconditioning [2], and covariance
matrices [1, Chapter 3] to name a few. To compare Hermitian matrices, the
Loewner order may be used. A matrix B is said to be greater than or equal
to a matrix A if and only if B −A is positive semidefinite. The Loewner order
is a partial order but not a total order (see [3, 4, 5] for more details on matrix
partial orderings). This means that some pairs of matrices are not comparable.
It was introduced in 1934 by Charles Loewner in [14]. The paper investigates
matrix monotone functions–a type of matrix functions preserving the Loewner
order. We may think of matrix monotone functions and the Loewner order as
a generalization of increasing real-valued functions to the matrix setting. Like-
wise, the corresponding notion of a matrix convex function is equally important.
For thorough treatments of these topics, we refer the reader to [6, Chapter V]
and [17].
Note that not all authors refer to the Loewner order by Loewner’s name. For
example, the well-known optimization text [8] simply refers to the generalized
inequality associated to the positive semidefinite cone, or even simply “the usual
matrix inequality”.
Basic properties of the Loewner order are described in [6, 7]. The Loewner
order is a partial order that is not total, and so one might hope that this order
has lattice properties such as the existence of unique least upper bounds (or
greatest lower bounds). Kadison [13] proved that this is as far from being true
as possible. Two matrices have a unique least upper bound (or greatest upper
bound) if and only if they are comparable, which Kadison called the “anti-
lattice” property. (Moreover, Kadison proves that this is true even for bounded
operators on any infinite dimensional Hilbert space. In fact, the Loewner order
is closely connected to the study of operator algebras, and Sherman [16] showed
that the lattice properties always fail in any noncommutative operator algebra.)
While finding a unique minimum upper bound is usually impossible, there
always exist minimal upper bounds, which have the property that there is no
strictly smaller upper bound in the Loewner order. This might be viewed as
a matricial analogue of Pareto optimality, which appears frequently in vector
optimization (cf.
[8, Section 4.7]).
In [18, Theorem 1.15], Stott provides a
geometric, kernel-based certificate for minimality in the Loewner order. Specif-
ically, if a real symmetric matrix B is an upper bound for the set of real n × n
symmetric matrices {A1, . . . , Ak}, then B is a minimal upper bound if and only

The main goal of this paper is to extend the work contained in [18] by devel-

of k Hermitian matrices of any finite size n × n. It provides a simple iterative
method that outputs a minimal upper bound for a given non-empty finite set of
Hermitian matrices using any initial upper bound matrix as an input, and the
minimal upper bound obtained is guaranteed to be less than the initial upper
bound matrix in the Loewner order. It is shown that the algorithm returns an
exact minimal upper bound matrix with at most n iterations. A pseudo-code
of the algorithm is introduced (see Algorithm 3.5) and the algorithm is imple-

to provide a simple computational method that returns an exact minimal upper
bound for any (non-empty) finite set of finite-dimensional Hermitian matrices.
Note that the algorithm can also be used to compute maximal lower bounds for
a finite set of Hermitian matrices, by simply negating all matrices involved. Pos-
sible applications where the algorithm may be valuable include finding a good
starting point in semidefinite programming optimization problems, or identify-
ing the outer Loewner-John ellipsoid (see [10]). More potential applications are
discussed in the conclusion.

Definition 2.1 (Positive definite and positive semidefinite). [12, Section 7.1]
Let A ∈Mn(F)h be a Hermitian matrix. We say that A is positive definite,
written A > 0, if
⟨Av, v⟩> 0
for all nonzero v ∈Fn.
We say that A is positive semidefinite, written A ≥0, if
⟨Av, v⟩≥0
for all v ∈Fn.
Frequently, we will use the standard fact that a positive semidefinite matrix
A has a matrix square root A1/2, which is the unique positive semidefinite
matrix satisfying A1/2A1/2 = A, and therefore also that ⟨Av, v⟩= ∥A1/2v∥2 for
all v ∈Fn. If A is positive definite, and therefore invertible, A−1/2 denotes the
square root of the inverse matrix A−1.
Definition 2.2 (Loewner order). [12, Def. 7.7.1] For two Hermitian matrices
A, B ∈Mn(F)h, we say that A is less than or equal to B in the Loewner order
if B −A is positive semidefinite. In this case, we write A ≤B or B ≥A.
From the definition of positive semidefiniteness, it follows that A ≤B if and
only if ⟨Av, v⟩≤⟨Bv, v⟩for all v ∈Fn. The following lemma is used in Section

Lemma 2.3. [12, Section 7.7] Let P, Q ∈Mn(F)h. If 0 ≤P ≤Q, then
null(Q) ⊆null(P).
Proof. Let v ∈null(Q). Then
0 = ⟨0v, v⟩≤⟨Pv, v⟩≤⟨Qv, v⟩= 0.

When dealing with real positive semidefinite matrices, the Loewner order
has a simple geometric interpretation. The ellipsoid associated to A is denoted
by EA and defined by
EA = {v ∈Rn | ⟨Av, v⟩≤1}.
The Loewner order may be described in terms of the ellipsoids EA and EB, by
the equivalency
A ≤B ⇐⇒EA ⊇EB.
Indeed, suppose that A, B ∈Mn(R)h are positive semidefinite. Then we
have
A ≤B ⇐⇒⟨Av, v⟩≤⟨Bv, v⟩
for all v ∈Rn.
Since ⟨Av, v⟩and ⟨Bv, v⟩are nonnegative, a rescaling argument shows that this
is equivalent to
⟨Bv, v⟩≤1 =⇒⟨Av, v⟩≤1
for all v ∈Rn,
i.e. EB ⊆EA.
When A ∈Mn(R)h is positive semidefinite but not positive definite, the
ellipsoid EA is degenerate meaning that the set is unbounded. Indeed, suppose
λ = 0 is an eigenvalue of A with unit eigenvector u. For any t ∈R, consider the
vector vt = tu. We obtain
⟨Avt, vt⟩= t2⟨Au, u⟩= 0 ≤1.

The semi-axes are aligned with the corresponding eigenvectors of λi.

Main Results
In this section, we introduce an algorithm (Algorithm 3.4) that outputs an exact
minimal upper bound for any (non-empty) finite set of n×n Hermitian matrices.
The algorithm takes as input any upper bound for the finite set. Theorem 3.7
represents one of the main results of this paper. It shows that the algorithm
ends in at most n iterations. Before introducing the algorithm, we introduce
the theoretical results needed to show the exactness of the algorithm.

Conclusion
In this paper, we studied the problem of computing a minimal upper bound
for a non-empty finite set of Hermitian matrices under the Loewner order. The
main contribution of this paper is the development of an an iterative method
(Algorithm 3.4) that exactly computes a minimal upper bound for any finite set
of n × n Hermitian matrices {A1, . . . , Ak} starting from any given upper bound
B0. It is proved that the algorithm terminates in at most n steps (Theorem 3.7),
and more precisely in exactly m = n−dim(E0) steps, where E0 denotes the sum
of the null spaces of the initial differences B0 −Ai, i ∈{1, . . . , k}. We also gave
a self-contained proof of Stott’s algebraic characterization of minimality in the
Loewner order, which serves as the termination criterion of the algorithm. The
algorithm is illustrated on examples, and a Python implementation is available
on GitHub (GitHub Repository).
Many future research directions have emerged from this work. It remains
unknown whether every minimal upper bound for a given non-empty finite set
of Hermitian matrices can be obtained by some sequence of direction vector
choices e in Algorithm 3.4. Another direction to explore is the usefulness of
the algorithm in semidefinite programming [20]. It is unclear whether mini-
mizing a convex objective, such as the trace or the log-determinant, over the
set of upper bounds produces a minimal upper bound in the Loewner sense, or
yields a distinguished minimal upper bound with additional optimality proper-
ties. Semidefinite programming duality theory may also provide new certificates
of minimality. The algorithm developed in this paper might also be valuable
to generate a high-quality feasible starting matrix before using a semidefinite
programming solver. Numerical experiments may be able to identify situations
leading to significant performance gain.
The theoretical results in this paper also lead naturally to some infinitary
questions. For example, can the algorithm be modified to converge to a minimal
upper bound for an infinite set of Hermitian matrices? For example, it is possible
to prove the existence of minimal upper bounds for any compact subset of
Mn(F)h. Another natural direction is to investigate minimality conditions such
as Theorem 3.3 in the setting of bounded operators on an infinite dimensional
Hilbert space.
The connection to the Loewner-John ellipsoid [10] might also be worth ex-
ploring. While Algorithm 3.4 produces an enclosed ellipsoid in at most n steps,
it remains open whether a judicious choice of vector e at each iteration can
recover the maximum-volume enclosed ellipsoid (the inner Loewner-John ellip-
soid) exactly. Exploring applications in control theory and quantum information
where the Loewner order governs comparisons of Lyapunov functions and den-
sity matrices, are other possible avenues. Finally, a rigorous numerical analysis
of the algorithm is an obvious future research direction.
