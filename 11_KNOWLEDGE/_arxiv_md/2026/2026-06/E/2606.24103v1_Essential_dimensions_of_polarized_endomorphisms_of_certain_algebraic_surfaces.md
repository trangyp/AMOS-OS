ESSENTIAL DIMENSIONS OF POLARIZED ENDOMORPHISMS OF
CERTAIN ALGEBRAIC SURFACES
QIANLI FANG, YUJIE LUO AND DE-QI ZHANG
Abstract. Let f : X →X be a polarized endomorphism of a smooth projective surface which
is birationally ruled. We answer a question of Koll´ar and Zhuang, in the affirmative, on the
incompressibility of f, under the assumption that f is Galois and an explicit lower bound of
deg f depending only on X. We also give examples showing the optimality of such a lower
bound.

1. Introduction
Throughout this article, we work over an algebraically closed field k of characteristic zero.
The essential dimension was first introduced in a modern context by Buhler and Reichstein
[3, 4]. It has been studied for decades. We refer the readers to Reichstein’s ICM talk for more
on its history [20]. To be precise, the essential dimension of a generically finite (dominant
rational) map f : X 99K Y , denoted by ed(f), is the smallest integer d such that f is birational
to the pull-back of a map of varieties of dimension d (cf. [3, 5, 12]). A generically finite map
f : X 99K Y is called incompressible if its essential dimension is equal to its maximum possible
value dim(X) [3, 5, 12].
Recall that an endomorphism f of a projective variety X is polarized if there is an ample
divisor H such that f∗H ∼qH for some positive integer q > 1. In this case, deg f = qdim X

We say that f : X = X1 →X = X2 is Galois if the function field extension K(X1)/K(X2)
is Galois with Galois group G and G acts biregularly on X1 (and hence X2 = X1/G).
Theorem 1.1. Let X be a smooth projective rational surface, and let f : X →X be a q-polarized
endomorphism such that q > 2. Then the following assertions hold.
(1) Suppose X is not isomorphic to P1 × P1, and f is Galois. Then f is incompressible.
(2) Suppose X = P1 × P1, f is Galois and f preserves both fibrations of X (this holds for
f2 if f2 is Galois). Then f is incompressible.
Remark 1.2. By Example 3.3, in Theorem 1.1(2), the condition that f preserves both fibrations
when X = P1 × P1, is necessary.
Suppose X is a smooth projective surface and f : X →X is a polarized endomorphism. If X
is birationally ruled and irrational, then X is a relatively minimal ruled surface over an elliptic
curve (see [18, Theorem 1]). In fact, S. W. Zhang has a complete classification of algebraic
surfaces that admit polarized endomorphisms [24, Proposition 2.3.1].
Theorem 1.3. Let X be an irrational birationally ruled smooth surface, and f a q-polarized
endomorphism of X with q > 2. We may write X = ProjC(V ), with C an elliptic curve and V
a rank two vector bundle on C. Assume that f is Galois. Then the following assertions hold.
(1) Suppose V is indecomposable. Then f is incompressible.
(2) Suppose V is decomposable. Then there exists a positive integer N depending only on
X such that if q > N (i.e., deg f > N2), f is incompressible.

2. Preliminary results
We adopt the standard notation from [7], [9], [13], [10] and [17]. We begin with some notation
for the ramification divisors and group actions.
2.1. Ramification divisors and group actions.
Definition 2.1. (1) Let f : X →Y be a finite surjective morphism between Q-factorial normal
varieties. For canonical divisors (regarded as integral Weil divisors), we have the ramification
divisor formula:
KX = f∗KY + Rf
where Rf is an effective Weil integral divisor, called the ramification divisor of f. Write Rf =
P(ri −1)Ri for some distinct prime divisors Ri and some positive integers ri. Then ri is called
the ramification index of f along Ri.
(2) Let G be a finite group acting faithfully on a variety X. For each element g ∈G, define
the (pointwise) fixed locus of g as
Fix(g) := {x ∈X | g(x) = x}.
Note that Fix(g) is Zariski closed in X. Let f : X →X/G be the quotient morphism which
is finite. Then the ramification divisor Rf has support equal to the union of codimension one
components Ri of Fix(G). Moreover, we define the (pointwise) stabilizer as
GRi = {g ∈G | g(x) = x for each x ∈Ri}.
Then the ramification index ri of f along Ri is equal to |GRi|. In particular, ri divides |G|.
Definition 2.2. Let V be a finite-dimensional vector space over k.
A nontrivial element
σ ∈GL(V ) of finite order is called a pseudo-reflection if it fixes a hyperplane in V pointwise.
A finite subgroup Γ ⊂GL(V ) is called a pseudo-reflection group if it is generated by pseudo-
reflections.
Theorem 2.3. ([21, Corollary 1.8]) Let X be a smooth affine variety with a faithful action by
a finite group G. Let P be a point in X fixed by G. Then G is generated by pseudo-reflections
if and only if X/G is smooth at the image of P.
We frequently use the following lemma due to H. Kraft and I. Stampfli [11] whose proof works
for any quasi-projective variety.

2.2. Essential dimensions. We start with the definition of the essential dimension of a gener-
ically finite dominant rational map.
Definition 2.7 (cf. [3, Definition 2.1]). Let E/F be a finite field extension over a base field
k. We say that E/F is defined over a subfield F0 of F if there exists an extension E0/F0 over
k such that [E0 : F0] = [E : F], E0 ⊆E and E0F = E. The essential dimension of E/F,
which we will usually abbreviate as edk(E/F) (or ed(E/F) when k is clear from the context),
is the minimal value of trdegk(F0) as F0 ranges over all fields for which E/F is defined over F0.
The essential dimension of a generically finite dominant rational map f : X 99K Y , denoted
by ed(f), is defined as the essential dimension of the corresponding function field extension
edk(K(X)/K(Y )).
We collect the following facts on essential dimensions defined above (see [14, Lemma 2.2]).
Lemma 2.8. We fix the base field k of characteristic zero.
(1) If two generically finite dominant rational maps are birationally equivalent, then they
have the same essential dimension. In particular, the essential dimension of a birational
map is zero.
(2) Let f : X 99K Y and g : Y 99K Z be generically finite dominant rational maps. Then
max{ed(g), ed(f)} ≤ed(g ◦f). In particular, ed(g2 ◦f ◦g1) = ed(f), when g1 (resp. g2)
is a birational map on X (resp. Y ).
(3) Let f : X 99K Y be a generically finite dominant rational map such that the induced field
extension K(X)/K(Y ) is abelian Galois with Galois group G. Then ed(f) ≤rank(G).
2.3. Algebraic surfaces with polarized endomorphisms. Polarized endomorphisms are
key objects in algebraic dynamics. We collect some equivalent descriptions of polarized endo-
morphisms of normal varieties.
Definition 2.9. Let f : X →X be a finite surjective endomorphism of a normal projective
variety X. We say f is q-polarized or simply polarized if there exists an ample Cartier divisor
(or equivalently, an ample R-Cartier divisor [16, Lemma 3.5]) H on X such that f∗H ∼qH
(or equivalently, f∗H ≡qH (numerical equivalence) [19, Lemma 2.3]) for some integer (or
equivalently, some rational number [16, Lemma 3.5]) q > 1.
The above notions behave well under iterations. To be more specific, if fs is qs-polarized for
some integer q > 1, then f is q-polarized; see [23, Proof of Theorem 2.7, Note 1].
Below is the classification theorem for projective surfaces admitting polarized endomorphisms.
Theorem 2.10 ([24, Proposition 2.3.1]). Let ϕ : X →X be a polarized endomorphism of a
smooth projective surface. Then X is one of the following types:
(1) Abelian surface.
(2) Hyperelliptic surface, i.e., the ´etale quotient of the product of two elliptic curves.
(3) Toric surface.

2.4. Negative curves on polarized surfaces. A curve C on a smooth projective surface X
is called a negative curve if the self-intersection number C2 < 0.
Lemma 2.12. Let X be a smooth projective surface and let f : X →X be a surjective endo-
morphism of deg f ≥2. Then:
(1) f−1 takes every negative curve on X to an irreducible negative curve. Hence both f and
f−1 induce bijections on the set of negative curves C of X (which is a finite set). In
particular, we have f−1(f(C)) = C, f∗f(C) = rC and f∗C = (deg(f)/r)f(C); here r
is the ramification index of f along C.
(2) Suppose further that f is Galois with Galois group G. Then every negative curve C on
X is G-stable, and the r in (1) is also equal to the order of GC = {g ∈G | g|C = id}.
Proof. (1) follows from Nakayama [18, Proposition 10] and the projection formula.
For (2), since f is Galois with Galois group G, we have that f−1(C) = ∪g∈Gg(C′), where
C′ is an irreducible curve such that f(C′) = C. In particular, g(C′) = C′ for all g ∈G by
(1). Since C′ ranges over all negative curves as C varies (by (1)), every negative curve on X is
G-stable. For the remaining assertion, note that deg(f|C) = |G/GC| = deg(f)/r by (1). Since
deg(f) = |G|, (2) follows.
□
