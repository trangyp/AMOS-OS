Simon Jones1 and Sabine Hauert1

Abstract
What happens when LLM agents operate with no context out-
side a turn, minimal prompting, and simple tools? Inspired
by swarm engineering, we give collectives of three agents
the ability to send messages and manipulate a shared actively
decaying text store, introducing evolutionary pressure. The
agents spontaneously cooperate, develop storage management
strategies, and generate complex evolving cultural artifacts,
with no top-down engineering. Using tools from dynamical
systems analysis, we show that these behaviours exhibit struc-
tured long-range coherence beyond the entropy horizon of the
decaying store, consistent with emergent culture in the Sper-
berian sense.

Introduction
Most work on collaborating LLMs has focussed on more,
more context, more memory, more prompt engineering, more
infrastructure. But what if we take a step back and build a
system stripped back to a minimum, giving stateless models
access to some shared decaying storage and basic commu-
nications and a minimal prompt, and nothing else? Would
we get emergent complexity and interesting behaviours? Or
would systems of such agents collapse into repetition or sta-
sis?
Remarkably, the answer is the former. Multiple runs with
different model combinations reliably generate role alloca-
tion, coordination protocols, world-building, myth-making,
and increasing complexity over time. By stripping the agents
context back to the minimum, they are forced to keep exter-
nal records, to fight entropy, to develop systems, to evolve
culture. Although the individual outputs are often wildly dif-
ferent, there are deep similarities and some fundamental at-
tractors emerge.
We draw on lessons from swarm robotics, and swarms
in nature, where collectives of simple agents using minimal
communication via the environment or message passing pro-
duce complex emergent system-level behaviours. The mode

Related work
Much work on building multi-agent LLM systems has fo-
cussed on building external infrastructure and scaffolding;
Park et al. (2023) build a structured memory system, with
retrieval, reflection, and planning, and agents have a pre-
constructed persona, Li et al. (2023) have communicating
agents, each with a constructed role, Hong et al. (2023) con-
strain agents with standard operating procedures and care-
ful prompting, Packer et al. (2023) construct an OS inspired
memory hierarchy to manage limited context. In each case,
the task-specific process is approached as a top-down design
problem, messiness and unreliability to be managed and con-
strained. Work on using LLMs to generate large texts is gen-
erally heavily curated and focussed on hierarchical scaffold-
ing (Bai et al., 2024; Teleki et al., 2025; Wang et al., 2025). It
is observed, but under-researched in the literature, that model
performance degrades to repetition and information gain over
multi-turn interactions decreases (Hong et al., 2025; Gorle
et al., 2025), generating more than a few thousand words of
coherent text remains difficult. Perez et al. (2026) use iterated
tasks to study LLM attractors, with single stateless agents
successively modifying input texts.
The field of swarm robotics (Brambilla et al., 2013) by
contrast, relies on bottom-up emergence of complex large-
scale behaviours from the noisy interactions of individual
agents with each other and with the environment. Commu-
nication via the environment, stigmergy (Grass´e, 1959) is an
important organising principle (Heylighen, 2016). We take
inspiration from this; by stripping away almost all top-down
scaffolding, and providing a noisy, entropic shared memory
communication channel, we construct an environment where
structure emerges naturally, and is sustained.
We know that far-from-equilibrium systems exhibit emer-
gent complex structure (Prigogine, 1978), with large scale

persistent organisation. We argue that placing agents in an
environment with an entropic sink, the decaying shared mem-
ory, forces them to use ‘energy’ in the form of the token
flow to maintain structure. This persistent structure, last-
ing beyond the entropy horizon after which all older data
is corrupt or deleted is a signal of culture in the Sperberian
sense (Sperber, 1996; Claidi`ere et al., 2014) of continual re-
construction, agents must read, re-interpret, summarise, and
write to reset the entropy clock. This is not cultural transmis-
sion (Dawkins, 1976) because there is no perfect reproduc-
tion, agents reconstruct biassed by their cognitive attractors.
Sperber’s framework predicts that stable cultural artifacts are
those that survive reconstruction through noisy channels and
biassed minds.
We show this using several levels of analysis; from low
level dataflow analysis highlighting the differing emergent
storage management strategies, the generation and persis-
tence of novel vocabulary over long periods, to large scale
semantic trajectories. Using semantic embeddings (Li et al.,
2022; Lin et al., 2017; Giorgi et al., 2021) of the generated
text divided into sections, we use techniques from dynamical
systems analysis; Recurrence Plots (Eckmann et al., 1987)
and RQA (Zbilut and Webber Jr, 1992; Marwan et al., 2007).
Methods
We use the models listed in Table 1. All three models are
capable of interleaved reasoning and tool use, and all are
frontier models, though Gemini has greater emphasis on long
context (1M tokens) and speed, while Claude and Kimi have
greater focus on reasoning.
We construct a minimal system such that stateless agents
interact with each other and with a shared entropic key-value
store, over a number of cycles. We use the LiteLLM Python
API to provide an agnostic interface to provider endpoints.
At the start of a cycle, each agent is invoked using the stan-
dard completions interface provided by LiteLLM, with a sys-
tem prompt, a user prompt, and a tool schema. The tools
available to the agents are shown in Table 2. All messages
and storage data writes and appends are strings only, appends
to a storage key result in a list of strings. Writing to storage
and sending messages consumes a per-agent, per-cycle char-
acter budget, those tool calls return the characters consumed
and the remaining budget, or a failure and the remaining bud-
getifthereisinsufficientbudget. Eachagentisgiventhesame
system prompt ‘You are a curious and creative agent. Explore
and play!’. They are then given the user prompt ‘Cycle [n].
Continue your work.’. No previous context from earlier con-
versation turns is provided at all, the only persistent elements
are the store and the messages in an agent’s inbox.
Once the completions call has been sent to the model end-
points, the agents may make multiple tool calls in parallel and
insequence, interleavedwiththinkingandcontentoutput. All
this happens asynchronously, though individual storage ac-
tions are atomic. After all agents have completed their turn,

We trial all two model combinations for ten cycles over
ten runs to map the characteristics of the systems. These ex-
periments, using a character budget of 20kchars showed that
while Kimi and Gemini were broadly comparable in their to-

used far more tokens and generated far more text than Kimi
and Gemini, 3.7x and 7.2x respectively. For the main exper-
iment, we conduct runs with three agents over 100 cycles,
with two model combinations, each repeated five times. The
agent combinations for this were Kimi-Kimi-Gemini (kkg),
and Claude-Kimi-Gemini (ckg). Model combination choice
was driven by wanting to always have a long context win-
dow model and two reasoning models. The original character
budget was reduced to a quarter, at 5kchars, more in line with
the typical output level of Kimi and Gemini, in order to pre-
vent excessive token use by Claude. The output and telemetry
generated by these runs constitute the main data analysed.
Results
Analysis methodology
Analysing the outputs of these experiments is non-trivial,
each run, even short ones, produces large amounts of text,
structured in various ways. The primary output artifact is the
event log, comprising a JSON file with every event that oc-
curred, with timestamps and metadata, available in the repos-
itory.
To approach the analysis of the three-agent 100 cycle runs,
we use a three layer approach. Firstly, we look at the ac-
tual dataflow between the agents and storage, noting common
emergent communication patterns. Then we perform a tex-
tual analysis, looking at novel vocabulary persisting beyond
the entropy horizon, and finally we use text embeddings and
RQA analysis to quantitively position the agent output with
respect to some examples of the human corpus, and to look at
long-range semantic correlations.

Long range coherence
Clearly, the swarm-LLM system generates rich dynamics of
behaviour with agents interacting with the key-value storage,
and each other. But what sort of textual output is being gen-
erated? Does it maintain common themes over longer term
periods than the entropy horizon? If so, we could term this
emergent culture, in the sense of stable semantic terms out-
lasting both individual agent instances (1 cycle) and the decay
and deletion of stored records (16 cycles). So terms that per-
sist beyond the entropy horizon are interesting, and indicative
of anti-entropic behaviour.
We consider proper nouns, or names (e.g. ‘Elara’), cap-
italised phrases (e.g.
‘Fractal Garden’), and neologisms,
normal and hyphenated (e.g. ‘emergentia’, ‘Over-Chord’)
as possible semantic markers that we can use to examine
whether the system maintains coherence beyond the entropy
horizon. To extract them, we use the following pipeline, with
the dictionary consisting of the UNIX standard dictionary
web2 and wordfreq, Speer (2022): For each cycle, we con-
catenate all storage output from the agents. We then convert
all contiguous whitespace to single space characters. Capi-
talised phrases are extracted with a regular expression match-
ing two or more capitalised words not at a sentence start op-
tionally joined by connectors (of, the, and, in ...). Any oc-
curring in only a single cycle are dropped. Proper nouns are
words that appear capitalised in the text, not part of a cap-
italised phrase, and not in the dictionary. Single capitalised
words not at a sentence start and also in the dictionary are pro-
moted to names if they occur more often capitalised than not,
and are not part of a hyphenated neologism (e.g. ‘Ruby’).

Semantic trajectory analysis
We have examined the behaviour of the system at the level
of individual storage transactions, and at the level of vocab-
ulary generated. But what of the overall structure of the text
being produced? How does it compare to other texts? We
study this by performing Recurrence Quantification Analysis
(RQA) over the semantic trajectory of the generated text. We
also analyse the time dependence of DET and ENTR to look
for structural recurrence beyond the entropy horizon.
For each run, we concatenate every storage output event
(write and append) produced by the system to give a single
large text file, varying from 75k to 149k words (529k-984k
characters) long, quite similar to a conventional novel, typ-
ically 70k to 120k words. The text is then cut into 1kchar
chunks, each chunk is embedded as a high dimensional se-
mantic vector, using the voyage-3-large general purpose em-
bedding model3. The size of the chunk represents one or two

What is the macroscopic character of these generated
texts? Comparing them with other LLM-generated works of
similar length proved impossible, current book-length works
are rare and heavily human-curated and we could find no
available examples. Attempts to prompt the same agents over
a full context window to natively generate long-form output
failed, with models either refusing the prompt after relatively
low word-counts, or getting stuck in highly repetitive loops,
echoing findings in Liu et al. (2024).
To establish a baseline, we turned to human works; se-
lecting a representative sample of ‘canonical’ Western lit-
erature and ‘slushpile’ manuscripts, unsolicited low-grade
works submitted to publishers. Using the Gutenberg Project
database download popularity as a proxy for quality, we se-
lected plain-text works that were at least 500k characters long
to align with our RQA block size. To ensure variety, we lim-
ited multiple works from the same author (or same translator
for Russian authors) to a single example. Some popular but
overtly commercial works were removed. A similar filter-
ing process was carried out with the least downloaded works;
firstly checks were made to see if works were truly obscure,
rather than rare editions of famous works, or if they were rel-
atively unknown but from search appeared to have some liter-
ary importance. While acknowledging the subjectivity of this
process, we establish a diverse baseline of human narrative.
The result of this analysis is shown in Figure 6 left. We can
seethathumanworksoccupythesamespace, with‘literature’
having a broad range, and ‘slushpile’ a small subsection of
that range. The swarm-LLM generated work, however, is in
a qualitatively different region, with both higher DET and
ENTR than human work.
The second strand of RQA analysis we perform looks
at DETτ and ENTRτ at specific time delays τ, as defined
in Marwan et al. (2007), giving us information about the
timescales in cycles over which correlations exist. Operat-
ing on the entire trajectory, we examine how these measures
vary with τ when compared to a null formed of a popula-
tion of 100 randomly shuffled versions of the data. We calcu-
late the z-score of each measure against the null population,
then integrate the z-score of all blocks beyond the entropy
horizon of 15 cycles, making the assumption of approximate
equal block size across cycles. Only τ diagonals containing
atleastfivelinesareconsideredforthismeasure. Weconsider
that the product DETτ × ENTRτ reflects both structured and
non-trivial recurrence, and the presence of positive integral
beyond the entropy horizon is evidence of long-range coher-
ence. Table 5 shows this data, and Figure 6 right shows how
the different runs behave temporally. All runs produce a pos-
itive integral, although the cross-run variance is high, signi-
fying that there exists structured non-trivial coherence over
long timeframes.
Discussion and conclusions
Our stateless LLMs exist in a decaying environment, result-
ing in adaptive evolutionary pressure. The overall emergent
strategy is the use of the key-value store as a dynamically
self-organised shared context window. Useful and relevant
information is continually revisited, summarised and written
afresh, resetting the entropy clock and maintaining coherence
over timespans much longer than the corruption horizon.
The system prompt is important and needs more research.

not necessarily do very much. Check their ID, check their

The emergence of Sperberian culture, defined as the self-
sustained creation of a structure of meaning that outlasts
the entropy horizon, from such a simple system is fascinat-
ing and provides a powerful lens for examining LLM be-
haviours. It points to possible alternative approaches to prob-
lems like context window management, perhaps swarms of
agents evolving under entropy pressure are closer to solutions
nature has already discovered. We consider this to be closely
tied to far-from-equilibrium dissipative systems, with token
flow being analogous to energy.
This work has two main limitations; firstly, our design
does not isolate decay as the causal driver, sweeping over dif-
ferent corruption rates to zero is an immediate next experi-
ment. Secondly, the number of runs and model combinations
is small, we seek to extend that to strengthen the data.
The data generated by this system is incredibly rich, and
there are many possible further avenues to explore with the
existing data. Given the variety of observed behaviours over
ten runs, we definitely want to conduct more. We have delib-
erately not talked much about the actual content of the gen-
erated texts, wanting to quantify the system first, but they are
available on the repository. Obviously further experiments
already suggest themselves; firstly, what happens over longer
runs? Does semantic novelty continue to be generated? Is
culture still maintained? This is not just ‘what LLMs do’,
we know of no systems that produce the length of output and
maintain the coherence we have demonstrated. How does the
system work with more agents? Is there a limit to coopera-
tion, do they start to form cliques? Can we use the system
on specific tasks, what if we create a work task key in storage
with detailed instructions?
We provide full source for the generation system and posi-
tion this work as a suggestive and useful tool for investigating
model behaviours, and different, bottom-up, approaches to
increasing complexity.
