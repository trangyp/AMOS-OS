Abstract
The Multiple-Depot Split Delivery Vehicle Rout-
ing Problem (MD-SDVRP) is a challenging prob-
lem with broad applications in logistics. The goal
is to serve customers’ demand using a fleet of ca-
pacitated vehicles located in multiple depots, where
each customer’s demand can be served by more
than one vehicle, while minimizing the total travel
cost of all vehicles. We study approximation al-
gorithms for this problem.
Previously, the only
known result was a 6-approximation algorithm for
a constant number of depots (INFORMS J. Com-
put.
2023), and whether this ratio could be im-
proved was left as an open question. In this pa-
per, we resolve it by proposing a (6 −2 · 10−36)-
approximation algorithm for this setting.
More-
over, we develop constant-factor approximation al-
gorithms that work beyond a constant number of
depots, improved parameterized approximation al-
gorithms related to the vehicle capacity and the
number of depots, as well as bi-factor approxima-
tion algorithms.

Introduction
The (Capacitated) Vehicle Routing Problem (VRP) is a clas-
sical and extensively studied routing problem [Toth and Vigo,
2014]. In this problem, we are given a set of customers with
integer demand and a depot that provides an unlimited num-
ber of vehicles with the same integer capacity. The objec-
tive is to design vehicle routes for to satisfy all customers
such that the total traveling cost is minimized. Each vehicle
route must begin and end at the depot, and in which the ve-
hicle delivers at most its capacity of demand to customers.
There are two famous variants of the CVRP: splittable and
unsplittable. In the splittable CVRP, each customer’s demand
can be served by multiple vehicles, whereas in the unsplit-
table CVRP, each customer’s demand must be served entirely
by a single vehicle. When the model is extended to allow
multiple depots, it becomes the Multiple-Depot VRP (MD-
VRP), which has also received substantial attention in the lit-
erature [Montoya-Torres et al., 2015].
However, in real-world scenarios, the number of vehicles
available at each depot may be limited. To address this sit-
uation, the Split Delivery VRP (SDVRP), a variant of the
splittable VRP, was introduced [Dror and Trudeau, 1989;
Dror and Trudeau, 1990]. The SDVRP has since been stud-
ied extensively [Belenguer et al., 2000; Zhang et al., 2015;
Gamst et al., 2024; Lin et al., 2025; Konstantakopoulos et al.,
2022], and a comprehensive survey can be found in [Archetti
et al., 2014].
Analogously, when multiple depots are involved, the cor-
responding problem is known as the Multiple-Depot SDVRP
(MD-SDVRP) [Lai et al., 2023].
Formally, in the MD-SDVRP, we are given an undirected
complete graph G = (V, E) with vertex set V = J ∪D and
edge set E = V ×V . The set J represents n customers, and D
represents k depots. Each customer v ∈J has a demand qv ∈
N+, and each depot u ∈D owns ru ∈N+ vehicles with the
same capacity Q ∈N+. Let L denote the set of all vehicles
and m = |L|. Each edge e ∈E has a non-negative cost
c(e) ≥0, and the edge cost function c satisfies the triangle
inequality. The objective is to design vehicle routes to satisfy
all customers while minimizing the total traveling cost. When
k = 1, the MD-SDVRP reduces to the SDVRP.
We study (parameterized) approximation algorithms and
bi-factor approximation algorithms for the MD-SDVRP.
For a minimization problem, an algorithm is called a ρ-
approximation algorithm if, for any instance I, it computes
a solution of cost at most ρ times the optimal value in poly-
nomial time poly(|I|), where |I| denotes the input size. The
quantity ρ is referred to as the approximation ratio. With re-
spect to some parameter k ∈N+, an algorithm is called a
slice-wise polynomial-time (XP) ρ-approximation algorithm
if it runs in poly(|I|) time for every fixed k = O(1) and
achieves an approximation ratio of ρ; an algorithm is called
a fixed-parameter tractable (FPT) ρ-approximation algorithm
if it runs in O(f(k)) · poly(|I|) time for some computable
function f(k) and achieves an approximation ratio of ρ.
The notion of a bi-factor approximation algorithm may
vary across problems. For the MD-SDVRP, we define a bi-
factor (ρ, γ)-approximation algorithm as a polynomial-time
algorithm that computes a solution whose cost is at most
ρ times the optimal value (under the original capacity con-
straint), while allowing each vehicle to exceed its capacity Q,
but with the total load on each vehicle bounded by γ·Q, where
γ ≥1. In the same manner, with respect to some parameter k,
one can define XP/FPT bi-factor approximation algorithms.

Related Work
In this subsection, we review the existing approximation al-
gorithms for the MD-SDVRP and its related problems.
The VRP and the SDVRP
First, we consider the VRP and the SDVRP, where the VRP
can be viewed as a special case of the SDVRP in which the
depot has an unlimited number of vehicles.
For the case Q = ∞, by the triangle inequality, the VRP
is equivalent to the Traveling Salesman Problem (TSP). For
the TSP, Christofides [2022] proposed a 1.5-approximation

denote the current best approximation ratio for the TSP.

A walk W in G, denoted by v1v2 . . . vℓ, is a sequence of
vertices in V , where a vertex may be repeated and each con-
secutive pair of vertices is connected by an edge. Let E(W)

A path is a walk where no vertex appears more than once.
The first and the last vertices of a path are referred to as its
terminals. A closed walk is a walk where the first and the last
vertices are the same, and a cycle is a walk where only the
first and the last vertices are the same. A cycle (or path) C
containing a single vertex is called trivial, and for which we
define E(C) = ∅.
Given a closed walk, by the triangle inequality, one can
skip repeated vertices along the walk to obtain a cycle of non-
increasing cost. Such an operation is called shortcutting. We
define a route or tour for a vehicle from depot u to be a cycle
in the form of uv1v2 . . . vℓu, where each vi is a customer. A
tour containing a single customer, e.g., uv1u, is called trivial.
A (perfect) matching M in G is a set of vertex-disjoint
edges that spans all vertices in V . A cycle cover B in G is a
set of vertex-disjoint cycles that spans all vertices in V . Note
that a tree (or cycle) may consist only of a single vertex.

by CE′. (Recall that a component is a connected subgraph

set Vs ⊆H, let H[Vs] denote the subgraph of H induced
by Vs. In H, the degree of a vertex v ∈VH is the num-

be computed in O(|VH| + |EH|) time [Cormen et al., 2022].

6.3
The Extension to the SDVRP
The algorithm in [Lai et al., 2023] achieves an approximation
ratio of 6 −4/k for the MD-SDVRP for each fixed k ≥2.
When k = 1, the MD-SDVRP reduces to the SDVRP. We
first explain why their algorithm achieves an approximation
ratio of 4 for the SDVRP.
Specifically, their algorithm computes a solution with cost
at most 2c(C)+OPT, where C is both a cycle cover in G and a
good component set. For the case k = 1, any component con-
taining all vertices in V is itself a good component set. Hence,
computing a minimum-cost such component is equivalent to
computing a minimum-cost cycle containing all vertices in G,
i.e., an optimal solution to the TSP. When k = 1, their algo-
rithm effectively simulates the 1.5-approximation algorithm
for the TSP [Christofides, 2022] to compute the component.
Hence, their algorithm achieves an approximation ratio of 4
for the SDVRP.
