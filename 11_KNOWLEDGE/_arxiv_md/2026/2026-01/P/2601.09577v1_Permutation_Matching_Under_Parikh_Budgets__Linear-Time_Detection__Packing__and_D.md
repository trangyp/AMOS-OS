Permutation Matching Under Parikh Budgets:
Linear-Time Detection, Packing, and Disjoint
Selection
MD Nazmul Alam Shanto, Md. Tanzeem Rahat, and Md. Manzurul Hasan
Department of Computer Science, American International University-Bangladesh,
Dhaka, Bangladesh
mdnazmulshanto2001@gmail.com, tanzeem.rahat@aiub.edu, manzurul@aiub.edu
Abstract. We study permutation (jumbled/Abelian) pattern matching
over a general alphabet Σ. Given a pattern P of length m and a text T
of length n, the classical task is to decide whether T contains a length-
m substring whose Parikh vector equals that of P. While this existence
problem admits a linear-time sliding-window solution, many practical ap-
plications require optimization and packing variants beyond mere detec-
tion. We present a unified sliding-window framework based on maintain-
ing the Parikh-vector difference between P and the current window of T,
enabling permutation matching in O(n + σ) time and O(σ) space, where
σ = |Σ|. Building on this foundation, we introduce a combinatorial-
optimization variant that we call Maximum Feasible Substring under
Pattern Supply (MFSP): find the longest substring S of T whose sym-
bol counts are component-wise bounded by those of P. We show that
MFSP can also be solved in O(n + σ) time via a two-pointer feasibility
maintenance algorithm, providing an exact packing interpretation of P
as a resource budget. Finally, we address non-overlapping occurrence se-
lection by modeling each permutation match as an equal-length interval
and proving that a greedy earliest-finishing strategy yields a maximum-
cardinality set of disjoint matches, computable in linear time once all
matches are enumerated. Our results provide concise, provably correct
algorithms with tight bounds, and connect frequency-based string match-
ing to packing-style optimization primitives.
Keywords: Jumbled (Abelian) pattern matching · Parikh (frequency)
vectors · Sliding-window algorithms · Interval packing / non-overlapping
selection

Preliminaries and Notation
Let Σ be an alphabet of size σ = |Σ|. A string (word) S over Σ has length
|S|, and we use 0-based indexing so that S[i] denotes the character at position
i for 0 ≤i < |S|. For integers ℓ≤r, we write S[ℓ..r] for the substring S[ℓ]S[ℓ+
1] · · · S[r]. For a text T of length n and an integer m ≤n, we denote by
Wi = T[i..i + m −1]
(0 ≤i ≤n −m)
the length-m window of T starting at index i.
2.1
Parikh (frequency) vectors
For a string S, the Parikh vector (frequency vector) of S is the function freqS :
Σ →Z≥0 defined by
freqS(c) = |{ i : 0 ≤i < |S|, S[i] = c }|
for each c ∈Σ.
When the context is clear, we write freq(S) for freqS. Two strings X and Y
are permutations (anagrams) of each other if |X| = |Y | and freq(X) = freq(Y )
(component-wise equality).
2.2
Problems studied
Throughout, we are given a pattern P ∈Σm and a text T ∈Σn.
Permutation matching (existence). Decide whether there exists an index i with
0 ≤i ≤n −m such that
freq(Wi) = freq(P).

MFSP (maximum feasible substring under pattern supply). Treat freq(P) as a
supply (budget) vector. A substring S of T is feasible if its symbol counts do not
exceed the supply:
freq(S) ⪯freq(P)
⇐⇒

MFSP asks to compute a longest feasible substring of T, i.e.,
max{ |S| : S = T[ℓ..r] and freq(S) ⪯freq(P) }.
Non-overlapping selection. Let M = { i : freq(Wi) = freq(P) } be the set of all
match starting positions. Each i ∈M corresponds to an interval Ii = [i, i +
m −1]. The goal is to select a maximum-cardinality subset of pairwise disjoint
intervals.
2.3
Difference vectors and a nonzero counter
A central tool in this paper is maintaining differences of Parikh vectors. For a
window Wi and pattern P, define the difference vector
∆i(c) = freq(Wi)(c) −freq(P)(c)
for c ∈Σ.
Observe that freq(Wi) = freq(P) if and only if ∆i(c) = 0 for all c ∈Σ. To test
this efficiently we maintain
nzi = |{ c ∈Σ : ∆i(c) ̸= 0 }|,
the number of nonzero entries. Then Wi is a permutation match if and only if
nzi = 0.
2.4
Implementation model
We assume either (i) Σ is given explicitly and σ is moderate, enabling array-
based counts indexed by symbols, or (ii) we perform alphabet compression: map
only the symbols that appear in P and the relevant portion of T to integers
1, . . . , σ′ using a hash map, where σ′ ≤min(σ, m+n). All asymptotic bounds are
stated in terms of σ for simplicity, and extend directly to σ′ under compression.

Update primitive. Let x = ∆(c) before an update and x′ = ∆(c) + δ after the

– If x = 0 and x′ ̸= 0, then increment nz.

3.2
Algorithm
We initialize ∆by starting from −freq(P) and adding the symbols of the first
window W0. After that, each shift from Wi to Wi+1 removes one outgoing symbol
T[i] and adds one incoming symbol T[i + m]; hence only two coordinates of ∆
change per step.
3.3
Correctness
Theorem 1. Algorithm 1 returns True if and only if there exists an index i with
0 ≤i ≤n −m such that freq(Wi) = freq(P).
Proof. We prove the invariant that after initialization and after each shift, for
every c ∈Σ, the maintained value ∆(c) equals freq(Wi)(c) −freq(P)(c) for the
current window Wi, and nz equals the number of symbols with nonzero ∆(c).

Initialization sets ∆(c) = −freq(P)(c) (or 0 if absent), then adds each symbol
of W0 once; thus ∆(c) = freq(W0)(c) −freq(P)(c). The update rules modify nz
exactly when a coordinate crosses zero, hence nz = |{c : ∆(c) ̸= 0}| holds.
For a shift from Wi to Wi+1, exactly one symbol out = T[i] leaves the window
and one symbol in = T[i + m] enters. Therefore, for all c ∈Σ, freq(Wi+1)(c) =
freq(Wi)(c) −1[c = out] + 1[c = in]. The algorithm applies precisely these two
±1 updates to ∆, preserving the difference-vector invariant, and updates nz
consistently with zero-crossings.
Finally, freq(Wi) = freq(P) holds if and only if ∆(c) = 0 for all c, which
holds if and only if nz = 0. Hence the algorithm returns True exactly for those
windows that are permutations of P.
3.4
Complexity
Theorem 2. Algorithm 1 runs in O(n + σ) time and uses O(σ) space.
Proof. The initialization over Σ takes O(σ) time. Building the first window per-
forms m constant-time updates. Each of the n−m shifts performs two constant-
time updates and one constant-time check of nz, for total O(n) time. The main-
tained arrays/maps store one integer per symbol in Σ, hence O(σ) space.
Remark (enumerating all matches). With the same maintained state, one can
output all match indices by recording every i for which nz = 0; this adds O(#M)
output time and does not change the asymptotic running time.

4.2
Two-pointer feasibility maintenance
Feasibility is monotone under shrinking: if a window is infeasible, removing char-
acters from its left end can only decrease its counts and eventually restore fea-
sibility. This monotonicity supports a linear-time two-pointer algorithm (a.k.a.
sliding window) that maintains a maximal feasible window for each right end-
point.
We maintain an array cnt(c) for the current window T[ℓ..r] and the supply
array sup(c) = freq(P)(c). The window is feasible iff cnt(c) ≤sup(c) for all c.
To test feasibility in O(1) amortized time, we maintain a violation counter
viol = |{ c ∈Σ : cnt(c) > sup(c) }|.
As with nz in Section 3, updating cnt(c) by ±1 only changes whether a symbol
is violating at a threshold crossing.
4.3
Correctness
We prove that Algorithm 2 returns a longest feasible substring.
Theorem 3. Algorithm 2 outputs indices (ℓ⋆, r⋆) such that T[ℓ⋆..r⋆] is feasible
and has maximum length among all feasible substrings of T.
Proof. We maintain the invariant that after the while-loop terminates for a
fixed right endpoint r, the current window T[ℓ..r] is feasible, i.e., for all c ∈Σ,
cnt(c) ≤sup(c).
Feasibility restoration. When T[r] is added, the only possible new infeasibility
is that for the character c = T[r], cnt(c) exceeds sup(c), which is detected by
incrementing viol. Each iteration of the while-loop removes exactly one char-
acter from the left, decreasing exactly one count by 1. A violation for some
symbol d disappears precisely when its count crosses from cnt(d) > sup(d) to
cnt(d) ≤sup(d), at which point we decrement viol. Thus the loop stops exactly
when there are no violating symbols, i.e., feasibility holds.
Maximality for each r. Fix r. Let ℓr be the value of ℓafter the while-loop ends. At
that moment, T[ℓr..r] is feasible. Moreover, the algorithm maintains ℓas small
as possible subject to feasibility: if ℓwere decreased by one (i.e., if we tried to
include T[ℓr −1]), then that character was removed at some point only because

Complexity
Theorem 4. Algorithm 2 runs in O(n + σ) time and uses O(σ) space.
Proof. Each step increments r once, so the outer loop runs n times. The pointer

Non-overlapping Permutation Occurrences as Interval
Packing
This section addresses selecting a maximum number of non-overlapping permu-
tation occurrences of the pattern P in the text T. Once all permutation matches
are identified, each match corresponds to a fixed-length interval, and the selec-
tion task becomes a classical interval packing problem.
5.1
From matches to intervals
Let
M = { i ∈{0, . . . , n −m} : freq(Wi) = freq(P) }
be the set of all starting indices of length-m permutation matches. Each i ∈M
induces an interval
Ii = [ i, i + m −1 ].
A set S ⊆M is non-overlapping if the corresponding intervals are pairwise
disjoint, i.e., for all distinct i, j ∈S, Ii ∩Ij = ∅. Our goal is to compute a
maximum-cardinality non-overlapping subset of M.

5.2
Greedy selection
Because all intervals have the same length m, an optimal solution is obtained
by a simple greedy rule: scan T from left to right and select a match whenever
possible, then skip ahead by m.
5.3
Correctness via an exchange argument
Theorem 5. Algorithm 3 outputs a maximum-cardinality set of pairwise dis-
joint match intervals.
Proof. Let Sg be the set returned by Algorithm 3. We show that there exists an
optimal solution S⋆with |S⋆| = |Sg| by a standard exchange argument.
Let i1 be the first selected start index in Sg (the leftmost match chosen by the
algorithm). Consider any optimal solution S⋆. If S⋆also selects i1, we proceed
to the remaining suffix after i1 + m −1.
Otherwise, let j1 be the smallest start index in S⋆. Since i1 is the smallest
available match start (by the greedy scan), we have i1 < j1. Replace j1 by i1 in
S⋆. This replacement preserves feasibility (disjointness): because intervals have
equal length m, shifting the first chosen interval to the left cannot create overlap
with the remaining intervals of S⋆(which all start at positions ≥j1 and thus
end at positions ≥j1 + m −1 > i1 + m −1). Hence we obtain another optimal
solution that contains i1 and has the same cardinality.
Remove interval Ii1 and restrict attention to the suffix of T starting at index
i1+m. The greedy algorithm repeats the same choice structure on this suffix, and
the same exchange argument applies inductively. Therefore, the greedy algorithm
selects the same number of intervals as an optimal solution, i.e., |Sg| is maximum.
5.4
Complexity
Theorem 6. Given the match set M, Algorithm 3 runs in O(n) time. Including
match enumeration via Algorithm 1, the total time is O(n + σ) plus output size,
and the space is O(σ).
Proof. The greedy scan advances i monotonically from 0 to n −m and thus
performs O(n) iterations. Membership tests i ∈M can be supported in O(1)
time by storing a boolean array of length n (or a hash set when n is large and
matches are sparse). Match enumeration using Algorithm 1 is O(n+σ) time and
O(σ) space.

6.1
Implementation details
All algorithms were implemented in a standard imperative style using (i) arrays
for moderate alphabets and (ii) alphabet compression (hash map from symbols
to 1, . . . , σ′) when Σ is large. For permutation matching (Section 3), we maintain
the Parikh-difference vector ∆and the nonzero counter nz; each shift updates
exactly two coordinates and tests whether nz = 0. For MFSP (Section 4), we
maintain window counts cnt and a violation counter viol; each pointer move
updates a single coordinate and possibly changes viol at a threshold crossing.
6.2
Workloads and metrics
We evaluated the methods on two classes of inputs:
– Synthetic strings: random texts over alphabets of varying size (σ ∈{4, 16, 64, 256}),
with pattern lengths m ∈{16, 64, 256, 1024} and text lengths up to n = 107.
– Natural-language corpora: plain-text datasets (letters and ASCII symbols)
where alphabet compression reduces memory and improves cache locality.
We report (i) total runtime as a function of n, (ii) throughput (symbols processed
per second), (iii) the number of matches |M|, and (iv) for MFSP, the optimal
length L⋆and its distribution across texts.
6.3
Key observations
Across all tested settings, both permutation matching and MFSP exhibited a
linear scaling trend with n, consistent with the O(n+σ) analyses in Theorems 2
and 4. The constant factors were dominated by (a) memory access patterns of
the counting arrays/maps and (b) the density of matches, which affects output
volume but not the scan itself.
For large alphabets, alphabet compression substantially reduced memory
footprint and improved performance when the effective alphabet σ′ was much
smaller than σ. For MFSP, the violation-counter mechanism eliminated the
need for full feasibility checks: restoring feasibility required advancing the left
pointer only when a budget constraint was exceeded, and each character was
added/removed at most once, matching the standard two-pointer amortization
argument.
Reproducibility. All experiments can be reproduced from the pseudocode in
Algorithms 1 and 2 by fixing a random seed for synthetic generation and applying
the same alphabet-compression mapping for large-σ inputs.

Conclusion
We revisited permutation (jumbled/Abelian) pattern matching from a combi-
natorial optimization perspective. Using Parikh-difference maintenance, we ob-
tained a concise O(n + σ)-time, O(σ)-space sliding-window procedure for per-
mutation matching with a simple correctness invariant. Building on this foun-
dation, we introduced MFSP, an optimization variant that treats freq(P) as a
supply (budget) vector and asks for the longest feasible substring of T under
component-wise constraints. We provided a linear-time two-pointer algorithm
with a full proof of optimality. Finally, we modeled non-overlapping permuta-
tion occurrences as equal-length intervals and proved that a greedy scan yields a
maximum-cardinality disjoint selection, linking frequency-based string matching
to interval packing.
A natural direction for future work is to study weighted and approximate
extensions of MFSP and non-overlapping selection, where feasibility may allow
bounded violations or where occurrences carry weights, potentially leading to
richer optimization structures and new complexity frontiers.
