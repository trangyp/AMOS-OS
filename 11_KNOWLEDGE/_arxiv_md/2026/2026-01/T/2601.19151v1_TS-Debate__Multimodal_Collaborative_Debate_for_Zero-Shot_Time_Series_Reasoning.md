Abstract
Recent progress at the intersection of large language models (LLMs) and time series (TS)
analysis has revealed both promise and fragility. While LLMs can reason over temporal
structure given carefully engineered context, they often struggle with numeric fidelity,
modality interference, and principled cross-modal integration. We present TS-Debate, a
modality-specialized, collaborative multi-agent debate framework for zero-shot time series
reasoning. TS-Debate assigns dedicated expert agents to textual context, visual patterns, and
numerical signals, preceded by explicit domain knowledge elicitation, and coordinates their
interaction via a structured debate protocol. Reviewer agents evaluate agent claims using
a verification-conflict-calibration mechanism, supported by lightweight code execution and
numerical lookup for programmatic verification. This architecture preserves modality fidelity,
exposes conflicting evidence, and mitigates numeric hallucinations without task-specific fine-
tuning. Across 20 tasks spanning three public benchmarks, TS-Debate achieves consistent and
significant performance improvements over strong baselines, including standard multimodal
debate in which all agents observe all inputs.

Introduction
Time-series data underlie critical decisions in finance, climatology, and industrial monitoring (Trirat et al.,
2024). Beyond forecasting, practitioners increasingly ask reasoning-centric questions such as: What explains
this anomaly?, Which historical pattern best matches this trajectory?, or Will the underlying cause of this trend
persist? Answering such questions requires integrating numerical precision, temporal structure, and domain
knowledge—capabilities that remain challenging for current large language models (LLMs). As LLMs become
a universal interface for data analysis, enabling robust time-series reasoning (TSR) in natural language is
both practically important and scientifically unresolved (Merrill et al., 2024; Chang et al., 2025).
Recent work suggests that TSR is inherently multimodal (Kong et al., 2025b; Liu et al., 2025a). Visual
prompting compresses long numerical sequences into charts that multimodal LLMs can parse efficiently,
reducing token costs while improving pattern recognition (Yoon et al., 2024). Vision–language approaches
further show that time- and frequency-domain visualizations expose salient temporal structure that text-only
or numeric-only prompting often misses (Liu et al., 2025b). However, simply adding modalities does not
guarantee correct reasoning. Models may over-trust visual impressions, hallucinate numeric details, or fall
back on shallow linguistic heuristics when modalities disagree. This gap motivates our main research question:
Can multimodal LLM agents perform zero-shot TSR by
collaboratively debating complementary evidence?

pattern, final answers frequently contain arithmetic errors or unjustified extrapolations. Classical debate
frameworks (Liang et al., 2024; Smit et al., 2024) are text-only and rely on persuasion rather than verification.
For time-series tasks, where many claims about trends, extrema, or temporal conditions are objectively
checkable, reliable reasoning requires programmatic verification and principled handling of disagreement.
To address these challenges, we introduce TS-Debate, a cross-modal, collaborative agentic debate framework
for zero-shot time-series reasoning. TS-Debate instantiates modality-specialized agents—a text analyst, a
visual analyst, and a numerical analyst—that act as teammates rather than adversaries. Each agent produces
explicitly labeled observations, inferences, and limitations grounded in its modality. A preliminary knowledge
elicitation stage activates relevant domain priors before any data analysis, reducing spurious reasoning paths.
Crucially, TS-Debate replaces majority voting with a verification-conflict-calibration protocol. Reviewer
agents verify quantitative claims using numerical lookup tools and code execution, detect cross-modal conflicts,
and calibrate answers based on both data consistency and domain validity. A final synthesizer evaluates
reviewer reasoning quality, resolves verified conflicts, and produces a calibrated answer. This design explicitly
discounts—rather than implicitly fuses—unverified or conflicting claims, adding a high-quality modality into
the reasoning process. Our main contributions are as follows.
• We propose TS-Debate, a multimodal, collaborative debate framework that decomposes TSR into comple-
mentary textual, visual, and numerical analyses.
• We introduce a verification-conflict-calibration protocol that enables programmatic verification of numeric
claims and resolution of cross-modal disagreement.
• We integrate domain knowledge elicitation and time-frequency decomposition to improve the reliability and
efficiency of zero-shot TSR.
• We demonstrate consistent empirical improvements over competitive baselines across 20 tasks on three
public benchmarks: MTBench (+7.39%), TimerBed (+22.74%), and TSQA (+21.58%).

Related Work
Time-Series Analysis and Reasoning. Recent work explores using LLMs for time-series analysis and
reasoning. A direct approach serializes numerical sequences as text, enabling zero-shot forecasting but
suffering from sensitivity to tokenization and brittle numerical fidelity (Gruver et al., 2023). Alignment-based
methods (Jin et al., 2024; Chow et al., 2024) address this issue by training adapters or auxiliary encoders that
map time series into LLM-compatible representations, improving performance at the cost of modality-specific
fine-tuning and additional training data. Several systems further couple LLMs with specialized time-series
models. TS-Reasoner (Yu et al., 2025) integrates foundation time-series encoders with LLMs to support
multi-step workflows over forecasting, anomaly detection, and causal discovery. ChatTime (Wang et al., 2025)
treats time series as a “foreign language,” reducing tokenization overhead while supporting bi-modal input and
output. Despite their effectiveness, these approaches primarily focus on representation learning or encoder
design and typically operate within a single numerical information channel. In contrast, TS-Debate assumes
off-the-shelf LLM and MLLM backbones and targets an inference-time orchestration protocol. Rather than
training new encoders, TS-Debate coordinates multiple modality-specialized agents (numerical, visual, and
textual) under explicit verification and calibration rules. This design avoids task-specific training and instead
emphasizes reliability and numerical faithfulness through structured, branch-style reasoning at inference time.
Multimodal LLMs (MLLMs) for Time Series. A parallel line of work leverages MLLMs by converting
time series into richer visual or cross-modal representations.
VL-Time (Liu et al., 2025b) proposes a
visualization-first pipeline that transforms time series into images (e.g., waveforms and spectrograms) and
reasons over them with MLLMs, achieving substantial gains with reduced token budgets. ByMyEyes (Yoon
et al., 2024) similarly shows that visual prompting over sensor-derived plots can outperform text-only
prompts while further lowering token costs. While these studies demonstrate the effectiveness of multimodal
representations, they typically rely on a single fusion step within an MLLM (Kong et al., 2025b). TS-Debate
departs from this paradigm in two key ways. First, instead of learning new multimodal encoders, we keep
the underlying models fixed and instantiate modality-isolated agents for numerical series, visual patterns,
and textual context. Second, we coordinate these agents through a multi-stage collaborative protocol with
explicit verification, conflict resolution, and calibration, allowing cross-modal evidence to interact iteratively
rather than being fused in a single forward pass.
Multi-Agent Debate (MAD). MAD frameworks (Smit et al., 2024) employ multiple LLM agents that
iteratively critique one another, often moderated by a judge, to improve reasoning quality. Early work
demonstrated gains on mathematical and logical benchmarks, while later studies examined debate topology
and aggregation rules and cautioned against over-interpreting debate-based evaluations (Li et al., 2024;
Kaesberg et al., 2025; Zhang et al., 2025). These approaches are predominantly text-only and typically
assume homogeneous agents with shared access to the same information. TS-Debate differs from generic
MAD in both assumptions and architecture. Rather than adversarial persuasion or majority voting,
TS-Debate adopts a collaborative debate paradigm in which agents contribute complementary evidence. We
enforce modality isolation by assigning each agent a distinct view of the problem, ensuring that disagreements
reflect genuinely different evidence rather than paraphrased reasoning. Moreover, our judges are equipped
with explicit verification tools, including code execution, to check numerical claims and domain constraints.
As a result, debate in TS-Debate is not an evaluation heuristic but an inference-time protocol tailored to
multimodal TSR, explicitly targeting numerical hallucinations and calibration errors. Table 1 summarizes
the key differences between TS-Debate and existing frameworks.

Proposed Framework: TS-Debate
3.1
Problem Setting
We study zero-shot TSR over univariate (d=1) or multivariate (d>1) sequences. Each instance consists of a
natural-language task specification q, an observed sequence x1:T ∈RT ×d with T time steps and d channels,
and auxiliary context c (e.g., textual descriptions, reports, or metadata). The goal is to produce an answer
ˆa ∈A(q), where the answer space A(q) is induced by the task (e.g., a class label, a numerical vector, or a
multiple-choice option). TS-Debate performs no task-specific training and does not update model parameters
at inference time. Instead, it orchestrates a set of LLM agents, each operating on a different representational
view of the same underlying signal, to construct and synthesize an evidence-grounded response.
To account for the temporal nature of time series, we distinguish past-present tasks, whose queried target lies
within the observed horizon, from future tasks, whose target lies beyond it. This distinction determines the
verification semantics: past-present claims can be directly checked against x1:T , whereas future-oriented claims
cannot be verified from the observation window alone and must instead be evaluated through domain-consistent
reasoning and uncertainty calibration.
3.2
Framework Overview
Let M = {T, V, N} denote the set of text, visual, and numerical modalities. As illustrated in Figure 2 (and
outlined in Algorithm 1), TS-Debate proceeds in three stages. First, it elicits task- and domain-specific priors
from q (optionally with c) to form shared guidance for all subsequent agents. Second, it constructs modality-
specific interfaces to the same underlying signal—textual context for semantics, charts for global structure, and
precise numerical evidence—and runs an iterative collaborative debate among modality-specialized analysts
to produce structured evidence. Third, it applies a verification-conflict-calibration protocol: multiple reviewer
agents verify the analysts’ claims against available sources, explicitly identify and resolve conflicts when
possible, and produce calibrated candidate answers. A final synthesizer then evaluates reviewer reasoning
quality and synthesizes the final answer ˆa.

3.3
Multimodal Query Construction
A central design principle of TS-Debate is to expose complementary and verifiable views of x1:T to different
agents, reducing reliance on any single representation. We implement this via task-conditioned knowledge
elicitation, construction of multiple representational views of the signal, and explicit visual and numerical
query interfaces.
Knowledge Elicitation. Before interpreting any data, TS-Debate elicits domain priors k = Elicit(q, c), which
serve as a shared analysis contract for all agents. Concretely, k captures a characterization of the task/domain
implied by q, domain constraints and expected patterns, salient signal attributes to attend to, a high-level
recommended analysis procedure, common failure modes and pitfalls, and guidance on which modalities are
likely most informative for the query. This step mitigates a common failure mode in zero-shot reasoning:
analyzing complex signals without first anchoring the interpretation to task semantics, domain-appropriate
methodology, and constraints.
Time-Frequency Views. From x1:T , we derive multiple representational views that support complementary
reasoning styles. In particular, we construct
• Temporal View (vtime): a time-domain representation emphasizing trends, change points, and extrema.
• Spectral View (vfreq): a frequency-domain representation highlighting periodicities and oscillatory struc-
ture (e.g., seasonality and recurring events).
• Feature/Statistical View (vfeat): summary statistics and detected events (e.g., peaks, troughs, and
anomalies) that support precise quantitative checks.
These views are not intended to be exhaustive. They provide a minimal set of perspectives that empirically
cover common TSR needs across heterogeneous tasks.
Visual and Numerical Query Interfaces. TS-Debate exposes these views through two explicit interfaces.
• Visual Interface. We generate a time-domain chart Charttime and a frequency-domain chart Chartfreq as
the input substrate for the visual analyst. This interface is designed to surface global structure (e.g., trend,
volatility regimes, and periodicity) that can be difficult to infer from numerical probes.
• Numerical Interface. We provide controlled tool access to the underlying time series and derived
attributes. At a conceptual level, this interface (denoted Lookup(·)) supports querying values over intervals,
probing neighborhoods around a point, retrieving detected events/features, and obtaining frequency-domain
information. This interface is essential for verifiability, enabling agents to ground claims in concrete values
and reducing ambiguity introduced by visual approximation.
Together, these interfaces treat multimodality not merely as heterogeneous inputs, but as composable evidence
channels with complementary strengths. Text provides task semantics and context, visualization captures
global patterns, and numerical access provides precision for checking and resolving disagreements.
3.4
Multimodal Collaborative Debate
TS-Debate uses collaborative debate as a structured mechanism to elicit diverse evidence without turning the
interaction into an adversarial contest. The objective is to explore and refine hypotheses across modalities
while explicitly acknowledging uncertainty and modality-specific limitations.
Modality-Specialized Analysts. For each modality m ∈M, TS-Debate instantiates an analyst Am. Here,
• Text analyst AT(q, c, k) interprets contextual constraints and any textual descriptions. It does not perform
numerical verification directly.
• Visual analyst AV(q, Charttime, Chartfreq, k) extracts qualitative, global structure from the generated charts.
• Numerical analyst AN(q, Lookup(x1:T ), k) invokes numerical queries to produce precise, checkable state-
ments about values and derived features.
All analysts share the same k, ensuring that disagreements arise from evidence and representational differences
rather than inconsistent task interpretations.

3.5
Verification-Conflict-Calibration (VCC) Protocol
Evidence generation alone is insufficient for reliable zero-shot reasoning. Multimodal debate can surface
diverse hypotheses, but without disciplined validation and disagreement handling, diversity can also amplify
error. We therefore introduce a VCC protocol that enforces explicit verification against available sources,
explicit conflict modeling, and calibrated answer synthesis.
A key motivation for VCC is to encourage monotonic improvement as additional high-quality modalities are
added. When new evidence is verifiable and domain-consistent, it should expand the support set or resolve
conflicts rather than degrade performance. While this is not a formal guarantee for arbitrary LLM behavior,
the protocol is designed so that additional verified evidence increases error detection and correction, and
unresolved conflicts lead to conservative calibration rather than brittle overconfidence.

Explicit Conflict Modeling.
After verification, reviewers indicate whether there exist outstanding
conflicts among analysts’ evidence and interpretations via ∆j ∈{∆NO_CONFLICT, ∆DETECTED, ∆RESOLVED}.
Here, ∆DETECTED indicates incompatible claims or interpretations with no verified resolution; ∆RESOLVED
indicates that conflicts were resolved through verification and domain constraints; and ∆NO_CONFLICT indicates
that evidence is mutually consistent (or immaterial to the answer).
Why explicit conflicts matter. Averaging or voting over conflicting rationales can be brittle in time-series
settings. Modalities can disagree for principled reasons (e.g., a trend appears visually but disappears under
numerical scrutiny), and a “majority” can be wrong if it shares the same methodological flaw. VCC therefore
handles conflicts explicitly, so that disagreements trigger additional verification or conservative calibration
rather than being smoothed away.
At the synthesizer (meta-reviewer) level, we summarize disagreement in two ways.
First, the answer
agreement pattern Γ ∈{ΓUNANIMOUS, ΓSPLIT, ΓALL_DIFFERENT} captures whether reviewers converge on
the same answer. Second, the resolution type Λ ∈{ΛVERIFIED_RESOLUTION, ΛUNRESOLVED, ΛNO_CONFLICT,
ΛAPPROACH_ERROR} indicates whether disagreements were settled by verified evidence, remain unresolved,
are absent, or stem from reviewers following an incorrect approach relative to k. This separates genuine
ambiguity from methodological error.

VCC record uj = (ˆaj, {(Vj(ω), Dj(ω))}ω∈Ω, ∆j, {sj,m}m∈M). Calibration follows explicit rules grounded
in verification and conflict status.
• If the key claims supporting ˆaj are VVERIFIED and DMATCHES, and ∆j = ∆NO_CONFLICT, the answer may be
stated confidently.
• If key claims are VUNVERIFIED or ∆j = ∆DETECTED, the answer must be conservative and explicitly reflect
uncertainty.
• If a claim is DVIOLATES, it is rejected even if it appears plausible from a single modality.
Temporal scope further modulates calibration. For past-present tasks, direct verification against x1:T dominates.
For future-oriented tasks, TS-Debate cannot verify future outcomes from past data; instead, it evaluates
whether the causes of observed patterns plausibly persist under domain knowledge k. This discourages naive
extrapolation (“the trend continues because it has continued”) and promotes conditional predictions grounded
in domain plausibility.
Finally, the synthesizer produces ˆa and is explicitly not a vote counter. It evaluates reviewers’ reasoning quality
based on their VCC records uj and selects (or reconstructs) the final answer using verified, domain-consistent
evidence. Concretely, it performs an approach check to assess whether each reviewer followed the analysis
procedure implied by k and respected temporal scope; reviewer scoring on a fixed rubric (each criterion
scored 0–20) covering task understanding, evidence usage, verification discipline, conflict handling, and
calibration; and decision synthesis that prioritizes answers supported by verified evidence and correct
methodology. If all reviewers exhibit approach errors (ΛAPPROACH_ERROR), the synthesizer re-verifies the most
decision-critical claims and derives an answer directly.
As a result, TS-Debate outputs a final answer ˆa that reflects both verification strength and unresolved conflict.

15.06%–28.75% improvements over prior methods. These gains suggest more effective integration of
temporal evidence from multiple aspects of time series for context-grounded QA.

Conclusions
We presented TS-Debate, a collaborative debate framework for zero-shot time series reasoning. The framework
enables text, visual, and numerical agents to exchange complementary evidence, while a lightweight reviewer
executes targeted code and lookup operations to verify numerical claims and resolve cross-modal conflicts.
Extensive evaluation across three benchmarks spanning 20 tasks and diverse domains shows that TS-Debate
consistently outperforms strong single-agent and multi-agent baselines, with particularly pronounced gains
in settings prone to conflicting cues, numerical hallucinations, and sparse prior knowledge, highlighting the
promise of structured debate for reliable zero-shot time series reasoning.
Limitations and Future Work.
While short collaborative debates are generally effective, performance
can degrade for long-horizon causal reasoning or highly noisy multivariate time series where visual trends and

B.1
Dataset Descriptions
We evaluate our approach on three public benchmarks comprising a total of 20 tasks. These benchmarks are
selected to stress complementary aspects of time-series reasoning, including multimodal grounding with rich
textual context, sensor-based classification under domain shift, and broad multi-task question answering (QA)

• MTBench (Chen et al., 2025). MTBench is a multimodal time-series benchmark that pairs numeric

spanning finance and weather domains, including trend classification, forecasting, indicator prediction,
correlation classification, and multiple-choice question answering (MCQA). MTBench includes both short-
and long-window settings with distinct temporal granularity regimes, e.g., 1-hour resolution with 7-day
input windows and 5-minute resolution with 30-day input windows.
• TimerBed (Liu et al., 2025b). TimerBed is a diverse time-series classification benchmark covering multiple
sensor-based domains, including healthcare, human activity recognition (HAR), bioacoustics, energy, and
geophysics. The benchmark is available at https://github.com/AdityaLab/TimerBed. We evaluate six
datasets with varying sequence lengths and between 2 and 7 classes. Specifically, these include ECG signals
for cardiac rhythm classification (4 classes), HAR using 3-axis accelerometer data (6 classes), EMG signals
for muscle activity classification (3 classes), CTU energy usage data (2 classes), RCW whale call detection
(2 classes), and TEE lightning event classification (7 classes).

• TSQA (Kong et al., 2025a). TSQA is a large-scale, multi-task benchmark for time-series question answering,

B.2
Sampling Strategy
Running multi-agent LLM methods on the full evaluation splits (over 200K instances across all tasks) is
cost-prohibitive. We therefore use a cost-aware but distribution-preserving sampling protocol that caps
per-task evaluation instances and stratifies sampling along the benchmark-defined axes most correlated with
task difficulty.
Main Experiments. For each task and each run, we sample n = min(100, available_test_instances)
instances. Tasks with fewer than 100 instances (e.g., EMG: 41, TEE: 73) use the full available set.
Ablation and Hyperparameter Studies. For each task, we sample 20 instances and run each ablation
configuration once, using a fixed seed.
Stratification. We apply benchmark-specific stratification as follows.
• MTBench (trend/forecasting/indicator/correlation): stratify by input source (short-window 7d vs.
long-window 30d).
• MTBench (MCQA): random sampling (uniform).
• TimerBed: hybrid stratification by class label (class-balanced) and sequence length buckets (difficulty
proxy).
• TSQA (anomaly/classification): stratify by domain.
• TSQA (forecasting/imputation): difficulty-stratify by input length.
• TSQA (QA): stratify by domain and question type (open-ended, multiple choice, and True/False).
Reproducibility. We set temperature = 0 and seed both sample selection and LLM calls. Sample selection
uses seed = 2025 + run_id (e.g., run 1 uses seed 2026).
Sample Representativeness. We validate sampling effects using chi-squared (χ2) tests where applicable.
For TSQA, stratified sampling preserves the original task distribution (χ2 = 1.38, p = 0.85). For MTBench,
capping at 100 samples per task intentionally balances task representation across finance and weather domains,
while preserving original proportions. For TimerBed, we employ hybrid class-balanced sampling with difficulty
stratification to ensure representative coverage of all class labels within each dataset.
B.3
Baselines
We implement and evaluate eight baselines covering single-agent prompting, multi-agent deliberation, and
time series-specific visual grounding. All baselines use the same backbone LLM and an identical chart
generation pipeline for multimodal variants. This design ensures that performance differences arise from the
underlying reasoning protocols, rather than from confounding architectural or implementation factors.
• Zero-Shot. A single LLM invocation that directly produces the final answer. We report both time
series-only and multimodal variants (+MM), where the latter receives the same textual context as well as
time- and frequency-domain visualizations as other multimodal methods.
• CoT (Wei et al., 2022). A single-agent chain-of-thought prompting baseline, evaluated in both time series-
only and multimodal settings (+MM). The prompt is intentionally kept minimal to avoid task-specific
engineering and to preserve comparability with the zero-shot setting.
• Multi-Agent Debate (MAD) (Liang et al., 2024). A multi-agent deliberation framework in which
multiple agents iteratively critique and refine each other’s responses. We follow the standard debate protocol
and introduce a multimodal extension (+MM) that supplies the same textual context as well as time- and
frequency-domain charts, ensuring parity with the information available to TS-Debate.

Framework Configurations
Backbone LLM. Unless otherwise noted, all experiments use gpt-4.1-mini with temperature = 0 as
discussed in §C.4.
Modalities and Tools. TS-Debate instantiates three modality-specialized analysts: Text (context ground-
ing), Visual (pattern recognition from plots), and Numerical (precise value retrieval via bounded lookup

calls per agent type (small constants) and expose only read-only lookup functions (e.g., value queries, feature
queries, frequency features) plus a restricted Python executor for verification.

C.4
Backbone Selection
We evaluate three API-accessible backbones—gemini-2.5-flash, gpt-4.1-mini, and grok-4.1-fast—
under the identical setup as the main experiments, using the same task suite, data sampling, multimodal
chart generation, hyperparameters, and fixed random seeds. Each backbone is evaluated once, ensuring that
performance differences are attributable solely to model capability.
Selection Criterion. As reported in Table 8, gpt-4.1-mini offers the best overall trade-off between
average task performance, inference latency, and estimated API cost. It achieves strong results across
classification, regression, and question answering, while remaining computationally efficient. We therefore
adopt gpt-4.1-mini as the default backbone for all main experiments.
Rationale for Non-Reasoning Backbones. Our objective is to evaluate whether TS-Debate provides an
explicit and portable reasoning scaffold for time-series understanding, rather than leveraging backbone-specific
internal reasoning mechanisms. Using specialized reasoning models would obscure attribution by conflating
protocol-level gains with proprietary chain-of-thought behaviors. We thus focus on fast, general-purpose
backbones to ensure that observed improvements stem from the proposed debate and verification framework.
