The incompatibility of the Condorcet winner and loser criteria
with positive involvement and resolvability
Wesley H. Holliday
University of California, Berkeley
wesholliday@berkeley.edu
Published in Economics Letters, Vol. 262, 2026, 112868.
Abstract
We prove that there is no preferential voting method satisfying the Condorcet winner and loser criteria,
positive involvement (if a candidate x wins in an initial preference profile, then adding a voter who ranks
x uniquely first cannot cause x to lose), and n-voter resolvability (if x initially ties for winning, then x
can be made the unique winner by adding some set of up to n voters). This impossibility theorem holds
for any positive integer n. It also holds if either the Condorcet loser criterion is replaced by independence
of clones or positive involvement is replaced by negative involvement.

Introduction
In the theory of preferential voting, where voters submit rankings of the candidates, there is a fundamental
tradeoff when selecting a voting method between ensuring desired variable-voter properties, ensuring desired
variable-candidate properties, and ensuring that ties are not too common. In this note, we prove an impos-
sibility theorem illustrating this tradeoff. The relevant variable-voter axiom is that of positive involvement
(Saari 1995, Pérez 2001, Holliday and Pacuit 2021): if a candidate x wins in an initial preference profile,
then adding a voter who ranks x uniquely first cannot cause x to lose. Alternatively, we can use negative
involvement (Fishburn and Brams 1983, Pérez 2001): if a candidate x loses in an initial preference profile,
then adding a voter who ranks x uniquely last cannot cause x to win. According to Pérez (2001, p. 605),
these axioms “may be seen as the minimum to require concerning the coherence in the winning set when new
voters are added.”1 On the candidate side, although the famous Condorcet winner and loser criteria (Con-
dorcet 1785) are not explicitly variable-candidate axioms, they can be motivated by considering candidates
dropping out or joining the race: one might think that if x would win (resp. lose) in every two-candidate
sub-election, then x should still win (resp. lose) in the full election—or else the election outcome might be
seen as too contingent on which other losing candidates happened to stay in the race. Instead of the Con-
dorcet loser criterion, we can use the explicitly variable-candidate axiom of independence of clones (Tideman
1987). Finally, for a formalization of the idea that a voting method should not make ties too common, we
use the resolvability axiom (Tideman 1986, 1987) that if x is initially tied for winning, then x can be made

Setup
Given infinite sets V and X of possible voters and possible candidates, respectively, a profile P is a function
assigning to each voter i in some nonempty finite set V (P) ⊆V a strict weak order P(i) on some nonempty
finite set X(P) ⊆X of candidates. We call P linear if for each i ∈V (P), P(i) is a linear order. All
results to follow continue to hold if all profiles are linear. If P and Q are profiles with V (P) ∩V (Q) = ∅
and X(P) = X(Q), then P + Q is the profile with V (P + Q) = V (P) ∪V (Q) such that for i ∈V (P),
(P + Q)(i) = P(i), and for i ∈V (Q), (P + Q)(i) = Q(i).
Given x, y ∈X(P), the margin of x vs. y in P is the number of voters who rank x above y minus the
number who rank y above x: MarginP(x, y) = |{i ∈V (P) | (x, y) ∈P(i)}| −|{i ∈V (P) | (y, x) ∈P(i)}|.
The margin graph M(P) of P is the weighted directed graph whose set of vertices is X(P) with an edge
from x to y when MarginP(x, y) > 0, weighted by MarginP(x, y).
A voting method is a function F assigning to each profile P a nonempty subset F(P) ⊆X(P). This
builds an assumption of “universal domain” into the definition of a voting method.
Definition 1. Let F be a voting method.
1. F satisfies the Condorcet winner criterion if for every profile P and x ∈X(P), if MarginP(x, y) > 0
for all y ∈X(P) \ {x} (so x is a Condorcet winner), then F(P) = {x}.
2. F satisfies the Condorcet loser criterion if for every profile P and x ∈X(P), if |X(P)| > 1 and
MarginP(y, x) > 0 for all y ∈X(P) \ {x} (so x is a Condorcet loser), then x ̸∈F(P).
3. F satisfies positive involvement if for every profile P, x ∈X(P), and profile Px with V (P)∩V (Px) = ∅
and X(P) = X(Px), if x ∈F(P) and Px consists of a single voter who ranks x uniquely first, then
x ∈F(P + Px).
4. F satisfies resolvability if for every profile P, if |F(P)| > 1, then for each x ∈F(P), there is some
single-voter profile S with V (P) ∩V (S) = ∅and X(P) = X(S) such that F(P + S) = {x}.2
Each of the axioms in Definition 1 is independent of the others. The Borda count (Borda 1784) satisfies
all the axioms except the Condorcet winner criterion. Minimax (Simpson 1969, Kramer 1977) satisfies all
of them except the Condorcet loser criterion.3 Ranked Pairs (Tideman 1987) satisfies all of them except
positive involvement. Split Cycle (Holliday and Pacuit 2023) satisfies all of them except resolvability.

Below we prove that there is no voting method satisfying all the axioms in Definition 1. The proof involves
reasoning about profiles with five candidates. It extends the strategy of Holliday 2024, which showed that for
four candidates, the axioms are jointly inconsistent with an additional axiom of ordinal margin invariance.
We leave open whether the axioms are jointly satisfiable without ordinal margin invariance if we only ask
for a voting method defined on four-candidate profiles. If we restrict the domain to two- or three-candidate
profiles, then the axioms are satisfied by the Minimax voting method.
The impossibility proof in the next section makes use of the following concept (cf. Kasper et al. 2019,
Holliday 2024).
Definition 2. Given a profile P, the defensible set D(P) of P is the set of candidates x ∈X(P) such that
for all y ∈X(P), there is a z ∈X(P) such that MarginP(z, y) ≥MarginP(y, x).
The following lemma is essentially Lemma 3 of Pérez 1995 (cf. Lemma 1 of Pérez 2001), which is in turn
an adaptation of a similar result of Moulin 1988, but we include a proof for convenience.
Lemma 3 (Moulin 1988, Pérez 1995). Let F be a voting method satisfying the Condorcet winner criterion
and positive involvement. Let P be a profile in which for all x, x′, y, y′ ∈X(P) with x ̸= x′ and y ̸= y′, if
MarginP(x, x′) > MarginP(y, y′), then MarginP(x, x′) > MarginP(y, y′) + 1. Then F(P) ⊆D(P).
Proof. Let F be such a method and x ∈F(P).
For contradiction, suppose x ̸∈D(P).
Then there is
a y ∈X(P) such that for every z ∈X(P), MarginP(z, y) < MarginP(y, x), which implies y ̸= x.
Let
k = max{MarginP(z, y) | z ∈X(P), z ̸= y}, so k < MarginP(y, x). If k < 0, then y is the Condorcet
winner in P, so F(P) = {y} by the Condorcet winner criterion, which contradicts x ∈F(P). Thus, k ≥0.
By our assumption about P in the lemma, k + 1 < MarginP(y, x). Let P′ be obtained from P by adding
k + 1 voters who rank x uniquely first and y uniquely second, followed by any linear order of X(P) \ {x, y}.
Hence by repeated application of positive involvement, x ∈F(P′). But y is the Condorcet winner in P′, so
F(P′) = {y} by the Condorcet winner criterion, which contradicts x ∈F(P′). Thus, x ∈D(P).

Remark 5. Inspection of the proof of Theorem 4 shows that resolvability can be replaced by quasi-
resoluteness (in the terminology of Holliday and Pacuit 2023): |F(P)| = 1 for any profile P that is uniquely
weighted in the sense that for all x, y, x′, y′ ∈X(P) with x ̸= y and x′ ̸= y′, if (x, y) ̸= (x′, y′), then
MarginP(x, y) ̸= MarginP(x′, y′).
It also shows that resolvability can be replaced by singleton positive
involvement (which Richelson (1978) calls voter adaptability), according to which F(P) = {x} implies
F(P + Px) = {x} (the analogous point applies to Theorem 7 and what Brandt et al. (2025) call singleton
negative involvement).6 This formulation with positive involvement and singleton positive involvement has
an implication for probabilistic voting methods if we regard F(P) as the support of a probability distribu-
tion: the Condorcet winner and loser criteria are jointly inconsistent with the axiom that adding a voter who
ranks x uniquely first never lowers x’s probability of winning (from positive to 0 or from 1 to less than 1).
The same proof strategy can be used to show that for each positive integer n, resolvability can be replaced
by n-voter resolvability: for every profile P, if |F(P)| > 1, then for each x ∈F(P), there is a profile Q with
|V (Q)| ≤n, V (P) ∩V (Q) = ∅, and X(P) = X(Q) such that F(P + Q) = {x}.7
