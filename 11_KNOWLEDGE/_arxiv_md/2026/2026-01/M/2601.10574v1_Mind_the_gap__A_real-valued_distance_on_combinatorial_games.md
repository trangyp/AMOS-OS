Abstract. We define a real-valued distance metric wd on the space C of
short combinatorial games in canonical form. We demonstrate the existence
of Cauchy sequences informed by sidling sequences, find limit points, and in-
vestigate the closure C, which is shown to partition the set of loopy games in
a non-trivial way. Stoppers, enders, and non-stopper-sided loopy games are
explored, as well as the topological properties of (C, wd).
1. Introduction
A combinatorial game is a two-player turn-based strategy game with perfect
information and no chance elements. Under the normal play convention the first
player unable to move on their turn is the loser. Players are traditionally referred
to as Left (with moves and pieces colored blue) and Right (with moves and pieces
colored red). By convention we denote a game by G = {GL|GR}, where GL is the
set of games Left can move to on their turn (called Left’s options), and GR the set of
options available to Right. For a full introduction to Combinatorial Game Theory
see [2] and [1]. Throughout this manuscript we will use the notation {x|y||z|w} (and
its recursive analog) to denote {{x|y}|{z|w}}. We make use of a bespoke Python
script for generating tikz diagrams to visualize game graphs, which is dependent on
the excellent CGSuite software package [6]. In addition, many of our calculations
could not have been completed without CGSuite, in which we both used default
functions and wrote a number of scripts for this express purpose.
Definition 1.1. A follower in a combinatorial game is a game reachable from that
game during play. A combinatorial game is short if no position can be repeated
and there are only a finite number of followers.
A short combinatorial game is in canonical form if it contains no dominated
or reversible options. For example, the game {∗, 1|0} simplifies to {1|0} since ∗is
dominated by 1 for Left. So {∗, 1|0} is not in canonical form. For the definition of
reversibility we paraphrase [1].

We let C denote the set of all short combinatorial games in canonical form.
A short game can be visualized as a rooted tree with edges colored blue and
red. However, since every short game G has a single source (the game itself) and
a single sink (the game 0) we can also represent any short game G by a bicolored
directed acyclic graph, or DAG, which can be generated from a tree by identifying
nodes that represent the same game. We will use D(G) to represent the DAG of
short game G, or simply G where the context is clear. See Fig. 1 for an example.
As another example consider the game G = {∗, 1|0} from above, which we saw
is not in canonical form. Because G is equivalent to the game {1|0} ∈C, we say
that D(G) collapses to D({1|0}). If G = {x|y} with x < y both numbers then G

Not all combinatorial games are short. Some involve the possibility of infinite
play.
Definition 1.3. A game is loopy if it has a follower that can be returned to at
some point during play.
If a game is loopy then it cannot be represented by a finite DAG, as a finite rep-
resentative graph requires cycles. There is also no currently agreed upon convention
for canonical forms of loopy games (though there has been work on expressing a
loopy game in its simplest form [4, 7]). However, if we allow for infinite graphs then
we can realize loopy games without the need for cycles. Consider on = {on|}, the
game where Left can move back to on and Right has no options. Traditionally on
is visualized as a single vertex with a single blue loop, but we can also draw it as
an infinite directed path of blue edges.
Note that not all games that are not short are loopy. We also have loop-free
infinite games, games with an infinite number of followers. Consider, for example,
the game ω, realized in game notation as {0, 1, 2, . . . |}. Left has infinitely many
options but there is no repetition possible, and the game will always end in a finite
number of moves.
A loopy game in which all cycles have length 1 is called a plum tree, of which
on is a named example, along with dud = {dud|dud} (which stands for deathless
universal draw), over = {0|over}, upon = {upon|∗}, and many others. Of note
is that the sum of on and off (another name for −on) is not 0 but dud, since
neither player has a move other than to return to the starting position.
Continuing our definitions around non-short games, it’s important to differenti-
ate between games that can stop and those that will stop. We now define two new
terms simultaneously.
Definition 1.4. A game that, when played in isolation in alternating play, cannot
continue forever without stopping is a stopper. A game in which it is impossible to
have an infinite series of moves, even under non-alternating play, is an ender.

2. Sequences in metric spaces
In this section we define some relevant terms from Analysis that will be useful
in later sections.
Definition 2.1. A distance metric d on a space W is a real-valued function on
W × W with the following properties.
For any a, b, c ∈W
(1) d(a, a) = 0
(2) If a ̸= b then d(a, b) > 0
(3) d(a, b) = d(b, a)
(4) d(a, b) ≤d(a, c) + d(c, b).
The pair (W, d) is a metric space.
Definition 2.2. A sequence (an) in a space W is Cauchy under a distance metric
d if, for any ϵ > 0, there is some N ∈Z such that ∀n, m > N, d(an, am) < ϵ.
Next, in order to define the closure of a space, we must first define limit points.

Definition 2.3. A limit point (or accumulation point) x of a metric space (W, d)
is an object such that for any ϵ > 0, there is at least one element w ∈W \ {x} with
d(w, x) < ϵ.
If d is a metric that extends to all limit points of W then we can define the closure
of (W, d) to be W along with all of its limit points, denoted W. For example, the
closure of Q under the euclidean metric is R, and since the euclidean metric is
defined on the irrationals we can use the same metric on R.
If d is not defined on the limit points of W then we must define the completion of
(W, d). Two distinct Cauchy sequences (an), (bn) can get arbitrarily close to each
other. Sequences like this, where d(an, bn) →0, are called equivalent sequences.
Equivalence of Cauchy sequences defines an equivalence relation on the space of
all Cauchy sequences in (W, d).

3. Diminishing weight distance
We are now ready to define our distance metric.
Definition 3.1. Let G, H ∈C.
An edit sequence from G to H is a sequence
of colored edge removals and/or additions that turns D(G) into a colored DAG
isomorphic to D(H), without changing which vertex is the source. If at any point
a vertex becomes isolated then it is removed from the digraph.

Theorem 3.2. Diminished weight distance is a distance metric on C.
Proof. We must show that (C, wd) has the following properties.
(1) wd(G, G) = 0 for all G ∈C
(2) If G ̸= H then wd(G, H) > 0
(3) For all G, H ∈C, wd(G, H) = wd(H, G)
(4) For all G, H, J ∈C, wd(G, H) ≤wd(G, J) + wd(J, H).
We prove these in turn.
(1) If G ∈C then the lowest total cost edit sequence from D(G) to D(G) is the
identity sequence with no edits. Thus wd(G, G) = 0.
(2) If G ̸= H then every edit sequence from G to H requires at least one edit,
and edit cost is positive. Hence wd(G, H) > 0.

(3) Let S be a minimum cost sequence of edits to turn D(G) into D(H). Re-

sequence to turn D(H) into D(G). If there was a sequence S′ to get from

(4) We finish with the triangle inequality. Consider G, H, J ∈C and let S1, S2
be edit sequences that take D(G) to D(J) and D(J) to D(H), respectively.
Since each sequence fixes the source vertex of each digraph, the sequence
S1 + S2 (the first sequence followed by the second) has total cost equal to
the sum of the costs of the two sequences. Thus S1 +S2 is an edit sequence
from D(G) to D(H) which cannot have lower cost than wd(G, H). And so
wd(G, H) ≤wd(G, J) + wd(J, H).

4. Other distance metrics
There are a number of alternative potential distance metrics on C, which we will
devote this section to discussing. Firstly, let’s consider some simpler metrics.
The simplest metric on any space is the discrete metric, under which every pair of
games has distance 1 if they are distinct and distance 0 if they are the same. There
is not much else to say about this metric, so we move on to some of potentially
more interest.

ruleset. However, the associated boards in K¯onane become unmanageably large
quite fast, and we also do not wish to bias our distance metric towards this ruleset.

5. Conclusion and remaining questions
We have motivated the case for, and developed, a real-valued distance metric
on the set of all short combinatorial games in canonical form, and have provided
a number of loopy games in the closure of the resulting metric space. In doing so
we have investigated sidling sequences, as well as sequences of finite games that do
not sidle.
Loopy games are partitioned into stoppers and non-stoppers, enders and non-
enders, and even stopper-sided and non-stopper-sided.
We have now seen that
the distance metric wd distinguishes loopy games yet again, those in C and those
outside of it. We have not seen a plum tree that is not in C, nor a non-stopper-sided
game in C. However, we have seen some non-stoppers in C and others that are not.
The following questions remain.
(1) Are all plum trees in C?
(2) Are any non-stopper-sided games in C?
(3) What distinguishes non-stoppers in C from those not in C?
We have also not addressed Cauchy sequences composed entirely of infinite
DAGs. Could sequences of this form help us expand C?
