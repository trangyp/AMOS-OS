Abstract—Self-regulating random walks (SRRWs) are decen-
tralized token-passing processes on a graph allowing nodes to
locally fork, terminate, or pass tokens based only on a return-time
age statistic. We study SRRWs on a finite connected graph under
a lazy reversible walk, with exogenous trap deletions summarized
by the absorption pressure Λdel = P
u∈Ptrap ζ(u)π(u) and a
global per-visit fork cap q. Using exponential envelopes for
return-time tails, we build graph-dependent Laplace envelopes
that universally bound the stationary fork intensity of any age-
based policy, leading to an effective triggering age Aeff. A
mixing-based block drift analysis then yields controller-agnostic
stability limits: any policy that avoids extinction and explosion
must satisfy a viability inequality (births can overcome Λdel
at low population) and a safety inequality (trap deletions plus
deliberate terminations dominate births at high population).
Under corridor-wise versions of these conditions, we obtain
positive recurrence of the population to a finite corridor.
Index Terms—Decentralized Systems, random walks, token
passing, fault tolerance, Markov chains.
I. INTRODUCTION
Decentralized algorithms enable processing and learning
over large-scale networks without relying on an omniscient
central coordinator. In many applications, information is prop-
agated by tokens that move across the network according to a
random walk (RW) on a communication graph. This leads to
communication-efficient protocols in which only a few nodes
are active at each time instance. Examples include RW-based
decentralized learning/optimization and message passing; see,
e.g., [1]–[5].
A central challenge is failure resilience. If a token is lost
due to a node or link failure, then the corresponding RW
trajectory (and the carried computation) is disrupted. Recent
work has proposed self-regulating random walks (SRRWs) and
closely related self-duplicating mechanisms as lightweight,
fully decentralized approaches to mitigate such losses and
improve robustness of RW-based learning (e.g., [6], [7]):
upon each token arrival, a node uses only locally available
information—typically the time since its last token visit (a
local “age” or return-time statistic)—to decide whether to (i)
pass the token, (ii) fork (duplicate) it into additional copies,
or (iii) deliberately terminate it to curb overload. Empirically

and algorithmically, carefully designed SRRW controllers can
maintain a desired token population and react to failures
without a central monitor.
At the same time, recent studies have highlighted funda-
mental vulnerabilities of RW-based decentralized learning un-
der localized adversarial disruptions, including Pac-Man-style
attacks [8]. These observations further motivate a principled
understanding of what behaviors are intrinsically attainable in
SRRW systems on a given graph.
Despite this progress, a basic question remains open: What
are the intrinsic limits of SRRWs, independent of the con-
troller? Here, a controller refers to the decentralized control
logic implemented at each node, which prescribes based only
on local age information (and possibly a coarse population
estimate), whether to fork, terminate, or pass a newly arrived
token. In practice, controllers are typically tuned by empir-
ically validating the performance of chosen local thresholds
and probabilities. It is not clear how to choose those thresholds
based on the network properties, nor which behaviors are
fundamentally attainable on a given network, and which are
ruled out by the geometry and mixing properties of the
underlying RW.
This paper takes a controller-agnostic viewpoint and focuses
on the most basic stability requirements for SRRW popu-
lations: viability (avoiding extinction) and safety (avoiding
explosion). We consider a finite, connected graph supporting
multiple tokens evolving as lazy RWs with a stationary
distribution π. A subset of nodes forms a trap set Ptrap:
when a token visits u ∈Ptrap, it is deleted with probabil-
ity ζ(u) ∈[0, 1], inducing an intrinsic absorption pressure
Λdel = P
u∈Ptrap ζ(u)π(u). At non-trap nodes, the controller
may fork or deliberately terminate tokens, subject to a per-visit
fork cap q ∈(0, 1] and a one-action-per-visit rule.
Our main technical tool is a pair of graph-dependent
Laplace envelopes built from return-time tails of the under-
lying lazy reversible walk. These envelopes universally bound
the stationary fork intensity achievable by any age-based
policy, and lead to a single scalar summary of the controller
via an effective triggering age Aeff, capturing the typical age
scale at which the policy acts in a steady state.

to node v. This process continues, with token communication
occurring at discrete time steps t. Therefore, the tokens move
through the graph as independent RWs.
B. Problem Formulation
Traps and actions. The problem we study is that of
token (or RW) failure throughout the process. We model the
failures by an arbitrary set Ptrap ⊆V of unreliable nodes.
When a token is visiting a node v ∈Ptrap, with probability
ζ(v) ∈[0, 1], the node will not propagate the token further,
thus permanently deleting the corresponding RW. With no
action taken to recover from failures, all RWs will eventually
be deleted. To recover from RW deletion, we consider a
decentralized policy that allows nodes to take actions based
on their local observations.
When a node u is visited by a token, it will run any
necessary task and take one of the following actions: (i) fork
the RW by creating a duplicate copy of the RW corresponding
to the visiting token and propagating the RWs to two different
neighbors; (ii) terminate the RW by not propagating the token
any further; or (iii) pass the token to a neighbor. We denote
by au(t) ∈{fork, terminate, pass} the action taken by
node u at time t. We restrict our attention to age-based actions.
Each node u maintains a return-time age of the tokens defined
as Au(t) := t −Lu(t), where Lu(t) is the last time step at
which u was visited by a token. The action taken by node u
will be based on Au(t).
