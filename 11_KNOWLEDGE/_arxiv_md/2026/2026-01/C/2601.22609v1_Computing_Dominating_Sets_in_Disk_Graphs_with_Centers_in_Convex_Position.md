Computing Dominating Sets in Disk Graphs with Centers in
Convex Position∗
Anastasiia Tkachenko†
Haitao Wang‡
Abstract
Given a set P of n points in the plane and a collection of disks centered at these points, the
disk graph G(P) has vertex set P, with an edge between two vertices if their corresponding disks
intersect. We study the dominating set problem in G(P) under the special case where the points of
P are in convex position. The problem is NP-hard in general disk graphs. Under the convex position
assumption, however, we present the first polynomial-time algorithm for the problem. Specifically,
we design an O(k2n log2 n)-time algorithm, where k denotes the size of a minimum dominating set.
For the weighted version, in which each disk has an associated weight and the goal is to compute
a dominating set of minimum total weight, we obtain an O(n5 log2 n)-time algorithm.
Keywords: disk graphs, dominating sets, convex position

Introduction
Let P = {p1, . . . , pn} be a set of n points in the plane, where each point pi ∈P is assigned a radius
rpi ≥0. Let Dpi denote the disk centered at pi with radius rpi. The disk graph G(P) has P as its vertex
set, with an edge between pi and pj if the two disks Dpi and Dpj intersect, i.e., |pipj| ≤rpi +rpj, where
|pipj| is the Euclidean distance of pi and pj. Disk graphs, including the unit-disk case, where all disks
have the same radius, arise naturally in numerous application domains, such as wireless sensor networks
(where devices with heterogeneous transmission ranges communicate when within range) [3,18,24,25],
surveillance networks [32], optimal facility location [10,34], etc.
Many classical problems on disk graphs are still NP-hard [10] and approximation algorithms have
been developed, such as vertex cover [14,22,33], independent set [14], feedback vertex set [4], dominating
set [17], etc. One exception is that finding a maximum clique in a unit-disk graph can be solved in
polynomial time [10,13,15]. But it has been a long standing open problem whether the clique problem
on general disk graphs can be solved in polynomial time; see [6, 19] for some recent progress on this
problem.
We are interested in the dominating set problem in disk graphs. A dominating set of G(P) is
a subset S ⊆P such that every vertex in G(P) is either in S or adjacent to a vertex in S. The
dominating set problem is to find a dominating set of minimum cardinality. In the weighted case, each
point of P has a weight, and the goal is to find a dominating set minimizing the total weight. The
problem is NP-hard even in unit-disk graphs [10]. Approximation algorithms have been proposed, e.g.,
[2,11,17,23].

1.1
Convex position setting and previous work
In light of the above hardness results, exploring structured settings that may allow efficient algorithms
is of particular interest. In this paper, we consider the dominating set problem in disk graphs in a
convex position setting where all points of P are in convex position, that is, every point of P appears
as a vertex of the convex hull of P. This setting models deployments along perimeters (e.g., fences,
shorelines, or rings of sensors) and, importantly, reveals strong structural relationships.
In this convex position setting, Tkachenko and Wang [31] studied the problem for the unit-disk case.
Specifically, they gave an O(n3 log2 n) time algorithm for the weighted dominating set problem, and
an O(kn log n) time algorithm for the unweighted case, where k is the size of a minimum dominating
set.
Other geometric problems in convex position have also been studied.
For the independent set
problem, which is to find a maximum subset of vertices of G(P) so that no two vertices have an edge,
an O(n7/2) time algorithm was given in [31] in the convex-position setting. The classical k-center
problem among a set of points in the plane is to find k congruent disks of smallest radius to cover all
points. The problem is NP-hard. Choi, Lee, and Ahn [9] studied the problem in the convex position
setting and proposed an O(n3 log n) time algorithm. For the discrete version of the problem where the
centers of the disks are required to be in the given point set, Tkachenko and Wang solved the problem
in O(n2 log2 n) time [31]. Given a set of points in the plane and a number k, the dispersion problem is
find k points so that their minimum pairwise distance is maximized. The problem is also NP-hard [34].
Singireddy, Basappa, and Mitchell [29] studied the problem in the convex position setting and gave an
O(n4k2) time algorithm. An improved algorithm of O(n7/2 log n) time was later derived in [31].
Even problems that are already polynomial-time solvable in the general case also attracted attention
in the convex position setting, e.g., the classic linear-time algorithm of Aggarwal, Guibas, Saxe, and
Shor [1] to construct Voronoi diagrams for a set of 2D points in convex position. Refer to [5,7,8,21,27,30]
for additional work in convex position setting.
1.2
Our result
We study the dominating set problem in disk graphs under the convex position setting.
While
polynomial-time algorithms are known for the unit-disk case [31], allowing disks of varying radii in-
troduces significant challenges. For instance, although a polynomial-time algorithm for computing a
maximum clique in unit-disk graphs was proposed more than 30 years ago [10], it remains unknown
whether the same problem can be solved in polynomial time for general disk graphs.
Nevertheless, we attempt to extend the techniques of [31] to the general disk graph setting. This
proves far from trivial, as many properties of the unit-disk case no longer hold. Even so, we uncover new
structural observations and develop novel algorithmic techniques. Consequently, we establish that the
dominating set problem in disk graphs under the convex position setting can be solved in polynomial
time.
Specifically, we present an O(n5 log2 n)-time algorithm for the weighted case. Furthermore, given
a size bound k, we can compute a minimum-weight dominating set of size at most k (if one exists) in
O(k2n3 log2 n) time. Our approach is a dynamic programming algorithm that leverages a key structural
property we prove, which we call the line-separable property. This property enables us to decompose
the original problem into smaller subproblems amenable to dynamic programming.
For the unweighted case, we design a more efficient algorithm by employing a greedy strategy,
achieving a running time of O(k2n log2 n), where k denotes the size of a minimum dominating set. In
particular, when k = O(1), our algorithm runs in O(n log2 n) time.
While problems in unit-disk graphs under the convex position setting have been studied previously,
to the best of our knowledge, little work has been done on general disk graphs in convex position. We
therefore hope that our result will stimulate further research in this direction.

Notation
We introduce some notations that will be used throughout the paper, in addition to those already
defined in Section 1, e.g., P, n, G(P), Dpi.
For any two points p and q in the plane, we use |pq| to denote their (Euclidean) distance. We also
use pq to denote the line segment connecting them.
Let H(P) denote the convex hull of P. We assume that the points of P are in convex position. Then
P can be considered a cyclic sequence around H(P). Specifically, let P = ⟨p1, p2, . . . , pn⟩represent a
cyclic list of the points ordered counterclockwise along H(P). We use a sublist to refer to a contiguous
subsequence of P. Multiple sublists are said to be consecutive if their concatenation is also a sublist.
For any two points pi and pj in P, we define P[i, j] as the sublist of P from pi counterclockwise to pj,
inclusive, i.e., if i ≤j, then P[i, j] = ⟨pi, pi+1, . . . , pj⟩; otherwise, P[i, j] = ⟨pi, pi+1, . . . , pn, p1, . . . , pj⟩.
Note that if i = j, then P[i, j] = ⟨pi⟩. We also denote by P(i, j] the sublist P[i, j] excluding pi, and
similarly for other variations, e.g., P[i, j) and P(i, j).
For any two points pi, pj ∈P, we define |DpiDpj| = |pipj| −(rpi + rpj), and we call it the disk
distance between Dpi and Dpj. If the two disks intersect, then |DpiDpj| ≤0; otherwise, |DpiDpj| > 0.
For any subset P ′ ⊆P, let D(P ′) = {Dpi | pi ∈P}. Sometimes we also say that disks of D(P) are
input disks. We emphasize that while the centers of the input disks, i.e., the points of P, are in convex
position, the disks themselves may not be, i.e., it is possible that an input disk Dpi is in the interior of
the convex hull of all disks of D(P).
3
Structural properties
We begin by examining the structural properties of dominating sets in G(P). We introduce these
properties for the weighted case, which are applicable to the unweighted case too.
For a sublist α of P, we say that a point pi ∈P dominates α if the disk Dpi intersects Dp for all
points p ∈α. For two points pi, pj ∈P, if Dpi intersects Dpj, then we also say that pi dominates pj
(and similarly, pj dominates pi).
Suppose S ⊆P is a dominating set of G(P). Let A be a partition of P into (nonempty) disjoint
sublists such that for every sublist α ∈A, there exists a point in S that dominates α. An assignment
is a mapping ϕ : A →S that assigns every sublist α ∈A to exactly one point pi ∈S such that pi
dominates α. For each pi ∈S, we define the group of pi, denoted by Api, as the collection of all sublists
α ∈A that are assigned to pi under ϕ. Depending on the context, Api may also refer to the set of
points of P in all its sublists. For example, if a point pj is in a sublist of Api, then we may write
“pj ∈Api”. By definition, the groups of all points of S are pairwise disjoint, and they together form a
partition of A and also form a partition of P.
An assignment ϕ : A →S is line-separable if for every two points pi, pj ∈S, there exists a line ℓ
such that the points of Api lie entirely on one side of ℓ, while the points of Apj lie on the other side.
The following lemma proves a line-separable property. As will be seen, the property is crucial for
our dominating set algorithms.
Lemma 1. Suppose S is an optimal dominating set of G(P). Then there exists a partition A of P and
a line-separable assignment ϕ : A →S such that (1) for every point pi ∈S, pi ∈Api, i.e., the group
Api contains pi itself, and (2) any two adjacent sublists of A are assigned to different points of S.

Proof. We first describe how to construct the partition A and the assignment ϕ, and then argue that
ϕ is line-separable.
Constructing A and ϕ.
Let VD(S) be the additively-weighted Voronoi diagram of the points of S
with the weight of each point p ∈S as −rp, i.e., the weighted distance dp(q) between any point q and
p is defined as |pq| −rp. Let R(p) denote the Voronoi cell of p in VD(S). Note that R(p) is star-shaped
and contains p [16,28].
Since S is an optimal dominating set, S does not have two points pi and pj such that Dpi ⊆Dpj
(since otherwise S \ {pi} is still a dominating set of G(P), contradicting the optimality of S). Because
of this, every point p of S has a non-empty Voronoi cell in VD(S) that contains p [16,28], i.e., p ∈R(p).
For each point pi ∈S, for every point p ∈P that is contained in R(pi), we assign p to the group
Api. If p lies on the boundary of two Voronoi cells, then we assign p to an arbitrary one of them. In
this way, each point p ∈P is assigned to exactly one point of S. In addition, since pi ∈R(pi), pi is
assigned to its own group Api (this guarantees the first condition in the lemma statement).
For each point pi ∈S, we make each contiguous maximal sequence of points of Api form a a sublist
(this guarantees the second condition in the lemma statement). Let A be the union of Api for all points
pi ∈S. The assignment ϕ simply follows from the above definition of groups Api. Note that A satisfies
both conditions in the lemma statement.
To show that A is a desired partition of P for S, it suffices to show, for any point pi ∈S, Dpi
intersects Dp for all points p ∈Api. Indeed, consider a point p ∈Api. Since S is a dominating set, Dp
must intersect Dpj for some point pj ∈S. Thus, dpj(p) ≤rp. Since p ∈Api, by our construction of
Api, p ∈R(pi). Hence, we have dpi(p) ≤dpj(p) ≤rp and thus Dp and Dpi intersect.
Proving the line-separable property.
It remains to prove that the assignment ϕ is line-separable.
Suppose to the contrary that there exist two groups Api and Apj (with pi, pj ∈S) that are not line-
separable. Then, since pi ∈Api and pj ∈Apj, there must be a point p ∈Api and a point p′ ∈Apj
such that pip and pjp′ cross each other. On the other hand, since p ∈Api, p is in R(pi). As R(pi) is
star-shaped with respect to pi [16,28], pip ⊆R(pi). Similarly, pjp′ ⊆R(pj). Since R(pi) and R(pj) are
interior disjoint, pip cannot cross pjp′. We thus obtain contradiction.
Following the notation in Lemma 1, for each center pi ∈S, we call the sublist of Api containing pi
the main sublist of pi, and all other sublists of Api are called secondary sublists.
Remark.
In the unit-disk case, for any optimal dominating set S, there always exists a partition A
and an assignment of ϕ such that for each pi ∈S, the group Api contains at most two sublists [31].
This property leads to a more efficient algorithm for the unit-disk case in [31]. Unfortunately, the
property no longer holds anymore for our general disk problem. Refer to Figure 1 for an example,
in which there is a large disk Dpi while other disks are disjoint and arranged in such a way that
they alternatively intersect and avoid Dpi. Assuming that all points have the same weight, pi will be
included in any optimal dominating set, and pi will be assigned Ω(n) sublists. Comparing with the
unit-disk case, this “unbounded” group size makes it substantially more challenging to design efficient
algorithms. Nonetheless, we demonstrate below that by relying solely on the line-separable property
from Lemma 1, we can still derive a polynomial-time algorithm.
We further have the following lemma, which will be instrumental in our algorithm design.
Lemma 2. Let S be an optimal dominating set of G(P), and let ϕ : A →S be the assignment given by
Lemma 1. Then, S has a point pi whose group Api only has a single sublist (which is the main sublist
of pi).

Proof. For each sublist α of A, we pick a point of α as its representative point. For each point pi ∈S,

4
The weighted dominating set problem
In this section, we present our algorithm for computing a minimum-weight dominating set in the disk
graph G(P).
For each point pi ∈P, let wi denote its weight. We assume wi > 0 since otherwise pi can always
be included in the solution. For any subset P ′ ⊆P, define w(P ′) = P
pi∈P ′ wi.
We will focus on the following bounded-size problem: Given an integer k, find a dominating set
S ⊆P of minimum total weight in G(P) subject to |S| ≤k. Solving this problem with k = n yields
a minimum-weight dominating set for G(P). Let W ∗denote the total weight of a minimum-weight
dominating set of size at most k.
The rest of this section is organized as follows. Section 4.1 first introduces a new concept rank-t
centers, which is crucial to our algorithm, and also provides an overview about our algorithm. Sec-
tion 4.2 gives the details of the algorithm while the correctness is proved in Section 4.3. The algorithm
implementation and time analysis are finally discussed in Section 4.4.
4.1
Rank-t centers and algorithm overview
Let S be an optimal dominating set of G(P) with |S| ≤k, and let ϕ : A →S be the assignment given
by Lemma 1 (note that the lemma was originally for an optimal dominating set without bounded-size
constraint, but the proof works for bounded-size optimal dominating set too).
Let α1, α2, . . . , αm be the sublists of A following the order of P, i.e., counterclockwise around H(P).
For any two sublists αg and αh, we define A[g, h] as the set of the sublists from αg counterclockwise to
αh inclusive. Depending on the context, A[g, h] may also refer to the union of all these sublists, which
form a sublist of P. We define S[g, h] as the subset of points p ∈S whose groups Ap contain a sublist
of A[g, h]. Note that if g = h, then A[g, h] refers to {αg}.

Definition 1. We say that a point pi ∈S is a rank-t center for A[g, h] if the following conditions are
satisfied: (1) |S[g, h]| ≤t; (2) at least one of αg and αh is in Api; (3) the main sublist of pi is in
A[g, h]; (4) if t > 1, then for each point pj ∈S[g, h] \ {pi}, Apj ⊆A[g, h], i.e., all sublists in the group
Apj are in A[g, h]; otherwise, Api ⊆A[g, h].
Note that this definition does not require Api ⊆A[g, h] if t > 1, and therefore it is possible that
some secondary sublists of Api are not in A[g, h]. We also say that A[g, h] in the above definition is a
rank-t sublist of pi. In addition, in the second condition of the definition, if exactly one of αg and αh
is in Api, then we call pi a rank-t open center, and if both αg and αh are in Api, then p a rank-t closed
center.
To see why the concept rank-t center is useful, observe that every point pi ∈S is a rank-k center
for some sublist A[g, h] that is P. Indeed, let αg ∈A be the main sublist of pi for some index g. Then,
since |S| ≤k, pi is a rank-k center for A[g −1, g] or A[g, g + 1], where the operations “g −1” and
“g + 1” are module m (we follow this convention in the rest of this section). Note that both A[g −1, g]
and A[g, g + 1] are P (and both S[g −1, g] and S[g, g + 1] are S).
In addition, at least one point pi ∈S is a rank-1 center of some sublist of A. Indeed, by Lemma 2,
there exists a center pi ∈S whose group Api has only its main sublist, denoted by αg. Then, pi is a
rank-1 center of the sublist A[g, g] = {αg}.
Algorithm overview.
Our algorithm is a dynamic program with k iterations. In each t-th iteration,
1 ≤t ≤k, we compute for each point pi ∈P a set Lt(i) of O(n2) sublists of P, with each sublist
L ∈Lt(i) associated with a value w′(L) and a subset SL ⊆P, such that the following algorithm
invariants are maintained: (1) w(SL) ≤w′(L); (2) SL dominates L; (3) pi ∈SL; (4) |SL| ≤t. Define
Lt = ∪pi∈P Lt(i).
To argue the correctness of the algorithm, we will show that for each point pi ∈P and each rank-t
sublist A[g, h] of pi, Lt(i) must contain a sublist L with A[g, h] ⊆L and w(SL) ≤w′(L) ≤w(S[g, h]).
Because every point pi ∈S is a rank-k center for some sublist that is P, after the k-th iteration, Lk
must contain a sublist L that is P with w(SL) ≤w′(L) ≤w(S) = W ∗, implying that SL is an optimal
dominating set (of size at most k). As such, after k iterations, among all sublists in Lk that are P, we
find the one L with minimum W ′(L) and return SL as the optimal dominating set. Note that because
at least one point pi ∈S is a rank-1 center of some sublist of A, our algorithm starts with t = 1.

After the k-th iteration, among all sublists of Lk that are P, we find the one L∗of minimum w′(L∗)
and return SL∗as our optimal dominating set of size at most k. If no sublist of Lk is P, then we report
that a dominating set of size at most k does not exist.

4.4
Time analysis and implementation
In the t-th iteration, 1 ≤t ≤k, the algorithm performs O(tn3) minimum-value enclosing sublist
queries: Given a sublist L of P, compute the minimum value sublist containing L in a set L of sublists.
This problem has been studied in [31]. We summarize the result in the following lemma.
Lemma 9. ( [31]) Given a set L of m sublists of P, each associated with a value, we can construct a
data structure for L in O(m log m) time, with m = |L|, so that each minimum-value enclosing sublist
query can be answered in O(log2 m) time.
In our algorithm, the total size of the involved sets L for which we need to construct the above
data structure is O(n3) in each iteration. Hence, the total time spent on these queries (including the
time for constructing the data structures) in the t-th iteration of the algorithm is O(tn3 log2 n) time.

Corollary 1. Given a set of n weighted disks whose centers are in convex position in the plane, we

can solve the unweighted problem in O(n5 log2 n) time. In the following, we provide an algorithm of
O(k2n log n) time, where k is the size of the smallest dominating set.
We follow the dynamic programming scheme of the weighted case, but incorporate a greedy strategy
by taking advantage of the property that all points of P have the same weight.
Section 5.1 first
describes the algorithm. The correctness proof is given in Section 5.2. Section 5.4 finally discusses the
implementation and the time analysis.

The t-th iteration computes O(t) sublists for Lt(i) for each point pi ∈P. Hence, a total of O(tn)

Time analysis and implementation
In each t-th iteration with 1 ≤t ≤k, we perform O(tn) operations for computing indices aj
i and bj
i and
O(tn) counterclockwise/clockwise farthest enclosing sublist queries: Given a point p ∈P, find from
a set L of sublists a sublist containing p with the farthest counterclockwise/clockwise endpoint from
p. Computing indices aj
i and bj
i takes O(log2 n) time by Lemma 10. The counterclockwise/clockwise
farthest enclosing sublist query problem has been studied in [31]; we summarize the result in the
following lemma.
Lemma 15. ( [31]) Given a set L of m sublists of P, we can construct a data structure for L in
O(m log m) time such that each counterclockwise/clockwise farthest enclosing sublist query can be an-
swered in O(log m) time.
In our algorithm, the total size of the involved sets L for which we need to construct the above data
structure is O(tn) in each t-th iteration. Hence, the total time of each t-th iteration is O(tn log2 n). As
there are k iterations, the runtime of the whole algorithm is O(k2n log2 n). We conclude this section
with the following theorem.
Theorem 2. Given a set of n disks whose centers are in convex position in the plane, a smallest dom-
inating set of the disk graph can be computed in O(k2n log2 n) time, where k is the smallest dominating
set size.
