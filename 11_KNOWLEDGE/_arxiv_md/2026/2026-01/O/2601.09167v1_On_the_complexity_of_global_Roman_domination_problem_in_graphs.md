Abstract
A Roman dominating function of a graph G = (V, E) is a labeling f : V →
{0, 1, 2} such that for each vertex u ∈V with f(u) = 0, there exists a vertex
v ∈N(u) with f(v) = 2. A Roman dominating function f is a global Roman
dominating function if it is a Roman dominating function for both G and
its complement G. The weight of f is the sum of f(u) over all the vertices
u ∈V . The objective of Global Roman Domination problem is to find
a global Roman dominating function with minimum weight.
In this paper, we study the algorithmic aspects of Global Roman Dom-
ination problem on various graph classes and obtain the following results.
1. We prove that Roman Domination and Global Roman Domi-
nation problems are not computationally equivalent by identifying
graph classes on which one is linear-time solvable, while the other is
NP-complete.
2. We show that Global Roman Domination problem is NP-complete
on split graphs, thereby resolving an open question posed by Panda and
Goyal [Discrete Applied Mathematics, 2023].
3. We prove that Global Roman Domination problem is NP-complete
on chordal bipartite graphs, planar bipartite graphs with maximum
degree five and circle graphs.
4. On the positive side, we present a linear-time algorithm for Global
Roman Domination problem on cographs.

1. Introduction
Roman Domination (RD) is a fascinating concept in graph theory,
inspired by the strategic placement of Roman legions to defend the Roman
empire efficiently. The concept of RD problem was introduced by Stewart [1]
in 1999. Given a graph G = (V, E), a Roman dominating function f : V →
{0, 1, 2} is a labeling of vertices such that each vertex u ∈V with f(u) = 0
has a vertex v ∈N(u) with f(v) = 2. The weight of a Roman dominating
function f is the sum of f(u) over all the vertices u ∈V . The minimum
weight of a Roman dominating function for G is denoted by γR(G). The
objective of RD problem is to compute γR(G).
A Roman dominating function f will be a global Roman dominating func-
tion if f is a Roman dominating function for both G and G. The minimum
weight of a global Roman dominating function f is denoted by γgR(G). The
objective of Global Roman Domination (GRD) problem is to compute
γgR(G).
The decision version of GRD problem is formally defined as follows.
Global Roman Domination:
Input: An instance I = (G, k), where G = (V, E) is an undirected
graph and an integer k.
Output: Yes, if there exists a function f : V →{0, 1, 2} such that
(1) P
u∈V f(u) ≤k,
(2) for every vertex u ∈V with f(u) = 0, there exist vertices v ∈NG(u)
and w ∈NG(u) such that f(v) = 2 and f(w) = 2; No, otherwise.
Liu et al. [2] proved that RD problem is NP-complete on split graphs and
bipartite graphs. They provided a linear-time algorithm for strongly chordal
graphs. RD problem also admits linear-time algorithms for cographs, interval
graphs, graphs of bounded clique-width and a polynomial-time algorithm for
AT-free graphs [3]. Fernau [4] studied RD problem in the realm of parame-
terized complexity and proved that the problem is W[2]-hard parameterized
by weight. They provided an FPT algorithm that runs in time O∗(5t), where
t is the treewidth of the input graph. In addition, for planar graphs, they

showed that RD problem can be solved in O∗(3.3723k) time. RD problem was
proved to be W[1]-hard parameterized by weight, even for split graphs [5].
Recently, Ashok et al. [6] provided an O∗(4d) algorithm for the Indepen-
dent Roman Domination (IRD) problem, where d is the cluster vertex
deletion set number.
Several studies have investigated the complexity differences between vari-
ous variants of Dominating Set (DS) problem. Duan et al. [7] proved that
RD problem and IRD problem differ in complexity aspects.
Chakradhar
et al. [8] showed that DS problem and Roman {3}-Domination problem
are not equivalent in terms of complexity. Mann et al. [9] demonstrated a
complexity distinction between Unique Response Roman Domination
problem and Perfect Roman Domination problem. It was proved that
DS problem and Total Roman {2}-Domination problem differ in com-
plexity [10].
Chakradhar [11] proved that DS problem and Restrained
Roman Domination problem are not equivalent in complexity. Along sim-
ilar lines, we construct a graph class F for which RD problem can be solved
in linear-time whereas GRD problem is NP-complete. We also construct a
graph class G for which GRD problem can be solved in linear-time, whereas
RD problem is NP-complete. Hence, we obtain that RD problem and GRD
problem are not computationally equivalent.
Panda et al. [12] proved that GRD problem is NP-complete on bipartite
graphs and chordal graphs. They also provided a polynomial-time algorithm
for threshold graphs. In addition, they proposed an O(ln |V |)-approximation
algorithm and showed that there does not exist an (1−ϵ) ln |V |-approximation
algorithm for any ϵ > 0, unless P = NP. Moreover, they also proved that
GRD problem is APX-complete for bounded-degree graphs.
We advance
the complexity study of the problem by proving that GRD problem is NP-
complete on split graphs, thereby resolving an open question posed by Panda
et al. [12].
We also show that GRD problem is NP-complete on chordal
bipartite graphs, planar bipartite graphs with maximum degree five and circle
graphs. We further present a linear-time algorithm for GRD problem on
cographs.
As cographs form a superclass of threshold graphs, our result
extends the known solution on threshold graphs.

3.1. Graph class: F
In this subsection, we construct a graph class F for which RD problem
can be solved in linear-time, whereas GRD problem is NP-complete.
Construction of H ∈F. Let G = (V, E) be a 3-regular graph. We create
three copies of G that are G1 = (V1, E1), G2 = (V2, E2) and G3 = (V3, E3).
Vertex u ∈V (G) is denoted by u1 in G1, u2 in G2 and u3 in G3 respectively.
For each vertex u1 ∈V1, we make u1 adjacent to every vertex in NG2(u2) and
NG3(u3). For each vertex u2 ∈V2, we make u2 adjacent to every vertex in
NG3(u3). We then introduce three vertices v1, v2 and v3 and make each of
them adjacent to every vertex in V1∪V2∪V3 to obtain the resultant graph H ∈
F. Formally F := {H | H is obtained from a 3-regular graph G by the above
procedure}. We show that RD problem is linear-time solvable on F whereas
GRD problem on F is NP-complete.
Lemma 2. γR(H) = 4 for every H ∈F.
Proof. Consider a graph H ∈F. One among the three vertices v1, v2 and
v3 is assigned the label 2 while the other two are assigned the label 1. All
the other vertices are assigned the label 0 in f. Each vertex with label 0 is
adjacent to v1 (or v2, v3) with label 2. Thus, we have that γR(H) ≤4.
In order to cover the vertices in V1 ∪V2 ∪V3, one vertex among {v1, v2, v3}
should be labeled 2.
As v1, v2 and v3 are non-adjacent, either both the
vertices that are not assigned the label 2 from {v1, v2, v3} should be labeled
1 or at least one vertex in V1 ∪V2 ∪V3 should be labeled 2. Thus, we have
that γR(H) ≥4.
Finally, we obtain that γR(H) = 4.
From Lemma 2, we have the following result.
Theorem 3.1. RD problem on graph class F is linear-time solvable.

From Lemmas 22 and 23, we have the following theorem.
Theorem 4.7. If G is a cograph then γgR(G) can be computed in linear-time.
5. Conclusion
In this paper, we studied the complexity of GRD problem and obtained
several interesting results.
We provided graph classes to differentiate the
complexity of GRD problem from that of RD problem. We proved that GRD
problem is NP-complete on split graphs, chordal bipartite graphs, planar
bipartite graphs with maximum degree five and circle graphs. On the positive
front, we presented a linear-time algorithm for GRD problem on cographs.
We conclude the paper with the following open questions on GRD problem.
• What is the complexity of the problem on interval graphs, block graphs
and strongly chordal graphs?
• Since the problem is known to be W[2]-hard parameterized by weight,
does it remain W[2]-hard on split graphs and bipartite graphs?
