Abstract. The l-Exact Component Order Connectivity problem
asks whether, given an input graph G and an integer k, there exists a
vertex subset S ⊆V (G) of size at most k such that every connected
component in G −S has exactly l vertices. In this paper, we present
an O(kl)-vertex kernel for this problem, computable in |V (G)|O(l) time.
This is the first known linear kernel for each fixed l ≥3. For l = 1, this
problem reduces to the classical Vertex Cover, and our result matches
the best-known 2k-vertex kernel. For l = 2 (known as Deletion to
Induced Matching), we can get a (3k + 1)-vertex kernel, improving
the previously known result of 6k vertices. Our kernelization algorithm
is built upon on an extended crown decomposition combined with linear
programming and other techniques.
Keywords: Graph Algorithms · l-Exact Component Order Connectiv-
ity · Deletion to Induced Matching · Linear Programming · Linear Kernel.

Introduction
Given a graph G and an integer k, the classic Vertex Cover problem asks
whether there exists a vertex subset S of size at most k such that every con-
nected component in the remaining graph after deleting S contains exactly one
vertex. This structural perspective naturally motivates the following general-
ization: can we delete at most k vertices from G such that every connected
component in the resulting graph contains exactly l vertices? Formally, for every
integer l ≥1, we consider the following problem, called l-Exact Component
Order Connectivity (l-ECOC).
l-Exact Component Order Connectivity (l-ECOC)
Instance: A graph G = (V, E) and an integer k.
Question: Does there exist a vertex subset S ⊆V of size at most k such
that every connected component in G −S has exactly l vertices?

ity corresponds exactly to Vertex Cover, which has been extensively stud-
ied [2,4,6,7,9,21,22]. For a long period time, the algorithm by Chen et al. [8]

In terms of kernelization, Chen et al. [7] first observed that the Nemhauser-
Trotter theorem [20] directly yields a 2k-vertex kernel for Vertex Cover. This
is considered a fundamental result in the field of parameterized complexity. For
Deletion to Induced Matching, Moser and Thilikos [19] provided a kernel
with O(k3) vertices, which Mathieson and Szeider [18] subsequently improved
to O(k2) vertices. Xiao and Kou [24] obtained the first linear vertex kernel of 7k
vertices for this problem, which was recently improved to 6k [17].
A closely related problem is the l-Component Order Connectivity prob-
lem, which asks whether there exists a vertex set S of size at most k such that
every connected component in G −S has at most l vertices. Drange et al. [11]
provided a parameterized algorithm running in O∗((l + 1)k) time, along with
a kernel of size O(kl(l + k)). The parameterized algorithm can be improved to
O∗((l + 1 −0.9245)k) time by reducing to (l + 1)-Hitting Set and applying
the corresponding parameterized algorithm [12]. The kernel size was improved
to 9lk vertices by Xiao [23], and further to 3lk vertices by Casel et al. [5]. Kumar
and Lokshtanov [16] showed that this problem admits a kernel with 2lk vertices
computable in |V (G)|O(l) time.
Our contributions. In this paper, we show that l-Exact Component Order
Connectivity admits a kernel with at most (l+1)k+l−1 vertices computable
in |V (G)|O(l) time. Specifically, for l = 1, our kernel matches the classic 2k-
vertex kernel for Vertex Cover. For l = 2, we obtain a kernel with 3k + 1
vertices for Deletion to Induced Matching, improving upon the previous
best bound of 6k vertices. Furthermore, our result provides the first kernel with
a linear number of vertices for any fixed l ≥3.
To achieve this result, we generalize the classic VC crown decomposition for
Vertex Cover to l-Exact Component Order Connectivity, introducing
the notion of an ECOC crown decomposition. Similar to VC crown decomposi-
tion, we demonstrate that whenever an ECOC crown decomposition is given, the
current instance can be safely reduced. Then, through combinatorial analysis,
we prove that any sufficiently large graph is guaranteed to contain an ECOC
crown decomposition.
Based on these analytical tools, our kernelization algorithm first exhaustively
applies a set of basic reduction rules. If the current instance is sufficiently small,
the algorithm returns it and terminates. Otherwise, the algorithm employs linear
programming techniques to compute an ECOC crown decomposition and fur-
ther reduce the instance. If no such decomposition can be found, the algorithm
correctly returns a trivial no-instance.

Preliminaries
All graphs considered in this paper are simple and undirected. Let G = (V, E)
be a graph with n = |V | vertices and m = |E| edges. A singleton {v} may simply
be denoted by v. We use V (G′) and E(G′) to denote the vertex set and edge set
of a graph G′, respectively. A vertex v is a neighbor of a vertex u if there is an
edge uv ∈E. Let NG(v) denote the set of neighbors of v in G. When the graph
G is clear from the context, we simply write N(v). For a vertex subset X ⊆V ,
let N(X) = S
v∈X N(v)\X and N[X] = N(X)∪X. For a vertex subset X ⊆V ,
the subgraph induced by X is denoted by G[X], and G[V \ X] is also written as
G \ X or G −X. Two disjoint vertex subsets X1 and X2 are adjacent if there is
an edge uv ∈E with u ∈X1 and v ∈X2.
A path P of length t −1 is a sequence of distinct vertices v1, v2, . . . , vt such
that vivi+1 ∈E for all 1 ≤i < t. A vertex u is reachable from a vertex v if there
exists a path starting at u and ending at v. By definition, every vertex is reachable
from itself. A connected component of a graph is a maximal set of vertices such
that every pair of vertices in the set is mutually reachable. For a graph G, we
denote the collection of its connected components by C = {C1, C2, . . . , Ct}. For
a collection of connected components C, we use V (C) to denote S
C∈C V (C). We
say two instances I and I′ are equivalent if I is a yes-instance if and only if I′ is
a yes-instance.
The classic crown decomposition technique, called VC crown decomposition,
was originally introduced for the Vertex Cover problem [1,10]. In this paper,
we will use a variant of it. We first give the definition of VC crown decomposition
for the ease of reference.
Definition 1. A VC crown decomposition of a graph G = (V, E) is a partition
(I, J, R) of the vertex set V satisfying the following properties.
1. There is no edge between I and R.
2. I is an independent set.
3. There is an injective mapping (matching) M : J →I such that x is adjacent
to M(x) for all x ∈J.
The following lemma is used to find a VC crown decomposition in polynomial
time if it exists.
Lemma 1 ([16]). There exists a polynomial time algorithm that given a bipar-
tite graph G = (A ∪B, E) with bipartition (A, B), outputs (if it exist) two sets
I ⊆A and J ⊆B with an injective mapping (matching) M : J →I such that
(I, J, V (G) \ (I ∪J)) is a VC crown decomposition for G.

ECOC Crown Decomposition
First, we present a variant of VC crown decomposition for l-ECOC, called ECOC
crown decomposition.
Definition 2. An ECOC crown decomposition of a graph G = (V, E) is a par-
tition (I, J, R) of the vertex set V satisfying the following properties:
1. Let C be the collection of connected components of G[I]. For every C ∈C,
|C| = l.
2. There is no edge between I and R (i.e., N(I) ⊆J).
3. There is an injective mapping (matching) M : J →C such that for all x ∈J,
there exists a vertex u ∈V (M(x)) with xu ∈E.
See Fig. 1 for an illustration. When l = 1, an ECOC crown decomposition
is equivalent to a VC crown decomposition. When l = 2, it is equivalent to the
AIM crown decomposition used in [17]. The following lemma establishes that an
ECOC crown decomposition allows us to find parts of the solution.
Lemma 2. Let (G, k) be an instance of l-ECOC and let (I, J, R) be an ECOC
crown decomposition of G. Then (G, k) is equivalent to the instance (G \ (J ∪
I), k −|J|).

We say that an ECOC crown decomposition (I, J, R) is strict if |C| ≥|J|+1,
where C is the collection of connected components of G[I]. For example, the
ECOC crown decomposition illustrated in Fig. 1 is strict since |C| = |J| + 1.
Clearly, every strict ECOC crown decomposition is also an ECOC crown de-
composition. The following lemma demonstrates how to obtain a strict ECOC
crown decomposition.
Lemma 3. Let G = (V, E) be a graph. Let I ⊆V be a non-empty vertex set,
let J = N(I), and let C be the collection of connected components of G[I]. If
|C| = l for all C ∈C and |C| ≥|J| + 1, then there exists a strict ECOC crown
decomposition (I′, J′, R′) such that ∅̸= I′ ⊆I and J′ ⊆J. Furthermore, this
strict ECOC crown decomposition can be found in polynomial time if I is given.
Proof. We construct an auxiliary bipartite graph G′ = (V ′, E′) with V ′ =
(A′, B′) as follows:
– Each vertex v ∈A′ corresponds to a connected component of size l of G[I].
– Each vertex v ∈B′ corresponds to a vertex in the vertex set J.
– An edge (a, b) exists in E′ if and only if the component in G[I] corresponding
to a is adjacent to the vertex corresponding to b in G.
Since |C| ≥|J| + 1, we have that |A′| ≥|B′| + 1. We compute a maximum
matching M ′ in G′, which can be done in O(n5/2) time using the Hopcroft-Karp
algorithm [14]. The following arguments are based on the maximum matching
M ′. A vertex is called M ′-saturated if it is an endpoint of an edge in M ′. A
path in G′ that alternates between edges not in M ′ and edges in M ′ is called an
M ′-alternating path.
Let Z ⊆A′ be the set of vertices in A′ that are not M ′-saturated. Since
|A′| ≥|B′| + 1, the matching M ′ cannot saturate all vertices in A′. Thus, we
have that Z ̸= ∅. We define I′′ ⊆A′ and J′′ ⊆B′ as the sets of vertices reachable
from Z via M ′-alternating paths in G′. By definition, Z ⊆I′′. Let C′ and J′ be
the components and vertices in G corresponding to I′′ and J′′, respectively. Let
I′ = V (C′). We verify that (I′, J′, V \ (I′ ∪J′)) forms the desired strict crown
decomposition:
– Property 1: Since every vertex in A′ corresponds to a component of size
l in G[I], the connected components of G[I′] are exactly C′, and each is of
size l.
– Property 2: We show N(I′) ⊆J′. It suffices to show that in G′, the neigh-
borhood of I′′ is a subset of J′′. Consider any edge (a, b) ∈E′ with a ∈I′′.
Since a is reachable from Z via an alternating path, we analyze the path
ending at a. If (a, b) ∈M ′, then b must have been the predecessor of a on
the alternating path, meaning b ∈J′′ is already established. If (a, b) /∈M ′,
we extend an alternating path ending at a by the edge (a, b), placing b in
J′′. Thus, it holds that N(I′) ⊆J′.
– Property 3: Let M ′′ = {(a, b) ∈M ′ | b ∈J′′}. Every vertex b ∈J′ must
be saturated by M ′; otherwise, an alternating path from Z to an unsatu-
rated vertex b would constitute an M ′-augmenting path, which contradicts

The Algorithm
Our kernelization algorithm contains several reduction rules. When a reduction
rule is applied, we assume that no preceding reduction rule is applicable to the
current instance. We first introduce the following simple reduction rules.
Reduction Rule 1. If |V (G)| ≤(l + 1)k + l −1, return the current instance
and exit the algorithm.
Reduction Rule 2. If there exists a connected component C such that |C| < l,
then return (G −C, k −|C|).
Reduction Rule 3. If there exists a connected component C such that |C| = l,
then return (G −C, k).
The correctness of Reduction Rules 1–3 is straightforward. The following
lemma is crucial for establishing our last reduction rule.
Lemma 4. There exists an algorithm that, given an instance (G, k) of l-ECOC
with at least (l+1)k+l vertices to which Reduction Rules 1–3 are not applicable,
runs in |V (G)|O(l) time and either finds an ECOC crown decomposition (I, J, R)
of G or concludes that (G, k) is a no-instance.
We postpone the proof of Lemma 4 and the description of the corresponding
|V (G)|O(l) time algorithm to the next section. Based on Lemma 4, we obtain
the following reduction rule.
Reduction Rule 4. Call the algorithm mentioned in Lemma 4 to compute an
ECOC crown decomposition (I, J, R). Return the equivalent instance (G \ (J ∪
I), k −|J|). If the algorithm cannot find such an ECOC crown decomposition,
return no to indicate that there is no solution.
Now, we analyze the kernel size and the running time of the algorithm. For
Reduction Rules 2–4, the kernelization algorithm either returns a strictly smaller
equivalent instance or correctly concludes that no solution exists. When Reduc-
tion Rule 1 is applied, the algorithm terminates and returns an instance (G, k)
with |V (G)| < (l + 1)k + l. Thus, the resulting kernel has at most (l + 1)k + l −1
vertices.

Regarding the running time, Reduction Rules 1–3 clearly run in polynomial
time. Reduction Rule 4 runs in |V (G)|O(l) time by Lemma 4. Furthermore, each
application of Reduction Rules 2–4 decreases the number of vertices in the in-
stance by at least one. Thus, these reduction rules are applied at most |V (G)|
times in total. Consequently, the kernelization algorithm runs in |V (G)|O(l) time.
We have the following theorem.
Theorem 1. l-Exact Component Order Connectivity admits a kernel
with (l + 1)k + l −1 vertices that can be computed in |V (G)|O(l) time.
When l = 2, this immediately yields the following theorem for the Deletion
to Induced Matching problem.
Theorem 2. Deletion to Induced Matching admits a kernel with 3k + 1
vertices.

Conclusion
In this paper, we present the first linear vertex kernel with O(lk) vertices for
l-Exact Component Order Connectivity for any fixed l ≥1. When l = 2
(known as Deletion to Induced Matching), we improve the previous result
from 6k to 3k + 1. When l = 1 (known as the classical Vertex Cover), our
result matches the well-known result of 2k, which implies our result is relatively
tight to some extent.
Note that our algorithm runs in |V (G)|O(l) time, which is no polynomial in l.
Whether we can obtain an O(kl)-vertex kernel for l-Exact Component Or-
der Connectivity using time also polynomial with l is left as an open prob-
lem for further study. For the highly related problem l-Component Order
Connectivity, there are known O(kl)-vertex kernels computable in polyno-
mial time [23,5]. However, it appears that their techniques could not be directly
adapted to l-Exact Component Order Connectivity. Additionally, estab-
lishing non-trivial lower bounds on kernels for this problem is also an interesting
topic for further study.
