LISTING THE HYPERARITHMETICAL FUNCTIONS
JOSEPH S. MILLER, GIAN MARCO OSSO, AND ISABELLA SCOTT
Abstract. Given a countable Turing ideal I ⊆ωω, we say that x is a list
(resp. weak list) of I if I = {x[n] : n ∈ω} (resp. if I ⊆{x[n] : n ∈ω}).
We show that, for several natural ideals I, x computes a list of I if and
only if it computes a function dominating all the functions in I. On the other
hand, we provide reals which are HYP-strongly null engulfing (and hence HYP-
dominating, by results of [GKT19]) but which cannot compute a weak list for
HYP, solving a problem left open in [GO26]. This result can be generalized
to any countable ideal which is downward closed under ≤HYP. We also give
a characterization of reals which compute a list of HYP: x computes a list of
HYP if and only if x is HYP-dominating and O is Σ0
2(x).
1. Introduction
This paper solves a problem which comes up naturally in [GO26] in the con-
text of computable analogues of cardinal characteristics. The latter paper builds
on work of [GKT19] (see also [BBTNN15]), showing how one can associate to any
countable Turing ideal I the so-called I-non-lowness classes, corresponding to com-
putational analogues of cardinal characteristics (the classes of interest in [GKT19]
are specifically those corresponding to cardinals in Cicho´n’s diagram). It is shown
in [GKT19] that, whenever we have a ZFC provable inequality A ≤B between
cardinal characteristics in Cicho´n’s diagram, then, for every I, the I-non-lowness
class of A is contained in the I-non lowness class of B.
In [GKT19], the authors single out the classes I-DOM (I-dominating), I-SME
(I-strongly meagre engulfing) and I-SNE (I-strongly null engulfing), defined below,
for their interesting behavior. According to the ZFC-provable inequalities between
the associated cardinals, the inclusions I-SNE ⊆I-SME ⊆I-DOM hold for every
countable Turing ideal.
Set theory would also predict that I-SNE ⊊I-SME ⊊
I-DOM, but, for example, we have REC-SNE = REC-SME = REC-DOM. Analyzing
the proofs of these facts, one observes the following: (i) a real x which dominates all
the computable functions is actually capable of listing all the computable functions
(see [JJ72]) and (ii) a real x that can list an ideal I is in I-SNE (see [Rup10,
Theorem 6], or [BBTNN15, Theorem 2] for a more direct proof that listing reals
are strongly meagre engulfing. The latter proof can be easily translated from the
context of category to that of measure).
This readily explains the unexpected
inclusion REC-DOM ⊆REC-SNE and hence the collapse of the entire chain.
In [GO26], the authors were able to prove that, if I is downward closed under
≤HYP, then I-SNE ⊊I-SME ⊊I-DOM. It immediately follows that, for such I,
not all reals x which dominate all the functions in I can also list I. This paper
addresses the natural question: what conditions on I are sufficient (and perhaps
necessary) to allow for some x ∈I-SNE that cannot list I?

Definition 2.9. A real x is a weak list of a countable ideal I if for every g ∈I
there is some n with x[n] = g, and it is a list of I if {x[n] : n ∈ω} = I.
We define the classes of I-weak listing and I-listing reals (denoted I-WL and
I-L, respectively) as consisting of those x which can I-compute a weak list (resp.
a list) of I.
By definition, for every countable Turing ideal I, we have I-L ⊆I-WL. A simple
diagonalization suffices to show that I-WL ⊆I-DOM. Indeed, the argument in
[BBTNN15, Theorem 2], translated in terms of measure, yields I-WL ⊆I-SNE.
Results of [GKT19] show that we always have I-SNE ⊆I-SME ⊆I-DOM. As we
mentioned above, the proofs in the literature showing that REC-DOM ⊆REC-SNE
actually rely on the fact (due to Jockusch, see [JJ72]) that REC-DOM ⊆REC-L.
Summarizing the situation for the ideal of computable functions, we have REC-L =
REC-WL = REC-SNE = REC-DOM.

with m < s + 1 by one bit, setting that bit equal to 0. If h(n, s + 1) = 1, then we
modify the sequences yn,m with m < s + 1 as in the proof of Theorem 3.8.
If n /∈O, then there are infinitely many stages s such that h(n, s) = 0. It is not
hard to see that, in the other stages, nothing is done. This is because the function
c of Proposition 3.1 has the property that, if n /∈O, then c(n) is the index of an
everywhere diverging function. Therefore, we have that ⟨yn,m : m ∈ω⟩is a list of
finite sets.
If n ∈O, then there is some m such that h(n, k) = 1 for every k ≥m. The
elements of the sequence ⟨yn,k : k ≥m⟩coincide with the elements of the corre-
sponding sequence defined in the proof of Proposition 3.5, so that finitely many of
these are eventually constant with value 0, and the other ones are ∅(n).
This shows that ⟨yn,m : n, m ∈ω⟩consists of some finite sets as well as all the
sets of the sequence ⟨∅(a) : a ∈O⟩. As in the proof of Proposition 3.5, it follows
that x can list HYP.
□
We point out that the right to left direction Theorem 4.1 is not specific to HYP.
Indeed, extending the construction of Proposition 3.5 as in the above proof only
requires that our function f dominates the uniform moduli gi of a countable family
of functions xi generating the ideal, and that we have a sufficiently definable way
to guess the indices witnessing that gi is a uniform modulus for xi.
Theorem 4.1 and a simple application of Gandy’s basis theorem gives the sepa-
ration HYP-L ⊊HYP-WL.
Theorem 4.2. HYP-L ⊊HYP-WL.
Proof. The class of weak lists of HYP is {y ∈ωω : ∀x ∈HYP ∃n (y[n] = x)} so, by
