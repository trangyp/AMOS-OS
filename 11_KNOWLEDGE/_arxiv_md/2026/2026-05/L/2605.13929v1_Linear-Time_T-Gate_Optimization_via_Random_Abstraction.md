Introduction
Quantum computers promise exponential speedups for a range of practically important problems—
from simulating quantum chemistry and materials science to breaking public-key cryptography
via Shor’s algorithm [30]. Realizing this promise at scale requires fault tolerance: physical qubits
are inherently noisy, so logical qubits must be encoded redundantly across many physical ones
using quantum error-correcting codes, and gates must be applied in a fault-tolerant manner.
In most practical fault-tolerance schemes, we use the universal Clifford+𝑇gate set. While Clifford
gates are efficiently simulable classically [15] and implemented transversally in most fault-tolerant
schemes,𝑇gates—phase rotations by 𝜋/4—cannot be implemented transversally, and instead require
costly magic-state distillation protocols [7, 8, 14] involving an elaborate and complex sequence of
operations. Each logical 𝑇gate can demand thousands of physical operations. As a result, 𝑇-gate
count can dominate the resource budget of large-scale quantum computations, and minimizing the
number of 𝑇gates in a circuit is a central bottleneck on the path to quantum advantage.
The challenge of𝑇-count reduction has attracted substantial attention, and a range of techniques
have been developed. One broad family of approaches relies on phase folding: when two rotation
gates act on the same basis states, their phases can be combined and redundant gates eliminated.
This idea has appeared in different guises across the literature [2, 3, 26], and has been shown to be
highly effective in practice. A second family of approaches uses rewriting: ZX-calculus represents a
quantum circuit as a graphical tensor-network diagram and applies a suite of local rewrite rules to
reduce gate count [9]. Tools based on these ideas, such as Feynman [2, 3] and PyZX [24], achieve
strong 𝑇-count reductions on standard benchmarks.

time algorithm. This is not merely an aesthetic goal: quantum advantage applications may involve
circuits with billions of gates, and any super-linear algorithm will be prohibitively slow at that

The phase-folding optimization. The heart of phase folding is proving that two rotation
gates act on the same qubit state at two distinct points in the circuit. To build intuition, consider
an analogy from classical program optimization. Suppose a compiler sees two array increment
statements, A[x]++ and A[y]++, and wants to fuse them into a single A[x] += 2. This is only sound
if x = y for every possible execution of the program—regardless of how the initial variables are set. A
static analysis can establish this by tracking a symbolic expression for each variable as statements
execute: if the analysis can prove that the expressions for x and y are always equal, the fusion is
justified.
Phase folding in quantum circuits is the same idea: two rotation gates can be merged—and one
eliminated—when they act on the same basis states for all possible inputs. Characterizing the set of
reachable quantum states at every rotation is generally intractable. Instead, existing approaches
soundly approximate the set of states by, for example, only tracking the effects of classical gates [35]
and treating others (like Hadamard) as non-deterministic operations [2]. We take great inspiration
from this view and use it to formalize a probabilistically sound and efficient abstraction.
Fast phase folding with randomized abstraction. Our key insight is that quantum states
can be approximated with a special algebraic structure: every qubit’s state is a linear function over
Boolean variables of the initial qubit values—it is a parity of the inputs. The state-equivalence
question therefore reduces to a parity-equivalence question, which admits a simple and efficient
randomized solution: Evaluate the two parities on random bitstrings and check if they evaluate to
the same answer!
Randomized parity equivalence provides us with a key ingredient for building a very fast static
analysis over quantum circuits: Rather than maintaining symbolic expressions, we assign each qubit
a random bitstring at the start of the circuit and propagate these bitstrings forward through each
gate—one inexpensive bit-level operation per gate. Intuitively, these bitstrings constitute an abstract
domain that probabilistically overapproximates the set of reachable basis states, achieving the same
goal as the symbolic analysis with constant-time, fast, bit-level operations. Each bit position in the
bitstring is an independent random draw, so a width-𝑘bitstring encodes 𝑘independent random
trials simultaneously; this is what makes the error probability drop exponentially with 𝑘. One can
view our approach as an analog of the random interpretation framework [17] for quantum circuits,
where we use randomization to achieve a very fast static analysis that can implicitly track affine
equalities.
Using our randomized abstract domain, we can propagate facts down the circuit and merge
rotations that share the same bitstrings. The probability of a spurious merge between any specific
pair of rotations is exponentially small in the bitstring width, but a correct run requires no spurious
merges across all pairs—a birthday-paradox situation. By choosing the bitstring width large enough
relative to the circuit size, the probability of even one unsound merge is negligible. Overall, we
demonstrate that our optimization algorithm runs in 𝑂(𝑛+ 𝑚) time, where 𝑛is the number of
qubits and𝑚is the number of gates. In other words, the algorithm performs one linear scan through
the circuit, eliminating unnecessary rotations. As we demonstrate experimentally, this allows it to
easily scale to very large circuits with millions of gates.

Contributions
The main contributions of this work are:
• We define a novel, randomized static analysis over an abstract domain of bitstrings that
probabilistically overapproximates the set of reachable basis states of a Clifford+𝑇circuit,
sound except with an arbitrarily small probability of error.
• We present a linear-time phase-folding algorithm that uses the randomized static analysis to
decide, with high-probability guarantees, whether two rotation gates are mergeable via a
single forward pass through the circuit.
• We implement our approach and perform a thorough experimental evaluation demonstrating
orders-of-magnitude runtime improvements over existing tools while closely matching their
output quality.

2.4
The Phase-Folding Optimization
There is another gate that we did not include above: the rotation gate Rz(𝜃), which multiplies
a qubit’s amplitude by 𝑒𝑖𝜃, where the angle 𝜃∈R. This gate only modifies the amplitude of a
quantum state, not its bits. So if we include it in our analysis, we simply treat it as a no-op, since
our analysis does not track amplitudes.
Rz(𝜃) gates are expensive in fault-tolerant quantum computing, as they require costly magic-
state distillation [7, 8, 14]. In particular, the 𝑇gate (= Rz(𝜋/4)) dominates the resource budget. We
therefore want to minimize the number of rotation gates in a circuit.

qubit into one. For example:

5
Randomized Static Analysis and Phase Folding
We are now ready to present our randomized static analysis and show how it can be used to realize
a linear-time phase-folding optimization algorithm.
What we are abstracting. Our goal is to design an abstraction of the relational circuit semantics
⟦C⟧that is precise enough to detect when two rotations can be folded yet cheap enough to compute
in a single linear pass. Recall from Thm. 3.3 that the phase-folding side condition is a statement
about ⟦C⟧: every reachable basis-state pair must agree on the values of two specific qubits.
The abstraction. We build an abstract domain in which each qubit is mapped to a 𝑘-bitstring,
initialized uniformly at random and updated by a small set of bitwise transfer functions, one per
gate. Throughout the circuit, we treat the equality of two qubits’ bitstrings as evidence that the
qubits hold the same value in every reachable state. In other words, our abstraction implicitly tracks
equalities between qubits.
Soundness with high probability. This is a one-sided guarantee: we do not claim to detect
every true equality, but we do ensure that whenever two qubits can disagree on some reachable
output, the analysis spuriously assigns them the same bitstring with probability at most 2−𝑘. The
parity equivalence lemma (Lem. 4.2) is the key ingredient: each qubit’s value at any program point
is a parity of the initial qubit values and the Hadamard outcomes, so equality between two qubits’
values reduces to equality of parities, which we test by sampling.

At its heart, our abstract domain tracks per-qubit parities. Two rotations on different qubits
whose phases cancel due to entanglement structure beyond parity equality are invisible. Richer
abstract domains (e.g., Amy and Lunderville’s path-sum-based abstractions) would recover more
merges, but at higher cost per gate. The design point of tzap is the opposite extreme: a single pass,
constant work per gate, and the merges it does find are correct with high probability.
7
Implementation and Evaluation
In this section, we describe our implementation of our approach and evaluate it to answer a range
of research questions.
Implementation. We implemented our algorithms in a tool called tzap in roughly 6,000 lines
of Rust. The tool is a command-line utility that ingests a subset of OpenQASM 2.0 [11] and emits
optimized OpenQASM 2.0. Non-Clifford+𝑇rotations Rz(𝜃) can optionally be decomposed into
Clifford+𝑇via the Ross–Selinger algorithm [27], using the rsgridsynth crate, at a user-specified
approximation precision 𝜖. Before phase folding, tzap makes a single pass over the circuit to remove
redundant adjacent gates (e.g., 𝑋𝑋, 𝐻𝐻).
Research questions. We aim to answer the following research questions:
(1) How does tzap compare to existing optimizers in runtime and 𝑇-count reduction?
(2) How does tzap scale to very large circuits, with millions to hundreds of millions of gates?
Benchmarks. We evaluate tzap on two benchmark suites spanning five orders of magnitude in
circuit size.
The first is the standard suite [2] that ships with the Feynman optimizer and has become
the de facto benchmark set for 𝑇-count optimization. It collects arithmetic and oracle circuits
drawn from the quantum-algorithms literature: Galois-field multipliers (GF(2𝑘) for 𝑘ranging
from 4 to 256), modular and carry-lookahead adders, hidden-weighted-bit functions, Barenco
Toffoli decompositions, Hamming-weight circuits, and several reversible-logic benchmarks (Grover
oracles, cycle and mod-5 circuits, etc.). Sizes in this suite range from tens of gates up to circuits
with hundreds of thousands of gates after Clifford+𝑇decomposition.

The second is the Cobble benchmark suite [40], which contains larger and more structurally varied
circuits drawn from two application domains: (i) Hamiltonian simulation circuits of increasing qubit
count and Trotter depth, and (ii) quantum linear-algebra kernels, including Chebyshev polynomial

spectral thresholding. We take the base circuits provided by Cobble, which range from 10s to 100s

Across both suites, we use the Clifford+𝑇forms of the circuits: any 𝑅𝑧(𝜃) rotations with non-

Correctness validation. We validated the correctness of our implementation at two scales.
For small circuits (up to 6 qubits), we generated hundreds of thousands of random circuits and
verified that the output of tzap is equivalent to the input by comparing their matrix representations
directly. For larger circuits, we used Feynman’s path-sum-based equivalence verifier [1] to check
equivalence between input and output on a majority of the feasible circuits in Feynman’s suite. In
all cases, tzap produced provably equivalent circuits.

analysis, not by extra passes layered on top. PyZX and QuiZX are not pass-decomposable in
the same way: their runtime is dominated by ZX rewriting and circuit extraction rather than a
phase-folding pass we can isolate, so we do not run the one-shot experiment for them.

Summary. tzap scales linearly over four orders of magnitude in circuit size, matching the

against input 𝑇-count on a log–log scale.

Related Work
Quantum circuit optimization has attracted many different approaches, ranging from algebraic
rewriting and ZX-calculus diagrammatics to numerical synthesis and learning-based superop-
timization. Our work sits firmly in the static analysis tradition: a single forward pass over the
circuit, propagating an abstract state through each gate and using the result to identify and fold
redundant rotations. This is the same compiler style used by classical data-flow analyses and
constant-propagation passes, and it is closest in spirit to the linear analyses of Amy and Lun-
derville [2] and QUESO [35], which also maintain an explicit symbolic representation of the parities
22


## Page 23


at each rotation site. We organize the related work into five groups: general circuit optimizers, 𝑇-
gate optimizers (the focus of this paper), abstract interpretation for quantum programs, probabilistic
static analysis, and symbolic/concolic execution.
Quantum circuit optimization. Several broad families of tools optimize general gate counts
or two-qubit gate usage, targeting the NISQ or early fault-tolerant regime rather than specifically
𝑇-count. VOQC [21] is a formally verified optimizer whose rewrite rules are machine-checked in
Coq; it implements the Nam et al. [26] pass-scheduling protocol, iterating gate cancellation and
phase folding. BQSKit [38] and tket [31] are widely used end-to-end frameworks: BQSKit uses
parameterized circuit instantiation as a core primitive for gate-count optimization and gate-set
transpilation, and tket provides retargetable optimization and routing passes for NISQ devices.
A second line of work synthesizes the rewrite rules themselves. QUESO [35] and Quartz [37] au-
tomatically derive provably correct rewrite rules for a target gate set—QUESO via enumeration and
verification, Quartz via equality saturation—and can outperform hand-crafted compilers. GUOQ [36]
combines fast rewrite-rule-based optimization with slow search-based unitary resynthesis; the two
strategies are synergistic and together outperform either alone.
A third line operates in the ZX-calculus [9], a complete equational theory for quantum circuits.
Duncan et al. [12] showed how to simplify circuits by converting to ZX-diagrams and applying
local complementation and pivoting rules; PyZX [24] and its Rust reimplementation QuiZX [23]
implement these ideas at scale [32].
tzap targets the phase-folding subproblem and is complementary to all of the above; it can serve
as a fast preprocessing step before any of them.
𝑇-gate optimization. In fault-tolerant quantum computing—e.g., using the surface code [13]—𝑇
gates cannot be implemented transversally [8] and instead require costly magic-state distillation
protocols [7, 8, 14], making each logical 𝑇gate significantly more expensive than a Clifford gate.
𝑇-count minimization is therefore a central concern for large-scale quantum computation [30],
further reinforced by the fact that classical simulation of Clifford+𝑇circuits runs in time exponential
in the 𝑇-count [6]. Van de Wetering and Amy [33] prove that 𝑇-count optimization (and related
metrics) is NP-hard in general, motivating the heuristic and approximate approaches below.
The dominant family of 𝑇-count optimizers—and the one closest to our work—exploits the
phase-polynomial structure of Clifford+𝑇circuits: a sequence of 𝑇-like rotations interleaved with
CX and X gates can be described as a sum of phase terms, each applied to a Boolean parity of
the input. Selinger [28] showed that any Clifford+𝑇circuit can be rewritten to have 𝑇-depth one,
establishing foundational bounds. Amy et al. [3] gave a polynomial-time algorithm for 𝑇-count
and 𝑇-depth minimization via matroid partitioning. Amy and Mosca [4] connect minimum 𝑇-
count to minimum-weight Reed–Muller codewords, providing exact bounds. Kissinger and van
de Wetering [25] combine ZX-calculus phase gadgetization with Clifford normalization to reach
the theoretical limits of affine phase folding. Amy and Lunderville [2] recast phase folding as a
relational static analysis and extend it to programs with arbitrary classical control flow, unifying
circuit optimization with classical program analysis.
A separate strand of work targets 𝑇-count via search rather than phase polynomials. Heyfron
and Campbell [20] develop TODD, a heuristic 𝑇-count optimizer that uses meet-in-the-middle
search over phase polynomials; Vandaele [34] improves its complexity, giving the current state-of-
the-art (FastTODD). Both achieve strong reductions but are expensive on large circuits. Yuan and
Carbin [42] work one layer up the stack: their Spire compiler restructures quantum control flow
before circuit-level compilation to avoid the polynomial 𝑇-count blowup that fault-tolerant control
constructs can otherwise introduce, complementary to circuit-level phase folding.
Abstract interpretation for quantum programs. Abstract interpretation [10] has been applied
to quantum programs to prove properties without full simulation. Yu and Palsberg [39] develop
23


## Page 24


quantum abstract interpretation using tuples of projections as an abstract domain over density
matrices, enabling verification of assertions for programs with hundreds of qubits. Bichsel et al. [5]
introduce Abstraqt, which compresses stabilizer simulation into a single abstract summand to
overapproximate circuit behavior, scaling to hundreds of qubits without full state-vector simulation.
Both target verification; we share the abstract-interpretation philosophy but use the abstraction to
drive an optimization, accepting a small probability of unsoundness in exchange for a constant-
width, constant-time-per-gate domain.
Probabilistic static analysis. Our work can be seen as a straight-line, F2 specialization of
Gulwani and Necula’s random interpretation [16–19], a randomized form of abstract interpreta-
tion [10] that trades absolute soundness for a vanishingly small error probability in exchange for
simpler and faster algorithms. We share the core philosophy: track an affine abstraction by random
instances, and use a hash-style equality check in place of symbolic reasoning.
The quantum-circuit setting, however, strips away most of the machinery that makes random
interpretation hard. There are no control-flow joins, no equality conditionals, and circuits unroll
fully, so neither the affine-join operation nor the Adjust operation nor any fixed-point computation
is needed. The Hadamard rule, which assigns a fresh random bitstring to a qubit when its linear
relationship to the inputs is destroyed, plays the role of Gulwani’s non-deterministic assignment.
Symbolic execution and concolic testing. Symbolic execution [22] runs a program on symbolic
inputs and maintains a formula describing all reachable states. The analysis underlying tools
employing phase folding can be viewed as symbolic execution over quantum circuits: each qubit is
assigned a symbolic parity expression over the initial inputs, updated by exact transfer functions
for each gate, and two rotations can be folded precisely when their parity expressions are provably
equal.
Concolic execution [29] blends concrete and symbolic execution in tandem: a program runs
on a concrete input while simultaneously accumulating a symbolic formula for the current path,
which is then solved to generate new concrete inputs that explore different paths. Our approach
can be seen as a further simplification: we run only a single concrete execution on a randomly
sampled bitstring, dispensing with the symbolic component entirely. The randomness substitutes
for symbolic reasoning—two parity expressions that are semantically equal evaluate to equal
bitstrings with probability 1, and two that are unequal collide only with probability 2−𝑘—so a single
concrete run conveys nearly the same information as a symbolic one, without ever constructing or
comparing formulas.
9
Discussion and Future Work
We presented an algorithm for optimizing quantum circuits, focused on reducing the number of 𝑇
gates. The key technical insight underlying our approach is a randomized static analysis that tracks
per-qubit parities via random bitstrings, enabling a linear-time phase-folding algorithm that is
correct with high probability. Our implementation, tzap, delivers 𝑇-count reductions comparable
to state-of-the-art optimizers while running up to multiple orders of magnitude faster, completing
in milliseconds optimizations that time out for other tools, and scaling linearly to circuits with
hundreds of millions of gates.
Our approach raises a number of questions for future consideration. First, our abstraction
tracks per-qubit parities (XORs and negations) and treats Hadamards in a non-deterministic way,
potentially losing optimization opportunities. Thus, a natural question to ask is whether we can
enrich the analysis while maintaining its linear-time nature. For example, one approach may
be to track superposition up to a fixed limit, and then introduce non-determinism to limit the
explosion. This is an approach that was used by Bichsel et al. [5] in the context of quantum program
verification, and it would be interesting to see if it can be adapted to the optimization setting.
24


## Page 25


Another potential extension is handling classical–quantum programs, like repeat-until-success
loops, which are common in quantum algorithms and can be optimized by folding rotations across
loop iterations. This would require extending our abstract domain to handle loops and control flow,
perhaps by combining the techniques of Gulwani and Necula [16, 17] with Amy and Lunderville’s
relational analyses for quantum programs [2].
Finally, it would be interesting to explore how our fast analysis can be used as a light-weight
static analysis for, for example, proving assertions about parity properties of qubits at various
points in the circuit, or to drive other optimizations beyond phase folding.
