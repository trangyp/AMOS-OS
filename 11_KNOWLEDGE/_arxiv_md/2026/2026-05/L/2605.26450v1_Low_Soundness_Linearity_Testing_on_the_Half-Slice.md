Introduction
Given oracle access to a Boolean function f : {0, 1}n →{0, 1}, we are interested in checking if f is
close to being a linear function using a small number of queries. In theoretical computer science,
this question is popularly known as the linearity testing problem. It has been widely studied due
to its key role in many diverse applications. The original work in the area is the legendary Blum-
Luby-Rubinfeld (BLR) test [BLR90] which states that if f passes the check f(x + y) = f(x) + f(y) with
non-trivial probability over a random pair (x, y), then f must correlate with some linear function.
Let n ∈N be an even integer and let |x| denote the Hamming weight of x ∈{0, 1}n. The “half
slice” of the Boolean hypercube {0, 1}n is defined as,
T :=

Motivated by questions in hardness amplification, PCP, and direct product testing, David, Dinur,
Goldenberg, Kindler, and Shinkar [DDG+17] initiated the study of linearity testing over T. They
proved that if f : T →{0, 1} passes the BLR check f(x + y) = f(x) + f(y) with probability 1 −ε over
a random pair (x, y) such that x, y, x + y ∈T, then f agrees with some linear function on 1 −O(ε)
fraction of the x ∈T. That is, they proved a linearity testing theorem over T in the “99% regime”.
The corresponding question in the “1% regime” asks whether a function which passes the
above BLR test over T with probability that is noticeably better than 1/2 must have non-trivial
correlation with a linear function. This question was left open by [DDG+17] and was essentially
untouched until the recent work of Kalai, Lifshitz, Minzer, and Ziegler [KLMZ24] who proved
that if f : T →{0, 1} passes the 4-query BLR check f(x + y + z) = f(x) + f(y) + f(z) with probability

This was exciting progress, and the argument in [KLMZ24] is extremely elegant with several

rather than the original BLR test, which uses three; and 2) the constant c is quite small (c ≈.0035).

Linearity testing beyond Boolean hypercube
Linearity testing has been studied in many domains

Recently, [MR26] gave a general framework for studying the linearity testing problem over finite

Boolean function analysis on the slice
In recent years, there has been an increased interest in
extending various results from Boolean function analysis to the slice setting. For instance, Filmus
and Ihringer [FI19] showed that constant-degree functions over the slice are Juntas, generalizing a
result by Nisan and Szegedy [NS94]. The famous invariance principle has also been ported to the
slice setting by Filmus, Kindler, Mossel, and Wimmer [FKMW16]. To achieve this result, they used
certain explicit orthogonal basis functions constructed by Filmus [Fil16a] in a previous work. In
a separate research, [Fil16b] also proved a version of the prominent Friedgut–Kalai–Naor (FKN)
theorem over the slice.
