A signed graph Γ is a pair (G, σ), where G = (V (G), E(G)) is an undirected graph, called the
underlying unsigned graph, and σ : E(G) →{−1, +1} is the sign function. The adjacency matrix

The sign of a cycle (with some orientation) C = v1v2 . . . vkv1, denoted by σ(C), is defined as the
product of the signs of its edges, that is
σ(C) := σ(e12)σ(e23) · · · σ(e(k−1)l)σ(ek1),
where eij is the edge between the vertices vi and vj. A cycle C is neutral if σ(C) = 1, and a signed
graph is balanced if all its cycles are neutral. The balanced clique number of a signed graph Γ,
denoted by ωb(Γ), is the maximum number of vertices in a balanced complete subgraph of Γ.
A function from the vertex set of G to the set {1, −1} is called a switching function. Two signed
graphs Γ1 = (G, σ1) and Γ2 = (G, σ2) are switching equivalent, written as Σ1 ∼Σ2, if there is a
switching function η : V (G) →{1, −1} such that
σ2(eij) = η(vi)−1σ1(eij)η(vj).
