LASH: Adaptive Semantic Hybridization for
Black-Box Jailbreaking of Large Language Models

Abstract
Jailbreak attacks expose a persistent gap between the intended safety behavior of
aligned large language models and their behavior under adversarial prompting.
Existing automated methods are increasingly effective but each commits to a single
attack family (e.g., one refinement loop, one tree search, one mutation space, or one
strategy library) and no single family dominates: the best-performing method shifts
across target models and harm categories, suggesting complementary strengths
that per-prompt composition could exploit. We introduce LASH (LLM Adaptive
Semantic Hybridization), a black-box framework that treats outputs from multiple
base attacks as reusable seed prompts and adaptively composes them for each
target request. Given a seed pool, LASH searches over seed subsets and softmax-
normalized mixture weights; a composition module synthesizes a single candidate
prompt, and a derivative-free genetic optimizer updates the weights using black-
box target feedback and a two-stage fitness function combining keyword-based
refusal detection with LLM-judge scoring. On JailbreakBench, which contains
100 harmful prompts across 10 categories, we evaluate LASH on six common
target models. LASH achieves an average attack success rate of 84.5% under
keyword-based evaluation and 74.5% under two-stage evaluation, where responses
are first filtered for refusals and then scored by an LLM judge for whether they
substantively fulfill the original harmful request. LASH outperforms five state-of-
the-art baselines on both metrics with only 30 mean target queries. LASH also
remains competitive under three defense mechanisms and induces more success-
like internal representations. These results suggest that adaptive composition
across heterogeneous jailbreak strategies is a promising direction for black-box
red-teaming.

Introduction
Aligned LLMs refuse most harmful requests. Modern alignment techniques such as reinforcement
learning from human feedback [25] and constitutional AI [2] have made these models substantially
more reluctant to produce dangerous instructions, disinformation, or other content their safety guide-
lines explicitly prohibit than their untuned predecessors. Yet this reluctance is not a hard guarantee: a
carefully reworded version of the same request can flip a model’s refusal into compliance [34].
Jailbreaking research has progressed from hand-crafted manual attacks [34, 30] to automated white-
box methods such as GCG [41] and AutoDAN [19], which use model-internal signals such as
gradients, log-probabilities, or losses. More recent black-box attacks, including PAIR [4], TAP [23],
GPTFuzzer [37], AutoDAN-Turbo [20], and FlipAttack [21], avoid access to target-model internals
and instead use the model response for refinement, fuzzing, strategy selection, or transformation-
based attack generation. Yet within this setting, each attack confines its search to a single family

Contributions: We introduce LASH (LLM Adaptive Semantic Hybridization), a black-box meta-
attack that treats prior jailbreak outputs as composable seed prompts and adaptively re-weights them

multiple base attacks at reduced query budget (Section 3.1), then searches over subsets of seeds
and over softmax-normalized mixture weights (Section 3.2). A composition LLM translates each
weight vector into a single coherent candidate prompt rather than a textual concatenation, while a
derivative-free genetic algorithm mutates only the real-valued logits using black-box target feedback
(Section 3.3); the prompt strings themselves are never directly modified, which keeps the optimization
independent of how each seed was originally generated. A two-stage fitness function (Section 3.4)
combines keyword-based refusal detection with LLM-judge scoring. The entire pipeline assumes only
query access to the target model: LASH observes the model’s response strings but never its weights,
gradients, or hidden activations, reflecting the practical constraints of attacking proprietary API-only
deployments. To preserve this assumption end to end, we use only black-box seed attacks, and
the genetic optimizer relies solely on response-level feedback. It uses no white-box loss, surrogate
model, or component fine-tuning. On JailbreakBench across six target models, LASH attains average
attack success rates of 84.5% under keyword-based evaluation and 74.5% under two-stage evaluation
using only 30 mean target queries, improving over the strongest baseline by +17.7 and +33.8
percentage points respectively, and remains competitive under three defense mechanisms (Section 4).
Mechanistic probing and activation patching further link these gains to a measurable shift in the target
model’s intermediate representations rather than to surface wording alone.

Related Work
Manual and white-box attacks: Manual prompt-engineering attacks [34, 30, 28, 9, 39] establish
that aligned models are sensitive to surface form, instruction hierarchy, and persona framing, but
require hand-crafted effort per request. Automated white-box methods such as GCG [41], COLD-
Attack [10], AutoDAN [19], and LARGO [15] reduce this effort using model-internal signals such as
gradients, log-probabilities, losses, or latent representations, but such access is usually unavailable for
proprietary API-only deployments. LASH targets this deployed setting and assumes only black-box
query access; manual prompts can be added to its seed pool but are not required.
Black-box jailbreak attacks: Automated black-box attacks fall into four overlapping subfamilies:
iterative-refinement loops driven by an attacker LLM (PAIR [4], TAP [23]); mutation- and strategy-
based methods that evolve handcrafted templates or retrieve from learned libraries (GPTFuzzer [37],
AutoDAN-Turbo [20], RLbreaker [5]); transformation-based methods that change how a request is
encoded or structured [7, 17, 16, 13, 38, 21, 36]; and learned generators that amortize attack synthesis
through dedicated trained models [18, 26, 14, 6]. Despite this breadth, each method is tied to a single
search space, such as one refinement loop, one tree search, one mutation pool, one strategy library,
one transformation, or one frozen generator. As a result, these methods cannot easily draw on the
strengths of other attack families when their chosen strategy is poorly matched to the input. LASH
operates one level above the methods above: instead of designing another search procedure, it treats
their outputs as seed prompts and optimizes how to combine them per request for improved attack
success and greater stealth. A more detailed discussion of related work is provided in Appendix A.

Why hybridize black-box attacks: Existing black-box methods are not uniformly effective: each
commits to a single search space, and the family that succeeds depends strongly on the target model
and harm category. Tab. 1, distilled from Tab. 2 and Tab. 4, summarizes where each of the four
black-box baselines is the strongest (excluding LASH) under two-stage evaluation (ASR2). Every
method wins on at least one target or category, but none wins more than eight of sixteen cases: PAIR
wins one target and no categories, while TAP, FlipAttack, and AutoDAN-Turbo each carry a different
operational regime. This complementarity, rather than any single method’s peak performance, is what
LASH is designed to exploit.
At a high level, LASH operates through four stages (Fig. 1). First, it constructs a seed prompt pool
by running multiple base attack methods on the input prompt. Second, it selects candidate subsets
from this pool and assigns continuous mixture weights to the selected blocks. Third, a composition
block synthesizes a single candidate prompt from the weighted blocks. Finally, the candidate is
queried against the target model, and the resulting score drives genetic optimization of the mixture
weights. This separates the generation of seed blocks from the optimization of their composition, so
LASH does not depend on any single seed method being consistently effective; instead, it searches
for complementary combinations of blocks for each input prompt.
3.1
Problem Formulation and Seed Pool
Let x denote an input prompt and T the target model. The goal of LASH is to construct a final prompt
p⋆such that the response r = T(p⋆) receives a high score under an evaluator J. The evaluator assigns
a scalar score J(x, p, r) ∈[0, 10], with larger values indicating that the response is more strongly
aligned with successful jailbreak behavior, and a prompt is considered successful if J(x, p, T(p)) ≥τ
for a predefined threshold τ.
LASH then constructs a seed prompt pool for x. Let A = {A1, . . . , An} denote a set of n black-box
base attack methods, drawn from diverse families such as iterative refinement, tree search, and
strategy-based attacks (and possibly multiple configurations of the same method). Each base method
Ai generates one seed prompt bi = Ai(x), and the resulting pool is B(x) = {b1, . . . , bn}. Each seed
captures a distinct attack strategy, phrasing pattern, or structural transformation. Rather than selecting
one seed as the final attack, LASH treats the pool as a set of reusable components and searches for an
effective combination of them for the current input.

Results
The experimental setup is in Section 4.1. Section 4.2 shows the effectiveness of LASH with and
without defenses. Ablation on the design of choices of LASH is shown in Section 4.3. At last, in
Section 4.4, we analyze the success of LASH over the baselines from the representation space lens.
4.1
Experimental Setup
Dataset: We evaluate LASH on JailbreakBench [3], a standardized benchmark of 100 harmful
prompts across 10 behavior categories. Its broad category coverage and common use in jailbreak
evaluation enable systematic red-teaming and comparison with established attack families.
Target models and baselines: We select these six target models to provide a diverse and repre-
sentative evaluation across model families, deployment settings, and capability levels. Specifically,
Llama-2-7B-Chat, Llama-3-8B-Instruct, and Vicuna-7B represent widely used open-source models,
while Gemini-2.0-Flash, GPT-4o-mini, and GPT-5.4-nano represent closed-source commercial mod-
els with strong instruction-following capabilities. This mixture allows us to evaluate whether the
proposed method generalizes across both open and proprietary models rather than overfitting to a
single architecture, model family, or provider. For all target models, we use deterministic decoding
by setting the temperature to 0 and top-p to 1. This minimizes sampling variance and ensures that
observed differences are primarily attributable to the attack method and target model behavior rather
than randomness in generation. We compare LASH against five state-of-the-art jailbreak baselines:
PAIR [4], TAP [23], AutoDAN [19], AutoDAN-Turbo (AutoDAN-T) [20], and FlipAttack [21]. For
recording the performance of baseline methods, we have kept the standard settings according to their
respective paper. For fair comparison, we tune the query-related parameters of query-based baselines
to use the same maximum target-query budget of 160. This ensures that all query-based methods are
evaluated under the same constraint.
Evaluation metrics: We report two attack success rate (ASR) metrics. ASR1 (keyword-based
ASR) considers a response successful if no refusal keyword is detected. ASR2 (two-stage LLM
judge-based ASR) first applies keyword-based refusal filtering, then uses GPT-4o-mini as a judge
LLM to score whether the response substantively fulfills the harmful request. Responses passing
the refusal filter receive a judge score in [0, 10], and are considered successful if the score exceeds
the threshold τ = 9. We also report Mean # Q for iterative query-based attacks, defined as the
average number of target queries used during attack optimization per input prompt. For LASH, Mean
# Q includes both seed-generation queries and GA-search queries; the seed-generation budgets are
maximum budgets, so seed methods may terminate before using all allocated queries.
We introduce ASR2 because keyword-only evaluation may overestimate success when models
produce evasive or unhelpful responses that avoid refusal keywords [32, 22]. While LLM judges have

LASH configuration and seed generation: LASH constructs its seed prompt pool from three black-

base method with intentionally reduced maximum query budgets (may converge faster): 5 for PAIR,
and TAP, and 10 for AutoDAN-Turbo. These low-budget seeds are intentionally weak, allowing us
to test whether LASH’s semantic composition and weight optimization can improve beyond the raw
seed prompts. The total seed generation cost is maximum of 20 queries per input prompt, leaving
140 queries for LASH’s genetic search within the 160 maximum query budget.
LASH’s genetic algorithm uses population size P = 8, mutation scale σmut = 0.6, and G = 2
generations. We use GPT-4o-mini as both the composition LLM in composition block and the judge
LLM (for two-stage fitness evaluation). This configuration maintains the black-box threat model
throughout the pipeline, as all three seed methods operate without white-box access.
Defenses: We evaluate LASH and all baselines under three advanced defense mechanisms. We
evaluated against SmoothLLM [29] with the standard setting. For Llama Guard [11], we use the
meta-llama/Llama-Guard-3-8B [8] classifier to filter both jailbreak prompts and target responses; a
sample is rejected if either the prompt or response is classified as unsafe. For perplexity filtering [12],
we discard prompts whose log-perplexity exceeds the threshold. The threshold is measured from the
JailbreakBench dataset. Defense results are reported using ASR2 unless otherwise noted.

Ablation Studies
GA Hyperparameter sensitivity: Figure 2 shows the sensitivity of LASH to the GA hyperparameters
on GPT-4o-mini model. For each setting, we run the experiment three times with different random
seeds and plot the mean ASR (ASR2). The results show that the default configuration, G = 2, P = 8,
and σmut = 0.6, achieves strong performance while keeping the search lightweight. Increasing
the search budget beyond this setting does not consistently improve ASR, suggesting that a small
population and a few generations are sufficient for effective semantic weight optimization. Figure 2
varies the number of GA generations, population size, and mutation scale. Performance improves
substantially when moving from no or minimal optimization to the default search setting, supporting
the GA configuration selection. The default configuration, G = 2, P = 8, and σmut = 0.6, lies in a
stable high-performing region of the tested hyperparameter space. Larger values do not uniformly
improve results, suggesting that small populations and a small number of generations are sufficient
for this low-dimensional search.
LASH Optimized vs. Uniform Weights: Figure 3a compares optimized LASH against a uniform-
weight variant. Overall, optimized weighting produces consistent gains across the evaluated models,
with the greatest improvement appearing on GPT-4o-mini, where optimized weights improve ASR2
from 24% to 85%. This shows that LASH benefits strongly from learning prompt-specific mixture

5
Conclusion and Discussion
We introduced LASH, a black-box meta-attack that lifts the unit of jailbreak optimization from
individual prompts to mixtures over attack outputs. Rather than designing yet another search
procedure, LASH treats the outputs of existing black-box attacks as composable seed prompts and
adaptively re-weights them per request, with a derivative-free genetic algorithm mutating real-valued
mixture logits and a composition LLM translating each weight vector into a single coherent candidate
prompt. The entire pipeline runs under query access only, making the complementarity between
black-box attack families directly available on every input rather than only on inputs that some single
family happens to handle.
On JailbreakBench across six target models and ten harm categories, LASH outperforms five state-of-
the-art baselines under both keyword-based and two-stage evaluation and remains competitive under
three defense mechanisms. Ablations show that LASH does more than select the best seed or assign
uniform weights, and mechanistic probing and activation patching link its gains to a shift in the target
model’s intermediate representations rather than to surface wording alone.
LASH is limited to single-turn prompt optimization and is not defense-aware, motivating multi-turn
planning and safeguard-adaptive composition. For broader impact, LASH supports pre-deployment
safety evaluation but is dual-use, requiring safeguarded release and clear usage guidelines. Future
versions of LASH can make the composition process defense-aware and extend the method to multi-
turn attack planning, where it optimizes sequences of composed prompts rather than a single final
prompt.

A
Detailed Related Work
Manual and prompt-level jailbreaks: Hand-crafted attacks remain useful for understanding how
surface wording, instruction structure, and persona framing influence the safety behavior of aligned
language models. Wei et al. [34] traced model failures to two recurring causes, namely competing
objectives and mismatched generalization, and showed that even small format changes can shift
refusal behavior. In-the-wild prompt analyses such as Shen et al. [30] characterize DAN-style
and persona-driven prompts collected from public communities, while Perez and Ribeiro [28] and
Greshake et al. [9] formalize prompt injection in its direct and indirect variants. Zeng et al. [39]
further studied persuasion-style appeals as jailbreak vectors. Collectively, these studies show that
aligned models are sensitive not only to literal content, but also to framing, instruction hierarchy, and
presentation format. This motivates attack pipelines that search over natural-language reformulations
rather than only token-level perturbations. LASH does not rely on any fixed manual template, but hand-
crafted prompts can be inserted into its seed pool as additional attack blocks alongside automatically
generated ones.
White-box and token-level optimization: A major family of automated jailbreak attacks operates
under the assumption of white-box access to the target model. GCG [41] exemplifies this approach
by constructing adversarial suffixes through greedy coordinate gradient-based optimization over
discrete token choices, using model-internal signals such as gradients and next-token log-probabilities.
This builds on earlier gradient-based prompt-optimization methods such as AutoPrompt [31] and
Hard Prompts Made Easy [35], which use model-internal signals to optimize discrete prompt tokens.
COLD-Attack [10] adapts energy-based constrained decoding with Langevin dynamics to generate
controllable adversarial prompts under constraints such as fluency, stealthiness, sentiment, and
contextual coherence. AutoDAN [19] uses a hierarchical genetic algorithm over structured natural-
language prompts to generate stealthy, semantically meaningful jailbreak prompts. Unlike token-level
suffix attacks such as GCG, AutoDAN is designed to preserve readability and evade simple perplexity-
based filtering. However, its original optimization still relies on white-box model-internal objective
signals, such as loss values, when scoring candidate prompts. More recently, LARGO [15] revisits
gradient-based jailbreak optimization in continuous latent space. It first optimizes an adversarial
embedding vector and then uses self-reflective decoding to translate the optimized latent state into a
fluent natural-language suffix. LARGO therefore shows that white-box optimization can produce
readable and transferable jailbreak prompts when the search is performed over latent representations
rather than directly over discrete tokens. The shared limitation across this family is the requirement
for model internals, including weights, gradients, loss values, or embedding-space access. LASH
does not make this assumption. It works with natural-language prompts, queries the target model
only as a black box, and optimizes using response-level feedback rather than token probabilities, loss
values, or latent gradients.
Black-box LLM-based search: PAIR [4] instantiates a black-box attacker-target loop in which
an attacker LLM iteratively rewrites candidate prompts based on feedback from the target model’s
responses. TAP [23] extends this idea into a branching tree search, using evaluator-guided pruning to
discard low-promise candidates and improve query efficiency on closed-source models. The broader
LLM-as-red-team paradigm proposed by Perez et al. [27] underlies these pipelines. However, each
of these methods commits to a single search trajectory, such as one attacker loop, one tree search
process, or one refinement policy for a given prompt. Rather than running one search process to
generate one candidate, LASH runs multiple base methods to populate a seed pool, then searches over
weighted combinations of those seeds. This allows LASH to exploit the complementary strengths of
different black-box search strategies rather than committing to a single trajectory.
Genetic, fuzzing, and strategy-based attacks: GPTFuzzer [37] evolves human-written jailbreak tem-
plates by applying LLM-based mutations, such as expansion, shortening, rephrasing, and crossover,
directly to the prompt text. AutoDAN-Turbo [20] uses lifelong strategy self-exploration to discover,
maintain, and apply jailbreak strategies in a black-box setting, and can also incorporate human-
designed strategies. RLbreaker [5] uses a deep reinforcement learning agent to guide black-box
jailbreak search, allowing the attacker to adapt its search actions based on feedback from previous
attempts. These methods search within one method-specific space: GPTFuzzer mutates a template
pool, AutoDAN-Turbo explores and applies strategies from its strategy space, and RLbreaker learns
which operators to use during search. LASH instead optimizes real-valued weights over seeds
from multiple heterogeneous methods. For example, a PAIR output, a GPTFuzzer mutation, and

according to learned weights.
Transformation-based attacks: Transformation-based attacks alter how the harmful request is
encoded, structured, or presented, rather than changing its underlying semantic intent. ReNeLLM [7]
first rewrites the harmful query to appear more benign, then embeds it inside a nested scenario that
encourages the model to respond. DeepInception [17] constructs nested fictional scenes and personas
around the request to induce unsafe behavior. DrAttack [16] decomposes a harmful instruction
into less detectable sub-prompts, uses benign in-context reassembly demonstrations, and searches
for synonym substitutions that preserve the original malicious intent. ArtPrompt [13] represents
sensitive words using ASCII art, exploiting weaknesses in how models interpret text-based visual
patterns. CipherChat [38] encodes unsafe requests using cipher-based prompts and demonstrations
to test whether safety alignment generalizes beyond natural-language inputs. FlipAttack [21] flips
or reverses text and uses guidance mechanisms that help the model recover and execute the hidden
request. Low-resource language attacks [36] translate unsafe prompts into languages with weaker
safety coverage, exposing cross-lingual gaps in alignment. No single transformation is uniformly
effective across all models and defenses: ASCII-art, cipher-based, character-level, and language-
based transformations each exploit different weaknesses, and their effectiveness can vary substantially
across target models and safeguard mechanisms. LASH can exploit this complementarity by running
multiple transformation methods on the same harmful prompt, collecting their outputs as seed
prompts, and using genetic optimization to find an effective weighted combination.
Learned jailbreak generators: Instead of optimizing a new attack from scratch for each prompt,
learned jailbreak generators train a dedicated model once and then use it to generate attacks quickly.
AmpleGCG [18] trains a generative model on adversarial suffixes collected from many GCG runs,
allowing it to produce similar suffixes without repeatedly running gradient optimization. Ad-
vPrompter [26] trains an adversarial prompt generator through alternating optimization and low-rank
fine-tuning, producing human-readable adversarial suffixes quickly without requiring gradients of the
target LLM. JailPO [14] trains attacker models using a preference-optimization-based objective so
that they learn to generate covert jailbreak prompts that are more likely to elicit unsafe responses.
MASTERKEY [6] collects successful jailbreak examples and fine-tunes a generator to mimic their
patterns, while also studying how chatbot defenses can be reverse-engineered. The main advantage
of these approaches is fast attack generation after training. However, the generator is typically fixed
after training and may not easily incorporate new attack methods or strategies that emerge later
without additional data collection and retraining. Training such generators can also require substantial
computing resources, time, and attack data. LASH is training-free. It composes outputs from existing
methods, so learned generators can contribute seeds without requiring LASH itself to retrain.
B
Prompt-Level Weight Optimization in LASH
B.1
Design Rationale
The design of LASH is motivated by the observation that seed prompts generated by different base
attack methods often contain useful but incomplete strategies. Some seed prompts may contain strong
framing, while others may contain better structure, wording, or transformation patterns. Instead of
selecting only one seed prompt, LASH treats the seed prompt pool as a compositional search space.
Weighted prompt hybridization allows LASH to emphasize useful seed prompts and reduce the effect
of weaker or conflicting ones. The softmax weights provide a simple way to assign different levels of
influence to each selected seed prompt. Subset search further helps remove seed prompts that are
noisy or incompatible for the current input prompt.
The resulting objective is difficult to optimize with gradient-based methods because the composition
block, target model, and evaluator are all treated as black-box components. For this reason, LASH
uses a derivative-free genetic algorithm. The genetic algorithm preserves strong candidates through
elitism and explores nearby prompt mixtures through Gaussian mutation of the mixture logits. This
keeps the search lightweight and fully black-box with respect to the target model.

B.2
Genetic Search over Mixed Prompts
Algorithm 1 describes the prompt-level genetic search used by LASH. The algorithm starts after
the seed prompt pool B(x) has already been constructed for the input prompt x. It then searches
over nonempty subsets of the seed prompt pool in descending order of subset size. This means that
LASH first tries to combine more seed prompts together, and then moves to smaller subsets if larger
combinations are not successful.
For each subset S, the algorithm initializes a population of random logit vectors. Each logit vector
represents one possible weighting of the seed prompts in the subset. The logits are converted into
normalized mixture weights using the softmax function. These weights, together with the selected
seed prompts and the original input prompt, are passed to the composition block. The composition
block then produces one synthesized prompt.
Each synthesized prompt is sent to the target model, and the target response is scored by the evaluator.
During this process, LASH keeps track of the best prompt, response, and score found so far. If any
candidate reaches the success threshold τ, the algorithm stops early and returns the best candidate.

top-scoring genomes are selected as elites. These elites are copied into the next population. The
