Abstract
We study the problem of deciding universal termination of linear and
affine loops over the reals in the bit-model of real computation. We show that
both problems are as close to decidable as one can expect them to be: there
exist sound partial algorithms that halt on all problem instances whose an-
swer is robust under all sufficiently small perturbations. We further show
that in each case the set of non-robust problem instances has Lebesgue mea-
sure zero.

Introduction
Discrete-time linear systems arise naturally in a wide range of application areas
across systems and control theory and verification. A fundamental liveness ver-
ification task is to decide whether every system state in a given set eventually
escapes the set under the dynamics. Here we consider the following instantia-
tion of this problem: does every point in a given polyhedron P escape P under
the iteration of a given matrix A? Tiwari [Tiw04] has shown that this problem is
decidable when A and P are specified by exact rational data.
In applications, the system under consideration may not always be specifi-
able by exact rational data – for example, it may not be possible to assume that
the transition probabilities of a Markov chain be exactly known. This leads to
the question whether the problem remains decidable when the matrix or poly-
hedron are known only approximately, but with guaranteed error bounds. Fol-
lowing [Neu21], we model this situation by studying the problem for matrices
and polyhedra specified by real data in the sense of computable analysis [Wei00,
Col20, BH21]. This line of work also connects to recent developments in exact
real computation and program verification, such as the Hoare-logic framework of
Park et al. [PBC+24], which provides a natural setting for verification problems
over real data. Further, Tiwari’s method in general requires exact computation
with algebraic numbers, in particular symbolic computation of the Jordan nor-
mal form, which is computationally very expensive (cf. the discussion in [Tiw04,
p.80]). We will solve the real-number version of the problem using validated nu-
merical methods, which are potentially much more efficient.

Let us define the decision problem we consider more precisely. For real vectors
v,w ∈Rm of the same dimension, we write v ▷w if vj > wj for all j ∈{1,...,m}. The
relations v ⊵w, v ◁w, and v ⊴are defined analogously. For a matrix B ∈Rm×n,
we let P(B) = {x ∈Rn | Bx ▷0} denote the open polyhedron defined by B. We let
P(B) = {x ∈Rn | Bx ⊵0} denote the closed polyhedron defined by B. Observe that,
since we do not impose any constraints on B, the set P(B) is not necessarily equal
to the closure of P(B). The Linear Universal Escape Problem is the following
decision problem: given matrices A ∈Rn×n and B ∈Rm×n, decide whether for all
x ∈Rn there exists k ∈N with Akx ∉P(B).
Since computability implies continuity, no non-trivial subset of Euclidean
space has a computable characteristic function. Thus, we cannot hope to decide
any interesting problem over real data in the naïve sense of computing its char-
acteristic function. However, we can ask for the next best thing: A subset S of a
represented space X is called maximally partially decidable [Neu21] if there ex-
ists an algorithm which takes as input an element x ∈X, and either runs forever
or halts in finite time. If it halts, it must report correctly whether x belongs to S.
Moreover, it is required to halt on all inputs x ∉∂S. Observe that if X is discrete
in the sense that equality for elements of X is semidecidable, then a subset of X
is decidable in the usual sense if and only if it is maximally partially decidable.
Thus, maximal partial decidability generalises decidability over discrete spaces
– generally in a more meaningful way than the naïve definition. See [Neu21] for
further discussion and motivation of this concept. When we think of S ⊆X as a
decision problem, we also refer to points x ∈X as instances of S. A point x ∈∂S is
called a boundary instance. A point x ∈X \∂S is called a robust instance.
Our first main result is the following:
Theorem 1. The Linear Universal Escape Problem is maximally partially de-
cidable.
Tiwari’s decision method [Tiw04] for the universal escape problem for rational
inputs relies on the computation of the Jordan normal form, which is well-known
to be uncomputable for real matrices for continuity reasons (cf. [ZB04]). Hence,
we pursue an entirely different approach: We characterise the robust problem
instances via first-order formulas, where all universal quantification ranges over
compact sets, and all existential quantification ranges over overt sets. This im-
mediately yields a maximal partial algorithm.

Preliminaries
2.1
Represented Spaces
We assume some familiarity with the basic results and definitions of computable
analysis and the theory of represented spaces. For details we refer to [Pau16]
or [Col20].
A represented space is a set X together with a partial surjective
map δX : ⊆NN →X. Examples of represented spaces include computable metric
spaces with the Cauchy representation [BP03, Ko91, Wei00]. A map f : X →Y
is called computable if there exists a computable function F : domδX →domδY
satisfying δY ◦F = f ◦δX. It is called continuous if there exists a continuous such
function. Clearly, computability implies continuity. Continuity in this sense is
closely linked to topological continuity with respect to the final topology induced
by the representation. See [Pau16, Sch02b, Sch02a] for details.
Represented spaces enjoy excellent closure properties. In particular, they ad-
mit countable products and exponentials. This is the basis for important hyper-
space constructions. Let Σ = {⊤,⊥} denote Sierpinski space, with the representa-
tion δΣ : NN →Σ where δΣ(0ω) = ⊥and δΣ(x) = ⊤for all x ∈NN \{0ω}. Then, for a

represented space X, the space O(X) of open subsets of X is given by identifica-
tion of an open set with its characteristic function as an element of the space ΣX
of all continuous functions from X to Σ. The space A (X) of closed subsets of X is
given by identifying a closed set A with its complement as an element of O(X).
A subset K ⊆X is compact if and only if the set □K = {U ∈O(X) | K ⊆U} is
an open subset of O(X). The set K is called computably compact if □K is a com-
putable open subset of O(X). Dually a subset A ⊆X is overt if and only if the
set ♢A = {U ∈O(X) | A ∩U ̸= ;} is an open subset of O(X). The set A is called
computably overt if ♢A is a computable open subset of O(X). It is easy to see
that every set is overt, so that only computable overtness yields a (classically)
meaningful notion.
For a represented space X the space K (X) of compact subsets of X is the
space whose underlying set is the set of saturated compact subsets of X and
whose representation is obtained by identifying a saturated compact set K with
the set □K ∈O(O(X)). The restriction to saturated compact sets is necessary,
since the set □K determines K only up to saturation. Dually, the space V (X) of
overt subsets of X is the space whose underlying set is the set of closed subsets
of X and whose representation is obtained by identifying a closed set A with
the set ♢A ∈O(O(X)). The restriction to closed sets is necessary, since the set
♢A determines A only up to closure. See [Pau16, Col20] for effective closure
properties of compact and overt sets.

Linear Dynamical Systems
We require two results on the long-term behaviour of linear dynamical systems.
We will decompose the systems under consideration into systems with only posi-
tive real eigenvalues and systems without any positive real eigenvalues. For our
purpose, the following theorem characterises the behaviour of the latter:
Theorem 7 (Bell and Gerhold, [BG07]). Let f : N →R be a linear recurrence
sequence without positive real eigenvalues. Then f is either eventually zero or f
assumes infinitely many (strictly) negative values.
Corollary 8. Let E be a finite-dimensional real vector space. Let L : E →E be a
linear map without positive real eigenvalues. Let ϕ: E →R be a linear functional.
Then for all x ∈E there exist infinitely many k ≥0 with ϕ◦L kx ≤0.
Proof. It follows from the Cayley-Hamilton theorem that the sequence of real
numbers ϕ◦L kx satisfies a linear recurrence whose characteristic polynomial is
that of the matrix L . The result now immediately follows from Theorem 7.
