Abstract
We prove that every concatenation of 10 or more binary squares contains an overlap.
The bound 10 is best possible. In contrast, over a ternary alphabet, there are infinitely
long overlap-free words that consist of a concatenation of squares.
1
Introduction
We say that a word w is a square if w = xx for some nonempty word x, and is an overlap if
w = axaxa for some (possibly empty) word x and a single letter a. For example, murmur is
a square, and alfalfa is an overlap.
Suppose w = xyz for some words x, y, z. We call x a prefix of w, y a factor of w, and z a
suffix of w. For example, for w = concatenation, the word con is a prefix, ten is a factor,
and nation is a suffix. We call a word squarefree if it has no square factor, and overlap-free
if it has no factor that is an overlap.
In this paper we are mostly concerned with finite words over the alphabet {0, 1}. We
define 0 = 1 and 1 = 0, and extend the notation for complement to words in the obvious
way.
The theory of overlap-free binary words was developed initially by Axel Thue [10, 3].
Here an important role is played by the Thue-Morse morphism µ, defined by µ(0) = 01 and
µ(1) = 10. We call 01 and 10 the µ-blocks. We also write µi for the i-fold iteration of µ.

In particular, a fundamental result in the area is the factorization theorem of Restivo
and Salemi [7, 8], which states that every sufficiently long finite overlap-free binary word w
can be written in the form xµ(y)z, where y is overlap-free, and x, z are words of length at
most two.
In this paper we prove the following result.
Theorem 1. Every concatenation of 10 or more binary squares contains a factor that is an
overlap, and the bound 10 is optimal.
The rough idea of the proof is as follows: we assume, to get a contradiction, there is a
shortest concatenation of 10 squares w that is overlap-free. If the squares in w are aligned
with the µ-blocks of the Restivo-Salemi factorization, then we can use that factorization to
construct a shorter overlap-free concatenation of 10 squares. If the squares are not aligned
with the µ-blocks, their structure is constrained, and we can simply use breadth-first search
to show that 9 squares is the maximum possible.
All words in this paper are indexed starting at position 0.

Useful lemmas
In this section we state some of the basic results needed for the proof.
Lemma 2. Let x, y ∈{0, 1}∗and a ∈{0, 1}.
(a) x is overlap-free if and only if µ(x) is overlap-free.
(b) If a x contains an overlap, so does a µ(x).
(c) If xa contains an overlap, so does µ(x)a .
(d) If x2 = µ(y) then x = µ(t) for some word t and y = tt.
Proof.
(a) See [10, Satz 6] or [1, Lemma 1.7.4].
(b) Suppose a x contains an overlap. Then either the overlap is entirely within x, or yaya
is a prefix of x for some y. In the former case, µ(x) contains an overlap by (a), and
hence so does aµ(x). In the latter case, a µ(x) = aµ(yaya) = aµ(y)aaµ(y)aa, which
clearly contains the overlap azaza with z = µ(y)a.
(c) Analogous to (b).
(d) See, for example, [1, Lemma 1.7.3]

Lemma 3 (Restivo-Salemi factorization). Let w ∈{0, 1}∗be an overlap-free finite word.
Then there exist u, v ∈{ϵ, 0, 1, 00, 11} and an overlap-free word y such that w = uµ(y)v. If
|w| ≥7 the factorization is unique.
Proof. The theorem is essentially in [7, 8]. The version we use here can essentially be found
in [6] or [1, Prop. 1.7.5].
Lemma 4. Let A = {02, 12, (010)2, (101)2}. Then a word w ∈{0, 1}∗is an overlap-free
square if and only if w is a conjugate of µi(x) for x ∈A and i ≥0. In particular, an
overlap-free square has length either 2i or 3 · 2i for i ≥1.
Proof. See Thue [10] or Shelton and Soni [9].

We define two functions on binary words. We define L(w) to be 1 if there exists a ∈{0, 1}
such that aw is overlap-free, and 0 otherwise. Similarly, we define R(w) to be 1 if there
exists a ∈{0, 1} such that wa is overlap-free, and 0 otherwise. Thus L measures whether an
overlap-free word can be extended one symbol to the left to get a longer overlap-free word,
and R measures the same thing for extension to the right.
Lemma 6. Let w ∈{0, 1}∗be overlap-free with |w| ≥16. Let its Restivo-Salemi factorization
be w = uµ(y)v, with y overlap-free, and u, v ∈{ϵ, 0, 1, 00, 11}.
(i) If u = aa for some a ∈{0, 1}, then L(w) = 0.
(ii) If v = aa for some a ∈{0, 1}, then R(w) = 0.
Proof. We prove only (i), as (ii) follows with a symmetric argument. Since |w| ≥16 and
|v| ≤2, it follows that |y| ≥6. Checking all eight 3-symbol prefixes of y, we easily confirm
that aaµ(y) being overlap-free implies that y begins with aaa. Thus w begins with aaµ(aaa).
If we prepend a, then the resulting word begins with the overlap aaa. If we prepend a then
the resulting word begins aaaaaaa, which is an overlap. Hence no left extension is overlap-
free, and L(w) = 0.

Proof of the main result
Theorem 8. Let w be an overlap-free binary word, and suppose w = S1S2 · · · Sk, where each
Si is a square. Then k + L(w) + R(w) ≤9.
Proof. Suppose the result is false, and let w be such that k + L(w) + R(w) ≥10, and |w|
is as small as possible. This means that k ≥8, and hence |w| ≥16. By Lemma 3, the
Restivo-Salemi factorization of w is unique, and we can write w = uµ(y)v, where u, v ∈
{ϵ, 0, 1, 00, 11}. Because |w| is even, we know that |u| and |v| have the same parity.

c = 0. If v ̸= ϵ, set d = 1; otherwise set d = 0. Define w′ = Sc+1Sc+2 · · · Sk−d; the effect is to

Larger exponents
Karhum¨aki and Shallit [5] proved that there is a factorization theorem for binary words
analogous to that of Restivo-Salemi, for all exponents e with 2 < e ≤7/3. So it is natural
to wonder if Theorem 1 has any counterpart for larger e. The answer is no, since Currie
and Rampersad proved that for each real e > 2 there is an infinite e-power-free word that
contains squares beginning at every position [4, Theorem 3.4].

Larger alphabets
Proposition 9. Over a ternary alphabet, there are uncountably many overlap-free infinite
words that are the concatenation of square factors.
Proof. It is well-known that there are uncountably many infinite squarefree words w over
the alphabet {0, 1, 2}. For example, see [2, Theorem 1.8]. Define a morphism h as follows:
h(a) = aa for a ∈{0, 1, 2}. Clearly z := h(w) is a concatenation of squares. We claim that
z is overlap-free.

Suppose, contrary to what we want to prove, that z has an overlap axaxa. Clearly z
cannot contain aaa, so assume |x| ≥1.
Case 1: |ax| is even. If the starting position of axaxa in z is even, it is aligned with the
h-blocks in z. Then there exists a nonempty word t such that h(t) = ax and tt is a factor of
w, a contradiction.
If the starting position of axaxa is odd, then it is offset by 1 from the h-blocks in z. Then
the same argument applies with h(t) = xa.
Case 2: |ax| is odd. If the starting position of axaxa in z is even, then the starting position
of the second axa is odd. Since the effect of h is to double letters, this forces the last letter
of x to be a, and the first letter of x to be a. Thus z contains aaa, a contradiction.
If the starting position of axaxa in z is odd, then the symbol in one position to the left
must also be a. Then the second axa starts at an even position, which forces the first letter
of x to be a. Thus again z contains aaa, a contradiction.
Hence the desired result follows.
