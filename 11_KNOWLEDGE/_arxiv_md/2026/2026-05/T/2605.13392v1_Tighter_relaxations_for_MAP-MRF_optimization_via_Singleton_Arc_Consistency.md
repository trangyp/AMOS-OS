Tighter relaxations for MAP-MRF optimization
via Singleton Arc Consistency
Asaf Lev-Ran, Pavel Arkhipov, Vladimir Kolmogorov
Institute of Science and Technology Austria (ISTA)
{asaf.lev-ran,pavel.arkhipov,vnk}@ist.ac.at
Abstract
We consider the MAP-MRF inference task, that is, minimizing a function of discrete variables
represented as a sum of unary and pairwise terms. A prominent approach for tackling this
NP-hard problem in practice is to solve its natural LP relaxation and then iteratively tighten
the relaxation by adding clusters. Based on some theoretical observations, we propose a new
technique for identifying such clusters. It works by running the Singleton Arc Consistency
algorithm in a certain CSP instance. Experimental results indicate that the new tightening
technique outperforms the previous approach by [SCL12] that searches for frustrated cycles.
Our code will be made available at https://github.com/vnk-ist/MAP-MRF/.

MAP-MRF optimization was a prominent approach in computer vision before the deep-learning

efficient text-to-image generation [JGR+24], SAM-based area matching formulated as an MRF
energy minimization problem solved by graph cuts [ZZ24], neuralized MRFs for interaction-aware
human trajectory prediction [FHL25], and voxel-adaptive message passing for deformable CT

LP relaxations and tightening
Although problem (1) is NP-hard in general, it has been
demonstrated that many practical instances can be solved to optimality. A prominent approach
is cluster-based tightening [SMG+12] which starts by solving an LP relaxation of (1) and then
iteratively tightens the relaxation by adding clusters of nodes. The success of this approach depends
crucially on which clusters are added. Early approaches chose clusters from a fixed dictionary, e.g.
the set of all triplets (3-cycles in the graph) [SMG+12, KP08, BNK11]. [SCL12] showed how to
avoid fixed dictionaries by proposing an algorithm for computing “frustrated cycles”, while showing
that after adding these cycles the dual objective can be improved.
The main contribution of this paper is a new algorithm for computing clusters. It is based on
running a Singleton Arc Consistency (SAC) algorithm on a certain CSP instance. We prove several
properties of this algorithm. Roughly speaking, they can be formulated as follows: (1) If SAC
produces a cluster then after adding this cluster either the dual objective can be improved or some
fractional vertices are cut off from the local polytope. (2) If the instance has at least one frustrated
cycle then SAC will find a cluster. For more formal statements we refer to Sections 3 and 5.
Our experimental results show our SAC tightening procedure outperforms the method in [SCL12]
by consistently finding the same or better bounds.
Other related work
[SJ07] proposed to tighten relaxations of MAP-MRF problems by adding
cutting planes that generalize odd-cycle inequalities for MAX-CUT. Their separation algorithm
works in the primal domain, and requires a (fractional) primal solution of the relaxation. In
contrast, we focus on tightening techniques that use only dual solutions (“reparameterization”),
since relaxations of large-scale problems are often solved via message-passing techniques that work
only in the dual domain.
Tightening techniques require introducing high-order terms, which can become expensive when
the number of labels is large. [SGJ08] address this issue by proposing to use coarse partitions on
labels for high-order terms. Note that this approach is orthogonal to the question studied in this
paper.
[Wer09] presented an approach based on the language of Constraint Satisfaction Problems
(CSPs), by showing that all unsatisfiable CSP subproblems could potentially tighten the relaxation.
However, no concrete algorithm for identifying such subproblems was proposed.
In this work we use a particular CSP algorithm, namely Singleton Arc Consistency (SAC). This
algorithm was recently used in [DWdG23] for identifying superreparameterizations that improve
the lower bound. At each iteration they replace current vector θ with another vector θ that
satisfies f[θ](x) ≤f[θ](x) for all labelings x, and guarantees that θ gives a better lower bound
than θ. This approach is not comparable with the tightening techniques that we consider: it can
be computationally less costly since it does not introduce any high-order terms, but it may also
decrease the minimum minx∈X f[θ](x) (which would never be “undone” in later iterations).
Note that a simpler Arc Consistency (AC) algorithm has been used for approximately solving
the standard LP relaxation of (1) (without tightening). In particular, an AC-based algorithm for
establishing the Virtual Arc Consistency has been given in [CdGS+08, CdGSF+10], and is similar
to the Augmenting DAG algorithm [Sch76, Wer09].
There are also alternative tightening approaches based on more expensive computational tools
such as semidefinite programming relaxations, see e.g. [DKS22]. We limit the scope of this work to
LP relaxations, which arguably can scale to larger problems.
A survey of tightening techniques for MAP-MRF optimization can be found in [KKP19].

Arc consistency (AC) algorithm
Let us consider the following problem: given instance
I = (V, X, V ∪E, Y), compute a maximal instance Y′ ⊆Y which is arc-consistent. Clearly, this
can be done by repeating the following two operations while possible.
1. Pick pair (a, b) ∈Yuv for {u, v} ∈E s.t. a /∈Yu. Remove (a, b) from Yuv.
2. Pick label a ∈Yu for {u, v} ∈E s.t. (a, b) /∈Yuv for all b ∈Xv. Remove a from Yu.
These operations can be implemented in O(|E| · (maxv |Xv|)2) time [BRYZ05]. Furthermore, if
it produces an empty CSP (i.e. if the domain of one of the variables becomes empty) then it is
possible to find a minimal sequence of such operations in the same time.
Singleton arc consistency (SAC)
Instance I = (V, X, V ∪E, Y) is called singleton arc
consistent if the following holds for each v ∈V and a ∈Yv: fixing the label of v to a (i.e. replacing
Yv with {a}) and then running the arc consistency algorithm gives a non-empty instance [DB97].
Such consistency can be achieved by repeating the following operation: pick node v ∈V and label
a ∈Yv, fix the label of v to a, run the AC algorithm; if it results in an empty CSP then remove a
from Yv. Efficient implementations of such an algorithm have been studied in [BE04].

Next, we discuss some implementational choices.
AC algorithm
We used the AC3 algorithm [Mac77] whose worst-case complexity is O(|E| ·
(maxv |Xv|)3). Although this is worse than the O(|E| · (maxv |Xv|)2) complexity of the AC2001/3.1
algorithm [BRYZ05], AC3 is simpler and may have an advantage when the number of labels is small.
It maintains a queue of directed edges (u, v), and processes them in certain order. To simulate a
BFS-like search, we use the FIFO order for this queue. In our experiments, this tends to produce
smaller inconsistent subproblems. Importantly, we limit the search to depth dmax = 3 to reduce the
complexity (when running AC in line 4). This means that the algorithm is able to find frustrated
cycles of length 2dmax = 6.
Choice of ε
We maintain the current value of ε (initially ε = 0.1). At each tightening stage
we run Algorithm 1 for values εi = 2−iε (i = 0, 1, 2, . . .) and compute corresponding sets A(i),
where for the i-th run set A at line 6 is initialized via A ←A(i−1). For each i we then try to add
computed triplets to F, and compute the number ki of those triplets that were not yet present
in F. If ki < 2ki−1 then we stop and update ε = εi−1. If ε becomes smaller than 10−6 then we
increase dmax by 1 and reset ε = 0.1.

Frustrated cycles algorithm
In this section we specify details of our implementation of the algorithm of [SCL12] described in
Section 2.2. The first question is how to set partitions Πv for v ∈V . To match the SAC tightening
algorithm, we compute Yv = {a ∈Xv : θv(a) ≤minb θv(b) + ε} and then for each a ∈Yv add the
partition ({a}, Xv −{a}) to Πv.
Next, we need to compute frustrated cycles, i.e. cycles in the signed graph G which have an odd
number of negative edges. To do this, [SCL12] first pick a spanning rooted tree T in G (namely, a
BFS tree starting from a random node). They observe that for each edge (u, v) in G one can check
in O(1) time whether the fundamental cycle passing though (u, v) has an odd number of negative
edges. They then return up to 5 such cycles sorted by their length.
We experimented with two different modifications:
FR1: return all fundamental cycles that are frustrated (in a single spanning tree).

construct a (not necessarily spanning) BFS tree of depth at most dmax = 3 from each vertex

Our overall implementation uses the same structure as in the previous section. The only
difference is that in lines 3-5 of Algorithm 1 instead of sets Ar we use the cycles computed as above,
triangulated into triplets; in line 5 they are sorted according to their size.

Discussion of results
From the plots one can see that the highest lower bound attained by
SAC is the same or better than that of FR1 / FR, and in half of the cases it is strictly better. This
confirms the discussion in Section 5 that SAC is capable of finding more useful triplets than FR1 /
FR.
Let us now discuss the performance of SAC vs toulbar2. The former finds a much better bound
in 7 cases, a worse bound in 1 case (1CKK), and similar bounds in 6 cases. In these 6 cases toulbar2
reaches the best bound faster than SAC in all cases except for one. We remark toulbar2 uses a very
different strategy; according to the documentation, its lower bounds are based on a combination of
various versions of Virtual Arc Consistency (VAC), dead end elimination and branch-and-bound
10


## Page 11


search. As the plots show, in many cases this strategy is less powerful than the cluster-based
tightening.
Overall, we conclude that SAC is the most robust tightening technique among considered
approaches. As noted above, SAC cannot make progress if the current CSP instance is singleton-arc-
consistent, which is the limitation of SAC. For the FR technique, a similar limitation is an absence
of frustrated cycles. Theorem 6 shows that SAC’s limitation is weaker than FR’s limitation in the
sense that we can make progress whenever FR can.
