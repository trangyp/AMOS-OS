THE i-EXTENDED IDEAL-BASED COZERO-DIVISOR GRAPH
OF A COMMUTATIVE RING
FARANAK FARSHADIFAR
Abstract. Let R be a commutative ring with identity and let J be an ideal
of R. In this paper, we introduce and investigate the notion of the i-extended
ideal-based cozero-divisor graph of R. This graph, denoted by Γ′′Ji(R), is a
simple graph of R whose vertex set is {x ∈R \ J | xR + J ̸= R}. Two distinct
vertices x and y are adjacent if and only if xm ̸∈ynR + J and yn ̸∈xmR + J
for some positive integers m and n with n ≤i and m ≤i.
1. Introduction
Throughout this paper, R will denote a commutative ring with identity and Z
will denote the ring of of integers. Also, the Jacobson radical of R will denote by
Jac(R).
A graph G is defined as the pair (V (G), E(G)), where V (G) is the set of vertices
of G and E(G) is the set of edges of G. For two distinct vertices a and b of V (G), the
notation a −b means that a and b are adjacent. A graph G is said to be complete
if a −b for all distinct a, b ∈V (G). A graph G is said to be an empty graph if
E(G) = ∅. Note by this definition that a graph may be empty even if V (G) ̸= ∅.
In [1], the authors introduced and investigated the cozero-divisor graph Γ′(R)
of R, in which the vertices are precisely the non-zero, non-unit elements of R and
two distinct vertices x and y are adjacent if and only if x ̸∈yR and y ̸∈xR. Let
I be an ideal of R. The authors in [2], introduced and studied a generalization
of cozero-divisor graph ´ΓI(R) of R with vertices {x ∈R \ AnnR(I) | xI ̸= I}
and two distinct vertices x and y are adjacent if and only if x ̸∈yI and y ̸∈xI.
In fact, ´ΓI(R) is a generalization of cozero-divisor graph introduced in [1] when
I = R. Farshadifar, in [3], introduced and investigated a new generalization of
cozero-divisor graph with respect to I, denoted by Γ′′
I (R), which is a simple graph
with vertices {x ∈R\I |xR+I ̸= R} and two distinct vertices x and y are adjacent
if and only if x ̸∈yR + I and y ̸∈xR + I. In [5], the present author introduced
and studied the extended ideal based cozero-divisor graph of R, denoted by Γ′′I(R),
which is a simple graph Γ′′I(R) of R with vertices {x ∈R \ I | xR + I ̸= R}. The
distinct vertices x and y are adjacent if and only if xm ̸∈ynR+I and yn ̸∈xmR+I
for some positive integers n and m.

2. Main Results
Definition 2.1. Let J be an ideal of R. For a positive integer i, the i-extended
ideal based cozero-divisor graph of R, is a simple graph Γ′′Ji(R) of R with vertices
{x ∈R \ J | xR + J ̸= R}. The distinct vertices x and y are adjacent if and only if
xm ̸∈ynR + J and yn ̸∈xmR + J for some positive integers m and n with n ≤i
and m ≤i. This can be regarded as a dual of the i-extended zero-divisor graph of
R when I = 0.

Definition 2.10. Let J be an ideal of R and x ∈R. We say that x is a conilpotent
relative to J element of R if 1 −x ̸∈Rxn + J and xn ̸∈R(1 −x) + J for some
positive integer n. For a conilpotent relative to J element x of R, ξ(x) denotes the
smallest positive integer k such that 1 −x ̸∈Rxk + J and xk ̸∈R(1 −x) + J. In
addition, we set ξ(R) = Sup{ξ(x) : x is a conilpotent relative to J element of R}.

Proposition 2.12. Let J be an ideal of R such that J ⊆Jac(R) and x be a non-
unite of R \ Jac(R) such that xn = xn+1 for some n ∈N. Then 1 −x ̸∈Rxn + J
and xn ̸∈R(1 −x) + J. That is, x is a conilpotent relative to J element of R.
Proof. First assume contrary that 1 −x ∈Rxn + J. Then 1 −x = rxn + a for some
r ∈R and a ∈J. Thus x(rxn−1 + 1) = 1 −a. Since a ∈J ⊆Jac(R), 1 −a has an
inverse b, say in R. Therefore, bx(rxn−1 + 1) = 1. It follows that Rx = R. Which
is a contradiction since x is a non-unite of R. Thus 1 −x ̸∈Rxn + J. Now, assume
contrary that xn ̸∈R(1 −x) + J. Then xn = r(1 −x) + a for some r ∈R and
a ∈J. Thus xn = r −rx + a and hence x2n = rxn −rxn+1 + axn. It follows that
x2n = rxn −rxn + axn = axn ∈J. Since J ⊆Jac(R), x2n ∈Jac(R). It follows
that x ∈Jac(R), which is a contradiction. Thus xn ̸∈R(1 −x) + J, i.e., x is a
conilpotent relative to J element of R.
□
Proposition 2.13. Let J be an ideal of R and x ∈R. Then we have the following.
(a) If for some n ∈N we have xn+1 = xn ∈V , then 1 −x ∈V .
(b) If J ⊆Jac(R), x is a non-unite of R, and 1 −x ∈V , then xn ∈V for each
n ∈N.
Proof. (a) Let for some n ∈N, xn+1 = xn ∈V . Then xn ̸∈J and Rxn + J ̸= R.
Assume contrary that 1−x ∈J or R(1−x)+J = R. If 1−x ∈J, then Rx+J = R.
Thus by [5, Lemma 2.1], Rxn + J = R, which is a contradiction. Hence 1 −x ̸∈J.
If R(1 −x) + J = R, then 1 = r(1 −x) + a for some r ∈R and a ∈J. This implies
that xn = rxn −rxn+1 + axn. Since xn+1 = xn, we have xn = axn ∈J. This
contradiction shows that R(1 −x) + J ̸= R. Therefore, 1 −x ∈V .
(b) Let J ⊆Jac(R), x a non-unite of R, and 1 −x ∈V . Assume contrary that
xn ∈J or Rxn + J = R for some n ∈N. If xn ∈J, then 1 = xn + (1 −xn) ∈
J + R(1 −x). It follows that R(1 −x) + J = R, which is a contradiction. Hence,
xn ̸∈J. If Rxn + J = R, then Rx + J = R. Hence 1 −rx ∈J ⊆Jac(R) for some
r ∈R. It follows that x is an unite, which is a contradiction. Therefore, xn ∈V
for each n ∈N.
□

of R\Jac(R) such that xn = xn+1 for some n ∈N. Then xn and 1−x are adjacent
in Γ′′
Jac(R).
Proof. If 1 −x ∈J ⊆Jac(R), then x is an unite. Which is a contradiction. Thus
1 −x ̸∈J. If R(1 −x) + J = R, then 1 = r(1 −x) + a for some r ∈R and
