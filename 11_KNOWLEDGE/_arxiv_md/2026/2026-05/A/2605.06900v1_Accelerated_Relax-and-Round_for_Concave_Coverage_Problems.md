Abstract
We present an accelerated relax-and-round algorithm for concave coverage problems, which
generalize the classic maximum coverage problem. Building on the relax-and-round framework
of Barman et al. [STACS 2021], we propose two significant improvements. First, we replace the
linear programming (LP) relaxation step with a projected accelerated gradient method applied to
a smooth surrogate objective to achieve a ˜O(mnε−1) running time. Second, we use a specialized
rounding scheme for the hypersimplex that combines the Carathéodory decomposition algorithm
in Karalias et al. [NeurIPS 2025] with randomized swap rounding of Chekuri et al. [FOCS 2010].
We prove tight approximation ratios for new reward functions, including a 0.827-approximation
for the logarithmic reward φ(x) = log(1 + x). Finally, we conduct maximum multi-coverage
experiments on synthetic and real-world graphs, demonstrating that our algorithm outperforms
approaches that use state-of-the-art LP solvers.

Introduction
While the massive scale of modern datasets continues to push the machine learning (ML) frontier,
the corresponding costs of data curation, storage, and model training have increased proportionally.
Consequently, efficient data pruning has become a critical component of ML workflows. Data subset
selection is typically formulated as a combinatorial optimization problem where the objective is to
find a core subset that fully represents the dataset while minimizing redundancy. This approach is
widely used across domains, including active learning [46, 40, 16, 47, 21], machine translation [28, 10],
bioinformatics [23, 30], and data mixture optimization [38, 39, 42]. Motivated by these applications,
we develop scalable algorithms for the concave coverage problem, a generalization of the NP-hard
maximum coverage problem that provides strong theoretical guarantees.

To give an example, we can frame data pruning as a c-multi-coverage problem on a bipartite
graph [28]. Let L be a set of n text documents and R be a set of semantic topics (e.g., concepts in a
natural language processing task). Define the edge {i, j} ∈E if document i ∈L represents topic
j ∈R (e.g., an ESPN article connects to the “sports” topic). To ensure a model learns each concept
sufficiently, our goal is to select a subset of data S ⊆L with budget |S| ≤k such that every topic is
covered at least c times. This objective is captured by the concave function φ(x) = min(x, c). Since
concave coverage is an instance of monotone submodular maximization subject to a cardinality
constraint, the greedy algorithm guarantees a (1 −1/e)-approximate solution [35]. Barman et al.
[7, 8], however, introduced a relax-and-round algorithm for concave coverage and proved it has a
tight approximation ratio equal to the Poisson concavity ratio αφ, which is purely a function of φ
and often better than 1 −1/e. For example, if we require deep semantic coverage with c = 1000,
then αφ = 1 −cc/(ecc!) ≥0.987. Conversely, setting c = 1 recovers the classic maximum coverage
problem and its 1 −1/e guarantee.
Theorem 1.3 (Barman et al. [7]). For any normalized nondecreasing concave function φ, there is
a polynomial-time αφ-approximation algorithm for the φ-MaxCoverage problem. Furthermore,
for φ(n) = o(n), it is NP-hard to approximate the φ-MaxCoverage problem to within a factor of
αφ + ε, for any constant ε > 0.
We note that for any reward function φ, we have αφ ≥1 −1/e. We give a short proof in Section A.1.

1.1
Our contributions
We summarize the main contributions of our work below:
• Faster LP relaxation. We construct a smooth surrogate coverage objective eCµ(x) in Section 3
and run accelerated projected gradient ascent starting from x(0) = xgreedy (Algorithm 1) to
optimize this concave proxy for x ∈∆n,k. We bound the number of steps required for a
(1 −ε)-approximation to the original objective C(x) in Theorem 4.6, achieving a ˜O(mn/ε)
running time, which is strictly faster than Barman et al. [7] (see Section A.2).
• Rounding. After computing an approximate LP solution ex∗, we use a rounding scheme tailored
for points in the hypersimplex ∆n,k. Pipage rounding in Barman et al. [7] takes O(nm∆)
time, but by combining the Carathéodory decomposition in Karalias et al. [26] and swap
rounding [13], we round ex∗to a high-value integral feasible solution in O(nk log n) time and
remove the dependence on the number of edges m and maximum degree ∆.
• Approximation ratios. We study new reward functions and prove tight approximation ratios in
Section 5. For example, if φ(x) = log(1 + x) then αφ ≈0.827. We also study piecewise linear
functions and the isoelastic utility φ(x) = x1−γ, which we show has a closed-form integral
expression for αφ by building on the infinite series in [7].
• Experiments. We construct c-multi-coverage instances where the greedy algorithm gets stuck
at (1 −1/e)OPT but relax-and-round converges to the optimal solution, i.e., αφ →1. Then we
compare Algorithm 1 to state-of-the-art LP solvers with pipage rounding on real-world SNAP
graphs, demonstrating better end-to-end running times and rounded objective values.
1.2
Related work
Submodular maximization.
Submodular maximization subject to a cardinality constraint k is an
NP-hard problem. For monotone submodular functions, Nemhauser et al. [35] showed that the greedy
algorithm achieves a (1 −1/e)-approximation, which is asymptotically optimal unless P = NP [22].
Over the last decade, there has been significant research on distributed algorithms for submodular
maximization in the MapReduce model [34, 33, 6, 31] and low-adaptivity models [5, 19, 20, 14].
Concave coverage.
Barman et al. [7, 8] study the concave coverage problem and give a relax-and-
round algorithm with tight approximation guarantees in terms of the Poisson concavity ratio αφ. A
related line of work starts with Stobbe and Krause [41], who give an algorithm for minimizing a
4


## Page 5


class of functions they call decomposable submodular functions, i.e., those that can be represented as
a sum of concave functions applied to modular functions (SCMs). Dolhansky and Bilmes [18] later
studied deep submodular functions (DSFs) and showed that deep neural networks with nonnegative
weights correspond to a DSF and that DSFs strictly generalize SCMs.
Bai et al. [4] is the first work to maximize DSFs, a class of submodular functions that includes
concave coverage. Their algorithm uses projected gradient ascent and pipage rounding, and requires
O(n2/ε2) calls to a submodular value oracle before rounding. In an independent work, Lv et al. [32]
recently used accelerated projected gradient ascent and pipage rounding for SCM maximization.
However, neither guarantees worst-case constant-factor approximation ratios. In fact, Lv et al.
[32] state that “the approximation bounds above are not fixed constants,” and specifically identify
φ(x) = log(1 + x) as one of “several commonly used [concave] functions.” Our work addresses these
open problems with tight analysis using the framework of Barman et al. [7].
ML applications.
Kirchhoff and Bilmes [28] use feature-based submodular functions for a machine
translation task (an instance of concave coverage) and find that “the square root φ(x) = √x performs
slightly better than the log function” in their experiments. Wei et al. [45] use the same formulation
for a large-scale speech data subset selection task. Karimi et al. [27] study weighted coverage
functions and give a concave relax-and-round algorithm for influence maximization. Deng et al. [17]
design reverse data auctions via submodular maximization and “quasi-linear utilities,” for which
we derive tight and novel approximation ratios in Theorem 5.2. For more examples, we direct the
reader to [11] for an excellent survey on applications of submodularity in machine learning.

Rounding
In the last stage of our algorithm, we round the fractional solution x(T ) ∈[0, 1]n to a feasible integral
solution xint ∈{0, 1}n. Barman et al. [7] use pipage rounding [1], but pipage rounding requires
O(nm∆) time since it evaluates the multilinear extension F(x) at most n times, which can be
prohibitively expensive.
To make this faster, we give a tailored version of the SwapRound algorithm [13] for uniform
matroids (cardinality constraint k) that removes the dependence on the number of edges m. A subtle
but crucial requirement for SwapRound is that the input fractional point needs to be represented as
a convex combination of matroid bases, i.e., x(T ) needs to be written as a convex combination of
vertices of the hypersimplex ∆n,k. Carathéodory’s theorem guarantees that such a decomposition
exists with at most n vertices, so we use the recent combinatorial vertex-peeling algorithm of Karalias
et al. [26] for uniform matroids to find this decomposition.

C.5.1
Carathéodory decomposition
A key insight for our rounding strategy is Carathéodory’s theorem, which states that any point x in
an n-dimensional convex hull Conv(P) ⊆Rn can be written as a convex combination of at most n+1
vertices of P. In our case, we want to decompose a fractional solution x(T ) ∈∆n,k, where ∆n,k is
the hypersimplex (the convex hull of all binary vectors in {0, 1}n with exactly k ones). Even though
the hypersimplex lives in Rn, the constraint Pn
i=1 xi = k restricts it to an (n −1)-dimensional affine
subspace. Thus, the effective dimension is n −1 and Carathéodory’s theorem guarantees that any
point x ∈∆n,k can be written as a convex combination of at most n vertices.
Computing a Carathéodory decomposition can be expensive, often requiring linear programming,
which is often too slow for large-scale coverage problems. To solve this, we use the recent combinatorial
breakthrough in Karalias et al. [26, Algorithm 1], as it is a highly efficient way to decompose x ∈∆n,k
into at most n vertices.
Theorem C.3 (Karalias et al. [26, Theorem 4.3]). For x ∈∆n,k, Algorithm 3 terminates in r ≤n
iterations and returns probability-vector pairs {(αt, vt)}r
t=1 such that x = Pr
t=1 αtvt, where vt is a
binary vector with exactly k ones. This algorithm can be implemented to run in O(nk log n) time.

Additional experiments
All of the experiments are implemented in C++ and run on an AMD EPYC 7B13 processor (2.45
GHz, 256MB L3 cache) with 240GB RAM. The LP solver versions we use are GLOP v9.15 [37],
HiGHS v.1.10.0 [25], and SCIP v7.0.1 [24].
We conducted our experiments on two graphs in the Stanford Network Analysis Platform
(SNAP) [29]: facebook and dblp. The original facebook graph has 4,039 nodes and ∼88k edges,
and the original dblp graph has of 317,080 nodes and ∼1M edges. For each dataset, we construct
a symmetric bipartite graph G′ = (L, R, E′). Specifically, for each node u in the original graph,
we create two copies: u ∈L and u′ ∈R, connected by an edge {u, u′}. Further, each original
undirected edge {u, v} is mapped to two edges, {u, v′} and {v, u′}, in the bipartite coverage graph.
Consequently, the resulting bipartite graph for facebook has 4,039 nodes per side with 180,507 total
edges, and the dblp bipartite graph has 317,080 nodes per side and 2,416,812 total edges. We study
c-multi-coverage [8], where φ(x) = min(x, c), for different values of c and cardinality constraints k.
