Abstract
Large language models succeed by combining large-scale pretraining with meaningful discrete
tokens. In molecular machine learning, SMILES is widely used as a token representation, but it
is a traversal-dependent string rather than a semantic decomposition of chemistry. We propose
VQ-Atom, a semantic tokenization framework that assigns discrete atom-level tokens based on
local chemical environments via vector quantization. Unlike SMILES tokens, VQ-Atom tokens
encode graph-local chemical context and are aligned with molecular structure. On protein-cold
drug–target interaction prediction using the KIBA dataset, VQ-Atom substantially improves
global ranking performance, achieving AUROC of 0.78 compared to 0.73 for SMILES under an
identical downstream architecture. While both representations achieve strong early enrichment,
the gains from ligand MLM pretraining are minimal. These results suggest that molecular
tokenization is not merely a preprocessing step, but a central design choice. In particular,
well-structured tokens can encode substantial chemical semantics, reducing reliance on large-
scale pretraining. VQ-Atom can be interpreted as defining a molecular language, where tokens
correspond to chemically meaningful atomic environments.
1
Introduction
Large language models have transformed natural language processing by combining large-scale
pretraining with meaningful discrete tokens [1, 2]. Transformers alone are not sufficient; successful
pretraining relies on stable symbolic units such as words or subwords that capture reusable semantic
structure [3]. Molecular machine learning increasingly aims to adopt this paradigm, yet chemistry
lacks an equivalent molecular vocabulary.
The dominant representation, SMILES [4], enables
token-based modeling but is fundamentally a traversal-dependent linearization of molecular graphs.
Its tokens are largely syntactic rather than chemically meaningful, and different valid strings can
represent the same molecule. This mismatch encourages shortcut learning and weak generalization
under distribution shift [5]. Graph neural networks [6] provide continuous molecular representations,
but continuous embeddings do not define persistent symbolic units for masked language modeling.
We therefore argue that molecular pretraining is limited not only by model architecture, but also by
tokenization.
We propose VQ-Atom, a semantic tokenization framework that assigns discrete tokens directly
to atom-level local chemical environments. Each token encodes not only atomic identity, but also
relational context such as bonding, aromaticity, ring structure, and neighboring atom composition.
Inspired by vector quantization approaches [7], this discretization provides a finite vocabulary
grounded in chemical structure. We evaluate VQ-Atom on protein-cold drug–target interaction

VQ-Atom: Overview
Figure 1 illustrates the overall pipeline, from continuous atom-level representations to discrete
semantic tokens. VQ-Atom constructs a discrete molecular vocabulary by encoding atom-centered
local chemical environments and discretizing them via vector quantization.
Each atom is represented by a feature vector capturing its local chemical context, including
atomic identity, degree, formal charge, hybridization, aromaticity, ring membership, hydrogen count,
and functional group indicators [8]. We further include higher-order descriptors such as ring size,
fused ring identity, aromatic neighbor counts, and bond-environment features. These features are
encoded by a graph neural network to produce atom-level representations.
Vector quantization [7] maps these continuous embeddings into a finite set of discrete codes.
Unlike SMILES [4], where token identity depends on a particular graph traversal, VQ-Atom tokens
are assigned directly to atom-centered local environments and are invariant to linearization. The
resulting token sequences are compatible with Transformer-based masked language modeling [1, 2],
while preserving chemically meaningful local structure. In this formulation, sequence order becomes
an implementation detail, whereas chemical context is embedded directly into the tokens.
Figure 2 shows examples of this transformation, where similar local environments are mapped
to shared token IDs across molecules, while distinct environments receive different tokens. These
observations indicate that VQ-Atom captures chemically meaningful local structure while enabling
reuse of common patterns across molecules.
Our goal is not to introduce a novel graph neural network architecture, but to study the effect of
semantic discretization. Therefore, we keep the encoder simple and focus on the properties of the
resulting tokenization.

3
Method
3.1
VQ-Atom Discretization
Each molecule is represented as an atom-level graph and encoded using a three-layer GINE network
with jumping-knowledge style concatenation over 0–3 hop representations. Atom features include
elemental identity, degree, formal charge, hybridization, aromaticity, ring membership, hydrogen
count, functional-group indicators, donor/acceptor flags, ring size, aromatic neighbor count, fused
ring identity, and local bond-environment descriptors. The encoder maps atoms to a 16-dimensional
latent space followed by L2 normalization. Vector quantization is applied using per-atom-type
codebooks of size 10,000, initialized via k-means and updated with exponential moving averages
during training. After training, the codebooks are frozen, and each atom is assigned to the nearest
codebook vector by cosine similarity, yielding a discrete VQ-Atom token ID. The quantization
module is trained using a commitment loss together with repulsion-based regularization:
L = Lcommit + λ1Llat-repel + λ2Lcb-repel
(1)
The commitment term encourages latent embeddings to align with assigned codebook vectors. The
3


## Page 4


latent repulsion term promotes separation between atom embeddings, while the codebook repulsion
term enforces diversity among codebook entries, preventing cluster collapse and encouraging a more
uniform partitioning of the latent space. The codebooks are trained on 208,524 unlabeled molecules
after size filtering and deduplication. The molecules are collected from public chemical databases,
primarily from ChEMBL [9], with additional structures from PDBBind [10]. This corpus is used solely
for learning atom-level discretization and is constructed independently of the downstream KIBA [11]
dataset. This formulation differs from reconstruction-based VQ objectives by explicitly encouraging
dispersed and semantically distinct atom representations, which we find to be particularly effective
for downstream molecular prediction tasks. The model is trained using Adam with learning rate
1 × 10−3 for 50 epochs, with batch size 256. The loss weights are fixed to λ1 = 1.0 and λ2 = 0.1.
3.2
Ligand Pretraining (MLM)
We pretrain a Transformer-based ligand encoder on VQ-Atom token sequences using a masked
language modeling (MLM) objective. Molecules are represented as variable-length token sequences
and padded within each batch. We pretrain on approximately 1.0 million unlabeled molecules
(1,007,434 molecules in total), comprising about 28 million atom-level tokens. Tokens are randomly
masked with probability 0.15 following the standard 80/10/10 strategy. The model is trained to
predict the original token identity using a cross-entropy loss over the discrete VQ-Atom vocabulary.
LMLM = −E(x,i) log pθ(xi | x−i)
(2)
where xi denotes the token at position i, and x−i denotes the input with the i-th token masked.
The encoder consists of 10 Transformer layers with hidden dimension 512, 16 attention heads, and
feed-forward dimension 1024, with dropout set to 0.1. Training is performed using AdamW with
learning rate 2×10−4, weight decay 0.01, batch size 64, gradient clipping at 1.0, and a warmup–cosine
learning-rate schedule. We train the model for up to 65 epochs and select the best checkpoint based
on validation loss. The final pretrained model (epoch 65) is used for downstream experiments. The
MLM objective converges stably after correcting the tokenization pipeline. The MLM preprocessing
pipeline, split configuration, and training scripts will be released.
3.3
DTI Model
For downstream drug–target interaction prediction, we use a dual-stream architecture where proteins
and ligands are encoded separately and fused via cross-attention. Proteins are encoded using
pretrained ESM [12], while ligands are represented either by SMILES tokens or VQ-Atom tokens.
Both encoders are fine-tuned during training, with the bottom 28 layers of ESM frozen. The
interaction module uses 8 attention heads, sigmoid attention, attention temperature 1.5, and token
dropout of 0.10 for both protein and ligand.
We do not use positional encodings for ligand tokens. Although tokens are processed as sequences
for compatibility with Transformers, VQ-Atom is inherently defined on graph-structured atom
environments. Positional encodings would impose an arbitrary ordering unrelated to chemical
structure and may introduce noise, so we omit them.
Figure 3 illustrates the overall architecture. The only difference between the two settings is
the ligand tokenization, enabling a controlled comparison between SMILES and VQ-Atom. The
interaction module departs from standard cross-attention in three key aspects. First, we use a
dual-stream formulation, computing both ligand-to-protein and protein-to-ligand attention maps.
These are combined using an element-wise minimum operation, retaining only mutually consistent
interactions and suppressing asymmetric noise. Second, instead of softmax normalization, we apply

a sigmoid activation to the attention logits. This allows each pairwise interaction to be modeled
independently rather than enforcing competition across tokens, which is more suitable for multi-

symmetric interaction map that better captures meaningful ligand–protein contacts.
Our comparisons focus on token-based representations (SMILES vs VQ-Atom) under a shared
architecture in order to isolate the effect of tokenization. We intentionally avoid comparisons with
specialized state-of-the-art DTI architectures, as such comparisons would confound improvements
from tokenization with architectural differences. Our goal is not to establish a new state-of-the-art
DTI model, but to evaluate how representation alone impacts downstream performance.
3.4
DTI Training
We formulate DTI prediction as a binary classification task. Continuous KIBA scores are binarized
using a threshold of 12.1, and the model outputs a scalar logit that is converted to an interaction

probability by a sigmoid function. The model is trained using a binary cross-entropy loss with logits,
with an auxiliary regression loss weighted by λ = 0.2.
LDTI = −E(x,y) [y log σ(z) + (1 −y) log(1 −σ(z))] ,
(3)
where z is the predicted logit and σ denotes the sigmoid function. We train the DTI model for 30
epochs using AdamW with learning rate 3 × 10−5, weight decay 0.05, batch size 16, and dropout
0.4. Both the protein encoder and ligand encoder are fine-tuned, while the bottom 28 layers of ESM
are frozen. Layer-wise learning-rate decay is applied with factor 0.97, and the ESM learning-rate
multiplier is set to 0.1. We use a linear warmup with ratio 0.05, followed by a plateau-based learning
rate scheduler. The interaction module uses 8 attention heads, sigmoid attention with temperature
1.5, token dropout of 0.10 for both protein and ligand tokens, and bidirectional ligand–protein
aggregation. Models are selected based on validation AUROC and evaluated once on the held-out
test set. The same training configuration is used for both SMILES and VQ-Atom representations.
We evaluate the model in inference mode without dropout and report test performance using
the checkpoint selected on the validation set. All experiments are repeated with 5 random seeds.
Hyperparameters are fixed across experiments unless otherwise noted.
4
Experiments
4.1
Dataset and Evaluation Setup
We evaluate on the KIBA dataset [11], following the preprocessing protocol of GraphDTA [13].
Continuous interaction scores are binarized using a threshold of 12.1. We construct a strict protein-
cold split using MMseqs2 clustering [14] at 40% sequence identity, ensuring that proteins are
completely disjoint across train, validation, and test sets. We focus on the protein-cold setting, which
is commonly used in prior DTI studies and reflects generalization to unseen targets. The dataset
sizes are 35,747 / 4,219 / 4,036 pairs, respectively, with positive rates of 32.5%, 22.4%, and 28.9%.
The number of unique proteins is 113 / 14 / 15, and the number of unique ligands is 1,007 /
841 / 793 across train, validation, and test sets, respectively. While proteins are strictly disjoint,
ligands are largely shared across splits. This setup prevents trivial memorization of protein identity
while enabling controlled evaluation of ligand representations. The dataset is relatively dense on the
protein side, while ligands are sparse in validation and test, creating a challenging generalization
setting. Under this structure, each ligand is associated with a limited number of proteins, making
ligand–target interactions relatively sparse from the ligand perspective.
We also experimented with stricter double-cold splits, where both proteins and ligands are unseen
during testing. However, such splits resulted in extremely small and unstable evaluation sets. In
particular, the number of interaction pairs per protein or per ligand often approaches one, making it
difficult for models to learn meaningful patterns and leading to high variance in evaluation.
We do not use large-scale datasets such as BindingDB [15] or structure-based datasets such as
PDBBind [10] for supervised evaluation. BindingDB is highly sparse, with very few interaction
pairs per protein–ligand pair, while PDBBind is relatively small and structurally biased. These
characteristics make it difficult to construct reliable protein-cold or double-cold splits and often lead
to unstable training and evaluation. Instead, we focus on the KIBA dataset, which provides a denser
interaction matrix and a more suitable benchmark for controlled evaluation of representation quality
under distribution shift.

4.2
Main Results
VQ-Atom substantially improves protein-cold DTI prediction under a controlled architecture. As
shown in Table 1, VQ-Atom achieves a final AUROC of 0.783 compared to 0.734 for SMILES under
ligand pretraining, and 0.782 compared to 0.741 without pretraining.
In terms of early enrichment, both representations achieve strong EF1 values in the range of
2.8–3.0, corresponding to hit rates of 82–88%. Interestingly, SMILES achieves higher EF1 and
Hit@1% in some settings despite lower overall AUROC.
To better understand the observed performance differences, we analyze the distribution of positive
rates across ligands and proteins (Figure 5). While protein-level distributions remain stable across
splits, ligand-level distributions exhibit a strong skew in the test set, with many ligands associated
with predominantly negative interactions. This suggests that ligand-level priors may play a significant
role in prediction, potentially favoring models that rely on ligand-specific signals.

4.3
Ablation: Tokenization vs Pretraining
To isolate the effect of tokenization, we compare SMILES and VQ-Atom with and without ligand
MLM pretraining under an identical downstream architecture (Table 1). Across both pretrained and
non-pretrained settings, VQ-Atom achieves higher AUROC than SMILES. Under ligand pretraining,
VQ-Atom reaches 0.783 compared to 0.734 for SMILES. Without pretraining, VQ-Atom achieves
0.782 compared to 0.741 for SMILES.
The effect of ligand MLM pretraining is limited. For VQ-Atom, AUROC changes only marginally
from 0.782 to 0.783. For SMILES, pretraining decreases performance from 0.741 to 0.734. Similar
trends are observed for enrichment metrics. We report enrichment factors (EF) normalized by the
dataset positive rate, such that EF = 1 corresponds to random ranking.
4.4
Analysis
Figure 2 provides an intuitive explanation for the observed performance gains. Unlike SMILES,
which encodes each molecule as a unique sequence, VQ-Atom decomposes molecules into reusable
atom-level tokens corresponding to local chemical environments. Chemically similar substructures
are consistently assigned identical token IDs across molecules, indicating that the representation
captures recurring chemical motifs.
This compositional structure enables the model to reuse learned representations across molecules,
improving generalization to unseen proteins and ligand contexts. This is particularly important
under protein-cold evaluation, where memorization of protein identity is not possible.
Interestingly, SMILES achieves higher EF1 and Hit@1% in some settings despite lower overall
AUROC. One possible explanation is the relative sparsity of ligand–target interactions under the
protein-cold split.
Although each ligand appears in multiple interaction pairs, the number of
associated proteins is still limited, making ligand identity a relatively strong signal. As a result, the
model may rely more heavily on ligand-specific patterns. Sequence-based representations such as
SMILES may more readily exploit this effect, leading to higher early enrichment (EF).
In addition to higher AUROC, VQ-Atom exhibits consistently lower variance across random seeds
compared to SMILES, as reflected by smaller standard deviations in both AUROC and enrichment
metrics. This trend is further illustrated in Figure 4, where VQ-Atom shows tighter clustering of
performance across seeds. This indicates that VQ-Atom yields more stable and reliable performance,
with reduced sensitivity to random initialization and training noise. This stability is particularly
important in practice, where model performance should be robust across training runs.
In addition, early enrichment metrics emphasize the top-ranked predictions and may favor models
that rank a subset of positive samples very highly. In contrast, VQ-Atom produces more distributed
representations, resulting in more consistent global ranking performance.
5
Discussion
5.1
Tokenization vs Pretraining
Our results highlight a key difference between molecular representation learning and natural language
modeling. In natural language, tokens inherently carry semantic meaning, whereas commonly used
molecular representations such as SMILES primarily encode syntax and traversal artifacts rather
than intrinsic chemical structure.
In our experiments, ligand MLM pretraining provides negligible improvement, while tokenization
has a substantial impact. This suggests that, in contrast to natural language, a well-designed
tokenization can already encode meaningful structure, reducing the need for large-scale pretraining.

One possible explanation is the relatively small scale of the pretraining data compared to modern
language models. However, the strong performance of VQ-Atom even under this regime indicates
that token design plays a central role in molecular representation learning.
5.2
Why VQ-Atom Works
VQ-Atom can be interpreted as a form of representation learning at the token level. By embedding
local chemical environments directly into discrete tokens, it shifts part of the modeling burden from
the neural network to the tokenization itself. This differs from conventional approaches, where
models must learn structural relationships implicitly from less structured inputs.
This compositional tokenization enables reuse of local chemical patterns across molecules, which
is particularly beneficial under distribution shifts such as protein-cold settings. As a result, VQ-Atom
achieves more consistent global ranking performance compared to sequence-based representations.
5.3
Implications for Molecular Modeling
The observed differences between AUROC and early enrichment metrics highlight that these metrics
capture distinct aspects of model behavior. Early enrichment focuses on top-ranked predictions,
while AUROC evaluates global ranking quality across all samples.
More broadly, our results suggest that molecular tokenization should be viewed as a central
design choice rather than a preprocessing step. In this perspective, improving token quality may be
as important as scaling model size or pretraining data in molecular machine learning.
6
Conclusion
We introduced VQ-Atom, a semantic molecular tokenization framework based on discrete atom-
level environments. Under protein-cold DTI evaluation, VQ-Atom consistently improves AUROC
compared with SMILES under a controlled architecture, while achieving comparable early enrichment
performance. Our results show that the impact of ligand MLM pretraining is limited in this setting,
whereas the choice of tokenization has a substantial effect on downstream performance.
This
suggests that tokenization can encode a significant portion of chemical structure, reducing the
burden on pretraining. More broadly, these findings highlight that molecular representation learning
differs from natural language modeling in an important way: rather than relying primarily on
large-scale pretraining to learn token semantics, it is possible to embed such semantics directly
into the tokenization itself. We argue that molecular modeling should not only adopt architectures
from language models, but also reconsider the design of the underlying representation. In this
sense, VQ-Atom can be viewed as a step toward a molecular language, where tokens correspond to
chemically meaningful local environments rather than syntactic fragments. Code, pretrained models,
and full preprocessing pipelines will be released upon publication to support reproducibility.
7
Limitations
Despite the promising results, several limitations should be noted. First, the current VQ-Atom
discretization is based on local atomic environments with a fixed receptive field. As a result, atoms
with different higher-order or long-range contexts may be assigned identical token IDs. While this
promotes generalization, it can also lead to loss of specificity in certain chemical settings. Second,
the capacity of the codebook is limited. Increasing the number of codebook entries or adopting more
expressive aggregation strategies may allow the representation to capture finer-grained chemical
9


## Page 10


distinctions. Third, the scale of ligand pretraining in this work is relatively small compared to modern
language models. Although we observe limited gains from pretraining, it remains possible that larger-
scale molecular corpora could lead to stronger improvements. Fourth, the current framework does
not explicitly incorporate long-range structural or 3D information. While VQ-Atom captures local
chemical environments, integrating structural supervision, such as atom–residue contact information,
may further improve performance. Finally, our evaluation is based on a protein-cold split, where
ligands are shared across training and test sets. While this setting provides a realistic and widely
used benchmark, it may still allow models to exploit ligand-specific patterns. In particular, although
each ligand appears in multiple interaction pairs, the number of associated proteins is limited, making
ligand–target interactions relatively sparse from the ligand perspective. This may bias models toward
relying more heavily on ligand-specific signals.
A stricter double-cold evaluation, where both proteins and ligands are unseen during testing,
would provide a stronger test of generalization. However, constructing such splits is challenging in
practice due to the extreme sparsity of available interaction data. Under double-cold constraints,
the number of interaction pairs per protein or per ligand often approaches one, making it difficult
for models to learn meaningful patterns. This also leads to a substantial reduction in dataset size,
resulting in small and statistically unstable evaluation sets. As a result, double-cold benchmarks may
not reliably reflect model performance in realistic settings. Developing scalable and robust evaluation
protocols for strict generalization remains an important direction for future work. Addressing these
limitations represents an important direction for future work.
8
Broader Impact
This work contributes to molecular representation learning and may accelerate drug discovery by
improving the generalization of drug–target interaction models. Potential risks include misuse in
the design or prioritization of harmful compounds, although this work does not directly enable
generative molecule design. We believe the primary impact is positive, supporting more efficient
identification of therapeutic candidates.

Additional Implementation Details
Each atom is represented by a concatenation of features including atomic number, degree, formal
charge, hybridization, aromaticity, ring membership, hydrogen count, functional group indicators,
donor/acceptor flags, ring size, aromatic neighbor count, and fused ring identifiers. Vector quan-
tization uses separate codebooks per atom type, each with size 10,000. Codebooks are initialized
via k-means and updated using exponential moving averages. The latent dimension is 16, and
nearest-neighbor assignment is performed using cosine similarity. For MLM pretraining, tokens
are masked with probability 0.15 following the 80/10/10 strategy, and the model is trained using
cross-entropy loss. For DTI training, sigmoid attention with temperature scaling is used instead
of softmax to stabilize training. All experiments are conducted on a single GPU, and full training
scripts will be released upon publication.
