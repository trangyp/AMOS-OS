A NOTE ON THE MODAL LOGIC OF SYMMETRIC
EXTENSIONS
HOPE DUNCAN
Abstract. Taking symmetric extensions can be considered as a gener-
alisation of forcing, which produces a richer multiverse of models with
and without the axiom of choice. We can study the structure of this
multiverse using modal logic. In particular, we define the concept of
of choice-switches, and show any independent system of choice-switches
is not itself independent from any standard example of an independent
system of buttons.
1. Introduction
A standard way of generating models of ZF without choice is by taking
a symmetric extension over a model of ZFC.
Symmetric extensions can
be considered to be a generalisation of forcing, where forcing is thought of
as taking a symmetric extension with names symmetric for the improper
subgroup filter (which contains the trivial group).
In a similar way we
can think of the multiverse of symmetric extensions as a generalisation of
the forcing multiverse, adding intermediate models generated by symmetric
extensions which may witness failures of choice. Modal logic gives us a lens
through which to study the structure of this multiverse. Modal logic adds
two modal operators □and ♢, where □φ expresses that φ is necessary,
and ♢φ that φ is possible. In the context of a forcing multiverse, φ being
necessary corresponds to φ being true in every forcing extension, and φ
being possible to φ being true in some forcing extension.
There are various axiom systems for modal logic we can define, the most
important for us being S4.2 (see Definition 4.2). Hamkins and Löwe showed
that the modal logic of forcing is S4.2 [5], and using a similar proof Block and
Löwe showed that the modal logic of symmetric extensions is also S4.2. A
key part of the proof that the modal logic of forcing is S4.2 is the existence
of an infinite independent system of buttons and switches.
A button is
a statement φ which is (necessarily) possibly necessary, and a switch is a
statement φ such that both φ and ¬φ are necessarily possible. Buttons and
switches are independent if they can be pushed/switched without affecting
any other button or switch.
In this generalised context, it is natural to consider whether we now have
new buttons and switches. We show there are no new buttons, but there
are new switches.

2. Preliminaries
2.1. Symmetric systems. In the following section, assume that V is a
model of ZF.
Let P be a forcing notion and consider an automorphism
π ∈Aut(P). We can extend the action of π to P names with the following
recursive definition,
π ˙x = {⟨πp, π ˙y⟩| ⟨p, ˙y⟩∈˙x}.
Let G be a group, we say that F is a normal filter of subgroups of G if it is
a non-empty family of subgroups of G closed under finite intersections and
supergroups, such that for every π ∈G and H ∈F, πHπ−1 ∈F.
Definition 2.1. A symmetric system S is a triple ⟨P, G , F⟩, where P is a
forcing notion, G ⊆Aut(P) is a group of automorphisms, and F is a normal
filter of subgroups on G .

that ˙x is F-symmetric if symG ( ˙x) = {π ∈G | π ˙x = ˙x} ∈F.

2.2. Clubs and collapses. We will rely on the following standard facts
about clubs.
Proposition 2.5. Suppose that λ is an uncountable regular cardinal, {Sα |
α < µ} is a sequence of clubs of λ. If µ < λ, then T{Sα | α < µ} is a club;
and if µ = λ then the diagonal intersection △{Sα | α < µ} is a club.
Proposition 2.6. Let κ be a regular cardinal in M (a model of ZF). If
in some extension, M[G], there exists a sequence of < κ many clubs, with
empty intersection, then κ is not regular in M[G]. In particular, if κ is a
successor cardinal in M, and M[G] |= ZFC, then κ must have been collapsed.
3. Collapsing cardinals
3.1. The Fodor property. Using a construction of Karagila [9], we know
that it is consistent that Fodor’s Lemma can fail everywhere. In particular,
for any uncountable regular cardinal λ, and µ < λ, there exists a symmetric
extension in which the (λ, µ)-Fodor property fails. For our purposes, we will
assume λ is a limit ordinal.
Definition 3.1. Let λ be an uncountable, regular cardinal, and µ ⩽λ. We
say that λ has the (µ, λ)-Fodor property if whenever S ⊆λ is a stationary
set, and f : S →λ is a regressive function with range of cardinality ⩽µ,
there is some α such that f−1({α}) is stationary.
We can phrase the Fodor property in terms of a property of the club filter.
Theorem 3.2. Let λ be an uncountable regular cardinal. The following are
equivalent for any µ < λ:
(1) λ has the (λ, µ)-Fodor property
(2) The club filter of λ is µ+-complete.

4. The modal logic of symmetric extensions
4.1. The modal logic of forcing. We can consider all the possible forcing
extensions of a model of ZFC, as a multiverse, with forcing acting as an
‘accessibility relation’ between them. To study this multiverse, it can be
helpful to use concepts from modal logic.

Modal logic adds two modal operators □and ♢, where □φ expresses
that φ is necessary, and ♢φ that φ is possible. In the context of a forcing
multiverse, φ being necessary corresponds to φ being true in every forcing
extension, and φ being possible to φ being true in some forcing extension.
Hamkins and Löwe gave an exact categorisation of the modal logic of forcing
in [5].
Theorem 4.1. The modal logic of forcing is exactly S4.2.
Definition 4.2. The axiom system S4.2 is as follows:
• (K): □(φ →ψ) →(□φ →□ψ)
• (Dual): ¬□φ ↔□¬φ
• (S): □φ →φ
• (4): □φ →□□φ
• (.2): ♢□φ →□♢φ
The proof of Theorem 4.1 relies on the existence of an infinite independent
system of buttons and switches.
Definition 4.3. A button is a statement φ which is (necessarily)1 possibly
necessary.
The statement V ̸= L is a button. The button is pushed when it becomes
necessary, else it is unpushed. So, once the button is pushed, φ holds in any
further forcing extension. We say a button φ is a pure button if when φ is
true, it is necessarily true, i.e. φ →□φ2.
Definition 4.4. A switch is a statement φ such that both φ and ¬φ are
necessarily possible.
This means we can turn a switch on by moving into a generic extension
where it is true, and then turn it off by moving into a generic extension
where it is false. For example, CH is a switch.
Definition 4.5. A system of buttons and switches is independent over a
particular model if (i) all of the buttons are unpushed in that model, and
(ii), necessarily, i.e. in any forcing extension, any of the buttons can be
pressed, and any of the switches can be switched without affecting any other
button or switch.
We can exhibit a an independent system of buttons and switches over
V = L as follows; take a countable partition of ω1 into stationary sets Sn,
and define buttons bn := ‘the set Sn is not stationary’. This set of buttons
is used in [5], for independence see [8, 23.8, 23.6]. Then we can define our
switches as sn := ‘2ℵn = ℵn+1’, for n ⩾2.

4.2. Choice-switches. A natural generalisation of this work is to ask what
the modal logic of symmetric extensions is. This question was answered by
Block and Löwe in [2].
Theorem 4.6. The modal logic of symmetric extensions is exactly S4.2.
The proof is similar to the proof of Theorem 4.1, which if we think about
symmetric extensions as a generalisation of forcing extensions is unsurpris-
ing. Indeed, the same system of buttons and switches can used in proof of
Theorem 4.6 as in 4.1. A natural question therefore is if taking symmetric
extensions is a generalisation of taking forcing extensions, do we have new
examples of pure3 buttons? Do we have new examples of switches? Quickly,
we can answer no, and yes, respectively. For brevity, we will say forcing
switch for a statement which is a button in the modal logic of forcing, and
symmetric switch for a statement which is a switch in the modal logic of
symmetric extensions.
Proposition 4.7. Every φ which is a pure symmetric button, was already
a forcing button.
Proof. If φ holds in every symmetric extension of a model, it necessarily
holds in every forcing extension.
□
Proposition 4.8. There exist symmetric switches φ which were not forcing
switches.
Proof. The axiom of choice is now a switch!4
□
Recall here that being a symmetric extension of a model of ZFC is equiv-
alent to being able to set force to restore choice.
We will now focus on
switches which ‘affect’ the axiom of choice.
Definition 4.9. We say φ is a choice-switch if necessarily, φ and ¬φ cannot
both hold in a model where the same fragments of the axiom of choice are
true.
For example, ‘the axiom of choice holds’ is a choice-switch. More inter-
esting examples include ‘countable choice holds’, and ‘there exists an amor-
phous set’. However, ‘CH holds’ is not a choice-switch, we can force ¬CH by
violating choice, but it is not necessary to do so.
Question 1. Can we construct an infinite independent system of buttons
and switches, using choice-switches?
We have nice examples of independent systems of choice-switches in the
literature already. In particular, Ryan-Smith’s construction of models with-
out extendible choice is built using a symmetric extension, and allows us to
vary ECκ at many κ independently.

Question 2. Is there an independent system of buttons which is itself inde-
pendent from any system of choice-switches?
Even if our switches do not directly affect choice, it is not clear how
inevitable choice is in our constructions. We could use a standard example
of an independent set of switches, GCH holding at the nth regular, in a
choiceless model. However, if for some initial segment of the universe Vα,
which is a model of ZF, if Vα |= GCH, then Vα |= AC. It is unclear whether
we have examples of switches which do not necessitate the universe being
well-orderable in this way.
Question 3. Is there an independent set of switches {sn | n < ω} such that
for every n, both sn and ¬sn can hold in a model with a non trivial failure
of choice? (i.e. the failure of choice is not far above any witness to sn or
¬sn).
The modal logic of symmetric extensions has thus far been considered in
the context of taking symmetric extensions over a model of ZFC, or equiv-
alently, considering models of ZF + SVC. We can, however, take symmetric
extensions over a model of ZF, or specifically over a model of ZF + ¬SVC.
Such models may be defined using a class sized symmetric system. Notable
examples of models of ZF + ¬SVC include the Gitik model [4], the Bris-
tol model [11], the Morris model [10], and ‘intermediate models with deep
failure of choice’ [6]. Goldberg also observed that the existence of a Rein-
hardt cardinal in a model implies that model is not a model of SVC [7].
It seems likely that the multiverse of symmetric extensions would have a
similar structure in this context, but it is not clear whether we know of an
independent system of buttons and switches over a model of ZF + ¬SVC.
Question 4. What is the modal logic of forcing, when the core of our mul-
tiverse is a model of ZF + ¬SVC? What is the modal logic of symmetric
extensions, when the core of our multiverse is a model of ZF + ¬SVC?
Hamkins and Löwe [5] studied and asked questions on several topics
closely related to the modal logic of forcing.
These included the modal
logic of forcing over a fixed model of set theory, the modal logic of forcing
with parameters, and the modal logic of forcing when we restrict to a par-
ticular class of forcing notions. Another further direction for research could
be seeing which of their proofs easily generalise to the symmetric extensions
case, and asking their open questions in the context of symmetric extensions.

Appendix: defining extendible choice
We will define a weak choice principle, known as extendible choice, that
is closely related to the notions of Hartogs and Lindenbaum numbers.
Definition 4.16. For a set X, we refer to the least ordinal α such that X
admits no injection α →M as the Hartogs number of X, denoted ℵ(X).
It easily follows that ℵ(X) must be a cardinal, and that in a model of AC,
ℵ(X) = |X|+. In models without choice, it can be useful to think of the
Hartogs number of a set as measuring ‘how well-orderable’ the set is.
Definition 4.17. For a set X, its Lindenbaum number is the least ordinal
α such that there is not a surjection from |X| to |α|, denoted ℵ∗(X).
It is straightforward to show that ℵ(X) ≤ℵ∗(X), and that under the
axiom of choice, ℵ= ℵ∗, and in fact the statement ℵ= ℵ∗is equivalent to
the axiom of choice for well-ordered families. In models without choice, if
for some set X, ℵ(X) < ℵ∗(X), we say that X is an eccentric set. By using
symmetric extensions, we have a lot of control over the possible Hartog–
Lindendaum spectrum, (see [12] and [14] for details).
Definition 4.18. For a given model M of ZF, the Hartogs–Lindenbaum
spectrum of M, denoted Specℵ(M) is the class
Specℵ(M) := {⟨λ, κ⟩| (∃X)ℵ(X) = λ, ℵ∗(X) = κ}.
There is a necessary core to the spectrum in every model of ZF, made up
of the {⟨λ+, λ+⟩| λ ∈Card}, since ℵ(λ) = ℵ∗(λ) = λ+ for all cardinals λ.
Using this fine control of the existence of eccentric sets, we can witness
very particular failures of choice. Extendible choice was first defined by Levy
[13], but we will use a more modern presentation by Ryan-Smith [15].
Definition 4.19. We say ECα holds if when X = {Aβ | β < α} has choice
functions for all ‘initial segments’ {Aβ | β < λ}, then X has a choice func-
tion.
The following equivalences of ECα are shown in [15], using previous results
of Levy.
Proposition 4.20. Let κ be an infinite ordinal and C be the class of cardi-
nals µ with cf(µ) =cf(κ). The following are equivalent:
(1) ECκ
(2) for all µ ∈C, ECµ
(3) for some µ ∈C, ECµ
(4) there is a limit µ ∈C and a set X such that ℵ(X) = µ
We also have a characterisation of exactly where EC can hold.
Proposition 4.21. For all ordinals α and β,
(1) EC0
(2) ECα+1
(3) if cf(α) =cf(β) then ECα = ECβ.
That is, ECα must hold when α is 0 or a successor ordinal, and may or
may not hold at limit ordinals.
