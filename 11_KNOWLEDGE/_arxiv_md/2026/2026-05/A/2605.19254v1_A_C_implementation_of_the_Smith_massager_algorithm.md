1. Introduction
Let A ∈Zn×n be a nonsingular integer matrix. Then there exists a unique diagonal matrix
S = diag(s1, s2, . . . , sn) with s1 | s2 | · · · | sn and unimodular matrices U, V ∈Zn×n such that
UAV = S. The matrix S is the Smith normal form for A while U and V represent row and column
operations invertible over the integers converting A to S. The Smith normal form is a fundamental
object in integer linear algebra with applications to finite abelian group classification [5, 10], linear
system solving [3], lattice computations, and many other areas.
A natural goal is to design algorithms for the Smith form problem with cost softly equivalent to
that of multiplying two matrices of the same dimension and entry size as the input. If ω denotes a
valid exponent for matrix multiplication — two n×n matrices can be multiplied in O(nω) operations
from the domain of entries — and ∥A∥= maxij |Aij| is the largest entry in absolute value, then
the target complexity is (nω log ∥A∥)1+o(1) bit operations. Following [6], we use M(d) to bound
the cost of multiplying two integers bounded by 2d, and B(d) = O(M(d) log d) for integer gcd-
related computations. In [1], integer linear system solving was deterministically reduced to matrix
multiplication. Building on this, [2] gave a Las Vegas algorithm for the Smith form that achieves the
target complexity up to logarithmic factors: O(nω B(log n + log ∥A∥) (log n)2) bit operations. The
central tool introduced in that paper is the Smith massager, a compact representation of A−1 modulo
the invariant factors. A subsequent paper [3] extended the approach to compute the unimodular
multipliers as well.
Our contributions.. In this paper we describe a C implementation of the Smith massager algorithm.
The implementation is built on top of the GMP library [14] for arbitrary-precision arithmetic, the
FLINT library [7] for integer matrix operations, and OpenBLAS [15] for fast numerical linear alge-
bra. The IML library [4] provides certified rational system solving. We detail the key implementation
techniques that bridge the gap between the theoretical algorithm and practical performance and

2.2. Three-phase algorithm
The algorithm has three phases:
Phase 1: Largest invariant factor. Compute the largest invariant factor sn of A (or a positive
multiple thereof) using a Monte Carlo method. This provides the initial modulus s for the iterative
construction.
Phase 2: Iterative massager construction. Starting from the trivial massager (0, 0, In, In), the al-
gorithm performs O(log n) iterations. At iteration i, the algorithm extracts the next batch of ri
invariant factors by computing an index-(m, ri) Smith massager for the current massaged matrix
B. Each iteration involves:
1. Computing a random projection P = Rem(sB−1J, s) for a randomly chosen J ∈Z2n×(ri+k),
via an integrality certification procedure. This reduces the problem to working modulo the
current s.
2. Computing the modular Smith form of the n × ri projection P1 over Z/(s), yielding matrices
U ∈Zri×n and M ∈Zn×ri such that −UP1 ≡D (mod s) and P1 ≡MD (mod s), where D
is the reverse Smith form of P1 modulo s.
3. Setting S′ = sD−1 (the extracted invariant factors) and updating the massaged matrix B
accordingly.
The batch sizes ri grow geometrically: r0, 2r0, 4r0, . . ., exploiting the “dimension × precision ≤
invariant” compromise [13]. As more invariant factors are extracted, the working modulus s shrinks,
so the cost per extracted factor decreases.
Phase 3: Unimodularity certification. Verify that the final massaged matrix B is unimodular using
the deterministic algorithm of [11]. The randomized projection in Phase 2 may fail to produce a
maximal massager (with probability at most 1/2); if Phase 3 detects that B is not unimodular, the
entire algorithm restarts from Phase 1.
2.3. Cost analysis
The cost of Phase 2 is dominated by O(log n) calls to the index massager, each involving an
integrality certification and a modular Smith form computation. The integrality certification for an
n×n matrix with modulus s costs O(nω M(log s) log n) bit operations. Summing over all iterations,
and using the dimension–precision tradeoff, the total cost is O(nω B(log n + log ∥A∥) (log n)2) bit
operations.
Theorem 4 ([2]). There exists a Las Vegas algorithm that computes the Smith form of a nonsingular
A ∈Zn×n using O(nω B(log n + log ∥A∥) (log n)2) bit operations.

3. Implementation techniques
The implementation is written in C and depends on GMP [14] for arbitrary-precision arithmetic,
FLINT [7] for integer matrix operations, and OpenBLAS [15] for BLAS-accelerated numerical linear
algebra. The IML library [4] provides certified rational system solving via Dixon’s p-adic lifting.
The main algorithm and the RNS arithmetic infrastructure live under src/core/. Two sup-
porting modules, src/lift/ (double-plus-one p-adic lifting [13]) and src/spinv/ (unimodularity
certification via high-order residues [11]), implement standard techniques from the literature; since
their implementation follows the published descriptions, we do not discuss their internals further.
In this section we document the engineering choices made in our implementation, which are
important for practical performance.
3.1. BLAS-accelerated modular arithmetic via the Residue Number System
The dominant cost in the algorithm is integer matrix multiplication.
The Residue Number
System (RNS) reduces multi-precision multiplication of n × n matrices with d-bit entries from
O(n3 M(d)) to O(n3·d) bit operations by mapping the work to word-sized BLAS calls – the standard
approach used by IML [4] and other libraries for exact integer linear algebra.
An integer matrix A with entries of bitlength d is reduced modulo ℓcoprime word-sized primes,
producing ℓresidue matrices. The product A · B is computed as ℓindependent double-precision
matrix multiplications using OpenBLAS’s cblas_dgemm, and the integer result is reconstructed via
the Chinese Remainder Theorem.
Our specific choices:
• Exact double-precision accumulation. For the BLAS output to be exact, the accumu-
lated inner product must not exceed 253 −1. The largest safe modulus p for dimension n is
determined from n(p −1)2 + (p −1) < 253 −1. Primes are chosen consecutively below this
bound.
• Fast modular reduction. The inner-loop reduction r = a −⌊a/p⌋· p avoids the expensive
integer division instruction by using multiplication by a precomputed floating-point reciprocal
1/p.
• Fast RNS base conversion. Converting a matrix from one RNS basis to another (needed
during lifting) is done with a Lagrange-based shortcut that uses a floating-point correction
factor, bypassing the expensive CRT reconstruction step entirely.
• Precomputed RNS constants. The RNS basis stores precomputed Lagrange interpolants,
modular inverses, and the floating-point weights used by the base conversion above. These
are computed once and reused across all matrix operations.
3.2. Adaptive batch sizing
The theoretical algorithm extracts the invariant factors in O(log n) batches of geometrically
growing size (r0, 2r0, 4r0, . . .).
The implementation collapses this to only 3 or 4 iterations – a
strategy also adopted in [12], there with a fixed coarse schedule. Here, the size of each batch is
chosen adaptively based on how fast the working modulus s shrank in the previous iteration, and
once s drops below word size the final iteration absorbs all remaining invariant factors at once. Each
batch performs an integrality certification via p-adic lifting, whose initialization cost (computing
A−1 mod p) is comparable to the lifting work itself. Collapsing many small batches into 3 or 4 large
ones amortizes this fixed cost over much more work – a significant speedup in practice.

4. Experimental results
All experiments were conducted on an Apple M4 Max processor (ARM64) with 64 GB RAM,
running macOS 26.4. The implementation was compiled with Apple Clang using OpenBLAS (Home-
brew), GMP 6, and FLINT 3.
4.1. Test matrices
For each prime n, we construct the n × n matrix A with entries Aij = ij mod n for 0 ≤i, j < n.
This is a Vandermonde matrix with entries reduced modulo n, so log ∥A∥= O(log n). Primality of
n ensures A is nonsingular. Following Jäger and Wagner [8], we use this family of matrices because
its Smith form is highly nontrivial: A typically has more than n/2 nontrivial invariant factors,
and the largest is very large relative to n. For instance, at n = 1009 the largest invariant factor
has 4083 bits. For these matrices the theoretical cost reduces to O(nω B(log n) (log n)2), and since
OpenBLAS uses standard cubic matrix multiplication (ω = 3), this is O(n3 (log n)c) for a small
constant c.

4.4. Scaling analysis
To assess asymptotic behavior, we compare the Smith massager’s running time against the cost
of a single double-precision n × n matrix multiplication using an optimized BLAS (cblas_dgemm).
If the Smith massager cost scales as nω times slowly-growing factors, both curves should be parallel
on a log-log plot.

constant vertical gap. This confirms that the Smith massager cost is proportional to matrix multi-
plication cost, as predicted by the theory.

5. Conclusion
We have described a C implementation of the Las Vegas algorithm of [2] for computing the Smith
normal form via the Smith massager.
The implementation makes integer matrix multiplication
practical at scale through BLAS-accelerated RNS arithmetic, and uses adaptive batch sizing to
amortize the substantial fixed cost of each batch’s integrality certification.
Our experiments on matrices of dimension up to n = 10007 confirm the theoretical prediction:
the Smith massager’s running time scales proportionally to matrix multiplication cost, with both
exhibiting the same effective growth exponent on a log-log plot. Correctness is verified independently
against SymPy for small inputs, together with the unimodularity of the massaged matrix B certified
for each run.
The source code is available at https://github.com/SmithMassager/SmithMassagerC.
