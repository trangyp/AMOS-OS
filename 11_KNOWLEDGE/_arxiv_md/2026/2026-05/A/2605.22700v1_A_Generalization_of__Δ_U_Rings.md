A GENERALIZATION OF ∆U RINGS
PETER DANCHEV, OMID HASANZADEH, AHMAD MOUSSAVI,
AND MEHRDAD ESFANDIAR
Abstract. In this paper, we introduce and study a new class of rings calling
them weakly ∆U-rings, hereafter abbreviated as W∆U-rings for short. A ring
R is said to be W∆U if every unit of R can be expressed as ±1 + d for some
d ∈∆(R), where ∆(R) is the largest Jacobson radical of R that is closed under
multiplication by units.
Utilizing the known structure of ∆(R), we investigate the relationships between
W∆U rings and certain classical concepts such as ∆U-rings, UJ-rings, WUJ-
rings, as well as clean and exchange rings. Among the main results, we show that
a matrix ring Mn(R) is never W∆U for any n ≥2. We also provide complete
characterizations of local, semi-local, semi-simple and semi-regular rings that are
W∆U. Furthermore, it is shown for exchange rings that the W∆U property is
equivalent to being WUJ.
Furthermore, the behavior of W∆U-rings under various ring extensions, includ-
ing skew polynomial rings, skew power series rings, triangular matrix rings, trivial
extensions and group rings, is thoroughly examined. Several examples are given
to illustrate that the class of W∆U-rings properly contains the class of ∆U-rings.
Finally, necessary and sufficient conditions for a group ring RG to be W∆U are
established too.
Resuming all of the presented above, our results expanded those by Karaba¸cak
et al. published in J. Algebra & Appl. (2021).
1. Introduction and Basic Notions
Throughout this paper, R is always a ring with identity as it does not need to be
commutative. In our work, we will use the following pretty standard symbols:
• U(R): the set of units (= invertible elements) of R;
• Nil(R): the set of nilpotent elements of R;
• C(R): the center of R;
• Id(R): the set of idempotent elements of R;
• J(R): the Jacobson radical of R.
Likewise, Mn(R) stands for the ring of n × n matrices over R, and Tn(R) stands
for the ring of n × n upper triangular matrices over R. A ring is called abelian if
every its idempotent lies in the center, meaning that Id(R) ⊆C(R).
Now, let us recall some classical things that we will use explicitly henceforth: A
ring R is said to be Boolean if each its element is idempotent. A ring R is called
regular (that means von Neumann regular) if, for each a ∈R, there is some x ∈R

In another vein, mimicking [19], a ring R is exchange if, for every a ∈R, there is
an idempotent e2 = e ∈aR such that 1 −e ∈(1 −a)R. Besides, a ring R is clean
if every element is the sum of an idempotent and a unit. It is well known that any
clean ring is exchange, but the converse is not generally true. However, for abelian
rings, this holds always.
Additionally, a ring R is semi-regular if R/J(R) is regular and all idempotents
lift modulo J(R). So, semi-regular rings are exchange, but again the reverse is not
true in general.
On another track, a ring R is named a UU-ring if U(R) = 1 + Nil(R) (see [10]).
Later, Danchev individually defined in [7] the so-called weakly UU-rings (or, shortly,
just WUU-rings) via the condition U(R) = Nil(R)±1. He showed that an exchange
ring is WUU if and only if it is clean and WUU, if and only if it is strongly weakly
nil-clean, if and only if J(R) is nil and R/J(R) is isomorphic to a Boolean ring B,
or to Z3, or to B × Z3. He also proved that, for n ≥2, the matrix ring Mn(R) is
never a WUU-ring.
Since it is always fulfilled that ±1+J(R) ⊆U(R), it is natural to look at rings in
which an equality holds. In this way, a ring R for which U(R) = 1 + J(R) is called
a JU-ring (or simply a UJ-ring) (see, respectively, [6] and [12]). Later on, Danchev
generalized in [8] this notion to weakly JU-rings (or simply WJU-rings). He proved
that an exchange ring R is WJU if and only if it is a clean WJU-ring, if and only if
it is weakly semi-boolean, if and only if idempotents lift modulo J(R) and R/J(R)
is isomorphic to a Boolean ring B, or to Z3, or to B × Z3.
On the other side, imitating Chen [1], an element is called J-clean if it can be
written as an idempotent plus an element of the Jacobson radical, and a ring is
J-clean if every element is J-clean. For such a ring R this is equivalent to R/J(R)
being Boolean and idempotents lifting modulo J(R) (such rings are also known as
semi-boolean). Moreover, it was shown in [1] that R is J-clean if and only if R is a
clean UJ-ring.
The main working tool of this article is the set ∆(R). It appeared in an exercise
proposed by Lam [14, 15] and was later studied by Leroy and Matczuk in [16]. We
know that the subring ∆(R) is the largest Jacobson radical of R which is closed
under multiplication by units as well as that J(R) ⊆∆(R) and ∆(R) = J(T),
where T is the subring generated by the units of R. The equality ∆(R) = J(R) is
valid precisely when ∆(R) is an ideal of R.
In 2021, Karaba¸cak and his coauthors introduced in [11] a new family of rings
as a nontrivial generalization of UJ-rings. They called these ∆U-rings: A ring R
is a ∆U-ring provided that 1 + ∆(R) = U(R). They also defined ∆-clean rings
as those rings for which each element is the sum of an idempotent and an element
from ∆(R). Thereby, any ∆-clean ring is clean, but the reciprocal implication is
definitely untrue. They also showed that R is ∆-clean if, and only if, R is a clean
∆U-ring.
Motivated by all of this, as a natural extension of these ideas, we presently
introduce the concept of weakly ∆U-rings saying that a ring R is weakly ∆U (or
just a W∆U-ring for simpleness of the exposition) if every unit is either the sum or
the difference of an idempotent and an element from ∆(R). Equivalently, for each

2. Fundamental Properties of W∆U-Rings
Now, for our further purposes, let R be a ring and let α : R →R be a ring
homomorphism. The skew polynomial ring R[x; α] consists of all polynomials in x
with coefficients from R and with multiplication rule xr = α(r)x for all r ∈R. If
α = 1R, we then just get the usual polynomial ring R[x].
Similarly, the skew formal power series ring R[[x; α]] consists of all formal power
series P∞

Finally, a ring R is called weakly 2-primal provided that Nil(R) = L(R), where
L(R) is the Levitzki radical. For example, any commutative ring or reduced ring is
ever weakly 2-primal.
We begin our more concrete considerations with the following technicalities.
Proposition 2.1. A ring R is local if, and only if, R = U(R) ∪∆(R).
Proof. If R is local, then
R = U(R) ∪J(R) ⊆U(R) ∪∆(R) ⊆R,
and thus R = U(R) ∪∆(R).
Conversely, suppose R = U(R) ∪∆(R) and a /∈U(R). Then, a ∈∆(R), and so
1 −a ∈U(R), whence R is a local ring.
□
For a ring R, we say that the set Id(R) (respectively, U(R) and ∆(R)) is trivial
whenever Id(R) = {0, 1} (respectively, U(R) = {1} and ∆(R) = {0}).
Recall also that a ring R is said to be Dedekind-finite if ab = 1 amounts to ba = 1
for any a, b ∈R. In other words, all one-sided inverses in such a ring are necessarily
two-sided.
