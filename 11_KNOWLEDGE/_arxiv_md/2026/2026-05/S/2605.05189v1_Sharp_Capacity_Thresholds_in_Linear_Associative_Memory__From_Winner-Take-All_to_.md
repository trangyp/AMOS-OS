Abstract
How many key-value associations can a d × d linear memory store? We show that
the answer depends not only on the d2 degrees of freedom in the memory matrix,
but also on the retrieval criterion.
In an isotropic Gaussian model for the stored
pairs, we show that top-1 retrieval, where every signal must beat its largest distractor,
requires the logarithmic model-size scale d2 ≍n log n. We prove that the correlation
matrix memory construction, which stores associations by superposing key-target outer
products, achieves this scale through a sharp phase transition, and that the same scaling
is necessary for any linear memory. Thus the logarithm is the intrinsic extreme-value
price of winner-take-all decoding.
We next consider listwise retrieval, where the correct target need not be the unique
top-scoring item but should remain among the strongest candidates. To formalize this
regime, we propose the Tail-Average Margin (TAM), a convex upper-tail criterion that
certifies inclusion of the correct target in a controlled candidate list. Under this listwise
retrieval criterion, the capacity follows the quadratic scale d2 ≍n. At load n/d2 →α,
we develop an exact asymptotic theory for the TAM empirical-risk minimizer through
a two-parameter scalar variational principle. The theory has a rich phenomenology:
in the ridgeless limit it yields a closed-form critical load separating satisfiable and
unsatisfiable phases, and it predicts the limiting laws of true scores, competitor scores,
margins, and percentile profiles. Finally, a small-tail extrapolation further leads to the
conjectural sharp top-1 threshold d2 ∼2n log n.

Introduction
Associative memory refers broadly to the ability of a system to store and retrieve relation-
ships between objects. Given a collection of input-output pairs, one would like the system to
recover the correct target when presented with a corresponding cue. This basic mechanism
appears in many forms, ranging from the first neural network models for pattern learning
[Kohonen, 1972, Amari, 1972, Anderson, 1972, Hopfield, 1982, 1984], to modern key-value
retrieval systems [Vaswani et al., 2017, Ramsauer et al., 2021, Gershman et al., 2025]. As-
sociative memory has also recently attracted attention as a model of factual recall in large
language models [Cabannes et al., 2024a,b, Jiang et al., 2024, Nichani et al., 2024] as trained
transformer layers have been observed to function as key-value memories [Geva et al., 2021,
Meng et al., 2022, Bietti et al., 2023].
A central theoretical question in associative memory is: given n associations, how large
must the memory model be in order to retrieve them under a prescribed criterion?
In
this paper, we study this question in the simple but already nontrivial setting of linear
associative memory.

information retrieval, which optimize criteria defined on ranked candidate lists rather than
on a single pairwise comparison [Cao et al., 2007].

1.2
Related Work
Neural associative memory.
Associative memory dates back to early neural models that
store patterns through correlations in the weights [Amari, 1972, Anderson, 1972, Nakano,
1972, Kohonen, 1972, Hopfield, 1982, 1984]. The Hopfield network [Hopfield, 1982] is the
symmetric case, where the goal is to memorize and retrieve the patterns themselves. We
focus instead on associative recall: a key should retrieve its paired target, and the two need
not coincide [Amari, 1972]. In particular, Kohonen [1972] define correlation matrix memory
as a sum of rank-one key-target outer products, the construction analyzed in Section 2.1.
Bidirectional associative memory is another paired-pattern model based on outer-product
updates [Kosko, 1988].
Modern versions of neural networks with built-in associative memory capabilities include
the neural Turing machine [Graves et al., 2014], memory networks [Weston et al., 2015],
dense associative memory [Krotov and Hopfield, 2016, Lucibello and M´ezard, 2024], MCHN
[Ramsauer et al., 2021], MCSDM [Kanerva, 1988, Bricken and Pehlevan, 2021], and universal
6


## Page 7


Hopfield networks [Millidge et al., 2022]. Binary variants of matrix memory have also been
studied in the literature [Willshaw et al., 1969, Gardner, 1987, Hobson, 2011].
Transformers and factual recall.
Transformer models trained on factual recall tasks
have been empirically observed to implement associative memory through their weight ma-
trices. Feedforward as well as attention layers have been shown to behave like key-value
memories [Geva et al., 2021, Bietti et al., 2023], and linear-memory viewpoints have been
used to study factual editing, induction head tasks, and latent space retrieval [Meng et al.,
2022, Bietti et al., 2023, Jiang et al., 2024]. On the theory side, Nichani et al. [2024] study
a sequence-based factual recall task where one token functions as the key, and show that a
one-layer transformer solves the task with capacity scaling linearly with parameter count,
up to logarithmic factors. This storage scaling has also been empirically observed in large
language models [Allen-Zhu and Li, 2024]. Related theoretical analyses include optimization
dynamics for a single-layer transformer on a token recall task [Vural et al., 2026], and a
measure-theoretic formulation of transformers with implicit associative memory mechanisms
[Kawata and Suzuki, 2026].
Storage capacity.
Nichani et al. [2024] study the capacity of linear and MLP associative
memories with random spherical embeddings, showing in particular that correlation matrix
memory succeeds when d2 ≳n(log n)4. Cabannes et al. [2024a] propose the exact retrieval
criterion and study correlation matrix memory under a weighted data distribution. From an
optimization perspective, Cabannes et al. [2024b] study gradient descent under a multiclass
logistic formulation, and Kim et al. [2026] compare the capacity of memory matrices obtained
by different optimizers under Gaussian embeddings. Compared with these works, our top-
1 result identifies the exact statistical logarithmic barrier d2 ≍n log n for arbitrary linear
memories. We also introduce the TAM criterion and, to our knowledge, give the first capacity
theory for linear associative memory under a listwise retrieval rule.
We also briefly mention that storage capacity has been studied in detail for the Hopfield
network and its variants. The capacity d ≍n of Hopfield networks is classical, see e.g.,
McEliece et al. [1987], Folli et al. [2017] and the works cited within, while modern exten-
sions such as dense associative memory have been shown to achieve exponential capacity
[Demircigil et al., 2017, Ramsauer et al., 2021, Lucibello and M´ezard, 2024]. The scaling in
these works differ from our results since we decode to a fixed vocabulary of size n, while the
classical Hopfield formulation decodes to the hypercube.

retrieval inequalities in (1). Based on numerical evidence comparing training and test errors,
and score distributions, they conjecture that the original and decoupled problems have the
same critical capacity. For the decoupled model, they carry out a Gardner-type statistical

Classification and leave-one-out methods.
The TAM learning problem is also con-
nected to high-dimensional classification through its logistic loss. The classical work of Cover
[1965] computed the separability capacity of random patterns, and the perceptron capacity
was later studied through statistical physics methods, including margin-constrained variants
[Gardner, 1988]. In ordinary unregularized logistic regression, the existence of the maxi-
mum likelihood estimator is equivalent to nonseparability of the labeled data; equivalently,
the failure of existence is a linear separability, or capacity, event. Sur and Cand`es [2019]
established a high-dimensional phase transition for this event under Gaussian covariates. A
broader line of work in statistical physics studies optimal errors and phase transitions in
high-dimensional generalized linear models via the approximate message passing algorithm
[Barbier et al., 2019, Aubin et al., 2020, Mignacco et al., 2020]. From a technical point of
view, our TAM analysis uses a leave-one-out approach, which has played an important role
in precise asymptotics for high-dimensional M-estimators [El Karoui et al., 2013, El Karoui,
2018, Lei et al., 2018]. At a conceptual level, this is also the cavity method from spin glass
theory [M´ezard et al., 1987].
The present problem differs from standard high-dimensional regression and classification
in several ways. The unknown is a matrix rather than a vector; the effective covariates
are rank-one tensors ujv⊤
i with strong dependencies; each sample contributes both a signal
score and a full column of competitor scores; and the TAM threshold is endogenous, selected
by the learned scores themselves. These couplings prevent existing leave-one-out theories
from applying as black boxes; the resulting cavity calculation is matrix-valued, listwise, and
self-consistent in a way that does not arise in standard high-dimensional regression.

3
Listwise retrieval and the Tail-Average Margin
Top-1 retrieval is a winner-take-all criterion: each query must identify a unique target in
a single step. This is natural for final decoding, but many memory modules are used as
intermediate stages. They surface a set of plausible associations, or form a mixture of high-
scoring memories, which later computation can refine. In this setting, successful retrieval
need not mean that the correct target is already ranked first. It is enough that the correct
association remains salient among the strongest competitors. This leads to a listwise notion
of retrieval, which is the focus of this section.
A direct listwise requirement would ask the signal score to beat a high competitor quantile,
thereby ensuring that the correct target belongs to a controlled candidate set. This rank
condition is natural, but it is non-convex and combinatorial. We therefore use a convex
certificate: we ask the signal score to beat the average of the strongest competitors. We call
the resulting functional the Tail-Average Margin (TAM). TAM is a listwise retrieval criterion
in its own right: it controls the mass of strong distractors rather than only the single largest
one, while retaining enough convex structure for optimization and asymptotic analysis.
In this section we define the TAM functional, record its basic properties, and formulate
the corresponding learning problem and performance criteria for linear associative memory.
In the next section, we derive an asymptotic theory of TAM learning in the quadratic regime
d2 ≍n, with a fixed tail fraction k/(n −1) →r ∈(0, 1).

6
Conclusion
We have shown that the capacity of linear associative memory is governed not only by the
number of degrees of freedom in the memory matrix, but also by the retrieval statistic used
to read it out. For exact top-1 retrieval, the relevant statistic is the largest distractor. This
extreme-value requirement forces the logarithmic model-size scale
d2 ≍n log n.
The correlation matrix memory achieves this scale, and our universal impossibility theorem
shows that the logarithmic factor cannot be removed by choosing a more sophisticated linear
memory. It is therefore not an artifact of the specific construction of correlation matrix
memory, but the intrinsic price of winner-take-all decoding.
The picture changes for listwise retrieval. We propose the Tail-Average Margin criterion,
which replaces the maximum competitor by the average strength of a fixed upper tail. This
still certifies that the correct association remains in a controlled candidate list, but it avoids
making success depend on a single extreme distractor. At fixed tail fraction, the resulting
theory operates at the quadratic scale
d2 ≍n,
the scale suggested by the number of parameters. Conditional on six precise postulates stated
in Section 4, we show that the TAM optimizer admits a scalar variational description that
predicts the limiting loss, score laws, margin distribution, percentile profile, and ridgeless
phase transition. This scalar theory reveals a rich phenomenology: a satisfiable/unsatisfiable
44


## Page 45


transition, explicit limiting score profiles, and percentile laws for where the true association
sits among its competitors. Proving the six postulates would turn this conditional prediction
into a fully rigorous capacity theory for listwise associative memory.
The fixed-tail theory also points back toward exact retrieval. Formally sending the tail
fraction r to the extreme value 1/(n −1) gives a tantalizing small-tail conjecture: the sharp
top-1 threshold should be
d2 ∼2n log n,
consistent with the concurrent prediction of Giorlandino et al. [2026], based on a simplified
decoupled model, and with the finite-dimensional simulations in Section 5.
Making this
prediction rigorous requires understanding a singular extreme-tail limit, where the fixed-tail
asymptotics and the top-1 extreme-value regime meet.
