SYMMETRIC 2-COCYCLES WITH VALUES IN C×
MOHAMAD MAASSARANI
Abstract. For many finite groups a symmetric 2-cocycle α (α(g, h) = α(h, g), for all pairs
(h, g) of the group) with values in C× is a coboundary. We show using a theoretic arguement
and GAP that there is a group of order 64 having a symmetric 2-cocycle with a non trivial
cohomology class.
1. Introduction and main result
We consider 2-cocycles over finite groups with values in C×. We will say that such cocycle
α is symmetric if α(g, h) = α(h, g) for all pairs of elements (g, h) of the group. It is know
that a symmetric 2-cocycles with values in C× of an abelian group is a coboundary. For G a
finite group, the subgroup H2
S(G, C×) of the Schur multiplier H2(G, C×) consisting of classes
of symmetric cocycles can be identified with a subgroup of the Bogomolov multiplier B0(G)
([MMb26]). In particular for a finite group with trivial Bogomolov multiplier all symmet-
ric 2-cocycles with values in C× are coboundaries. According to [Ku10], all simple groups
has trivial Bogomolov multiplier and hence trivial H2
S(G, C×). It is knonw that groups of
order strictely less then 64 have trivial Bogolomov Multiplier. The group H2
S(G, C×) is also
trivial for G a Schur cover (see for instance [MMa26],[MMb26]). In [LE24], ¯C-groups are
defined as groups defined by generators and relations and where the only relations are re-
lations of the form aba−1 = c and dk = 1 for a, b, c, d generators. It is shown that for a
¯C-group G there is an injective map between the enveloping group A(G) of the conjugacy
quandle of G and G × ZcG where cG is the number of conjugacy classe of G. In [MMb26],
we prove that for a finite group this map is injective if and only if H2
S(G, C×) = 0. This
implies that for a finite ¯C-group all symmetric 2-cocycles with values in C× are coboundaries.
In [MMb26], we proved that for G finite H2
S(G, C×) is zero if and only if the derived group
of G and the derived group of the enveloping group A(G) of the conjugacy quandle of G
are isomorphic. We show that for G corresponding to the group SmallGroup(64, 149) of
order 64 of GAP, the derived group of A(G) has more elements then the derived group of G,
proving that H2
S(G, C×) is non trivial and hence that SmallGroup(64, 149) posses a sym-
metric 2-cocycle with values in C× with a non trivial cohomology class (not a coboundary).
To establish the result we use GAP 4.15.1. The code executes in seconds on a standard
Hardware. For instance, the existence of such cocycle proves that the conujugacy quandle
of SmallGroup(64, 149) posses an irreducible quandle representation that can’t be obtained
as product of a quandle character and a linear representation of the group [MMb26].
Key words and phrases. 2-cocycles, groups, GAP.

2. Existence of the 2-cocyle
Let G be a group. The enveloping group of the conjugacy quandle of G is the group :
A(G) = ⟨eg, g ∈G|egehe−1
g
= eghg−1 for g, h ∈G⟩.
As in the introduction, we will denote H2
S(G, C×) the subgroup of the Schur multiplier
H2(G, C×) consisting of classes of symmetric cocycles. The following is a part of proposition
3.4 of [MMb26] :
Proposition 2.1. For G finite the derived subgroup of A(G) is isomorphic to the derived
subgroup of G if and only if H2
S(G, C×) = 0.
From now on, G is the group corresponding to SmallGroup(64, 149) of GAP.
Proposition 2.2. The derived group of G has order 8.
Proof. We use the code :
G := SmallGroup(64,149);
dG:=DerivedSubgroup(G);
a:=Size(dG);
GAP returns 8 for the value of a.
□
We implement the group A(G) in GAP by adding to the code in the previous proposition
the lines :
elms := Elements(G);
r := Length(elms);
F := FreeGroup(r);
gens := GeneratorsOfGroup(F);
rels := [ ];
for i in [1..r] do
for j in [1..r] do
h := elms[j];
po:=elms[i]*elms[j]*elms[i] b-1 ;
k := Position(elms, po);
Add(rels, gens[i] * gens[j] * gens[i]b-1*gens[k]b-1);
od;
od;
H := F / rels;
Hence the group A(G) correspond to the group H in the code.

Proof. We find using the following code lines :
