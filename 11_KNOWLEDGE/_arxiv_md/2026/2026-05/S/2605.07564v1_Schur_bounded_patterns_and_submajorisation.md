SCHUR BOUNDED PATTERNS AND SUBMAJORISATION
E. MCDONALD, F. SUKOCHEV, AND D. ZANIN
Abstract. We characterise the Schur bounded patterns of ideals of compact operators that
are not closed under submajorisation, in particular the Schatten ideals Cp with 0 < p < 1.
Conversely we characterise the ideals that are not closed under submajorisation by their Schur
bounded patterns.
1. Introduction
Let m ∈ℓ∞(N2) be a bounded matrix. The corresponding Schur multiplier Tm is the linear
map on matrices given by
Tm{Aj,k}j,k≥0 = {m(j, k)Aj,k}j,k≥0.
We say that Tm is a bounded Schur multiplier (or just a Schur multiplier) if there exists a constant
Cm such that
∥{m(j, k)Aj,k}j,k≥0∥∞≤Cm∥{Aj,k}j,k≥0∥∞
for any finitely supported matrix A, where ∥· ∥∞is the operator norm on the algebra B(ℓ2(N))
of all bounded linear operators on ℓ2(N). A subset S of N2 is called a Schur bounded pattern if
every bounded function m on N2 supported on S is a bounded Schur multiplier. In this article,
we shall consider Schur multipliers on (quasi)-normed ideals of compact operators in on B(ℓ2(N))
[17, 7, 8, 19, 12, 6]. A linear subspace (E, ∥· ∥E) of bounded operators is a (two-sided) ideal if
ABC ∈E whenever A, C ∈B(ℓ2(N)) and B ∈I. The ideal E equipped with a (quasi-)norm ∥·∥E)
is a (quasi-)normed ideal (E, ∥· ∥E) if ∥ABC∥E ≤∥A∥∞∥B∥E∥C∥∞whenever A, C ∈B(ℓ2(N))
and B ∈E.
Definition 1.1. Let (E, ∥· ∥E) be a quasi-normed ideal of B(ℓ2(N)). We say that m ∈ℓ∞(N2) is
a bounded Schur multiplier of E if there exists Cm such that
∥Tm(A)∥E ≤Cm∥A∥E
for any finitely supported matrix A.
A set S ⊂N2 is called a Schur E-bounded pattern if any m ∈ℓ∞(N2) supported on S is a
bounded Schur multiplier of E.
Remark 1.2. If Tm has the property that Tm(E) ⊆E, then Tm is a bounded operator on E. This
is because if ∥An −A∥E →0 then An weakly converges to A. Since Tm is weakly continuous, if
Tm(An) has a limit then it must converge to Tm(A). Therefore Tm is closed and hence bounded.
A question concerning the description of Schur bounded patterns were suggested in [14] and
was fully resolved by Davidson and Donsig [4]. A Schur bounded pattern must decompose into
two sets, one with a bound on the number of entries in each row, and the other with a bound on
the number of entries in each column. By duality, this result from [4] immediately extends to the
complete description of Schur C1-bounded patterns, where C1 is the trace class [19].
By standard interpolation theory, we infer that every Schur C1-bounded pattern is also a Schur
E-bounded pattern for any quasi-Banach ideal (E, ∥·∥E), provided that the latter is an interpolation
space for the Banach pair (C1, B(ℓ2(N))). We explain about this subclass of quasi-Banach ideals
in a little more detailed fashion.
The Schur C2-bounded patterns consist of arbitrary subsets of N2, while for 1 < p ̸= 2 < ∞,
the characterisation of Schur Cp-bounded patterns is an open problem. We were motivated to

2. Statement of Main Result
Some immediate consequences of the definition of a Schur E-bounded pattern are as follows:
Lemma 2.1. Let (E, ∥· ∥E) be a quasi-normed ideal.
(i) S is a Schur E-bounded pattern, and S′ ⊂S, then S′ is a Schur E-bounded pattern.
(ii) If S, S′ are Schur E-bounded patterns, then S ∪S′ is a Schur E-bounded pattern.
(iii) Let a, b : N →N. If S is a Schur-bounded pattern, then so is {(a(n), b(m)) (n, m) ∈S}.
(iv) For any finite set F, F × N and N × F are Schur E-bounded patterns.
Proof. Parts (i) and (ii) are obvious consequences of linearity. To prove (iii), let Ua(en) = ea(n)
and Ub(en) = eb(n). Then Ua and Ub are partial isometries, and

To prove (iv), observe that if m is supported in F × N, then {m(j, k)Aj,k}j,k≥0 has rank at most
|F|, and hence belongs to any ideal of B(ℓ2(N)).

3. Ideals closed under submajorisation
Recall that we say that an ideal E of operators is closed under submajorisation if A ∈B(H), B ∈
E satisfy A ≺≺B then A ∈E.
By contrast, a quasi-Banach ideal (E, ∥· ∥E) is called fully symmetric if E is closed under
submajorisation and A ≺≺B implies ∥A∥E ≤∥B∥E [5].

5. Existence of nontrivial Schur bounded patterns
We are now prepared to prove our main result.
Proof of Theorem 2.3. If E is closed under submajorisation, then by Theorem 4.1, the diagonal is
a Schur E-bounded pattern, but the diagonal is not a subset of a set of the form F × N ∪N × F
for finite F. This shows that (i) implies (ii).
Conversely, suppose that there exists a Schur E-bounded pattern S such that
S ∩({n, n + 1, n + 2, . . .} × {n, n + 1, n + 2, . . .}) ̸= ∅
for infinitely many n. If follows that there exist increasing sequences {nk}k≥0 and {mk}k≥0 such
that {(nk, mk) : k ≥0} ⊂S. By Lemma 2.1.(i) and (iii), it follows that ∆is a Schur E-bounded
pattern.
The fact that (ii) is equivalent to (v) is precisely Theorem 4.1.
Obviously, (i) implies (iv) and (iii). Since any non-empty Toeplitz pattern contains an infinite
diagonal, we also have the equivalence (iii)↔(ii).
Nikolskaya-Farforovskaya [14, Lemma 3.6] proved that there exist infinite Hankel Schur B(H)-
bounded patterns, which by duality must also be Schur C1-bounded patterns. Hence If E is fully
symmetric, then there exists an infinite Hankel Schur E-bounded pattern, and this shows that (iv)
implies (v), which completes the proof.
□
