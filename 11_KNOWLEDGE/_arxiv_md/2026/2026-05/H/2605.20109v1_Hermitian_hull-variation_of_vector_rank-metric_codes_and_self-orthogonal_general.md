Abstract
We study the Hermitian hull-variation problem for vector rank-metric codes.
Except for one parameter pair, we show that the Hermitian hull dimension of such
a code can be reduced to any smaller value within its equivalence class, and in par-
ticular every such code is equivalent to a Hermitian LCD code. We then address
the existence of maximum rank distance (MRD) codes with prescribed Hermitian
hull dimension. To this end, we introduce the notion of a scaled trace-self-dual basis
of a finite field extension, which exists in all cases, and use it to construct Hermi-
tian self-orthogonal generalized Gabidulin codes for every prime power. Combined
with the hull-variation theorem, this yields MRD codes attaining every admissible
Hermitian hull dimension.
Keywords: Vector rank-metric codes, Hermitian hull, hull-variation, Gabidulin codes,
generalized Gabidulin codes, Hermitian self-orthogonal codes, MRD codes, scaled trace-
self-dual basis.

Introduction
Let C be a linear code over a finite field, equipped with either the Euclidean or the
Hermitian inner product on its ambient space. The hull of C is the intersection
H(C) := C ∩C⊥,
where C⊥denotes the dual of C with respect to the chosen inner product. The hull
is a fundamental subcode of C, and its dimension governs several constructions. Codes
with trivial hull, called linear complementary dual (LCD) codes, were used by Carlet and

Guilley [3] as countermeasures against side-channel attacks. In 2018, Guenda, Jitman,
and Gulliver [13] showed that the hull dimension of C equals the number of maximally
entangled pairs required to construct an entanglement-assisted quantum error-correcting
code (EAQECC) from C, in the framework introduced by Brun, Devetak, and Hsieh [2].
Understanding the behavior of the hull dimension under code equivalence is thus a natural
and well-motivated problem.
In [4], Carlet, Mesnager, Tang, Qi, and Pellikaan proved that every [n, k] linear code over
Fq is equivalent to a Euclidean LCD code provided q > 3, and that every [n, k] linear code
over Fq2 is equivalent to a Hermitian LCD code provided q > 2. The latter result was
sharpened in [5, 21]. There it was shown that for every linear code C over Fq2 (q > 2)
with Hermitian hull dimension h and every ℓ∈{0, 1, . . . , h}, there exists a code equivalent
to C with Hermitian hull dimension exactly ℓ. This phenomenon leads to the so-called
hull-variation problem formulated by Hao Chen in 2023, see [6]. The problem is stated as
follows.
Hull-Variation Problem: When a linear code C is transformed to an equivalent linear
code C′, how is its Euclidean or Hermitian hull changed?
In parallel with these developments in the Hamming metric, the rank metric, introduced
by Delsarte [9] and Gabidulin [10], has emerged as a robust framework with applications
in network coding [18, 28] and, more recently, in quantum error correction. Delfosse and
Z´emor [8] propose quantum Gabidulin codes via a CSS-type construction to correct cir-
cuit faults in a stacked quantum memory, requiring a self-dual normal basis of F2n/F2 and
thereby restricting the memory to n × n with n odd. Nizuka and Matsumoto [25] subse-
quently give an alternative construction over F22m/F2 that uses Hermitian self-orthogonal
Gabidulin codes in the framework of Matsumoto and Uyematsu [22]. This removes the
odd-length restriction and improves the relative rank distance.
The Hermitian inner
product on vector rank-metric codes is thus a natural object of study in this setting, and
motivates an analogue of the hull-variation problem for vector rank-metric codes.
In [14], the author and Johnsen investigated the Euclidean hull-variation problem for
vector rank-metric codes. The present paper first addresses the analogous Hermitian hull-
variation problem. We show that, outside the single case (q, n) = (2, 2), every Hermitian
hull dimension up to dim H(C) is attained within the equivalence class of C. In particular,
every such code is equivalent to a Hermitian LCD code.
Among rank-metric codes, those attaining the Singleton-like bound on minimum rank
distance are called maximum rank distance (MRD) codes, and play the role of MDS
codes in the rank metric. The second part of the paper addresses the existence of MRD
codes with prescribed Hermitian hull dimension. Islam and Horlemann [15] studied the
Galois hull dimensions of Gabidulin codes and, in particular, constructed Hermitian
self-orthogonal Gabidulin codes whenever a trace-self-dual Fq-basis of Fq2m exists. By
Seroussi–Lempel [27] and Jungnickel–Menezes–Vanstone [17], such a basis exists if and

In Section 2 we recall the necessary background.
Section 3 establishes the Hermitian hull-variation theorem and identifies the obstruction

2.3
Scaled trace-self-dual basis
The trace bilinear form B1(x, y) := TrK/Fq(xy) is a nondegenerate symmetric Fq-bilinear
form on K, viewed as an Fq-vector space of dimension 2m. An Fq-basis α = (α1, . . . , α2m)
of K is (trace-)self-dual (with respect to B1) if TrK/Fq(αiαj) = δij for all i, j. By [27, 17],
a self-dual basis of Fqr/Fq exists if and only if q is even or both q and r are odd. In our
setting r = 2m is even, so no self-dual basis exists when q is odd, which motivates the
scaled variant that we introduce next.
For any λ ∈K∗, the scaled trace bilinear form is
Bλ(x, y) := TrK/Fq(λxy).
Equivalently, Bλ(x, y) = B1(µλ(x), y), where µλ : K →K, x 7→λx. Since µλ is an Fq-
linear automorphism of K and B1 is nondegenerate, Bλ is also a nondegenerate symmetric
bilinear form.
Definition 2.4. A scaled trace-self-dual basis of K/Fq is a pair (α, λ), where α =
(α1, . . . , α2m) is an Fq-basis of K and λ ∈K∗, such that
TrK/Fq(λαiαj) = δij
for all 1 ≤i, j ≤2m.
When λ = 1, the basis α is an ordinary self-dual basis.

trace-self-dual basis of K = Fq2m over Fq.
