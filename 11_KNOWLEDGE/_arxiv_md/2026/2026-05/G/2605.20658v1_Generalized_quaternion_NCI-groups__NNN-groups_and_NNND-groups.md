GENERALIZED QUATERNION NCI-GROUPS, NNN-GROUPS AND
NNND-GROUPS
JUN-FENG YANG, JIA-LI DU∗, YAN-QUAN FENG, AND YOUNG SOO KWON
Abstract. A Cayley (di)graph Cay(G, S) of a finite group G is called CI if, for every Cayley
(di)graph Cay(G, T) of G, Cay(G, S) ∼= Cay(G, T) implies that Sσ = T for some σ ∈Aut(G). The
group G is called an NDCI-group (resp. NCI-group) if every normal Cayley digraph (resp. graph)
of G is CI. It was shown that the generalized quaternion group Q4n of order 4n (n ≥2) is an
NDCI-group if and only if either n = 2 or n is odd, but its NCI-group classification has been left
as an open question. In this paper, we solve the question and prove that Q4n is an NCI-group for
every n ≥2. A normal Cayley (di)graph of a group G is called NNN if its automorphism group
contains a non-normal regular subgroup isomorphic to G, and G is called an NNND-group (resp.
NNN-group) if it admits an NNN Cayley digraph (resp. graph). In this paper, we show that Q4n
is not an NNN-group for every n ≥2, and is an NNND-group if and only if n ≥6 and n is even.
Key words: CI-digraph, NCI-group, NNN-group, NNND-group, generalized quaternion group.
2020 Mathematics Subject Classification: 20B25, 05C25.
1. Introduction
Let Γ be a digraph. Denote by V (Γ) and A(Γ) the vertex set and arc set of Γ respectively, and
by Aut(Γ) the automorphism group of Γ. If Γ is a graph, V (Γ) and E(Γ) are the vertex set and
edge set of Γ, respectively. In this paper, we view a graph Γ as a digraph with the same vertex set
V (Γ) and arc set {(u, v) | {u, v} ∈E(Γ)}, and this causes no ambiguity.
Let G be a group and let S be a subset of G with the identity of G not in S. The Cayley digraph
Cay(G, S) of G with respect to S is defined to have vertex set G and arc set {(g, sg) | g ∈G, s ∈S},
while Cay(G, S) is called a Cayley graph when S = S−1. Clearly, Γ is connected if and only if
⟨S⟩= G, that is, S generates G.
For g ∈G, the right multiplication map R(g) : x 7→xg,
x ∈G, is an automorphism of Cay(G, S).
Write R(G) = {R(g) | g ∈G}.
Then R(G) is a
regular subgroup of Aut(Γ).
It was shown that a digraph is isomorphic to a Cayley digraph
of a group G if and only if its automorphism group contains a regular subgroup isomorphic to
G; see [9].
A basic relation between R(G) and Aut(Cay(G, S)) was given by Godsil [16] and
he proved that the normalizer of R(G) in Aut(Cay(G, S)) is precisely R(G) ⋊Aut(G, S), where
Aut(G, S) = {α ∈Aut(G) | Sα = S}. A Cayley digraph Cay(G, S) of G is called normal if R(G)
is a normal subgroup in Aut(Cay(G, S)); see Xu [43]. The above Godsil’s result implies that if
Aut(Cay(G, S)) is normal, then Aut(Cay(G, S)) = R(G) ⋊Aut(G, S).
A classical problem in algebraic graph theory is the Cayley isomorphism (CI) problem.

In recent years, CI have been considered for normal Cayley digraphs. Note that Li [21] provided
examples of normal Cayley digraphs that are not CI, and proposed the following question: Char-
acterize normal Cayley digraphs which are not CI-digraphs. More recently, Ryabov [32] studied
the CI-property of normal Cayley digraphs over abelian groups, and reduced the abelian case to
abelian p-groups. A group G is called an NDCI-group if every normal Cayley digraph of G is a
CI-digraph, and an NCI-group if every normal Cayley graph of G is a CI-graph. Note that every
DCI-group is an NDCI-group, and every CI-group is an NCI-group, but the converses are not true.
Xie, Feng, Ryabov and Liu [37] proved that a cyclic group of order n is NDCI if and only if 8 ∤n,
and is NCI if and only if either n = 8 or 8 ∤n. For dihedral groups, Xie, Feng and Zhou [39]
proved that a dihedral group of order 2n is NDCI or NCI if and only if n = 2, 4, or n is odd. In
2022, Xie, Feng and Kwon [38] proved that a generalized quaternion group of order 4n is NDCI if
and only if either n = 2 or n is odd, but left the NCI case as an open question. In this paper, we
solve this problem; see Theorem 1.1.
A Cayley digraph Γ = Cay(G, S) is called NNN when Γ is normal and Aut(Γ) has a non-normal
regular subgroup isomorphic to G. A group G is called an NNND-group or NNN-group if there
exists an NNN Cayley digraph or graph of G, respectively. Since a graph is viewed as a digraph,
every NNN-group is an NNND-group, but the converse is not true.
The first NNN-graph was constructed by Royle [31] in 2008, which is a normal Cayley graph of
Z6
2. In 2010, Giudici and Smith [14] built another NNN-graph, a strongly regular Cayley graph of
Z2
6. In 2011, Bamberg and Giudici [5] found the first infinite family of NNN-graphs as point graphs
of a certain family of generalized quadrangles. Moreover, Xu [41] gave further infinite families of
NNN-graphs using Cartesian product, direct product, and strong product in 2017.
In 2018, Xu [42] proved that every elementary abelian 2-group Zd
2 with d ≥6 is an NNN-group,
and that every non-abelian simple group is not an NNND-group. In 2022, Xu [40] proved that the
symmetric group Sn of degree n is an NNN-group if and only if n ≥5. In 2019, Giudici, Morgan,
and Xu [15] showed that every cyclic group is not an NNN-group. Using a different method from
[15], Yang et al. [44] also proved that there is no cyclic NNN-group and NNND-group, and further
proved that a dihedral group D2n of order 2n is an NNN-group or NNND-group if and only if
n ≥6 is even and n ̸= 8. In this paper, we classify generalized quaternion NNN-groups and
NNND-groups. As a result, we find infinitely many generalized quaternion NNND-groups but not
NNN-groups, and to the best of our knowledge, this is the first discovery of an infinite family of
groups with such property.

Let n ≥2 and let Q4n be the generalized quaternion group of order 4n. Our first result in this

Theorem 1.1. Every generalized quaternion group Q4n (n ≥2) is an NCI-group.
By Babai [4], a Cayley digraph Γ = Cay(G, S) of a group G is CI if and only if all regular
subgroups of Aut(Γ) isomorphic to G are conjugate. From this we know that if Γ is a normal
Cayley digraph of G, then Γ is CI if and only if R(G) is the unique regular subgroup of Aut(Γ)
isomorphic to G. This implies that every NDCI-group is not an NNND-group and every NCI-group
is not an NNN-group. Thus, we have the following corollary.
Corollary 1.2. Every generalized quaternion group Q4n (n ≥2) is not an NNN-group.
For generalized quaternion NNND-group, we have the following result.
Theorem 1.3. A generalized quaternion group Q4n (n ≥2) is an NNND-group if and only if
n ≥6 and n is even.

2. Preliminaries

criterion for Γ to be a normal Cayley digraph.
Proposition 2.1. ([43, Proposition 1.5]) Let Γ = Cay(G, S) be a Cayley digraph of a group G
with respect to S. Then Γ is normal if and only if Aut(Γ) = R(G) ⋊Aut(G, S), and if and only if
Aut(Γ)1 = Aut(G, S).
The following is a classification of generalized quaternion NDCI-groups.
Proposition 2.2. ([38, Theorem 1.1]) Let n ≥2 be a positive integer and let Q4n be the generalized
quaternion group of order 4n. Then Q4n is an NDCI-group if and only if either n = 2 or n is odd.
