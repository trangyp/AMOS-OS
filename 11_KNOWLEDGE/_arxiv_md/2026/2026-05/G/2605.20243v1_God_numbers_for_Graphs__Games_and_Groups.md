GOD NUMBERS FOR GRAPHS, GAMES AND GROUPS
Z. ADAMS, M.Z. CASSIM, C. HOU, O. KNILL, V. SECO ROOPNARAINE, M.H. SALEEM
Abstract. We describe and axiomatize finite solitaire puzzles and zero sum sequential games
graph theoretically. Zermelo’s theorem telling that there is a win for one of the players or a draw
follows from the definitions. The god number is a geometric quantity that quantifies the number of
moves necessary to solve the puzzle. In the solitaire case, the god number is the minimal distance
from the initial state v to the solution space A. If v and A are not specified, the god number is
the graph diameter. God number computations are related to combinatorial sorting problems and
is a NP-complete problem in general even when restricted to concrete sliding problems. In the
two-player case, the god number is a minimax critical value: it minimizes the maximal game event
length over the set of all strategies. A strategy is a sub-graph of the game graph that contains the
initial vertex. The definition is done so that a “mate in k” chess problem has god number k. As
for examples: in the solitaire case, we look at group games like Rubik type problems, transposition
games related to sorting, at sliding puzzles like the 15 puzzle or rainbow ball, or the tower of
Hanoi. For two-player games, we illustrate the story using examples of small chess games, a small
card game or tic-tac-toe type problems.

1. In a nutshell
1.1. A solitaire is a finite simple directed graph G = (V, E) with an initial condition v ∈V and
a solution set A ⊂V , for which the puzzle is considered solved. We use the term “puzzle” as a
synonym to “one-player game” or “solitaire”.
The game is not continued when the equilibrium
set S and especially the solution set A ⊂S is reached. The equilibrium set S is defined as
the set of vertices in G with only incoming edges.
A graph is simple if no self loops v →v, nor
multiple connections appear. It is possible to see an edge (a, b) as undirected, if both connections
a →b, b →a are present. The god number of a winnable solitaire is the minimal path length
from v to A. For undirected graphs, it is the geodesic graph distance between v and A. If
a solitaire is non-winnable, it is custom to define the god number to be infinite. We can still
then still look at maximal game events. Also, if S and so A are empty, we could look at the
maximal length of a game event. Finding this is related to the question whether the graph is
Hamiltonian.
1.2. Here is the graph theoretical axiom system for a two-player game. It will be outlined again in
separate sections and summarized in a slightly more formal way at the end: a two-player game
is a bipartite directed graph G = (V ∪W, E) with an initial position v and a set A of win
positions in the set of equilibria S. The set V consists of all positions of the first player, while W
is the set of positions of the second player. We refer to G as the game graph.
The first player
moves along edges pointing from V to W, the second payer moves on edges pointing from W to V .
The set S of end position consists of all vertices without outgoing edges. The complement of A
in S are draw positions. These are vertices representing game positions where the game can not
be continued but where none of the players has won. A game event is a maximal simple path γ
in G that starts at v. It could be a path of length 0 like if v ∈S. That γ is simple means that
it does not cover any vertex twice. Maximal means that it is not part of a strictly larger game
event. A game event terminating in A is called winning, otherwise it is a draw game event:
it can either end up in S or then trap itself, as it needs to be self-avoiding.
The first player
who reaches A is a winner. There are two scenarios for a draw: the draw event γ can either end
in S \ A or then end in a vertex, where a continuation is not possible without hitting an already
covered position and so violating the simplicity of γ.
1.3. A strategy is a sub-graph H of G that contains v. 1 A win strategy for V is a strategy
H that does not remove any edges starting from W and which has the property that every game
event in H ends in A ∩W. A win strategy for W is a strategy H that does not remove any
edges starting from V such that game event in H ends in A ∩V . A draw strategy is a strategy
that is neither a win strategy for V , nor a win strategy for W. In a draw strategy H, both players
have limited their move options (removed edges) so that the win set A can not be reached in H
by neither of the players.
1.4. In this frame work, Zermelo’s theorem for a game (G = (V, W, E), v, A) logically follows
from the definition. Let us prove it nevertheless, as traditionally one uses backward induction on
the finite game tree [49]. 2 We also have game graph, not a game tree so that that argument
anyway would not work in the graph theoretical frame work that we consider here. 3
Theorem 1 (Zermelo’s theorem). There is either a win strategy for V , or a win strategy for W
or a draw strategy.

2. Introduction
2.1. God numbers quantify optimal solutions for deterministic, finite, zero sum, sequential
games. The term “god number” has appeared first in the context of the Rubik cube puzzle
[74, 69, 37], where the number is now known to be 20 in the half turn metric [67]. The term
was popularized in the early 1980ies by “cubists” and mathematician David Singmaster, who
distributed notes on the “magic cube” in 1979 already. (They were published in 1981 [74]).
For
a two-player game, the god number is a minimax optimization problem for the game graph.
The prototype is a chess problem “mate in n” has god number n.
2.2. A problem “draw in n” for example tells that for some strategy, the maximal path length
in it leads to a draw. In a game with god number n, the analysis of a game only needs to to be
done in a neighborhood graph Bn(v) of v. 6 “Draw” either forces a game event to reach S \ A
or then ends in a dead end, not being able to continue without crossing itself. “Draws” can also
be a “theoretical draws” meaning that they are undisputed end positions. In chess for example,
if we reach a position where both players only have a king and a horse. The game does not need
to be continued. We could bake this into the geometry by removing any outgoing edges at such
points of the game graph. As more advanced players are, as more they can prune the game graph
and also label positions w as points in A which are clearly winning. Pruning means to remove
any outgoing edges from w.
2.3. The class of games that can be described as such is close to [81], who would rather see it
as a playground within set theory rather than geometry. Zermelo’s article was only three and a
half pages long and needed various clarifications [70]. Restricting to graph situations covers most
puzzles and games. The geometric language of graphs allows to use intuitive geometric notions.
2.4. The geometric setup models the usual assumptions:
• The term zero sum means that if one players wins the other playes loses. It is not possible
that both win. If both lose, the game is a draw.
• Deterministic means that both players at any time have the same full access to informa-
tion, that no external randomness nor third party input can happen.
• Sequential means that players always take alternate turns. This is encoded in the bipartite
structure of the graph. It also is an ingredient to deterministic.
• Finite means that the entire game has only finitely man states. The game is so encoded
as a finite simple graph, where the nodes are the possible configurations and where the
oriented edges are the possible moves.
• Finite events are forced by the assumption that all game events describing game events
must be maximal simple paths starting at v. The case for having no self intersections is
done such that there are only finitely many game events.
• No cycles is encoded in the simplicity of the game events. It is an important assumptions
we want a finite set of game events.
The convention in chess, limiting the number of
repetitions can easily be bent to this. If a position appears three times, just cut away the
loops which have led to it and stop the game after the first repeat.

Cayley graph of a finite simple graph with R = 8!12!(37)(210) elements. Since this is larger than
265, we can not hope to draw out the entire game graph.

2.7. The size of the neighborhood graphs Br(v) of the initial position v in chess grows fast and is

2.8. One reason to restrict to 2 players is that for more than two-players, like a 3 player chess,
the possibility of collusion is possible already. With more players, one also has to clarify the
order in which players play like taking turns in a circular way. A geometric description is not as
simple as for 2-player games because Zermelo’s theorem does not generalize in an obvious way. It
is not true that either one of the player wins or that we have a draw. We can have a perfectly
symmetric case with 3 players where one of the players needs to pick a strategy favoring one of
its opponents and so decide the winner. The game itself does not determine that as in the case of
2-player setup.
2.9. Also the sequential assumption is important. If the players could move simultaneously, like
in a rock-paper-scissors game or prisoner dilemma game, the two players would have both to
move at the same time. Since in that case only partial information is available, Nash equilibria
conditions start to matter. If randomness was allowed, it would force to include a probability
space that to generate the input. This would force us to look at very large graphs or then look at
conditional expectations.
2.10. We can exploit that many popular puzzles and games naturally are given as finite directed
graphs (even so the graphs are too large to be drawn out like in chess). This allows for a rather
intuitive axiomatic setup which is simpler, if one compares it with the existing alternatives. The
geometric frame work only appears to be a limitation if one would insist that one can construct
the entire game graph. But such limitations appear everywhere: we can not explore the graph of
all integers N, where two are connected if one is a factor of the other for example. This graph
exists but we can only see a small pert of it. Similarly, if games are small enough, we have a
reasonable chance to oversee the entire graph and measure the god number.
2.11. For the foundations of game theory, see [53]. The geometric setup restricts to games that
have entered popular culture. Remarkably, the number of board games or solitaire games that
can be described using graphs is quite rich.

2.13. As for originality, one should note that graph theoretical approaches to games are hardly
original, this probably goes back to Cayley already. But it should be pointed out again that
traditionally one looks at “game trees”. The closest in literature is the recent book [23], where a
strategy (or policy) is formally seen a function from all paths to edges (see page 16 in the open
preprint version of [23]). The language uses arenas or “game structure” which could be interpreted
as a game graph. There are other major differences in that quantitative or qualitative winning
conditions are considered. There are other major differences in that all vertices have an outgoing
edge in [23]. We feel that this is very restrictive. Already simple games like peg solitaires or Tic-
Tac-Toe two player games have positions without outgoing edge. One could mend it by assuming
that such positions have self-loops.
2.14. Zermelo’s work of 1913 can be seen as the beginning of formal game-tree search. But
Zermelo did not use the language of graphs. This should probably be attributed to Kalmar from
his 1928/29 work on abstract games [38]. Kalmar’s article was written in German would use
terminology like “taktik” instead of strategy. Kalmar’s work considerably clarifies Zermelo’s
theorem. See [20].
2.15. The elementary graph-theoretic formalism presented here is close to finite games with per-
fect information and turn-based multiplayer games on graphs which are also called “arenas” with
reachability objectives. We think that a novelty of the present formulation is the elementary
subgraph interpretation of strategies and seeing the associated “god numbers” as measuring
the worst-case number of moves by the initial player needed under a winning strategy. The sim-
plicity of the set-up is maybe best illustrated in that the theorem of Zermelo is immediate and
that many commonly known puzzles and games can be covered with the language.

4. Two player games
4.1. A two-player game is a finite simple directed bipartite graph G = (V ∪W, E) together
with a vertex v giving the staring position and a subset A of win positions in S, where S is
the set end positions, the set S of vertices without an emanating edge. Points in S are game
positions, where no move is possible any more. The set S of end positions is part of the rules of
the game and sometimes artificially added. For example, it can be a position where naturally no
move is possible any more. It can be a position which is defined to be a defeat like if the king
is mate, or then a position which is declared to be hopeless, like a position where both players
do not have enough resources to win and where it would be pointless to continue. An example
in chess would be if both players only have a king and a horse, in which case only a “help mate”
could render a win.
4.2. An game event is a maximal simple path γ in G that starts from v. The assumption is
that on each directed edge, the path needs to follow the direction of the digraph. Simple means
that no vertex is covered twice. Pawn moves in chess are examples of directed moves. Capturing
an opponents piece is an other example of a non-reversible move in chess. The length |γ| of γ is
the number of V -vertices in γ. We choose this and not the length of γ in order to have “mate in
n moves” be a problem with god number n. We also designate a subset A ⊂S as the set of win
positions. The complement of A in S are declared to be draw positions.
4.3. A strategy is a sub-graph H of G. A strategy for V is a strategy that does not remove
any edges starting from W. A strategy for W is a strategy that does not remove any edges
starting from V . A win strategy for V is a strategy for V such that every game event ends in
A ∩W. A win strategy for W is a strategy for W such that every game event ends in A ∩V .
A draw strategy is a strategy that is neither a win strategy for V nor for W.
4.4. The god number of a strategy H is the maximal possible length of a game event in H.
For a game that can be won by V , the god number is God(G) = minH maxγ=γ(H) |γ|, where
H runs over all V -strategies leading to a win of V . The other cases are similar. While minimax
principles for two-player zero-sum games go back John von Neumann, the min-max situation in
our case is much simpler. The length of a game event is the potential loss. To get the god number,
we minimize the maximal loss over all possible game strategies.
4.5. Examples:
a) Let us look at a chess game on a 2 × 4 board, where both parties only have king or queen and
no other figures are present. This is obviously a draw case. The set of configurations with only
kings present is declared to be part of S as the game does not continue there. The initial player V
= (White) has a winning strategy. It removes all initial plays except capturing the other queen.
W can now use the empty W-strategy because it is forced to recapture the queen. But then we
are in S.
b) Lets look at a chess game on a 4 × 3 board again with only king and queen on both sides at
the corners. Now the initial player V = (White) has an obvious win strategy: capture the queen.
It is mate in 1. The god number is 1.

5.1. In this section we describe a class of solitaire games that come from finitely presented
groups that are generated by involutions, and so are Coxeter group. In this case it is in
general the symmetric group. We are not interested so much in the group but in the Cayley
graph of the group generated by a set of transpositions. Finding its diameter and so the god

vertex set V . The reason to restrict to connected graphs is that the god number of of the disjoint
union Γ = Γ1 ∪Γ2 of two graphs is the sum of the god numbers of the components.

Proof. If ∆is a subgraph of Γ, it generates a subgroup as less generators are used. Let ∆be a
spanning tree in Γ. It still has n vertices, but now it has (n −1) edges. We made the problem

We use induction with respect to n. For n = 1, there is no edge and S1 is the trivial group. This
is the induction foundation. As for the induction step, assume that the statement is true for all

6. Sliding puzzles
6.1. Sliding puzzles generalize the classic 15-puzzle (Γ = C4 × C4) or the magic ball Γ is the
icosahedron graph) to arbitrary connected graphs. Sliding puzzles for connected Γ produce
game graphs G that are in general more interesting than the game graphs of transposition games,
as the latter are always Sn. Wilson’s theorem [80] classifies the graphs.
6.2. Given a graph Γ = (V, E) on n vertices, one of the tokens is called a hole. A legal move
slides the hole into an adjacent position, opening the hole where it had been. From a node v ∈G
only transpositions involving the hole can be used. The sorting is now localized near the hole.
The set of all reachable permutations again produces a game graph G whose diameter is then the
God number.
6.3. The history of the 15-puzzle (where Γ is the grid graph C4×C4) is iconic and well documented:
after a precursor was shown around by Noyes Chapman in 1874, he applied for a patent in
1880. A craze was driven by Sam Loyd’s offer of $1000 for swapping tiles 14 and 15. Johnson and
Story [36] demonstrated that a permutation parity is an invariant. implying that only half of the
16! positions are reachable. Finding the god number of the general n × n version of the puzzle is
an NP complete problem [62].

deepening in the context of pattern databases. [44] introduced iterative-deepening. [64]
showed that the 8-puzzle’s god’s number is 31.

7. Chess games
7.1. Chess is without doubt one of the most iconic multi-player games. It motivated the first
steps in mathematical game theory [81, 72]. Many chess variants have been developed [61]. In the
graph theoretical setup used here, we assumed that a game event is modeled by a finite simple
maximal graph that starts at v. This obviously is not the standard assumption in chess, as one
does not want to have the same position appear 3 times. And it does not matter for the God
number, nor for the Zermelo function Zermelo : {Games} →{V wins, Wwins, draw}.
7.2. Let us discuss the repetition case issue. Assume G(n) is a game variant, where the game
rule assumes that a position can not occur more than (n −1) times and where otherwise, all rules
are the same. Game events in a sub-graph H of G(n) are now the maximal finite simple paths in
H which can not have more than n −1 self intersections. We formulated the result for chess but
obviously it takes place for all games covered by the axioms. The following lemma is therefore a
justification why the assumption that game events are finite simple maximal paths starting at v
is a reasonable one and would not change essential things like ”who wins” if one would allow a
number of repetitions (like in chess).
Lemma 3 (Repetition). God(G(n)) = God(G(1)) and Zermelo(G(n)) = Zermelo(G(1)).
Proof. Assume G(n) is win for the initial player V =White. This means that V has a strategy H
such that no game event for W with n −1 possible self intersections ends up in the winning set
A. But then also no game events W that has no self intersections ends up in the winning set A
so that also G(1) is win.
The same argument holds if G(n) is a win for W.
If G(n) is a draw, then there is a game strategy H to which both players have contributed such
that there is no game event with possibly up to (n −1) self intersections that ends up in A. So,
also no game event with no self-intersections ends up in A which means that the game strategy
H is also a game strategy for draw in G(1).
The opposite direction follows from Zermelo’s theorem and logic: assume that G(n) is not a win
for white, then this means that G(n) is a draw or win for black for G(n). But in both cases this
leads to a draw or win for black for G(1) and so not to a win for white for G(1). The other cases
are similar.
□
7.3. We see that the theoretical simplification to assume finite simple paths as game events is also
in very concrete situations like chess irrelevant. It does not change the basic question whether
the game is a win or loss. Not imposing any limit on the number of times that a position can
be revisited, would change things however. Such objections had been voiced to Zermelo’s original
approach. Having not only a finite set of game positions but also a finite set of game events is
essential.

7.6. The 4 × 2 chess board has pieces {K, Q, P} for both white and black players. It defines
a directed digraph G = (V ∪W, E). The graph starts from the starting position v ∈V . The
graph is generated using a breadth-first search (BFS) starting from v. For each state dequeued,
we compute the legal moves using pseudo-legal move generation followed by check validation to
ensure legality. States are added to the vertex set V ∪W and the queue only upon first discovery
so that each unique position is processed exactly once. The BFS traversal guarantees that G
contains all reachable states and represents the complete game tree. The height of a node is the
distance to v.

9. Rubik type games
9.1. For group games and in particular Rubik type games, we work in a finitely presented
group ⟨S|R⟩= ⟨g1, . . . gm|r1 . . . rm⟩, where S are the generators and R are the relations. A
group can also be defined by giving a finite set of generators in a permutation group. This is
the permutation representation. One usually assumes that the generator set S is invariant
under involutions. This gives god number 20 for the Rubik cube.
9.2. Many geometric shapes have been made into Rubik type puzzles in particular various n×m×k
generalizations, or tetrahedra, octahedra or dodecahedra. There are version where the coloring
has changed like bi-colored cubes [51]. One of the famous examples is the 2 × 2 × 2 Rubik cube
already described in [74]. (it is also known as the“pocket cube”) and where we only allow moves
of 180 turns of two faces L and U. This group has 6 elements and is isomorphic to ⟨a = (1, 2), b =
(2, 3)|a2 = b2 = (ab)3⟩= S3. The god number is 3. For the full pocket graph, the Cayley graph
can be constructed by GAP and the god number determined. See the code section.
9.3. The 2×2×1 Rubik is called the ”Floppy”. Its group has 2304 elements. The god number is

12. Other games
12.1. Hex [31] is a two-player game that has relations to theorems in topology. It can be played
on any rectangle [50]. It was invented in 1942 by Piet Hein and rediscovered by John Nash in
1948. Hex is a paradigm because of the Hex theorem telling that it never leads to a draw. It
has been used to prove the Brouwer fixed point theorem [25], who also pointed out that it is also
related to the Jordan curve theorem. David Gale also covert the n-dimensional Hex theorem on a
n dimensional cube which belongs to a n-person Hex game. Gale writes From the game-theoretic
point of view, n-person Hex is probably not of much interest. Aside from the mechanical problem
of designing a practical board there is the usual difficulty of multi-person games that players may
form coalitions, requiring more sophisticated analysis how how such coalitions can be formed and
play against each other.
12.2. Hex type games can be played on any finite simple graph Γ. Each player selects out an
edge. The first one who has a closed simple loop of the same color wins. A famous variant is a
square grid on a torus. Player A needs to build a path from left to right not crossing any path
of B. Player B needs to build a path from bottom to top to bottom. The most famous variant
is ”Hex” which has been popularized by Nash (but Nash would play on a square board, not a
hexagonal lattice). It is an example where the first player has a winning strategy.

12.7. NIM is 2-player game in which the goal is to take the last object. Each player can take an

player if the pile sizes are different. Otherwise, the second player wins. If both piles have n pieces

12.8. Shannon writes in [72]: “In some games, there is a simple evaluation function f(P) which
can be applied to a position P and whose value determines to which category (won, lost, etc.)
the position P belongs. In the game of NIM (Hardy and Wright, 1938), for example, this can be
determined by writing the number of matches in each pile in binary notation. These numbers are

12.9. An other class of arithmetic games are Zeckendorf games. Like NIM or alpha-zero [8] it

13. Remarks
13.1. Conway constructed numbers as a subclass of games [18]. It is concept allowing to construct
surreal numbers. The axiomatic setup of Conway’s combinatorial game theory can describe
any two-player game with perfect information and no chance. Donald Knuth wrote a novel [42]
about it, in which two people found themselves on a deserted island with a stone telling some of
the axioms of the concept. Knuth’s title in English was Surreal Numbers: How Two Ex-Students
Turned On to Pure Mathematics and Found Total Happiness. The German title of that book
was island of numbers. Note however that even for simple games like Tic-Tac-Toe, one would
hardly write the game as part of the ”numbers of games” paradigm.
13.2. Many solitaire game can be made into a 2 player game where two-players take turn. The
6-card game we have seen is first of all a simple solitaire sorting game. The one who lands in the
win position wins. This is in general not that difficult to analyze. Such games can be played on
any Cayley graph. One could also give each player the option to lock one of the generators. For
transposition games where G = Sn one can naturally take V = An the set of even permutations
and W = Sn \ V , the set of odd permutations. After choosing v and A one has a game.
13.3. God number problems are related to run length analysis of algorithms, like sorting or
path finding. A breadth first search builds up larger and larger neighborhoods. To get from a
neighborhood of all points in distance r, build all unit balls from all vertices of the boundary to
get a ball of radius r + 1. This is Breadth-First Search. Once all vertices are covered, we have
the largest distance from x. This can be inefficient. It can be that a vertex x has Sr(x) = G but
r is smaller than the spectral radius. A simple example is the wheel graph, where the center x
gives B1(x) = G but where the graph diameter is 2.
13.4. A general strategy to generate 2 player game is to take a graph, select a certain geometric
property for partially 2-colored graphs like having a path graph of length 4 with one color. Then
have two-players place colors on edges. The first one who realizes the pattern wins. Already in
the solitaire game, finding patters is NP complete in general. Finding complete sub-graphs of a
graph for example is NP complete.
13.5. The collection of all solitaire games could be made into a category. The objects are the
graphs a homomorphism from (V, E, v, A) and (W, F, w, B) would be a map ϕ : V →W that
maps edges to edges or vertices and which maps v to w and A to a subset of B and for which
the inverse ϕ−1(y) is a connected sub-graph of (V, E) for every y ∈W. Homomorphisms do not
honor ”win” however in general. Two games are isomorphic if there exist a graph isomorphism
that maps v to w and A to B. Isomorphic games have the same god number. An example are the
following two 2x2x2 Rubik implementations.

14. History
14.1. The history of game theory starts earlier than von Neumann and Morgenstern [53]. A good
source reference is [20]. James Waldegrave first described minimax solutions to best strategies
in two-person zero sum card games. But as pointed out in the introduction to [20] Waldegrave
did not attract attention so that the first formal reasoning for game theory are attributed to
Cournot and Edgeworth 1897 who pioneered oliopoly theory to model industries with a few
producers. An important early start in mathematical game theory with von Neumann proved in
1928 the minimax theorem. Von Neumann’s minimax theorem tells that P n is the space of
probability vectors in R⋉and A is a n × m matrix, then the bi-linear function f(x, y) = x · Ay
satisfies maxx∈P nminy∈P mf(x, y) = miny∈P mmaxx∈P nf(x, y). Von Neumann considered simplices
like P n strategy sets and f(x, y) the expected payoff when the first player plays x and the
second player plays y. It latter got generalized to concave-convex functions, functions f(x, y) that
are concave in x and convex in y.
14.2. If the theory of games is seen from a finitist point of view one can pretend to be able to
oversee the entire game graph. In this “microcanonical perspective” probabilistic thinking is not
really needed. When playing a traditional game like chess or checkers, we are in a finite setting and
do in principle not need probability spaces. In a discrete finite frame work, in principle, we could
do perfectly rational decisions by checking all possible game outcomes. While impractical

16. Summary of axioms
16.1. Here is a summary of the axiomatic setup for 1-player games = solitaire games.
1) The game graph G of a solitaire game is a finite simple directed graph (V, E).

17. Some questions
17.1. The beauty about games is that the provide an endless source for problems. In general,
for any family of games like like n × m × k Rubik cubes or n × m tic-tac-toe games, one can ask
asymptotic questions or extend things to in higher dimensions. Four dimensional Rubik cubes
based on tesseracts have been implemented on computers in the 90’ies already. Given a puzzle(n),
not only the growth rate of God(puzzle(n)) but the construction of the solution path is interesting.
17.2. Problem A) Is there a closed formula for the god number for the transposition game of the
wheel graphs Wn? Are the god numbers of Wn and Sn the same for large n or are there infinitely
large n, where God(Sn) = ⌊3n/2⌋> God(Wn)? For the star graph, see [1] (where a proof sketch
appears in Theorem 7.) Unlike for path graphs Pn or circular graphs Cn, where the god number
grows quadratically with n, the god number grows linearly for wheel or star graphs because the
diameter of such graphs is 2. If a graph has diameter O(n) like for Pn or Sn, the God number is
expected to grow like O(n2).
17.3. Problem B) Given a random connected graph in Erdoes-Renyi probability space, or a ran-
dom tree obtained by some branching process. How does the God number of the transposition
game graph or the sliding game graph behave in average? In particular, how does the expected
God number behave in the limit n →∞? The answer will depend on the parameters of the
probability models.
17.4. Problem C) Sliding or transposition problems look interesting on cylinder Cn ×Pm or torus
Cn × Cn. One can play such puzzles on any discrete manifold. We have seen that the god number
different on a M¨obius strip or a cylinder even so the Cayley graphs G1, G2 have the same vertex
degree and same size. It would be interesting to study the topological properties of these graphs.
They have the same size but different diameter.
17.5. Problem D) It would be nice to have more examples of non-square n × m chess boards
set-ups where the game graph has a reasonable size. There are infinitely many variants one can
consider like on 3D cubes or on different manifolds such as tori. If we take a standard chess and
move each army of 16 pieces one step forward, it can be played on a torus and is mate in 1.
There are likely also other games situations with unexpected outcome. Take a standard chess for
example and play it on the Moebius strip where left and right part are identified in an opposite
way. White can as a first move immediately capture a rook, but then also black can do that.
What happens on a 8 × 4 board with the standard set-up with the middle 4 rows taken away so
that all figures are covered. Now play this on the Moebius strip.
17.6. Problem E) Mankala, where each player has exactly m stones in each of the n = 6 pits has
a chance to be analyzed for small n and m. For n = 1 and 2, the first player obviously wins. For
a larger number of pits, unexpected strategies might occur due to the rule that if one has a pit
with a lot of stones so that one can go around the entire game and land in an empty of its own
pits, one gets all the stones from the opponent. For small n, one can draw out the game graphs.
17.7. Problem F) What happens with the 4 peg tower of Hanoi (Reeves puzzle) in the limit
n →∞. Does the shape also converge to a fractal object if realized suitably in R3, similarly as the
Hanoi graph converges to a Sirpinski fractal in R2. In the Hanoi case, the geodesic is the boundary
line when embedded as the Sirpinski fractal. What are the geodesics in the Reeves puzzle?

17.8. Problem G) For transposition puzzles, there is the interesting question about the size of
the antipodal set, the set of points which have maximal distance to some vertex. In any Cayley
graph, this is independent of the vertex. In general the BFS layer profile is of interest. This
is the length of the wave front starting at v. This layer profile is most of the time concave down
(unimodal) but we have seen exceptions. What BFS layer profiles can occur? A concrete question
to ask is whether the BFS layer profile determines the graph Γ in a transposition graph set-up or
whether there are non-isomorphic graphs Γ with n vertices such that their BFS layer profiles are
the same.
