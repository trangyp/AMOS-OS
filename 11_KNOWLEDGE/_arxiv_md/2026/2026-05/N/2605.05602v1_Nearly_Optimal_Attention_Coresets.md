Introduction
Modern transformer-based generative models [46, 1, 44, 39] make heavy use of the attention mechanism.
Each attention head typically retains a large KV-cache (set of keys and values), that serves as the working
memory and context of the model during generation [41, 37]. As context windows grew, the size of this cache
become one of the dominant bottlenecks of deploying large language models [27, 39, 19, 32, 42]. Compressing
KV-caches is therefore a central problem for the practical deployment of long-context models. There has
already been substantial effort in this direction (see Section 1.1 for further related work).
We study the question of optimal KV-cache compression with error guarantees. A powerful general
technique for compression is coreset selection. It is widely used for compressing large datasets while provably
preserving quality for a rich families of queries [28, 36, 12, 23]. These use deep existential results in discrepancy
theory which are recent algorithmic breakthroughs [4, 5, 6, 16, 3, 7, 31], and these techniques are now known
to yield essentially optimal compression rates for several related objectives.
These include all sums of scalar functions of the dot product and Euclidian distance [28]. More recently,
this approach was also applied to streaming attention approximation [30].
Perhaps surprisingly, the optimal size of the coreset for the attention problem has not been known yet,
and our goal here is to establish such a bound. Building on the above line of work, we construct a subset of
key-value pairs that uniformly approximates the attention output for every query of bounded norm, with a
coreset size that nearly matches our information-theoretic lower bound.

Limits of compression and on the need to bound the norm of q.
Without any constraints on or
relaxations of the attention problem, no compression is possible. The attention mechanism approximates
retrieval; the very terminology of “keys” and “values” is borrowed from associative lookup. Concretely,
attention can be made to reproduce any single value vector almost exactly: place a query in the direction of
the corresponding key and scale its norm to make that key dominate the softmax. Any sketch that supports
arbitrary queries must therefore essentially store the full set of values, which seems to rule out any lossy
compression.
The escape from this impossibility is to bound the query norm. A query that “cherry-picks” a specific
value is necessarily one of large norm: the larger the desired separation in softmax weights, the larger the
query norm required. We therefore seek to compress the cache so that attention is approximated for all
queries below a fixed norm threshold ρ. Without such a constraint, the lower bounds such as [30] or our
improved Theorem 2 rule out any compression.

Related work
Work on compressing the KV-cache has, broadly, taken four directions:
• Floating point compression: The first is to keep all key-value pairs but represent each entry using fewer
bits. These include a large number of techniques which are out of scope for this manuscript. Notable
examples include [13, 26, 21, 50]. These methods reduce per-entry storage but leave the number of
cached tokens unchanged.
• Distillation: A second line replaces the original keys and values with a different, smaller set that
mimics the same attention behavior. Examples include clustering keys and values to a small set of
2


## Page 3


centroids [52], learning compact representations of long contexts [18], prefix and prompt tuning [33],
and attention-matching distillation [54]. The substituted set need not be a subset of the original vectors.
The approaches require access to the query distribution to avoid degrading quality.
• Linearization: A third line abandons the explicit cache altogether and replaces the attention mechanism
with a linear-time surrogate based on random or learned feature maps [38, 29, 14, 47, 40], or with
state-space and recurrent alternatives [24, 8]. Such models trade exact softmax attention for fixed-size
state but require architectural changes and retraining.
• Coresets selection: A fourth direction, and the one taken in this paper, is coreset construction: keep
a small subset of the original key-value pairs and discard the rest. Heuristics in this family include
attention-sink retention [49], accumulated-attention scoring [53, 53, 34, 35, 35], layer- and head-adaptive
budget allocation [11, 20, 48], query-aware sparsity [43], model-guided eviction [22], sparse long-context
patterns [9], and short-window memorization [10]. A recent line gives provable guarantees for coreset-
style attention approximation via discrepancy theory [30, 52, 51, 25].
Computing attention for all queries.
A related but distinct line studies the cost of computing the full
attention matrix-vector product for n queries, rather than compressing a fixed KV-cache for future queries.
Exact implementations such as FlashAttention optimize memory traffic and hardware utilization but still
compute the dense attention pattern [17]. On the theory side, subquadratic or near-linear algorithms are
possible under additional smoothness, bounded-entry, or approximation assumptions, often via kernel-density
estimation, sampling, or kernel data structures [51, 25, 12, 40].
We highlight the work of [2] who parametrize the complexity of the problem as a function of the size
of the entries of K, V, and q’s, similar to our bound on norm ρ. They identify a sharp bounded-entry
transition: for d = O(log n) and entries below √log n, attention can be approximated in near-linear time,
while entries of order √log n lead to SETH-based barriers against truly subquadratic algorithms. Our setting
is complementary: we ask how many key-value pairs must be retained so that a compressed cache answers
every bounded-norm query, independent of the number of future queries.
