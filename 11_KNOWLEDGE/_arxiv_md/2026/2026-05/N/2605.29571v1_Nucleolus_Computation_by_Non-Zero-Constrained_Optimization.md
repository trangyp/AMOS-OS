Abstract. We extend the list of games where the nucleolus is com-
putable in polynomial time. Based on the classical MPS scheme, nucle-
olus computation can be reduced to the problem of finding a coalition
with minimum excess that does not belong to a given linear subspace.
We call this problem LSA-MinExcess, and show that it is equivalent to
NZ-MinExcess: Given integral values per player, find a coalition with
minimum excess whose player values do not sum up to 0. Exploiting
this representation, we prove that the nucleolus is computable in poly-
nomial time for arboricity games, network strength games, and certain
b-matching games. Along these lines, we show that for b-matching games
with b ≤2, LSA-MinExcess is polynomially equivalent to Shortest
Non-Zero Cycle.
Further, we prove that in general, linear subspace avoidance strictly in-
creases the complexity of the minimum excess problem, even for mono-
tone games. We still provide a reduction that trades linear subspace
avoidance against an arbitrarily small approximation error. Finally, we
show that the nucleolus is unstable in the following sense: A small change
in the value function of the game can lead to a change in the nucleolus
that is exponential in the number of players.

Introduction
A cooperative game is a pair (P, v) of a finite set of players P and a value func-
tion v : 2P →R on coalitions S ⊆P with v(∅) = 0. (P, v) is called monotone if
v(S) ≤v(T) for all S ⊆T ⊆P, and superadditive if v(S ∪T) ≥v(S) + v(T) for
all S, T ⊆P. Usually, v is not given explicitly, but by some combinatorial opti-
mization problem, e.g., as the maximum weight of a matching in the subgraph
G[S] of some weighted graph G for S ⊆P [8]. This way, the input size of (P, v)
can be controlled. Given a cooperative game (P, v), a cost allocation is a vector
y ∈RP . We will write y(S) := P
p∈S yp for S ⊆P. The nucleolus by Schmeidler
[32] defines a unique and supposedly fair cost allocation. For a formal definiton,
let y ∈RP , and consider the excess vector θ(y) that contains all coalitional
excess values (y(S) −v(S))S⊆P in non-decreasing order. The nucleolus is the
unique cost allocation that lexicographically maximizes the excess vector θ(y)
among all y ∈RP with y(P) = v(P).

1.1
Our Results
We study the cost allocation concept of the nucleolus for cooperative games. Its
computation can be reduced to separating over the polytopes in the classical
MPS scheme: For a proposed cost allocation, we have to find a coalition with
smallest excess that is not yet fixed. The latter requirement results in a linear
subspace avoidance constraint. We show that linear subspace avoidance (LSA)
is polynomially equivalent to requring a non-zero (NZ) coalition in the following
sense: Given integral values per player, the total sum of these values in our
coalition cannot be 0.
Proposition 2. The problems LSA-MinExcess and NZ-MinExcess are poly-
nomially equivalent.
This representation proves to be extremely powerful. While linear subspace
avoidance has not received much attention beyond applications in game the-
ory, non-zero constraints have appeared in various fields. For example, we can
make use of previous results about non-zero matroid basis computation [17] and
non-zero submodular function minimization [15]. Further, we extend the list of
games for which the nucleolus can be computed in polynomial time:
Theorem 1. The nucleolus can be computed in polynomial time for
– b-matching games with b ≤2, if b = 2 for only constantly many vertices,
– b-matching games with b ≤2, if Shortest Non-Zero Cycle can be solved
in polynomial time,
– arboricity games,
– network strength games.
The Shortest Non-Zero Cycle problem is closely related to the Shortest
Odd Cycle problem, which is conjectured to be polynomially solvable [31].
Therefore, this seems like a promising approach to compute the nucleolus of
general b-matching games with b ≤2.
Beyond these applicational results, we study linear subspace avoidance from a
more general perspective. It was known before that linear subspace avoidance
constraints strictly increase the complexity of minimum excess problems in gen-
eral, unless P = NP [21]. The reduction relies on a non-monotone game. We show
that the same complexity increase occurs for the class of monotone games, even
if P = NP. On the positive side, we provide a polynomial-time reduction from
LSA-MinExcess to MinExcess that trades the linear subspace avoidance con-
straints against an arbitrarily small approximation error. Unfortunately, such an
error might propagate exponentially in the MPS scheme. The nucleolus defines a
continuous mapping based on the value function of a coooperative game [32]. We
show that this mapping is generally unstable, even when restricting to monotone
and superadditive games, in the following sense:

1.2
Related Work
Since its definition by Schmeidler in 1969 [32], the nucleolus and its computability
have received much attention in the context of cooperative game theory. The first
positive result, i.e., an algorithm that computes the nucleolus in polynomial time,
was attained by Littlechild [25] for minimum cost spanning tree games on line
graphs. More games followed, e.g., convex games [14] and spanning connectivity
games [4]. On the other hand, the first negative result, i.e., a proof of NP-
hardness of nucleolus computation, was attained by Faigle, Kern, and Kuipers
[13] for general minimum cost spanning tree games. Over the years, both lists
have grown and are still extended.
We contribute positive results for arboricity games, network strength games, and
certain b-matching games. For both arboricity and network strength games, the
nucleolus was previously known to be computable in polynomial time in case
of a non-empty core due to Xiao and Fang [35] and Baïou and Barahona [5],
respectively. We will show that the same is possible for all instances. Note that
moving from instances with non-empty core to general instances is often non-
trivial [6, 20, 30]. For b-matching games, nucleolus computation was shown to
be NP-hard by Könemann, Toth, and Zhou [22], even for bipartite graphs and
b ≤3. The general case of b ≤2 is still open. Certain special cases were solved
in [22]. We will provide a detailed overview over past work in Section 3.1.
Next to results for specific games, there are also structural findings such as the
MPS scheme for nucleolus computation by Kopelowitz [23] and Maschler, Peleg,
and Shapley [26], and a framework by Könemann and Toth [21] that requires a
certain structure of a game. Part of our work follows this line of research. We
will provide a detailed discussion comparing our work with [21] in Section 2.3.
Stability of the nucleolus has not been studied thoroughly, but an example of
Kumabe and Yoshida [24] implies that changing the value function of a game by
a constant may change the nucleolus by Ω(|P|). We show that this change can
even be exponential in |P|.
Finally, we want to mention that all our results carry over to cooperative games
defined by a cost function (instead of a value function), as well as related solution
concepts which also lexicographically maximize the excess vector, but require a
different total value y(P) [6, 2, 27, 12].

Congruency-Constrained Optimization
Könemann and Toth [21] also considered LSA-MinExcess to compute the nu-
cleolus. They proved that it can be reduced to a congruency-constrained problem.

While the constraint a(S) ≡k mod p may seem similar to the constraint a(S) ̸=
0 of NZ-MinExcess, it turns out that congruency constraints are strictly harder
in general: Given a matroid on a ground set E, a ∈ZE, and a target number
k ∈Z, finding a basis B of the matroid with a(B) = k is impossible with only a
polynomial number of calls to an independence oracle [9]. This is still true if a and
k are polynomially bounded and we allow for randomized algorithms. Note that
this corresponds to the special case of a congruency-constrained problem where
p is much larger than a. In contrast, finding a basis (or an arbitrary independent
set) B with a(B) ̸= 0 can be done in oracle polynomial time [17]. One can even
find such a basis (or independent set) with maximum weight. This fact is the
foundation for our results on games with a matroid structure in Section 3.2. It
further shows that, while LSA-MinExcess and NZ-MinExcess are equivalent,
the same is not true for the congruency-constrained variant of Könemann and
Toth [21], even when restricting to monotone games. For this reason, we focus
our attention on the NZ-MinExcess problem.

Application to Specific Classes of Games
In this section, we focus on LSA-MinExcess for specific classes of games. Our
proofs rely on the equivalent formulation as NZ-MinExcess, cf. Proposition 2.
Recall that if we can solve LSA-MinExcess in polynomial time, we can also
compute the nucleolus in polynomial time by Proposition 1. Our positive results
are summarized in Theorem 1, which is a consequence of Theorems 2, 4 and 5.
Further, we can recover previous positive results on nucleolus computability:
LSA-MinExcess is solvable in polynomial time for convex games and spanning
connectivity games. For both, polynomial time computability of the nucleolus
was known before, but derived differently. Convex games are characterized by a
supermodular value function. We can solve NZ-MinExcess due to a result by
Goemans and Ramakrishnan [15] on submodular functions, and the fact that
non-zero coalitions constitute what they call a parity family. Spanning connec-
tivity games [3] are based on the graphic matroid, and fall under Theorem 5.

In the following part, we will study LSA-MinExcess for b-matching games:

for bipartite graphs and b ≤3 [22]. Thus, we focus on b ≤2, where the nucleolus
is so far known to be computable in polynomial time for certain instances on
bipartite graphs [22]. We show that LSA-MinExcess for b-matching games with

This is closely related to Shortest Odd Cycle, where one asks for a cycle
with odd (instead of non-zero) total value. In fact, both problems are a special
case of a non-zero constraint in a commutative group, for the groups Z and
Z2. Problems with a non-zero constraint in a group have been studied e.g. for
shortest path [19, 18] and matroid problems [17].
Schlotter and Sebő [31] showed that Shortest Odd Cycle is NP-hard if one
additionally requires the cycle to contain a specified vertex. Their construction
can trivially be adapted to show that the same is true for Shortest Non-Zero
Cycle. However, the complexity of both problems without this constraint is still
open. Schlotter and Sebő [31] conjecture that Shortest Odd Cycle can be
solved in polynomial time. Their main reason for this is the fact that it can be
solved in randomized polynomial time for polynomially bounded weights, which
is also true for Shortest Non-Zero Cycle, see Theorems 2 and 3. Therefore,
it seems likely that Shortest Non-Zero Cycle is solvable in polynomial time,
which would immediately imply an algorithm to compute the nucleolus of general
b-matching games with b ≤2 in polynomial time.
Finally, we show that LSA-MinExcess for b-matching games with b ≤2 can
be solved in some new special cases. If the weights and cost allocation are poly-
nomially bounded, then the problem can be solved in randomized polynomial
time. Additionally, we show that it can be solved in polynomial time if b = 2
only for a constant number of vertices. For this class of games, the nucleolus was
previously not known to be computable in polynomial time.

LSA-MinExcess for General Games
In this section, we study the hardness of linear subspace avoidance, that is, the
complexity gap between LSA-MinExcess and MinExcess:
Problem 6 (MinExcess). Given a cooperative game (P, v) and a cost allocation
y ∈RP , find a coalition S ⊆P that minimizes y(S) −v(S).
It was known before that for non-monotone games, linear subspace avoidance
might increase complexity from polynomial-time solvability to NP-hardness [21].
We extend this result to monotone games, using completely new ideas. Then,
we provide a reduction from LSA-MinExcess to MinExcess that incurs an
arbitrarily small additive error in the approximation guarantee, which is the
best we can hope for. Finally, we show that any such tiny error might propagate
exponentially in the MPS scheme, so the reduction does not imply satisfying
guarantees for approximate nucleolus computation. In fact, this leads to a gen-
eral instability result for the nucleolus as a mapping of the value function of a
cooperative game, even if we restrict to monotone and superadditive games.
4.1

For non-monotone games, linear subspace avoidance constraints can increase
the complexity of MinExcess: Computing a shortest s1-t2-path in a directed

must strictly distinguish feasible paths from s1 to t2. Further, for monotone

Conclusion
We have introduced the NZ-MinExcess problem and shown that it can be used
to compute the nucleolus. This relates nucleolus computation to results on non-
zero-constrained optimization. We demonstrated the power of this approach by
applying it to arboricity and network strength games. This strengthens previous
results on these games (which require a non-empty core), while at the same time
being much simpler. We believe that computing the nucleolus for more classes of
games by solving NZ-MinExcess is a promising direction for further research.
For b-matching games with b ≤2, we showed that LSA-MinExcess is equivalent
to the Shortest Non-Zero Cycle problem. The complexity of this, and of the
related Shortest Odd Cycle problem, are still unknown. Since there is already
some interest in this from different areas, these are important open problems.
While the general case is still open, we showed that the nucleolus of b-matching
games with b ≤2 can be computed if b = 2 only for a constant number of
vertices. This also gives a new proof that the nucleolus for matching games can
be computed in polynomial time. For bounded weights and cost allocations, we
showed that LSA-MinExcess can be solved in randomized polynomial time.
However, turning this into an algorithm to compute the nucleolus for instances
with bounded weights would require a strong bound on the bit complexity of
the b-matching nucleolus. We are not aware of any such bound.
We also provided insights into LSA-MinExcess for general monotone games,
including a reduction to MinExcess that incurs an arbitrarily small error, which
is best possible. The nucleolus, however, was shown to be very unstable under
slight changes in the value function.
