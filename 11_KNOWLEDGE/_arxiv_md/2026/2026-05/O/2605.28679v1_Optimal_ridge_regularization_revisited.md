Optimal ridge regularization revisited
Jack Timmermans and Sergio A. Alvarez
Abstract—We consider L2-regularized linear (ridge) regression over a finite data sample X with bounded covariance and linear
prediction targets y with additive isotropic noise of finite variance. We present an iterative procedure to compute the optimal regularization
strength numerically from the generative parameters in the fixed-X setting and prove its convergence at limited noise levels. Our
experimental evaluation over synthetic data shows that the proposed procedure combined with sample-based parameter estimates attains
near-optimal random-X generalization across a wide range of sample sizes, aspect ratios, and noise levels, at an added computational
cost equivalent to one preliminary ridge regression in the underparameterized regime and two in the overparameterized case.
Index Terms—Supervised learning, statistical learning, hyperparameter optimization, regularization, generalization.

Optimality of model-based fixed-point Algorithm 2
As a preliminary step, we verified that the regularization
strength returned by the fixed-point approach in Algorithm 2

4.2.3
Regularization approaches considered
We compared the following techniques for computing the
ridge regularization strength:
Optimal regularization as determined by numerical opti-
mization: We used the value λmin returned by the minimize
function in scipy.optimize for the mean squared predic-
tion error over the test sample. This value may overfit the
test sample, and occasionally yields test error rates below the
ϵ2 noise variance lower bound in Eq. 8; while unattainable
out of sample, it nonetheless provides an aspirational ideal.
Optimal model-based regularization using the true gen-
erative parameters θ, ϵ: We used the value λfp returned by
Algorithm 2, based on a fixed-point iteration solution of the
first-order analytical stationarity condition of Eq. 9.
Sample-based regularization using our proposed technique,
Algorithm 3: We used the value λsfp returned by Algorithm 3.
This approach is based on estimation of the generative noise
standard deviation ϵ using Eqs. 14, 15 and of the label-
generative parameter θ using a preliminary ridge estimate.
A sample-based version of the signal-to-noise approach
of [9]: We used the value λSN = d ˆϵ2/∥ˆθ∥2 from section 2

4.5.3
Suboptimality of the signal-to-noise approach
The model-based signal-to-noise regularization strength
λSN = d ϵ2/∥θ∥2 of [9] would provide strong generaliza-
tion if used with the true generative parameter values
ϵ = 1, ∥θ∥= 1 used in Table 5: the resulting strength λSN = d
lies within the confidence interval for the optimal strength
λmin for the larger sample sizes N = 100, 500, and remains
close to that interval for the smaller size N = 20.
In the sample-based context, the signal-to-noise approach
suffers from its sensitivity to the ridge-estimated parameter
norm, ∥ˆθ∥: Table 6 shows that the latter values are much
higher (though less so than an unregularized estimate) than
the true norm of 1, yielding λSN values far below optimal.
Using a positive exponent p = 0.25 in the regularized
rank computation of Eq. 14 compensates somewhat by
increasing the estimated noise level ˆϵp, slightly raising the
estimated signal-to-noise ratio d ˆϵ2/∥ˆθ∥2. This effect is minor,
however: the regularized rank rp is only ≈20% smaller than
the nominal rank d at higher sample sizes (Table 6), not nearly
enough for the resulting larger ˆϵp to offset the excess in the
∥ˆθ∥norm estimate, yielding small regularization strengths
λSN and weaker generalization for λSN in Table 4.

prove that the proposed technique converges for sufficiently
small values of the noise variance. We further propose an

Fig. A.5 provides a wide view of the behavior of out-of-
