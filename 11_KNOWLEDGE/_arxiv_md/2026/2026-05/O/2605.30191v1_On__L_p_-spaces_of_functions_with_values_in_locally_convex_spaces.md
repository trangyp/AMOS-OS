On Lp-spaces of functions with values in locally convex spaces
Matthieu F. Pinaud1, Humberto Prado
Abstract
We study Lusin-measurable functions with values in locally convex spaces. In particular,
the behavior of pointwise limits of sequences of Lusin-measurable functions and exhibit
pathological phenomena arising in the nonmetrizable setting.
Moreover, we establish
approximation and density results for Lp-spaces constructed with this notion of measur-
ability, including the density of simple functions in Hausdorff locally convex spaces and
convergence results obtained through dyadic approximations.

Introduction
Let a < b be real numbers. We consider the closed interval [a, b] endowed with its Borel
σ-algebra B([a, b]) and the restriction of the Lebesgue measure λ. For a real Banach space E,
the classical theory of Lebesgue spaces Lp([a, b], E) of vector-valued functions is well under-
stood via Bochner-measurability. However, many problems in infinite-dimensional analysis,
particularly in the theory of infinite-dimensional Lie groups (see e.g. [4, 5, 6, 7, 8]), require
working in the context of locally convex spaces.
If E is a real locally convex space and E′ its topological dual space, we can define different
notions of measurability for a function γ : [a, b] →E
a) The function γ is Borel-measurable if γ−1(A) ∈B([a, b]) for each A ∈B(E).
b) The function γ is Lusin-measurable if for each ε > 0 there exists a compact subset Kε
of [a, b] such that γ|Kε is continuous and λ ([a, b] \ Kε) ≤ε.
c) The function γ is strongly-measurable if it is the pointwise limit a.e. of a sequence of
simple functions (βn)n.
d) The function γ is weakly-measurable if for each f ∈E′, the function f ◦γ : [a, b] →R
is Borel-measurable.
In the classical setting, when E is finite-dimensional, all four notion are equivalents. If E is
any second countable topological vector space, by the Lusin’s Theorem, Borel-measurability
implies Lusin-measurability (see e.g. [2, 12]). If E is a Banach space, by the Pettis Measura-
bility Theorem (see [2]), a function is strongly-measurable if and only if it is separably valued
and weakly-measurable. When E is a not-metrizable locally convex space, all these notion
are not equivalents since locally convex spaces introduce several pathologies that do not arise
in the Banach setting. For instance, the sum of two Borel-measurable functions may fail to

For the Fr´echet

Borel-measurability. In the locally convex setting, several authors have studied the construc-
tion of Lp-spaces using Lusin-measurability (see e.g. [1, 3, 7, 8, 9]).
We divide this article into two parts. The first one focuses to the study of the pointwise
limit of a sequence of Lusin-measurable functions (γn)n and the condition under which the
pointwise limit is Lusin-measurable.
In the second part, for 1 ≤p < ∞, we focus on the Lp-space of Lusin-measurable functions.
We show some classical density, convergence results and we exhibit a pathology where the
convergence in Lp does not imply any kind of pointwise convergence, in contrast with the
classical theory. Moreover, for each Lp-function is limit of a sequence of simple function given
by the dyadic partition.
In this article, we assume all locally convex spaces are real vector spaces and not necessary
Hausdorff. For details of locally convex spaces, we refeer the reader to e.g. [6, 10]. Let us
consider the real-valued function g : [0, 1] →[a, b], g(t) = a + t(b −a). By Lemma 2.15 of [7],
if γ : [a, b] →E is Lusin-measurable, the function γ ◦g : [0, 1] →E is Lusin-measurable. This
enables us to work simply with the closed interval [0, 1].

Lusin-measurable functions
Let E and F be locally convex spaces. If γ : [0, 1] →E is a continuous function, then it is
straightforward that γ is Lusin-measurable. If φ : E →F is continuous, then φ◦γ : [0, 1] →F
is Lusin-measurable. Moreover, it is shown in [7] that if γ, η : [0, 1] →E are Lusin-measurable
functions, then (γ, η) : [0, 1] →E ×E is Lusin-measurable. Therefore, since E is a topological
vector space, for each α ∈R, the function
αγ + η : [0, 1] →E,
t 7→αγ(t) + η(t)
is Lusin-measurable.
Moreover, if γ : [0, 1] →E is Lusin-measurable, then it is weakly-measurable. Indeed, for
each ε > 0 and f ∈E′, there exists a compact subset Kε of [0, 1] such that λ([0, 1] \ Kε) < ε
and (f ◦γ)|Kε = f ◦(γ|Kε) is continuous. Then f ◦γ : [0, 1] →R is Lusin-measurable, then
it is Borel-measurable.
