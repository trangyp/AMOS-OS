On continuous isomorphisms from σ-compact paratopological
groups onto topological groups
Tayomara Borsich and Pedro J. Chocano
Abstract
In this short note we give a negative answer to the following open question: Let X be
a σ-compact paratopological group. Does there exist a continuous isomorphism of X onto
a topological group G? Specifically, we construct a family of σ-compact paratopological
groups for which a continuous isomorphism onto a topological group G exists if and only
if G carries the trivial topology.
1
Introduction
Alexandroff spaces, and in particular finite topological spaces, have proved to be very useful
tools for addressing problems of diverse nature in mathematics. For instance, shape theory
can be described by means of inverse sequences of finite topological spaces [7]. Moreover,
several realization problems for algebraic structures via topological spaces have been answered
positively (see, for example, [4, 5, 6] and the references therein).
Recently, in [3], the authors considered Alexandroff topologies on groups and proved that
no non-trivial topological group admits such a structure unless the topology is either trivial
or discrete. This motivated the study of a broader context: paratopological groups, that is,
groups endowed with a topology for which the multiplication is continuous, while the inversion
need not be. In this setting, non-trivial examples do exist. In that paper, the authors also
investigated several properties of these spaces and discussed two open problems in the theory
of paratopological groups, illustrating how Alexandroff spaces can be used to clarify certain
questions within the theory.
The aim of this short note is to address the following natural question posed in [1, Chap-
ter 2, Open Problem 2.3.1]:
Let G be a σ-compact paratopological group. Does there exist a continuous iso-
morphism of G onto a topological group?
We construct a family of σ-compact paratopological groups with the property that, when-
ever a continuous isomorphism onto a topological group exists, the latter must necessarily

Preliminaries
For basic information on Alexandroff spaces we refer the reader to [8, 2]. The results recalled
below can be found in greater detail in those references.
Definition 2.1. An Alexandroff space is a topological space in which arbitrary intersections
of open sets are open.
Let X be an Alexandroff space. For each x ∈X, denote by Ux the intersection of all
open sets containing x; this is the smallest open neighbourhood of x. Similarly, let Fx be the
intersection of all closed sets containing x, which is the smallest closed neighbourhood of x.
Given two points x, y ∈X, declare x ≤y if and only if Ux ⊆Uy. It is straightforward to
verify that this relation is a preorder. Moreover, if X is a T0-space, then the above relation is
a partial order on X.
Conversely, if (X, ≤) is a partially ordered set, then the collection of lower sets forms a basis
for an Alexandroff topology on X, which is T0. These two constructions are mutually inverse.
Therefore, there is a one-to-one correspondence between partial orders and Alexandroff T0
topologies on a set X. If f : X →Y is a map between Alexandroff T0 spaces, then f is
continuous if and only if it is order-preserving. Hence:
Theorem 2.2. The category of partially ordered sets and the category of Alexandroff T0
topological spaces are isomorphic.
From now on, we assume that every Alexandroff space is T0, and we do not distinguish
between an Alexandroff space and its associated partial order. In particular, we freely use
order-theoretic notation. For instance,
Ux = {y ∈X : y ≤x}
and
Fx = {y ∈X : y ≥x}.
Given an Alexandroff space X, the Hasse diagram of X is the directed graph whose vertices
are the points of X, with a directed edge from x to y whenever x < y and there is no z such
that x < z < y. In the diagrams appearing below, we omit arrow orientations and assume an
upward orientation.
For an introduction to the theory of topological groups and paratopological groups we
refer to [1].
Definition 2.3. Let G be a group endowed with a topology. We say that G is a topological
group if:
1. the multiplication map m: G × G →G is continuous, and
2. the inversion map Inv: G →G is continuous.

Alexandroff paratopological group.
Proof. We first verify that the multiplication map m: Xn × Xn →Xn is continuous. This is
equivalent to showing that m is order-preserving. Suppose
((a, b), (c, d)) ≤((x, y), (z, w)).
Then (a, b) ≤(x, y) and (c, d) ≤(z, w). There are four cases to consider:
1. If a <u x and c <u z, then clearly a + c <u x + z, and hence
m((a, b), (c, d)) = (a + c, b + d) ≤(x + z, y + w) = m((x, y), (z, w)).
2. If a = x, b = y, c = z and d = w, the claim is immediate.
3. If a <u x, c = z and d = w, then a + c <u x + z, and the desired inequality follows.

We now show that the only open neighbourhood of f(a, b) is the whole space whenever
a ̸= 0. Assume without loss of generality that (−a, b−1) < (a, b). Then (−a, b−1) ∈U(a,b), so

If (a, b) satisfies a = 0, then U−1
