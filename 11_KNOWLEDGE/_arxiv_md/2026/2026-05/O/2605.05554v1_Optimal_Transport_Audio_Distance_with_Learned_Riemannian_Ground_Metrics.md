Optimal Transport Audio Distance with Learned
Riemannian Ground Metrics
Wonwoo Jeong∗
Sogang University
Abstract
In audio generation evaluation, Fréchet Audio Distance (FAD) is a 2-Wasserstein
distance with structural constraints for both primitives: the cost is a frozen em-
bedding pullback whose invariance set hides severe artifacts, and the coupling
is a Gaussian fit that dilutes rank-1 contamination relative to discrete OT. We
propose Optimal Transport Audio Distance (OTAD), which corrects each primitive
with one dedicated mechanism—a residual Riemannian ground-metric adapter for
the cost and entropic Sinkhorn optimal transport for the coupling. Across eight
encoders under a four-axis protocol, coupling-only comparisons at ε=0.05 show
that Sinkhorn’s rank-1 sensitivity exceeds FAD’s by a factor of 1.9 to 3.6. Fur-
thermore, OTAD achieves a higher mean Spearman correlation with audio-quality
MOS (DCASE 2023 Task 7) than baseline metrics. As an intrinsic benefit of the
discrete transport plan, OTAD yields per-sample diagnostics with AUROC ≥0.86,
a capability that scalar- or kernel-aggregated metrics structurally lack.

Introduction
Text-to-audio (TTA) synthesis [25, 28] has matured to the point where most generated samples are
perceptually adequate; user experience is now determined by sparse extreme artifacts—a misplaced
click, a tonal break, a repeated motif. Evaluation metrics must therefore possess micro-level dis-
criminability: the ability to detect rare but consequential quality failures. Fréchet Audio Distance
(FAD) [22], the dominant audio metric, was designed for distributional comparison and is structurally
insensitive to such artifacts.
We adopt a unifying viewpoint in which the FAD and Kernel Audio Distance (KAD) metrics are
instances of the 2-Wasserstein distance, specified by two primitives: a cost quantifying pairwise
dissimilarity between samples, and a coupling aggregating local matches into a global distance. FAD
restricts both: its squared Euclidean cost has an invariance set onto which severe artifacts project
to near-zero distance [21], and its Gaussian coupling dilutes rank-1 contamination by a spectrum-
dependent attenuation factor relative to discrete OT (Theorem 1). We propose Optimal Transport
Audio Distance (OTAD), which corrects each primitive with one dedicated mechanism.
Our contributions are threefold: (i) a Wasserstein two-primitive lens that locates FAD’s shortcomings
in cost-side invariance and coupling-side rank-1 dilution (Theorem 1, Proposition 1, and Proposition 2)
and exposes KAD’s residual cost-side restriction (Section 6); (ii) OTAD, the first audio metric to
correct both Wasserstein primitives—via a residual Riemannian ground-metric adapter on the cost
and entropic Sinkhorn optimal transport on the coupling—yielding per-sample diagnostics that scalar-
or kernel-aggregated alternatives structurally lack; (iii) systematic empirical validation across eight
encoders and a four-axis evaluation suite, providing an encoder-dependent factor decomposition and
recovering the predicted rank-1 attenuation. We release the resulting metric as otadtk2, serving as a
drop-in replacement for existing pipelines.

Related work
The standard pipeline for audio generation evaluation relies on frozen encoder representations. While
Inception Score [32] assesses samples intrinsically via classifier entropy, FID [19] and FAD [22]
established the paradigm of comparing generated and reference distributions. Recently, Kernel Audio
Distance (KAD) [5] relaxed FAD’s Gaussian fit via an MMD kernel [2]. Although these updates
primarily refine how distributions are compared, empirical critiques have probed the encoder side: [16]
compares embedding and reference-set choices for generative-music FAD across VGGish [17], CLAP
[34], MERT [27], EnCodec [9], and DAC [26], with sample-size correction and per-song diagnostics,
while we previously attributed FAD’s perceptual blind spots to an approximate invariance set
induced by the encoder’s training task, quantified along a four-axis recall/precision/semantic/structural
framework [21]; [29] reports analogous sensitivities in vision FID. These observations document that
the encoder-induced cost is the binding constraint, yet the cost function itself is left frozen.
The methodological tools to act on this constraint come from the optimal transport literature. Be-
yond the Bures-Wasserstein form [30] underlying FID/FAD, scalable couplings such as Sinkhorn
divergences [7, 11, 14], Wasserstein GANs [1], and sliced Wasserstein distances [23] relax distri-
butional assumptions while leaving the cost as given. The decisive perspective for our setting is
ground metric learning [8], which formalises learning the cost itself from data, but it has remained
largely unexplored for audio evaluation. OTAD is designed precisely to bridge this gap : a learned
Riemannian adapter on top of the cost-defining frozen encoder is composed with discrete entropic
optimal transport on the coupling.

4
Method
4.1
Cost primitive: a Riemannian ground-metric adapter
Building on the ground-metric learning framework [8], we bridge deep learning and measure
theory by learning a residual adapter gθ(z) = z + fθ(z) [18] that yields the corrected cost
cθ(x, ˜x) = ∥gθ(Φ(x)) −gθ(Φ(˜x))∥2. This parameterization induces a linear chain of mathemati-
cal identities: the residual fθ perturbs the Euclidean identity to define a local Riemannian metric
Mθ(z) = Jθ(z)⊤Jθ(z) (Proposition 1), while the Jacobian factor | det Jθ(z)|−1 implements the
pointwise density reweighting that compensates for local volume changes under the map (Proposi-
tion 2). By coupling control of local distances and density, OTAD restructures the embedding space
to expose rare artifacts invisible to the frozen backbone.

Two-track adapter training
All encoders are frozen; only the lightweight adapter (∼d2/2 parameters per encoder) is trained on
FSD50K [12] (200 classes, ∼37k clips). We maintain two adapter variants to serve distinct purposes.

gnative reshapes the embedding space to specifically favour the Sinkhorn coupling and is therefore
reserved for maximum-performance evaluation rather than for fair decomposition.

Experiments
5.1
Experimental setup
We train adapters on the FSD50K train split (200 classes, ∼37k clips) and evaluate on ESC-50 [31]
(50 classes, 2,000 clips); no ESC-50 clips are used during training. Five primary encoders span
d∈{128, 512, 768, 2048}—VGGish [17], EnCodec [9], CLAP [34], AudioMAE [20], PANNs [24]—
with OpenL3, AST, BEATs supplementing in Appendix B.4 (full specs: Table 2, Appendix B.1). Each
adapter is a residual MLP (d →d/4 →d, LayerNorm, GELU, dropout 0.1), trained per encoder; the
metric and adapters are released as otadtk (Appendix B.6).
Evaluation follows our four-axis protocol [21] on ESC-50 (R = all 2,000 clips): recall (same-
class different instances, averaged over 5 draws), semantic (ε-fraction cross-class replacement),
precision (additive Gaussian noise at controlled SNR), and structural (temporal segment shuffling
with crossfade), each designed to stress a specific encoder weakness.

5.2
Outlier sensitivity under rank-1 contamination
We begin with the cleanest possible probe of the coupling primitive: we hold the cost function fixed
(no adapter, raw encoder embedding) and vary only the coupling. This isolates Primitive 2 from any
cost-side effect and directly tests Theorem 1, providing the empirical baseline against which the joint
cost-coupling factor decomposition in Section 5.3 can be interpreted. We contaminate ESC-50 at rates
ε ∈{0.005, 0.01, 0.02, 0.05, 0.1, 0.15, 0.2} under two conditions. In the full-rank condition, each
outlier is independent Gaussian noise, spreading energy across all eigenvalues so that the covariance
trace increases uniformly. In the rank-1 condition, all outliers are the same point µ + 5σ · v1 along the
first principal component, concentrating energy on a single eigenvalue. Four metrics are compared:
FAD (Gaussian coupling), KAD (MMD kernel), Sinkhorn divergence, and Exact OT via a network
simplex solver [30], serving as the ground-truth reference.
Under full-rank contamination, all three OT-based metrics agree to within 0.2% after self-
normalisation [21] (each metric divided by its full-rank response at ε=0.20): when outlier energy is
isotropic the Gaussian assumption introduces no measurable bias and the choice of coupling method
is irrelevant.
Rank-1 contamination tells a dramatically different story. Figure 1(a) plots log10(Sinkhorn/FAD)
on PANNs (d=2, 048): each metric’s rank-1 response is normalised by its own full-rank baseline
at ε=0.20 before taking the ratio, and the shaded band marks the realistic TTA regime (ε ≤0.05)
where mode-collapse contamination is most plausible. In this regime FAD lies an order of magnitude
below Sinkhorn, narrowing to a 1.3−1.9× gap only as ε ≥0.15 when both metrics partially recover.
Panel (b) fixes ε=0.05 and reports R1/FR ratios across all eight encoders: Sinkhorn dominates FAD
on every encoder and the multiplicative gap broadens with embedding dimension, consistent with the
spectrum-dependent FAD/W 2
2 attenuation predicted by Theorem 1 (the encoder spectra in our suite
become longer-tailed at higher d, lowering the L2/T factor that bounds FAD’s relative response),
while Sinkhorn remains aligned with discrete OT up to regularisation slack. KAD fares no better
here: for ε ≤0.05 its values fluctuate around zero, indistinguishable from noise, reflecting the
bounded-kernel surrogate ceiling Eq. (2). Per-encoder, per-ε values for all four metrics under both
contamination conditions are tabulated in Appendix B.5.
TTA mode collapse—where a model repeatedly generates the same artifact—approximates rank-
1 perturbation in embedding space, precisely the regime in which FAD’s Gaussian coupling is
structurally attenuated while Sinkhorn retains spectrum-independent coupling sensitivity relative to
discrete OT (Theorem 1). Replacing Gaussian coupling with Sinkhorn—OTAD’s design choice for
Primitive 2—directly closes this failure mode without invoking exact OT, which only serves as the
theoretical ceiling on what any coupling-based metric can achieve.

5.3
Factorial decomposition of cost and coupling effects
Section 5.2 fixed the cost function and showed that the coupling primitive alone produces a clear
dimension-dependent signal under rank-1 contamination. We now lift the cost-fixed restriction and
ask the central design question: does OTAD’s improvement over FAD come primarily from the cost
correction (adapter), the measure correction (Sinkhorn), or their interaction? We design a 2 × 2
factorial experiment with two binary factors: cost function (original Φ vs. adapted gθ ◦Φ) and
coupling method (Gaussian vs. Sinkhorn OT). This yields four conditions: (A) FAD baseline (Φ,
Gaussian), (B) measure-only (Φ, Sinkhorn), (C) cost-only (gθ ◦Φ, Gaussian), and (D) full OTAD
(gθ ◦Φ, Sinkhorn). All four conditions use gagnostic to ensure unbiased decomposition (Section 4.3).

would be misleading. We apply a log-normalisation Snorm(x) = log(1+x)/ log(1+xmax) separately
within each metric family (FAD for conditions A,C; Sinkhorn for B,D), mapping all values to [0, 1].

5.4
Per-sample diagnostics
Beyond aggregate distributional comparison, OTAD provides per-sample diagnostic information
through the transport costs cj defined in Eq. (7). We validate this capability through controlled con-
tamination experiments on ESC-50; alignment with human judgement is then taken up in Section 5.5.
Starting from the clean reference (N=2,000), we contaminate an ε-fraction of samples with three
types of artifacts: Gaussian noise, cross-class replacement (real audio from wrong categories), and
silence insertion. For each contaminated distribution, we compute cj for every sample and evaluate
whether contaminated samples receive systematically higher costs using AUROC and the separation
ratio (mean contaminated cost / mean clean cost).
At ε=0.05, all five encoders achieve perfect detection on the Gaussian-noise and silence settings
(AUROC=1.0), with separation ratios spanning up to five orders of magnitude across encoders.
Cross-class replacement is the most challenging case because the contaminating samples are real,
well-formed audio that differs from the reference only in semantic content; even here, AUROC
remains in [0.86, 1.00] across encoders. Figure 3 visualises the underlying cj distributions per
encoder, normalised so the clean median sits at 1: the contaminated boxes shift consistently above the

5.6
Analysis of Design and Efficiency
The two-track training strategy is validated by comparing gagnostic and gnative under the same 2 × 2
decomposition (full results in Appendix B.2). With gnative, every encoder switches to cost dominance
and the Sinkhorn divergence collapses far more than FAD does, confirming that gnative reshapes the
embedding to minimise the Sinkhorn coupling and is therefore unsuited for fair 2 × 2 separation. The
Sinkhorn regularisation εreg has a sweet spot in [0.05, 0.10] (sweep details in Appendix B.5); below
this range the solver iterates without gain, whereas above 0.5 entropy overwhelms cost information.
Counterintuitively, for N ≤2,000, Sinkhorn is an order of magnitude faster than FAD on a standard
GPU (FAD is CPU-bound by sqrtm), with mini-batch or sliced OT extending this scalability to larger
datasets.

6
Discussion
The same decomposition that pins down FAD’s failures (Section 3) places KAD [5] between FAD
and OTAD in our two-primitive lens: replacing the Gaussian coupling with an MMD kernel removes
the parametric coupling assumption (KAD is the high-regularisation limit of entropic OT [11, 14]),
but the bounded RBF kernel inherits the encoder invariance set IΦ — for nearby points its induced
RKHS distance behaves like ∥Φ(x) −Φ(˜x)∥/σ, yet saturates at a finite ceiling for distant points —
producing a noise floor that prevents matching discrete-OT sensitivity under rank-1 contamination.
The empirical signatures are the rank-1 noise floor of Section 5.2 and the per-category MOS collapse
of Section 5.5. OTAD therefore corrects the primitive that KAD leaves untouched while subsuming
the coupling-side benefit of MMD as a regularisation limit.
7
Limitations and future work
Our human-MOS validation rests on a single listening test (DCASE 2023 Task 7 Foley, n=9 systems
and n=63 system-category cells) and does not include music or speech generative benchmarks; the
magnitude of OTAD’s perceptual gain in those domains has not been measured, and the small system
count bounds the statistical power available to separate metric variants. All adapters are trained on
FSD50K (200 environmental-sound classes), which biases the cost-side correction towards general
audio, and we do not provide cross-domain evidence that the same adapter generalises—or that re-
trained adapters preserve their cost-side advantage—to music, speech, or specialised audio domains.
Likewise, our encoder coverage spans eight general-audio backbones but excludes music-domain
backbones such as MERT and DAC [26, 27]; whether OTAD retains its cost-side advantage on
music-specialised representations is open.
The residual adapter cannot recover information already discarded by the encoder’s null space:
EnCodec is the empirical witness, with MOS correlation remaining weak across both axes (ρ ∈
[−0.21, 0.07]) under every metric including OTAD, confirming that distance-side correction has
fundamental ceilings dictated by the upstream representation. On the coupling side, naive entropic OT
becomes memory-bound beyond ∼5,000 samples, so mini-batch, sliced, or low-rank approximations
are needed at larger scales. Theorem 1 also formalises only the rank-1 stress test: the FAD/W 2

is bounded by an effective-rank factor L2/T = c2

the empirical 1/d-like attenuation in Figure 1 is mediated by encoder spectra and may not extrapolate
to backbones with markedly different effective ranks; multi-mode or correlated artifacts likewise lie
outside this model.
Future work should extend the MOS validation to music and speech domains, and to music-specialised
encoders such as MERT and DAC, to test the generality of the cost-side advantage, while sequence-
level OT models and scalable approximations are needed to handle correlated artifacts and larger
evaluation scales.
8
Conclusion
We introduced a two-primitive lens for audio evaluation, showing that FAD suffers from both
an encoder-invariant cost that blinds it to artifacts and a Gaussian coupling that dilutes rank-1
contamination by a spectrum-dependent factor (Theorem 1). KAD relaxes the coupling but inherits
the same frozen cost. OTAD corrects each primitive directly: a residual Riemannian adapter learns a
local cost that escapes encoder invariances, while Sinkhorn entropic optimal transport preserves the
spectrum-independent sensitivity of discrete OT.
This dual correction recovers discrete-OT-grade rank-1 sensitivity, supplies per-sample diagnostics
(AUROC ≥0.86) that scalar- and kernel-aggregated metrics structurally lack, and achieves the
highest MOS correlation on DCASE 2023 Foley — at fine granularity where KAD collapses below
FAD, OTAD remains stable. A factorial decomposition across eight encoders shows that cost
correction is the dominant lever at low dimensions, that measure correction alone is never sufficient,
and that a learned synergy emerges at higher dimensions. The two-primitive lens and the residual
adapter design together provide a modality-independent blueprint for any FID-style evaluation. For
audio, the released otadtk toolkit serves as a drop-in replacement.

B.3
Reproduction note: KAD bandwidth and the PANNs-CNN14 vs. PANNs-WGLM gap
The KAD paper [5] reports its strongest correlation numbers using PANNs-Wavegram-LogMel-
Cnn14 (henceforth PANNs-WGLM), a variant distinct from the PANNs-CNN14 checkpoint that has
been the de facto PANNs encoder in the FAD/audio-evaluation literature. While preparing Section 5.5
we observed that KAD’s correlation collapse is sharper on PANNs-CNN14 than the original paper
suggests, and traced the discrepancy to two sources: (i) the PANNs backbone, and (ii) the bandwidth
heuristic. We document both here so that the comparison in Figure 4 is reproducible and so that
practitioners adopting KAD can avoid the pitfall.
(i) Bandwidth heuristic.
KAD uses an MMD2 with a Gaussian RBF kernel kσ(x, y) =
exp(−∥x −y∥2/(2σ2)) whose bandwidth σ is selected by the median heuristic. There is, how-
ever, a meaningful implementation choice: the median can be computed over (a) the union
of reference and test embeddings, or (b) the test (eval) set only.
We initially used (a), the
more common median-of-pooled-pairwise-distances rule. The reference kadtk library accom-
panying [5] uses (b), σ = median{∥yi −yj∥: i ̸= j} over eval embeddings only.
We
aligned with (b) for all numbers in the main paper; the change improves KAD’s audio-quality
correlation on PANNs-WGLM (system-level ρ rising to 0.73 at n=9 under variant (b), sub-
stantially above the value obtained with variant (a)) and is neutral or mildly favourable on the
other encoders. To rule out lingering implementation drift, we additionally cross-checked our
compute_kad against kadtk.calc_kernel_audio_distance on shared random embeddings
spanning d ∈{128, 512, 2, 048}: the two functions agree exactly in float32 at d≤512 and within
relative error 7 × 10−5 at d=2, 048 (script: scripts/verify_kadtk_equivalence.py), so any
remaining KAD discrepancy from [5] reflects dataset/preprocessing choices rather than the metric
implementation.
(ii) Backbone gap. Even with the corrected heuristic, KAD’s correlation depends strongly on the
PANNs variant. Table 4 contrasts the two backbones on the audio-quality axis. At system-level,
PANNs-WGLM and PANNs-CNN14 produce identical FAD and comparable OTAD numbers, but
KAD on CNN14 (0.48) lags KAD on WGLM (0.73) by +0.25 Spearman—a backbone-specific gain
that is not shared by FAD (0.80 on both backbones) or OTAD (0.85 on CNN14, 0.82 on WGLM).
At per-category granularity the picture inverts modestly: KAD on WGLM (0.39) edges KAD on
CNN14 (0.37), but both fall well below FAD (0.45 and 0.54) and OTAD-agnostic (0.67 and 0.63).
This pattern is consistent with our two-primitive analysis: KAD’s coupling-side improvement is real
but operates only over the cost geometry it inherits from the encoder, so its perceptual alignment is
genuinely backbone-dependent in a way the cost-and-coupling-corrected OTAD is not.

The otadtk reference toolkit
We release otadtk, a Python package distributed under the CC BY 4.0 licence that implements
OTAD with the same install-and-go ergonomics as fadtk [16] and kadtk [5]. The package ships nine
pretrained Riemannian adapters (one per registered encoder model, including distinct PANNs-CNN14
and PANNs-WGLM checkpoints), an embedding cache shared with kadtk’s on-disk layout, and a
CLI that exposes OTAD, FAD and KAD behind a uniform interface so practitioners can swap metrics
with a single flag. The source code is publicly available at https://github.com/wonwoo-jeong/
otadtk.
Installation & self-containment. The wheel bundles all nine × two adapter checkpoints under
otadtk/checkpoints/, totalling ≈43 MB, so a fresh install runs end-to-end with no network
access; the bundled SHA-256 hashes are recorded in checkpoints/MANIFEST.json for repro-
ducibility audits.
pip install otadtk
# 38MB wheel, 18 adapters bundled
pip install "otadtk[all-encoders]"
# adds transformers, encodec, openl3
python -m pytest tests/
# 7 smoke tests, no GPU/network needed
Command-line. The CLI mirrors kadtk’s positional triple (model, ref_dir, eval_dir) and
adds three OTAD-specific flags—–variant, –epsilon, and –diagnose:
otadtk panns ref/ eval/
# OTAD-agnostic
otadtk panns ref/ eval/ --variant raw --epsilon 0.05
# raw OTAD
otadtk vggish ref/ eval/ --diagnose --diag-out cj.csv
# per-sample c_j
otadtk panns ref/ eval/ --indiv per_file.csv
# per-file CSV
otadtk panns ref/ eval/ --fad
# FAD baseline (same encoder/cache)
otadtk panns ref/ eval/ --kad
# KAD baseline (kadtk-aligned bandwidth)
otadtk-embeds -m vggish -d ref/ eval/
# cache only
otadtk-list-models
# registered encoders
Python API.
from otadtk import OTAD
otad = OTAD(model="panns_wglm", variant="agnostic", epsilon=0.10)
score = otad.score("ref/", "eval/")
diag = otad.diagnose("ref/", "eval/")
# diag.cj, diag.files
print(diag.top_k(10))
# worst-offender listening list
diag.to_csv("cj.csv")
# per-file CSV (file,cj)
auroc = diag.auroc(contaminated_mask)
# ground-truth AUROC if labelled
otad.score_individual("ref/", "eval/", csv="per_file.csv")
Reproducibility. The same otadtk call reproduces every cell of Tables 5–10; we also ship the
raw run_exp1_factorial.py and eval_dcase2023task7.py drivers used to generate Figure 1,
Table 1, the per-sample diagnostics in Section 5.4, and the MOS correlations in Section 5.5. SHA-256
hashes for every bundled checkpoint are recorded in otadtk/checkpoints/MANIFEST.json so
readers can audit that the running adapter matches the one we trained.
Hosting plan. Development and releases are maintained on GitHub (https://github.com/
wonwoo-jeong/otadtk); the package is also available on PyPI (pip install otadtk). We
intend to archive a versioned artefact snapshot on Zenodo with a DOI.
