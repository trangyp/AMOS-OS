Abstract
The main result of the paper is Theorem 3, which states that for any self-affine dendrite
K, generated by a polygonal system, there are constants C > 0 and λ ∈(0, 1) such that for
any x, y ∈K, the Jordan arc γ ⊂K with endpoints x, y satisfies inequality diam(γ)
∥x −y∥λ ≤C.
In 2017 [6] it was proved that if a self-similar dendrite K ⊂R2 is generated by a system
of convex polygons, then K is a continuum with C-bounded turning [8]. That is, there is a
constant C > 0 such that for any x, y ∈K, the Jordan arc γ ⊂K with endpoints x, y satisfies
the inequality diam(γ)
∥x −y∥≤C. This statement is not valid for self-affine dendrites in R2, even if
they are generated by a system of convex polygons.

The SIP and self-similar boundary. The system S has the single-point intersection property
(SIP) if, for any pair Ki, Kj of the copies of the attractor K, the intersection Ki ∩Kj is either
empty or is a singleton {Aij}. The set of all intersection points Aij is denoted by C.
The set of all x ∈K such that for some i ∈I∗, Si(x) ∈C, is called the self-similar boundary
∂K of the set K.
Note that if the system S has the SIP, then for any two incomparable multiindices i, j ∈I∗the
intersection Ki ∩Kj is empty or is a singleton.

Definition 1. A dendrite is a locally connected continuum that does not contain simple closed
arcs.
The following criterion that was proved in [7] makes it possible to distinguish self-similar
dendrites that have the single-point intersection property.
Theorem 1. Let S = {S1, . . . , Sm} be a system of injective contractions in Rn. If the attractor
K = K(S) has the single intersection property and the bipartite intersection graph bG(S) of the
system S is a tree, then K is a dendrite.

Polygonal systems
Extending the idea of the paper [6] to the self-affine case, we introduce the construction that
produces a wide variety of self-affine dendrites possessing the SIP; we prove the remarkable
metric properties of such dendrites.

The main Theorem
An arc γ is called a t-quasi-arc, t > 1, if there is a constant K > 0 such that for every x, y ∈γ
the subarc γ(x, y) satisfies the inequality (diam(γ(x, y)))t ≤K∥x −y∥.
The main result of the paper is that in the case of affine polygonal system S there is
λ ∈(0, 1) such that for any two points x, y in its attractor K, they can be connected by a
1/λ-quasiarc [5],[9].
It is essential that the polygon P in the definition of the system is required to be convex,
because even in the self-similar case there is the example of a self-similar arc K which is the
attractor of a polygonal system with a non-convex polygon P and which is not a t-quasiarc for
any t ≥1.[9, 2].
