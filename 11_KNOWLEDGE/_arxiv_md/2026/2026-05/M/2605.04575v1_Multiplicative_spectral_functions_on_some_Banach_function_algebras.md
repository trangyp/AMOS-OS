MULTIPLICATIVE SPECTRAL FUNCTIONS ON SOME BANACH
FUNCTION ALGEBRAS
NAHID BAYATI AND FERESHTEH SADY
Abstract. In this paper, we study multiplicative functions φ: A →C on a
natural Banach function algebra A on a compact Hausdorff space X, such that
φ(f) ∈σ(f) for all f ∈A. It is shown that for certain natural Banach function
algebras A, either ker(φ) is a maximal ideal of A or 1 ∈span(ker(φ)) (that is
1 = f1 + f2 + · · · fn for some f1, ..., fn ∈ker(φ)). Then we investigate for the
linearity of φ in either of cases that φ is continuous or 1 /∈span(ker(φ). We show
that, for some natural Banach function algebras A, in either of these cases, there
exists a point x0 ∈X such that φ(f) = f(x0) for some family of functions f ∈A
(including those functions f ∈A that f ∈A). In particular, such a multiplicative
spectral function on some Banach algebras including C(X), Lipschitz algebras,
Banach algebras of absolutely continuous functions on [0, 1] and C1([0, 1]) is linear
and hence it is a character.
1. Introduction
For a unital complex Banach algebra A, let G(A) be the group of all invertible
elements of A, G1(A) be the principle component of G(A) and exp(A) be the subset
{ea : a ∈A} of G1(A). Given a ∈A, let σ(a) denote its spectrum. We say that
a function (not necessarily linear) φ: A →C on a Banach algebra A is spectral,
if φ(a) ∈σ(a) for all a ∈A. By the classical Gleason-Kahane- ˙Zelazko theorem,
any complex-linear spectral function φ: A →C on a unital Banach algebra A is a
character on A. The Kowalski-S lodowski theorem [6] provides an additive version of
the Gleason-Kahane- ˙Zelazko theorem by showing that any complex function φ: A →
C that satisfies φ(a) + φ(b) ∈σ(a + b) for all a, b ∈A, is a character on A. Without
the linearity assumption, the following result has been proven by A. Maouche for
multiplicative spectral functions on a unital Banach algebra.
Theorem 1.1. [8] Let A be a (complex) unital Banach algebra and φ: A →C be
a multiplicative function such that φ(a) ∈σ(a) for all a ∈A. Then there exists a
unique character ψ on A such that ψ(a) = φ(a) for all a ∈G1(A).
The example given in [8] shows that the above multiplicative spectral function φ
is not necessarily linear. However, under the continuity assumption, there are some

concludes a result concerning the linearity of multiplicative spectral functions on the
Banach algebras such as C(X), Lipschitz algebras and also the Banach algebra of
all absolutely continuous functions on [0, 1]. The second theorem provides another
linearity result for some Banach function algebras such as C1([0, 1]). Our approach
is based on using peaking functions, strong boundary points and their properties in
uniform algebras and Banach function algebras.
2. Preliminaries
For a compact Hausdorff space X, we denote the Banach algebra of all continuous
complex-valued functions on X by C(X). The supremum norm of a function f ∈
C(X) will be denoted by ∥f∥X. A point separating subalgebra A of C(X) which
contains the constant functions is called a Banach function algebra on X if it is
a Banach algebra under some norm ∥· ∥. In the case that the norm of a Banach
function algebra A on X is the same supremum norm, we call it a uniform algebra

AC([0, 1]).

3. Main Result
Throughout this section, unless otherwise is stated, we assume that A is a natural
Banach function algebra on a compact Hausdorff space X. We put A+ = {f ∈
A : f ≥0}.
As we noted before, by a spectral function on A we mean a (not
necessarily continuous) function φ: A →C satisfying φ(f) ∈σ(f) for all f ∈A.
Clearly in this case we have σ(f) = f(X) for all f ∈A. By Theorem 1.1 for each
multiplicative spectral function φ: A →C there exists a unique point x0 ∈X such
that φ(ef) = ef(x0) for all f ∈A. We call x0 the associated point of φ.
We begin with the following proposition concerning the kernel of a multiplicative
spectral function on A.
Proposition 3.1. Let ch(A) = X and φ : A →C be a (not necessarily continuous)
multiplicative spectral function. Then the following statements hold.
(i) There exists a unique point x0 ∈X such that |φ(f)| ≤|f(x0)| for all f ∈A.
In particular, |φ(f)| = |f(x0)| for all f ∈G(A).
(ii) Either ker(φ) is a maximal ideal of A or 1 = f1 +· · ·+fn for some f1, ..., fn ∈
ker(φ).
(iii) In the case that A is a uniform algebra, we have φ(f) = f(x0) for all f ∈
G(A).
Proof. i) Let x0 ∈X be the associated point of φ, i.e. φ = φx0 on exp(A). We show
that |φ(f)| ≤|f(x0)| for all f ∈A. Given f ∈A and ϵ > 0, by Lemma 2.2, there
exists a function h ∈Px0(A) ∩exp(A) such that ∥fh∥X < |f(x0)| + ϵ. Choose a
sequence {hn} in exp(A) which uniformly converges to h. Then we have ∥fhn∥X <
|f(x0)| + ϵ for sufficiently large n ∈N. Clearly we have φ(hn) = hn(x0) →1. Hence,
using the spectral condition once again, we have
|φ(f)hn(x0)| = |φ(fhn)| ≤∥fhn∥X < |f(x0)| + ϵ,
for sufficiently large n ∈N.
Tending n →∞, since ϵ > 0 is arbitrary we get
|φ(f)| ≤|f(x0)|, as desired.
Now assume that f ∈G(A). Without loss of generality we assume that f(x0) = 1.
Since |φ(f)| ≤|f(x0)| = 1, |φ(f −1)| ≤|f −1(x0)| = 1 and φ(ff −1) = 1 we get
|φ(f)| = 1 = |f(x0)|.
The uniqueness property is immediate from the equality |φ(ef)| = eRe(f(x0)) for all

We note that, by the above argument, x0 is indeed, the same associated point to
φ, that is φ(ef) = ef(x0) for all f ∈A.
ii) Clearly, by part (i), we have φ(f) = f(x0) for all f ∈A with f(x0) = 0, that is

be applied to show that if G is a multiplicative subgroup of G(A) containing exp(A),
then for any multiplicative spectral function φ: G →C there exists a character ψ
on A such that φ(x) = ψ(x) for all x ∈G1(A). Then the proof of Proposition 3.1
(iii) yields the following corollary.
Corollary 3.9. Let A be a natural uniform algebra on a compact Hausdorff space X
with ch(A) = X, G be a subgroup of G(A) containing exp(A) and let φ : G →C be
a multiplicative function satisfying φ(f) ∈σ(f) for all f ∈G. Then φ is extended
to a character on A.
