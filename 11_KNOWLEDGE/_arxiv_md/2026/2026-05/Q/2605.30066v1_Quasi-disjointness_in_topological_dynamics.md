QUASI-DISJOINTNESS IN TOPOLOGICAL DYNAMICS
HUI XU AND XIANGDONG YE
ABSTRACT. Motivated by Berg’s notion of quasi-disjointness for ergodic systems, we
introduce and investigate the concept of quasi-disjointness for minimal systems. Several
equivalent characterizations are provided. We prove that quasi-disjointness is preserved
under taking factors, proximal extensions, and group extensions. As a consequence, we
establish that every minimal PI system is quasi-disjoint from all minimal systems. In ad-
dition, some variant of quasi-disjointness, namely strong quasi-disjointness is also intro-
duced and examined. Particularly, we prove that each AI system is strongly quasi-disjoint
from all minimal systems.
1. INTRODUCTION
A topological dynamical system (or simply a system) is a pair (X,T), where X is a
compact metric space and T is a homeomorphism on X. Given two systems (X,T) and
(Y,S), a joining of (X,T) and (Y,S) is an invariant closed subset of X ×Y that has full
projections onto both X and Y. If X ×Y is the only joining of (X,T) and (Y,S), then we
say that they are disjoint, denoted by X ⊥Y.
The notion of disjointness was introduced simultaneously in ergodic theory and topo-
logical dynamics by Furstenberg in his seminal paper [9]. In a sense, disjointness captures
a certain form of independence between two systems. In [9], two main open questions
regarding disjointness were raised: one asks for a characterization of systems that are
disjoint from all minimal systems, and the other for a characterization of those that are
disjoint from all distal systems. The second question was resolved by Peterson [24], who
showed that the class of systems disjoint from all distal systems consists precisely of the
minimal weakly mixing systems. Research on the first question has since attracted con-
siderable effort; see for example, [21, 19, 23, 13, 27] and the references therein. Recently,
G´orska, Lema´nczyk and de la Rue gave a characterization of measure preserving systems
that are disjoint from all ergodic systems [15], a result later reproved in a shorter way by
Glasner and Weiss [14]. In the work [18], the authors provide several intrinsic character-
izations of topological dynamical systems that are disjoint from all minimal systems.
Perhaps motivated by Furstenberg’s second question, Berg introduced the notion of
quasi-disjointness among ergodic systems in [4] and further properties of quasi-disjointness
are obtained in [5]. Recently, Moreira, Richter and Robertson generalize Berg’s definition
of quasi-disjointness to ergodic systems acted by countable groups [22]. In this paper, we
study quasi-disjointness in topological dynamical systems.

(1) If X ⊥Q Y then Z ⊥Q Y;

2. PRELIMINARIES
2.1. Basics on topological dynamical systems. A topological dynamical system (or sys-
tem for short) is a pair (X,T), where X is a compact metric space and T : X →X is a
homeomorphism on X. Throughout the paper, we use ρX (or ρ when there is no risk of
ambiguity) to denote the metric on X.
Let (X,T) be a system and x ∈X. The orbit of x is {T nx : n ∈Z}, which is denoted
by orbT(x) or orb(x). A system is topologically transitive (or transitive for short) if there
is some point whose orbit is dense and such a point is called a transitive point. A system
is minimal if the orbit of every point is dense. A point x ∈X is a minimal point if the
restriction of T on orbT(x) is a minimal subsystem.
Let (X,T) and (Y,S) be two systems. If there is a continuous onto map π : X →Y such
that π ◦T = S◦π, then we say that (X,T) is an extension of (Y,S) and (Y,S) is a factor of
(X,T). In this case, we also say that π is a factor map or a homomorphism. Further, if π is
one to one, then we say that (X,T) and (Y,S) are topologically conjugate or isomorphic.
Let (X,T) be a system. A pair (x,y) of points in X is said to be proximal if there is
a subsequence (ni) in Z such that ρ(T nix,T niy) →0 as i →∞. We use P(X) to denote
the set of proximal pairs in X. The system (X,T) is distal if every pair of distinct points
x,y ∈X are not proximal. (X,T) is equicontinuous if for every ε > 0 there is some δ > 0
such that ρ(T nx,T ny) < ε for every n ∈Z whenever ρ(x,y) < δ.
Let π : (X,T) →(Y,S) be an extension between two systems. If for every x1,x2 ∈X
with π(x1) = π(x2) are proximal then we say that π is a proximal extension. If for every
x1 ̸= x2 ∈X with π(x1) = π(x2) are not proximal then we say that π is a distal extension. If
for every ε > 0 there is some δ > 0 such that for every x1,x2 ∈X with π(x1) = π(x2), one
has ρ(T nx1,T nx2) < ε for every n ∈Z, then we say that π is an equicontinuous extension.
If the set {x ∈X : |π−1π(x)| = 1} is residual in X, then we say that π is an almost one to
one extension.

2.4. Disjointness and quasi-disjointness. Let (X,T) and (Y,S) be two systems. A join-
ing of (X,T) and (Y,S) is a T × S-invariant closed subset in X ×Y that projects onto
each coordinate. (X,T) and (Y,S) are disjoint if whenever there is a system (Z,R) with
φ : Z →X and ψ : Z →Y, then there is a homomorphism θ : Z →X ×Y such that φ = pXθ
and ψ = pYθ, where pX : X ×Y →X and pY : X ×Y →Y are projections. We then write
X ⊥Y. An equivalent characterization of disjointness is that X ⊥Y if and only if X ×Y
is the only one joining ([9, Lemma II.1]).
Two systems (X,T) and (Y,S) are weakly disjoint if (X ×Y,T ×S) is transitive, which
is denoted by X ⋏Y.
