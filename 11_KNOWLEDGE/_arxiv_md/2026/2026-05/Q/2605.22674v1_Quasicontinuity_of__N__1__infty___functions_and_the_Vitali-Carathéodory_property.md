Abstract.
This note is a follow up on our recent paper with L. Mal´y (to appear in
Rev. Mat. Complut.). We provide a simple example of a compact metric space P for
which L∞(P) has the Vitali–Carath´eodory property, the Sobolev C∞-capacity is an outer
capacity, but the Newtonian space N 1,∞(P) contains functions which are not weakly
quasicontinuous. The novelty here is that the Vitali–Carath´eodory property is satified.
We also obtain some related results about quasicontinuous functions in N 1,∞(P) and a
characterization of when L∞(P) has the Vitali–Carath´eodory property.
Key words and phrases: metric space, Newtonian space, outer capacity, quasicontinuity,
Sobolev capacity, upper gradient, Vitali–Carath´eodory property, weak quasicontinuity.

Introduction
This note is a follow up on our paper [1] (joint with L. Mal´y). We refer to that
paper for further discussion of the concepts in this note. We will provide some
rather simple but illuminating observations concerning capacity and quasicontinu-
ous functions in the Newtonian Sobolev space N 1,∞(P).
We assume throughout the note that P = (P, d, µ) is a metric measure space
equipped with a positive complete Borel measure µ such that 0 < µ(B) < ∞for
every ball B ⊂P. It follows that P is separable and Lindel¨of.
The following statements for the metric measure space P were studied in [1] in
the setting of Newtonian spaces based on general quasi-Banach function lattices:
(A) Every u ∈N 1,∞(P) is quasicontinuous.
(B) C∞is an outer capacity.

C∞is an outer capacity, i.e. (B) holds.

and other examples when they all hold.
In particular, we will see in Example 3.3 that the quasicontinuity properties (A),
(F) and (G) are not implied by the Vitali–Carath´eodory property. Thus, in some
sense, Theorem 1.1 (and [1, Theorem 1.5]) is sharp. Unlike all the counterexamples
in [1], this example has the Vitali–Carath´eodory property.
The Vitali–Carath´eodory property for L∞(P) can be characterized in the fol-
lowing way.
Proposition 1.3. The Vitali–Carath´eodory property for L∞(P) holds if and only
if µ({x}) > 0 for every x ∈P.
In particular, P has to be finite or countable.
When there are (L∞-almost) no nonconstant rectifiable curves in P, the fol-
lowing result gives some further equivalent statements to the Vitali–Carath´eodory
property. Some statements about (weak) quasicontinuity of functions in N1,∞(P)
were for such spaces P given in [1, Theorem 6.2].
Proposition 1.4. Assume that there are L∞-almost no nonconstant rectifiable
curves in P. Then the following are equivalent:
(a) The Vitali–Carath´eodory property holds for X = L∞.
(b) C∞is an outer capacity.
(c) C∞(E) = 1 for every nonempty set E.
(d) µ({x}) > 0 for every x ∈P.
Another property important for quasicontinuity is the density of continuous
functions in N 1,∞(P). This property will, however, not be considered in this note.
It is easily shown that if P has L∞-almost no curves, then continuous functions are
dense in N 1,∞(P) = L∞(P) if and only if all points in P are isolated, which in turn
implies that all functions in N 1,∞(P) are continuous.
For locally complete connected metric spaces P, equipped with a doubling mea-
sure, Durand-Cartagena–Jaramillo–Shanmugalingam [2, Theorem 3.1] showed that
N 1,∞(P) = Lip∞(P), with comparable seminorms, if and only if P supports an
∞-Poincar´e inequality, which in turn is equivalent to P being very thick quasicon-
vex. See also Garc´ıa-Bravo–Ikonen–Zhu [3] for similar results with infinitesimally
doubling measures. However, Lipschitz continuity is a stronger requirement than
continuity (=quasicontinuity), as seen for example by the slit disc. Note that on
nontrivial connected spaces, the Vitali–Carath´eodory property fails, by Proposi-
tion 1.3.

Definition 4.1. P is locally connected at x ∈P if for every r > 0 there is a
connected neighbourhood (not necessarily open) G ⊂B(x, r) of x.
P is locally connected if it is locally connected at every point x ∈P.
(Connected) components are always closed. If P is locally connected then every
component is open. This is never the case when P is not locally connected.
Proposition 4.2. Assume that P is not locally connected.
Then there is a non-continuous function u ∈N 1,∞(P), and moreover u is not
even quasicontinuous.

Remark 4.3. If P is disconnected, then there are two cases:
(a) The components of P are “well separated” in the following sense: If x ∈P
