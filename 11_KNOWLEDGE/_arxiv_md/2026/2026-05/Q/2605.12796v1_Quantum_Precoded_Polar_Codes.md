Abstract—We introduce a new family of CSS codes obtained
from rate-1 precoded polar codes, which harnesses the precoding
benefits obtained for classical short blocklength polar codes. We
optimize the rate profile and precoder of these codes with a
genetic algorithm, and present codes of dimension [[256, 2]] and
[[512, 2]] that have logical error rates similar to the [[1201, 1, 25]]
surface code over the depolarizing channel.
I. INTRODUCTION
Quantum computers are being developed with an increas-
ing number of qubits (N ⩾256). However, qubits are an
incredibly fragile resource, and quantum computers are still
limited by the error on these qubits. Developing quantum
error correction codes that mitigate quantum errors is therefore
crucial.
There are many classes of quantum error correcting codes.
Two of specific interest for the present work are stabilizer
codes [1], and CSS codes [2], [3], a special type of stabilizer
code. Quantum polar codes constructed as CSS codes have
previously been explored [4], [5], [6], most recently under
successive cancellation list (SCL) decoding [7]. The perfor-
mance of [7] is competitive with the surface code [8], however
the polar codes were constructed primarily to satisfy the CSS
constraints; they are not necessarily the best construction.
Despite classical asymptotic optimality, polar codes [9] suf-
fer from shortcomings in the short blocklength regime, when
bits have not sufficiently polarized. In recent years, there has
been increased interest in developing algorithmic and engi-
neering approaches to boost the performance of polar codes.
Of these, most prominent is list decoding [10]. Applying a list
decoder to the successive cancellation (SC) decoding of polar
codes enables the decoder to track multiple paths at once,
allowing them to retroactively correct a previous bit decision
that would have been myopically made in the absence of a
list. Going from SC to SCL happens at the decoder, meaning
no modification needs to be made to the polar code (or the
Clifford gates constructing the code).
Additionally, it has been shown that applying an outer code
to a polar code also significantly improves the performance
[11], even when the outercode is rate-1 [12], [13]. The rate-1
precoder applied is not acting as an effective outer code (since
it is rate-1) but is actually aiding the list decoder, making
incorrect decisions easier to detect. This means that a rate-
1 precoded polar code (which we will simply refer to as a
precoded polar code) is only useful when the decoder has
memory (e.g., SCL). Precoded polar codes have also been
studied under the name polarization-adjusted convolutional
(PAC) codes [14] and polar codes with dynamically frozen
bits [15].
In light of the usefulness of a list decoder for quantum polar
code [7], a list decoder for quantum precoded polar codes
is a natural extension. However, the extension is not trivial,
as the constraints required to construct a CSS code mean
that one cannot use a time-invariant convolutional precoding.
Additionally, as seen in the classical case, the information
sets constructed to best make use of the precoder are also
driven algorithmically [16], [17], [18], as opposed to the
asymptotically optimal constructions based on information-
theoretic quantities. Another challenge to address is therefore
ensuring that the sets that best use the precoder also lead to
valid CSS constructions.
The contributions of this work are addressing following two
challenges:
1) Understanding how a rate-1 precoder can be applied to a
quantum polar code, and conducting a search for a good
precoder.
2) Conducting a search for an improved information set,
that is both valid and makes use of the precoding.
The rest of the paper is structured as follows. In Section
II, we provide background review of necessary concepts. In
Section III, we present a way to construct quantum precoders.
Section IV, we showcase some of the new codes found in our
method and provide additional discussions. We then conclude
in Section V.

C. Syndrome Decoding of Polar Codes
A key challenge for quantum systems is that the data
cannot be measured without disturbing the state. Therefore,
when receiving a received noisy codeword y, instead of trying
to estimate x, the decoder may only access information on
the noise, n, through syndrome measurements. The decoder
now outputs an estimate of the noise, ˆn, and reapplies it as
y+ˆn = x+n+ˆn = ˆx, ideally removing the noise. This setup is
known as syndrome decoding, which can be viewed as source
coding without side information [19]. For any code C that has
a parity check matrix H, it is known that xHT = 0∀x ∈C.
Therefore yHT = 0 + nHT = s, where s is the syndrome of
the noise and aids the decoder in estimating ˆn. For a polar code
with information set A, since G is its own inverse, we know
that xGF = uF = 0, making the parity check matrix F T GT .
The syndrome is obtained as nGF = sF. The decoder is now
aiming to build the entire N length vector s, and ultimately
obtain an estimate ˆn = sG. Algorithmically, this means that
the decoder is no longer forcing a frozen bit to be 0 in (2),
but rather the appropriate bit from sF. In this problem, the
decoder sets yi = 0 ∀i, a choice that communicates that the
decoder has no side information, and preserves the BSC(p)
noise structure of the channel [19].
D. Precoded Polar Codes
A precoded polar code still polarizes u to get the final
codeword, except now u = vT, with v being the new informa-
tion vector and T being a causal, upper-triangular matrix. The
information set A now affects v, having vA = m, vF = 0.
Decoding and metric decisions from (1)-(4) are still based
on ˆui, but the decoder’s branches are based on ˆvi and ˆui is
now determined from ˆv0:i and T. Row i of T determines how
the decision of ˆvi affects future decisions of ˆui+1:N−1, and
column j of T determines how previous bits ˆv0:j−1 affect ˆuj
based on the decision of ˆvj. Further discussions of precoded
polar codes can be found in [16], [20].

III. QUANTUM PRECODED POLAR CODES
In this section we establish that, under the correct con-
straints, a polar code can remain CSS when precoded with
matrix T, and how additional Clifford gates create this pre-
coding. We then propose a genetic algorithm to search for
good quantum precoded polar codes.
A. Valid Quantum Precoders
Similar to the translation of a classical polar encoding circuit
to a quantum polar encoding circuit, the quantum precoder T

B. Genetic Algorithm Search
While Section III-A establishes the functionality and exis-
tence of a valid T, and Section II-F establishes that a valid A
exists, finding an optimized A or T under the CSS constraints
is an open problem. Even in the classical regime, the idea
of an optimized T is rarely addressed, as typically a time-
invariant convolutional matrix is more than sufficient; however

these matrices are not their own inverses, making the need for
a non-trivial T relevant. Furthermore, [23] showed that, on
non-erasure channels, after polarization, a bad bit-channel i
does not enforce a good bit-channel N −1 −i, a necessary
condition to have vanishing error under a CSS construction.
Therefore, finding high-performance sets using metrics besides
mutual information is of interest, e.g. minimum weight [24],
PM [16], or data-driven genetic algorithms [18], [25].
A genetic algorithm is a promising approach. A large benefit

V. CONCLUSION
We have presented quantum precoded polar codes, a new
family of codes that apply the breath of literature on short
blocklength polar codes towards quantum polar codes. Anal-
ysis shows how a precoder can be implemented for encoding
and syndrome extraction, as well as the algorithmic changes
the decoder makes. A search finds codes of length N = 256
and 512 that compare favorably against the surface code in
terms of logical error rate, with fewer encoding/ancilla qubits
required, larger rate, and better complexity, but at the cost of
an increased number of Clifford gates required. These codes
may be useful in a regime where increasing Clifford gates is
easier than increasing the number of qubits.
