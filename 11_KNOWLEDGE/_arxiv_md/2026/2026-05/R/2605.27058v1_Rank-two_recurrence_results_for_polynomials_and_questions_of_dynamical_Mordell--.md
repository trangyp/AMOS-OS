1. Introduction
1.1. A theorem of Yang and Zhong. For every rational map h ∈C(z) and
every integer n ∈Z>0, the n-th iterate of h is denoted by h◦n, and by convention
we set h◦0(z) = z. Recall that an arithmetic progression in Z≥0 is a subset Z of
Z≥0 of the form
Z = {a + bk: k ∈Z≥0}
for some a, b ∈Z≥0. If b = 0, then Z = {a} is a singleton. Recently, Yang and
Zhong proved the following theorem [YZ26, Theorem 1.14]:
Theorem 1.1 (Yang–Zhong). Let f, g ∈C[z] \ C and c ∈C[z]. Then the set
Sf,g,c := {n ∈Z≥0 : ∃λ ∈C, f ◦n(λ) = g◦n(λ) = c(λ)}
is a finite union of arithmetic progressions.

1.2. Our generalization to rank two. The aim of this article is to generalize
Theorem 1.1. There are several possible directions for generalizing Theorem 1.1.
First, it seems that only dealing with f ◦n and g◦n for the same n ∈Z≥0 is a
considerable restriction. In fact, the proof of Theorem 1.1 in [YZ26] reflects this
problem to some extent. In [YZ26], the proof of Theorem 1.1 (when deg(f) ≥2
and deg(g) ≥2) is divided into two cases:
(1) deg(f) = deg(g);
(2) deg(f) ̸= deg(g).
We want to generalize Theorem 1.1 and obtain a more unified statement for these
cases (1) and (2), by studying rank-two recurrence sets defined as follows.

In complex dynamics, the exceptional maps defined below are often regarded
as special classes of rational maps of degree ≥2. They are the rational maps on
P1

For endomorphisms g : X →X and h : Y →Y of algebraic varieties, we say that
h is semi-conjugate to g if there is a dominant morphism π : X →Y such that
π ◦g = h ◦π, in which case we write g ≥h (or g ≥π h when π is specified).
Definition 1.11. Let f : P1
C →P1
C be an endomorphism of degree d ≥2.
• The map f is called a Lattès map if there exists an endomorphism ϕ of an
elliptic curve E such that ϕ ≥f. The map f is called flexible Lattès if there
exist an elliptic curve E and an integer n ∈Z\{0, ±1} for which [n] ≥π f,
where [n] denotes the multiplication-by-n map on E and π : E →P1 is
the quotient map by the action of {±1}. A non-flexible Lattès map is
called rigid Lattès.
• We say that f is of monomial type if it is semi-conjugate to a power map
on P1. It is well known that f is of monomial type if and only if it is
conjugate to z±d or ±Td(z), where Td(z) is the (normalized) Chebyshev
polynomial of degree d, i.e., the unique monic polynomial Td ∈C[z] of
degree d such that
Td(z + z−1) = zd + z−d.
See [Sil07, Chapter 6] and [Mil06].

(equivalently, every) k ∈Z>0.
Lattès maps are not (conjugate to) polynomials because their Julia sets are

and only if f is (aﬀinely) conjugate to zd or ±Td(z).

1.4. Questions of dynamical Mordell–Lang type.
Dynamical Mordell–Lang conjecture and higher-dimensional questions. The dy-
namical Mordell–Lang conjecture, proposed by Ghioca and Tucker [GT09], is a
dynamical analogue of the classical Mordell–Lang conjecture on subvarieties of
semi-abelian varieties:
Conjecture 1.14 (Dynamical Mordell–Lang conjecture (DML)). Let k be an
algebraically closed field of characteristic zero. Let X be a quasi-projective variety
over k and f : X 99K X be a dominant rational self-map. Then for every Zariski
closed subset V ⊆X and every point x ∈X(k) whose forward f-orbit is well-
defined, the set
{n ∈Z≥0 : f ◦n(x) ∈V }
is a finite union of arithmetic progressions.
We remark that the original version of DML only deals with endomorphisms.
For some progress on DML, see [BGT16, Xie23] and references therein.
By
replacing the point x with a subvariety Z, Xie proposed the following higher-

2. Presburger arithmetic and semi-linear sets
A theorem of Ginsburg and Spanier asserts that semi-linear sets (see Defini-
tion 1.3) are exactly the definable sets in a certain first-order structure Pr with
underlying set Z≥0.
This characterization of semi-linear sets is useful for the
proofs of our main theorems. For basic material on first-order model theory, we
refer the reader to [Mar02].
Definition 2.1 (Presburger arithmetic). The (modified) Presburger arithmetic
is the first-order structure
Pr =
(
Z≥0, +, <, 0, 1, (Pn)n∈Z≥2
)
,
where (Z≥0, +, <, 0, 1) have their usual meanings, and for each integer n ≥2, Pn
is the unary relation consisting of elements divisible by n, i.e., Pn is the subset
nZ≥0 of Z≥0.
Remark 2.2. The language of Pr is L =
{
+, <, 0, 1, (Pn)n∈Z≥2
}
.
Note that
(Z≥0, +, <, 0) is the usual ordered additive monoid structure on Z≥0.
In the literature, Presburger arithmetic usually refers to the structure
PrZ =
(
Z, +, <, 0, 1, (Pn,Z)n∈Z≥2
)
(or its theory), where Pn,Z is the unary relation given by Pn,Z = nZ for each
integer n ≥2. In this article, we are only concerned with the modified one Pr
(i.e., the restriction of PrZ to Z≥0) and call it Presburger arithmetic for simplicity.
It is easy to see that the theory of Pr (also, the theory of PrZ) is a complete
decidable theory with quantifier elimination (cf. [Mar02, Corollary 3.1.21]).
Ginsburg and Spanier proved that semi-linear sets coincide with the definable
sets of Pr:
Theorem 2.3 ([GS66, Theorem 1.3]). For every integer k ≥1 and every subset
Z of Zk
≥0, Z is semi-linear in the sense of Definition 1.3 if and only if Z is
definable in the structure Pr.
Remark 2.4. By [Mar02, Exercise 1.4.15], the definable sets of Pr (equivalently,
semi-linear sets) coincide with the definable sets of the structure
(Z≥0, +, 0, 1).
See [GS66, § 1] for a description of definable sets of Pr.

rem 1.1]):
Corollary 2.5. The family of semi-linear subsets of Zk
≥0 (k ≥1) is closed under
finite unions, finite intersections, and complementation.
Projections of semi-
linear sets are semi-linear.
