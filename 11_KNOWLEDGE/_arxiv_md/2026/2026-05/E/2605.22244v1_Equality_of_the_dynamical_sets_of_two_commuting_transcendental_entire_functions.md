EQUALITY OF THE DYNAMICAL SETS OF TWO COMMUTING
TRANSCENDENTAL ENTIRE FUNCTIONS
MANISHA KUMARI AND DINESH KUMAR
Abstract. In this paper, we study the dynamics of commuting transcendental entire
functions f and g, where g is of the form afp + b with a, b ∈C, p ∈N, and a ̸= 0, 1. We
establish that the escaping sets, filled Julia sets, and bungee sets of f and g all coincide.
As an immediate consequence, we obtain in particular that the Julia sets of f and g
are identical. Our theorem extends the 1998 result of Poon and Yang. Furthermore,
following Wang and Yang, we consider a non-constant polynomial Q and permutable
entire functions f and g satisfying the relation Q(g) = aQ(f)+b, where a(̸= 0, 1), b ∈C.
In this more general setting, we also prove that the escaping sets, filled Julia sets, and
bungee sets of f and g are equal.
1. Introduction
Let f : C →C be a transcendental entire function and let f n denote the n-th iterate
of f for all n ∈N. The dynamical behavior of f is described by partitioning the complex
plane into two fundamental sets viz., the Fatou set and the Julia set. The Fatou set of f
is denoted by F(f) and is defined by
F(f) = {z ∈C : {f n}n∈N is normal in some neighborhood of z},
and its complement J(f) = C \ F(f) is called the Julia set. Points in the Fatou set
exhibit stable dynamical behavior, whereas the Julia set represents chaotic dynamics and
sensitive dependence on initial conditions.
Basic properties and structural aspects of
these sets are well documented in the literature [3], [5].
Apart from the classical decomposition of the complex plane into Fatou and Julia sets,
one may further classify points according to their orbits under iteration. The escaping
set of f is denoted by I(f) and is defined by
I(f) = {z ∈C : f n(z) →∞as n →∞}.
It was introduced by Eremenko [6] and consists of all those points whose forward orbit
tends to infinity.
Also, he proved that I(f) is non-empty and that every connected
component of I(f) is unbounded. The filled Julia set of f is denoted by K(f) and is
defined by
K(f) = {z ∈C : {f n(z)}n∈N is bounded}.
That is, it contains those points that have bounded orbit [4]. In addition, the bungee set
of f is denoted by BU(f) and is defined to be the collection of those points whose orbit

Two functions f and g are said to be commuting (permutable) if f ◦g = g ◦f. Fatou
proved that such permutable rational functions have identical Fatou sets [2].
Under
analogous special hypothesis, Hua and Wang [7], answered a question originally posed
by Baker [1]. This naturally leads to the question of whether similar kind of results also
hold for the escaping set, the filled Julia set and the bungee set which has been addressed
in this article.
Motivated by these developments, the present work studies the dynamics of certain
special classes of transcendental entire functions together with their affine modifications.
It has been shown that under suitable hypothesis, two commuting entire functions f and
g have the same filled Julia set, escaping set and bungee set. Our results extend the
work of Poon and Yang [9], by establishing the equality of the three dynamical sets viz.,
the escaping set, the filled Julia set and the bungee set for a wider class of commuting
transcendental entire functions. Additionally, we obtain the equality of the Julia sets of
these commuting transcendental entire functions.
2. The equality of dynamical sets
As shown in [9], if f and g are permutable transcendental entire functions, then F(f) =
F(g), where g(z) = af(z) + b, a, b ∈C are constants and a ̸= 0. In addition, |a| = 1.
Analogous conclusion for the filled Julia set, the escaping set and the bungee set are then
naturally explored in a more general setting. The following elementary lemma, which
will be used frequently in the sequel, describes how affine mappings perform on bounded
and unbounded sets.
Observation : Let P(z) = az + b with a, b ∈C and a ̸= 0. Then P sends every
bounded subset (respectively, an unbounded subset) of C to a bounded set (respectively,
an unbounded set). With the help of above Lemma 2, we investigate the filled Julia set,
the escaping set and the bungee set of two permutable transcendental entire functions.
Before proving the next result, we first state the following lemma, which clarifies the
connection between f, g and the affine function P(z) = az + b, 0 ̸= a, b ∈C.
Lemma 2.1. Suppose f and g are two commuting transcendental entire functions where
g = af p + b, a, b ∈C, p ∈N, and a ̸= 0, 1. Then,
f(az + b) = af(z) + b.
Proof. We have f ◦g(w) = g ◦f(w). As g(w) = af p(w) + b, we obtain
f ◦g(w) = f(af p(w) + b).
On the other hand, we have g ◦f(w) = af p(f(w)) + b. Substituting f p(w) = z, this leads
to the following functional equation f(az + b) = af(z) + b.
□

We now generalize this result to obtain the equality of the filled Julia sets of two
permutable entire functions. The next result establishes the equality of the filled Julia
sets for two commuting transcendental entire functions.
Theorem 2.4. Suppose f and g be commuting transcendental entire functions where
g(z) = af p(z) + b for some a, b ∈C, p ∈N with a ̸= 0, 1. Then K(f) = K(g) .
Proof. Let z ∈K(f). Then f n(z) is bounded for all n ∈N, that is, there exists A > 0
such that |f n(z)| ≤A for all n ∈N. From Lemma 2.2, we have gn(z) = P n ◦f np(z) for
all n ∈N. Using Lemma 2, P n sends bounded set to bounded set. As a result, there
exists M > 0 such that |gn(z)| ≤M for all n ∈N which implies that z ∈K(g). Thus
K(f) ⊂K(g).
On the other hand, observe that f np(z) = P −n(gn(z)) is bounded for all n ∈N. As
f is continuous, we have f k(f np(z)) is bounded for all n ∈N and k = 1, 2, . . . p −1.
Consequently, f n(z) = {f np(z)} ∪{f(f np(z))} ∪· · · ∪{f p−1(f np(z))} is bounded for all
n ∈N. We deduce that K(g) ⊂K(f). Hence, K(f) = K(g).
□
In the next result, we show the equality of the escaping set of two permutable entire
functions.
Theorem 2.5. Suppose f and g are commuting transcendental entire functions where
g(z) = af p(z) + b for some a, b ∈C, p ∈N with a ̸= 0, 1. Then I(f) = I(g).

Proof. Let z ∈I(f). Then f n(z) →∞as n →∞. By Lemma 2.2, gn(z) = P n ◦f np(z).

Using the above two results, we now demonstrate that the corresponding results also
apply to the bungee set as shown in the remark below.
Remark 2.6. Suppose f and g are commuting transcendental entire functions, where
g(z) = af p(z) + b for some a, b ∈C, p ∈N with a ̸= 0, 1.
Then the bungee set of
f and g are identical. For, if z ∈BU(f), then z ∈C \ (K(f) ∪I(f)). Accordingly,
z ∈C \ (K(g) ∪I(g)) = BU(g).
As a consequence of Theorem 2.5, we obtain that ∂I(f) = ∂I(g), where ∂U denotes
the boundary of the set U. Eremenko in [6], proved that ∂I(f) = J(f). Thus we obtain
J(f) = J(g). This gives another proof of the equality of the Julia sets of two permutable
entire functions under the given hypothesis as in [9]. In fact, our results are more general
in the sense that on taking p = 1, we get the result obtained in [9, Lemma 2.1].
