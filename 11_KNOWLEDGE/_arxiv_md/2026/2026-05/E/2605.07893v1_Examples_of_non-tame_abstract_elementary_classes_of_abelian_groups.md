DANIEL HERDEN, MARCOS MAZARI-ARMIDA, MICHAEL D. WALTON
Abstract. We construct an abstract elementary class K1 of torsion-free abelian
groups such that K1 is not (< ℵ0)-tame but is ℵ0-tame. This answers a ques-
tion of [BoVa17]. Furthermore, for every regular uncountable cardinal µ less
than the first measurable cardinal, we construct an abstract elementary class
K2(2µ) of torsion-free abelian groups such that K2(2µ) is not (< µ)-tame.
K1 and K2(2µ) are non-tame for algebraic reasons. Furthermore, they con-
stitute the first examples of non-tame abstract elementary classes in a natural
language.
1. Introduction
Abstract elementary classes (AECs for short) [She87a] are the prominent setup
for studying non-elementary classes of structures as they are general enough to
encompass many interesting examples while at the same time allowing the devel-
opment of a deep theory. For examples of AECs see [BoVa17, Section 3.2], [Maz21,
Example 2.2], [Bon26, Section 3.2]; and for the development of the theory see
[Gro02], [She09], [Bal09], [BoVa17].
An abstract elementary class is an object determined by a class of structures
K and a partial order ≤K on K which satisfies a few natural closure properties.
Two of the key properties are that the class is closed under increasing chains and
that every subset of an element in K can be closed to a small element in K (see
Definition 2.2). In this paper, K will always be a class of torsion-free abelian groups
and ≤K will strengthen the subgroup relation.
As an AEC is a semantic object, the correct notion of type in this setup is not
a collection of formulas as in first-order model theory, but that of a Galois type
[She87b]. Intuitively, the Galois type of an element b in N ∈K over the set of
parameters A (for A ⊆N) is the equivalence class of all triples (b′, A, N ′) such that
there is a way of sending b to b′ while simultaneously keeping all parameters in A
fixed (see Definition 2.5).
Since Galois types are semantic objects, it might not be possible to distinguish
two types by a small subset of their set of parameters. When we can distinguish
types by subsets of size less than λ, we say that an AEC is (< λ)-tame. It is worth

Tameness was isolated by Grossberg and VanDieren [GrVan06a] twenty five years
ago and since then has become one of the central notions in the study of AECs.
Nowadays, many results on AECs either outright assume tameness, see [GrVan06b],
[BKV06], [Bon14], [GrVas17] [Vas18], [Leu24], [MaYa24], or showing tameness (of-
ten with assumptions beyond ZFC) is an intermediate step toward a larger goal,
see [Vas17], [Vas20], [ShVas24].
There are plenty of tame AECs. For instance, all the following AECs with pure
embeddings are (< ℵ0)-tame: torsion abelian groups, ℵ1-free abelian groups, and
absolutely pure R-modules. Many more examples of tame AECs, both of algebraic
and non-algebraic flavor, are provided in [BoVa17, Section 3.2].
Moreover, the
statement that every AEC is (< λ)-tame for some cardinal λ is equivalent to a
large cardinal axiom [BoUn17], [BoLi21].
On the other hand, there are only three families of examples known to be non-
tame: Hart-Shelah, see [HaSh90], [BaKo09], Baldwin-Shelah [BaSh08], and Boney-
Unger-Shelah, see [BoUn17], [She]. The Hart-Shelah and Boney-Unger-Shelah ex-
amples are of set-theoretic nature, while the Baldwin-Shelah example is at the
border of algebra and set theory. Further details about these three examples can
be consulted in [BoVa17, Section 3.2.2].

mentary classes. The reason tameness fails in our examples is a purely algebraic

Abstract elementary classes. Abstract elementary classes (or AECs) were in-
troduced by Shelah in the seventies [She87a]. Given a structure M, we will write
|M| for the underlying set of the structure and ∥M∥for its cardinality.
Definition 2.2. An abstract elementary class is a pair K = (K, ≤K) where:
(1) K is a class of L-structures (for some fixed finitary language L = L(K)).
(2) ≤K is a partial order on K.
(3) If M ≤K N, then M is a substructure of N.6
(4) If M ≤K N are in K and f : N ∼= N ′ is an isomorphism, then f[M] ≤K N ′
for the image f[M] of f.
In particular, K is closed under isomorphic
images.
(5) Coherence: If M0, M1, M2 ∈K satisfy M0 ≤K M2, M1 ≤K M2, and
M0 ⊆M1, then M0 ≤K M1.
(6) Tarski-Vaught axioms: Suppose δ is a limit ordinal and {Mi ∈K : i < δ}
is an increasing chain. Then
(a) Mδ := S
i<δ Mi ∈K and Mi ≤K Mδ for every i < δ.
(b) Smoothness: If there is some N ∈K so that for all i < δ we have
Mi ≤K N, then Mδ ≤K N.
(7) L¨owenheim-Skolem-Tarski axiom: There exists a cardinal λ ≥|L(K)| + ℵ0
such that for any M ∈K and A ⊆|M|, there is some M0 ≤K M such
that A ⊆|M0| and ∥M0∥≤|A| + λ. We write LS(K) for the minimal such
cardinal.
Remark 2.3. In this paper, L will be the language L = {+, −, 0} of abelian groups,
K will be a class of torsion-free abelian groups, and ≤K will strengthen the pure
subgroup relation ≤p of abelian groups.
We say that f : M →N is a K-embedding if f : M ∼= f[M] and f[M] ≤K N.
Observe that K-embeddings are always injective. For λ an infinite cardinal, let
Kλ := {M ∈K : ∥M∥= λ}.
Three common properties of AECs are no maximal models, joint embedding,
and amalgamation. We say that K has no maximal models if for every M ∈K,
there exists an N ∈K with M ≤K N and |M| ⊊|N|. K has joint embedding
if for every M1, M2 ∈K, there exist N ∈K and K-embeddings f1 : M1 →N
and f2 : M2 →N. Lastly, K has amalgamation if for every pair of K-embeddings
f1 : M →N1 and f2 : M →N2 there are N ∈K and K-embeddings g1 : N1 →N
and g2 : N2 →N such that g1 ◦f1 = g2 ◦f2 on M.
An additional property we leverage in this paper is admitting intersections. This
strong property often fails even for elementary classes. These AECs were introduced
in [BaSh08].

Since Galois types are semantic objects, they might not be determined by their
restriction to subsets of a given size. This leads to the notion of being tame.
Definition 2.7. Let λ, θ be infinite cardinals.
K is (< λ, θ)-tame if for every
M ∈K with ∥M∥= θ and p, q ∈gSK(M), if p ̸= q, then there is A ⊆|M| such
that |A| < λ and p ↾A ̸= q ↾A.
We say that K is (< λ)-tame if K is (< λ, θ)-tame for every infinite cardinal θ.
We say K λ-tame if it is (< λ+)-tame.
Stability is a key model-theoretic dividing line. Although it is not the main focus
of this paper, we will study it for the classes we introduce in the next sections.
Definition 2.8.
(1) K is stable in λ if for any M ∈K with ∥M∥= λ it holds that |gSK(M)| ≤λ.
We say that K is stable if there exists a cardinal λ ≥LS(K) for which
K is stable in λ.
(2) ([PaSh, Definition 2.4]) We say that K is almost stable in λ if for any
M ≤K N with ∥M∥= λ it holds that |gSK(M; N)| ≤λ, where gSK(M; N) :=
{gtpK(b/M; N) : b ∈N}.
We say that K is almost stable if there exist arbitrarily large cardinals
λ ≥LS(K) for which K is almost stable in λ.
Remark 2.9. If K has amalgamation. then K is almost stable in λ if and only if
K is stable in λ, see [PaSh, Observation 2.6].
