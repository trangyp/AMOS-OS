ERGODICITY OF C2 MINIMAL ACTIONS OF THOMPSON GROUP T
ON THE CIRCLE
KLAUDIUSZ CZUDEK
Abstract. We show that every C2 minimal action of Thompson group T on the circle
is ergodic with respect to the Lebesgue measure. If such action is not minimal then the
Lebesgue measure of the exceptional minimal set is zero.
1. Introduction
1.1. Definitions and Main Theorem. If G is a group and M a manifold, then a homeo-
morphism Φ : G →Homeo+(M) is called a representation of G in Homeo+(M). We say the
representation Φ is Cr (resp. Cω) if the image of Φ is contained in Diffr(M) (resp. Diffω(M)).
We usually identify g ∈G with Φ(g) and therefore assume that G ⊆Homeo+(M) and say
that G acts on M via orientation preserving homeomorphisms. If µ is equipped with a refer-
ence measure µ, then we say the representation is ergodic with respect to µ if the condition
g(A) = A for every g ∈G and some measurable A ⊆S1 implies µ(A) ∈{0, 1}. Group actions
on manifolds play an important role in mathematics (see e.g. [3], [4], [11], [21], [22], [19]).
In this paper we are interested in group actions on the circle. In that case exactly one of
the following cases holds (see Theorem 2.1.1 in [21])
(i) there exists a point x ∈S1 whose orbit is finite,
(ii) the orbit of an arbitrary point is dense (the action is minimal),
(iii) there exists a unique minimal invariant compact set homeomorphic to the Cantor set
(moreover, this set is contained in the set of accumulation points of orbit of an arbitrary
point).
There are two still open major problem in this theory (Section 3.5 in [21]). The first prob-
lem attributed to Ghys and Sullivan is if every C2 minimal action on the circle is necessarily
ergodic with respect to the Lebesgue measure. The second problem is if for any C2 action
admitting the exceptional minimal set, is it true that the Lebesgue measure of this set is
necessarily 0?
The answers to both are affirmative in the case when the group has an element with the
irrational rotation number (proven independently by Katok [15], Theorem 12.7.2, and Herman
[14]) or when for every point x ∈S1 there exists g ∈G such that g′(x) > 1 (Shub and Sullivan
[23]). However, the latter condition is not always satisfied, thus for a given group G it makes
sense to define the set of nonexpandable points NE(G)={x ∈S1 : g′(x) ≤1 for every g ∈G}.
Examples of actions with nonempty NE(G) include the canonical action of PSL(2, Z) and
smooth actions of Thompson group T.
A crucial contribution in dealing with that case
has been made by Deroin, Kleptsyn and Navas [7], who introduced so called conditions (∗)
and (Λ∗) and proved that every C2 minimal action with (∗) is ergodic with respect to the

Definition 1. Let G act on S1 minimally. We say that G has property (∗) if for every x ∈

Paper [7] provides also nontrivial examples of actions with property (∗).
The actions
with nonempty set of nonexpandable points has been studied subsequently ([9], [16]). The
properties (∗) or (Λ∗) has been proven later for groups with one end satisfying some additional
assumptions [10], for groups acting analytically on the circle that act freely [8] or have
infinitely many ends [1].
One of the examples provided in [7] with property (∗) is the canonical action of PSL(2, Z).
The other one are certain actions of Thompson group T, one of the famous Thompson group
F, T and V that are studied intensively nowadays (e.g. [13], [20], [2], see also [5] for a general
introduction to Thompson groups). Thompson group T can be defined as the group of all
piecewise affine circle homeomorphisms with finite number of breaking points being diadic
rational numbers and slopes being integer powers of two. Although this action is obviously
not C1, Thurston has shown that one can actually construct an action of T on the circle
by C∞diffeomorphisms. Later the work of Ghys, Sergiescu [12] has shown that there are
plenty of possible actions of Thompson group T on S1 (this construction is described in
Section 2.2). For now we just state that to every circle covering map of degree two φ with
φ(0) = 0 we can associate certain action of T on the circle that is denoted in this paper by
Tφ. Depending on the properties of φ this actions is either minimal or admits the exceptional
minimal set. The original action of T by piecewise affine circle homeomorphisms is obtained
when φ(x) = 2x mod 1 and if φ is C2, φ′(0) = 1, φ′′(0) = 0 then each element of Tφ is a
C2 circle diffeomorphism. Deroin, Kleptsyn and Navas [7] proved property (∗) in the case
when φ′(x) > 1 for x ̸= 0 (see more details in Section 2.2 and [21]). Here we show that every
minimal action of Thompson group T on the circle satisfies (∗). Moreover, [7] do not provide
any example of C2 action admitting exceptional minimal set with property (Λ∗). Here we
show that every such action of Thompson group T satisfies (Λ∗).
Theorem 3. Every C2 minimal action of Thompson group T on the circle satisfies property
(∗) and therefore is ergodic. Every C2 action admitting an exceptional minimal set satisfies
property (Λ∗) and consequently the Lebesgue measure of the exceptional minimal set is zero.
The proof of the first part (minimal case) is an easy application of Theorem 2.1 and Lemma
3.6 in [18]. To show the second part (exceptional minimal set) we cannot apply those result
directly. However, it is possible to modify the proofs to obtain the desired theorem.

(i) there exists a point x ∈S1 whose orbit is finite,
(ii) the orbit of an arbitrary point is dense,
(iii) there exists a unique minimal invariant compact set homeomorphic to the Cantor set
(moreover, this set is contained in the set of accumulation points of orbit of an arbitrary

Let Tφ be the action of Thompson group T on the circle associated to the circle covering
map φ. By Theorem 4.14 [17] it is sufficient to consider only such actions.
3.1. G acts minimally on the circle. If the action is minimal then φ is necessarily orbit
expanding as explained Section 2.3. By Theorem 2.1 in [18] the set of parabolic periodic
points Par(φ) of φ is finite and by Lemma 3.6 therein there exists λ0 > 1 such that for every
x that is not a parabolic periodic point there exists k ≥1 such that (φk)′(x) ≥λ0, which
readily implies that for every x that is not a parabolic periodic point of φ there exists g ∈Tφ
such that g′(x) > 1.
Let x ∈NE(Tφ). Then x is a parabolic periodic point of φ of some period s and (as φ
is orbit expanding) φs has no other fixed points in some ε-neighborhood of x. Clearly there
exists g ∈Tφ with g = φs on some neighborhood of x. Since x ∈NE(Tφ) was arbitrary, this
completes the proof of property (∗).
