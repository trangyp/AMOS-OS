Abstract
We prove a PCP theorem for the existential theory of the reals, showing that MAX-ETR-INV
is ∃R-hard to approximate to within some constant factor.
The existential theory of the reals (ETR) is a decision problem asking if there exists a set
of real-valued variables satisfying some constraints involving polynomials and inequalities, and
∃R is the complexity class of problems polynomial-time reducible to ETR. Many important
geometric problems are known to be ∃R-complete.
∃R-hardness results frequently work by a reduction from the ∃R-complete problem ETR-
INV, which asks if there is a an assignment of real variables each in the interval [ 1
2, 2] satisfying
some constraints of form x = 1, xy = 1 and x + y = z.
MAX-ETR-INV is a related optimization problem that asks, given a set of constraints of
form x = 1, xy = 1, and x + y = z, for a feasible (that is, satisfiable with variables in [ 1
2, 2])
subset of those constraints of the largest possible size. We show that there is some constant ϵ > 0
such that it is ∃R-hard to approximate MAX-ETR-INV better than a 1 −ϵ factor. This means
that even a non-deterministic polynomial-time algorithm can’t approximate MAX-ETR-INV
better than this factor unless ∃R = NP.
We also give a polynomial-time 8-factor approximation algorithm and a non-deterministic-
polynomial-time 2-factor approximation algorithm for MAX-ETR-INV.

Background and related work
The existential theory of the reals.
The existential theory of the reals (ETR) is the decision
problem for sentences of the form:
∃x1, . . . , xn : Φ(x1, . . . , xn)
where the xi are real variables Φ is a formula involving rational constants, arithmetic operations (+,
−, ·), (in)equalities (=, ≤, <), and logical connectives (∧, ∨, ¬). So an instance of ETR consists
of constraints involving polynomials and inequalities, and asks for an assignment of real variables
satisfying these constraints.
The complexity class ∃R consists of problems that are polynomial-time reducible to ETR. It
is straightforward to see that ETR is at least NP-hard, but much less easy to see that it is even
decidable. In 1988, Canny [Can88] showed that ETR can be decided in PSPACE. So NP ⊆∃R ⊆
PSPACE. It is unknown whether either inclusion is strict.
More recently, the class ∃R has become increasingly relevant in the study of the complexity of
geometric problems, with many important problems being show to ∃R-complete. Notable examples
come from art-galleries [AAM21, Sta25], packing [AMS20], and training neural networks [BHJ+23,
AKM21]. A recent survey [SCM24] lists roughly 150 ∃R-complete problems.
Note that a satisfying assignment for an instance of ETR can require irrational coordinates (e.g.
the instance ∃x : x · x = 2). So we generally don’t expect algorithms for ETR (or any ∃R-complete
problem) to output a satisfying assignment, only to determine if one exists.

Hardness of approximation.
The complexity of optimization problems is often studied in terms
of a related decision problem, which asks if the optimum is better than some threshold. This models
the complexity of obtaining an exactly optimal solution.
In order to study the complexity of obtaining an approximate solution, we can instead look at a
related “gap” problem. If A is a maximization problem with objective taking values in [0, 1], then
for 0 ≤a < b ≤1, the promise problem Gap-Ab
a asks, given an instance of A, whether the optimal
objective value at least b. We are promised that the optimum is either ≥b or ≤a, so an algorithm
for Gap-Ab
a need not give a correct answer if the optimum is in (a, b).
To show hardness of approximation for A, we can reduce a known hard problem to Gap-A.
A reduction to to Gap-Ab
a must guarantee that the instance produced does not have optimum in
(a, b).
For some complexity class C, if there are some a and b such that every problem in C reduces in
polynomial time to Gap-Ab
a, then we say that A is C-hard to approximate to within a factor of a
b.
Indeed, a better-than-a
b-factor approximation algorithm for A is sufficient to distinguish between
instances with optimum ≤a and instances with optimum ≥b.
In a few cases, existing NP-hardness constructions can be used to obtain NP-hardness of ap-
proximation. For example, the fact that 3-colorability of graphs is NP-hard implies that graph
coloring is NP-hard to approximate to within a 3
4 factor. But typically, hardness of approximation
is not this straightforward to show.
A common strategy to show NP-hardness is to reduce from 3SAT. So in order to show hardness
of approximation, it is useful to consider the optimization version of 3SAT. The problem MAX-
3SAT is an optimization problem that asks, given a 3-CNF formula, for an assignment of the
variables that satisfies the largest possible fraction of the clauses. The PCP theorem implies that
MAX-3SAT is NP-hard to approximate to within some constant factor:
Theorem 1. (PCP theorem, hardness of approximation version) There is some constant c < 1 so
that Gap-MAX-3SAT1
c is NP-hard.
The theorem was first proved by Arora, Lund, Motwani, Sudan, and Szegedy [ALM+98], build-
ing on a long line of previous work (including [BFL90, BFLS91, FGL+91, FGL+96]).
For the formulation above, the best-known value of c is due to Guruswami and Khot [GK05],
who proved that Gap-MAX-3SAT1
c is NP-hard for each 1 > c > 7
8. Karloff and Zwick [KZ97] gave
a randomized polynomial-time algorithm that decides Gap-MAX-3SAT1
c for any c < 7
8, so this is
essentially tight unless NP⊆BPP.
Version of Theorem 1 have been used to show or improve hardness of approximation bounds for
optimization versions of many classical NP-complete problems. Notable examples include maximum
independent set, max cut [PY91], set-cover [RS97], max-clique [FGL+91, FGL+96, Zuc07], and
graph coloring [Zuc07].
Probabilistically checkable proofs.
The initialization PCP comes from the theory of inter-
active proof systems, and stands for probabilistically checkable proofs. We imagine a prover (with
unbounded computational resources) that wants to convince a verifier (with polynomially-bounded
resources) of the truth of some statement. The prover sends the verifier a “proof”, which is some
information that the verifier uses to help check the claim.
The PCP theorem says that a randomized protocol with polynomial proof length where the
verifier only needs to read a constant number of bits of the proof can be (up to some small false-
positive probability) as powerful as any protocol with polynomial-length proofs where the verifier

can read the entire proof. Note that the statement being proved is agreed upon before hand, and
isn’t considered to be part of the proof.
Here the bits that the verifier chooses to read depend on the outcomes of some random events.
However, they are chosen non-adaptively, that is, the verifier must choose all the bits to read before
having read any of the proof. They cannot use the proof to inform decisions about which bits to
read.
To see that this claim is equivalent to Theorem 1, suppose that the prover wants to convince
the verifier that an instance of SAT is satisfiable. Both the prover and verifier use the reduction
implied by Theorem 1 to construct a Gap-MAX-3SAT1
c instance. Since the original SAT instance
was satisfiable, the Gap-MAX-3SAT1
c will be also, and the prover can send the satisfying assignment.
The verifier then chooses O( 1
1−c) of the clauses independently at random, and checks that the
assignment sent satisfies those clauses. If the instance is not satisfiable, (that is, if the optimum is
< 1), then Theorem 1 guarantees that any assignment fails to satisfy a 1 −c fraction of clauses,
and so there is a high probability that the verifier would check one of these clauses.
So if all the clauses checked by the verifier are satisfied, then the verifier can be highly confi-
dent that the original SAT instance was satisfiable. We say that the proof sent by the prover is
probabilistically checkable.
Locally testable, decodeable, and correctable codes.
Known proofs of the PCP theorem
frequently make use of error-correcting codes with certain “local” properties.
A code C ⊆Σm over an alphabet Σ is called q-local δ-testable if there is a randomized process
that chooses (non-adaptively) q entries of a string x ∈Σm and accepts or rejects based on those
queries. The test should satisfy:
• (Completeness) if x ∈C, then the test accepts with probability 1
• (Soundness) if the x ∈Σm is such that the test accepts with high probability, then there is
some y ∈C such that x and y differ on at most a δ fraction of entries (we say that x and y
are δ-close).
A code C ⊆Σm is (q, δ, ϵ)-locally correctable if there is a randomized process that given an
index i ∈[m], reads q entries of a string x ∈Σm and guesses an element of Σ. If x is δ-close to
some y ∈C, then the process should correctly determine the ith entry of y with probability at least
1 −ϵ.
A code f : Σn →Σm is (q, δ, ϵ)-locally decodeable if there is a randomized process that given an
index i ∈[n], reads q entries of a string x ∈Σm and guesses an element of Σ. If x is δ-close to f(y)
for some y ∈Σn, then the process should correctly determine the ith entry of y with probability at
least 1 −ϵ.
A variety of constant-query locally testable, decodeable, and/or correctable codes are known
over finite alphabets (see e.g. [Gol10, DEL+22, Yek12, BSS20]). Over an infinite alphabet (R, say),
it is possible to create codes with unreasonably good properties, for example using an injective map
Rn →R. To rule out these examples, we can restrict to linear codes, that is codes given by a linear
subspace of C ⊆Rm.
While constant-query locally-decodeable linear codes are known over R, the best correctors
known requires queries roughly proportional to log(dim(C)) [ABP+24, ABP+25]. Little seems to
be known about local testability of codes over R.

Our results
Let MAX-ETR-INV be the optimization version of ETR-INV. So an instance of MAX-ETR-INV
consists of some constraints of form x = 1, xy = 1, or x + y = z, and asks to determine the largest
fraction of clauses that can be satisfied simultaneously by an assignment of variables in [1
2, 2]. Our
main result is the following:
Theorem 2. There is some constant c < 1 such that Gap-MAX-ETR-INV1
c is ∃R-hard.
This says that even a non-deterministic polynomial-time algorithm can’t approximate MAX-
ETR-INV better than a c factor, unless NP = ∃R.
In order to prove Theorem 2, we first show hardness of approximation for a somewhat more
general problem that we call ETR-C(q). For each q > 0, the problem ETR-C(q) asks if it is possible
to assign in [1
2, 2] to some variables so that some constraints of form x = y, x = (1 + q)y, x + y = z,
x + y = z + w, xy = z, and xy = zw are satisfied. The problem MAX-ETR-C(q) asks for largest
number of clauses that can be satisfied by an assignment.
We first prove that, for sufficiently small q, it is ∃R-hard to approximate MAX-ETR-C(q) to
within some constant factor. In Section 5, we then use more-or-less standard algebraic manipula-
tions to show that any constraint appearing in MAX-ETR-C(q) can be simulated with O(log(1
q))
constraints of form x = 1, xy = 1, or x + y = z. By choosing some small fixed q, this will prove
Theorem 2.
Our proof that MAX-ETR-C(q) is ∃R-hard to approximate is based on a proof of the PCP
theorem by Dinur [Din07], and some simplifications of that proof by Radhakrishnan [Rad06].
We discuss Dinur’s proof (and the improvements by Radhakrishnan) in Section 3. The proof
proceeds in three steps, and in Section 3.1, we notice that the first two steps can already be applied
in our setting.
The third step is the construction of an assignment tester.
An assignment tester is like a
PCP protocol for satisfiability of a constraint satisfaction problem, but the proof also contains an
assignment of the variables in the original instance. In addition to verifying that the instance is
satisfiable, the verifier also needs to check that the assignment provided is close (in some sense) to
a satisfying assignment.
Roughly speaking, the first two steps in Dinur’s proof show that in order to prove a PCP theorem
for a constraint satisfaction problem, it is enough to construct an assignment tester for that problem,
where the proof can have unbounded length and the verifier has unbounded computational resources
(but is still only allowed a constant number of queries to the proof).
Existing assignment-tester constructions work only for discrete alphabets, and constructing
one for a problem like ETR-C(q) requires some new ideas. In Section 4, we fully state our main
technical result, which is a type of assignment tester for ETR-C(q). We then explain how to obtain
inapproximability of Max-ETR-C(q) from this result. The construction of our assignment tester
occupies Sections 6 to 8.

Interactive proofs with real RAM.
Similar to the PCP theorem, we can give an interpretation
of Theorem 2 in terms of interactive proof systems. We should imagine an interactive proof system
where the proof sent by the prover consists of real numbers (rather than binary bits), and the
verifier has access to real RAM. So the verifier can add, subtract, multiply, divide and compare
real variables at unit cost per operation.
Theorem 2 implies that ETR has polynomial-length probabilistically-checkable proofs in this
model with a constant number of queries, even if the verifier is only allowed to perform a constant
number of arithmetic operations on real RAM (and even if the only operations allowed are checking
constraints of form x = 1, xy = 1, x + y = z, or x ∈[1
2, 2]).
Complexity of solutions.
A satisfying assignment to an instance of ETR-INV can require irra-
tional coordinates, but if a solution exists, then one exists where the coordinates are real algebraic
numbers (that is, roots of integer-coefficient univariate polynomials, this is implied by e.g. the
algorithm from [Can88]).
It is possible to perform arithmetic operations on real algebraic numbers. For example, Mishra
and Pedersen [MP90] give a nearly canonical way of representing a real algebraic as a root of a
polynomial with integer coefficients, and show that basic arithmetic operations can be performed
in time polynomial in the size of this representation.

However, an satisfiable instance of ETR-INV might require coordinates that have exponential
complexity in this representation. Our techniques can be used to show that this extends to approx-
imating ETR-INV. Recall that a real algebraic number α generates a field extension Q(α) of Q of
finite degree, where the degree of the extension is the degree of the lowest-degree integer-coefficient
polynomial of which α is a root.
Theorem 3. There is some constant 0 < c < 1 such that, for any k ∈N, there is a satisfiable
instance of ETR-INV with n ≥2 variables such that any assignment satisfying at least a c fraction
of constraints requires at least one variable to be set to a value that generates a field extension of
degree more than nk over Q.
The representation from [MP90] represents a real algebraic number using a polynomial of which
it is a root, so we need at least d bits to represent a number that generates a field extension of
degree d. So Theorem 3 implies that we need super-polynomially many bits to represent even an
approximate solution to ETR-INV. We give a proof of Theorem 3 in Section 9.
Approximation algorithms for ETR-INV.
In Section 10, we give two constant-factor approx-
imation algorithms for ETR-INV. The first algorithm is a polynomial-time 8-factor approximation
algorithm. This is based on a fairly standard probabilistic argument.
Using the additional power of NP, we get a better approximation algorithm with an approxi-
mation factor of 2. The idea is to try to satisfy either all the constraints of form x = 1 and xy = 1
or as many of the constraints of form x + y = z as possible. We need the power of NP because
this requires solving the NP-hard (and hard to approximate [AK95]) maximum-feasible-subsystem
problem.
Both algorithms Section 10 can output assignments achieving the fraction of satisfied constraints
that they report. The assignments that they output are rational numbers with polynomially many
bits.

Preliminaries
We use [n] to represent the set {1, . . . , n}. All logarithms are natural unless marked otherwise.
Throughout, a graph will be allowed to have self loops and multiple edges. Given a graph G,
we write V (G) for the vertex set and E(G) for the edge set.
An constraint graph is a graph G equipped with an alphabet Σ, and, for each edge, a constraint
modeled as a subset of Σ2. An assignment of a constraint graph is a map A : V (G) →Σ. We say
that an edge e = (u, v) is satisfied by an assignment if (A(u), A(v)) is in the corresponding subset
of Σ2.
Given a constraint graph G, let UNSAT(G) be the smallest fraction of edges that are not
satisfied over all assignments. A graph is satisfiable if UNSAT(G) = 0.
A subset of Rn is called semialgebraic if it can be cut out by constraints of form f(x) = 0,
f(x) ≥0 or f(x) < 0, where each f is a rational-coefficient polynomial Rn →R. The constraints in
a real constraint graph will be semialgebraic sets, which are represented in terms of the polynomials
cutting them out.
For an alphabet Σ, a constraint set on Σ is a set of subsets of Σ. If C is a constraint set on Σ2,
then we say that a constraint graph G has constraints in C if every edge constraint is an element
of C.

We will describe a tester and a decoder for our code C. Here we describe
