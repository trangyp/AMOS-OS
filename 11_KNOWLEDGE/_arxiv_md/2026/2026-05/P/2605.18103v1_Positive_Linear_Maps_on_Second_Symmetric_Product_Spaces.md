POSITIVE LINEAR MAPS ON SECOND SYMMETRIC PRODUCT SPACES
PAVANKUMAR RAICKWADE AND K. C. SIVAKUMAR
Abstract. Let X(2) denote the second symmetric product space of a partially ordered vector space
X, endowed with the projective cone.
A characterization of linear maps T : X(2) →X(2) which
preserve the set of all positive decomposable vectors, is proved. As applications of this result, an
alternative proof, as well as an infinite dimensional generalization, of a representation theorem for
(i) automorphisms on the completely positive cone and (ii) linear preservers of CP-rank-1 matrices,
are presented. It is also shown that if T preserves the set of all decomposable vectors, then so does
the Drazin inverse, T D (if it exists). The case of the Moore-Penrose inverse is also investigated.
1. Introduction
For a vector space X, let X ⊗X denote its tensor product with itself. The subspace X(2) ⊆X ⊗X,
of all symmetric tensors of degree two, is called the second symmetric product space of X. For a
nonzero element A ∈X(2), the rank of A is the least integer k such that A = Pk
i=1 λi(xi ⊗xi) where
x1, . . . , xk are linearly independent vectors in X and λ1, . . . , λk are nonzero scalars in R. The rank
atmost one elements in X(2) are called the decomposable elements. For a linear map f : X →X, the
linear map P2(f): X(2) →X(2), given by
P2(f)(x ⊗y) = f(x) ⊗f(y),
∀x, y ∈X,
is called the second symmetric power of f. A linear map T : X(2) →X(2) is called rank one non-
increasing (or a linear preserver of decomposable elements) if, rank(A) = 1 implies rank(T(A)) ≤1. In
[8, Theorem 1], the author characterized linear maps T : X(2) →X(2) that are rank one non-increasing,
as follows.
Theorem 1.1. Let T : X(2) →X(2) be linear. Then T is rank one non-increasing if and only if either
of the following holds.
(i) T = cP2(f) for some linear map f : X →X and c ∈R \ {0},
(ii) T(·) = ϕ(·)y ⊗y for some linear functional ϕ: X(2) →R and y ∈X.

2. Preliminaries
2.1. Partially ordered vector spaces. Let X be a real vector space and X′ denote the algebraic
dual of X, i.e. the space of all linear functionals on X. A partial order ≤on X is called a vector space
order if the following compatibility relations hold:
∀x, y, z ∈X : x ≤y =⇒x + z ≤y + z,
∀x, y ∈X, λ ≥0: x ≤y =⇒λx ≤λy.
In this case, we call X a partially ordered vector space. A set K ⊆X is called a cone if K is closed
under addition, λK ⊆K for every λ ≥0, and K ∩(−K) = {0}. If “ ≤” is a vector space order on X,
then
(2.1)
X+ := { x ∈X | x ≥0 }
is a cone. On the other hand, if K ⊆X is a cone, then a vector space order on X is given by
(2.2)
x ≤y :⇐⇒y −x ∈K,
and for X+ as in (2.1), one obtains X+ = K. Hence, there is a one-to-one correspondence between
cones and vector space orders, and we denote an ordered vector space by (X, X+) in case we want to
specify the corresponding cone. The articles [1, 2, 7] are excellent sources for information on cones
and partially ordered vector spaces.

dual of X.

2.3. Generalized inverses. Let us recall the notions of the Moore-Penrose inverse and the Drazin
inverse of a linear operator.
Let H1, H2 be Hilbert spaces over the same field of scalars and let
B(H1, H2) denote the space of all bounded linear operators from H1 to H2. Let R(T), ker(T) denote
the range and kernel of T, respectively. If T ∈B(H1, H2) has closed range, then there exists a unique
([16, Theorem 2.2.1]) linear operator U ∈B(H2, H1) such that
(2.3)
TUT = T, UTU = U, (TU)∗= TU, (UT)∗= UT.
This operator U is called the Moore-Penrose inverse of T, denoted by T †. On the other hand, if, for
T ∈B(H1, H2), there exists U ∈B(H2, H1) satisfying (2.3), then R(T) is closed. To see this, Let {yn =
T(xn)}n∈N ⊆R(T) be such that yn →y. Then UT(xn) →U(y), and so yn = TUT(xn) →TU(y).
Thus y = TU(y) ∈R(T). For more details on the Moore-Penrose inverse, see [17, 16].
For the Drazin inverse, we consider a vector space X and a linear operator T : X →X. We say
that T is Drazin invertible if there exists S : X →X and k ∈Z+ := N ∪{0} such that

Ind T ≤k if and only if R(T k+1) = R(T k) and ker(T k+1) = ker(T k). The Drazin inverse of a linear

[17, 20].
