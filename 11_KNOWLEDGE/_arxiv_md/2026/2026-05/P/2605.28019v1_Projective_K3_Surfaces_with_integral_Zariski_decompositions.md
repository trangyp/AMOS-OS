SICHEN LI
Abstract. We characterize all projective K3 surfaces on which every integral pseudo-
effective divisor admits an integral Zariski decomposition, using an explicit, terminating
finite-step algorithm.
1. Introduction
The geometric significance of Zariski-Fujita decomposition [Fuj79,Zar62] lies in the fact
that, given an integral pseudo-effective divisor D on a smooth projective surface X with
Zariski decomposition D = P + N such that P and N are Q-divisors, P is nef, and one
has for every sufficiently divisible integer m ≥1 the equality
H0(X, OX(mD)) = H0(OX(mP)).
We say X has bounded Zariski denominators if there exists such d(X) = m which is inde-
pendent of the choice of D. In fact, d(X) is defined as the maximum of the denominators
appearing in the Zariski decomposition of all integral pseudo-effective divisors on X.
A celebrated theorem of Bauer, Pokora, and Schmitz [BPS17] says that X has bounded
Zariski denominators if and only if X satisfies the bounded negativity conjecture (cf.
[Bauer et al. 13, Conjecture 1.1]) as follows.
Theorem 1.1. For a smooth projective surface X over an algebraically closed field, the
following two statements are equivalent:
(1) X has bounded Zariski denominators.
(2) X satisfies the bounded negativity conjecture (BNC for short), i.e., there exists an
integer b(X) ≥0 such that C2 ≥−b(X) for every curve C ⊆X.
We say that a smooth projective surface X satisfies d(X) = 1 if every integral pseu-
doeffective divisor D on X admits the Zariski-Fujiki decomposition D = P + N with P
and N integral divisors. On the one hand, let X be a smooth projective surface with
d(X) = 1. Then X satisfies the BNC by Theorem 1.1. On the other hand, the following

2. Preliminaries
Notation and Terminology. Let X be a smooth projective surface over C.
• By a curve on X, we mean a reduced and irreducible curve.
• A negative curve on X is a curve with negative self-intersection.
• A (−k)-curve on X is a curve C with C2 = −k < 0.
• The intersection matrix of some curves C1, · · · , Ck on X is
I(C1, · · · , Ck) = (Ci · Cj)1≤i,j≤k.
