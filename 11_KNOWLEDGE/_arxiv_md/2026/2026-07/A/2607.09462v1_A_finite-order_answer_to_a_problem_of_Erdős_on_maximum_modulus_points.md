A FINITE-ORDER ANSWER TO A PROBLEM OF ERD˝OS ON
MAXIMUM MODULUS POINTS
LETICIA PARDO-SIM´ON AND DAVID J. SIXSMITH
Abstract. In 1964, Erd˝os asked whether, for a non-monomial entire function, the
number of maximum modulus points on the circle |z| = r can become arbitrarily large
as r →∞. In 1968, Herzog and Piranian answered this question affirmatively, but
without quantitative control on the resulting function. We prove that such an example
can be chosen to have finite order and, moreover, to belong to the Eremenko–Lyubich
class B. We also prove an interpolation theorem for maximum modulus sets: prescribed
points with pairwise distinct moduli can be forced to lie in the maximum modulus set
of some function in B, with finite order under a geometric separation condition.
1. Introduction
For r ≥0, write M(r, f) ..= max|z|=r |f(z)|. Following [Six15], we denote by M(f)
the maximum modulus set of f, that is,
M(f) ..= {z ∈C: |f(z)| = M(|z|, f)}.
(1.1)
If f is a monomial, then M(f) = C. Otherwise, M(f) consists of a union of closed
maximum curves, which are analytic except possibly at their endpoints; see [Val49,
Theorem 10] or [Blu07]. Maximum modulus sets have been studied by many authors;
see, for example, [Har09, JL86, Tyl00, COS90, HTW13, PS22].
For a non-monomial entire function f, the intersection of M(f) with each circle
|z| = r, r > 0, is finite. We denote its cardinality by
vf(r) ..= #(M(f) ∩{|z| = r}).
The elementary examples fn(z) = exp(zn), n ∈N, show that there is no local obstruction
to having many maximum modulus points on a circle: in this case vfn(r) = n for every
r > 0. Erd˝os asked whether this phenomenon can occur, with n tending to infinity, for
a single non-monomial entire function. More precisely, he asked the following.
Question (Erd˝os, 1964). Let f be a non-monomial entire function.
(1) Can vf be unbounded, that is, can one have lim supr→∞vf(r) = ∞?
(2) Can vf tend to infinity, that is, can one have lim infr→∞vf(r) = ∞?
The problem seems first to have appeared in Hayman’s book on research problems in
function theory [Hay67]; see also [GP24] for further historical discussion, including the
later attribution of the second part to Clunie.
The first part of Erd˝os’ question was answered positively by Herzog and Piranian
[HP68], who constructed an entire function f such that vf(n) = n for every n ∈N. Their

The proof of Theorem 1.1 uses logarithmic coordinates. Lifting by the exponential
map, circles become vertical lines, and maximum modulus points become points where
the associated logarithmic transform is maximal on a vertical line.
We construct a
conformal model whose tract has, at selected real parts, many competing channels. The
geometry is arranged so that many channels realise the maximum simultaneously. We
then approximate the model by an entire function in class B, using the approximation
theorem of Rempe [Rem14]. The main difficulty is to keep the tract sufficiently regular
to obtain finite order.
The same method also gives a different kind of flexibility. Instead of asking how many
maximum modulus points can lie on one circle, one may ask how freely the position of
maximum modulus points can be prescribed. Our second result says that, within the
class B, essentially any escaping sequence of points on distinct circles can be forced to
lie in the maximum modulus set.
Theorem 1.2. Suppose that (zn)n∈N is a sequence of points in the plane, tending to
infinity, and such that no two points have the same modulus. There is an entire function
f ∈B such that zn ∈M(f), for all n ∈N. Moreover, if there is a constant K > 1 such
that |zn+1| ≥K|zn|, for all n ∈N, then f can be taken to have finite order.
Remark. The escape condition in Theorem 1.2 is natural.
Indeed, near the origin,
the maximum modulus set of a non-monomial entire function consists of finitely many
analytic arcs meeting with equal angles; see [Hay51, EPS21]. In a forthcoming paper
[PS26], we show that an analogous local description holds near any point of the plane.
