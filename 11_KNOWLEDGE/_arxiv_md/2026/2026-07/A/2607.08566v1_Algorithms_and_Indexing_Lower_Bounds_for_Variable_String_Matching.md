Algorithms and Indexing Lower Bounds for Variable String
Matching
Estéban Gabory∗
Institute of Computer Science, University of Wrocław, Wrocław, Poland
Abstract
A generalized degenerate string (GD) is a sequence T = T1 · · · Tn of nonempty finite sets
of strings (called segments) such that all strings within each segment have the same length,
called the width of the segment.
We study pattern matching in generalized degenerate
strings: given a solid string P and a GD string T, decide whether P occurs in T, that is,
whether P is a substring of a string obtained by concatenating one string from each segment
of T. This problem was identified by Ascone et al. (WABI 2024) as the main remaining
open case in the fine-grained complexity of pattern matching on variable strings, a family
of string representations for sets of similar strings with different levels of generality. It is
the remaining boundary case between the variants admitting near-linear-time algorithms
and those with quadratic conditional lower bounds under SETH. In this paper, we show
a ˜O(N√m)-time algorithm for GD string matching, where N is the total size of T and
m = |P|, placing the problem on the subquadratic side of this boundary.
We complement this with upper and lower bounds for the indexed setting. For elastic-
degenerate strings (ED), where the equal-width condition is dropped, Gibney (SPIRE 2020)
showed that one can answer pattern matching queries in O(nm2) time where m is the
length of the pattern and n is the number of segments of the ED string, after linear-time
preprocessing. We show that this index can be adapted to GD strings to answer queries
in O(nm) time. We observe that an existing SETH-based reduction from the same paper
already applies to GD strings and rules out indices with polynomial-time preprocessing
and with query time O(n1−εmO(1) + m) for any ε > 0. We then prove that, under the
k-clique conjecture, no combinatorial index with polynomial preprocessing time can answer
queries in O(nO(1)m1−ε + m) time for any ε > 0. For ED strings, we prove under the same
conjecture that no combinatorial index with polynomial preprocessing can answer queries
in O(nO(1)m2−ε) time for any ε > 0, matching the quadratic dependence on m in Gibney’s
upper bound. Finally, assuming the OMv conjecture, we show that there is no data structure
that, after polynomial-time preprocessing of a set of strings and a pattern, answers active-
prefix queries on a bit vector of length m in O(m2−ε) time for any ε > 0; such queries are
the standard bottleneck in elastic-degenerate pattern matching. Taken together, these lower
bounds suggest that improving the query time for indexed ED pattern matching below
O(nO(1)m2) would require both non-combinatorial techniques and an approach that avoids
using active-prefix queries as the central bottleneck.

String matching (or pattern matching) is a fundamental task
in computer science. Given a text and a pattern, one asks whether the pattern occurs in the text,
or asks to count or report all occurrences. This simplest setting can be solved in linear time [9].
This line of research has since been extended to more complex settings, such as approximate
matching [21, 22, 8, 14, 7], or pattern matching on different data structures [19, 23, 18, 16, 2,

A natural generalization is to replace each position of a string by a set (called a segment),
representing the possible characters at that position.
This leads to several data structures
with different levels of generality, from degenerate strings (or indeterminate strings) where the
segments are subsets of the alphabet, to elastic-degenerate strings where segments can be any
finite set of strings (see Figure 1).
Ascone et al. [3] studied the fine-grained complexity of
pattern matching in each of those variants (collectively called variable strings) and showed a
clear dichotomy between the cases where a solid pattern can be matched in near-linear time
and cases admitting quadratic conditional lower bounds under SETH. More precisely, they gave
a near-linear algorithm for pattern matching in a k-degenerate string, where each segment is
a set of length-k strings, for a fixed integer k. For the lower bounds, Backurs and Indyk [4]
showed that a subquadratic algorithm for pattern matching in an elastic-degenerate string would
contradict SETH. The intermediate case of generalized degenerate strings (GD), in which the
strings within each segment have a common length that may vary between segments, was left
as an open boundary case, with an O(N + nm)-time algorithm, where N is the total size of the
text, n is the number of segments, and m is the length of the pattern.
Generalized degenerate strings were first introduced by Alzamel et al. [1] as a restriction of
elastic-degenerate strings. Importantly, they showed that one can solve the intersection problem
(namely, assessing whether two given variable strings have a common string in their languages) in
linear time for GD strings. For ED strings, subquadratic conditional lower bounds and matching
upper bounds were shown [13]. It is therefore natural to ask whether the same separation holds
for pattern matching.
Recently, Equi et al. [10] gave a subquadratic quantum algorithm for pattern matching in a
GD string, running in ˜O(
√

this paper, we answer this question by giving a classical algorithm solving pattern matching in
GD strings in ˜O(N√m) time.
Another classical task is text indexing, where a text can be preprocessed to answer pattern
matching queries faster than the time needed to solve the problem from scratch. In the case of
variable strings, a natural goal is to obtain a query time that does not depend on N, but instead
on the number of segments n and on the pattern length m. For ED strings, the main results
were given by Gibney [15], who showed the existence of a data structure answering queries in
O(nm2) after linear-time preprocessing, and claimed conditional lower bounds under SETH,
showing that no index can answer queries in O(nαmβ + m) time with α < 1 or β < 1.
Contributions.
We show that pattern matching in a GD string can be solved in ˜O(N√m)
time, where N is the total size of the text and m is the length of the pattern. This answers the
open question left by Ascone et al. [3], and places GD strings on the subquadratic side of the
boundary between cases admitting near-linear algorithms and cases with quadratic lower bounds
under SETH. The algorithm computes, for each column of the text, the number of segments
matched by the pattern when aligned at that column. This array is computed by a heavy-light

time for indexed ED pattern matching below O(nO(1)m2) would require both non-combinatorial
techniques and an approach that avoids using active-prefix queries as the central bottleneck.

Indexing
4.1
On previous results
For ED strings, Gibney [15] gave the main indexing results, and several of them can be directly
applied in our setting. In particular, an index for ED strings was given, answering queries in
O(nm2) time after linear-time preprocessing. In fact, by slightly adapting the index, we can
obtain an index for GD strings with linear-time preprocessing and O(nm) query time.
Theorem 4. A GD string T can be preprocessed in O(N) time so that pattern matching queries
are answered in O(nm) time.
Proof. For every segment Ti, we build an Aho–Corasick automaton for the set of strings in Ti.
We also build two generalized suffix trees: one for Ti, and one for the set obtained by reversing
every string in Ti. The total size of these data structures over all segments is O(N).
When a query pattern P of length m is given, we process the segments from left to right,
maintaining a bit vector that marks the prefixes of P matched by the segments processed so
far. As in Theorem 3, we distinguish the four cases: easy, suffix, prefix, and anchor. The easy
case is handled by searching P in the generalized suffix tree of Ti, which takes O(m) time. The
suffix and prefix cases are handled by searching for the prefixes and suffixes of P that match
strings in Ti, which can be done in O(m) time using the generalized suffix trees. Finally, the
anchor case is handled by reporting the occurrences of strings of Ti as substrings of P. This
takes O(m + Occ) = O(m) time using the Aho–Corasick automaton, since all strings in Ti have
6


## Page 7


the same length and therefore the cumulative number of occurrences is at most m. Since each
segment is processed in O(m) time, the total query time is O(nm).
Another result from [15] is a conditional lower bound for indexing ED strings, showing that
no index with polynomial preprocessing can answer queries in O(nαmO(1)) time with α < 1,
unless SETH is false. The proof is based on a reduction from the Orthogonal Vectors problem:
Orthogonal Vectors (OV)
Input: Two sets X and Y of n vectors in {0, 1}d, where d = Θ(log n)
Question: Does there exist a pair (a, b) ∈X × Y such that a · b = 0?
The Orthogonal vectors hypothesis (OVH) states that OV cannot be solved in O(n2−ε) time
for any ε > 0. It is known that OVH is implied by SETH [24]. Importantly, OVH also implies
hardness for the indexing version of the problem:
Lemma 5 ([11, 12]). Under OVH, one cannot solve OV in O(|X|α|Y |β) with α < 1 or β < 1,
even after allowing arbitrary polynomial-time preprocessing of X.
We observe that the reduction of Gibney actually uses generalized degenerate strings, hence
the same lower bound applies to GD strings:
Theorem 6 ([15]). Over an alphabet of size two, there is no solution for GD-indexing with query
time O(nαmO(1) + m) for constant α < 1 under OVH (and hence SETH), even with arbitrary
polynomial preprocessing.
Finally, another reduction from the same paper gives the following result:
Theorem 7 ([15]). OV-indexing on vector sets X, Y ⊆{0, 1}d can be reduced to ED-indexing
over an ED-text T, constructed from X, of length n = O(d(|X|+|Y |)), of size N = O(d(|X|2 +
|Y |)), and having an alphabet of size four. One pattern P needs to be given as a query, where P
is constructed from Y and has length m = O(d|Y ||X|).
It is then claimed that this implies a lower bound that prohibits any index with polynomial
preprocessing that can answer queries in O(nαmβ + m) time with β < 1, unless SETH is false.
However, the proof appears not to account for the additive +m term, which is necessary to
read the pattern P in the query. In fact, since m = O(d|Y ||X|), simply reading the pattern
already takes enough time to solve the OV instance without contradicting OVH. We did not find
a way to fix the reduction, and leave the existence of such a lower bound as an open problem.
However, in what follows, we show several hardness results for indexing GD and ED strings,
which suggest that the claimed lower bound for ED strings is likely to hold.

4.3
Active-prefix problem
Let us consider the following problem:
9


## Page 10


Active-prefix (AP)
Input: A string P of length m, a bit vector U of length m, and a set S of strings of total
size N
Question: Compute a bit vector V of length m such that V [j] = 1 if and only if there exist
i ≤j and s ∈S such that U[i] = 1 and P[1 . . . i] · s = P[1 . . . j].
This problem is often considered the main bottleneck for elastic-degenerate string matching,
as every existing algorithm computes partial matches from left to right and extends them upon
processing the segments of the elastic-degenerate text [16, 2, 5, 3]. We consider the Online
Boolean Matrix-Vector multiplication (OMv) conjecture [17], and show that active-prefix queries
cannot be answered in O(m2−ε) time for any ε > 0 after polynomial-time preprocessing of the
string set and the pattern, unless the OMv conjecture is false. This suggests that a query time
of O(nO(1)m2−ε) for some ε > 0 is unlikely to be achieved for elastic-degenerate string indexing,
unless this comes from a radically different approach than the existing ones. In particular, the
O(nm2)-time index from [15] is likely to be optimal, unless one can improve upon it with a
non-combinatorial algorithm without relying on the AP problem.
We consider the following problem:
Online Boolean Matrix-Vector multiplication (OMv)
Index: A Boolean matrix M of size n × n
Queries: Given a sequence of vectors v1 . . . vn, after receiving vi, return Mvi before receiving
vi+1.
Conjecture 15 ([17]). For any constant ε > 0, there is no algorithm for OMv that answers all
queries in O(n3−ε) time, even after arbitrary polynomial-time preprocessing of M.
The reduction is based on that of Bernardini et al. [5], which reduces Boolean matrix mul-
tiplication to AP and gives a combinatorial lower bound for the latter problem. We observe
that the same construction can be interpreted in the indexed setting: after preprocessing the set
of strings encoding the matrix, each active-prefix query corresponds to an online vector query.
This yields a lower bound for indexed AP under the OMv conjecture.
Theorem 16. Assuming the OMv conjecture, one cannot preprocess a set of strings S of total
size N and a pattern P of length m in polynomial time in N +m and answer active-prefix queries
for an input vector U in O(m2−ε) time for any ε > 0.
Proof. Let M be an n × n Boolean matrix.
Let the alphabet be {a, b} and set P = anban. For every entry M[i, j] = 1, add the string
si,j = an−jbai to S. Then |P| = 2n + 1 = Θ(n), and ||S|| ≤n2(2n + 1) = O(n3). Thus S can
be constructed and preprocessed in polynomial time in the size of M.
Now consider an online vector v ∈{0, 1}n. We build the AP bit vector U = v · 0n+1, so
U[k] = v[k] for 1 ≤k ≤n, and U[k] = 0 for n < k ≤2n + 1. Let V be the answer to the AP
query (P, U).
We claim that for every i ∈{1, . . . , n},
V [n + 1 + i] = 1
⇐⇒
(Mv)[i] = 1.
Indeed, for k, i, j ∈{1, . . . , n},
P[1 . . . k] · si,j = akan−jbai = ak+n−jbai.
This is a prefix of P = anban if and only if k = j, and then it is exactly P[1 . . . n + 1 + i].
Therefore V [n + 1 + i] = 1 if and only if there exists j such that U[j] = 1 and M[i, j] = 1, which
is precisely (Mv)[i] = 1.

Consequently, one AP query computes the matrix-vector product for one online vector. If
AP queries could be answered in O(m2−ε) time after polynomial preprocessing of S and P,
then any sequence of online vectors could be processed by issuing one AP query per vector. In
particular, the total query time would be O(n3−ε). This contradicts the OMv conjecture.
5
Conclusion and future work
We studied the problem of pattern matching in generalized degenerate strings, and we gave an
algorithm running in ˜O(N√m) time, which is the first classical subquadratic-time algorithm for
this problem. We also gave a combinatorial lower bound for indexing generalized degenerate
strings (resp. elastic-degenerate strings), showing that no combinatorial algorithm can answer
queries in O(nO(1)m1−ε + m) time (resp. O(nO(1)m2−ε)) after polynomial preprocessing, unless
the k-clique conjecture fails. We also showed that active-prefix queries cannot be answered in
O(m2−ε) time after preprocessing the string set and pattern in polynomial time, unless the OMv
conjecture fails. We leave open the following questions:
• Is the ˜O(N√m)-time algorithm for generalized degenerate string matching optimal? Can
we improve it to near-linear time, or prove a matching lower bound? Another natural
target is to match the running time of the quantum algorithm of Equi et al. [10], namely
˜O(
√
Nmn) time.
• Could we extend our lower bounds to general algorithms, not only combinatorial ones?
• A symmetric taxonomy was considered for the graph variant of each type of variable
string [3], where adjacent segments in the text are connected by edges and where con-
catenations are allowed only along paths in the graph. In particular, the same gap was
observed: it is not known whether one can solve pattern matching in founder graphs, the
graph variant of generalized degenerate strings, in subquadratic time. Can we adapt our
techniques to this setting?
