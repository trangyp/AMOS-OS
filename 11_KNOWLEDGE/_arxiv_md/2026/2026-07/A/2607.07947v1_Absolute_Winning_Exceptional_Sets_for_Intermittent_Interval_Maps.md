ABSOLUTE WINNING EXCEPTIONAL SETS FOR
INTERMITTENT INTERVAL MAPS
JASON DUVALL
Abstract. We prove that for a Manneville–Pomeau type interval
map, the set of points whose orbit closures miss a prescribed count-
able set is absolute winning in the sense of McMullen. The proof
has three parts. First we directly prove that the exceptional set
for the distinguished endpoint of the induced first-return map is
absolute winning. Then we use the finite-branch winning theorem
of Hu–Li–Yu, together with the one-dimensional implication from
1/2-strong winning to absolute winning, to obtain absolute winning
for all countable induced targets. Finally, a quasisymmetric pull-
back argument transfers these induced results back to the original
map.

2. The absolute game
We recall McMullen’s absolute game [5] specialized to the present
setting. Let I ⊂R be a nontrivial compact interval and let S ⊂I. Fix
0 < β < 1/3. In the β-absolute game, Bob chooses a nontrivial closed
interval B1 ⊂I. After Bob chooses Bn, Alice deletes a closed interval
An ⊂Bn satisfying
|An| ≤β|Bn|.
Bob then chooses a closed interval satisfying
Bn+1 ⊂Bn \ An,
|Bn+1| ≥β|Bn|.
Alice wins if T Bn meets S. If Alice is able to win regardless of Bob’s
choices, S is called β-absolute winning; S is called absolute winning if
it is β-absolute winning for every 0 < β < 1/3.
We will repeatedly use the following standard facts due to McMullen
[5] without further mention.
Theorem 2.1 (McMullen). Absolute winning subsets of an interval are
dense, uncountable, and have full Hausdorff dimension. The absolute
winning property is stable under countable intersections and quasisym-
metric homeomorphisms. Supersets and cocountable subsets of absolute
winning sets are again absolute winning. Consequently, if S, C ⊆I and
C is countable, then S ∪C is absolute winning in I if and only if S is
absolute winning in I.
In addition, Badziahin, Harrap, Nesharim, and Simmons proved the
following relationship between the various notions of winning in one
dimension [1].
Theorem 2.2 (Badziahin, Harrap, Nesharim, and Simmons). A subset
of R that is 1/2-strong winning is absolute winning.
We will also use the following finite-branch theorem of Hu–Li–Yu [3].

Finally, we record the following elementary locality principle to pass
from absolute winning on the components of the complement of a closed
countable set to absolute winning on the whole interval.
Lemma 2.4 (A locality property). Let S ⊂[0, 1]. Suppose C ⊂[0, 1]
is closed and countable and every component U of [0, 1] \ C has the
following property: for every nontrivial compact interval I ⊂U, the set
S ∩I is absolute winning in I. Then S is absolute winning in [0, 1].
Proof. This is standard, but we include the short argument for com-
pleteness. Fix 0 < β < 1/3. Alice begins by making arbitrary legal
deletions of maximal length until Bob first chooses an interval contained
in a single component U of [0, 1] \ C. If this never happens, then Bob’s
intervals shrink to a single point ω. Since C is closed, if ω /∈C, then ω
lies in some component U of [0, 1] \ C, and all sufficiently small Bob
intervals would be contained in U, a contradiction. Hence ω ∈C, so
Alice wins for the target S ∪C.
Otherwise, suppose Bob chooses an interval Bn contained in a com-
ponent U of [0, 1] \ C. Choose a nontrivial compact interval I ⊂U
containing Bn. From that point on, Alice plays the β-absolute winning
strategy for S ∩I inside I. Since all later Bob intervals remain inside I,
this is also a legal strategy in the original game on [0, 1], and it forces
T Bn ⊂S ∩I ⊂S. Thus S ∪C is absolute winning in [0, 1] and the
result follows.
□
