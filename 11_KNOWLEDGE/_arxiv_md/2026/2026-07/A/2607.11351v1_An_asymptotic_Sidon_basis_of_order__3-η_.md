AN ASYMPTOTIC SIDON BASIS OF ORDER 3 −η
WEI NIU
Abstract. Pilatte recently proved that there exists an infinite Sidon set of
positive integers which is an asymptotic basis of order 3, answering a problem
posed by Erd˝os, S´ark˝ozy and S´os in 1994. In this paper, we strengthen
this result by proving that for any 0 < η < 0.0527, there exists an infinite
Sidon set S ⊂N which is an asymptotic basis of order 3 −η; that is, every
sufficiently large integer m can be represented as
m = s1 + s2 + s3
for some s1, s2, s3 ∈S satisfying
min{s1, s2, s3} ⩽m1−η.
To prove this, we develop a truncated version of Pilatte’s construction and use
a deep result of Sawin on sums of Dirichlet convolutions of the von Mangoldt
function over function fields.
1. Introduction
1.1. Sidon sets. A subset S of the natural numbers is called a Sidon set if all sums s1 + s2,
with s1, s2 ∈S and s1 ⩽s2, are distinct. Introduced by Sidon [Sid32] in 1932, Sidon sets are
now widely regarded as one of the central objects in additive combinatorics. For historical
background, one can refer to the excellent book of Halberstam and Roth [HR83], the survey
of O’Bryant [OBr04], and also the book of Guy [Gu04, C9].
A fundamental question is to determine how large a Sidon set can be. For the finite case,
let f(n) be the largest cardinality of a Sidon set taken from {1, 2, . . . , n}. It is well known
that
f(n) ∼n1/2, n →+∞.
(1.1)
The upper bound is due to Erd˝os and Tur´an [ET41], while the lower bound follows from
the constructions of Singer [Sin38] and Bose [Bo42]. The asymptotic formula (1.1) was
recorded by Chowla [Ch44] and by Erd˝os [Er44]. Moreover, Erd˝os [Er94] conjectured that
for any ε > 0,
f(n) = n1/2 + Oε(nε).
The lower bound of f(n) is related to the existence of primes in short intervals, see, for
example, [OBr04, Section 4.1, p. 9; see also p. 18]. For the upper bound of f(n), an
explicit form was later given by Lindstr¨om [Li69], and then by Ruzsa [Ru93], Graham
[Gr96] and Cilleruelo [Ci10]. Recently, Balogh, F¨uredi and Roy [BFR23] and O’Bryant

1.2. Asymptotic Sidon bases. A set A ⊂N is called an asymptotic basis of order k ⩾1
if every sufficiently large integer can be written as the sum of k elements of A. Clearly, it
follows from (1.2) that no Sidon set can be an asymptotic basis of order 2. Erd˝os, S´ark˝ozy
and S´os asked the following problem in [ESS94a, Problem 14]; see also [ESS94b, Problem 8]:
Problem 1.1 (Erd˝os–S´ark˝ozy–S´os, 1994). Does there exist an infinite Sidon set which is
also an asymptotic basis of order 3?
The same problem was asked repeatedly by Erd˝os [Er94] and S´ark˝ozy [Sar01, Problem
32]. Deshouillers and Plagne [DP09] gave an affirmative answer to Problem 1.1 with the
order 7 in place of 3. The constant 7 was refined by Kiss [Ki10] to 5, by Kiss, Rozgonyi
and S´andor [KRS14] to 4, and by Cilleruelo [Ci15] to 3 + ε for any ε > 0. Here, an infinite
Sidon set S being an asymptotic basis of order 3 + ε means that every sufficiently large
integer n has a representation
n = s1 + s2 + s3 + s4,

Several of these results [Ci15, Ki10, KRS14, KS23] are based on the probabilistic method
introduced by Erd˝os and R´enyi [ER60]: construct a random set A by selecting each integer
n ∈N independently with some probability p(n), and then use standard probabilistic
inequalities, together with the Borel–Cantelli lemma to show that A satisfies the desired
properties with probability one. See the book of Halberstam and Roth [HR83] for more
details.
In a recent breakthrough, Pilatte [Pi24] completely solved Problem 1.1, starting from
Cilleruelo’s construction of infinite Sidon sets [Ci14]. Pilatte constructs a carefully designed
auxiliary set A (see Lemma 2.3) by using the alteration method 1. The elements of A
play the same separating role as the fixed number 4 and the range of xj(p) in Cilleruelo’s
construction2, while the structure of A provides enough flexibility to ensure that the
resulting set is an asymptotic basis of order 3. Pilatte’s proof also relies on a deep result of
Sawin [Saw24] on sums of Dirichlet convolutions of von Mangoldt functions over function
fields. We use the same result of Sawin in a different form, recorded below as Lemma 2.2.
In fact, Pilatte’s arguments yield the following quantitative version: Every sufficiently
large integer m can be written as
m = s1 + s2 + s3,
where each summand si in the representation of m satisfies
me−O((log m)1/2) ⩽si ⩽m.
See [Pi24, Lemma 3.4 (ii)] and [Pi24, Proof of Lemma 5.3]. Motivated by this observation
and by the 3 + ε result of Cilleruelo [Ci15], Ping Xi asked the author the following 3 −η
problem:
Problem 1.2 (3 −η). Find an admissible constant η > 0, as large as possible, such that
there exists an infinite Sidon set S ⊂N which is an asymptotic Sidon basis of order 3 −η,
that is, all sufficiently large integers m can be represented as
m = s1 + s2 + s3,
s1, s2, s3 ∈S,
where
min{s1, s2, s3} ⩽m1−η.

an asymptotic Sidon basis of order 3 −η .

Motivated by this 3 −η version of the asymptotic Sidon basis problem, Csaba S´andor
asked the following more general problem:
Problem 6.1 (a + b + 1 version). Let 0 ⩽a ⩽b ⩽1 be real numbers satisfying
a + b > 1.
Does there exist a Sidon set S ⊂N such that every sufficiently large integer m has a
representation
m = s1 + s2 + s3,
s1, s2, s3 ∈S,
with
s1 ≪ma,
s2 ≪mb,
s3 ≍m?
The condition a + b > 1 is the natural necessary condition suggested by the classical
upper bound S(x) ≪x1/2 for any infinite Sidon set S. The method of the present paper,
however, does not seem to apply directly to this more general problem.
We also propose the following problem, in the spirit of additive problems with almost
equal summands.
Problem 6.2 (Almost equal summands version). Does there exist a constant 0 < θ < 1
and an infinite Sidon set S ⊂N such that every sufficiently large integer m can be written
as

s1, s2, s3 ∈S,

We also mention related work on Bh[g]-sets, also known as generalized Sidon sets. A set
A ⊂N is called a Bh[g]-set if every positive integer has at most g different representations
of the form
n = a1 + · · · + ah,

a1, . . . , ah ∈A.
Kiss and S´andor [KS21] proved that for every h ⩾2, there exists a Bh[1]-set which is an
asymptotic basis of order 2h+1. They later improved the order from 2h+1 to 2h in [KS25].
And they [KS21, KS25] asked the following problems:
Problem 6.3. Determine the smallest value of k = k(h) ⩾h for which there exists a
Bh[1]-set which is an asymptotic basis of order k.
Pilatte [Pi24] mentioned that a simple modification of his proof should show that
k(h) ⩽2h −1.
Problem 6.4. Determine the smallest value of g = g(h) for which there exists an asymptotic
basis of order h + 1 which is a Bh[g]-set.
