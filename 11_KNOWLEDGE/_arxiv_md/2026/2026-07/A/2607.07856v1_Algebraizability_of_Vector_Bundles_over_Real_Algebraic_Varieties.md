Abstract
Let X be an affine smooth real algebraic variety (in the sense of Bochnak, Coste,
and Roy) and let V be a topological vector bundle over X(R). We investigate the
problem of deciding whether V is topologically isomorphic to an algebraic vector
bundle using motivic homotopy theory.
We prove that if dim X ≤3, then the
algebraicity of Stiefel-Whitney classes is a necessary and sufficient condition for V
to be algebraizable. Next, we show that when dim X = 4 and X(R) is compact,
even if the characteristic classes of V are algebraic, there is still an obstruction to
algebraizing V related to the Pontryagin class p1 and the Stiefel-Whitney class w4.
Then we give some applications of this result. Namely, we give an example where
this obstruction is nontrivial, and we investigate the group K0(X).

Introduction
Let X be an algebraic variety over R. Write X(R) for the topological space of R-points
of X equipped with the Euclidean topology. Let Vectn(X) denote the set of isomorphism
classes of rank n algebraic vector bundles over X, and let VectTop
n
(X(R)) denote the set of
isomorphism classes of topological rank n real vector bundles over X(R). Analytification
produces a natural map
Vectn(X) →VectTop
n
(X(R)).
Definition 1.0.1. A vector bundle V over X(R) is said to be algebraizable if it lies in
the image of this map, i.e. if it is topologically isomorphic to (the R-points of) some
algebraic vector bundle.
In this paper, we will study the problem of deciding when a topological vector bundle
over X(R) is algebraizable.
Remark. Before proceeding, we need to point out a subtlety arising from the fact that R
is not algebraically closed. If X = Spec A is a smooth integral affine variety over R, then
there are many functions f ∈A such that f is not a unit in A but f is nonzero on X(R)
(for example, the function 1 + x2 over A1
R = Spec R[x]). We will invert those functions
in the structure sheaf of X and we will allow them to be transition functions in vector
bundles. The schemes obtained by such localizations will be referred to as real algebraic
varieties. In particular, the algebraic vector bundles that we consider in this paper are
only defined over a neighbourhood of X(R). This will be made rigorous in subsection 2.3.
Remark. For obvious reasons, we will assume that X is irreducible and all vector bundles
over X(R) have constant rank.
This problem, and its analogues concerning complex vector bundles over real or com-
plex varieties, have been studied for a long time. Intuitively, an algebraic vector bundle
should have “algebraic” characteristic classes in a suitable sense. To be more precise,
recall that for a variety Y over C, we have cycle class maps
cl : CHi(Y ) →H2i(Y (C); Z)

We will say that a cohomology class is algebraic if it lies in the image of the above maps

Now it is very natural to ask if the converse is true, i.e.
if a vector bundle has
algebraic characteristic classes, is it true that the bundle itself is algebraizable? There
are many results on this problem in the case where the dimension is small and in some
special cases.
For a smooth projective or smooth affine variety of dimension 3 or less over C, the
answer is yes [6] [21]. For an affine smooth real algebraic variety X of dimension 3 or less
with X(R) compact and for X = RPn when n ≤13 and for X = Sn, the answer is also
yes [9] [13] [28] [14]. These results are mainly obtained using topological and analytic
methods or explicit constructions. Also, we know that for 4-dimensional varieties, there
exist non-algebraizable vector bundles with algebraic characteristic classes [7] [2].
In this paper, we will investigate this problem for smooth affine real algebraic varieties
using motivic homotopy theory following existing methods developed by Morel, Asok,
Fasel, and their collaborators [23] [5] [2]. For a smooth affine variety X, it was shown that
Vectn(X) is in bijection with the set of A1-homotopy classes [X, BGLn]A1 where BGLn is
the infinite Grassmannian. Hence, Vectn(X), and the obstructions to algebraizing vector
bundles, can be described using (relative) Postnikov towers. In particular, we prove the
following theorems.
