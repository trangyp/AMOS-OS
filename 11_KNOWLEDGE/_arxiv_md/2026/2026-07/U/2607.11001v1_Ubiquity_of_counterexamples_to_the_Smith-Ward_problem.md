SAMUEL J. HARRIS
Abstract. The Smith-Ward problem about matrix ranges, posed in the 1980s, was recently
resolved in the negative by Marcel Scherer [18] by obtaining a three-dimensional operator
system S ⊆M4(C∗
r (F2)) without the lifting property. However, this operator system must
be exact. In this paper we show that, for every finitely generated C∗-algebra A without the
local lifting property (LLP), there exists a three-dimensional operator system S ⊆Mn+2(A)
without the lifting property (LP), thus generalizing Scherer’s result and eliminating the
reliance on Ext(A) not being a group. In particular, we prove that whenever T is a finite-
dimensional operator system without the LP, then Mn+2(C∗
u(T )) contains a 3-dimensional
operator system without the LP for some n ≤2(dim(T ) −1).
In this way, we yield a
plethora of counterexamples to the Smith-Ward problem. In particular, unlike Scherer’s
example, these three-dimensional operator systems fail both the LP and exactness. We also
prove the existence of a three-dimensional operator system that detects nuclearity for unital
C∗-algebras, strengthening previous work of Kavruk [14].
1. Introduction
The Smith-Ward problem [19] is a problem about matrix ranges of operators. Given
an operator T ∈B(H) where H is a Hilbert space and an n ∈N, one can consider the n-th
matrix range of T, defined as
W n(T) = {Φ(T) | Φ : B(H) →Mn unital, completely positive}.
Arveson’s extension theorem [2] shows that W n(T) depends only on T and not the C∗-
algebra containing it. As an example, the set W 1(T) is the closure of the numerical range
{⟨Tx, x⟩: x ∈H, ∥x∥= 1} of T. The sets W n(T) are important for many reasons, but the
one most pertinent to this paper is that the operator system span{I, T, T ∗} is completely
described by unital, completely positive (ucp) maps into matrix algebras by the proof of the
Choi-Effros theorem (see [6]), which are described precisely by the sets W n(T) for n ∈N.
The Smith-Ward problem, arising from the Smith-Ward theorem [19], concerns es-
sential matrix ranges; that is, matrix ranges of operators in the Calkin algebra Q(H) =
B(H)/K(H) (here H is assumed to be infinite-dimensional and separable, and K(H) denotes
the compact operators).
For an operator T ∈B(H), we let ˙T be its quotient image in
Q(H). The Smith-Ward theorem [19] says that, if T ∈B(H) and N ∈N, then there exists
a compact operator K ∈K(H) such that W n(T + K) = W n( ˙T) for all 1 ≤n ≤N.
The Smith-Ward problem [19] asks whether, given an operator T ∈B(H), there exists
a K ∈K(H) such that W n(T + K) = W n( ˙T) for all values of n. This problem was open
until very recently when Scherer provided a counterexample [18]. Scherer’s counterexample
stems from a three-dimensional operator system S ⊆M4(C∗
r(F2)) that is hyperrigid in the
sense of Arveson (see [4] for an overview); that is, C∗(S) = M4(C∗
r(F2)) and every unital
∗-homomorphism π : M4(C∗
r(F2)) →B(H) has the property that there is only one ucp map
ψ : M4(C∗
r(F2)) →B(H) extending π|S. (While this is not the original form of hyperrigidity,

We note that the Smith-Ward problem has a positive answer for an operator T ∈B(H)
if and only if the associated operator system S ˙T := span{ ˙I, ˙T, ˙T ∗} ⊆Q(H) has the lifting
property (LP) (this is essentially the proof of [13, Proposition 11.4]). Moreover, whenever S
is a three-dimensional operator system that does not have the LP, then one can find a ucp
map φ : S →Q(H) that does not have a ucp lift to B(H) [13, Proposition 7.4]. Replacing
S with φ(S) yields an operator system of the form S ˙T, and hence an operator T for which
the Smith-Ward problem has a negative answer. Thus, Scherer’s three-dimensional operator
system without the LP directly yields a counterexample to the Smith-Ward problem (see
[18] for an argument on how to get from the operator system to the operator T).
(We
note in passing that Scherer’s operator system must be three-dimensional, since all one
and two-dimensional operator systems are C∗-nuclear and automatically satisfy the LP; see
Proposition 3.2.)
In this paper, we generalize the hyperrigidity theorem of Scherer in the following way:
Theorem 2.4. (rephrased) If A is a finitely generated unital C∗-algebra, then there is an
n ∈N and a three-dimensional operator system S ⊆Mn+2(A) that is hyperrigid.
When A = C∗
r(F2) we have n = 2 and the operator system S appearing in Theorem 2.4
is exactly the operator system in Scherer’s work [18]. We then give a few applications of this
theorem. The first is relaxing the criteria for finding counterexamples to the Smith-Ward
problem:
Theorem 3.1. Let A be a finitely generated unital C∗-algebra which possesses a (not neces-
sarily injective) unital ∗-homomorphism π : A →Q(H) with no ucp lift to B(H). Then there
is an n ∈N and a hyperrigid three-dimensional operator system S ⊆Mn+2(A) for which
(idn+2 ⊗π)|S : S →Mn+2(Q(H)) has no ucp lift to Mn+2(B(H)). In particular, S does not
have the LP and hence is a counterexample to the Smith-Ward problem.
As a result, whenever A is a finitely generated unital C∗-algebra and Ext(A) is not a
group, then for some n ∈N, Mn+2(A) contains a three-dimensional operator system that
is hyperrigid and does not have the LP. We find this interesting since Anderson proved in
1978 that there exists a finitely generated unital C∗-algebra A where Ext(A) is not a group
[1], before the Smith-Ward problem even originated! We note that Anderson’s algebra A is
generated by two unitaries (which coincidentally generate C∗
r(F2)) and an extra projection (or
equivalently, a self-adjoint unitary by replacing the projection p with the self-adjoint unitary
2p−1), so Anderson’s algebra A already yields a counterexample to the Smith-Ward problem
by Theorem 3.1 with n = 3.
Next, using some facts about how hyperrigidity interacts with operator system tensor
products, we show that any finitely generated unital C∗-algebra A without the local lifting
property (LLP) yields a three-dimensional operator system S ⊆Mn+2(A) (for some n)

Lastly, we use Theorem 3.7 to exhibit a three-dimensional operator system that is a

detector if, whenever A is a unital C∗-algebra with S ⊗min A = S ⊗max A (that is, there

operator systems were popularized in a paper of Kavruk [14] which exhibits a family of
nuclearity detectors, the smallest of which is a four-dimensional operator system known as
W3,2, which is contained in M6. We note that all the nuclearity detectors that Kavruk gave
are actually subsystems of finite-dimensional C∗-algebras and are duals of what are known
as WEP detectors. (An operator system T is called a WEP detector if, whenever A is a
unital C∗-algebra, then T ⊗min A = T ⊗max A if and only if A has the weak expectation
property, or WEP for short.)
Before the resolution of the Smith-Ward problem, it was not clear if there could even
be any non-C∗-nuclear three-dimensional operator systems (if all three-dimensional operator
systems were C∗-nuclear, then they would all have LP and the Smith-Ward problem would
have a positive answer [13]). Now, not only do we know that this is false, but the opposite
is true:
Theorem 4.2. There is an n ∈N with n ≤6 and a three-dimensional operator system
S ⊆Mn+2(C∗
u(W3,2)) with the following properties:
• S is hyperrigid in Mn+2(C∗
u(W3,2)).
• S does not have the LP.
• S is not exact.
• S is a nuclearity detector.
As this nuclearity detector is not exact, it cannot be a subsystem of a finite-dimensional
C∗-algebra, since exactness passes to subsystems [12, Corollary 5.8]. Theorem 4.2 further
shows that, like higher-dimensional operator systems, the world of three-dimensional opera-
tor systems is far from tame, and is in fact very wild.
The rest of the paper is organized as follows. In Section 2 we prove Theorem 2.4 on
the existence of three-dimensional hyperrigid operator subsystems of Mn+2(A), where A is
generated by n unitaries. In Section 3, we prove our main results about counterexamples
to the Smith-Ward problem and exhibit three-dimensional operator systems that fail both
the LP and exactness. Finally, Section 4 is devoted to proving the existence of a three-
dimensional nuclearity detector.

3. Three-dimensional operator systems with neither LP nor exactness
In this section, we prove that any finitely generated unital C∗-algebra with a non-lifting
unital ∗-homomorphism into Q(H) yields a three-dimensional subsystem S ⊆Mn+2(A),
for some n, without the lifting property (Theorem 3.1).
Then, using how hyperrigidity
interacts with certain operator system tensor products, we relax the assumption on A to the
assumption that A is finitely generated and does not have the LLP (Corollary 3.5). Lastly,
we provide a ubiquity of three-dimensional operator systems that fail both exactness and the
LP (Theorem 3.7). All of these operator systems yield counterexamples to the Smith-Ward
problem.
While we will have more general results about counterexamples to the Smith-Ward
problem than Theorem 3.1 later in this section, we feel that the following theorem is impor-
tant enough to state first.
Theorem 3.1. Let A be a finitely generated unital C∗-algebra which possesses a (not neces-
sarily injective) unital ∗-homomorphism π : A →Q(H) with no ucp lift to B(H). Then there
is an n ∈N and a hyperrigid three-dimensional operator system S ⊆Mn+2(A) for which
(idn+2 ⊗π)|S : S →Mn+2(Q(H)) has no ucp lift to Mn+2(B(H)). In particular, S does not
have the LP and hence is a counterexample to the Smith-Ward problem.
Proof. Suppose A has a generating set of n unitaries. We let S ⊆Mn+2(A) be the three-
dimensional hyperrigid operator system from Theorem 2.4. Let ρ : B(H) →Q(H) be the
canonical quotient map and suppose that Ψ : S →Mn+2(B(H)) is a ucp map such that
(idn+2 ⊗ρ) ◦Ψ = φ, where φ = (idn+2 ⊗π)|S. Then by Arveson’s extension theorem, we can
extend Ψ to a ucp map eΨ : Mn+2(A) →Mn+2(B(H)). Then the map Φ = (idn+2 ⊗ρ) ◦eΨ :
Mn+2(A) →Mn+2(Q(H)) is equal to φ on S. By hyperrigidity, Φ = idn+2 ⊗π. But then
the mapping a 7→(e1,1 ⊗1)eΨ(In+2 ⊗a)(e1,1 ⊗1) is a ucp lift of π to B(H), a contradiction.
Thus, S does not have the LP.
□

Proposition 3.2. The only operator systems of dimension at most two, up to unital complete
order isomorphism, are C and C2.
Proof. The one-dimensional case is trivial so we assume that S ⊆B(H) is a two-dimensional
operator system. Then S = span{I, H} for some self-adjoint contraction H with ∥H∥=
1 and {I, H} linearly independent.
Then C∗(S) = C∗(H) ≃C(σ(H)), the continuous
functions on the spectrum of H, via the Gelfand transform. This mapping sends I to the
constant function 1 and H to the function t on σ(H). As S is a subsystem of an abelian
C∗-algebra, S is a minimal operator system, in the sense that S = OMIN(V ) for some
Archimedean order unit (AOU) space V that is two-dimensional [17, Theorem 3.4]. So we
need only determine the structure of positive elements in S rather than in matrices over S.
A function α1+βt is positive in S ⊆C(σ(H)) if and only if α+βt ≥0 for all t ∈σ(H). This
inequality only depends on the extreme values for t ∈σ(H) (that is, when |t| is maximized),
so we may assume that σ(H) = {r, s} where −1 ≤r < s ≤1 and still have the same
AOU space (and hence, the same minimal operator system up to unital complete order
isomorphism). Note that since ∥H∥= 1, at least one of r = −1 or s = 1 holds. But then
it is easy to see that C(σ(H)) = C2, and since S ⊆C(σ(H)) = C2 we must have S = C2.
Thus, the only operator system of dimension 2, up to complete order isomorphism, is C2.
□
Thus, if S is a one-dimensional or two-dimensional system, then it is C∗-nuclear and
hence has the LP (this latter fact also appeared in [13, Proposition 6.13]). In stark contrast,

This follows a similar argument to a previous work of the author [8], but also relies on how
hyperrigidity interacts with tensor products.
First, we prove that for an operator system S that is hyperrigid in a unital C∗-algebra
A, exactness (respectively, LLP) of S passes to A.
To do this, we need to prove that
hyperrigidity passes to certain tensor products. The analogous version of this for the minimal
and essential operator system tensor products was proven in [9, Proposition 6.2]. We recall
that the tensor product S ⊗elT of operator systems S and T is the operator system structure
arising from the inclusion of S ⊗T into I(S) ⊗max T , where I(S) denotes the injective
envelope of S. Similarly, the tensor product S ⊗er T of operator systems S and T is the
operator system structure arising from the inclusion of S ⊗T into S ⊗max I(T ). We refer
the reader to [11] for details. One key property is that the el tensor product is left injective,
in the sense that if S1 and S2 are operator systems and S1 ⊆S2, then the identity map
id : S1 ⊗el T →S2 ⊗el T is a complete order embedding. (Similarly, the er tensor product
is right injective.) In particular, if A and B are unital C∗-algebras and A ⊆B(H), then
A ⊗el B is completely order isomorphic to the inclusion of A ⊗B in B(H) ⊗max B, so that
A ⊗el B is a C∗-algebra. (Similarly, if B ⊆B(L) for some Hilbert space L, then A ⊗er B is
completely order isomorphic to the inclusion of A ⊗B in A ⊗max B(L), so that A ⊗er B is a
C∗-algebra.)

Proposition 3.4. Suppose that S is an operator system contained in a unital C∗-algebra A
and suppose that S is hyperrigid in A.
(1) If S is exact, then A is exact.
(2) If S has the LLP, then A has the LLP.

We note that all nuclearity detectors exhibited in the work of Kavruk [14] are actually

Problem 4.3. Let S be the three-dimensional nuclearity detector from Theorem 4.2. Is Sd a
WEP detector? That is to say, is it true that a unital C∗-algebra A has the weak expectation
property if and only if Sd ⊗min A = Sd ⊗max A?
If the answer to Problem 4.3 is yes, then there is a three-dimensional operator system
S (along with its dual) whose tensor products tell us that both the Smith-Ward problem
and Connes’ embedding problem have a negative answer. Indeed, the Smith-Ward problem
having a negative answer is summarized in the fact that S does not have LP, but this
is equivalent to having S ⊗min B(H) ̸= S ⊗max B(H) where H is infinite-dimensional and
separable by [12, Theorem 8.1]. But by Theorem 4.2, the fact that S ⊗B(H) does not have
a unique operator system tensor product follows from the well-known fact that B(H) is not
nuclear!
Similarly, if Sd is a WEP detector, then applying this to C∗(F2) (or any C∗-algebra
in Kirchberg’s reformulation of Connes’ embedding problem [15]), the Connes embedding
problem would have a positive answer if and only if Sd ⊗min C∗(F2) = Sd ⊗max C∗(F2).
Thanks to the landmark result that MIP∗= RE, we know that the Connes embedding
problem has a negative answer [10], and so C∗(F2) does not have WEP, which would force
Sd ⊗min C∗(F2) ̸= Sd ⊗max C∗(F2). So it is possible that the negative solutions to both
the Smith-Ward problem and Connes’ embedding problem are wrapped up in the tensor
products of this three-dimensional operator system S (and its dual).
On the other hand, if the answer to Problem 4.3 is no, then it would provide, to our
knowledge, the first example of a finite-dimensional operator system that detects nuclearity
but whose dual does not detect the WEP.
