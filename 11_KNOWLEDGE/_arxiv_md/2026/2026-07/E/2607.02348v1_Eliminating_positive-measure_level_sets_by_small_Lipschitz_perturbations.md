ELIMINATING POSITIVE-MEASURE LEVEL SETS BY SMALL
LIPSCHITZ PERTURBATIONS
SORINA BARZA AND MARTIN LIND
Abstract. We establish a new regularity phenomenon of continuous func-
tions. Specifically, given any continuous function f and arbitrary ϵ > 0, we
construct a Lipschitz perturbation gϵ whose Lipschitz seminorm is less than ϵ
such that every level set of f + gϵ has Lebesgue measure zero.

has no level set of positive measure.

Before outlining the proof of Theorem 1.1, we briefly describe the motivation
behind the result. The theorem arose naturally in the context of rearrangement
inequalities [1]. The non-increasing rearrangement of a function f (see e.g. [2,
Chapter 2]) is defined by
f ∗(t) = inf {y > 0 : µ({x ∈I : |f(x)| > y}) < t}
(t > 0).
It is well known, and easy to verify, that f∗is strictly decreasing if and only if every
level set {x : f(x) = y} (y ∈R) has measure zero. An immediate consequence
of Theorem 1.1 is therefore that any continuous function can be perturbed by a
function with arbitrarily small Lipschitz seminorm so that the resulting function
has a strictly decreasing rearrangement. In [1], we use this observation to establish
a variant of the fractional P´olya–Szeg˝o principle for functions on the line.
We finally outline the idea behind the proof of Theorem 1.1. It is instructive to
consider how a perturbation gϵ can be constructed for a concrete and reasonably
non-trivial function with level sets of positive measure, such as the Cantor function
FC. In this case, one may define gϵ so that, on each interval where FC is constant,
its graph forms an isosceles triangle with sufficiently small height.
The height
is chosen so that the slope of gϵ remains bounded in magnitude by ϵ. It is not
difficult to convince oneself that FC + gϵ has no level set with positive measure.
The general case is subtler, since the level sets of an arbitrary continuous function
can be quite intricate. In particular, a level set may have positive measure while still
having empty interior. The construction outlined above is generalized in Lemma
2.2. Nevertheless, the proof of Theorem 1.1 itself is non-constructive, as it relies on
the Baire category theorem.
