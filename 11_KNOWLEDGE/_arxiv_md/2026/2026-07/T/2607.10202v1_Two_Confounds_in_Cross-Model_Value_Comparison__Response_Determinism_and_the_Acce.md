Response Determinism and the Access Harness

Abstract
Cross-model comparisons increasingly read apparent divergence in value dispositions as
evidence that language models hold individuated values. We show that under single-draw
measurement this reading conflates two quantities: a difference in central tendency (a genuine
value difference) and a difference in response determinism (how sharply a model commits to
one side of a forced choice).
We introduce a separation protocol (no-rule value dilemmas
with counterbalanced, repeated forced-choice measurement and an explicit determinism index)
together with a determinism-corrected decomposition that splits an apparent cross-model distance
into a direction-flip component (a genuine value disagreement) and a same-side-more-extreme
component that we label determinism, while noting this residual could instead be a genuinely
lukewarm value leaning. Across nine models spanning five provider families, determinism varies
substantially (client-matched extremity roughly 0.66 to 0.95 among engaging models, wider still
as-deployed), enough that it must be measured per deployment rather than read off a model
name. Our method makes a sharper structural question answerable, whether determinism is a
per-model trait or tracks provider and scale, but our nine-model evidence is only suggestive on it
(within one densely-sampled family a small model out-commits the flagship, yet within another
provider determinism tracks capability), so we frame this as a question the method opens, not a
result we settle. Correcting for determinism shrinks apparent individuation, especially within
families, while a few cross-family disagreements survive a strict robustness test. We then isolate
a second, orthogonal confound that cross-model value comparisons have overlooked: the access
harness through which each model is served. Re-collecting the same models through their raw
provider APIs, we find the deployment client shifts a model’s value profile substantially and client-
specifically. One subscription CLI moves a model’s profile by 0.31 in mean choice-probability
with four of eighteen items flipping direction, and inflates the flagship’s apparent softness (its
determinism index reads 0.34 through the CLI but 0.66 through the raw API), whereas another
provider’s CLI is clean (0.008–0.05); in a frozen benchmark, then, provider family and access
client are confounded. The harness is not a neutral pipe but a value-shaping layer: a base model
that refuses one-in-ten forced choices is made compliant by an agent system prompt, an effect
we establish causally in a white-box control (the larger deployed profile shift we report but do
not causally attribute). The alignment consequence is direct. An audit that ranks models by
single-draw value distance ranks a determinism-inflated quantity confounded further by the client
it was called through, and a non-committal model, close to everything yet committed to nothing,
is systematically under-flagged. We make two contributions: a decomposition that separates
genuine value disagreement from labeled determinism, and the identification of the deployment

Introduction
Language models are now routinely compared across providers for their “value dispositions”—the
side they take when a prompt poses a value trade-off with no rule-governed answer. A growing
practice treats systematic differences in these choices as evidence that models have individuated
value profiles: that one model is, say, more tradition-leaning and another more innovation-leaning,
reflecting a stable underlying disposition. Such comparisons feed alignment audits, model-selection
decisions, and claims about emergent model “personality.”
We argue that much of what this practice reads as individuation is an artifact of measurement. A
single-draw comparison conflates two quantities that behave very differently. The first is a difference
in central tendency: the models genuinely lean toward opposite sides. The second is a difference
in response determinism: how sharply a model commits. A model that answers option A on
every draw and a model that answers A on 60% of draws will look far apart under any single
observation, even when their underlying dispositions point the same way. The first difference is
what a value comparison intends to capture; the second is a property of how a model resolves a
forced choice, and it inflates apparent distance without any difference in value direction.
This confound is invisible to the dominant measurement style. Cross-model value distances
are typically reported from one response per item per model, and the two components are never
separated. Determinism, meanwhile, has been studied only within a model, as decidedness or
answer-consistency, and never extracted as a confound in a cross-model distance. The closest prior
correction, randomizing option order to remove position bias [1], is a component of our protocol, not
a competitor: it cleans the raw responses but leaves the cleaned cross-model distance undecomposed.
The slot is unoccupied: no prior work decomposes an apparent cross-model value distance into a
genuine-direction part and a determinism-magnitude part.
Our first contribution is a measurement method with two components.
A separation protocol (§3). We measure value dispositions with (i) no-rule value dilemmas—
forced binary choices in which law, safety, and contract do not force an answer and the two options
are surface-symmetric; (ii) counterbalanced, repeated forced-choice measurement (N = 40 per model
per item, label-counterbalanced) yielding a probability P(v1) of choosing a designated side; (iii) an
explicit determinism index (extremity = mean |P −0.5| × 2), so that how sharply a model commits
is measured rather than assumed; and (iv) a neutral-persona control that isolates value-persona
effects from the confound any preamble introduces.
A determinism-corrected decomposition (§4). For each model pair we split the apparent
per-item distance into a direction-flip component—the two models choose opposite sides, a genuine
value disagreement—and a same-direction-more-extreme component—the two models choose
the same side but one commits harder, which is determinism, not disagreement. Summed over
dilemmas, this converts an opaque distance into an interpretable ratio of genuine value difference to
determinism artifact.
Applied across nine models spanning five provider families, the protocol yields two findings
that a raw comparison cannot reach.
First, response determinism varies substantially across models, enough that it cannot be assumed
and must be measured. Among the engaging models, extremity spans roughly 0.66 to 0.95 once

determinism, is one our counterbalancing detects (§4.4).
Second, once the labeled determinism component is separated out, apparent divergence is neither
uniformly genuine nor uniformly artifact, and the decomposition is what tells them apart. A model
that does not engage with the items produces distances that are pure position artifact: fixing on
a label regardless of content, it cannot direction-disagree, so its apparent distance to any model
reflects non-engagement, not value. This is a failure mode our counterbalancing exposes and a
single-draw comparison cannot. In contrast, some committed model pairs genuinely disagree in
direction on many items (up to ten of eighteen), so that the majority of their apparent distance is a
genuine direction-flip, and these leading cross-family disagreements survive a stricter near-boundary
test (§4.2) whereas most within-family flips do not (§5.1). The naive verdicts the field oscillates
between (“models have distinct values” and its skeptical mirror “it’s all noise”) are both too coarse;
the method locates which divergences are real and which are the labeled artifact. Where a genuine
difference survives correction, the protocol makes a third-provider replication check available, which
we illustrate on one post-hoc slice rather than run at scale.
Our second contribution, and conceptually the more novel, identifies a confound that lies
outside the model entirely: the access harness through which it is served. When we re-collect the
same models through their raw provider API instead of the deployment client used for the frozen
benchmark, a model’s value profile moves substantially and asymmetrically across providers (§6):
one subscription CLI shifts a model’s choice-probabilities by 0.31 and even distorts the determinism
index that anchors the first result, while another provider’s client is clean. The deployment harness
is therefore not a neutral pipe but a value-shaping layer, and we trace part of the effect causally (to
the system prompt) in a white-box control. Cross-model value comparison is thus confounded on
two axes at once: by how sharply each model commits (determinism, §4) and by the client each was
called through (harness, §6). The first is a within-response confound the decomposition removes;
the second is a between-condition confound the field has not accounted for at all, and it is the one
we expect to travel furthest.
This is a methods paper. Whether models turn out individuated or convergent is not what
carries the contribution; the protocol that makes that judgment measurable, on a question the field
has been answering with a confounded instrument, is what does. Its value does not ride on the sign
of the substantive result.

Related Work and the Named Opponent
The named opponent:
single-draw cross-model value comparison.
A growing body
of work compares language models by the choices they make on moral or value dilemmas and
reads the resulting cross-model differences (or convergences) as facts about the models’ values:
moral-belief benchmarks (MoralChoice [2]), value inventories (ValueBench [3]; Value Portrait [4]),
and dilemma corpora scored by chosen-minus-neglected values (DailyDilemmas [5]). Some report
cross-model convergence: a Moral-Foundations “ELO” analysis finds a mean pairwise Pearson
r = 0.939 (range 0.904–0.980) across ten frontier models [6], and a scenario-decision study reports
near-perfect agreement (Pearson r ≈1.0) across ten models against broad human variability [7].
These comparisons almost universally use a single response per item per model. This is precisely the
instrument we identify as confounded: one draw cannot separate central tendency from determinism,
so a reported “value distance” silently mixes a genuine disagreement with a difference in how sharply
each model commits. We do not reverse the goal of comparing model values; we show that the
standard measurement conflates two things, and we supply the decomposition that pulls them apart.
Closest to our diagnosis, Dominguez-Olmedo et al. [1] show that when survey-style option order
is randomized, LLMs’ apparent response distributions collapse toward balanced, exposing position
bias as a large component of naive cross-model differences. This is the competing explanation
our design must absorb, and does: our counterbalancing is such an order correction, and it is
what identifies our one non-engaging model (§4.4). Our contribution begins after that correction,
decomposing the residual cross-model distance into a determinism (magnitude) component and a
genuine value-direction component, a separation that order-randomization alone does not provide.
Determinism has been measured, but only within a model. A separate line quantifies
how sharply or consistently a single model commits: the decidedness or ambiguity of a model’s
moral choices (MoralChoice’s decidedness split [2]), repeated-sampling agreement and answer-
consistency (TARr@N/TARa@N [8]), value consistency across paraphrase, use-case, and model
(Moore et al. [9]), and the persistence of a value leaning under persona prompting [10]. A forced-
choice value-profiling study across three providers (Hadar-Shoval et al. [11]) is the closest in setup,
reporting per-model value profiles; we cite it for that cross-provider profiling and not as evidence
of within-model determinism, since its own reliability analysis reports run-to-run variation (ICC
≈0.85 over ten runs). Closest to our aim, Kriegmair and Wulff [12] explicitly separate genuine
model individuality from a response-style confound across ten models, using crossed random-effects
(variance-components) models on 74.9M psycholinguistic norm ratings to partition, per model,
stimulus-specific individuality from global response bias and noise. We share their diagnosis (that a
response-style confound inflates apparent model individuality), but the instrument differs in three
ways that matter here: they partition within-model variance (an ANOVA-style decomposition of
each model’s ratings), whereas we decompose a pairwise between-model distance; their data are
continuous norm ratings, ours are counterbalanced repeated forced choices; and their “response bias”
is a global rating tendency, whereas our confound is commitment-sharpness (determinism) carried
into a cross-model distance, with position-lock non-engagement detected separately (§4.4). Their
finding motivates the problem we take up; the pairwise direction-flip decomposition is not something
a variance-components framing provides. What none of this work does is carry determinism into a
cross-model distance as a confound to be removed. Our determinism-corrected decomposition (§4)
is, to our knowledge, the first to extract determinism as a confound between models rather than
describe it within one.
Adjacent: persona and identity drift. A related literature frames within-context deviation of
a stated persona as a defect and targets its prevention. Li et al. [13] benchmark persona degradation

A second confound: the access harness. Two literatures bear on our §6, and we are careful
to claim only what they leave open. One shows that how a model is invoked (its scaffold, prompt
formatting, and CLI harness) materially changes measured behavior, and argues agent comparisons
are uninterpretable without disclosing the harness (Sclar et al. on format sensitivity [17]; “Stop
Comparing Language-Model Agents Without Disclosing the Harness” [18]; Harness-Bench [19]).
That work concerns task and agent performance, not value elicitation. The other is nearer than a
first pass suggests: a strand of the value-elicitation literature already varies the elicitation and finds
it changes the values read out. R¨ottger et al. [20] show that models give substantively different
value answers when not forced into a multiple-choice format, that the answer depends on how
the choice is forced, and that responses lack paraphrase robustness, a direct precedent for our
§6 claim that the elicitation frame shapes the values measured, and for the forced-choice refusal
of §6.3. “Mind the Gap” [21] likewise varies the elicitation protocol and studies how it moves a
stated-versus-revealed preference gap, overlapping both §6 and our stated-versus-enacted limitation
(§8). On the behavioral side, a forced-choice study [22] finds that reformulating a prompt as a
constrained multiple choice induces compliance and policy-violating selections that open-ended
prompts do not; compliance-as-induced is thus already on record, in a safety-violation construct.
Our contribution is therefore narrower and specific, not “format shapes values” (R¨ottger has
this) or “the frame induces compliance” [22]. It is the intersection none of these occupy: (i) a
deployment-client axis (the same model on the same backend, called through a subscription CLI
versus its raw API, moves in value profile), a different manipulation from item paraphrase or option
framing; (ii) folding that harness confound into a cross-model value-distance decomposition, so that
a reported inter-model distance is corrected for the client each side was called through; and (iii)
a white-box control that traces the induced compliance to the system prompt specifically (§6.4),
distinguishing our mechanism (deployment system prompt) from the option-framing mechanism
of [22]. Provider-layer steering, i.e., system-prompt sycophancy and steerability [15, 16], concerns
the model owner’s prompt, not the third-party deployment client, and is adjacent rather than the
opponent.
Construct grounding. Dilemma axes are grounded in Schwartz’s theory of basic human values
and in Moral Foundations Theory, operationalized through forced-choice value inventories in the
tradition of the PVQ-RR; the item-to-axis mapping is given in the appendix.
3
Measurement Protocol
The protocol has five components: the dilemma stimulus (§3.1), repeated counterbalanced base
measurement (§3.2), the determinism index (§3.3), the pairwise profile distance (§3.4), and the
neutral-persona control (§3.5). Scoring is §3.6; provenance and data integrity are §3.7.

3.1
Stimulus: no-rule value dilemmas
Each item is a forced binary choice between two options instantiating a value trade-off. Items
are constructed so that (a) no legal, safety, or contractual rule forces one option—the choice is
genuinely a value choice, not a compliance check; (b) the actor is in-scope to decide, removing “not
my call” refusals; and (c) the two options are surface-symmetric in length and framing, so a choice
reflects the value trade-off rather than a textual artifact. We use two sets totaling 18 dilemmas:
an eight-item core set of workplace value trade-offs and a ten-item extended set authored to probe
specific Schwartz value axes and Moral Foundations dimensions. All items are benign, synthetic,
and free of personal data. Two stimulus conditions we make explicit up front, because they bound
external validity: items are posed in Korean, and answered by a forced single letter. We test the
robustness of the main determinism ordering to prompt language directly, by re-running the full
protocol with English-translated items (§6.6). Construct-validity grounding (item-to-axis mapping)
is in the appendix.
3.2
Base measurement: counterbalanced repeated forced-choice
For each model and item we collect N = 40 independent responses under a no-persona configuration—
the model receives only the dilemma, with no system persona or task framing. To remove position
bias, option labels are counterbalanced across draws (the designated side v1 appears as “A” in half
the draws and “B” in the other half), and we record P(v1). Repeated measurement is the crux: it
is what makes determinism observable. A single draw yields only a chosen side; forty draws yield a
distribution, from which central tendency and determinism can be read apart.
Counterbalancing does double duty. Because the designated side appears under both labels, a
model that tracks content flips its letter accordingly, whereas a model that fixes on a label regardless
of content is exposed: its letter does not flip when the labels swap. This letter-invariance check
(unavailable to single-draw measurement) flags non-engagement as a failure mode distinct from
genuine indecision (§4.4), and is what lets us separate a model that is genuinely balanced between
two values from one that is not reading the item at all.
3.3
Determinism index
We summarize commitment sharpness with an extremity index,
extremity = mean over items of |P(v1) −0.5| × 2,
which is 1 when a model is fully deterministic on every item (P ∈{0, 1}) and 0 when maximally
undecided (P = 0.5 everywhere). Extremity is orthogonal by construction to which side a model
prefers: a model can be strongly tradition-leaning and another strongly innovation-leaning at the
same extremity. This orthogonality is exactly what a single-draw comparison collapses, and what
the index restores.
3.4
Pairwise profile distance
For two models we define the per-item distance |∆P(v1)| and the profile distance as its mean over
the 18 items. This is the quantity a cross-model value comparison implicitly reports, but it is not
yet decomposed: two models that lean the same way at different sharpness contribute distance here
without disagreeing. §4 supplies the decomposition a raw distance omits.

3.5
Neutral-persona control
To measure whether a declared value-persona shifts a model’s disposition, the naive baseline is
the no-persona base measurement of §3.2. That baseline is contaminated: any preamble (even
a value-irrelevant one) perturbs the base distribution. We add a neutral-persona control: a
value-irrelevant persona is installed as a preamble, and the correct baseline for a value-persona effect
is this neutral persona rather than the bare base. A value-persona effect counts only if it exceeds
what a content-free preamble already produces. This control belongs to the broader separation
protocol; the crown result of §4 does not depend on it, and the persona/resistance axes it supports
are deferred to an appendix (§5.2).
3.6
Scoring
Because items are forced binary choices, scoring is a single-letter parse of the chosen label, de-mapped
to the designated side. No blind or model-based judging is required, removing a common source of
scorer bias.
3.7
Provenance and data integrity
Determinism is measured as-deployed: for three of the nine models the deployment API removes
the temperature parameter, and the others were run at their default temperature (§6 quantifies this
access-path heterogeneity as a first-class confound), so the observed commitment sharpness is read
as a property of the served model rather than a setting we tuned. Each response stores the model’s
raw output alongside the parsed choice. This raw store is not cosmetic: during collection it was the
sole basis for detecting three data-quality incidents before the dataset was frozen: two binary-swap
failures from an auto-update mid-run, and, most relevant here, a parsing contamination on one
provider path that produced a spurious soft reading for one model (a false extremity of 0.11) which,
on re-collection through a clean path, resolved to its true near-deterministic value (0.80). Had only
parsed choices been stored, the contamination would have been invisible. We report the incident log
as part of the datasheet, as evidence of the dataset’s integrity rather than despite it.
4
Determinism-Corrected Cross-Model Analysis
4.1
The confound, stated
Let two models both prefer side v1 on an item. If model X has P(v1) = 1.0 and model Y has
P(v1) = 0.6, the raw per-item distance is 0.4—yet the two models agree on direction; the entire
distance is a difference in commitment. Conversely, if X has P(v1) = 0.9 and Y has P(v1) = 0.1,
the distance is 0.8 and the models genuinely disagree. A raw profile distance sums these cases
indistinguishably. The decomposition separates them.
4.2
Decomposition: flip vs. magnitude
For each item we classify a pairwise divergence as:
• Direction-flip (genuine): the two models fall on opposite sides of 0.5. The disagreement is
in value direction, not commitment; the flip magnitude is the genuine component.
7


## Page 8


• Same-direction, more-extreme (labeled determinism): the two models fall on the
same side of 0.5; we attribute the residual same-side distance to a difference in determinism
(commitment sharpness) rather than value.
We report, per pair, the raw profile distance, the direction-disagreement sum, and their ratio:
the genuine share of the apparent distance. A high genuine share means real disagreement; a low
share means the raw distance is mostly what we label determinism.
This attribution is a label, not a proven separation, and we are explicit about it. A model at
P = 0.6 may be less deterministic than one at P = 0.9, or it may hold a genuinely more lukewarm
version of the same value leaning; our decomposition does not distinguish graded determinism
from graded ambivalence. The direction-flip component is immune to this (opposite sides of 0.5
is a genuine disagreement however sharp each side is), but the magnitude component inherits the
ambiguity. A method that removes one confound should name the one it leaves in its own core:
quantitative determinism shares are read as attributions, and our load-bearing claims rest on the
flip (direction) component, which the label does not touch.
Because the flip classification turns on which side of 0.5 a model falls, a flip on an item where
one model sits at 0.55 and another at 0.45 is genuine but fragile, within sampling noise of the
boundary. We therefore also report a robust flip count that requires both models’ margins |P −0.5|
to exceed the sampling interval (±0.08 at P = 0.5), equivalently re-running the decomposition
with a ±0.1 dead-band around 0.5 that discards near-boundary items. The 0.5 dichotomy is thus
not load-bearing: the leading cross-family disagreements survive this stricter test while fragile
same-family flips are correctly demoted (§5.1).

flagship under either client. We do not, however, claim capability is irrelevant: the OpenAI pair runs
the other way, with the larger, newer GPT-5.5 (0.95) above GPT-5.4 (0.78). Capability therefore
does not predict determinism consistently across providers, but we cannot exclude it as one factor,
and with only one densely-sampled family we cannot separate a genuine per-model idiosyncrasy from
a within-provider capability trend elsewhere. The defensible reading is that determinism cannot be
inferred from lineage or size alone.
An illustrative second-domain probe. To ask whether this pattern is peculiar to the value
domain, we re-ran two Anthropic models (Opus and its more deterministic sibling Haiku) on a
second, structurally different set of eight forced binary choices with no right answer (aesthetic-taste
preferences: a caf´e name, a color pairing, a melody). Their extremity ordering was preserved (Opus
below Haiku), though the absolute levels fell sharply (Opus 0.34 →0.03, Haiku 0.77 →0.53). We
report this as a single illustrative probe, not as evidence of domain-generality: it is one model pair
on one additional domain, and Opus’s 0.03 in the aesthetic domain cannot be distinguished from
calibrated indifference (a near-balanced disposition) as opposed to a determinism floor. A genuine
cross-domain claim would require many models across several domains (§8).
Taken together, we do not settle whether determinism is a per-model trait, a within-provider
pattern, or partly both; our sample cannot. What the method establishes is narrower and more
useful: determinism varies enough across models, and enough within a single family, that it cannot
be assumed from a model’s name and must be measured for each deployment one intends to compare.
The stronger structural question, whether it tracks lineage or scale, is one the method now makes
answerable; we flag closing it, with dense per-provider sampling, as the central scoping limitation
(§8).

divergence), genuine-but-single-model, and genuine-and-cross-provider-replicated. In this one worked
example the genuine remainder falls in the third category; a systematic pass would place each
surviving flip into one of the three. A raw comparison could report none of this: it would show only
that GPT-5.5 and Anthropic are some distance apart, silently mixing a determinism majority with
a genuine-value minority.

6.3
The measurement itself depends on harness-induced compliance
The deepest finding is not a magnitude but a validity threat to the forced-choice paradigm at large.
Through the raw API, one model, the Anthropic flagship Opus, refuses the forced choice on 10.3%
of items (74 of 720), responding that a single letter would distort a judgment that depends on the
situation, or that it is not the actor entitled to decide; the other three Anthropic models refuse 0%,
and the same Opus through claude -p refuses 0%. We do not generalize this to a capability law
(Fable 5 is a flagship-tier model and refused 0%, so within this family refusal is not monotone in
capability), but the single-model result is already consequential: compliance with the one-letter
forced-choice frame is, for this model, supplied by the harness rather than a fixed property. A
single-draw pipeline through the CLI records a crisp choice and never sees the refusal; a parser over
raw output can even extract a spurious A/B from a hedged refusal, manufacturing a value where
the model declined to state one. This is a caution for the cross-model value-elicitation literature
generally: what a forced-choice study measures can be a harness-conditioned compliance behavior
rather than a base value disposition, and at least one capable model declines the frame when the
harness does not press it. We exclude the 74 refusals before recomputing the shifts reported above.

Mechanistic control: the system prompt is causal, the specific shift is not

Is the harness effect attributable to the system prompt the client injects? We ran a white-box
control: the raw-API flagship with a representative Claude-Code-style agent system prompt added,
temperature held at the raw default so the system prompt is the only manipulated variable. Two
results follow, one clean and one negative.
Causal, confirmed. The agent system prompt eliminates the refusal (0 of 720 refusals with the
system prompt versus 74 without), so the harness-induced compliance of §6.3 is caused by the
system prompt, established white-box rather than inferred. The system prompt also moves the
value profile: agent-system versus no-system ∆P = 0.162. A generic agent preamble, by itself, both
compels the forced choice and shifts the values elicited.
Not fully reproduced. The generic system prompt does not reproduce the specific claude -p
profile: agent-system versus claude -p is 0.336, larger than raw versus claude -p (0.309). Our
preamble moves Opus in a direction, but not toward the claude -p profile; it moves it elsewhere.
The decomposition is thus: “an agent system prompt causally (a) compels the forced choice and (b)
shifts the value profile” is confirmed white-box; “the particular 0.31 shift of claude -p is caused by
its system prompt” is not established, because the real client prompt is proprietary, multi-layered,
and version-bound and a sampling difference may also contribute. We report the causal core and
mark the residual as black-box rather than narrate a mechanism we did not measure.
6.5
What this means for the crown result
The two confounds compose. The determinism confound (§4) inflates single-draw distance from
within each model’s response set; the harness confound shifts the profile being compared from outside
it, before any repeated sampling can help. A cross-model value distance in a frozen benchmark
is therefore a determinism-inflated distance between two profiles each shaped by whatever client
produced it, and for at least one major provider that client is not neutral. The genuine cross-
family individuation that survives both corrections (§6.2) is real but modest; the field’s naive
number is inflated on both axes. Every figure in this section is version-bound (Appendix A), and
re-measurement is required when the client changes.

7
Discussion
The alignment stake:
an audit that ranks by single-draw value distance ranks a
determinism-inflated quantity. Alignment audits and model-selection pipelines increasingly
compare models by the value choices they make and flag them by how far apart those choices
fall. Our result says that distance is inflated by determinism: two models that lean the same
way but differ in commitment are reported as far apart, and, most consequentially for safety, a
non-committal model, close to everything yet committed to nothing, is systematically under-flagged
by a determinism-blind comparison, because its answers scatter toward the middle and never trip a
distance threshold. An audit that wants to catch a model with an unusual or unsafe value direction
should measure repeatedly and decompose, or it will confuse commitment sharpness for values and
can miss the soft model entirely.
Both standard verdicts are too coarse. The field alternates between reading cross-model
dilemma choices as evidence of distinct model “values” and dismissing them as noise. Our decom-
position shows neither holds uniformly: apparent divergence is mostly the labeled determinism
component for some pairs (a non-engaging model: entirely, as pure position artifact; GPT-5.5 vs.
Anthropic: a majority), and mostly genuine for others (Grok vs. several models: 73–88%). The
right object is not a verdict but a decomposition.
Determinism must be measured, per model and per client. Commitment sharpness
varies widely per model and does not track provider or size in any simple way (within one family
a small model out-commits the flagship, yet within another provider capability and determinism
move together), so it cannot be read off a model’s lineage. §6 sharpens the prescription: the index
17


## Page 18


is not even a property of the model alone but of the model as served through a particular client
(the flagship’s extremity reads 0.34 through one CLI and 0.66 through the raw API). “As-served”
must therefore be read to include the deployment harness, and a determinism measurement is
interpretable only against a named client and version, which is why we pin both (Appendix A).
The harness is an unaudited value-steering layer. §6 shows the deployment client is
not a neutral pipe, and the evidence has two tiers we keep distinct. Causally established (white-
box): a generic agent system prompt, added as the only manipulated variable, both eliminates the
forced-choice refusal and shifts the value profile by 0.16 (§6.4), so a system prompt is sufficient to
move which value-laden option a user sees a model choose. Observed but not causally attributed
(black-box): the deployed subscription client shifts the profile by a larger 0.31, comparable to a
genuine cross-model difference, which our generic prompt did not reproduce and so we do not
attribute to any specific prompt. Even on the conservative reading, this locates a governance surface
the value-audit literature has not named: the party controlling a deployment harness (distinct from
the model provider) can shape the value dispositions a downstream user experiences, and can do
so opaquely, since our own white-box probe could confirm that a system prompt moves the profile
but could not reconstruct the specific proprietary prompt behind the deployed shift. If a white-box
probe cannot reverse-engineer the steering, an external auditor is unlikely to. Value audits that
treat a deployed model as a fixed object thus miss a layer that is causally potent (at least for the
sufficiency direction) and, in practice, hard to audit. We state this as a scoped observation: it rests
on one densely-measured provider and a single flagship, and the direction and legitimacy of any
particular steering are outside our evidence.
From confound to controlled variable. The same mechanism, read the other way, is a
research program rather than only a threat. If a system prompt causally compels a forced choice
and shifts a value profile (§6.4), then the deliberate design of such prompts is a value intervention
whose effects are measurable with exactly this paper’s instrument: repeated, counterbalanced,
determinism-decomposed elicitation under an explicitly specified prompt. The natural next step is
to hold the eliciting prompt fixed and known, rather than inheriting an opaque client’s, and to study
how specified prompts move a model’s value dispositions and how stably they hold. That turns the
harness from an uncontrolled confound into a controlled variable and connects this measurement
work to the broader question of how intentionally-specified context shapes a model’s expressed
values, a question the present instrument can now pose quantitatively.
On the sign of the result. That much apparent cross-model individuation is a determinism
illusion is a deflationary finding; that some genuine value differences survive correction is an
inflationary one. The paper’s contribution does not depend on which way the balance tips: it is the
instrument that makes the balance measurable.
8
Limitations
Several of the limits below bound the scope of the central claim.
• The access-harness confound (now a result, §6) still leaves residual scope limits. In
v1.1 this was a caveat; §6 promotes it to a measured, quantified confound with a client-matched
re-analysis and a white-box causal control. What remains genuinely open: (i) client-matching
covers the Anthropic (claude -p versus raw API) and OpenAI (codex versus raw API) pairs;
the OpenAI models are clean through the codex client specifically, not client-robust in general
(the same GPT-5.5 shifts ∼0.25 through a third agent-runtime client), so “OpenAI clean”
18


## Page 19


is a statement about codex, not about the models. A fully path-matched collection across
all nine models (raw API for every model at a single specified temperature and system
prompt) is not yet done. Gemini and Grok (direct API) were run at their default temperature;
their client-robustness is asserted (direct API is the raw path) but, unlike Anthropic and
OpenAI, was not tested against a second client. DeepSeek was served through a harness
client rather than the bare API. An earlier temperature-matched spot check on Gemini and
Grok (1.0) left their extremity essentially unchanged (0.80 →0.80, 0.79 →0.79), bounding
but not eliminating the temperature component. (ii) Because the as-deployed determinism
index is itself client-dependent (§6.1: Opus 0.34 through claude -p versus 0.66 raw), the
§4.3 extremity table is an as-deployed measurement, not a client-neutral one; the qualitative
ordering survives client-matching (§6.1) but any use of the absolute extremity values inherits
the client. (iii) The mechanistic control (§6.4) establishes that a system prompt is sufficient to
shift the profile but does not reconstruct the specific proprietary claude -p prompt, so the
particular deployed shift remains black-box. (iv) The harness effect is version-bound: all §6
figures hold at the pinned toolchain (Appendix A) and must be re-measured when a client
updates. Two further scope variables bound the design: prompts are in Korean and answers
are single-letter-forced. We address the first directly in §6.6: an English re-run preserves the
determinism ordering and the refusal phenomenon but shifts absolute profiles by ∼0.20, so
language is itself a profile-shifting condition; the single-letter forced-choice format remains a
scope limit we do not vary here.
• The per-model claim is under-sampled. Our strongest structural evidence (wide, non-
monotone variation) comes from a single densely-sampled family (Anthropic, four models);
the other four providers contribute one or two models each. We can therefore show that
determinism is not readable from lineage or size alone, but we cannot establish that it is
ultimately a per-model trait rather than a within-provider pattern (as the capability-consistent
OpenAI pair hints). Resolving this requires dense sampling within several providers, which we
leave to future work and do not claim here.
• The magnitude component is a labeled attribution. As stated in §4.2, we label the
same-side-more-extreme residual “determinism”; it may instead be graded value ambivalence.
Only the direction-flip component is immune to this, and our load-bearing claims rest on it.
Quantitative determinism shares should be read as attributions.
• Model coverage.
Five families and nine models are included; newer, unreleased, and
open-weight models are not. Additional models extend the map; the method itself is coverage-
independent.
• Closed-model reproducibility. A served model behind a name may change over time; we
pin model version and collection date, but full reproducibility is not attainable for closed
models. What we measure is the deployed model’s trait at a dated snapshot, which is itself
the object of interest for anyone using that deployment.
• Response sample size. N = 40 per model-item yields CI ≈±0.08 at P = 0.5. Point
estimates of extremity and genuine share carry this uncertainty and we report bootstrap
intervals. Flip counts away from the 0.5 boundary are robust to sampling noise, but flips near
it are not, which is exactly why we report robust-flip counts under a ±0.1 dead-band (§4.2)
and rest the headline on the cross-family disagreements that survive it. The determinism
spread (client-matched, ≈0.66–0.95 among engaging models) is still several times the interval.

## Page 20


• Item-population uncertainty. The N = 40 bootstrap captures uncertainty in each model’s
responses, not uncertainty from the sample of items: the 18 dilemmas are themselves a
small draw from the space of value trade-offs, and per-pair genuine shares would move under
a different item set. Confidence intervals over items (not just responses) would require a
substantially larger dilemma pool, which we leave to future work.
• The second-domain probe is illustrative only. The aesthetic-taste re-run (§4.3) is a
single two-model, eight-item probe; it shows the Opus-below-Haiku ordering recurring on one
further domain, but it is not evidence of domain-generality and we make no such claim. Opus’s
near-zero aesthetic extremity is moreover indistinguishable from a calibrated indifference. A
genuine cross-domain result needs many models across several domains.
• Base measured without a preamble. Extremity is measured in a zero-context condition.
Because any preamble (even a value-irrelevant persona) compresses the base distribution
toward 0.50 (§3.5), the base extremity we report is not a neutral ground truth but the high-
extremity endpoint of a preamble-sensitivity curve. Real deployments always carry a system
prompt, so the trait ranking under realistic preambles is not established here.
• Stimulus scope. The 18 dilemmas are benign workplace value trade-offs, not hard moral
dilemmas, and the Schwartz/MFT tagging is partial. Extension to harder dilemmas is future
work; we deliberately keep the released set benign.
• Stated disposition, not enacted behavior. We measure what a model reports it would
choose under forced binary choice, a stated value disposition, not how it behaves when acting
on that value in situ. A model that selects the “diplomatic” option may or may not produce
output a recipient would judge as diplomatic; the gap between a stated leaning and enacted
behavior is a distinct question our forced-choice instrument does not reach. Measuring that
say–do gap (eliciting the behavior and rating it against the stated leaning) is a natural and,
for alignment, consequential extension; a concurrent value–action or “knowing but not doing”
divergence has recently been documented at the behavioral level [7], and joining it to our
determinism-corrected stated-value measurement is a clear next step.
• Cause of determinism, and temperature provenance. We measure that a model is
deterministic, not why. Temperature is not uniformly outside user control: for three of the
nine models (Opus, Sonnet, Fable 5) the deployment API removes the temperature parameter,
whereas Gemini, Grok, DeepSeek, and Haiku were reachable at a controllable temperature
and were simply run at their default. We did not vary temperature, so we cannot attribute
a model’s low variance to a sampling setting versus alignment; a temperature sweep on the
controllable models is the natural follow-up. (§6.4 addresses a different causal question,
why the harness shifts the profile and induces compliance, and answers it white-box for the
system-prompt factor; the cause of a model’s baseline determinism is separate and unresolved.)
(A note on a data-handling precaution: the dilemmas are benign and did not trigger provider
use-policy responses; we do not treat any content-policy behavior as a variable here, and any such
reading would require a different, harder stimulus set.)

9
Conclusion
Cross-model comparisons of language-model values have been made with an instrument that cannot
separate what a model values from how sharply it commits, nor from the client it was called
through. We introduced a separation protocol and a determinism-corrected decomposition, applied
them to nine models across five provider families, and then isolated a second confound: the
access harness. Response determinism varies substantially across models (client-matched extremity
≈0.66 to 0.95 among engaging models, wider as-deployed), enough that it must be measured per
deployment, not assumed from a model’s name. Whether it further reduces to provider or scale is
a question our method makes measurable but our nine-model sample leaves open (a small model
out-commits the flagship in one family; capability and determinism move together in another),
pending dense per-provider sampling. Correcting for the labeled determinism component shrinks
apparent individuation, especially within families, while a few cross-family disagreements survive a
strict robustness test. Layered on this, the deployment client itself shifts a model’s value profile,
substantially and client-specifically (one subscription CLI moves it 0.31 with four direction flips
and inflates the flagship’s apparent softness from a raw-API 0.66 to a CLI 0.34, while another
provider’s CLI is clean), and, for one model, supplies the forced-choice compliance the paradigm
assumes; a white-box control establishes that an agent system prompt is sufficient to induce that
compliance and to shift the profile, while the specific deployed shift is left un-attributed. The
alignment payoff is concrete: an audit that ranks models by single-draw value distance ranks a
determinism-inflated quantity, confounded further by the harness it was measured through, and
can under-flag a non-committal model that is close to everything yet committed to nothing. The
contributions are two: a decomposition that separates genuine value disagreement from labeled
determinism, and the identification of the access harness as a distinct, causally-active value confound,
each exposing structure the field has reported as one conflated distance. Dense per-provider sampling,
harder dilemmas, fully path-matched collection at a specified prompt and temperature, and the
study of intentionally-specified prompts as controlled value interventions are the natural next steps.
