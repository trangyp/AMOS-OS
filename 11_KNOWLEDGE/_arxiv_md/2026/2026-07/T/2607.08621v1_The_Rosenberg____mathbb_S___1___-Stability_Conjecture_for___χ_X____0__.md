THE ROSENBERG S1-STABILITY CONJECTURE FOR χ(X) = 0
JIE XU
Abstract. Let X be a closed, oriented manifold with dim X ⩾5. In this article, we show that
2006 Rosenberg’s S1-stability holds when X has zero Euler characteristic. The 2006 Rosenberg-
Stolz Conjecture for X × R also follows under the same assumption, provided that the Riemannian
metric g on X ×R is complete, is of bounded curvature, and whose smallest eigenvalue is uniformly
bounded below by some positive constant. We then show a Tn-stability theorem with the same
hypothesis of X.
1. Introduction
Let X be a closed, oriented manifold, dim X ⩾5. We denote by χ(X) the Euler characteristic
of X. We also denote by g the Riemannain metric on some manifold, and Rg be the associated
scalar curvature. We say that g is a positive scalar curvature (PSC) metric if Rg > 0 everywhere.
We say that g is a uniformly positive scalar curvature metric if there exists some positive constant
κ > 0 such that Rg ⩾κ > 0 everywhere.
A 2006 Rosenberg S1-Stability Conjecture [12] asked whether the following statement is true in
the sense of “transpose” of the positivity:
X ×S1 admits a positive scalar curvature metric if and only if X admits a positive scalar curvature
metric.
One direction is trivial: X × S1 has a product PSC metric if X has a PSC metric. Since S1 is
the one-point compactification of R, it is closely related to a 1994 Rosenberg-Stolz Conjecture [13]
in the contrapositive statement:
X × R admits a complete, positive scalar curvature metric if and only if X admits a positive scalar
curvature metric.
The two conjectures are related, in that a PSC metric g on X × S1 lifts to the PSC metric π∗g
on X × R, where π : X × R →X × S1 is the smooth covering map. Note that π∗g is of bounded
curvature in the sense of of Aubin [1, Chapter 2]: g is complete, has positive injectivity radius,
and its sectional curvatures are uniformly bounded. In addition, the smallest eigenvalue of π∗g is
uniformly bounded below by a positive constant.
The main technical result answers the Rosenberg-Stolz conjecture for a wide class of metrics
on manifolds X × S1 and immediately implies the S1-stability conjecture, provided χ(X) = 0 and
dim X ⩾5. In particular, the S1-stability conjecture holds if dim(X) = 2k −1, k ⩾3.
Theorem 1.1. (i) Let X be a closed, oriented manifold with dim X ⩾5. Assume that (X × R, g)
admits a complete, uniformly PSC metric g of bounded curvature. Assume also that the smallest
eigenvalue of g is uniformly bounded below by some λ > 0. If χ(X) = 0, then X admits a PSC
metric.
(ii) Let X be a closed, oriented manifold with dim X ⩾5 and χ(X) = 0. Then X × S1 admits a
PSC metric if and only if X admits a PSC metric.
With the same hypothesis on X, we generalize the S1-stability conjecture to a Tn-stability
