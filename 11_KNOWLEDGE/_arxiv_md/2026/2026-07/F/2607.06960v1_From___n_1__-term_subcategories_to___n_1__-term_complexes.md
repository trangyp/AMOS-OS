FROM (n + 1)-TERM SUBCATEGORIES TO (n + 1)-TERM COMPLEXES
ZHAOTAI ZHANG, YU ZHOU, AND BIN ZHU
Dedicated to the memory of Idun Reiten
Abstract. Let n be a positive integer. Given an n-rigid subcategory M of an algebraic
triangulated category T, we explicitly construct an extriangulated functor from the (n + 1)-
term subcategory of T generated by M to the full subcategory of (n + 1)-term complexes
in the bounded homotopy category Kb(M), which restricts to the identity on M. In the
broader context of reduced (n −1)-Auslander extriangulated categories, we provide nec-
essary and sufficient conditions for such a functor to be full, in which case it induces an
equivalence of extriangulated categories modulo a certain ideal. Furthermore, we establish
a mutation-compatible bijection between the silting subcategories of these categories. Fi-
nally, we apply these results to n-cluster tilting subcategories and n-cluster tilting objects
in (n + 1)-Calabi-Yau categories.

1. Introduction
As a natural extension of classical tilting theory in the representation theory of algebras,
cluster tilting theory arose from the additive categorification of Fomin-Zelevinsky’s cluster
algebras [15]. The key notions in this categorification are cluster tilting objects (or subcat-
egories) and their mutations. These concepts were first introduced in cluster categories by
Buan-Marsh-Reineke-Reiten-Todorov [9] (see [11] for cluster categories of type An), and
subsequently investigated in more general 2-Calabi-Yau triangulated categories by Keller
[26, 27], Iyama-Yoshino [24], and Geiß-Leclerc-Schr¨oer [17]. One of the central problems
in cluster tilting theory is to understand the relationships between the combinatorial muta-
tion structure of cluster tilting objects in a 2-Calabi-Yau triangulated category, the cluster
algebras associated with their quivers, and the representation-theoretic properties of their
endomorphism algebras [1, 28, 29, 35].
Key words and phrases. (n + 1)-term subcategory, (n −1)-Auslander extriangulated category, extriangulated
functor, extriangle equivalence, silting subcategory, n-cluster tilting.

To approach these relationships, a fundamental tool is the τ-tilting theory introduced in
[1]. Let K be a field, and let T be a cluster tilting object in a K-linear Hom-finite Krull-
Schmidt 2-Calabi-Yau triangulated category T. Let Λ = EndT(T) be the endomorphism
algebra of T, and let mod Λ be the category of finitely generated right Λ-modules. The
functor HomT(T, −): T →mod Λ induces a mutation-compatible bijection between the set
of (basic) cluster tilting objects in T and the set of (basic) support τ-tilting modules over Λ.
Notably, this connection is part of a broader algebraic property: for any finite-dimensional
K-algebra (and thus for Λ), the 0-th cohomology functor H0(−): K[−1,0](proj Λ) →mod Λ
induces a mutation-compatible bijection between the set of (basic) 2-term silting objects
in Kb(proj Λ) and the set of (basic) support τ-tilting modules over Λ. Here, K[−1,0](proj Λ)
denotes the full subcategory of the homotopy category Kb(proj Λ) consisting of complexes
isomorphic to 2-term complexes of the form P−1 →P0, where P−1, P0 ∈proj Λ, and proj Λ
is the subcategory of mod Λ consisting of finitely generated projective modules.
Recent developments have generalized this correspondence by dropping the 2-Calabi-
Yau assumption and weakening the cluster tilting condition. Let T be an arbitrary K-
linear Hom-finite Krull-Schmidt triangulated category with suspension functor Σ, and T
a rigid object in T with endomorphism algebra Λ = EndT(T). By introducing the 2-
term subcategory CT = (add T) ∗(add ΣT), the functor HomT(T, −): CT →mod Λ [24,
30] induces a mutation-compatible bijection between the set of (basic) maximal relative
rigid objects in CT and the set of (basic) support τ-tilting modules over Λ [38, 16]. It is
worth noting that this generalization naturally recovers the aforementioned setting: if T is
cluster tilting, then CT = T, and when T is 2-Calabi-Yau, the maximal relative rigid objects
coincide precisely with the cluster tilting objects [38, 16].

Convention. Throughout this paper, all categories are additive. All subcategories are as-
sumed to be full, additive, and closed under isomorphisms. For a category C, we write
X ∈C for an object in C, and M ⊆C for a subcategory of C. For a subcategory X ⊆C, we
denote by [X] the ideal of C consisting of morphisms factoring through an object in X. For
two subcategories X, Y ⊆C, we denote by [X, Y] the ideal of C consisting of morphisms
factoring through a morphism from an object in X to an object in Y. For a class X of objects
in C, let add X denote the subcategory of C whose objects are direct summands of finite
direct sums of objects in X. If X = {X}, we simply write add X instead of add{X}. The
composition of morphisms f : X →Y and g: Y →Z is denoted by gf (or g ◦f). For any
two subcategories X and Y of a triangulated category T, we denote by X∗Y the subcategory
of T consisting of the objects Z such that there exists a triangle X →Z →Y →ΣX with
X ∈X and Y ∈Y.

We now apply the preceding results to establish a correspondence between n-cluster

Corollary 6.6. Let T be a Hom-finite Krull-Schmidt algebraic K-linear (n + 1)-Calabi-
Yau triangulated category and let M be an n-cluster tilting object in T. Suppose that
HomT(ΣiM, M) = 0 for all 1 ≤i ≤n −1. Let A = EndT(M). Then the functor P
induces a bijection between the isoclasses of basic 2-term n-cluster tilting objects in T and
the isoclasses of basic 2-term silting complexes in Kb(proj A), which is compatible with
mutation.
Assume in addition that HomT(ΣnM, M) = 0. Then the above bijection restricts to a
bijection between the isoclasses of basic 2-term n-cluster tilting objects X in T satisfy-
ing HomT(ΣX, X) = 0 and the isoclasses of basic 2-term tilting complexes in Kb(proj A).
Moreover, for any 2-term n-cluster tilting object X in T, HomT(ΣX, X) = 0 if and only if
HomT(ΣiX, X) = 0 for all 1 ≤i ≤n.
Proof. The first assertion follows from Theorem 5.20 and Proposition 6.5. When n = 1,
the second assertion is [37, Theorem 3.16 (d)], while the third assertion is trivial. Now
we assume n > 1. Since HomT(ΣnM, M) = 0, by Corollary 6.1, the functor P: T →
K[−n,0](proj A) is an equivalence of additive categories. Let X be a 2-term n-cluster tilting
object in T. Since X is 2-term, we have HomT(X, Σ−1 add M) = 0 and HomT(ΣiX, X) = 0
for all 2 ≤i ≤n −1. Hence, by Lemma 5.23, there exists an isomorphism
HomT(ΣX, X)  HomKb(add M)(ΣP(X), P(X)).
Thus, HomT(ΣX, X) = 0 if and only if P(X) is tilting. In this case, by [5, Theorem 2.1],
EndKb(proj A)(P(X)) is self-injective, which in turn implies that EndT(X) is self-injective.
