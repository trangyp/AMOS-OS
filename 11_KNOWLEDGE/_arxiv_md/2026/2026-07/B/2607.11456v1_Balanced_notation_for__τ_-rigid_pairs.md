BALANCED NOTATION FOR τ-RIGID PAIRS
KIYOSHI IGUSA AND GORDANA TODOROV
Abstract. Over any finite dimensional algebra Λ over any field K, we propose a
new notation for τ-rigid pairs: We represent these as “balanced pairs” A
B . We show
that many formulas in τ-tilting theory are simplified in the balanced notation. For
example, the Jasso category and its dual, the torsion class and torsion-free class
associated to any τ-tilting pair. Other dual concepts, such as signed and cosigned
exceptional sequences are also easier to compare using the balanced notation. Bal-
anced notation is also visually appealing because it matches the wall labels for the
semi-invariant picture in the hereditary case and almost matches the wall labels in
the general case. We also show that, in the functorially finite case, the formulas for
torsion classes given by Igusa and Maresca [11] agree with the standard formulas of
Adachi, Iyama and Reiten [1] when expressed in balanced notation.

2. Balanced notation for τ-rigid pairs
In τ-tilting theory we consider τ-rigid pairs which are defined to be pairs of
finitely generated modules (M, P) so that
(1) M is τ-rigid, meaning HomΛ(M, τM) = 0 and
(2) P is projective so that HomΛ(P, M) = 0.
Note that condition (1) holds vacuously when M is projective. We assume M and
P do not have repeated summands.
We often write the τ-rigid pair (M, P) as a
single object in the derived category of mod-Λ, namely M ⊔P[1] where M, P satisfy
conditions (1) and (2) above. We note that
τ (M ⊔P[1]) = τM ⊔νP.
If the number of summands of M ⊔P[1] is n, the rank of Λ, then it is maximal
since the g-vectors of the direct summands of M ⊔P[1] are linearly independent [1,
Theorem 5.1]. (The g-vector of P[1] is defined to be g(P[1]) = −g(P).)
Definition 2.1. Given A, B ∈mod-Λ, we define A
B to be a balanced pair if
(1) HomΛ(A, B) = 0
(2) B ∼= τA ⊔I where I is injective and
(3) A ∼= τ −1B ⊔P where P is projective

8. Application: cosigned exceptional sequences
The goal of the balanced notation was to treat projective and injective objects
equally. “Signed exceptional sequences” is another concept which gives preference
to projective objects. These are exceptional sequences in which relative projective
objects P (defined below) are allowed to be shifted forward: P[1]. We will develop
a dual notion which we call “cosigned exceptional sequences”. These are exceptional
sequences in which relatively injective objects J are allowed to be negatively shifted
to make J[−1]. We use the “co-” prefix for this notion.
Definition 8.1. Over any Artin algebra Λ, a co-τ-rigid pair is a pair of modules:
(N, J) satisfying the following.
(1) J is an injective Λ-module.
(2) HomΛ(N, J) = 0.
(3) HomΛ(τ −1N, N) = 0.
Note that condition (3) holds vacuously when N is injective. If, in addition the pair
(N, J) is maximal which is equivalent to N ⊔J having n indecomposable components,
we call (N, J) a co-τ-tilting pair.
As an object in the derived category, (N, J) corresponds to N ⊔J[−1].
To obtain what we consider to be the corresponding τ-rigid pair, we first pass to
balanced notation. The co-τ-rigid pair (N, J) corresponds to the balanced pair
