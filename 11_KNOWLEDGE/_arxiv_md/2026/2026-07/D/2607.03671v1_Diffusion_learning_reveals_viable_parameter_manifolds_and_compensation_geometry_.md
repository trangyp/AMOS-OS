Significance Statement
Biological dynamical systems often admit many parameter combinations that produce the same
function. We show that these non-unique inverse solutions form structured viable parameter mani-
folds whose dimension, tangent directions, curvature, and multimodality quantify how observables
constrain the underlying dynamics. Conditional diffusion models learn these manifolds directly from
simulation data in Lorenz, Izhikevich, and neuronal network models. The learned geometry reveals
compensation laws, hidden parameter couplings, and the number of effective degrees of freedom
that remain after the function is fixed. By turning robustness from a qualitative observation into a
measurable geometric object, this framework provides a practical route to analyzing degeneracy
and mechanism in complex biological models.
Abstract
Models of complex systems often have many parameters, yet are constrained by far fewer
experimentally accessible observables: similar activity can emerge from coordinated parameter
changes. We formalize these compatible parameter sets as viable parameter manifolds: the inverse
images of a system’s target dynamical behaviors under a parameter-to-feature map. The relevant
codimension is not the number of reported features, but the effective rank of that map at the
target scale. Co-varying features lower the codimension, while poor conditioning, high curvature,
or regime mixing degrade learnability. We train conditional score-based diffusion models on
simulated parameter–feature pairs and use them as amortized samplers of prior-weighted viable
sets. In the Lorenz system, scalar trajectory statistics generate thin viable sheets, and two-feature
conditioning localizes a transition-adjacent corridor. In the Izhikevich neuron model, four firing
descriptors lie close to a nearly two-dimensional family of features, and the learned inverse images
reveal distinct regular and irregular compensation geometries. In a recent ODE reduction of finite

Introduction
A central lesson from biological dynamics is that function can be reproducible even when the
parameters that generate it are not. Neurons with different conductance combinations can fire
in similar ways, networks with different synaptic couplings can produce comparable population
activity, and systems biology models often preserve output while many microscopic parameters
vary over wide ranges [1–6]. Across fields, this phenomenon appears as sloppiness, model-manifold
compression, structural non-identifiability, dynamical compensation, and biological degeneracy
[1, 6–12]. This degeneracy is not merely a nuisance for parameter estimation. It is one mechanism
by which biological systems remain robust, adaptable, and evolvable [2, 5, 13–15]. Yet most inverse
analyses still report isolated parameter fits, local sensitivities, or low-dimensional sweeps, leaving
the full shape of the compatible parameter set largely unseen.
We propose that the natural object of study is the viable parameter manifold: the set of parameters
that realizes a specified dynamical behavior. If θ ∈Θ ⊂Rk denotes model parameters and I(θ)
denotes a low-dimensional vector of statistics extracted from simulated dynamics, then a target
behavior y defines
My = {θ ∈Θ : I(θ) = y}.
(1)
Within a fixed dynamical regime, the statistics I often vary smoothly with the parameters, so My
is locally a level set. This simple observation changes the inverse problem. Instead of asking which
parameter configuration is best, we study the viable parameter manifold as the inverse image of the
parameter-to-feature map, My = I−1(y). Then we inquire the geometrical features of My, namely
the number of (local) dimensions, how it bends, and whether it splits into multiple mechanistic
branches.
This geometric viewpoint gives direct scientific meaning to quantities that are otherwise treated as
technical details. Intrinsic dimension estimates the number of effective degrees of freedom that remain
after fixing a target behavior. Tangent spaces encode compensation laws, i.e., infinitesimal parameter
co-variations that preserve the same output. Curvature measures how these laws change across the
viable set. Nearby level sets show how changes in the desired behavior moves through parameter
space. Disconnected components or irregular folds suggest that the chosen observables may be
mixing distinct dynamical regimes, often near bifurcations or attractor transitions. Thus, the viable-
manifold language used here gives an inverse-geometric way to connect parameter nonuniqueness to
prior work on robustness, adaptability, and evolvability [13–15].
The computational challenge is that these manifolds are embedded in parameter spaces that
are too large for exhaustive sweeps and too structured for pointwise optimization because of the
curse of dimensionality. Conditional score-based diffusion models offer a practical way to uncover

and to represent them. We train a diffusion model on simulated parameter–feature pairs and then
condition the sampler on a target feature vector to generate parameters compatible with that target
[16, 17]. Recent theory helps explain why this is plausible: under suitable regularity assumptions,
score-based diffusion can adapt to smooth low-dimensional manifold structure without explicitly
estimating the manifold [18]. In our setting, diffusion is therefore used as an amortized sampler of
inverse geometry rather than a black-box optimizer.
We develop this view across three dynamical systems of increasing complexity and biological
relevance. In the Lorenz system [19], scalar trajectory statistics generate thin viable sheets and
provide a controlled calibration of the geometry. In the Izhikevich neuron model [20, 21], target firing
statistics reveal parameter manifolds whose tangent directions express compensatory changes among
excitability, reset, and adaptation parameters. In dsODE reductions of finite spiking networks [22],
viable manifolds expose how excitatory–inhibitory balance extends beyond two-dimensional sweeps
to hidden dependencies among synaptic strengths, timescales, connection probabilities, and external
drives. Across these systems, the central message is the same: compatible parameters are not a
cloud of arbitrary alternatives. They are organized geometric objects, and learning their geometry
turns robustness from a qualitative observation into a measurable structure.

2.1
A regular inverse-geometry framework for viable parameter manifolds
The object we seek to learn is not a single fitted parameter vector but the inverse geometry of a
dynamical model. Consider a dynamical system with k parameters
˙x = f(x, θ),
θ ∈Θ ⊂Rk,
(2)
and let I : Θ →Rm be a vector of dynamical statistics computed from simulated trajectories. For a
target feature value y, the compatible parameters form the viable set
My = {θ ∈Θ : I(θ) = y},
and
My,ε = {θ ∈Θ : ∥I(θ) −y∥≤ε}
(3)
for exact and tolerance-thickened conditioning, respectively. Fig. 1A illustrates this inverse view: a
low-dimensional feature landscape is cut by target values, and each cut can select one or several
viable components in parameter space.
Throughout the main analysis, we make one explicit local regularity approximation. For a chosen
target and sampling neighborhood, we treat the generated parameters as lying within a single
dynamical regime. Under this approximation, the long-time statistics used as target features depend
smoothly on θ, and a diffusion model conditioned on y should return samples close to a smooth
level-set manifold. This assumption is deliberately local rather than global. When it fails, the
failure is itself informative: split clouds, strong folding, abrupt changes in intrinsic dimension, or
unstable local tangent spaces suggest that the target neighborhood crosses a bifurcation, mixes
multiple attractor branches, or uses summaries that do not fully separate dynamical regimes.
The number of independent constraints imposed by the target is the effective rank of the parameter-
to-feature map, not the nominal number of reported features. Let σ1(θ) ≥· · · ≥σq(θ), with
q = min{k, m}, denote the singular values of DI(θ). At the numerical tolerance of an experiment,

we define ry as the number of singular directions resolved above feature noise, simulation error, and
target tolerance. If ry is locally constant on a viable component and the active singular values are
bounded away from zero at that scale, the constant-rank theorem gives a local inverse image of
dimension k −ry. Thus, a four-dimensional feature vector may impose only two active constraints if
two features co-vary, whereas a scalar feature typically produces a codimension-1 sheet when it is
regular.
This statement about rank is the entry point to the geometry used throughout this paper.
Neighboring level sets My show how changes in target behavior move through parameter space.
Intrinsic dimension estimates how many parameter degrees of freedom remain after imposing the
target. At a regular point, the tangent space
TθMy = ker DI(θ)
(4)
contains the infinitesimal compensation directions: first-order parameter co-variations that preserve
the requested behavior. The normal directions, spanned by the active rows of DI(θ), point toward
changes in the target statistics. Curvature measures how these compensation laws change along
the viable set; a nearly flat sheet corresponds to an approximately linear tradeoff, whereas a
curved manifold indicates that parameter compensation differs across regions. Fig. 1D serves as a
visual glossary for these readouts: neighboring level sets, a local tangent approximation with an
across-target direction, and an intrinsic-dimension estimate from a generated cloud.
Operational regularity checks. We interpret a target-conditioned cloud as a regular
viable manifold when, at the sampling scale, (i) the feature map is smooth within the
regime being analyzed; (ii) the active rank of DI is locally stable, even if the nominal
features are redundant; (iii) curvature and target-thickening are small enough that local
tangent estimates are meaningful; and (iv) connected components can be analyzed directly
or chart-wise. When these checks fail, the generated cloud is not discarded. Its irregularity
becomes evidence for regime mixing, bifurcation proximity, insufficient observables, or the
need for a component-wise atlas.
The practical workflow follows this geometry. We fisrt construct a library by randomly sampling
parameters, simulating the system, and summarizing the dynamics. then we train a conditional score-
based diffusion model on pairs (θ, I(θ)). The score network receives the current noisy parameter
state, the target feature vector, and a diffusion-time embedding, and returns a parameter update
used in an annealed Langevin sampler (Fig. 1B). Reverse diffusion then transforms an initially
random parameter cloud into a target-conditioned cloud concentrated near the viable set (Fig. 1C).
Unlike local optimization, which returns one or a few solutions, the diffusion sampler approximates
an entire conditional family of viable parameters.
This conditional family is not automatically a uniform distribution on My. Generated samples
usually represent a prior-weighted, tolerance-thickened empirical atlas of the viable set (more in
SI). Accordingly, the learned parameter set and all its geometric features should be validated by
direct re-simulation rather than by raw sample density alone, with diffusion-validation iterations
repeated until the learned parameter set converges. Here, we focus on a first-round demonstration
rather than on exhaustive iterative refinement of each target-conditioned set. Our goal is not to
recover a fully converged viable set for every single target, but to introduce a generative approach
to viable-manifolds learning and demonstrate how it facilitates mechanistic analysis for modelers.

that demonstrably separate the behaviors in Fig. 2A. This is because strange attractors maintain
large fluctuations, rapidly convergent fixed-point trajectories have very small fluctuations, and
transient-chaotic trajectories produce small fluctuations when starting from stable fixed points, but
large fluctuations from distant initial conditions.

2.3
Izhikevich neurons: viable manifolds organize firing statistics beyond cate-
gorical classes
We next turn to the Izhikevich model. It is a canonical reduced, two-dimensional neuron model of
the neuronal membrane potential v and a recovery variable u. Using only four dynamical parameters
and a reset rule, the Izhikevich model reproduces diverse firing patterns, including tonic spiking,
adaptation, bursting, and irregular responses [20, 21]:
˙v = 0.04v2 + 5v + 140 −u + I,
˙u = a(bv −u),
(6)
and a reset rule v 7→c, u 7→u + d whenever v ≥30 mV [21]. The parameters a, b, c, d model
respectively the recovery time constant, sensitivity to subthreshold fluctuations, the nominal voltage
reset value, and the post-spike reset of the recovery variable. We fixed the input step current at
I = 20 to examine the diverse spiking patterns accessible within a simple stimulation protocol.
We start by conditioning on a four-component target. After discarding the first 50 ms of initial
transients, we summarized spikes in the 50–200 ms applied current window by firing rate, mean
inter-spike interval (ISI), coefficient of variation (CV) of the ISI, and Fano factor (Fig. 3A). Firing
rate is spike count divided by window duration; mean ISI and CV(ISI) summarize spike-to-spike
timing; and Fano factor summarizes count variability across 10-ms bins. We chose these standard
descriptors because they are both widely used observables in analyses of cortical and single-neuron
spiking [24–28].
Were these four targets to act as independent, locally transverse constraints, one might expect
the inverse images in (a, b, c, d) to shrink to isolated points, or to small tolerance-broadened clouds.
Instead, the relevant quantity proves to be the effective rank of the target family. This is because
firing rate and mean ISI encode the timescale of the output. In contrast, CV(ISI) and Fano factor
measure temporal irregularity and count variability. Across randomly sampled responses filtered to
20–200 Hz, the four reported statistics lie close to a nearly two-dimensional surface: the first two
principal components explain 52.2% and 37.9% of the variance, respectively (Fig. 3B). The nominally
four-dimensional feature target is therefore closer to a two-constraint object in the sampled regimes,
so codimension-two viable sets are the generic inverse geometry.
That lower effective dimension appears directly in parameter space. Target-conditioned diffusion
generates thin, structured subsets of (a, b, c, d) that pass through held-out original parameters and
reproduce their target feature vectors under direct simulation (Fig. 3C,D). The irregular medium-rate
target in Fig. 3C (107 Hz, 9.7 ms, CV 0.80, Fano 0.93) occupies a visibly curved sheet, whereas the
more regular target (193 Hz, 5.3 ms, CV 0.31, Fano 0.31) is narrower and closer to an affine strip.
Their participation-ratio dimensions, 2.08 and 1.74, are consistent with a four-parameter model
constrained by a feature family with effective dimension near two. They are viable manifolds with
clear geometrical features, not merely noisy balls around a reference point.
Two observations are especially relevant for neuroscience. First, tangent spaces at points on the
manifolds reveal the first-order compensation geometry: local co-variation of (a, b, c, d) that preserves
firing statistics. Second, nearby feature targets produce nearby manifolds, indicating that the model
learned a smoothly varying family of viable sets rather than memorizing discrete templates. Thus,
the learned manifolds can be viewed as population-of-models descriptions of neuronal degeneracy
and homeostatic compensation, revealing dependencies among excitability, recovery, reset, and
adaptation parameters [1–5, 29].

As a second-order geometric descriptor, curvature measures how a local compensation law changes
along the manifold. In our generated irregular-firing manifolds, several projections have negative
curvature, which we interpret as an antagonistic compensation pattern in those coordinates: larger
movement in one parameter direction requires an increasingly strong offset in another to preserve the
target features. The reset/adaptation interpretation below is derived from the local spike-to-spike
map analysis in the SI Appendix. Biologically, this suggests that irregular firing is maintained by
balancing reset-driven excitability against adaptation-driven memory or stability. These competing
influences pull the manifold in different directions and allow the Izhikevich model to produce
diverse spiking patterns. As a validation, parameter configurations generated from these manifolds
reproduce irregular firing patterns and statistics similar to the target dynamics (Fig. 3D).
The seemingly linear parameter manifolds for regular spiking admit a sharper dynamical inter-
pretation (Fig. 3E). Under constant input within the stimulation window, the hybrid flow reduces
spike-to-spike dynamics to a one-dimensional return map for the post-spike recovery value. Regular
spiking corresponds to a stable fixed point of this adaptation map, so fixing the target firing rate
or mean ISI and low irregularity imposes approximately two independent smooth constraints on
(a, b, c, d): one on the inter-spike time interval from the reset c to the threshold, and another
on the balance amongst the spike-triggered recovery increment d, the recovery timescale a, and
the subthreshold coupling b. Linearizing these constraints around a stable periodic orbit yields
local compensation laws of the form Aaδa + Abδb + Acδc + Adδd ≈0, so the viable set is well
approximated by a small affine chart. Consistent with this picture, the regular-firing family remains
two-dimensional and becomes increasingly ribbon-like as the rate increases. This interpretation is
also consistent with the near-zero curvature of the corresponding parameter manifold.

2.4
dsODE synaptic manifolds extend E–I landscape geometry into network
inverse problems
We next moved to dsODE, a deterministic reduction of finite-sized spiking neuronal networks (SNN).
dsODE uses a discretized voltage-bin structure to represent the population voltage configuration of
the SNN, and uses pending synaptic variables to describe the recurrent drives to neuron populations.
In different sweeps of the parameter space, dsODE reveals and faithfully reproduces fixed points, one-
beat and multi-beat oscillations, coexistence of multiple attractors, and the bifurcation organization
of the underlying spiking network model [22]. These properties make dsODE an especially useful
testbed for inverse problems: it remains mechanistically tied to SNN dynamics, yet is light enough
to support the large simulation libraries needed for conditional generation. Without a reduction
of this kind, broad parameter evaluations at the level of the full SNN would be computationally
prohibitive, especially if one wishes to preserve the attractor and bifurcation structure that organizes
viable solutions [22, 30]. The basic construction of dsODE and a few of the representative activities
(the “one-beat” and “two-beat” oscillations) are summarized in Fig. 4.
We begin with the four recurrent synaptic coupling strengths (SEE, SIE, SEI, SII) because these
are precisely the parameters to which the overall network dynamics is most sensitive. Xiao et
al. showed that the viable firing-rate region is thin in this synaptic-strength landscape, so single-
parameter perturbations of order 1% can already leave the viable set [30], while dsODE showed
that varying these same couplings organizes a much richer set of dynamical regimes [22]. Following
Xiao et al., we analyzed the four-dimensional synaptic box in the inhibition-plane coordinates
(SIE/SII, SEI/SEE), whose product acts as a suppression index for E-cells. In the background-
regime analysis, excitatory and inhibitory mean rates remain tightly linked near the mean-field
relation, so the nominal two-rate target behaves effectively as a single active constraint. The
corresponding viable set is therefore close to codimension-1 in the four-dimensional synaptic space
and appears as hyperbolic viable strips in the inhibition plane, consistent with Fig. 1A of Xiao et al.
[30]; the left panel of Fig. 5B reproduces that landscape. We recovered this result with dsODE
in the same regime (SI Appendix), where participation-ratio dimensions are 2.5–2.9, close to the

We then moved to a more driven regime, where E and I mean rates are less tightly coupled and
therefore provide two less dependent constraints (Fig. 5A middle). The learned mean-conditioned
families become intrinsically thinner, with participation-ratio dimensions between about 1 and
2.2, even though their projection onto the inhibition plane remains strip-like. Direct re-simulation
confirms recovery of the target mean rates (Fig. 5A right). In this sense, the same inhibitory-balance
mechanism still organizes the projection, but the intrinsic dimension now reflects the number of
firing rate directions that are genuinely independent.
This already suggests that once temporal heterogeneity (e.g., oscillations or bursting behavior)
becomes appreciable, mean rates alone may not fully resolve the viable structure in this synaptic
box. As in the one-beat and two-beat dynamics reported previously [22, 31], our simulations show
that distinct oscillatory families can have similar long-time average E/I rates while differing strongly
in temporal modulation amplitude. We therefore next conditioned on the standard deviations (std)
of the excitatory and inhibitory rates. The resulting families in Fig. 5B differ qualitatively from the
mean-conditioned ones: they can split, becoming visibly multimodal in the same inhibition plane,
even though direct re-simulation still validates the requested std targets. Parameter configurations
located in different clusters correspond to 1-beat and 2-beat oscillatory dynamics, respectively
(Fig. 5B right).
We regard that irregularity as informative rather than as a failure of the generator. Conditional
manifold learning is easiest when the inverse support varies smoothly with the target locally,
but near bifurcations that support can fold or split because nearby parameters lie on different
dynamical branches while possibly maintaining similar low-order summaries. Mean-conditioned sets
therefore tend to remain close to the single compensation strip imposed by E–I balance, whereas
std-conditioned sets are more branch-sensitive and can separate distinct dynamical regimes, e.g.,
one-beat from two-beat responses.
Finally, we find that overlapping mean- and std-conditioned manifolds collapse to compact local
neighborhoods around held-out original parameters on the inhibition plane and generate temporally
similar trajectories within each branch (Fig. 5C). Consistent with this view, these neighborhoods are
approximately ellipsoidal in projection, closer to Gaussian-like clusters than to long compensation
strips. Thus, low-order moments do not merely tighten a point estimate; taken together, they
localize branch-specific viable parameter sets while revealing the nearby regime structure that
perturbs an otherwise smooth manifold geometry.

2.6
Dimensionality and regularity determine both learnability and interpretation
Across all three systems, the same principle appears repeatedly: diffusion learns viable sets most
effectively when the target-conditioned inverse family is both low-dimensional and regular at the
tolerance scale. This is precisely where the method becomes computationally useful. Let I : Θ →Rry
be the feature map, with Θ ⊂Rk. Assume the target coordinates are locally rank DI = ry at the
solution set, and the viable set I−1(y∗) has intrinsic dimension d = k −ry. In a bounded parameter
box, an ε-tube around such a set occupies only an O(εry) fraction of the ambient volume. Therefore,
unguided rejection or nearest-neighbor search pays a penalty in the normal directions before it ever
resolves the tangential geometry.
By contrast, conditional diffusion amortizes the need for simulation in parameter space: one
simulation library can be reused across many nearby target queries, and inference becomes direct
proposal generation followed by re-simulation validation. More importantly, the cost of building the
library can itself be reduced by the regularity of the viable set and is therefore not fully described

participation-ratio dimensions directly reflect this compression.
Multimodality or disconnected components can flag either genuine regime structure or insufficient
observables. The dsODE example in Fig. 7A makes this concrete: mean-rate guidance alone can
merge one-beat and two-beat families, whereas adding standard deviations splits that merged
cloud into branch-specific neighborhoods. More generally, richer targets help only when they
add independent active information. Adding redundant coordinates to the guide need not lower
intrinsic dimension; it may only improve conditioning. By contrast, observables aligned with the
active normals of the parameter-to-feature map can contract clouds, separate nearby regimes, and
regularize local geometry. This is why target design is itself a scientific issue. The most informative
guides are not merely larger feature vectors, but observables that resolve the directions along which
biological function actually changes [10, 11, 32].
3
Discussion
This work recasts inverse modeling in dynamical systems as the study of viable parameter manifolds.
The typical parameter-fitting task answers one question: can the model reproduce the target? A
viable manifold answers a deeper question: In how many mechanistically distinct ways can the model
reproduce it and how must parameters co-vary to preserve it? Throughout this study, the compatible
parameter sets were not featureless clouds but manifolds with geometry. The geometry matters not
only for fitting but also for what a model can generalize, explain, and render interpretable, echoing
the sloppy-model view that predictions are controlled by a small number of effective parameter
combinations [6–9, 33].

The three case studies play complementary roles. The Lorenz system shows the basic inverse
geometry in a classical setting: fixing a scalar trajectory statistic cuts a three-dimensional parameter
box into thin 2D sheets. In the Izhikevich model of single-neuron dynamics, four common firing
descriptors co-vary strongly rather than acting as four independent constraints, so the inverse images
remain extended manifolds in a four-dimensional parameter space. Their tangent directions describe
compensatory changes among physiological parameters. The dsODE examples then move from single-
neuron compensation to network homeostasis. Mean rates recover excitatory–inhibitory balance-like
strips, rate fluctuations split branches that would merge when targeted on mean rates alone.
Furthermore, higher-dimensional generations reveal tradeoffs among recurrent strength, filtering
timescale, refractory effects, and external drive. In this sense, the learned parameter manifolds
provide population-of-models descriptions of neuronal degeneracy and homeostatic compensation
rather than opaque families of equally good fits [1–5, 29].
A useful way to summarize these results is that degeneracy is not disorder. In biological models,
many parameter combinations can produce the same function or behavior, but these combinations
are constrained by the key features in the behavior. Intrinsic dimension measures the number
of free local parameter directions. Tangent spaces identify the local compensation laws. The
relative location of neighboring level sets shows how the function changes as parameters move
(local coordinates of tangent spaces and normal directions shown in Fig. 7C). Curvature tells us
when a simple linear compensation rule is only local, and component structure reveals alternative
mechanisms or multiple regimes. In this paper these geometric quantities are treated as mechanistic
observables extracted from the inverse problem, complementing the forward model-manifold view of
sloppy systems [8, 9, 33].
Thus our results also clarify the true goal of target design. Imposing more feature coordinates is
useful only when those coordinates add independent active information about the parameter-to-
feature map. Conversely, a small number of well-chosen observables resolving the true geometry can
sharply contract a viable set or separate dynamical branches if they are well aligned with directions
along which the system dynamics actually changes.
This regular-manifold viewpoint is deliberately local. Yet parameter spaces of nonlinear systems
are not globally smooth in this sense. Bifurcations, coexistence of attractors, transient chaos, and
branch switching can match the same low-order statistics with different mechanisms [23, 34]. In
such cases, irregular diffusion outputs are strong indicators of regime mixing or nearby bifurcation
structure, and should trigger targeted simulation, continuation, or component-wise analysis rather
than being averaged into a single, smooth manifold.
The reader should note that conditional diffusion does not remove the need for simulation nor
guarantee uniform sampling on a level set. Therefore our framework should not be treated as a
universal solver for high-dimensional bifurcation discovery. It is valuable here because diffusion
amortizes inverse queries and returns structured candidate sets that can be validated and ana-
lyzed geometrically. This perspective connects several traditions that are often separated. The
sloppy/model-manifold literature studies forward images in prediction space, whereas identifiability
and dynamical-compensation theory emphasize inverse non-uniqueness; viable manifolds unify these
viewpoints as inverse geometric objects [9–11, 32, 33]. From dynamical systems, it inherits the idea
that qualitative regimes organize parameter space. From inverse problems, it inherits the importance
of pre-images and identifiability. From neuroscience, it inherits the problem of robustness and
degeneracy in neurons and circuits. From modern generative modeling, it gains a scalable way to
19


## Page 20


sample complicated embedded sets.
This synthesis suggests a broader program: building regime-aware atlases of viable manifolds,
using active learning to refine transition-adjacent strata, and combining diffusion samplers with
classical continuation methods to trace bifurcation surfaces when the smooth-manifold assumption
fails. The natural next step is therefore regime-aware inverse geometry. Promising directions
include component-wise manifold learning, active refinement of transition-adjacent strata, and
diffusion-assisted continuation along codimension-1 boundaries.
The main conceptual conclusion is that robust biological function corresponds to a structured
space of possibilities rather than to a privileged parameter configuration. Learning that space
makes robustness measurable, compensation visible, and hidden dependencies testable. Viable
parameter manifolds therefore turn inverse modeling from the search for one answer into the analysis
of the space of answers. By connecting modern generative modeling to classical dynamical-systems
ideas, this study establishes a technical language for a core principle: that complex dynamical
systems maintain robust function amid parameter variability through structured, low-dimensional
mechanisms that we can now extract and analyze.

Materials and Methods
4.1
Conditional diffusion model
We used conditional score-based diffusion models to learn the distribution of parameters θ given
target features y = I(θ) [16, 17, 35, 36]. Training data consisted of simulation-labeled parameter
samples (θi, yi). In all case studies, the score network was conditioned on both the target feature
vector and the diffusion time or noise level, and generated parameters were always checked by direct
re-simulation. Parameters and features were linearly normalized before training.
At test time, the model was queried with a desired target feature vector and used to generate
candidate parameters. The figures report re-simulated generated samples or direct simulations
of representative generated parameters rather than raw network output. For Lorenz validation
histograms we used 5000 generated parameters per scalar target. For Izhikevich validation traces
and histograms we simulated 300 generated neurons per target. For dsODE validation panels, dots
and error bars summarize re-simulations of 200 generated parameters per target.
