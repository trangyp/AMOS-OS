1. Introduction
1.1. Motivation and large intersections. Furstenberg’s seminal proof of Szemer´edi’s theorem estab-
lished a profound connection between ergodic theory and additive combinatorics.
Within this ergodic framework, Furstenberg established the following multiple recurrence theorem
[26]:
Theorem 1.1 (Furstenberg multiple recurrence theorem). For any system (X, B, µ, T), any set A ∈B
with µ(A) > 0, and any k ∈N, there exists a constant c > 0 such that the set of return times
n

is syndetic (i.e., it has bounded gaps).
It was shown in [14] by Bergelson et al., that a value of the constant c which depends only on µ(A)
and k exists. The optimal combinatorial scenario is referred to as the large intersection property, which
occurs when c can be chosen arbitrarily close to the theoretical limit of independent intersections,
specifically µ(A)k+1 −ε for any ε > 0. Relying on the Host and Kra [27] and Ziegler [33] structural
theories, in [13] Bergelson, Host, and Kra demonstrated that the large intersection property holds for
linear configurations of short lengths in ergodic systems:
Theorem 1.2 (Large intersection property along short arithmetic progressions). Let (X, B, µ, T) be an
ergodic measure preserving system, let A ∈B with µ(A) > 0, and let k = 2 or 3. Then for any ε > 0,
the set
{n ∈N : µ(A ∩T −nA ∩· · · ∩T −knA) ≥µ(A)k+1 −ε}
is syndetic.
They furthermore showed that for k ≥4, the set of large intersections may be empty. To extend these
structural properties beyond linear progressions, one considers polynomial sequences. Specifically, we
study rationally independent integer polynomials, which are families of polynomials such that no non-
trivial linear combination of them over the rationals is a constant. For such families, Frantzikinakis and
Kra [21] established that the large intersection property is fully recovered even without the ergodicity
assumption:

1.2. IP configurations and sequences with rational spectrum. Another fundamental approach to
characterizing the “largeness” of a subset of N relies on its intersections with structured families of sets.
Given an infinite sequence of natural numbers (ni)i∈N, in the literature the IP generated by it, denoted
IP((ni)i∈N), is defined as the set of all finite sums of distinct elements from the sequence. However, here
we will need a somewhat more general definition (see Definition 2.4). Moreover, a subset of N is IP∗if
it intersects every IP((ni)i∈N) non-trivially.
In [24], Furstenberg and Katznelson proved the IP-Szemer´edi theorem, yielding the following strong
recurrence property:
Theorem 1.4. For any ergodic system (X, B, µ, T), any set A ∈B with µ(A) > 0, and any k ∈N, the set
{n ∈N : µ(A ∩T −nA ∩· · · ∩T −knA) > 0}
is IP∗.
The analogous result for sequences for rationally independent polynomials was obtained in [15] by
Bergelson and McCutcheon:
Theorem 1.5. Let (X, B, µ, T) be an ergodic system and let A ∈B with µ(A) > 0. For any k ∈N
and any family of rationally independent integer polynomials p1, . . . , pk satisfying pi(0) = 0 for all
i = 1, . . . , k, the set
{n ∈N : µ(A ∩T p1(n)A ∩· · · ∩T pk(n)A) > 0}
is IP∗.
To refine these intersection properties, we restrict our attention to IP sets generated by sequences
(ni)i∈N possessing a rational spectrum (see Definition 2.9).

2. Preliminaries
2.1. Measure preserving systems and factors. An invertible measure preserving system (or just a
system for short) is a quadruple (X, B, µ, T), where X is a compact metric space, B is its Borel σ-
algebra, µ is a regular probability measure, and T : X →X is a µ-preserving invertible transformation
(i.e., µ(T −1A) = µ(A) for all A ∈B).
We write L2(X), or L2(µ), for the corresponding Hilbert space of all square µ-integrable functions on
X modulo equivalence µ-almost everywhere. We abuse the notation and write T both for the measure
preserving transformation on X and for an associated unitary operator T : L2(X) →L2(X).
Given two systems (X, B, µ, T) and (Y, C, ν, S ), we say that Y is a factor of X if there is a measure
preserving map π : X →Y, such that π ◦T = S ◦π. If π is invertible the systems are called isomorphic.
Each factor Y defines a unique T-invariant sub σ-algebra π−1(C) ⊆B, and an embedding L2(Y) ,→
L2(X) (defined by g 7→g ◦π). In fact each T-invariant sub σ-algebra of X give raise to a factor. So we
will interchangeably think of factors of a system in these two equivalent ways, and sometimes may call
a factor the subspace L2(Y) ⊆L2(X), since Y can be reconstructed from L2(Y). If Y is a factor of X, we
denote by E(·|Y) the conditional expectation with respect to corresponding sub σ-algebra.
2.2. Characteristic factors and Nilmanifolds. In this paper we focus on some special families of
factors. The first one is the rational Kronecker factor. A function f : X →C is called an eigenfunction
for X or T, if there exists some eigenvalue λ ∈S 1 so that T f = λf.
Definition 2.1. Let (X, B, µ, T) be a measure preserving system. The rational Kronecker factor of X is
the minimal sub σ-algebra of B with respect to which all eigenfunctions with rational eigenvalues are
measurable. We denote it by Krat(X).

respect to which all eigenfunctions with eigenvalues of order r are measurable. It is classical that Kr(X)
