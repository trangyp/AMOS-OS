Abstract. Originally, an exotic Diophantine triple is a set {a, b, c} of
distinct nonzero rational numbers for which
a + 1,
b + 1,
c + 1,
ab + 1,
ac + 1,
bc + 1,
abc + 1
are all perfect squares. We prove that there is no such triple in R[X],
with at least one nonconstant element, if none of a, b, c is equal to
1. Equivalently, under the distinct nonzero convention, every exotic
Diophantine triple in R[X] with a nonconstant element must contain the
element 1.

Keywords. Diophantine m-tuples, polynomial Diophantine tuples, squares
in polynomial rings.
1. Introduction
A classical Diophantine m-tuple is a set of m distinct positive integers
such that the product of any two of its distinct elements, increased by 1,
is a square. This problem has a long history, beginning with examples of
Diophantus in the rational case and Fermat in the integer case (see [1]). Since
then, many variants have been considered, obtained either by changing the
observed ring or by modifying the square conditions imposed on the elements.
Recently, Dujella, Kazalicki, and Petričević [2] introduced the following
seven-square variant of the Diophantine tuple condition over the rational
numbers. Here is a more general definition:
Definition 1. A set {a, b, c} of distinct nonzero elements of a commutative
ring R with 1 is called an exotic Diophantine triple if
(1)
a + 1,
b + 1,
c + 1,
ab + 1,
ac + 1,
bc + 1,
abc + 1
are all perfect squares of some elements of R.
Equivalently, {1, a, b, c} is a Diophantine quadruple and abc + 1 is also
a square.
Obviously, for every exotic triple, sets {a, b, c} and {1, ab, c}
are Diophantine triples. Dujella, Kazalicki, and Petričević [2] proved that
infinitely many such triples exist over Q, while no such triples exist in positive
integers. The closely related four-square condition that ab + 1, ac + 1, bc + 1,
and abc + 1 are all perfect squares was considered by Dujella and Szalay [3],
who proved that there are infinitely many such triples {a, b, c} of positive

The nonexistence of exotic Diophantine triples in the polynomial ring

The question considered here is whether, under the usual convention
that the entries are distinct and nonzero, an exotic triple over R[X] can
be nonconstant when the value 1 is excluded. The answer is negative. In
other words, in R[X] the presence of 1 in an exotic Diophantine triple is
forced. The family (2) shows that this conclusion is sharp. The proof uses
the regularity theorem of Filipin and Jurasić [4] for polynomial Diophantine
quadruples in R[X].
Theorem 2. There is no set {a, b, c} ⊂R[X] of distinct nonzero polynomials
such that:
(1) at least one of a, b, c is nonconstant,
(2) none of a, b, c is equal to 1,
(3) all seven polynomials in (1) are perfect squares in R[X].
2. Preliminaries
We first record that, once 0 and 1 are excluded, a nonconstant exotic
triple over R[X] has no constant element.

In the proof of the main theorem, we use the regularity theorem for
polynomial Diophantine quadruples over R[X].
Theorem 4 (Filipin and Jurasić [4]). Let {a, b, c, d} be a set of four distinct
nonzero polynomials in R[X], not all constant. Suppose that the product of
any two distinct elements of that set, increased by 1, is a perfect square in
R[X]. Then the quadruple is regular; equivalently, for any labeling a, b, c, d
of the four polynomials in that set,
(4)
(a + b −c −d)2 = 4(ab + 1)(cd + 1).
Using the same notation as in [2], the expression (4) can be replaced by
r4(a, b, c, d) = 0, where
r4(a, b, c, d) = (a + b −c −d)2 −4(ab + 1)(cd + 1).
Then, r4 is a symmetric polynomial in a, b, c, d.

3. Proof of the main theorem
Proof of Theorem 2. Assume that {a, b, c} ⊂R[X] satisfies the hypotheses.
By Lemma 3, a, b, c are nonconstant. Let
deg a ≤deg b ≤deg c.
Since a + 1, b + 1, c + 1 are perfect squares, write
(8)
a = x2 −1,
b = y2 −1,
c = z2 −1,
with x, y, z ∈R[X]. Then x, y, z are nonconstant and
deg x ≤deg y ≤deg z.
Let r ∈R[X] satisfy
(9)
ab + 1 = r2.
Changing r to −r if necessary, assume that r has the same leading coefficient
as xy. From (8) and (9), we have
(10)
r2 = (x2 −1)(y2 −1) + 1 = x2y2 −x2 −y2 + 2
and deg r = deg x + deg y.
The set {1, a, b, c} is a Diophantine quadruple in R[X], with at least
one nonconstant element. By Theorem 4, this quadruple is regular. Thus
r4(1, a, b, c) = 0. Since r4 is symmetric, we may write the regularity relation
as r4(a, b, 1, c) = 0. Hence, (a + b −1 −c)2 = 4(ab + 1)(c + 1). Using (8), (9),
and (10), we get
(11)
c + 1 = (xy ± r)2.
We now exclude the minus sign in (11). Since r and xy have the same
degree and the same leading coefficient, it follows that
(12)
deg(xy + r) = deg x + deg y.
Moreover, from (10), it follows
(13)
(xy −r)(xy + r) = x2y2 −r2 = x2 + y2 −2.
The polynomial on the right-hand side has degree 2 deg y, since deg x ≤deg y
and the leading coefficients of x2 and y2 cannot cancel over R. Combining
this with (12) and (13), we get
deg(xy −r) = deg y −deg x < deg y,
since x is nonconstant. But, deg z ≥deg y. Hence, z cannot be equal, even
up to sign, to xy −r. Replacing z by −z if necessary, we may assume that
(14)
z = xy + r.

Corollary 6. Let A be a subring of R containing 1. Under the distinct
nonzero convention, every exotic Diophantine triple in A[X] with a non-
constant element contains 1. In particular, this holds over K[X], for every
subfield K ⊆R.
Since 2 is not a square in Q[X], there are no exotic
Diophantine triples in Q[X] with a nonconstant element.
Proof. Any exotic Diophantine triple in A[X] is also one in R[X].

Remark 7. If the zero polynomial is allowed, then for any nonconstant
t ∈R[X] the set
{0, t2 −1, (t + 1)2 −1}
satisfies the seven-square condition (1) and contains no element equal to
