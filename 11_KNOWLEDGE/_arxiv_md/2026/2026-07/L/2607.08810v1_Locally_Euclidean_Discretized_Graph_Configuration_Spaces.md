Abstract. We investigate discretized graph configuration spaces as defined by Aaron
Abrams in his PhD thesis in 2000. Specifically, we extend Abrams’ work by completely
classifying which ones admitted by simple graphs are homeomorphic to closed manifolds. In

1. Introduction
Graph configuration spaces are excellent models for numerous real-world applications,
including safe robot pathing [GK02], digital microfluidic devices [GP07], and topological
quantum computers [MS19]; their study has been a growing area of research in geometric
settings since [Abr00].
A key feature of Abrams’ model is that Conf □
n (Γ) is homotopy equivalent to Confn(Γ)
when Γ is suitably subdivided (see Theorem 3.2 of [PS14]). So, by studying Conf □
n (Γ) we
can sometimes determine homotopy invariants of Confn(Γ) such as the graph braid group

Bn(Γ). One property of the graph braid group is the possibility of being a manifold group. In
[JV26] it is shown that B3(Θ5) is a 3-manifold group. By classifying exactly which discretized
graph configuration spaces are manifolds, we partially determine which graph braid groups
are manifold groups; any other examples of manifold groups must be determined through
other means, e.g. thickening.
The goal of this paper is to resolve the following question of Abrams.
Question 1.1 (Question 5.1 in [Abr00]). For which simple graphs Γ without loops and which
positive integers n and m is the discretized n-point (ordered) configuration space, denoted
Conf □
n (Γ), homeomorphic to a closed m-manifold without boundary?
Abrams had made the most headway towards answering the general question in [Abr00].
He classifies all such examples when the dimension of the manifold is maximal. That is,
when the number of points in the configuration space equals the dimension.
Theorem 1.2 (Corollary 5.8 in [Abr00]). If Γ is a simple graph without loops, then Conf □
n (Γ)
is homeomorphic to an n-manifold without boundary if and only if n = 1 and Γ is a cycle or
n = 2 and Γ is isomorphic to K5 or K3,3.
By establishing a duality result, Abrams recovers other examples of manifolds in [Abr00]
such as Conf □
2 (K1,3), Conf □
3 (K5), and Conf □
4 (K3,3). Our interest in this question started
when Conf □
3 (Θ4) was shown to be closed orientable surface in [App+24]. This had been
done before (see Example 4.3 of [KP11]). However, while searching for other examples, we
found that such examples are rare.
Interested in generalizing the notion of when Conf □
n (Γ) is homeomorphic to a manifold,
Fernandes investigated when Conf □
2 (Γ) is a 2-pseudomanifold in [Fer03].
Definition 1.3 (Definition 5.1 in [Fer03]). A finite m-dimensional cubical complex X is
a closed m-pseudomanifold if and only if every (m −1)-cell in X is a face of exactly two
m-dimensional cells.
Fernandes determined that Conf □
2 (Γ) is a closed 2-pseudomanifold if and only if Γ is K5,
K3,3, K4 with each edge doubled, or K2,2 with each edge doubled. We approach question 1.1
in a way similar to how Fernandes approached Conf □
2 (Γ) by determining graph invariants
necessary for Conf □
n (Γ) to be a m-pseudomanifold. Unlike Fernandes, the graph invariants
we determine involve the language of graph matchings (see Definition 2.6), which generalize
naturally for increasing values of m and n. With this approach, we completely classify when
Conf □
n (Γ) is an m-pseudomanifold and Γ is a simple graph in Theorem 1.4 below. Note that
this theorem contains Fernandes’ result (for simple graphs) as a special case.
Theorem 1.4. Conf □
n (Γ) is a closed m-pseudomanifold if and only if at least one of the
following is true.
(1) Γ is a finite disjoint union of cycles, n ∈{1, |V (Γ)| −1}, and m = 1
(2) Γ ∼= K2m+1 and n ∈{m, m + 1}
(3) Γ ∼= Km+1,m+1 and n ∈{m, m + 2}
(4) Γ ∼= Km,m+2 and n = m + 1
(5) Γ ∼= Kp ⊔Kq for some odd p and q satisfying p + q = 2m + 2 and n = m + 1

2. Definitions and Preliminaries
2.1. Configuration Spaces.
Definition 2.1. The n-point configuration space of a space X is Confn(X) = Xn \ ∆where
∆is the “fat” diagonal {(x1, · · · , xn) ∈Xn | xi = xj for some i ̸= j}.
When our space is the geometric realization of a graph denoted |Γ|, we will often just
write Confn(Γ) instead of Confn(|Γ|), but both of these symbols refer to the same space.
Intuitively, Confn(X) is the set of positions of n particles placed in X such that no two
particles occupy the same spot. Given some fixed point ⃗x ∈Xn, we can define the n-strand
pure braid group of X as Pn(X) = π1(Confn(X),⃗x). When X = R2, this is simply known as
the n-strand pure braid group. By taking π1 of the n-point unordered configuration space of
X, we obtain the braid group of X denoted Bn(X). The braid group of R2 is the classical
Artin braid group. We point the reader to [BB05] for a comprehensive survey of braids.
Definition 2.2. Given a space X, the n-point unordered configuration space of X is
UConfn(X) = Confn(X)/Sn where Sn is the degree n permutation group acting on Confn(X)
by permuting the coordinates of points in Confn(X).
Intuitively one can think of UConfn(X) as the set of positions of n indistinguishable
particles placed in X such that no two particles occupy the same spot. More precisely, a
permutation σ of the set {1, · · · , n} acts on a point ⃗x = (x1, · · · , xn) in Confn(X) by giving
the point σ⃗x = (xσ(1), · · · , xσ(n)). The orbit of ⃗x under this action is the set Sn⃗x = {σ⃗x |
σ ∈Sn}, and the orbit space Confn(X)/Sn is the set of orbits of points in Confn(X).
Critically, this action is a covering space action (see Proposition 1.40 of [Hat01]) meaning
p : Confn(X) →Confn(X)/Sn where p(⃗x) = Sn⃗x is a covering map. Hence by Proposition
1.40 and Proposition 1.32 of [Hat01] if Confn(X) and UConfn(X) are both path connected
and locally path connected, then Confn(X) is an n!-fold cover of UConfn(X). In this work
we primarily work with the ordered configuration space although the unordered space will
come in handy to simplify some counting arguments in subsection 2.3.

Theorem 2.4 (Theorem 3.2 in [PS14]). Let n > 1 and Γ be a connected graph. We say
a vertex is essential if its degree is not 2. Confn(Γ) deformation retracts onto Conf □

(1) Each path connecting distinct essential vertices of Γ has length at least n −1.
(2) Each homotopically essential path connecting a vertex to itself has length at least

Abrams originally conjectured that the conditions of this theorem were sufficient, but
this was first proven in [PS14].
As mentioned in the introduction, Theorem 2.4 means
that by studying Conf □

only “discretized graph configuration space”. In [MS19] the authors consider Swiatkowski’s
combinatorial graph configuration space. They remark that Swiatkowski’s model has the
advantage that it has the same homological dimension as Confn(Γ) without any necessary
subdivisions.
However, they note that Abrams’ model is more convenient to use when
applying discrete Morse theory.
In this work, we only consider Abram’s model and do

3. Pseudomanifolds
In this section, we answer Question 1.1 by determining exactly which discretized graph
configuration spaces are m-dimensional pseudomanifolds (recall Definition 1.3) in Theorem
1.4, then pointing out when these pseudomanifolds fail to be manifolds in Propositions 3.15,
3.17, and 3.16. Corollary 1.5 then checks that the remaining spaces are indeed manifolds.
The key idea we use is stated in Lemma 3.2. Essentially, if we want to know if a graph
configuration space is an m-pseudomanifold, then any (m−1)-cell in our configuration space
must be a face of exactly two m-cells. In the language of placing particles on graphs, this
roughly translates to “for any collection of (m−1) moving particles, the remaining n−(m−1)
particles placed on the graph should be able to move in a limited way.” Our approach uses
this idea translated into the language of matchings.
Note that if V is a set of vertices in a graph Γ, then the graph Γ−V refers to the subgraph
of Γ with vertex set V (Γ) \ V and edge set {e ∈E(Γ) | neither endpoint of e is in V}. Also,
if E is a set of edges in Γ, then the graph Γ −E refers to the subgraph of Γ with vertex set
V (Γ) and edge set E(Γ) \ E. Figure 4 illustrates this notation.
Before Definition 2.6, we remarked that the movement of k particles on a graph Γ corre-
sponds to a particular k-matching in Γ. So, if (m −1) particles are moving, the remaining
