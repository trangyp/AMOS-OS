SUM-PRODUCT PHENOMENON VIA DIMENSION
YUYAN HE AND SERGEI STARCHENKO
Abstract. We show a sum-product phenomenon in fields equipped
with abstract dimension theories, which simultaneously general-
izes the dimensions in geometric theories and Hrushovski’s coarse
pseudo-finite dimensions. More precisely, we show that for type-
definable sets of positive non-zero dimension, non-expansion in di-
mension of both the sumset and product set implies the existence
of a definable field in the same dimension. Main ingredients of the
proof include dimensional analogues of the Ruzsa triangle inequal-
ity and the Pl¨unnecke Ruzsa inequality.

2. Continuous Real Dimension
Let T be a complete first order theory, and let M |= T be a model.
By definable sets, we mean definable with parameters unless further
specified. A partial type is a consistent collection of formulas, possibly
with parameters. We denote by Def(M) the collection of definable sets
defined using parameters from M.
Let δ : Def(M) →R≥0 ∪{+∞} be a function taking values in the
non-negative real numbers or infinity. We say that δ is a continuous,
real-valued dimension if it satisfies the following axioms:
(I) For any definable sets X, Y ∈Def(M),
(1) δ(X ∪Y ) = max{δ(X), δ(Y )}.
(2) δ(X × Y ) = δ(X) + δ(Y ).
(3) δ(X) = 0 if X is finite.
(4) δ(X ∩Y ) ≤min{δ(X), δ(Y )}.
(5) For any definable surjection f : X →Y we have
δ(Y ) + inf{δ(f −1(y): y ∈Y } ≤δ(X) ≤
δ(Y ) + sup{δ(f −1(y): y ∈Y }.
(II) The function δ is continuous. I.e., for any formula ϕ(¯x, ¯y) and
s < t ∈R, there is a ∅−definable D such that
{a : δ(ϕ(¯x, a)) ≤s} ⊆D ⊆{b : δ(ϕ(¯x, b)) < t}.
We will abbreviate and call such a function δ a dimension, which we
always assume to be continuous and real-valued.
We say that T is a dimensional theory if there is a model M |= T
and a function δ = δ satisfying the above axioms. It is easy to see
that, by continuity, δ(ϕ(¯x, ¯a)) is determined by the type of a over ∅
in the theory T. It follows that δ extends uniquely to any elementary
extensions N ⪰M, and passes to elementary equivalent models, and
we simply call δ the dimension of T.
If T expands the theory of fields, we say that it is a theory of dimen-
sional fields, and similarly for expansions of the theory of groups.
