PALINDROMIC POINCARÉ POLYNOMIALS IN TYPE B
GASTON BURRULL
Abstract. We completely describe the set of all palindromic Poincaré poly-
nomials in type Bn. Additionally, we show that all lower Bruhat intervals in
type An occur in type Bn. As a consequence, all Poincaré polynomials Pw(q)
and all Kazhdan–Lusztig polynomials Px,y(q) of type An occur in type Bn.

The goal of this paper is to describe the complete list of palindromic Poincaré
polynomials in type B. In type A, these polynomials are indexed by weakly in-

1.1. Palindromic Poincaré polynomials in type A. Let LSn be the canonical
Lehmer code for Sn (Definition 2.9). By [6, Proposition 7.10 and Theorem 7.11],
this single Lehmer code is enough to recover all palindromic Poincaré polynomials
of Sn. More precisely,
(1.1)
{Pw(q) : w ∈Smn} = {Pw(q) : w ∈Pr(LSn)}.
In [6, Section 7], it is shown that the palindromic Poincaré polynomials are in
one-to-one correspondence with unimodal permutations of Sn. More precisely, each
palindromic Poincaré polynomial corresponds to a family of smooth elements, and
each family contains a unique unimodal permutation. Since the codes of the prin-
cipal elements are n-tuples which are weakly increasing Fubini words, the number
of palindromic Poincaré polynomials in Sn is 2n−1.
