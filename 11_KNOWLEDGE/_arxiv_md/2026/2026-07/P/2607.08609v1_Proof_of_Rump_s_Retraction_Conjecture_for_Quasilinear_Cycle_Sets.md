Abstract. Nondegenerate cycle sets were introduced by Rump as an algebraic framework for non-
degenerate, involutive solutions to the Yang–Baxter equation. Nondegenerate cycle set structures
on abelian groups, such as translation-invariant and quasilinear cycle sets, are of particular interest
when studying the retraction problem in the theory of the Yang–Baxter equation. In this article,
we solve the retraction problem for finite quasilinear cycle sets by showing that each nontrivial
quasilinear cycle set is retractable, thus proving a conjecture of Rump.
1. Introduction
Let V be a finite-dimensional vector space over a field k and let R : V ⊗2 →V ⊗2 be an automor-
phism of k-vector spaces. Then V is said to satisfy the (linear) quantum Yang–Baxter equation if
the following equality holds in Endk(V ⊗3).
(YBE1)
(R ⊗idV )(idV ⊗R)(R ⊗idV ) = (idV ⊗R)(R ⊗idV )(idV ⊗R).
This braiding condition originated from the work of the physicists James B. McGuire [17], Chen-
Ning Yang [23] and Rodney J. Baxter [1] on integrable systems but was soon discovered to have
applications in geometric topology by Turaev [21] who developed a framework to systematically
construct knot invariants from solutions to the Yang–Baxter equation, thus providing a vast gen-
eralization to the famous Jones polynomial [13].
In 1990, Drinfeld proposed studying set-theoretic solutions to the Yang–Baxter equation [7].
These are given by a finite set X and a bijection r : X2 →X2 that satisfies the following equality
of bijections on X3.
(YBE2)
(r × idX)(idX ×r)(r × idX) = (idX ×r)(r × idX)(idX ×r).
Linearizing such a solution yields a solution to (YBE1) which can be submitted to a deformation
process.
In the middle of the 1990s, Gateva-Ivanova and van den Bergh [10], and Etingof, Schedler and
Soloviev [8] successfully developed a systematic approach to the investigation of nondegenerate in-
volutive set-theoretic solutions to the Yang–Baxter equation by means of group-theoretic methods,
thus initiating the algebraic theory of the Yang–Baxter equation.
Before continuing, we explain the notions of nondegeneracy and involutivity. A solution (X, r)
is called involutive if r2 = idX2. Furthermore, writing r(x, y) = (λx(y), ρy(x)), a solution is called
nondegenerate if the maps λx and ρx are bijections of X for all x ∈X.
Convention 1.1. From now on, by a solution, we will mean a set-theoretic solution to the Yang–
Baxter equation that is finite, nondegenerate and involutive.
Rump proved that each solution on a set X corresponds to a cycle set structure on X, and vice
versa [18]. We give the definition of a cycle set and outline the Rump correspondence.

In the following, a cycle set X is called squarefree if its diagonal is trivial, that is, TX = idX.
Furthermore, X is said to be retractable if there are distinct x, x′ ∈X such that x ∗y = x′ ∗y for
all y ∈X.
In [9], Gateva-Ivanova poses the following conjecture on squarefree solutions that, in terms of
cycle sets, is stated as follows.
Conjecture 1.4. If X is a squarefree cycle set with |X| > 1, then X is retractable.
Gateva-Ivanova’s conjecture – also called the strong conjecture – was ultimately refuted by Ven-
dramin [22] who developed a method to construct certain coverings of cycle sets that has later been
conceptualized by Lebed and Vendramin in form of a cohomology theory for braided sets [16].
However, the retraction problem – that is, the problem of finding criteria for retractability of
cycle sets – is still relevant, as a retractable cycle set can, in principle, be constructed from a smaller
cycle set - its retraction - as an extension [22]. The definition of a retraction is given in Section 2.
In [20], Rump addresses the retraction problem for translation-invariant and quasilinear cycle
sets. Here, a cycle set X is called translation-invariant if X is squarefree and admits an action by
a regular, abelian automorphism group A. Identifying X with A, translation-invariance translates
to 0 ∗0 = 0, together with the invariance condition
(1.1)
(a + c) ∗(b + c) = (a ∗b) + c
(a, b, c, ∈A).
On the other hand, a cycle set structure on an abelian group A is termed quasilinear if it satisfies
the condition
(1.2)
a ∗(b + c) = a ∗b + (a −b) ∗c.
For another, equivalent, definition in the language of τ-groups, see Section 3. Rump showed that
both translation-invariant and quasilinear cycle sets can be obtained as certain τ-groups, which are
abelian groups A with a bijection τ : A →A such that τ(0) = 0. Furthermore, using the language
of τ-groups, he establishes a bijective correspondence between translation-invariant cycle sets and
rational quasilinear cycle sets. Details on the connections between τ-groups and cycle sets can be
found in [20].
For quasilinear cycle sets, Rump poses the following conjecture.
Conjecture 1.5. If A is a quasilinear cycle set with |A| > 1, then A is retractable.
If true, Conjecture 1.5 also implies the following statement for cycle sets of size p, posed by
Rump as another conjecture.
Conjecture 1.6. If A is a quasilinear cycle set of size p, where p is a prime, then there is an
isomorphism of quasilinear cycle sets A ∼= Zp, where x ∗y = α · y for some fixed α ∈Zp \ {0}.

The goal of this article is to prove Conjecture 1.5. The proof uses the theory of left braces
that has been developed by Rump for studying cycle sets [19], together with the cabling method
of Lebed, Ram´ırez and Vendramin [15]. The main new ingredient in the proof is the extended
permutation group of a quasilinear cycle set, a modification of the classical permutation group [8]
that also encodes the underlying abelian group.
We give an overview of the structure of this work.
In Section 2, we recall some facts concerning braces, cycle sets and the cabling method. In order
to adjust the cabling method to our needs, we reformulate it in terms of the permutation brace of
a solution, as opposed to the method in [15] which uses the structure brace.
In Section 3, we give a more convenient, but equivalent, definition of quasilinear cycle sets in
terms of τ-groups. Moreover, we recall the necessary definitions and results from [20] on quasilinear
cycle sets and give Rump’s reformulation of Conjecture 1.5 in terms of the socle of a quasilinear
cycle set.
In Section 4, we continue by defining the extended permutation group ˜G(A) of a quasilinear cycle
set A. One of its most important properties is its solvability (Theorem 4.7), which will be essential
in the proof of Conjecture 1.6.
In Section 5, we prove the existence of an action - the ˜λ-action - of ˜G(A) by automorphisms of
(G(A), +), the additive group of the permutation brace of a quasilinear cycle set, thereby extending
the λ-action of the permutation brace G(A) (Theorem 5.1). While ˜G(A) does not admit a compatible
brace structure, it does act as a transitive subgroup of the holomorph of (G(A), +) (Proposition 5.6).
Finally, in Section 6, we prove Rump’s conjecture with the machinery developed in the previous
sections. While it is possible to give a proof of Rump’s conjecture that uses the extended permuta-
tion group ˜G(A) while avoiding the use of the ˜λ-action, we believe that it allows a more streamlined
approach and is of independent interest.
We remark that we do not address the retraction problem for translation-invariant cycle sets
which has also been investigated by Rump.

2.1. Brace theory. In this article, we make extensive use of the theory of left braces (which, in
the more general theory of skew braces, are also labelled skew left braces of abelian type). For
details, we refer the reader to [2,11].
Definition 2.1. A left brace (or brace, for short) is a triple (A, +, ◦) where A is a set and +, ◦:
A × A →A are binary operations such that (A, ◦) is a group, called its multiplicative group, (A, +)
is an abelian group, called the additive group, and such that for all a, b, c ∈A:
(2.1)
a ◦(b + c) + a = a ◦b + a ◦c.
Conventions 2.2.
(1) The additive identity of a brace A is denoted by 0.
Note that this
coincides with the multiplicative identity of A, which can be verified by plugging b = c = 0
into (2.1). For an element a ∈A, its additive inverse is denoted by −a and its multiplicative
inverse by a−1.
(2) The trivial subgroup of a - not necessarily abelian - group is always denoted by 0.

We now recall substructures of a brace.
If B is a brace, a subbrace is a subset A ⊆B such that A is a subgroup of both (B, +) and (B, ◦).
This implies that A itself is a brace under the operations inherited from B. Furthermore, if B, C
are braces, we call a map f : B →C a brace homomorphism if f is a homomorphism between the
additive and the multiplicative groups.
A left ideal of a brace B is a subgroup I ⩽(B, +) that is invariant under the λ-action, that
is for all a ∈B, b ∈I, we have λa(b) ∈I. As the multiplication in a brace can be expressed as
a ◦b = a + λa(b), each left ideal is a subbrace.
Convention 2.3. From now on, if not stated otherwise, all braces considered are assumed to be
finite.

p, the p-primary component is defined as
Bp = {a ∈A : o+(a) = pk for some k ⩾0}.

Proposition 2.4. Let A be a brace, and let I, J ⩽A be left ideals with I ∩J = 0. Suppose that M

b + λb(a′) = b ◦a′ = a ◦b = a + λa(b).

2.2. Cycle sets. By Rump’s correspondence (see Section 1), the theory of (nondegenerate) cycle
sets is equivalent to the theory of (involutive, nondegenerate) solutions to the Yang–Baxter equation
and has the advantage of being more compact, in that their definition requires only one binary
operation. Details can be found in [18].
If f : X →Y is a map between cycle sets, f is called a homomorphism if f(x ∗y) = f(x) ∗f(y).
Derived notions, such as isomorphism, are defined in the usual way.
A cycle set X = (X, ∗) is called trivial if for all x, y ∈X, we have x ∗y = y.
An important property of cycle sets investigated in this article is their retractability. We elaborate
on that notion. Given a cycle set X, one defines on X the equivalence relation x ∼y ⇔σx = σy.
The relation ∼is, in fact, a congruence relation on X ( [18, Lemma 2]), therefore Ret(X) = X/∼is
again a cycle set under the operation [x]∗[y] = [x∗y]. The cycle set Ret(X) is called the retraction
of X. Moreover, the canonical projection X ↠Ret(X); x 7→[x] is a homomorphism of cycle sets.
