Polynomial Matrices in Integer Programming With
Restricted Subdeterminants
Marcel Celaya∗

Abstract
We introduce a framework for tackling questions in discrete optimization
associated with parametric constraint matrices. More precisely, the constraint
matrices have entries that are polynomials in one variable and all subdetermi-
nants of these matrices are polynomials in a given prescribed set S. Two key
problems arise in this context. The first is the recognition problem: can a matrix
of this form be recognized in polynomial time? The second is the optimization
problem: given an integer program whose constraint matrix is of this form, can
it be solved in polynomial time? We answer both questions affirmatively for a
particular set S consisting of nine linear forms. The matrices we consider are of
themselves independent interest; they arise as matrix projections of certain bi-
modular matrices that admit two distinct unimodular projections. This paper
is an extension of a conference proceedings version by the same authors that
was presented at IPCO 2024.
Keywords. integer programming, subdeterminants, totally unimodular matrices,
bimodular matrices, polynomial matrices, matroids

Introduction
For a matrix M, let ∆(M) denote the maximal absolute value of a subdeterminant
of M. It has long been known that the number ∆(M) plays a crucial role in un-
derstanding complexity questions related to integer programming problems whose
associated constraint matrix is M. Important examples include bounds on the di-
ameter of polyhedra [10, 15, 27], questions about the proximity between optimal LP
solutions and optimal integral solutions [3, 11, 13, 24], and bounds on the size of
the minimal support of integer vectors in standard form programs [1, 2, 4, 19, 22].
Largely unexplored however remain two fundamental algorithmic questions: Given
a finite set S ⊆Z of allowed values for the subdeterminants of the matrix M:

1. What is the complexity of solving an integer linear program with associated
constraint matrix M in terms of |S| and maxs∈S |s|? (Optimization problem)
2. How can we efficiently verify whether a matrix M has all its subdeterminants
in S? (Recognition problem)
If S = ±{0, 1}, both questions have been answered. Indeed, a famous theorem
of Hoffmann and Kruskal [20] and a decomposition theorem of Seymour for totally
unimodular matrices [34] allow us to tackle both questions. We refer to [33] for fur-
ther theory concerning totally unimodular matrices. If S = ±{0, 1, 2}, there exists a
polynomial time algorithm to solve Question 1 [7, 36]. In this generality, further op-
timization results are not known to us. However, more polynomial time algorithms
exist under specific matrix restrictions: for instance, if one assumes that each row
of the constraint matrix contains at most two non-zero entries [16, 21], or when the
constraint matrix is the transpose of a network matrix with a constant number of
additional rows [5]. A randomized polynomial time algorithm for the related inte-
ger feasibility question can be derived if the constraint matrix is ±{0, ∆}-modular
for ∆≤4 [25, 26]. There are also polynomial time algorithms for the optimiza-
tion and recognition problem if the constraint matrix is ±{a, b, c}-modular [18] for
a, b, c ∈N.
The main reason why there are only few general results on optimization and
recognition problems is due to the lack of understanding of integral matrices with
bounded subdeterminants. The motivation of this paper is to develop a framework
to investigate the structure of those matrices. Our point of departure is to swap out
Z for the ring Z[x] of polynomials with integral coefficients in one indeterminate x,
and consider matrices M over Z[x] whose subdeterminants all lie in some fixed set
S ⊆Z[x].
Definition 1. Let R be a commutative ring with unity, and let S ⊆R. Let 1 ≤m, n. A
matrix M ∈Rm×n is totally S-modular if every k ×k subdeterminant of M is contained
in S for 1 ≤k ≤min{m, n}. Given that m ≤n, a matrix M ∈Rm×n with full row rank
is S-modular if every m × m subdeterminant of M is contained in S.
The advantage of operating in Z[x] is that we can leverage arithmetic properties
of Z[x] to prove statements which would not otherwise hold over Z. From this more
abstract setting, we can still make progress towards Question 1 and 2 by evaluating
the polynomials in M and S at integers. Indeed, if S ⊆Z[x], then we can evaluate
the polynomials in S at an integer a to get the set S(a) ⊆Z, and it is not hard to
show that every totally S-modular matrix M becomes a totally S(a)-modular matrix
M(a) after evaluating the entries of M at a. Moreover, we show in Theorem 3 that
if S is finite, then the function M 7→M(a) is a bijection from totally S-modular
matrices to totally S(a)-modular matrices for all but finitely many integers a.
In this paper we primarily focus on the case S = ±{0, 1, x, x+1, 2x+1}, although
many of the techniques we develop are more widely applicable. We outline why
we think this particular set is interesting in Section 2. We state our main results

Choosing a Set of Polynomials
Which sets S ⊆Z[x] are interesting to study in the context of totally S-modular
matrices? We make some stipulations up front: S consists of linear forms only,
S = −S, and s ̸= 2s′ for each non-zero pair s, s′ ∈S. In this section, we make the
case for S = ±{0, 1, x, x + 1, 2x + 1}.
The first observation is that we should have 0 ∈S, since we would otherwise
have only finitely many invertible totally S-modular matrices. This follows from,
for instance, [6, Lemma 7]. In light of Remark 1, or alternatively the standard con-
vention that the determinant of a 0×0 matrix is 1, it also makes sense to have 1 ∈S.
Finally, we want at least one non-constant polynomial in our set, so we might as well
have x ∈S. So far, this yields S = ±{0, 1, x}.
Definition 2. Let 2 ≤l. The matrix M ∈Z[x]l×l is a forbidden submatrix for S if
every (l −1)×(l −1) submatrix is totally S-modular but det M /∈S. By F(S), we denote
the set of all polynomials that arise as a determinant of some forbidden submatrix for S.
For the particular case S = ±{0, 1, x}, S-modular (and hence totally S-modular)
matrices have a very simple structure: they are of the form given in Example 3. To
get something more interesting, we can append to S those elements F(S) to S which
do not violate the above stipulations. Using Lemma 1 we calculate
F(S) = ±{2, 2x, 2x2, x −1, x + 1, x2}.

We add the elements x−1 and x+1 to S to get S′ = ±{0, 1, x−1, x, x+1}. We show

Here is another way to arrive at our desired set. Given that S ⊆Z[x] consists
only of linear forms, what are the maximal S for which there exist two distinct
integers a < b such that S(a) = S(b) = {−1, 0, 1}? Such S are interesting be-
cause non-constant totally S-modular matrices admit two distinct totally unimod-
ular evaluations. Each element of such an S corresponds to a line in the plane
which meets exactly one point in {(a, −1), (a, 0), (a, 1)} and exactly one point in
{(b, −1), (b, 0), (b, 1)}. There are nine such lines in total. Moreover, by integrality
we must have b −a = 1. Replacing x with x −b, we can assume without loss of
generality that b = 0 and a = −1. Our nine lines are now defined precisely by the
linear forms ±{0, 1, x, x + 1, 2x + 1}. This connection to total unimodularity is the
key to the recognition algorithm given in Section 6.

Results
Let us discuss our main results, and comment on how the results of this paper ex-
tend the results of the extended abstract [12]. Our first main result is that, for some
particular sets S ⊆Z[x], we can recognize total S-modularity in polynomial time.
Theorem 1. Let M ∈Z[x]m×n and S ⊆Z[x] be one of the following sets:
1. ±{0, 1, x},
2. ±{0, 1, x, x + 1}, and
3. ±{0, 1, x, x + 1, 2x + 1}.
Then one can decide in polynomial time whether M is totally S-modular.
Our next result concerns integer linear programs of the following form, where
we assume that N is a full column rank matrix and b and c are integral:
ILP(N, b, c) : max c⊤x s.t. Nx ≤b, x ∈Zn.
Given a ∈Z, S ⊆Z[x] and a totally S-modular matrix M ∈Sm×n, we define
S(a) ⊆Z to be the set of evaluations of all polynomials of S at a, and similarly we
define M(a) ∈(S(a))m×n to be the matrix obtained from M by evaluating each
entry at a.
Theorem 2. Let S = ±{0, 1, x, x + 1, 2x + 1}. Let M ∈Z[x]m×n be totally S-modular.
Then one can solve in polynomial time ILP(M(a), b, c) for integral b, c, and all a ∈Z such
that M(a) has full column rank.

To formulate the next result, recall from Definition 2 that F(S) denotes the set

Theorem 3. Let S ⊆Z[x] be finite and 0 ∈S. Then the function M 7→M(a) is a
bijection from totally S-modular matrices to totally S(a)-modular matrices if and only if
a ∈Z\I(S). Moreover, I(S) is finite, which means this function is not a bijection for at
most finitely many values of a ∈Z.
Given particular choices of S, we show in Section 5.3 that it is possible to com-
pute I(S) explicitly. This leads to the following two corollaries:
Corollary 1. Let N ∈Zm×n and S ⊆Z be one of the following sets
1. ±{0, 1, a} for all a ∈Z\{−2, 2},
2. ±{0, 1, a, a + 1} for all a ∈Z\{−3, −2, 1, 2}, and
3. ±{0, 1, a, a + 1, 2a + 1} for all a ∈Z\{−3, −2, 1, 2}.
Then one can decide in polynomial time whether N is totally S-modular.
Corollary 2. Let a ∈Z\{−3, −2, 1, 2} and S = ±{0, 1, a, a + 1, 2a + 1}. Let N ∈
Zm×n have full column rank and be totally S-modular. Then one can solve ILP(N, b, c) for
integral b and c in polynomial time.
Now let S = ±{0, 1, x, x + 1, 2x + 1}. The last result of this paper shows that
S-modular matrices correspond to bimodular matrices which admit two distinct
unimodular matrix projections. We define matrix projections in Section 4.4.
Theorem 4. Assume that A is a full row rank matrix with entries in Z[x] with at least two
distinct non-zero maximal subdeterminants in absolute value. Then A is S-modular if and
only if there exists a full row rank bimodular matrix T and non-zero, non-parallel integer
vectors p, q such that T /p and T /q are unimodular and A = T /(xp + (x + 1)q).
We now comment on how these results relate to and extend the ones in [12].
Theorem 1 and Corollary 1 are new, although Theorem 1(3) appears as [12, Lemma 8]
and Corollary 1(3) appears as [12, Theorem 2]. Theorem 2 puts [12, Theorem 3]
in a more general context, and, in addition, both Theorem 2 and Corollary 2 gener-
alize [12, Theorem 3] by adding ±1 to the set S. Theorem 3 is an extension of [12,
Lemma 3]. Finally, Theorem 4 is new.

Open Directions
There are several interesting directions that would allow us to generalize the range
of applications of the framework introduced in this paper. A first step relates to
Section 2. We believe that one could establish a theory of what sets S ⊆Z[x] of
polynomials are interesting because of their combinatorial or algebraic properties.
For instance, for our most general set S = ±{0, 1, x, x + 1, 2x + 1} of allowed de-
terminants, it seems reasonable to add a determinant that is currently attained by a
forbidden submatrix, i.e., an element in F(S).
So far all recognition algorithms in Section 6 are based on characterizations that
relate totally S-modular matrices to totally unimodular matrices. In light of the cel-
ebrated Robertson-Seymour theorem [32], a first step to establish results beyond
Seymour’s decomposition could be to classify for which sets S the number of for-
bidden submatrices is finite. Initial computations show that this is true for totally
±{0, x, x + 1}-modular matrices [12, Section 1.1] or when 0 /∈S [6]. However,
this is not true for our general set S = ±{0, 1, x, x + 1, 2x + 1}. Even with entries
restricted to {x, x + 1} we can find an infinite sequence of forbidden submatrices;
see the first row of Figure 1. Interestingly, if one removes ±1 from S and passes to
±{0, x, x + 1, 2x + 1}, then we are only aware of finitely many forbidden minors;
see the second row of Figure 1. It is open whether this list is complete. A positive
answer might support the following conjecture for a finite set S ⊆Z[x] such that
s ∈S implies −s ∈S: there exists a finite list of forbidden minors if ±1 /∈S.

The optimization result presented in this paper rely on Lemmas 19 and 20, which
reduce optimization over a totally ±{0, 1, x, x + 1, 2x + 1}-modular matrix to an op-
timization problem over a totally unimodular system with an additional constraint
such that the resulting matrix is bimodular. A major hurdle in studying optimiza-
tion problems for more general S is that currently there exists no polynomial time
algorithm that solves integer linear programs with bounded subdeterminants be-
yond two. In view of Section 8, where we show that ±{0, 1, x, x+1, 2x+1}-modular
matrices arise as special bimodular matrices, it would be natural to consider analo-
gous sets of polynomials that correspond to special families of 3-modular matrices
and allow for a decomposition into a totally unimodular matrix plus an additional
row.
