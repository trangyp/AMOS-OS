ON THE REGULARITY INDEX OF THE MINIMUM DISTANCE
FUNCTION IN PROJECTIVE NESTED CARTESIAN CODES
C´ICERO CARVALHO, MARIA VAZ PINTO, AND RAFAEL H. VILLARREAL
Abstract. Let X be a projective nested product of fields and let δX (d) be the minimum
distance in degree d ≥1 of the projective nested Cartesian code CX (d). The regularity index
reg(δX ) of the minimum distance function δX is the minimum integer d0 ≥0 such that δX (d) = 1
for d ≥d0. We give a formula for reg(δX ) by determining an indicator function of least degree
for each point of X and using the fact that reg(δX ) is the v-number of the vanishing ideal IX
of X. Then we give an arithmetical criterion that characterizes when X is Cayley–Bacharach.

We use indicator functions to determine the regularity index of δX . An indicator function for
a point P ∈X is a homogeneous polynomial f ∈S such that f(P) ̸= 0 and f(Q) = 0 for all
Q ∈X \ {P}. These functions are used in coding theory [5, 12, 18], Cayley–Bacharach schemes
[7, 8, 19], and interpolation problems [10]. An indicator function of P ∈X can be computed
using [10, Corollary 6.3.11], see also [4] and references therein.

that vanish at all points of X. For each point P of X, let p = IP be the vanishing ideal of P,
and let Ass(IX ) = {IP : P ∈X} be the set of associated primes of IX . Then, IX = T

Following [5], we define the v-number of IX locally at each point P of X as:
vP (IX ) := min{d ≥0 : ∃f ∈Sd with (IX : f) = IP },
where (IX : f) := {g ∈S : gf ⊂IX } is a colon ideal. The least degree of an indicator function

the following algebraic description of the v-number of IX at P [5, Proposition 4.2]:
vP (IX ) = α((IX : IP )/IX ) ,
where α((IX : IP )/IX ) is the minimum degree of the non-zero elements of (IX : IP )/IX . Local
v-numbers appear in the work of Geramita, Kreuzer and Robbiano. More precisely the degree
degX (P) of a point P, in the sense of [7, Definition 2.1], is equal to vP (IX ).
The monomial order ≺we choose comes into play by considering the footprint ∆(IX ) of the
ideal IX which is the set of monomials tα of S which are not a leading monomial of any non-zero
polynomials in IX . The monomials of ∆(IX ) are the standard monomials of IX and an indicator
function f of a point P ∈X is called standard if all the monomials that appear in f are standard.
For each P ∈X there exists a unique, up to multiplication by a scalar from K∗, standard
indicator function f of P of degree vP (IX ), and (IX : IP )/IX is a principal ideal of S/IX gen-
erated by f = f + IX [14, Proposition 3.4]. This gives an algebraic method to compute f [14,
Procedure A.1] using Macaulay2 [15]. In Proposition 3.2, we give an explicit formula for an
indicator function f of P and we show in Theorems 4.3 and 4.9 that f is of degree vP (IX),
f + IX generates (IX : IP )/IX but f is not necessarily standard.

duced by Cooper et. al. [5] to study the asymptotic behavior of δX :
v(IX ) := min{d ≥0 : ∃f ∈Sd and p ∈Ass(IX ) with (IX : f) = p}.
The v-number of IX is the least degree among all indicator function of the points of X. By
[5, Corollary 5.6], we have
