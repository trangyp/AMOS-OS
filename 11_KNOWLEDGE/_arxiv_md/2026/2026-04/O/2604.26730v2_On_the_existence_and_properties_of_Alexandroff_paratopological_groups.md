On the existence and properties of Alexandroff paratopological
groups
Tayomara Borsich and Pedro J. Chocano
Abstract
We study groups endowed with Alexandroff topologies and show that no non-discrete
Alexandroff topology can turn a group into a topological group. This settles negatively the
basic existence problem for Alexandroff topological groups. Motivated by this obstruction,
we turn to the broader setting of Alexandroff paratopological groups. We establish sev-
eral fundamental properties of these spaces and provide explicit non-compact T0 examples,
showing that the Alexandroff framework is rich enough to capture nontrivial paratopo-
logical phenomena. As applications, we address two classical open questions concerning
feebly bounded subsets in paratopological groups, proving that non-compact Alexandroff
paratopological groups offer a positive solution both for products of feebly bounded sets
and for the feebly boundedness of B2 when B is a feebly bounded subset.

Introduction
The theory of finite topological spaces, or more broadly Alexandroff spaces, has proven to be
a powerful tool for addressing problems of various kinds in mathematics. For example, there
has been recent interest in applying these spaces to the study of dynamical systems (see [5]
or [7] and the references therein). They also appear in classical theoretical problems, such as
Quillen’s conjecture (see [4, Chapter 8]).
In [8], the authors construct a group whose elements encode simplicial complexes of both
negative and positive dimension and which also carry a natural topological structure. This
topological structure is, in fact, an Alexandroff topology. However, the group structure is not
compatible with this topology, and therefore the resulting object is neither a topological group
nor a paratopological group. This observation motivates the following question, which is the
starting point of the present work: can a group admit a non-discrete Alexandroff topology
that turns it into a topological group? And in the affirmative case, what properties should
such a group satisfy?
In this paper we answer the question in the negative: the only connected Alexandroff
topology that turns a group into a topological group is the discrete topology on the one-point
space. This motivates us to consider instead the weaker notion of paratopological groups

Preliminaries
Let us recall the main definitions and concepts from the theory of Alexandroff spaces and
paratopological groups. For a comprehensive introduction to paratopological groups, we refer
the reader to [12]. For an introduction to the theory of Alexandroff spaces, we recommend
the standard references [4, 9].
Definition 2.1. A topological group X is a topological space equipped with a group structure
such that
(i) the multiplication map m : X × X →X, defined by m(x, y) = xy, is continuous; and
(ii) the inversion map Inv : X →X, defined by Inv(x) = x−1, is continuous.
If condition (ii) is omitted, then X is called a paratopological group.

Notation. Throughout, we assume that for any paratopological group X, the symbol
1 ∈X denotes the identity element of the group. For each x ∈X, let Lx : X →X (resp.,
Rx : X →X) denote the map Lx(y) = m(x, y) (resp., Rx(y) = m(y, x)). Morphisms in this
category are maps that are continuous and also group homomorphisms. We simply say that
a map f : X →Y between two paratopological groups is a continuous homomorphism if it
satisfies these conditions. If there exists a continuous homomorphism f−1 : Y →X such that
f ◦f−1 and f−1 ◦f are the identity maps, then we say that X is isomorphic to Y .
Definition 2.2. A topological space X is an Alexandroff space if the arbitrary intersection
of open sets is an open set.
One of the most important examples of Alexandroff spaces is that of finite topological
spaces, since any topology on a finite set automatically satisfies the property of Definition
2.2.
Given an Alexandroff T0-space X and a point x ∈X, define Ux (resp., Fx) as the inter-
section of all open (resp., closed) sets containing x. Set x ≤y if and only if Ux ⊆Uy. This
relation defines a partial order on X. Conversely, for any partially ordered set (X, ≤), the
collection of lower sets forms a basis for an Alexandroff T0 topology on X. Moreover, a map
f : X →Y between Alexandroff spaces is continuous if and only if f : (X, ≤) →(Y, ≤) is
order-preserving. From this, one obtains one of the fundamental theorems in the theory (see
[1]):
Theorem 2.3. The category of Alexandroff T0-spaces is isomorphic to the category of partially
ordered sets.
From now on, we do not distinguish between an Alexandroff T0-space and a partially or-
dered set (or poset). Moreover, we will assume, without further mention, that every Alexan-
droff space under consideration satisfies the T0 separation property. This convention is justi-
fied because any Alexandroff space satisfying the T1 separation axiom must have the discrete
topology.
Remark 2.4. Let X be an Alexandroff space. Then
Ux = { y ∈X | y ≤x },
Fx = { y ∈X | y ≥x }.
Moreover, for any subset S ⊆X, define
US = { y ∈X | y ≤s for some s ∈S },
FS = { y ∈X | y ≥s for some s ∈S }.
Similarly, we define
Cx = Ux ∪Fx,
CS = US ∪FS.
When defining the partial order on an Alexandroff space X, one may also consider the
following relation: x ≤y if and only if Ux ⊆Uy. This relation defines another partial order
on X, which we call the opposite order. If one instead takes upper sets in a partially ordered
set (X, ≤), then one obtains an Alexandroff T0 topology on X, called the opposite topology.
We denote by Xop the set X equipped with this opposite topology or, equivalently, with the
opposite partial order. It is straightforward to see that Ux corresponds to Fx in Xop, and vice
versa.

Given an Alexandroff space X and a point x ∈X, let Ax denote a maximal antichain
containing x. The width of X, denoted width(X), is defined as the cardinality of a maximal
antichain in X. The height of X, denoted ht(X), is defined as one less than the length of a
maximal chain in X. The height of a point x is defined by ht(x) = ht(Ux). Furthermore, we
write x ≺y in X to indicate that there is no element z ∈X such that x < z < y. Note that if
f : X →Y is a homeomorphism, then f preserves heights, the width, chains, and antichains.
The Hasse diagram of X is the directed graph whose vertices are the elements of X, with a
directed edge from x to y whenever x ≺y.
Let us recall a basic property of Alexandroff spaces:
Proposition 2.5. Let X be an Alexandroff space. Then X is connected if and only if it is
path-connected. Moreover, a path from x to y in X is a finite sequence of points x0, . . . , xn ∈X
such that x0 = x, xn = y, and for each i we have either xi < xi+1 or xi > xi+1.
Now, we introduce a useful construction within this setting:
Definition 2.6. Let X and Y be Alexandroff spaces. The join X ⊛Y is the Alexandroff
space that consists on the disjoint union of X and Y , where we keep the given ordering in X
and Y and we declare that x ≤y for every x ∈X and y ∈Y .
To conclude this section, we recall some basic results concerning homotopy in this setting.
We begin by introducing notation. Given continuous maps f, g : X →Y between Alexandroff
spaces, we write f ≥g (resp., f ≤g) if f(x) ≥g(x) (resp., f(x) ≤g(x)) for every x ∈X.
Theorem 2.7. Let f, g : X →Y be continuous maps between Alexandroff spaces. If there
exists a sequence f0, ..., fn : X →Y of continuous maps such that f0 = f, g = gn and
fi+1 ≤fi or fi+1 ≥fi with i = 0, ..., n −1, then f is homotopic to g.
Definition 2.8. Let X be an Alexandroff space and x ∈X. It is said that x is a down (resp.,
up) beat point if Ux \ {x} (resp., Fx \ {x}) contains a maximum (resp., minimum).
Theorem 2.9. Let X be an Alexandroff space. If x ∈X is a down or up beat point, then
X \ {x} is a strong deformation retract of X.

Proof. This follows immediately from Lemma 3.3. If U is a proper open subgroup of X, then
U−1 = U, which implies that U is also closed. The connectedness hypothesis then yields the
result.
Moreover, from Lemma 3.3, we obtain the following result:
Theorem 3.5. Let X be a non-compact Alexandroff paratopological group. Then the conjugate
topology coincides with the opposite topology.
For any given paratopological group (G, τ), it is well known that G∗= (G, τ ∨τ −1) is a
topological group. This group is called the topological group associated to the paratopological
group G (see [12, Section 1] for more details and notation). In our setting, the topology of the
topological group associated to a non-compact Alexandroff paratopological group is trivially
the discrete topology. This is consistent with the fact that if G satisfies the T0 separation
axiom, then G∗is Hausdorff. Moreover, in general, an Alexandroff topology and its opposite
need not coincide.

Theorems 3.6 and 3.7 give that within this setting the only non-trivial spaces are the
non-compact paratopological Alexandroff spaces. To conclude this section, we present three
examples of such spaces. The first two examples are abelian, while the third is not.
Example 3.8. Let us consider the set of the real numbers R or integer numbers Z with
the usual order and the sum. This is a non-trivial non-compact Alexandroff paratopological
group.
Example 3.9. Let Mn the set of square matrices of order n. Consider the Loewner order on
this set, i.e., A ≤B if and only if B −A is positive semi-definite. This defines an Alexandroff
T0 topology on Mn. Moreover, the usual sum of matrices is compatible with this partial order.
Hence, Mn is a non-compact abelian paratopological Alexandroff group. Note also that U0
consists on the set of every positive semi-definite matrices, where 0 denotes the matrix of
zeros.
Let us consider the real numbers R as in Example 3.8. It is easy to verify that the map
tr : Mn →R defined by the usual trace of matrices is a continuous homomorphism between
non-compact Alexandroff paratopological groups.

Remark 4.2. Theorem 4.1 shows that there are no elements of finite order in (U1∪F1)\{1} for

of finite order. For example, consider GLn(R) from Example 3.10. It is evident that for
every permutation matrix P, one has that P n is the identity matrix. This does not contradict
Theorem 4.1 because P is not comparable to the identity matrix.

Corollary 4.3. Let X be a non-compact Alexandroff paratopological group. If x ∈X has

Embeddings of non-compact Alexandroff paratopological groups
One problem that has been widely studied in the literature on both topological groups and
paratopological groups is the characterization of embeddings of such groups as closed sub-
groups of products of topological or paratopological groups satisfying additional structural
properties. See, for example, [11] and the references therein. In [10], this problem is solved
for T0 paratopological groups. In this section, we adapt the statements from that thesis to
our framework, simplifying both the formulation of the main theorem and several classical
definitions.
Definition 4.25. Let X be a paratopological group with identity 1. A family γ of open
neighborhoods of 1 is subordinated to an open neighborhood U of 1 if for every x ∈X, there
exists V ∈γ such that xV x−1 ⊆U.
If X is a non-compact Alexandroff paratopological group and we consider U1, the above
condition can be written simply as xvx−1 ≤1 for every v ∈V .
Definition 4.26. Let X be a paratopological group. We say that X is ω-balanced if for
every open neighborhood U of 1, there exists a countable family γ of open neighborhoods of
1 subordinated to U.
In our framework, Definition 4.26 can be simplified as follows:
Lemma 4.27. Let X be non-compact Alexandroff paratopological group. Then X is ω-balanced
if and only if there exists a countable family γ of open neighborhoods of 1 subordinated to U1.
Proof. Let us suppose that there exists a countable family γ of open neighborhoods of 1
subordinated to U1. Recall that for every open neighborhood U of 1, one has that U1 ⊆U.
Hence, for every open neighborhood U of 1 consider γ. Clearly, for every x ∈X, there exists
V ∈γ such that xV x−1 ⊆U1 ⊆U, as desired. The other implication follows trivially.
This characterization simplifies the statement of [10, Theorem 2.2.8] in our setting as
follows:
Theorem 4.28. Let X be a non-compact Alexandroff paratopological group.
Then X is
topologically isomorphic to a subgroup of a product of first countable paratopological groups T0
if and only if there exists a countable family γ of open neighborhoods of 1 subordinated to U1.

The combinatorics of Alexandroff paratopological groups
We adapt and investigate several well-known properties of partially ordered sets within this
framework. This approach leads to a classification of a family of non-compact Alexandroff
paratopological spaces.
Proposition 5.1. Let X be a non-compact Alexandroff paratopological group. Then ht(X) =
∞.
Proof. We argue by contradiction. Suppose ht(X) = n, which gives that there exists a chain
x0 < x1 < ... < xn. On the other hand, as an immediate consequence of Theorem 4.4: Fx0 is
homeomorphic to Fxn. Thus, we can extend the chain x0 < x1 < ... < xn with elements from
Fxn and this gives the contradiction.
Unlike with the height, we may have finite width as we demonstrate with the following
non-trivial example.
Example 5.2. Let X = {xi, yj}i,j∈Z with xi, yj < xs, yk if and only if i, j < k, s. It is evident
that X is a partially ordered set with this relation (see Figure 2 for the Hasse diagram of X).
For every i ∈Z, define xi : X →X by xi(xj) = xj+i and xi(yj) = yj+i, and define yi : X →X
by yi(xj) = yj+i and yi(yj) = xj+i. Let us verify that xi and yi are continuous maps. We
first prove that xi is continuous by studying cases.
(i) xj < xs, then j < s and we obtain xi(xj) = xj+i < xs+i = xi(xs).
(ii) xj < yk, then j < k and, therefore, xi(xj) = xj+i < yk+i = xi(yk) since j + i < k + i.
(iii) yj < xs implies j < s and we deduce xi(yj) = yj+i < xs+i = xi(xs).
(iv) yj < yk gives j < k, then xi(yj) = yj+i < yk+i = xi(yk).
