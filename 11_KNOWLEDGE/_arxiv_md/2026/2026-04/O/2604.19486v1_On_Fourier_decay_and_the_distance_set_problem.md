On Fourier decay and the distance set problem
Jonathan M. Fraser and Thang Pham
Abstract. We study the Falconer distance set problem in Euclidean space and obtain improved
dimensional estimates under natural Fourier analytic assumptions cast in terms of the Fourier
dimension and spectrum. Interestingly, under reasonably mild assumptions, we are able to beat
the d/2 dimension threshold in dimensions d ⩾5. For example, we show that (in any ambient
spatial dimension d) a Borel set with Fourier dimension at least 2 has a distance set of full
Hausdorff dimension. We also show that (in any ambient spatial dimension d) a Borel set with
Fourier spectrum at least d/4 + 1 at θ = 1/2 has a distance set of full Hausdorff dimension. In
particular, this can hold for sets with Fourier dimension zero (provided d ⩾4). We also consider
pinned variants of these problems and construct examples that demonstrate the sharpness (or
near sharpness) of our results.
Mathematics Subject Classification 2020. primary: 28A80, 42B10; secondary: 28A75, 28A78.
Key words and phrases: distance set problem, Hausdorff dimension, Fourier dimension, Fourier
spectrum.

1. Introduction
1.1. The distance set problem and summary of our results. The distance set problem is a
famous and important problem in geometric measure theory. It was introduced in an influential
paper of Falconer from 1985 [Fa85], but can be viewed as a continuous analogue of the famous
distance problem of Erd˝os which asks how many distinct distances are guaranteed to be determined
by a set of N points in the plane.

Given a Borel set E ⊆Rd, the distance set is defined by
D(E) = {|x −y| : x, y ∈E},
that is, it is the set of distances realised between points in E. The distance set problem is then to
determine how large D(E) must be, given certain geometric constraints on E. Here we interpret
‘large’ in terms of Hausdorff dimension, and the geometric constraint on E might simply be that
it is itself large in terms of dimension. For example, one of the most well-known versions of the
problem is the conjecture that
(1.1)
dimH E ⩾d/2 ⇒dimH D(E) = 1.
This conjecture is open for all d ⩾2 despite sustained interest over several decades and much
recent progress, see [DIOWZ21, DZ19, DORZ23+, GIOW20, KS19, SW25].
It is known, and
important to keep in mind for this paper, that the threshold d/2 in (1.1) cannot be improved, see
[Fa85]. That is, there exist (compact) E ⊆Rd with dimH E arbitrarily close to (but smaller than)
d/2, but yet dimH D(E) < 1. The sets used to demonstrate the d/2 threshold are very rigid and
possess a lot of arithmetic resonance. These features mean that the Fourier analytic behaviour
of measures supported on these examples must be very bad. This perhaps suggests that, under
mild Fourier analytic assumptions, the threshold d/2 might be lowered. This is our main objective
in this paper. In the opposite direction from the rigid examples described above, it is natural to
consider sets with optimal Fourier decay, namely, Salem sets (see the next section for a precise
definition). Mattila proved in [Ma87] that the distance set problem (1.1) can be resolved for Salem
sets in the sense that if E is Salem, then the conjectured implication
dimH E ⩾d/2 ⇒dimH D(E) = 1
indeed holds. We show that this result can be dramatically improved in high dimensions by proving
that if E is Salem, then
dimH E ⩾2 ⇒dimH D(E) = 1,
see Theorem 2.4 and Corollaries 2.7 and 2.8. In particular, our result beats the d/2 threshold
for d ⩾5. This result is a special case of more general results which require much weaker Fourier
analytic assumptions.
These assumptions are cast in terms of the Fourier spectrum and give
concrete, checkable, and relatively mild conditions ensuring that the distance set of a given set is
of full Hausdorff dimension or even has positive 1-dimensional Lebesgue measure, see Corollaries
2.5 and 2.7.
We also consider the more general problem where one studies the distances realised between two
given sets, see our main Theorem 2.1 as well as Corollary 2.3, and the problem where one
fixes a ‘pin’ and considers only distances realised between the pin and other points. More precisely,
given Borel sets E, F ⊆Rd, we define the distance set
D(E, F) = {|x −y| : x ∈E, y ∈F}.
Then D(E, E) = D(E) and
D({x}, E) =: Dx(E)
is the pinned distance set for x ∈Rd. If x ∈E, then Dx(E) ⊆D(E) and a priori the pinned
distance set should be much smaller than the full distance set. In particular, there is interest in
proving the stronger conclusion that, for example, there exists x ∈E such that dimH Dx(E) = 1
