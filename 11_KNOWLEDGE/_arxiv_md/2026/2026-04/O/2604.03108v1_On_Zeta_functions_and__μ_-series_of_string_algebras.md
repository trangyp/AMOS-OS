1. Introduction
In the representation theory of finite-dimensional associative algebras over an algebraically closed field
K, the trichotomy result due to Drozd [Dro80] and Crawley-Boevey [Cra88] partitions all such algebras into
finite, tame, or wild representation type–the names signify the tractability of the classification problem for
their module categories.
Recall that a finite-dimensional K-algebra Λ of infinite representation type is said to be tame if, for each
m ≥1, there exist finitely many Λ-K[x]-bimodules M1, · · · Ms, that are free of finite rank as right K[x]-
modules, such that (up to isomorphism) all but finitely many indecomposable m-dimensional Λ-modules are
isomorphic to a module of the form Mi ⊗K[x] S with S a simple K[x]-module. Let µΛ(m) denote the minimal
number of such bimodules with total dimension m.
The µ-series of Λ is the formal power series ¯µΛ(t) := P
m≥1
µΛ(m)tm.
The class of tame algebras can be further partitioned. A tame algebra Λ is said to be
• domestic if there exists some n ≥0 such that µΛ(m) ≤n for each m ≥1;
• of polynomial growth if there exists some n ≥1 such that µΛ(m) ≤mn for each m ≥1;
• of exponential growth if for each n ≥1 there exists some m ≥1 with µΛ(m) > mn.
Among tame algebras, string algebras form an important test subclass for various conjectures, since their
module categories are completely understood via combinatorics. Indeed, a classification result of Butler and
Ringel [BR87] states that any finite-dimensional module over a string algebra Λ = KQ/I–presented using a
bound quiver (Q, I)–can be described using combinatorial entities called strings and bands, that are certain
walks and certain cyclic walks respectively in the quiver Q. As a consequence, the µ-series of a string algebra
is essentially determined by the set Ba(Λ) of all bands for Λ up to cyclic permutation.

5. Prime number theorem for string algebras
In this section, we define string algebras, and then prove an analogue of the graph prime number theorem
for them (Theorem A), as a corollary of which it follows that non-domestic string algebras have exponential
growth (Corollary B).
Definition 5.1. A zero-relation algebra Λ = KQ/I is a string algebra if the following conditions hold.
(1) For all v ∈Q0, there are at most two arrows a, b ∈Q1 such that s(a) = s(b) = x.
(2) For all v ∈Q0, there are at most two arrows c, d ∈Q1 such that e(c) = e(d) = x.
(3) For all b ∈Q1, there is at most one arrow a ∈Q1 such that ab /∈I.
(4) For all b ∈Q1, there is at most one arrow c ∈Q1 such that bc /∈I.

A complete combinatorial classification of the finite-dimensional indecomposable modules of a string
algebra Λ was given by Butler and Ringel [BR87]–we recall this classification result briefly. There is a string

only if b′ is a cyclic permutation of either b or b−1, n = n′ and θ = θ′. Furthermore, no string module is
isomorphic to a band module.

7. Extension to special biserial algebras
Special biserial algebras form a distinguished subclass of tame algebras that properly contains the class of
string algebras–they are defined by dropping the requirement of being a zero-relation algebra in the definition
of a string algebra. We recall some facts about the representation theory of special biserial algebras from
[WS83] and [WW85].
Consider a special biserial algebra Λ = KQ/I.
Let ˜I be generated by the set of paths u such that
(u −λv) ∈I for some path v sharing the source and end with u and λ ∈K so that ˜Λ := KQ/˜I is
a string algebra.
Every finite-dimensional indecomposable Λ-module is either a string module, a band
module, or a projective-injective module. The canonical surjection Λ →˜Λ induces a bijection between the
isomorphism classes of indecomposable ˜Λ-modules and the isomorphism classes of indecomposable Λ-modules
that are not projective-injective. Since there are only finitely many projective-injective indecomposables up
to isomorphism, it follows that the µ-series of Λ and ˜Λ coincide. Therefore, the results of the above two
sections extend to special biserial algebras.
