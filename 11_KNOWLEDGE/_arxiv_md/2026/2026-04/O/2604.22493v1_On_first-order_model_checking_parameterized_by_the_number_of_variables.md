Abstract
The first-order (FO) model checking problem asks, given an FO sentence ϕ and a graph G, whether
G is a model of ϕ. This problem is known to be AW[∗]-hard when parameterized by the quantifier
rank of the formula. A classical algorithm decides this problem in XP-time parameterized by the
number of variables in the formula.
Due to AW[∗]-hardness, it is natural to ask about the complexity of the problem when restricted
to some well-behaved class of graphs. There are many results describing graph classes C such that
the FO model checking problem restricted to C admits an FPT-time algorithm when parameterized
by the quantifier rank of the formula.
Parameterization by the quantifier rank is significantly more restrictive than parameterization by
the number of variables. We investigate the graph classes C for which the FO model checking problem
restricted to C admits an FPT-time algorithm when parameterized by the number of variables in the
formula. We characterize these classes in the monotone setting, and prove a slightly weaker result in
the hereditary setting.

Introduction
The first-order (FO) model checking problem asks, given a graph G and an FO formula ϕ,
whether G |= ϕ. The FO model checking problem thus generalizes all problems expressible
in first-order logic. Given an n-vertex graph G and FO formula ϕ using k distinct variables,
the well-known naive evaluation algorithm decides G |= ϕ in time O(|ϕ| · nk). That is, the
FO model checking problem parameterized by the number of variables can be solved in
XP-time. Downey, Fellows, and Taylor [2] proved that the FO model checking parameterized
by the quantifier rank of the formula is AW[∗]-hard, thus giving rise to the following natural
question:
▶Question 1.1. For which graph classes C does it hold that FO model checking admits an
FPT-time algorithm when restricted to inputs from C and parameterized by the quantifier
rank of the formula?
Over the last few decades, there has been significant progress towards Question 1.1.
However, the naive evaluation algorithm runs in XP-time even when parameterized by the
number of variables rather than the quantifier rank of the formula. Hence, it seems natural
to also ask the following question:
▶Question 1.2. For which graph classes C does it hold that FO model checking admits an
FPT-time algorithm when restricted to inputs from C and parameterized by the number of
variables of the formula?
We investigate Question 1.2 in the settings where the class C is monotone or hereditary.
We fully answer the question for monotone graph classes:
▶Corollary 3.3. There is a computable function f : N × N →N, and an algorithm A such
that, given an FO formula ϕ with s variables and a graph G of tree-depth k, A decides G |= ϕ
in time O(f(s, k) · (|G| + |ϕ|)).
▶Theorem 4.6. Let C be a monotone class of unbounded tree-depth. Then, the FO model-
checking problem is AW[∗]-hard when restricted to C and parameterized by the number of
variables of the formula.
Theorem 4.6 together with Corollary 3.3 immediately gives the following solution to
Question 1.2 in the monotone setting:
▶Theorem 1.3. Assume that FPT̸=AW[∗]. Let C be a monotone class of graphs. Then, FO
model checking is FPTwhen restricted to inputs from C and parameterized by the number of
variables if and only if C has bounded tree-depth.
We conjecture that a statement similar to Theorem 1.3 holds also for hereditary classes
with tree-depth replaced by shrub-depth. We prove the existence of an algorithm and a
conditional lower bound supporting our conjecture:
▶Corollary 3.5. For every graph class C of bounded shrub-depth and every integer s ∈N,
there is a constant c ∈N and an algorithm A such that, given an FO formula ϕ with s
variables and a graph G ∈C, A decides G |= ϕ in time O(c · (|G| + |ϕ|)).
▶Theorem 4.8. Let C be a hereditary class of unbounded shrub-depth. Assume that one of
the following holds:
(a) For every t ∈N, C contains a flipped half-graphs of order t; or

a symmetric relation F on P. We denote by F ⊕G the following graph: V (F ⊕G) = V (G),
and uv ∈E(F ⊕G) is decided as follows:
If {u, v} ̸⊆S P, then uv ∈E(F ⊕G) if and only if uv ∈E(G).
Otherwise, there are U, V ∈P such that u ∈U and v ∈V . Then, uv ∈E(F ⊕G) if and

In a slight abuse of notation, we sometimes say that a graph H is a P-flip of G if there is a
P-flip F such that H = F ⊕G. If P = {P} has only one part, then we write P-flip instead
of {P}-flip.
A half-graph Ht of order t is a bipartite graph on 2t vertices a1, . . . , at, and b1, . . . , bt
such that aibj ∈E(Ht) if and only if i ≤j. We always assume that the bipartition is
At = {a1, . . . , at} and Bt = {b1, . . . , bt}. A flipped half-graph of order t is any {At, Bt}-flip
of Ht.
We denote by kPt the disjoint union of k paths of length t. We assume that V (kPt) =
[k] × [t], and (a, b)(c, d) ∈E(kPt) if and only if a = c and |b −d| = 1. With each kPt, we
associate a layering Lk,t = (L1, . . . , Lt), where Li = {(a, i) | a ∈[k]}. A layerwise flipped kPt
is any Lk,t-flip of kPt.

2.2
Graph parameters
▶Definition 2.1 (Elimination forests and tree-depth). Let G be a graph, and let T be a forest
on the same vertex set. We say that T is an elimination forest of G if endpoints u, v of every
edge uv of G are in ancestor-descendant relation in T. The tree-depth of G is the minimum
height of its elimination forest.
▶Definition 2.2 (Tree-models and shrub-depth). Let G be a graph, and let T be a c-colored
rooted tree such that the set of leaves of T is exactly the vertex set of G. We say that T is a
tree-model of G if adjacency in G of a pair of vertices u, v ∈V (G) depends only on their
color and distance in T.
A graph class C has shrub-depth at most t if there is c ∈N such that every graph G ∈C
admits a tree-model of height at most t using at most c colors.

It is well-known that a graph class C has bounded shrub-depth if and only if C has

A notable property of hereditary classes of bounded shrub-depth and monotone classes of
bounded tree-depth, proven by Gajarský and Hliněný [5], is the existence of an FPT-time
algorithm for MSO model checking parameterized by the quantifier rank of the formula with
elementary dependency on the quantifier rank. Furthermore, the results of Frick and Grohe
[4] together with the results of Mählmann [6] immediately imply that (assuming P̸=NP) there
is no hereditary class of unbounded shrub-depth nor monotone class of unbounded tree-depth
admitting an FPT time algorithm for MSO model checking with elementary dependency on
quantifier rank of the formula.
2.3
First-order logic and pebble games
We assume that the reader is familiar with FO logic. Briefly introducing, an FO formula over
the language of colored graphs can existentially (∃x : ϕ) and universally (∀x : ϕ) quantify
over vertices of the graph; it can use the usual boolean connectors (ϕ ∧ψ, ϕ ∨ψ, ¬ϕ, . . .); it
can express equality (x = y) and adjacency (E(x, y)) of a pair of variables x, y; and it can
express a variable x having color i (Ci(x)). A sentence is a formula without any free variable.
The quantifier rank of a formula is the maximum depth of quantifier nesting. It is well-known
that there are only finitely many formulas of each quantifier rank up to logical equivalence.
The number of variables of a formula is the number of distinct variable names. Note that
one can reuse variables. Clearly, the quantifier rank of a formula ϕ is greater or equal to the
number of variables of ϕ. On the other hand, it is easy to see that three variables suffice to
write a formula ϕk(x, y) expressing “there is a path of length at most k between x and y”.

We say that two graphs A and B are elementarily equivalent if tp(A) = tp(B), and we
denote this by A ≡B. Similarly, we say that A and B are FOs equivalent if tps(A) = tps(B),
and we denote this by A ≡FOs B. In order to prove elementary equivalence or FOs equivalence,
one uses pebble games. The well-known Ehrenfeucht-Fraïssé game is used to prove elementary
equivalence. The game is played by two players – Duplicator and Spoiler on a pair of graphs
A and B. In each turn, Spoiler picks one of the graphs and places a new pebble on a vertex
of that graph, or moves an existing pebble from one vertex to another. Then, the Duplicator
places a new pebble or moves an existing pebble in the other graph. The Duplicator must
place a new pebble if Spoiler placed a new pebble, and it must move the i-th pebble if Spoiler
moved the i-th pebble. Consider k-tuples ¯a = (a1, . . . , ak) of vertices of A and ¯b = (b1, . . . , bk)
of vertices of B; we say that ¯a 7→¯b is a partial isomorphism if the function f(ai) = bi is
an isomorphism of A[{a1, . . . , ak}] and B[{b1, . . . , bk}]. Let ¯a be the tuple of vertices with
pebbles from A (ordered by the time when a pebble was first placed there), and let ¯b be the
analogous tuple from B. If ¯a 7→¯b is not a partial isomorphism at the end of any turn, then
Spoiler wins the Ehrenfeucht-Fraïssé game. Duplicator wins if Spoiler does not win after
any round. The graphs A and B are elementarily equivalent if and only if Duplicator has a
winning strategy for Ehrenfeucht-Fraïssé on A and B.
In order to prove FOs equivalence, one uses a variation on the Ehrenfeucht-Fraïssé game,
where the players can only use s pebbles on each graph (however, they can move each pebble
as many times as they want). We refer to this game as the FOs pebble game. Again, it holds
that two graphs A and B are FOs equivalent if and only if the Duplicator wins the FOs
pebble game on A and B.

Hardness
We consider both the monotone and hereditary settings, and we investigate which graph classes
admit FO model checking in FPT-time when parameterized by the number of variables rather
than quantifier rank. In the monotone setting, the following theorem extends Corollary 3.3
to a full characterization of these classes.
▶Theorem 4.6. Let C be a monotone class of unbounded tree-depth. Then, the FO model-
checking problem is AW[∗]-hard when restricted to C and parameterized by the number of
variables of the formula.
In the hereditary setting, we provide strong evidence suggesting that classes of bounded
shrub-depth are the “limit” of this parameterization of FO model checking. The main
difference from the monotone setting is that, in the case of a monotone class C of unbounded
tree-depth, it is easy to construct a graph P ∈C of arbitrarily large tree-depth. Indeed,
it suffices to take a sufficiently long path P. Mählmann [6] proved that hereditary class C
has unbounded shrub-depth if and only if C contains layerwise flipped tPt for all t ∈N. So
far, we do not know how to algorithmically construct a layerwise flip of tPt belonging to C.

Conclusions
We have shown that FO model checking on colored shallow trees admits FPT-time algorithm
parameterized by the quantifier rank of the formula. It seems natural to ask whether the
same parameterization would also work with monadic second-order logic. We note that there
are some non-trivial obstacles towards such an algorithm, but we conjecture it to be possible:
▶Conjecture 5.1. There is an algorithm A and a function f : N4 →N such that the following
holds. Let ϕ be a formula of monadic second-order logic using s1 first-order and s2 monadic
second-order variables. Let T be a c-colored tree of depth d. Then, A decides T |= ϕ in time
O(f(s1, s2, c, d) · (n + |ϕ|)).
In the case of monotone classes, we have fully resolved Question 1.2. However, the
question is still open in the hereditary setting, and we thus conjecture that Theorem 4.8 can
be strengthened, and that bounded shrub-depth is the right “limit” of efficient FO model
checking on hereditary graph classes when parameterized by the number of variables.
▶Conjecture 5.2. Let C be a hereditary class of unbounded shrub-depth. Then, the FO
model-checking problem is AW[∗]-hard when restricted to C and parameterized by the
number of variables of the formula.
We note that, as an easy corollary of Lemma 3.1, we obtain another characterization of
hereditary classes of bounded shrub-depth:
▶Corollary 5.3. There is a constant s0 ∈N such that the following holds. Let C be a
hereditary graph class, and let s ∈N, s ≥s0, and let tps(C) := {tps(G) | G ∈C} be the class
of all FOs types of graphs from C. Then, C has bounded shrub-depth if and only if there is
c ∈N such that | tps(C)| ≤c.
Proof.
Let C be a hereditary graph class with unbounded shrub-depth. Then, there is a 1-
dimensional interpretation ι such that ι(C) is the class of all paths. It is easy to observe
that Spoiler wins the FO3 pebble game between any pair of paths of distinct lengths,
so the class of all paths has an unbounded number of FO3 types. Hence, C also has an
unbounded number of FOs′ types for some s′ depending only on the interpretation ι.
Let C be a graph class with bounded shrub-depth.
Then, there is a 1-dimensional
interpretation ι and constants d and c such that C ⊆ι(Td,c), where Td,c denotes the class
of all c-colored trees of depth d. Observe that it suffices to show that the number of
FOs+s′′ types of trees from Td,c is bounded for some constant s′′ depending only on the
interpretation ι. This follows immediately from Lemma 3.1, because each tree from Td,c
is FOs+s′′ equivalent to one of the finitely many c-colored trees on a bounded number of
vertices.

constant s.
