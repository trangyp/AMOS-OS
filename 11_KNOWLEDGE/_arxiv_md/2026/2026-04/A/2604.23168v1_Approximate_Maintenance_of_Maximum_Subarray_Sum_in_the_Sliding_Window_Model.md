Approximate Maintenance of Maximum Subarray Sum
in the Sliding Window Model
Ryo Suzuki∗
Yutaro Yamaguchi∗
Abstract
In the sliding window model, we are required to maintain the target statistics over the
most recent n elements of a data stream, which is captured by a window of size n sliding
over the data stream. Exact computation usually requires space linear in n, and the central
goal is approximate maintenance using sublinear space. In this paper, we study the problem
of maintaining the maximum subarray sum in the sliding window model. While the classical
Kadane’s algorithm computes the exact answer using constant space in the static setting,
it does not extend directly, because a new element makes the oldest one expire, which may
invalidate the optimal subarray so far. Our first observation is that the so-called Smooth
Histogram framework can lead to a constant-factor approximation (in the sense of relative
error) using O((log n)2) bits of space. We then refine this framework accordingly, which
enables for any ϵ > 0 to maintain a (1 ± ϵ)-approximation using O(ϵ−1(log n)2) bits of space
and O(ϵ−1 log n) operations per update. The space complexity is asymptotically optimal.
Keywords: Sliding window, Maximum subarray sum, Smooth histogram

Introduction
The rapid growth of sequential data such as network logs, sensor measurements, and financial
transactions has led to increasing interest in data stream processing. In many applications, only
the most recent data is relevant for decision making, which motivates the sliding window model.
In this model, at each time t, computations are performed on the most recent n elements, while
older elements expire automatically.
Maintaining statistics (e.g., mean, variance, and counting specific elements) is a typical task
in the sliding window model. It is easy if we have plenty of time and memory, but becomes
challenging under strict time or memory constraints. Storing all elements requires Ω(n) space,
which is impractical for large-scale streams.
Therefore, the central goal is to maintain an
approximation of the target statistics using sublinear space. For many problems in real-time
applications, the time complexity of each update is also significant.
1.1
Sliding Window Model
We formalize the sliding window model and the goal. Let (p1, p2, . . . ) be a stream of data, and
n be the window size. As a usual setting, we assume that all elements pi are integers whose
absolute values are bounded by O(poly(n)). At each time t = 1, 2, . . . , the active window is
defined as
Wt :=

Let f(Wt) denote the true value of the target statistics of Wt. Then, for ϵ > 0, an estimation
f′(Wt) of f(Wt) is called a (1 ± ϵ)-approximation if
(1 −ϵ)f(Wt) ≤f′(Wt) ≤(1 + ϵ)f(Wt).
(2)
An algorithm is also said to be (1 ± ϵ)-approximation if at every time t it maintains a (1 ± ϵ)-
approximation of f(Wt).
The sliding window model was formally introduced by Datar, Gionis, Indyk, and Mot-
wani [5]. They proposed the Exponential Histogram (EH) technique to maintain a certain type
of statistics. As the simplest example, it shows that for any ϵ > 0, a (1 ± ϵ)-approximation of
counting 1s in the sliding window over a bit stream (where every pi is 0 or 1) can be maintained
only using O(ϵ−1(log n)2) bits of space (see Section 2.1 for more details). This work initiated a
large body of research on sliding window algorithms (see, e.g., [2,9]).
While the EH technique can handle weakly additive functions efficiently, many important
statistics fall outside this class. To address this limitation, Braverman and Ostrovsky [4] intro-
duced the Smooth Histogram (SH) framework, which extends the applicability of sliding window
algorithms to a broader class of functions satisfying a smoothness property (see Section 3 for
the details).
Subsequent work has further explored both the power and limitations of this framework.
In particular, Krauthgamer and Reitblat [8] introduced the notion of almost-smooth functions,
showing that the smooth histogram paradigm can be extended to functions that do not strictly
satisfy smoothness, by relaxing the structural conditions.
In addition, several works have improved space bounds for specific problems within the
sliding window model. For example, Braverman, Grigorescu, Lang, Woodruff, and Zhou [3]
established nearly optimal bounds for counting distinct elements and heavy hitters, showing
that polylogarithmic space is both necessary and sufficient up to lower-order factors. More
recently, Feng, Swartworth, Woodruff [6] further tightened these bounds by introducing the

1.3
Our Contribution
In this paper, we prove the following:
Theorem 1.1. For any ϵ > 0, a (1 ± ϵ)-approximation of the maximum subarray sum in the
sliding window can be maintained using O(ϵ−1(log n)2) bits of space and O(ϵ−1 log n) operations
per update.
Our first observation is that the maximum subarray sum satisfies a relaxed smoothness
condition. This observation enables a (1 ± α)-approximation using O((log n)2) bits of space for
a constant α > 1

This can be done without essentially increasing space complexity, which leads to Theorem 1.1.

Indeed, the lower bound of

special case of our problem as mentioned above.

Preliminaries
2.1
Exponential Histogram (EH)
We briefly review the Exponential Histogram (EH) proposed in [5], which is a fundamental
technique to maintain approximate statistics in the sliding window. This technique is applied
to a class of functions known as weakly additive functions. Intuitively, such functions can be
approximately decomposed over disjoint intervals.
Definition 2.1. A function f defined over intervals of the stream is weakly additive1 if it
satisfies the following:
• 0 ≤f(A) = O(poly(n)) for any interval A;
• there exists a constant Cf ≥1 such that for any pair of adjacent intervals A and B,
f(A) + f(B) ≤f(A ∪B) ≤Cf(f(A) + f(B));
(4)
• f admits a sketch (giving an approximation) such that for adjacent intervals A and B, a
sketch for f(A ∪B) is efficiently computed from sketches for f(A) and f(B).
In particular, if we can take Cf = 1, we say f is additive; then, (4) is always satisfied with
equality, and the exact value of f is eligible for its sketch (without any error).
The idea of the Exponential Histogram is sketched as follows. For the sake of simplicity,
we consider the problem of counting 1s over a bit stream; then, f is clearly additive. The
algorithm maintains a sequence of buckets, each representing an interval of the stream. Each
bucket maintains the function value f(A) of the corresponding interval A and also a timestamp,
which represents when the bucket can be deleted (i.e., when all 1s contributing to f(A) in the
bucket are completely outside the sliding window). The values maintained in buckets grow
exponentially (1, 2, 4, . . . ), and the number of buckets of each value is bounded by a prespecified
parameter, which controls the trade-off between the relative error of estimation and the space
complexity.
More specifically, when a new element arrives,
• if it is 1, a new bucket consisting of the single element is created, and
• if there are too many buckets of the same size, the oldest two among them are merged
into a single larger bucket.

In addition, if the oldest element that has expired instead of the new arrival matches the
timestamp of the oldest bucket, it is deleted.
At each time, the function value is estimated by aggregating the values maintained in the
buckets. As f is additive, the only error comes from the oldest bucket, which may partially
overlap with the window.
For any ϵ > 0, it can be bounded by ϵ in the relative sense by
appropriately setting the upper bound kϵ = Θ(ϵ−1) of the number of buckets of each value. Then,
the number of buckets is always bounded by O(ϵ−1 log n), which concludes that O(ϵ−1(log n)2)
bits of space is sufficient (as f(A) ≤n here, and f(A) = O(poly(n)) in general).
This idea is naturally extended to general additive functions.
Moreover, if f is weakly
additive, a similar trade-off can be achieved by appropriate adjustment. Intuitively, there are
other types of estimation error caused by nonadditivity of f and by inaccuracy of the sketch
of f, which can be bounded using Cf and another parameter representing inaccuracy of the
sketch, respectively. See the original paper [5] for the details.
2.2
Kadane’s Algorithm for Maximum Subarray Sum
We review Kadane’s algorithm [1] for computing the maximum subarray sum in the static
setting. Let (x1, x2, . . . , xn) be the input sequence of integers. For i = 0, 1, 2, . . . , n, the algo-
rithm computes the maximum subarray sum of the prefix (x1, . . . , xi) by a standard dynamic
programming technique.
At each point, the algorithm maintains the following two pieces of information, each requiring
O(1) words (and hence O(log n) bits under the assumption that |xi| = O(poly(n))):
• the maximum µi of the sum of a subarray ending at position i if it is positive, or µi := 0
otherwise, and
• the global maximum µ∗

• µi+1 ←max{0, µi + xi+1}, and

itself attaining the maximum by storing the starting and ending points of the corresponding
subarrays in addition to the values of µ and µ∗.
In the sliding window model, the situation is significantly more challenging.
When the
window moves,
• a new element is inserted at the end, and
• the oldest element is deleted.
The insertion at the end is easily handled in the same way, but the deletion may invalidate
the optimal subarray so far. A naive approach requires restoring the elements in the window
and recomputing the answer from scratch, leading to Θ(n) time per update and Θ(n) words of
space.

Smooth Histogram (SH)
We explain the idea of the Smooth Histogram (SH) framework introduced by Braverman and
Ostrovsky [4], which provides a general method for approximating functions over sliding windows
beyond weakly additive functions.
As discussed in the previous section, the EH technique relies on weak additivity and fails
for functions whose values highly depend on interactions across interval boundaries. The SH
framework overcomes this limitation by maintaining multiple overlapping summaries of the
stream.
The framework applies to functions satisfying a structural property called smoothness. For
two intervals A and B, we mean by B ⊆r A that B is a suffix of A, i.e., B is included in A and
their rightmost elements are the same.
Definition 3.1. For 0 < β ≤α < 1, a function f defined over intervals of the stream is
(α, β)-smooth2 if it satisfies the following:
• 0 ≤f(A) = O(poly(n)) for any interval A;
• for any pair of intervals A and B with B ⊆r A,
– f(B) ≤f(A), and
– if (1 −β)f(A) ≤f(B), then (1 −α)f(A ∪C) ≤f(B ∪C) for any interval C adjacent
to A and B.
The idea of the Smooth Histogram is sketched as follows. At each time t, it maintains a
sequence of indices
s1 < s2 < · · · < sq = t,
each corresponding to an instance for which a base algorithm computes f(Ii) exactly over the
interval Ii = [si, t], which starts at position si and ends at position t. Intuitively, these indices
represent candidate starting points of the window.
The key invariant is that the function
values between consecutive indices do not differ significantly (unless the starting points are
consecutive).
More specifically, when a new element arrives,
• all maintained instances are updated by adding the element at the end,
• a new instance starting at the current time is created, and
• redundant instances are removed so that ps1 is expired but ps2 is still active, and at least
one of the following conditions is satisfied for any index si (1 ≤i < q):
– si+1 = si + 1 and f(Ii+1) < (1 −β)f(Ii);
– f(Ii+1) ≥(1 −α)f(Ii) and if i + 2 ≤q then f(Ii+2) < (1 −β)f(Ii).
The last condition implies q = O(β−1 log n) since
0 ≤f(Iq) ≤· · · ≤f(I2) ≤f(I1) = O(poly(n)).
Moreover, the (α, β)-smoothness of f enables us to maintain a (1 ± α)-approximation of f(Wt),
which is achieved by f(I2). Indeed, I2 ⊆r Wt ⊆r I1 implies
(1 −α)f(I1) ≤f(I2) ≤f(Wt) ≤f(I1),

4.3
Toward (1 ± ϵ)-Approximation
The limitation of the standard SH approach is that it only uses the function values f(A) to
prune the maintained intervals.
This is insufficient when the optimal subarray crosses the
boundary between two intervals, because in that case the relevant quantity is not f(A) itself
but the boundary term Suf(A)+Pre(C). In particular, it may happen that f(B) is close to f(A)
while Suf(B) is much smaller than Suf(A). Then replacing A with its suffix B may severely
underestimate the value of f(A ∪C) once a suitable interval C is appended.
To overcome this difficulty, we check not only f(A) but also Suf(A) when pruning. For each
interval Ii = [si, t], Kadane’s algorithm (cf. Section 2.2) actually maintains the pair (µi,t, µ∗
i,t)
that corresponds to (Suf(Ii), f(Ii)). We then modify the pruning rule of the SH framework
described in Section 3 as follows.
Let Ii := [si, t] (i = 1, 2, . . . , q) be the maintained instances. In the original SH framework
(with β = ϵ), to maintain the last condition for the starting positions si, the algorithm checks
for i = 2, 3, . . . , q −1 in this order whether f(Ii+1) ≥(1 −ϵ)f(Ii−1) or not and removes Ii (and
updates the indices accordingly) if yes. In addition to this condition, we impose Suf(Ii+1) ≥
(1 −ϵ)Suf(Ii−1) for its removal. Then, both the maximum subarray sum and the maximum
suffix sum are preserved up to a factor (1 −ϵ) after its removal.
The next lemma shows that this improved pruning rule is sufficient to preserve the contri-
bution of subarrays crossing interval boundaries.

f(B) ≥(1 −ϵ)f(A),
Suf(B) ≥(1 −ϵ)Suf(A).

f(B ∪C) ≥(1 −ϵ)f(A ∪C).

Then

4.4
Algorithm and Its Complexity
An algorithm that incorporates the improved pruning rule is summarized as follows.
At each time t, it maintains a sequence of indices
s1 < s2 < · · · < sq = t,
where each si corresponds to an instance Ii = [si, t] for which the maximum subarray sum is
computed by Kadane’s algorithm.
When a new element arrives, the algorithm performs the following operations:
1. update all maintained instances by adding the new element at the end;
2. create a new instance for the singleton interval consisting of the new element;
3. remove redundant instances using the improved pruning rule based on both f and Suf,
i.e., for i = 2, 3, . . . , q −1 in this order, if f(Ii+1) ≥(1 −ϵ)f(Ii−1) and Suf(Ii+1) ≥
(1 −ϵ)Suf(Ii−1), then remove Ii (and update the indices accordingly);
4. delete all expired indices so that ps1 is expired and ps2 is active.
As in the standard SH framework, the output is the value f(I2) maintained by the first
active instance, which satisfies
(1 −ϵ)f(Wt) ≤f(I2) ≤f(Wt).

operations per update.

Suf(Ii+1) < (1 −ϵ)Suf(Ii−1).
(7)
Since f is monotone and bounded by O(poly(n)), (6) can hold O(ϵ−1 log n) times. Furthermore,
Suf is also monotone with respect to adding elements at the beginning, which also bounds the
number of occurrences of (7) by O(ϵ−1 log n). Thus, q = O(ϵ−1 log n), which concludes that the
algorithm uses O(ϵ−1(log n)2) bits of space in total.
Finally, we discuss the computational time. Each instance can be updated in O(1) operations
as with Kadane’s algorithm, and there are q = O(ϵ−1 log n) maintained instances. Thus, Steps
1 and 2 require O(ϵ−1 log n) operations. In addition, Steps 3 and 4 can be easily implemented
in O(q) time, which completes the proof.

In this paper, we have studied the problem of maintaining the maximum subarray sum in
the sliding window model. Since the maximum subarray sum is not simply decomposed into
intervals, the standard Exponential Histogram technique looks difficult to apply directly to this
problem. Our main contribution is to show that this problem can nevertheless be handled within
