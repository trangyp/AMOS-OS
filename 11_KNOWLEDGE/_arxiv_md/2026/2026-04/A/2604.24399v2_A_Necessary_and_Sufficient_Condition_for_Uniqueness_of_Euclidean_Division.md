A Necessary and Sufficient Condition for Uniqueness of
Euclidean Division
Senan Sekhon
April 30, 2026
Abstract
A well-known result from the 1960s characterizes all Euclidean domains in which division is guaranteed to produce a
unique quotient and remainder. As this relies on the historical (and more restrictive) definition of a Euclidean domain,
the question of whether the result still holds under the modern definition was left open. In this paper, we prove the
answer is afirmative.

Background
In a Euclidean domain, the quotient and remainder of Euclidean division are generally not unique. A well-known
result, proved independently by Rhai (1962) [5] and Jodeit (1967) [2], fully characterizes the cases where they are unique:
If R is a Euclidean domain in which the quotient and remainder of Euclidean division are always unique, then either R
is a field or R ∼= K[x] for some field K.
However, both Rhai and Jodeit used the original definition of a Euclidean domain (Definition 2.2), which was stan-
dard at the time but more restrictive than the modern definition (Definition 2.1), involving an extra assumption for the
Euclidean function. In other words, the old and new definitions agree on what a Euclidean domain is, but they disagree
on what qualifies as a Euclidean function. A result of Rogers (1971) [6] states that one can always enforce this assumption
by constructing a new “refined” Euclidean function.
Since uniqueness depends on the Euclidean function (not just the Euclidean domain itself), this left a gap in the
literature: Jodeit and Rhai’s result holds assuming uniqueness under a refined Euclidean function, as per Rogers’ con-
struction. Is uniqueness under some Euclidean function (without any modification) enough to conclude that R is a field
or R ∼= K[x]? This paper closes that gap.

Definition 2.2. f is strongly Euclidean on R if f is Euclidean on R, and for all a, b ∈R\{0}, we have f(a) ≤f(ab).

Lemma 2.3. Suppose f is strongly Euclidean on R. Then for all a, b ∈R\{0}, we have f(a) = f(ab) if and only if
b ∈R×.
Proof.
(⇐) Suppose b ∈R×. Then bc = 1 for some c ∈R. This yields f(ab) ≤f(abc) = f(a), and so f(a) = f(ab).
(⇒) Suppose f(a) = f(ab) but b /∈R×. Since f is a Euclidean function on R, there exist q, r ∈R such that:
a = q(ab) + r
and
(r = 0 or f(r) < f(ab))
This can be rewritten as:
a(1 −bq) = r
and
(r = 0 or f(r) < f(a))
Since b /∈R×, we have 1 −bq ̸= 0, and since R is an integral domain, we have a(1 −bq) ̸= 0. Thus r ̸= 0, and
so f(a(1 −bq)) < f(a), a contradiction as f is strongly Euclidean. Thus b ∈R×.
■
Remark. This does NOT mean f(x) = f(y) ⇒x and y are unit multiples of each other. It means that if y is a
multiple of x (or vice versa) and f(x) = f(y), then x and y are unit multiples of each other.
Example. In Z[i], we have N(2 + i) = N(2 −i) = 5, but 2 + i and 2 −i are not multiples of each other in Z[i].
Lemma 2.4. Suppose f is strongly Euclidean on R, and define m = mina∈R\{0} f(a). Then f(b) = m if and only if
b ∈R×.
In other words, the minimum value of a strongly Euclidean function is attained precisely by the units.
This follows directly by substituting a = 1 into Definition 2.2 and Lemma 2.3.
Definition 2.2 was the original definition of a Euclidean domain (an integral domain with a strongly Euclidean func-
tion), and is used in [1] and [4].

following construction:

Proposition 2.6. Suppose f is Euclidean on R. Then ef is strongly Euclidean on R.
Proof. Note that ef is well-defined, since for every a ∈R\{0}, the set {f(ab) | b ∈R\{0}} is a non-empty subset of
Z+
0 , so it has a minimum. Also, for all a ∈R\{0}, we have ef(a) ≤f(a · 1) = f(a).
We first show that ef is Euclidean on R. Suppose a, b ∈R, b ̸= 0. By (1), there exists c ∈R\{0} such that ef(b) = f(bc).
Since f is Euclidean on R, there exist q, r ∈R such that a = q(bc) + r and (r = 0 or f(r) < f(bc)). This yields
a = (cq)b + r. We want to show that r = 0 or ef(r) < ef(bc). If r = 0, we are done. If not, we have:
ef(r) ≤f(r) < f(bc) = ef(b)
Thus ef is Euclidean on R.
Now suppose a, b ∈R\{0}. By (1), there exists c ∈R\{0} such that ef(ab) = f(abc). Since abc is also a nonzero
multiple of a, we have:
ef(a) ≤f(abc) = ef(ab)
Thus ef(a) ≤ef(ab), and so ef is strongly Euclidean on R.
■
Corollary 2.7. f is strongly Euclidean on R if and only if ef = f.
Proof.
(⇐) By Proposition 2.6, ef is strongly Euclidean, so if ef = f, then f is strongly Euclidean.
(⇒) Suppose a ∈R\{0}. As we have shown in Proposition 2.6, ef(a) ≤f(a). Since f is strongly Euclidean, we have
f(ab) ≥f(a) for all b ∈R\{0}, and so ef(a) ≥f(a). Thus ef(a) = f(a).
■
Definition 2.8. f is ultra-Euclidean on R if f is Euclidean on R, and for all a, b ∈R\{0} such that a + b ̸= 0, we
have f(a + b) ≤max{f(a), f(b)}.

Remark. The name “ultra-Euclidean” comes from the similarity to the triangle inequality in ultrametric spaces:
d(x, z) ≤max{d(x, y), d(y, z)}.
Examples.
1. The degree is ultra-Euclidean on K[x].
2. The order is not ultra-Euclidean on K JxK, since ord(1 + (x −1)) = ord(x) = 1 > 0 = max{ord(1), ord(x −1)}.
3. The absolute value is not ultra-Euclidean on Z, since |1 + 1| = 2 > 1 = max{|1|, |1|} = 1.
Definition 2.9. f is uniquely Euclidean on R if for all a, b ∈R, b ̸= 0, there exist unique q, r ∈R such that
a = qb + r and (r = 0 or f(r) < f(b)).
Examples.
1. The degree is uniquely Euclidean on K[x].
2. The order is not uniquely Euclidean on K JxK, since 1 = 0·x+1 = 1·x+(1−x), and ord(1) = ord(1 −x) < ord(x).
In fact, this works with 1 = a · x + (1 −ax) for any a ∈K. Thus, if K is infinite, there are always infinitely
many Euclidean divisions of 1 by x.
3. The absolute value is not uniquely Euclidean on Z, since 1 = 0 · 2 + 1 = 1 · 2 + (−1) and |1| = |−1| < |2|. In
fact, for all a, b ∈Z, b ̸= 0, if b does not divide a, there will always be two Euclidean divisions of a by b, one
with a positive remainder and one with a negative remainder.
3
The original result
We now state Jodeit and Rhai’s main result in our terminology:
Theorem 3.1. Suppose f is strongly Euclidean and uniquely Euclidean on R. Then either R is a field or R ∼= K[x]
for some field K.
See [2] and [5] for a proof.
Remark. The conclusion of the theorem does not make any reference to f, so it applies to all integral domains that
have at least one function that is both strongly Euclidean and uniquely Euclidean.
We will use the following terminology: A candidate division of x by y (where x, y ∈R and y ̸= 0) is any expression
of the form x = qy + r, where q, r ∈R. It is valid if r = 0 or f(r) < f(y).
As such, saying that f is Euclidean (resp. uniquely Euclidean) simply amounts to saying that for all x, y ∈R, y ̸= 0,
there is at least one (resp. exactly one) valid candidate division of x by y.
In their original proofs, both Jodeit [2] and Rhai [5] prove the following result as a lemma, which we restate and prove
using our terminology.
Proposition 3.2. Suppose f is strongly Euclidean on R. Then f is uniquely Euclidean if and only if it is ultra-
Euclidean.
Proof.
(⇒) Suppose f is not ultra-Euclidean.
Then there exist a, b ∈R\{0} such that a + b ̸= 0 and f(a + b) >
max{f(a), f(b)}. Note that the following are candidate divisions of a by a + b:
a = 0 · (a + b) + a
(2)
a = 1 · (a + b) + (−b)
(3)
These are distinct as 0 ̸= 1. By assumption, we have f(a) < f(a + b), so (2) is valid. Also, since f is strongly
Euclidean and −1 ∈R×, by Lemma 2.3, we have:
f(−b) = f((−1)b) = f(b) < f(a + b)
Thus (3) is also valid, and so f is not uniquely Euclidean.
(⇐) Suppose f is not uniquely Euclidean. Then there exist a, b ∈R, b ̸= 0 such that there are at least two distinct
candidate divisions of a by b. In other words, there exist q, r, s, t ∈R such that:
a = qb + r = sb + t
and
q ̸= s
and
(r = 0 or f(r) < f(b))
and
(t = 0 or f(t) < f(b))
• If r = 0, then a = qb = sb + t, so t = (q −s)b. Since f is strongly Euclidean and q −s ̸= 0, we have
f(t) = f((q −s)b) ≥f(b).
• If t = 0, then a = qb + r = sb, so r = (s −q)b. Since f is strongly Euclidean and s −q ̸= 0, we have
f(r) = f((s −q)b) ≥f(b).

Example (Ultra-Euclidean ̸⇒strongly Euclidean). Suppose R = F4 = {0, 1, α, β}, the field with four elements. Define
f : R\{0} →Z+
0 by f(1) = 0, f(α) = f(β) = 1. Since R is a field, f is Euclidean.
The only pairs (a, b) of nonzero elements of R whose sum is nonzero are (1, α), (1, β) and (α, β).
In all cases,
we have f(a+b) ≤max{f(a), f(b)}, since the right side is 1 and the left side is either 0 or 1. Thus f is ultra-Euclidean.
However, f is not strongly Euclidean as f(α) = 1 > 0 = f(1) = f(αβ). It is also not uniquely Euclidean as 1 = 0α+1
and 1 = 1α + β are two valid candidate divisions of 1 by α.

The improved result
The key ingredient to improving Jodeit and Rhai’s result (Theorem 3.1) is the following:
Theorem 4.1. If f is uniquely Euclidean on R, then f is strongly Euclidean on R.
Proof. Suppose a, b ∈R\{0}. We want to show that f(a) ≤f(ab). Note that the following is a candidate division of
a by ab:
a = 0 · (ab) + a
(4)
Since a ̸= 0, this is valid if and only if f(a) < f(ab).
1. If (4) is valid, then f(a) < f(ab), and we are done.
2. If (4) is not valid, then f(a) ≥f(ab). We will show that f(a) = f(ab). Suppose a = q(ab) + r is the unique
valid division of a by ab, i.e. q, r ∈R and (r = 0 or f(r) < f(ab)). Then r = a(1 −qb).
(i) If r = 0, then 1 −qb = 0, so qb = 1. Note that the following are candidate divisions of ab by a:
ab = b · a + 0
(5)
ab = 0 · a + ab
(6)
Note that (5) is always valid (since it has remainder 0), and (6) is valid if and only if f(ab) < f(a). If so,
these candidates must be equal, and so b = 0, a contradiction. Thus (6) is invalid, so f(ab) ≥f(a), and so
f(ab) = f(a).
(ii) If r ̸= 0, then f(r) < f(ab). Note that the following are candidate divisions of r by a:
r = (1 −qb) · a + 0
(7)
r = 0 · a + r
(8)
Note that (7) is always valid (since it has remainder 0), and (8) is valid if and only if f(r) < f(a). If so,
these candidates must be equal, and so r = 0, a contradiction. Thus (8) is invalid, so f(r) ≥f(a), and so
f(a) ≤f(r) < f(ab) ≤f(a), a contradiction.
Thus f(a) ≤f(ab).
■
This result immediately yields a necessary and sufficient condition for a function to be uniquely Euclidean.
Corollary 4.2. f is uniquely Euclidean if and only if f is strongly Euclidean and ultra-Euclidean.
This follows by combining Proposition 3.2 and Theorem 4.1.
Theorem 4.3. If f is uniquely Euclidean on R, so is ef.
Proof. By Theorem 4.1, f is strongly Euclidean, so by Corollary 2.7, ef = f, and so ef is uniquely Euclidean.
■
We are now ready to state and prove our improvement of Jodeit and Rhai’s result (Theorem 3.1). We use some
ideas from their original proofs [2] and [5], reformulated in our terminology. The crucial enhancement is that due to
Theorem 4.1, we can drop the assumption that f is strongly Euclidean.
Theorem 4.4. Suppose f is uniquely Euclidean on R. Then either R is a field or R ∼= K[x] for some field K.
Proof. By Theorem 4.1, f is strongly Euclidean, so by Lemma 2.4, f(1) is the minimum value of f and is attained
precisely by the units.

Define K = R× ∪{0}. We first show that K is a field. Clearly K is closed under multiplication, and K\{0} = R×,
so every nonzero element of K is invertible. Suppose u, v ∈K. If u = 0, v = 0 or u + v = 0, then clearly u + v ∈K.
Suppose u, v, u+v ̸= 0. Then u, v ∈R×, so f attains its minimum at u and v. By Corollary 4.2, f is ultra-Euclidean,
so f(u + v) ≤max{f(u), f(v)}. Thus f also attains its minimum at u + v, and so u + v ∈R× ⊆K. Thus K is also
closed under addition, and so it is a field.
If K = R, then R is a field and we are done. Suppose K ̸= R. Then there exists x ∈R such that f(x) = miny∈R\K f(y).
Suppose a ∈R. We will show that a can be expressed uniquely as a polynomial in x with coefficients in K. By
assumption, there exist unique q, r ∈R such that a = qx + r and (r = 0 or f(r) < f(x)). In other words, r = 0 or
r ∈R×, and so r ∈K. We first show that f(qx) ≤f(a).
• If r = 0, then a = qx, and so f(qx) = f(a).
• If r ̸= 0, then a ̸= 0 (otherwise a = qx + r = 0 · x + 0 would be two valid candidate divisions of a by x). By
Corollary 4.2, f is ultra-Euclidean, so f(qx) = f(a −r) ≤max{f(a), f(−r)}. Since f is strongly Euclidean, we
have f(−r) = f(r) < f(x) ≤f(qx), so max{f(a), f(−r)} = f(a), and so f(qx) ≤f(a).
Since x is not a unit, by Lemma 2.3, we have f(q) < f(qx), and so f(q) < f(a).
If f(q) < f(x), then q ∈K, so a = qx + r is a polynomial in x with coefficients in K. If f(q) ≥f(x), we can
repeat this process with q in place of a. This yields unique q1, r1 ∈R such that q = q1x + r1 and r1 ∈K, as well
as f(q1) < f(q). Repeating this process further, we get a sequence f(a) > f(q0) > f(q1) > · · · . This is a strictly
decreasing sequence in Z+
0 , so it must terminate, say at qn−1. This yields a = qn−1xn + rn−1xn−1 + · · · + r1x + r0,
where r0, r1, . . . , rn−1 ∈K (and since f(qn−1) < f(x), we also have qn−1 ∈K). Thus every a ∈R can be expressed
uniquely as a polynomial in x with coefficients in K, and so R ∼= K[x].
■
Since a Euclidean function on a field is strongly Euclidean if and only if it is constant, this immediately character-
izes all strongly Euclidean (and a fortiori all uniquely Euclidean) functions on a field: They are the constant functions
f : K\{0} →Z+
0 .
As for K[x], the situation is just as nice. [5, Theorem 2.2] states that every uniquely Euclidean function f on K[x] is
of the form ϕ ◦deg, where ϕ : Z+
0 →Z+
0 is strictly increasing1.
Combining these results with Theorem 4.4, we obtain a full characterization of all uniquely Euclidean functions:
Corollary 4.5. Suppose f is uniquely Euclidean on R. Then exactly one of the following holds:
1. R is a field and f is constant.
2. R ∼= K[x], where K = R× ∪{0} is a field, and there is a strictly increasing function ϕ : Z+
0 →Z+
0 such that
f = ϕ ◦deg.
A consequence of Corollary 4.5 is that every uniquely Euclidean function f on K[x] must be constant among polyno-
mials of the same degree. If we only assume f is ultra-Euclidean, the result fails, as the following example shows:
Example. Suppose R = F4[x], where F4 is the field with four elements. Define f : F4[x] →Z+
0 by f(1) = 0 and
f(p) = deg(p) + 1 for p ̸≡1. Then f is ultra-Euclidean on F4[x], but f is not constant among polynomials of degree
0 (since its value is 0 at 1 and 1 at other nonzero constants).

Further investigation
At this point, a natural question to ask is the following:
Conjecture. If f is ultra-Euclidean on R, so is ef.
We were not able to prove or disprove this conjecture. If true, this would allow us to further strengthen Theorem 4.4:
Corollary. If R has an ultra-Euclidean function, then either R is a field or R ∼= K[x] for some field K.
Any counterexample to the conjecture must be a Euclidean domain R with a function f : R\{0} →Z+
0 such that f
is ultra-Euclidean but not strongly Euclidean, while ef is strongly Euclidean but not ultra-Euclidean.
