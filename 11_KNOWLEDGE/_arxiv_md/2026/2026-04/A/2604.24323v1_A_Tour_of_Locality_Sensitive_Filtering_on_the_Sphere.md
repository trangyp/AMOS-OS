Abstract
The Approximate Near Neighbor (ANN) problem is a cornerstone in high-dimensional data
analysis, with applications ranging from information retrieval to data mining. Among the most
successful paradigms for solving ANN in high-dimensional metric spaces is Locality Sensitive Hashing
(LSH), alongside the more recent Locality Sensitive Filtering (LSF). Since the seminal work of Indyk
and Motwani, literature has expanded into a complex landscape of variants, often presented under
different perspectives and adopting different notation.
In this work, we address the technical challenge of navigating this landscape, by providing
a self-contained, unified view of the essential algorithmic ingredients governing LSH-based and
LSF-based solutions for angular distance – a case of particular relevance in modern applications. In
doing so, we touch on deep connections between LSF and LSH strategies.
Our contribution is twofold. First, we design and analyze an LSF-based data structure for the
Angular ANN problem, serving as a “guided tour” through fundamental techniques and results in
the area. Second, we provide a streamlined analysis that, piecing together technical ingredients and
results appeared throughout previous literature, proves optimality of the proposed data structure.
In doing so, we revisit and strengthen a key technical lemma central to this body of work. The
result is a critical and cohesive review that identifies core mechanisms of proximity search, offering
both a streamlined entry point for researchers and a refined perspective on the state of the art.

Introduction
In the Nearest Neighbour problem, we are given a dataset X of points from a metric space
(M, dist). The goal is to preprocess X so as to efficiently answer queries of the form: given a
point q ∈M, retrieve a point x ∈X that is among the closest to q. Despite its seeming
simplicity, Nearest Neighbour entails a fundamental primitive in a wide range of modern
applications – including machine learning, data mining, information retrieval, and computer
vision – in which data are naturally represented as vectors in a feature space. In this setting
(often referred to as the vector space model), similarity between objects is typically captured
by a distance function, and identifying the most similar object reduces precisely to solving a

This problem poses significant computational challenges when data volume grows to a
scale. In this case, naive solutions with linear query-time and/or quadratic space are no
longer feasible. Moreover, known sublinear solutions exhibit an exponential dependence
on the dimensionality of the data in the query time and/or space [6, 7, 15, 19, 24], the
well-known curse of dimensionality.
These limitations motivate the study of approximate variants of the problem. In a seminal
work, Indyk and Motwani [21] introduced Locality-Sensitive Hashing (LSH), a randomized
framework that allows to approximate the Nearest Neighbour1 with polynomial preprocessing
time, sublinear query time, and subquadratic space. This approach leverages a reduction to
the (r, cr)-Approximate Near Neighbor (or (r, cr)-ANN) problem in which, given a query q,
we must return a point x′ ∈X at distance at most cr with constant probability, whenever
a point x at distance at most r from q exists in X. The idea behind LSH is to use hash
functions that are sensitive with respect to the metric, i.e., such that points that are close
are more likely to share the same hash value. More formally, we say that a family H of hash
function is (r, cr, p1, p2)-sensitive for a metric space (M, dist) if, for a randomly chosen of
h ∈H, and for every x, y ∈M, we have P (h(x) = h(y)) ≥p1 if x, y are at distance at most
r (we say that x and y are close points), and P (h(x) = h(y)) ≤p2 if x, y are at distance at
least cr (we say that x and y are far points).
Indyk and Motwani [22] proved that a (r, cr, p1, p2)-sensitive hash family H for (M, dist)
affords a data structure that solves (r, cr)-ANN with constant error probability for a query
point q, in time O(nρ) and using O(n1+ρ) space, where ρ =

The LSH framework is not the only approach to the (r, cr)-ANN problem. A related,
yet different approach is the more recent Locality Sensitive Filter (LSF), introduced in [11].
One of the main advantages of LSF is that it potentially offers a more flexible and agile
way to tune the behavior of the data structure and the underlying space-time trade-offs
[18]. Informally, a filter h is a boolean function, and we say that a data point x passes
the filter if h(x) = 1. In the spirit of LSH, in LSF one designs a family of filters F that is
sensitive with respect to a desired distance, so that points that are close enough are more
likely to pass the same filters than points that are farther apart. More formally, a family
of filters F is (r, cr, q1, q2)-sensitive for a metric space (M, dist) if, for a randomly chosen
filter h ∈F, and for every x, y ∈M, we have P (h(x) = 1 | h(y) = 1) ≥q1 if x and y are
“close”, and P (h(x) = 1 | h(y) = 1) ≤q2 if x and y are “far apart”. LSH and LSF seemingly

In this work, we consider the ANN problem when M is the unit d-dimensional sphere

distance on the sphere and thus cosine similarity, commonly adopted in applications including
image search [23], speaker representations [29] and tf-idf datasets [30]. Moreover, all results
for Angular ANN seamlessly extend to the entire Euclidean space [9, 18, 28].
1.1
Our Contribution
In this paper, we revisit key approaches and technical results in locality-sensitive filtering
and hashing for near neighbor search for angular distance. Through the design and analysis
of an LSF-based data structure for the Angular ANN problem, we offer a guided tour of
fundamental ingredients that have been developed in the past decade. While our analysis
proceeds along the lines of prior research, it is far from a synthesis of previous contributions,
providing a streamlined and unified presentation of key ingredients and results. In more
detail:
We present a LSF-based data structure for angular ANN that is particularly simple (e.g. it
is simpler than the other LSF-based solutions in [11, 18]), essentially representing the most
direct instantiation of the framework proposed in [11] (up to the choice of filters). This
simplified data structure allows to achieve expected query complexity O(nρ), expected
space O(n1+ρ), and a proof of the asymptotic optimality of the obtained parameter ρ.
(For example, in [11] the optimality of ρ is only claimed while the reader is referred to a
similar analysis contained in other papers for a formal proof.)
A key technical problem underlying virtually all contributions in this area is the following:
given two points x and y at a fixed angle, bound the probability that their inner
products with a common random Gaussian vector θ ∼N(0, I) both exceed a specific
threshold. While a cornerstone for both angular LSF and LSH, previous solutions to this
problem have been mathematically involved, asymptotic in nature, or incomplete. For
instance, the analysis of [18] does not cover all angle ranges and relies on coarse geometric
approximations (e.g., bounding the probability of a multivariate normal vector belonging
to a closed convex body) that are only tight up to polynomial factors. Similarly, Becker et
al. [11] circumvent the exact probabilistic analysis by relying on bounds for the volume of
the intersection of spherical caps, which requires additional non-trivial steps to relate back
to Gaussian projectors. In contrast, Lemma 6 offers a fully self-contained, elementary
analysis of this problem using only basic calculus. Our bounds are rigorous, hold for all
possible angle ranges, and are slightly tighter than those in previous literature. This direct
approach completely does away with heavy asymptotic notation and complex geometric
machinery used in previous work. In turn, this simplification directly translates into a
much more streamlined and transparent proof of the asymptotic optimality of Spherical
LSF (Section 4.2). Finally, we complete the standard research pipeline in Section 4.3 by

1.2
Further Related Work
The prominent work of Indyk and Motwani [22] deals with Hamming distance as well as ℓ1
norm and Euclidean distance (ℓ2 norm). A later work by Charikar [17] characterizes the class
of metrics that admit LSH and posed a particular focus on the angular distance introducing
the well-known SimHash (or Hyperplane hash).
Notably works on the Euclidean distance and angular distance are the following. Datar et
al. [20] is the first work that provides a natural hash family for Euclidean distance without
embedding it into the Hamming space which achieves ρ ≈1/c. Motwani et al. [25] show
the first lower bounds to the LSH data structure under the ℓ1 norm. Later, Andoni and
Indyk [1] introduce a scheme for the Euclidean distance achieving ρ ≈1/c2, significantly
improving upon the previous 1/c bound. This result has been later shown to be optimal for
data-independent LSH in the Euclidean setting [16, 26].
Indeed, from the lower bound point of view we have the work of O’Donnell et al. [26]
that gives a lower bound for the Hamming distance in which ρ ≥1/c −od(1). By applying
their results to the unit sphere or Euclidean space, they derive a lower bound for ρ of 1/c2
in that setting.
Of particular interest is the work of Terasawa and Tanaka [31] whose LSH scheme named
cross-polytope is analyzed in [3] and shown to be optimal. The cross-polytope LSH has
some resemblance to the LSF scheme studied in this paper. Indeed, the main core of the
cross-polytope hash function resides in the computation of dot-products between the points
in the dataset and random Gaussian N (0, I/d) points. The analysis provided here may also
be applied to that particular case. The cross-polytope scheme of [3] has been turned into
practical implementations [9, 27]. Finally, to overcome the limitations imposed by the lower
bound for ρ, data-dependent approaches are introduced and analyzed in [4, 5], achieving a
superior exponent of ρ = 1/(2c2 −1).
The concept of LSF was formally introduced by Becker et al. [11] in the context of the
Shortest Vector Problem (SVP). This framework was further generalized by Christiani [18],
who provides a rigorous treatment of space-time tradeoffs for LSF. Locality-sensitive-based
solutions have recently found applications beyond traditional ANN search, particularly in the
domain of algorithmic fairness [10] and differential privacy [8]. A more detailed comparison
between Becker [11], Christiani [18] and this paper is given in Section 4.

4.2
Optimality of Spherical Filtering
In this section, we prove that the discriminating power of the spherical filters proposed in
Section 3.1 is asymptotically optimal, as measured by the parameter ρ from Definition 4.
A digression on parameter ρ.
Before delving into the technical details, we provide some
context that might hopefully benefit the reader, briefly discussing the reasons behind
Definition 4 and the relationships with the analogous parameter ρ defined for LSH. LSF was
introduced in [11], where they also defined ρ as we do in this paper. The reason for their
definition of ρ stems from their analysis [11, Section 3, Thm. 3.1] of the time and memory
costs of the data structure they propose (essentially, the same we introduced in Section 3.1
up to the choice of the filters). The authors of [11] discuss the asymptotic behavior of the
ρ computed for the filters they propose, comparing it with the ρ computed for the LSH
schemes proposed in [5, 3], though the two are clearly defined differently. There is a practical
justification for drawing this comparison though, since [11] also makes a connection (similar
to the one for LSH) between the ρ from Definition 4 and the performance of their LSF-based
data structure. Indeed, the connection between the ρ from LSF as defined in Definition 4
(and [11]) and the analogous parameter for LSH runs deeper. In particular, Christiani proved
[18, Section 5, Lemma 5.1 and Thm. 1.4] that every LSF scheme for the ℓs distance with
given value ρ according to Definition 4 yields an LSH scheme with the same value of the
corresponding parameter ρ, up to lower order terms. This in particular implies that every
LSF scheme for ℓs must satisfy the general lower bound given in [26, Thm. 3.1 and Cor. 3.2],
which is 1/c2 −od(1) for the Euclidean distance.

▶Remark 10. We briefly discuss an aspect that we consciously overlooked in Theorem 9,
in order to keep the proof compact and since considering this aspect would lead us astray
with respect to the scope of this paper. In expectation, any near point and the query point
share ln 1
δ buckets and an overall number of O(nρ) candidates are considered, which implies
that O(nρ) points collide in every bucket in expectation when δ is a constant. Since the
expected size of the data structure is O(n1+ρ), this in turn implies that the number of filters
we are using might be as large as O(n). In principle, this is important, since the query
time should also include the number of filter evaluations that need to be performed. A
similar problem arises (and is discussed) for the number of hash function computations in
the LSH literature (e.g., see [21, Thm. 3.4] or [5, Thm. 2.3], where the authors assume
p1, p2 ≥1/noc(1)) and it can be addressed in a number of ways in LSF. These include random
product codes that modify the distribution from which filters are sampled [11], or powering
and tensoring techniques that amplify the locality sensitive properties of the filters [18].
While these theoretical constructions allow to improve the number of filter evaluations (e.g.,
bringing it down to O(nρ) in expectation), computing the signature of a query vector is
rarely a bottleneck in practice (e.g., [27]). One of the reasons is that multiple inner products
between independent standard normal vectors and a query vector can be effectively and
very efficiently simulated using pseudo-random rotations, e.g., based on the Fast Hadamard
Transform [3, 27]. We refer the interested reader to these references for more details.
