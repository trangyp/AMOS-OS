A note on the horizontal class transposition group
Junyao Pan
School of Cyber Science and Engineering, Wuxi University, Wuxi, Jiangsu, 214105, P. R. China
Abstract: Let n be an integer with n > 1. For every r satisfying the inequalities 0 ≤r < n, the
residue class modulo n is defined as r(n) = {r + kn|k ∈Z}, where Z is the set of all integers.
Then for 0 ≤r1 ̸= r2 < n, the horizontal class transposition τr1(n),r2(n) is an involution that
interchanges r1 + kn and r2 + kn for each integer k and fixes everything else. The horizontal class
transposition group CTn is generated by all horizontal class transposition τr1(n),r2(n). Let N be the
least common multiple of the numbers 2, 3, ..., n and CT(n) = ⟨CT2, CT3, ..., CTn⟩. In this note, we
prove that for n > 3, CT(n) ∼= SN, where SN is the symmetric group of degree N. Thus, we solve
a conjecture proposed by Bardakov and Iskra, which has been included in the kourovka notebook:
Unsolved problems in group theory, Novosibirsk, 2026.
Keywords: Residue class; Horizontal class transposition; Symmetric group.
Mathematics Subject Classification (2020): 20B30, 20B35

Introduction
Throughout this paper, Z denotes the set of all integers; Sn stands for the symmetric group of
degree n; n | m and n ∤m means that n divides and does not divide m, respectively; a ≡b(mod n)
and a ̸≡b(mod n) imply that a is congruent and not congruent to b modulo n, respectively.
Let m be a natural number with m > 1. For every r satisfying the inequalities 0 ≤r < m, the
residue class modulo m is defined as r(m) = r + mZ = {r + km|k ∈Z}. If r1(m1) ∩r2(m2) = ∅,
the class transposition τr1(m1),r2(m2) is the product of independent transpositions, that is,
τr1(m1),r2(m2) =
Y
k∈Z
(r1 + km1, r2 + km2).
If m1 = m2 then τr1(m1),r2(m2) is called horizontal class transposition; otherwise, τr1(m1),r2(m2) is
called slanted class transposition. S. Kohl [4] introduced the class transposition group CT(Z) that
is generated by all class transpositions, and showed that this group has a number of remarkable
properties, such as the CT(Z) is simple, and contains all symmetric group Sn and hence all finite
groups. Additionally, Kohl proposed an open problem that is it true that there exists only a finite
set of natural numbers that occur as the orders of the product of two class transpositions? In fact,
some connections between this problem and the famous Collatz conjecture have been established
in [5], and further this open problem has been included in [6, Problem 18.48]. Recently, Bardakov
and Iskra made breakthrough progress on this problem, see references [1,2].
Given an integer n with n > 1. The horizontal class transposition group CTn is generated by
all horizontal class transpositions τr1(n),r2(n). Let CT(n) = ⟨CT2, CT3, ..., CTn⟩and N be the least
common multiple of the numbers 2, 3, ..., n. For the group CT(n), Bardakov and Iskra [1] proposed
a conjecture that has been included in [6, Problem 21.8], as follows:
Conjecture 1.1 ([5, Problem 21.8]) Is it true that for n > 3 the group CT(n) is isomorphic to the
symmetric group SN.

Next we present some notions and notations about permutation groups, and for more details
can be seen in [3]. Let G be a permutation group acting on a set Ω, and ∆⊆Ω. Then the point
stabilizer of ∆in G is denoted by G(∆) = {g ∈G|αg = α, ∀α ∈∆}. In particular, if ∆= {α} then
G(∆) is abbreviated as Gα. For a point α ∈Ω, if Ω= {αg|g ∈G} then G is said to be transitive on
Ω. If any k-tuple of distinct points can be mapped, by some element of G, to any other k-tuple of
distinct points, then G is said to be k-transitive on Ω. If k > 1, then G is k-transitive if and only
if G is (k −1)-transitive and (k −1)-points stabilizer is transitive on the set of remaining points.
