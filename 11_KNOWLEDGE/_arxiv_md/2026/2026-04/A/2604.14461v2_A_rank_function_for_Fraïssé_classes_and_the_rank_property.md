A RANK FUNCTION FOR FRAïSSÉ CLASSES AND THE RANK PROPERTY
CARLOS LÓPEZ-CALLEJAS AND JAREB NAVARRO-CASTILLO
Abstract. Given a hereditary class F of finite relational structures, the rank function rk : σF →
ω1 ∪{∞}, introduced by Kubiś and Shelah, measures how far a countable structure is from being
universal within its class: rk(X) = ∞if and only if the Fraïssé limit embeds into X. We say that
F has the Rank Property (RP) if every countable ordinal is realized as the rank of some X ∈σF.
We develop the basic theory of the rank function and establish RP for three families of classes:
those satisfying the free amalgamation property and the full extension property (covering graphs,
hypergraphs, and many others); finite tournaments; and finite linear orders. For the latter, we
compute the rank of every countable ordinal: if ωβ1 · c1 is the leading Cantor normal form term
of α ≥ω, then rk(α) = ω · β1 + ⌊log2 c1⌋.
1. Introduction
A classical problem in Fraïssé theory is to determine which countable structures are universal
for a given hereditary class — that is, which structures embed every finite member of the class (see,
e.g., [2, 11, 7] for general background). A natural refinement of this problem is to measure, in a
graded way, how far a countable structure is from being universal.
The classical framework for this question is Fraïssé theory [2]: given a hereditary class F of
finite relational structures satisfying the joint embedding property and the amalgamation property,
there exists a unique countable Fraïssé limit that is universal and ultrahomogeneous for F. Familiar
examples include the Rado graph, the rational order (Q, <), the generic tournament, and the generic
partial order [11].
The Fraïssé limit is the most universal object in σF,1 but what about the structures that
fall short of full universality? How can one measure, in a precise and graded way, the degree of
universality of a countable structure?
The rank function rk : σF →ω1∪{∞} (Definition 2.3) provides a natural answer to this question.
Defined recursively, the rank satisfies rkX(F) ≥α + 1 if every prime extension of F can be realized
in X with rank at least α. Ordinals thus serve as a natural scale of partial universality: rk(X) = 0
means there are single-element structures in F that are not substructures of X, rk(X) = ∞
means every extension succeeds at every level (equivalently, the Fraïssé limit embeds into X; see
Proposition 3.6), and the countable ordinal values in between form a fine hierarchy. The rank
admits a game-theoretic interpretation (Proposition 2.6): two players alternately choose one-point
extensions and realizations in X, and the rank is infinite if and only if Player II can keep the game
going forever.
The central question driving this paper is:
For which hereditary classes F does the rank function achieve every countable
ordinal value?
We say that F has the Rank Property (RP) if for every α < ω1 there exists X ∈σF with rk(X) = α.
The Rank Property can be understood as a fine-structure analysis of the Fraïssé limit and its class:
it asserts that the hierarchy of partial universality is as rich as possible, with no ordinal levels
missing.
Since rk(X) ≥ω forces F to be a Fraïssé class (Theorem 3.3) and is equivalent to age(X) = F
(Proposition 3.5), the Rank Property forces F to be Fraïssé (Corollary 3.4). The converse does not

We establish the Rank Property in three settings, each requiring different techniques.
Free amalgamation classes. If F satisfies the free amalgamation property (FAP) and the
full extension property (FEP), we prove RP (Theorem 4.18). The proof constructs finite “universal”
structures Hn with rk(Hn) = n, then builds countable structures of any prescribed rank γ + n by
amalgamating copies of previously constructed structures over Hn as a kernel. The free amalgamation
property ensures that the leaves of the kernel construction are pairwise disconnected, which is
essential for the upper bound on the rank. This covers the classes of finite graphs, finite hypergraphs,
finite directed graphs, edge-colored structures, and, more generally, any class of finite structures in a
finite relational language with no axioms beyond irreflexivity of non-unary relations2 (Corollary 4.19).
In the language of Conant [1], these are the free amalgamation theories, whose model-theoretic
properties (NSOP4, rosiness, 1-basedness when simple) have been extensively studied.
Tournaments. The class of finite tournaments has strong amalgamation but not FAP: every
pair of vertices must receive a directed edge. Its Fraïssé limit is the generic countable tournament,
classified by Lachlan [10]. We prove RP for tournaments (Corollary 5.17) by combining a Cross-
Piece Bound on kernel amalgamations (Lemma 5.10) with a rigidity property of the structures Hn
(Lemma 5.14), which forces realizations of certain types to lie inside Hn. These ingredients replace
the disconnection between components in the FAP setting; the rest of the construction is formally
parallel to the kernel amalgamation for graphs.
Linear orders. The class of finite linear orders is a Fraïssé class (with (Q, <) as its Fraïssé
limit) but does not satisfy FAP: every amalgam must totally order the elements, so there is no
“free” choice. We introduce the Interval Characterization (Proposition 6.5): the rank of a finite
substructure F in a linear order Y equals the minimum rank of the intervals determined by F in Y .
This reduces rank computations to a one-dimensional problem and replaces the kernel machinery
entirely. The key upper-bound tool is a Pigeonhole Lemma for intervals (Lemma 6.9), which bounds
the rank in terms of the number of convex pieces with the “correct” tail behavior.
For finite linear orders, the rank is completely determined by cardinality: rk(Y ) = ⌊log2(|Y |+1)⌋
(Theorem 6.4). For infinite ordinals, we compute the rank of every countable ordinal (Theorem 6.12):
if α ≥ω has Cantor normal form with leading term ωβ1 · c1, then rk(α) = ω · β1 + ⌊log2 c1⌋. In
particular, the rank depends only on the leading term and refines the classical Hausdorff rank [4]:
rk(α) = ω · VD(α) + ⌊log2 c1⌋(Remark 6.15). We extend this to linear orders of the form Z · α
(Theorem 6.19). The Rank Property for finite linear orders (Corollary 6.13) then follows directly
from these computations.
The rank function was introduced by Kubiś and Shelah in [9], within the framework of evolution
systems [8] — a category-theoretic generalization of Fraïssé theory where “transitions” (one-point
extensions) replace the classical age/amalgamation setup. In that setting, the rank measures the
universality of objects in a locally countable evolution system. The present paper originated when
the authors visited Prague and learned of the rank function from Kubiś. We develop the theory
from scratch in a purely combinatorial setting, without requiring the categorical machinery. The
forthcoming paper by Kubiś and Shelah [9] develops the rank in the full generality of evolution
systems.
The Rank Property is related to, but distinct from, several other rank notions. The K-rank of
Guingona and Parnes [3] is a rank on partial types parametrized by a strong amalgamation Fraïssé
class; for linear orders, it coincides with dp-rank. The Hausdorff rank [4] on scattered linear orders
measures depth in the condensation hierarchy, and our Theorem 6.12 shows precisely how the rank
function refines it.

2. The rank function and its basic properties
Fix L, a countable relational language without constants, and F, a hereditary class of finite
L-structures closed under isomorphisms. In this section every structure will be an L structure. By
σF, we denote the class of all countable structures isomorphic to unions of ⊆-chains in F. Usually,
A, B, C, etc., denote structures in F, while X, Y, Z, etc., denote structures in σF. By age(X) we
denote the set of all finite substructures of X.
We write A ≃B to indicate that A and B are isomorphic, A ≤B to indicate that A is a
substructure of B (for all a ∈[A]<ω and every R ∈L, a ∈R(A) if and only if a ∈R(B); in the class
of finite graphs, subgraph means induced subgraph), A < B for proper substructure, and A ,→B for
embeddability.
Recall that F is a Fraïssé class if the following hold:
(1) Joint Embedding Property (JEP): if A, B ∈F, then there exists C ∈F such that A, B ,→C;
(2) Amalgamation Property (AP): if A, B, C ∈F with A ,→B and A ,→C, then there exists
D ∈F such that B, C ,→D and the respective diagram commutes.
In this case, there exists a unique (up to isomorphism) countable X ∈σF that is both universal
(age(X) = F) and ultrahomogeneous (every isomorphism between finite substructures extends to
an automorphism). This X is the Fraïssé limit of F [2, 5].
Definition 2.1. Let A, B, and C be structures. We say that B and C are isomorphic over A if
A ≤B, C, and there is an isomorphism from B to C that is the identity on A.
Definition 2.2. Let A, B, C, and X be structures such that A ≤B and A ≤X. Then:
• We say that B is a prime extension of A if |B \ A| = 1.
• If C ≤X, then we say that C is a realization of B in X if B and C are isomorphic over A.
Definition 2.3. Let X ∈σF, F ∈age(X) and α an ordinal.
• rkX(F) ≥0 always.
• rkX(F) ≥α + 1 if every prime extension of F in F has a realization C in X such that
rkX(C) ≥α.
• For α a limit ordinal, rkX(F) ≥α if rkX(F) ≥β for every β < α.
• rkX(F) = sup {α | rkX(F) ≥α}, with the convention that rkX(F) = ∞if rkX(F) ≥α for
every ordinal α.3
• rk(X) := rkX(∅).
A routine transfinite induction shows that if rkX(F) ≥α and β ≤α, then rkX(F) ≥β.
Remark 2.4. For F ∈age(X), we have rkX(F) = 0 if and only if there is some prime extension G
of F that cannot be realized in X.
Note that Remark 2.4 applied to the class of graphs shows that for a graph X and a vertex
v ∈X, we have rkX({v}) = 0 if and only if v is an isolated vertex or v ∼x for all x ∈X \ {v}. This
is because in both scenarios, there exists a prime extension of {v} that cannot be realized in X: in
the first case, the prime extension is K2, and in the second, it is the complement of K2.
Definition 2.5. Let X ∈σF and F ∈age(X). The rank game on X starting from F is played
by two players, I and II, over ω rounds. At round n (with current position Fn ∈age(X), where
F0 = F):
(1) I chooses a prime extension B of Fn in F.
(2) II responds with a realization C of B in X, and sets Fn+1 = C.
II loses at round n if no realization exists; II wins if the game lasts all ω rounds.

Proposition 2.6. Let X ∈σF and F ∈age(X). Then rkX(F) = ∞if and only if II has a winning
strategy in the rank game on X starting from F.
Proof. (⇒): If rkX(F) = ∞, then every prime extension of F has a realization C in X with
rkX(C) = ∞. This gives II a strategy: at each round, respond with a realization of infinite rank.
Since infinite rank is preserved at every step, the game never terminates.
(⇐): Suppose rkX(F) = α < ∞. Since rkX(F) ̸≥α + 1, some prime extension B of F has all
realizations in X of rank less than α. I plays B, forcing rkX(F1) < α. Iterating, I produces a strictly
decreasing sequence of ordinals, which must terminate.
□
The rank game can be viewed as an asymmetric variant of the abstract Banach–Mazur game
studied by Krawczyk and Kubiś [6] in the context of evolution systems [8, 7]. In that game, both
players alternately choose concrete finite substructures from age(X) to form an increasing chain.
In contrast, the rank game is fundamentally asymmetric: Player I proposes abstract prime
extensions from the class F, while Player II must find concrete realizations of those extensions
inside the fixed structure X. The rank measures how many rounds II can survive this challenge.
It might seem that if F, G ∈age(X) are isomorphic, then we would have rkX(F) = rkX(G).
However, this is clearly false; for example, if X is a graph and v, w ∈X where v is isolated and w is
not isolated nor connected to every other vertex, then rkX({v}) = 0 < rkX({w}), while {v} ≃{w}.
On the other hand, if h : X →X is an automorphism of X such that h[F] = G, then
rkX(F) = rkX(G). This follows by a straightforward transfinite induction: h maps prime extensions
of F to prime extensions of G and realizations in X to realizations in X, preserving the rank at
each level.
Proposition 2.7. Assume F has the amalgamation property. Let X ∈σF and α an ordinal. If
F, G ∈age(X) are such that G is a prime extension of F and rkX(G) ≥α, then rkX(F) ≥α. In
particular, rkX(F) ≥rkX(G).
Proof. By induction on α. The case α = 0 is straightforward, as everything has rank at least 0.
Successor case: Assume the result holds for α and let us prove it for α + 1. Let F, G ∈age(X)
with G = F ∪{w} a prime extension of F and rkX(G) ≥α + 1. Let B = F ∪{y} ∈F be any prime
extension of F; we seek a realization C ∈age(X) of B with rkX(C) ≥α. By AP applied to G and
B over F, there exists H ∈F with G ≤H and an embedding ι : B →H that is the identity on F;
set y′ := ι(y) ∈H \ F (since ι is injective and the identity on F).
Subcase 1: y′ ∈G. Then y′ = w and ι(B) = G, so G itself is a realization of B in X with
rkX(G) ≥α + 1 ≥α.
Subcase 2: y′ ∈H \ G. Then H = G ∪{y′} is a prime extension of G in F, so since rkX(G) ≥α + 1
there is a realization D ∈age(X) of H with rkX(D) ≥α and an isomorphism f : H →D with
f ↾G = idG. Setting z := f(y′), the composition f ◦ι : B →D is an embedding which is the
identity on F and has image F ∪{z}, so C := F ∪{z} is a realization of B in X. Since D = C ∪{w}
is a prime extension of C in age(X) with rkX(D) ≥α, the inductive hypothesis gives rkX(C) ≥α.
Limit case: Suppose that β is a limit ordinal, and the result holds for all α < β. Let F, G ∈
age(X) be such that G is a prime extension of F and rkX(G) ≥β. In particular, rkX(G) ≥α for
every α < β. By the inductive hypothesis, rkX(F) ≥α for all α < β, which implies rkX(F) ≥β.
□
Corollary 2.8. Assume F has AP. If F, G ∈age(X) are such that F ≤G, then rkX(F) ≥rkX(G).
Proof. We can construct a chain (Fi)i∈n of structures in age(X) such that Fi+1 is a prime extension
of Fi for all i < n −1, with F0 = F and Fn−1 = G. Therefore, by Proposition 2.7, we obtain:
rkX(F) = rkX(F0) ≥rkX(F1) ≥· · · ≥rkX(Fn−1) = rkX(G).
□

B0, the two facts combine: there exists a realization E with β < rkX(E) < α. Apply the induction
hypothesis to E and rkX(E) to obtain a structure of rank exactly β.
□
3. Rank and the amalgamation property
We now explore the relationship between the rank function and the amalgamation property.
The results in this section hold for an arbitrary hereditary class F of finite relational L-structures
closed under isomorphisms and substructures. The main results are: the rank controls embeddability
of finite structures, rk(X) ≥ω characterizes Fraïssé classes and full ages, rk(X) = ∞characterizes
embeddability of the Fraïssé limit, and the Rank Property implies that F is Fraïssé. The converse
does not hold: being Fraïssé does not suffice for RP, as the example of finite sets shows.
Proposition 3.1. Let X ∈σF with rk(X) ≥n. Then every A ∈F with |A| ≤n can be embedded
into X.
Proof. Let {vi | i ∈m} be an enumeration of the elements of A (so m ≤n). We construct a sequence
(xi)i∈m of elements from X such that for all j ≤m: (1) the function vi 7→xi is an embedding of
{vi | i ∈j} into {xi | i ∈j}, and (2) rkX({xi | i ∈j}) ≥n −j. For j = 0, both conditions hold
since rkX(∅) ≥n. Given (xi)i∈j with j ≤m −1, the structure {vi | i ∈j + 1} ≤A ∈F is a prime
extension of {vi | i ∈j}, so the corresponding prime extension of {xi | i ∈j} (with the same type
as vj over {v0, . . . , vj−1}) is in F. Since rkX({xi | i ∈j}) ≥n −j ≥1, this prime extension has a
realization in X with rank ≥n −(j + 1), providing the desired xj.
□
The converse of Proposition 3.1 does not hold in general. In the class of finite graphs, the
converse holds for n ≤2 but fails for n = 3: the graph on 5 vertices {1, 2, 3, 4, 5} with edges 1-2, 1-3,
2-3, 1-4 contains all graphs on 3 vertices as induced subgraphs, yet has rank 2. Moreover, 5 vertices
is optimal: in any graph on 4 vertices containing K3, three vertices form a triangle, and then every
triple includes at least two of them, so K3 cannot be embedded. In the class of finite tournaments
(see Section 5), the failure already occurs at n = 2: the unique tournament on 2 vertices contains
every tournament of size ≤2, but has rank 1. In the class of finite linear orders, the failure is even

Theorem 3.3. There is X ∈σF such that rk(X) ≥ω if and only if F is a Fraïssé class.
Proof. (⇐): If F is a Fraïssé class, the Fraïssé limit has rank ∞≥ω.
(⇒): Let X ∈σF with rk(X) ≥ω. For AP: given A, B, C ∈F with A ,→B and A ,→C,
apply Lemma 3.2 to ∅and A to obtain A′ ∈age(X) isomorphic to A with rkX(A′) ≥l −|A|,

Corollary 3.4. If F has the Rank Property, then F is a Fraïssé class.
Proof. By RP there exists X ∈σF with rk(X) ≥ω, so F is Fraïssé by Theorem 3.3.
□

Corollary 6.13. The class of finite linear orders has the Rank Property.
Proof. For α < ω, any finite linear order of size 2α −1 has rank α by Theorem 6.4. For α ≥ω,
write α = ω · β + n with β ≥1 and n < ω; then rk(ωβ · 2n) = ω · β + n = α by Theorem 6.11.
□
The class of finite linear orders does not satisfy the free amalgamation property, so the Rank
Property cannot be deduced from Theorem 4.18. The Interval Characterization (Proposition 6.5)
replaces the kernel machinery: it reduces the rank computation to controlling the ranks of intervals,
just as the kernel machinery reduces it to controlling the ranks of disconnected components.
Corollary 6.14. For every linear order Y , rk(Y ∗) = rk(Y ). In particular, rk(ω∗) = ω and
rk((ωβ · m)∗) = ω · β + ⌊log2 m⌋for every β ≥1 and m ≥1.
Proof. Immediate from Proposition 6.8 and Theorem 6.11.

ω + 1.

7. Questions
Question 7.1. Which Fraïssé classes have the Rank Property? In particular, does the class of
finite partial orders have RP? This class satisfies AP (even SAP [12]) and every type is F-good, so
the rank is unbounded; however, the kernel amalgamation technique does not produce a valid partial
order due to the transitivity axiom.
Question 7.2. What is the weakest amalgamation condition on F that, together with a suitable
extension property, implies RP? In particular, can the free amalgamation property in Theorem 4.18
be replaced by the strong amalgamation property?
Question 7.3. What are the model-theoretic consequences of RP for the Fraïssé limit?
Note that the Rank Property is compatible with IP (finite graphs have RP and the random
graph has IP) and with NIP (finite linear orders have RP and (Q, <) is NIP), as well as with
simplicity (the random graph is simple) and non-simplicity ((Q, <) is not simple). In particular,
RP does not imply any of stability, NIP, IP, or simplicity.
Question 7.4. For the class of finite graphs, let N(n) denote the minimum N such that every
graph X ∈σF containing all graphs of cardinality N as induced subgraphs satisfies rk(X) ≥n. We
have N(1) = 1, N(2) = 2, and 4 ≤N(3) ≤|H3|. What is the growth rate of N(n)?
For finite linear orders, the analogous question is trivially resolved: since every linear order of
size m contains all linear orders of size ≤m, Theorem 6.4 gives N(n) = 2n −1. The graph case is
genuinely harder because embeddability of all structures of a given size is a much weaker condition
than having high rank.
