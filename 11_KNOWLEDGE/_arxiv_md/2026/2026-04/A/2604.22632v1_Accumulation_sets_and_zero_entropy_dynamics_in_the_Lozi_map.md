Abstract. For the family of Lozi maps La,b, we consider parameter pairs for which the
fixed point X has no homoclinic points and the period-two orbit {P, P ′} is attracting.
For such parameters, let ℓbe the set of accumulation points of the unstable manifold
W u
X that do not lie on W u
X. We construct a polygon D whose forward images under
La,b form nested sequences of sets that eventually become trapping. We show that this
geometric construction gives a characterization of ℓas the intersection of these iterates.
Using this structure, we prove that the non-wandering set for L2
a,b is contained in the
union of ℓand the set of fixed points of La,b. As a consequence, the Lozi map, restricted
to the complement of ℓin the plane, has zero topological entropy. This result extends a
recent one of Misiurewicz and ˇStimac to a broader set of parameters.
1. Introduction
The Lozi map is a piecewise affine counterpart to the H´enon map: it is a planar
homeomorphism given by
La,b : R2 →R2,
La,b(x, y) = (1 + y −a|x|, bx),
and it depends on two parameters a, b ∈R, b ̸= 0.
Almost half a century after R.
Lozi proposed this map in [10], a complete understanding of its dynamical properties
still requires substantial research. One such aspect is topological entropy htop, a core
dynamical invariant that measures the exponential growth of orbits for a given system.
A general formula for the topological entropy of Lozi maps in terms of the parameters
is not known, but there are some partial results on its discontinuity and jumps (see
[14]), as well as its monotonicity along specific directions in the parameter space (see
[5, 6, 13]). Although the parameter region where htop(La,b) is maximal has been completely
determined in [4], the zero entropy locus of the Lozi family is still not fully understood.
In [13], Yildiz reviewed a result of Ishii and Sands which states that htop(La,b) = 0
when −1 ⩽b < 0 and a ⩽b −1, as well as when 0 < b ⩽1 and a ⩽1 −b. In addition,

map. In addition, if f is invertible, let f −n = f −1 ◦f −1 ◦. . . f −1 (n times). A set Y ⊆X

Finally, we state a classic result for homeomorphisms of the plane as it was formulated
(and proved) in [3]. For a homeomorphism f : R2 →R2, a domain of translation for f
is an open, connected subset of R2 whose boundary is p ∪f(p), where p is a properly
embedded line in R2, and p separates f −1(p) and f(p).
Theorem 2.2 (Brouwer Plane Translation Theorem, BPTT). Let f : R2 →R2 be a fixed-
point-free, orientation-preserving homeomorphism of the plane. Then every point of the
plane is contained in a domain of translation for f.
In this paper, we will use one consequence of BPTT, which is also a known fact.
However, for completeness, we will state and prove it.
Corollary 2.3. If f : R2 →R2 is a fixed-point-free, orientation-preserving homeomor-
phism of the plane, then every point in the plane is a wandering point for f.
Proof. Let x0 ∈R2 be a point in the plane. By BPTT, there is a domain of translation U
for f which contains x0. Since U is an open set, there exists ε > 0 such that the open ball
centered at x0 of radius ε is contained in U, that is, Bε(x0) ⊂U. Then f(Bε(x0)) ⊆f(U)
and since by BPTT we have U ∩f(U) = ∅, it follows that Bε(x0) ∩f(Bε(x0)) = ∅. Now,
by [3, Corollary 1.3] we have that Bε(x0) ∩f n(Bε(x0)) = ∅for all n ∈N.
Therefore, x0 has a neighborhood which is disjoint from all of its forward images, so x0
is a wandering point for f. Since x0 was arbitrary, the claim follows.

Guided by this, one might think that ℓ= {P, P ′} could hold for all parameters (a, b) ∈

other counterexamples exist, such as parameter pairs in a small neighborhood of (a, b) =

moreover, they imply that the accumulation set ℓcan have a nontrivial structure for
parameters in R \ R. Therefore, a complete characterization of the zero entropy locus for
the Lozi map remains unresolved, and determining it precisely continues to be an open
problem that calls for further investigation.
