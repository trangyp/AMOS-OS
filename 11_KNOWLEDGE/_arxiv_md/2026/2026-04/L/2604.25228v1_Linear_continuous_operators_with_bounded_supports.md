VESKO VALOV
Abstract. For any Tychonoff space X let D(X) be either the set C(X)
of all continuous functions on X or the set C∗(X) of all bounded con-
tinuous functions on X. When D(X) is endowed with the point conver-
gence topology, we write Dp(X).
Zakrzewski [14, Theorem 3.12] proved
that if X and Y are σ-compact spaces and there is a continuous linear
map T : Cp(X) →Cp(Y ) such that T(Cp(X)) is dense in Cp(Y ) and
|supp (y)| ≤m for every y ∈Y , then dim Y ≤m·dim X +m+m!−1. Here,
supp (y) denotes the support of the linear continuous map ly : Cp(X) →R,
defined by ly(f) = T(f)(y). In the present paper we improve the last in-
equality by showing that dim Y ≤m · dim X provided X, Y are Tychonoff
spaces and there is a continuous linear surjection T : Dp(X) →Dp(Y ) with
|supp (y)| ≤m for every y ∈Y . This implies the following generalization of
[4, Theorem 1.4]: If T : Dp(X) →Dp(Y ) is a continuous linear surjection
with X, Y Tychonoff spaces and dim X = 0, then dim Y = 0. Our proofs
are obtained by refining the techniques developed in [4].

This question was answered negatively by Leiderman-Levin-Pestov [7] and

dim Y = 0.
The last result was extended for arbitrary compact spaces by
Kawamura-Leiderman [6] who raised the question if their result holds for arbi-
trary Tychonoff spaces X and Y . Recently, this difficult question was answered
positively in [4]. In the present paper we show this is also true for linear con-
tinuous surjections T : Dp(X) →Dp(X), see Corollary 1.3 below.
Everywhere below, by D(X) we denote either C∗(X) or C(X), and Dp(X)
stays for D(X) endowed with the point-wise convergence topology.
If T :
Dp(X) →Dp(Y ) is a continuous linear map, then there are four possible cases:
D(X) is either C(X) or C∗(X) and D(Y ) is either C(Y ) or C∗(Y ). Suppose
Y is a compactification of a space Y and E∗(Y ) is a subalgebra of C∗(Y ), we
say that E∗(Y ) is associated with Y if every f ∈E∗(Y ) can be extended to
a function f ∈C(Y ) and C(Y ) = {f : f ∈E∗(Y )}. Similarly, a subalgebra
E(Y ) of C(Y ) is associated with Y if every f ∈E(Y ) can be extended to a
continuous function f : Y →R = R ∪{±∞} and {f|Y : f ∈C(Y )} ⊂E(Y ).
Zakrzewski [14, Theorem 3.12] proved the following result: If X and Y are
σ-compact spaces and there is a continuous linear map T : Cp(X) →Cp(Y )
such that T(Cp(X)) is dense in Cp(Y ) and |supp (y)| ≤m for every y ∈Y ,
then dim Y ≤m · dim X + m + m! −1. Here, supp (y) denotes the support of
the linear continuous map ly : Cp(X) →R, defined by ly(f) = T(f)(y), see the
precise definition below. In the present paper we improve the last inequality.
Theorem 1.1. Let X and Y be spaces and F(Y ) be a subalgebra of Dp(Y )
associated with a compactification Y of Y . Suppose T : Dp(X) →Fp(Y ) is
a surjective continuous linear map such that |supp (y)| ≤m for every y ∈Y .
Then there exits a σ-compact subset H ⊂Y containing Y such that dim H ≤
m · dim X.
Corollary 1.2. Suppose X, Y are spaces and there is a linear continuous sur-
jection T : Dp(X) →Dp(Y ) such that |supp (y)| ≤m for all y ∈Y . Then
dim Y ≤m · dim X.
Note that in case both X and Y are metrizable, Corollary 1.2 was established
in [9].
Corollary 1.3. If X and Y are spaces and T : Dp(X) →Dp(Y ) is a surjective
continuous linear map such that dim X = 0, then dim Y = 0.

2. Preliminary results
Let Q be the set of rational numbers. A subspace E(X) ⊂D(X) is called
a QS-algebra [5] if it satisfies the following conditions: (i) If f, g ∈E(X) and
λ ∈Q, then all functions f + g, f · g and λf belong to E(X); (ii) For every
x ∈X and its neighborhood U in X there is f ∈E(X) such that f(x) = 1
and f(X\U) = 0.
We need the following facts from [5]:
(2.1) If X has a countable base and Φ ⊂D(X) is a countable set, then there
is a countable QS-algebra E(X) ⊂D(X) containing Φ;
(2.2) If E(X) is a QS-algebra on X and U ⊂X is an open set containing the
points x1, x2, .., xk and λ1, λ2, .., λk ∈Q, then there exists f ∈E(X)
such that f(xi) = λi for each i and f(X\U) = 0.
(2.3) We consider the following condition for a QS-algebra E(X) on X: For
every compact set K ⊂X and an open set W containing K there
exists f ∈E(X) with f|K = 1, f|(X\W) = 0 and f(x) ∈[0, 1] for
all x ∈X. Note that if X has a countable base B, then there is a
countable QS-algebra E(X) on X satisfying that condition. Indeed,
we can assume that B is closed under finite unions and find U, V ∈B
such that K ⊂V ⊂cl(V ) ⊂U ⊂cl(U) ⊂W. Then consider the set Φ
of all functions fU,V : X →[0, 1], where cl(V ) ⊂U with U, V ∈B, such
that fV,U|cl(V ) = 1 and fV,U|(X\U) = 0. According to (2.1), Φ can be
extended to a countable QS-algebra E(X) on X.
