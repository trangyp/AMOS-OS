Abstract. Right-reversing is an algorithm used to compute least common
multiples in monoids that admit a right-complemented presentation. The
algorithm can either terminate and find a result, fail, or run indefinitely.
The correctness of the algorithm can be proved with additional assumptions
coming from Garside theory. In the same framework, we prove that a non-
terminating run of the algorithm is necessarily cyclic. Stopping when a cycle
is detected provides a way of computing a minimal Garside family.

1. Introduction
1.1. Context
A right-complemented presentation of a monoid is a presentation ⟨S|R⟩+ where the
relations in R have the form sθ(s, t) = tθ(t, s), where θ is a partial map from S × S
to the free monoid S∗. Introduced in [4], the main example for which this notion
was defined was to study braid groups and monoids, and more generally Artin-Tits
groups and monoids. We recall the definition of Artin-Tits monoids:
Definition 1.1. A Coxeter matrix M associated with a finite set of generators
S is a symmetric square matrix whose entries, ma,b for all a, b ∈S, are integers
satisfying ma,b ≥2 or ma,b = ∞for all a ̸= b ∈S and ma,a = 1 for a ∈S. We
often represent a Coxeter matrix M with its associated Coxeter graph Γ = ΓM, an
undirected graph whose vertices are the elements of S and two generators a, b are
linked by an edge if ma,b ≥3 and the edge is labelled by ma,b if ma,b ≥4.
With a Coxeter matrix M, we will associate a set of relations that will define
the Artin-Tits monoid of type M.

matrix M (and a Coxeter graph Γ) is the monoid with the presentation ⟨S|R⟩+,

A right-complemented presentation allows one to define a process called right-
reversing [3]: starting with a signed word w ∈(S∪S−1)∗, representing an element of
the enveloping group of the monoid, one can try to write it as a fraction uv (where
v is the notation for v−1) with u, v ∈S∗, by “pushing” all the negative letters to
the right. Such writing is also called a “positive-negative path”. In practice, we
replace a subword st by θ(s, t)θ(t, s). Right-reversing is formally not an algorithm,
it is a rewriting system, but since it is confluent, one can derive an algorithm from
it (see [1] for the theory of rewriting systems). However, neither termination nor
correctness of this algorithm is guaranteed in general. Such an algorithm for writing
elements of the enveloping group of a monoid where the word problem is decidable
would give a solution to the word problem in the group. This can be applied to
the well-studied class of monoids called Garside monoids, introduced by Dehornoy
and Paris in [10]. That class includes the spherical type Artin-Tits monoids, where
right-reversing behaves well. Multiple issues arise when trying to extend the use of
right-reversing to the larger class of monoids with a finite Garside family, which
includes all Artin-Tits monoids [8].
Another use of the right-reversing algorithm is to compute least common mul-
tiple. Starting with a word uv, if right-reversing ends on a fraction v′u′, then the
element represented by uv′ = vu′ is a common right-multiple of u and v. Computing
common right-multiples is crucial, for example in multifraction reduction [6], which
is a new approach to the word problem in Artin-Tits groups in general. The com-
putability of right-lcms with right-reversing was already known for a fixed monoid :
if a bound on the length of the elements of a Garside family is given, one can write
a correct algorithm to compute lcms, by computing the maximal number of right-
reversing steps for finite computations. This is the argument for the computability
of right-lcms in [6], Lemma 5.13. However, we are not aware of any algorithm to
compute this bound in general. This is a classic problem in computability theory,
known as non-constructive algorithm proof. The existence of the algorithm relies
on the existence of a bound that is unkown. For Artin-Tits monoids, the existence
of a finite Garside family [8] is a consequence of the existence of finitely many low

In the case of Garside monoids, least common multiples always exist, and right-
reversing detects them. In a more general framework, additional assumptions are
needed. The correctness of computing least common multiples with right-reversing
relies on the notion of completeness, for which different criteria were developed
such as the θ-cube condition. (see. [5] and II.4.4 in [7]). However, termination is also
tricky. After discussing some special cases where right-reversing is complete, Section
II.4.3 in [7] ends with the following trichotomy when right-reversing is complete:
(1) either right-reversing leads in finitely many steps to a positive-negative path;
(2) or one gets stuck at some step with a pattern st such that θ(s, t) and θ(t, s) do
not exist;
(3) or right-reversing can be extended endlessly reaching neither of the above two
cases.
Thus, even when right-reversing is complete, it does not provide an algorithm
to decide if two elements have a common right-multiple, it only computes it when
it exists. In practice, a possible implementation is to just stop the algorithm after
a large number of steps, and this is actually correct when a finite Garside family
exists if the maximum number of steps is large enough, for the reason explained
above.
The easy case where right-reversing is terminating is when the signed word
is decreasing in length at each step, which means that θ(s, t) has length 0 or 1
for all s, t ∈S. In that case, the right-complemented presentation is called short.
The notion of Garside family (also called set of basic elements) naturally arises in
this context. The idea is to add θ(s, t) and the lcm as new generators, for all s, t
successively to increase the generating set until it is closed under right-lcm and right-
complement. Such a generating set is called a Garside family. It is a generalization of
the notion of Garside monoid in the following sense: in a Garside monoid, generators
share a common right-multiple called the Garside element, usually denoted by ∆.
Then the Garside family is the set of divisors of this element, i.e. the interval [1, ∆].
The process of closing the atom set under right-lcm and right-complement ends in
a finite number of steps only when there exists a finite Garside family, which is non-
trivially the case for Artin-Tits monoids [8]. Now, given a finite Garside family, one
can compute in the monoid (as in Section 4 of [9]). However, there was no algorithm
computing least common multiples with only the assumption of the existence of a
finite Garside family. Moreover, the natural algorithm that computes the smallest
Garside family by closing the atom set under right-lcm and right-complement ( [9],
algorithm 2.23) may fail to terminate even if the smallest Garside family is finite
because right-reversing can never terminate. So we might want to have a better
understanding of what happens when right-reversing does not end.

1.2. Results
Our main result answers this question in the classic setup where we assume that
right-reversing is complete and there exists a finite Garside family. A pair (u, v) is
failing if right-reversing of uv stops because of an undefined right-complement, and
it is eventually periodic if some periodic subword appears in the process.
Theorem 1.4. Let ⟨S|R⟩+ be a right-complemented presentation of a monoid M
for which right-reversing is complete. We assume that M has a finite Garside family
G. Let u, v be two words of S∗. Then one of the following holds:
(1) (u, v) is failing
(2) (u, v) is eventually periodic
(3) θ∗(u, v) is defined, i.e. there exist some positive words u′, v′ on S such that
uv ↷∗v′u′.
In other word, we show that if right-reversing can be extended endlessly, then
there is necessarily a cyclic pattern that can be detected. Stopping when a cycle is
detected provides an algorithm for computing right-lcms in the right-complemented
case based on right-reversing that does not need a bound on the length of the
element in the minimal Garside family. This shows that right lcms is not computable
only on a fixed monoid with a Garside family, it is computable given the presentation
of a monoid with a finite Garside family as an input. It also allows one to write
an algorithm for multifraction reduction without knowing a Garside family of the
monoid [6]. Moreover, this algorithm then provides a way of computing a minimal
Garside family when it is finite. We implemented it and computed the Garside
families for affine type Artin-Tits monoids f

2. Arithmetics in monoids
We start by describing the framework of right reduction. First with purely algebraic
properties that will then be transposed into algorithmic results. The results of this
section can be found in [7], II.2. The idea is to have properties in the monoid that
are analogous to the divisibility relation in the integers.
2.1. Divisibility relations in monoids
First, we recall the notion of cancellativity.
Definition 2.1. A monoid M is left-cancellative if, for all a, b, c ∈M, ca = cb
implies a = b. It is right-cancellative if, for all a, b, c ∈M, ac = bc implies a = b.
It is cancellative if it is both left and right-cancellative.
The non-commutative law on monoids leads us to distinguish a left and a right
divisibility relation.
Definition 2.2. Let a, b ∈M. We say that a is a left-divisor of b, or equivalently
that b is a right-multiple of a, if there exists c ∈M such that b = ac, and we write
a ≤b.
We say that a is a right-divisor of b, or equivalently that b is a left-multiple of a,
if there exists c ∈M such that b = ca, and we write a e≤b.
We write < (resp. e<) for the proper left (resp. right) divisibility relation, that is,
ax = b (resp. xa = b) with x non invertible.
We denote by D(a) (resp. eD(a)) the set of left-divisors (resp. right-divisors) of a.
The existence of a neutral element (resp. the associativity) in the monoid makes
the relation ≤and e≤reflexive (resp. transitive), so they are both pre-orders on M.
If a and b are such that a ≤b and b ≤a, then there exist c1, c2 such that b = ac1
and a = bc2, and we can write a = ac1c2. If M is left-cancellative, we can cancel
a and get c1c2 = 1, so c1 and c2 are invertible. If furthermore M has no nontrivial
invertible elements, we can conclude that c1 = c2 = 1, and we have a = b, so ≤is

2.2. Gcds and lcms
Definition 2.4. Let M be a monoid, and a, b, c ∈M. We say that c is a left
greatest common divisor (left-gcd) of a and b, if c ≤a and c ≤b, and for all d ∈M
such that d ≤a and d ≤b, we have d ≤c.
If M is left-cancellative and has no nontrivial invertible elements, then the left-gcd
is unique when it exists, as it is a greatest lower bound of a and b for the order ≤.
We denote it by c = a ∧b. Similarly, when M is right-cancellative, we denote by
a e∧b the right-gcd of a and b.
This is enough to define gcd-monoids. However, the counterpart of gcd, namely,
least common multiple will play a very important role in the theory of gcd-monoids.
Definition 2.5. We say that c is a right least common multiple (right-lcm) of a
and b, if a ≤c and b ≤c, and for all d ∈M such that a ≤d and b ≤d, we
have c ≤d. For the same reason, if M is left-cancellative and has no nontrivial
invertible elements, the right-lcm is unique when it exists, and we denote it by
c = a ∨b. Similarly, when M is right-cancellative, we denote by a e∨b the left-lcm
of a and b.
When a right-lcm of a and b exists, we can write it a ∨b = aa′ = bb′. Then a′
(resp. b′) is called the right-complement of a in b (resp. of b in a), denoted by (a\b)
(resp. (b\a)), so we have a ∨b = a(a\b) = b(b\a).
As the name suggests, gcds will always exist in gcd-monoids, but lcms may not
exist. However, a weaker condition will be satisfied.
Definition 2.6. A cancellative monoid M is said to have conditional right-lcms,
(resp. conditional left-lcms) if for all a, b ∈M, if a and b have a common right
(resp. left) multiple, then they have a right-lcm (resp. left-lcm). We say that M has
conditional lcms if it has both conditional right-lcms and conditional left-lcms.
Now, we can define the notion of gcd-monoid.
Definition 2.7. A gcd-monoid is a monoid M such that:
(1) M is cancellative,

Definition 2.11. A monoid M is called left-noetherian if the relation < is well-
founded, that is, there is no infinite decreasing sequence for <. It is called right-
noetherian if the relation e< is well-founded, and noetherian if the relation ⊂is
well-founded.
When M is cancellative, the notion of noetherianity can be described by the
existence of a noetherianity witness a map from the monoid to the collection of
ordinals Ord:
Definition 2.12. A map λ : M →Ord is called a left-noetherianity witness (resp.
right-noetherianity witness), if for all a, b ∈M, a < b (resp. a e< b) implies λ(a) <
λ(b). It is called sharp if, additionally, a ≤b (resp. a e≤b) implies λ(a) ≤λ(b).
The following proposition has its right counterpart.
Proposition 2.13. Let M be a cancellative monoid. Then the following are equiv-
alent:
(1) M is left-noetherian.
(2) M has a left-noetherianity witness.
(3) M has a sharp left-noetherianity witness.
Proof. (1) ⇔(2) is a basic result of set theory (see [12]).
(3) ⇒(2): a sharp left-noetherianity witness is by definition a left-noetherianity
witness.

The notion of witness can be used to define a stronger notion of noetherianity.
Definition 2.14. A monoid M is called strongly noetherian if there exists a map
λ : M →N such that for all a, b ∈M, λ(ab) ≥λ(a) + λ(b) and λ(a) > 0 for every
non invertible element a ∈M.
Strong noetherianity implies noetherianity, as we simply constrained the values
of the witness to be integers instead of any ordinals.
