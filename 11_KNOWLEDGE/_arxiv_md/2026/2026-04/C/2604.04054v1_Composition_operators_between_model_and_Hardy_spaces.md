the corresponding boundary values.
1.1. Composition operators. Consider a holomorphic mapping φ : Dn →D,
n ≥1. It is known that the composition operator Cφ : f 7→f ◦φ maps Hp(D)
into Hp(Dn), p > 0. Indeed, assume that f ∈Hp(D). The following argument is
well known. Let h denote the Poisson integral of the boundary values |f∗|p. Then
|f ◦φ|p ≤h◦φ and h◦φ is a pluriharmonic function in Dn. Hence, f ◦φ ∈Hp(Dn),
as required.
Since Cφ maps Hp(D) into Hp(Dn), it is natural to ask about characterizations of
those symbols φ for which Cφ : Hp(D) →Hp(Dn) is a compact operator. For n = 1,
an explicit approach based on the Nevanlinna counting function was developed in
[8]. A different answer, in terms of the Clark measures, was obtained in [3].
1.2. Model spaces.
Definition 1.1. A holomorphic function Θ : D →D is called inner if |Θ(ζ)| = 1
for m1-a.e. ζ ∈T.

Let (A0, A1) be a compatible pair of Banach spaces. For parameters 0 < θ <

Theorem 3.3 ([4]). Let (A0, A1) and (B0, B1) be compatible pairs of Banach
spaces.

and T : A0 →B0 is a compact operator. Then T : (A0, A1)θ,q →(B0, B1)θ,q is a
compact operator for all admissible parameters θ and q.
