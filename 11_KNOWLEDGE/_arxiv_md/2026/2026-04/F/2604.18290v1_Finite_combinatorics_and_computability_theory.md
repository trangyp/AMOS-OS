FINITE COMBINATORICS AND COMPUTABILITY THEORY
DAMIR D. DZHAFAROV AND JUN LE GOH
Abstract. We prove that the existence of finite combinatorial objects such
as affine planes, mutually orthogonal Latin squares, and resolvable balanced
incomplete block designs can be reformulated as the existence of certain al-
gorithmic reductions between problems related to the pigeonhole principle.
We then study the latter using counting arguments and computability theory.
In particular, we demonstrate that computability theoretic techniques can be
used to refine and prove new results in finite combinatorics.
1. Introduction
Notions of reduction are widespread in mathematics and computer science. In
computational complexity theory, say, one considers polynomial-time reductions
between decision problems, or counting problems involving finite objects. In com-
putability theory, one instead studies reductions defined in terms of Turing re-
ducibility. Informally, a function f : N →N is Turing reducible to (or computable
from) a function g : N →N, written f ≤T g, if there is an algorithm for computing
f(n) from n that is allowed to query the graph of g during the computation process
(in parlance, the algorithm uses g as an oracle). The definition can be extended
from functions to subsets of N, by identifying these with their characteristic func-
tions. A function (or set) is computable if it is Turing reducible to ∅. Importantly,
the definition of Turing reducibility is not concerned with time or space complexity,
which makes all finite sets computable, regardless of size. Reductions defined in
terms of Turing reducibility are thus most often studied between problems that
involve infinite sets.
As an example, consider the problem of finding an infinite monotone sequence
in a given countable linear order. We can reduce this problem to that of finding an
infinite homogeneous set for a given coloring of the unordered pairs of integers (i.e.,
to Ramsey’s theorem for pairs). Indeed, suppose we are given a countable linear
order; say its domain is N, and the ordering relation is ≤L. Define a coloring c of
the unordered pairs of integers as follows: for x < y in N, set c({x, y}) to be 0 if
x <L y, and 1 if x >L y. Now it is easily seen that if H is any infinite homogeneous
set for c (i.e., if c is constant on the unordered pairs of elements of H) then H is
monotone for L.

Reductions defined in terms of uniform computability are a central focus in
the area of computable analysis, with Weihrauch reducibility being arguably the
most prominent. See Brattka, Gherardi, and Pauly [8] for a general introduction,
and Section 3 below for some of the key definitions. Weihrauch reducibility has
been widely used to study relationships between problems in analysis (cf., e.g.,
[6, 10, 12, 26, 27]), infinitary combinatorics (cf. [13, 15, 17, 19, 22, 24, 30]), topology
(cf., e.g., [2, 3, 20]), and other areas. See Brattka [4] for a complete bibliography
of work in this area. Our interest in this article will be to apply the framework of
Weihrauch reducibility to the study of certain problems from finite combinatorics,
specifically the finite pigeonhole principle. Although computability theory on finite
sets and objects is trivial, uniform computability is not. And, as we will see in
Sections 2 and 3, to gain a more complete picture of the situation surrounding
finitary problems requires also looking at infinitary versions.
Part of the motivation for us comes from reverse mathematics, an area in the
foundation of mathematics that seeks to gauge the logical strength of theorems
in terms of the minimal axioms needed to prove them. Standard references are
Simpson [32], Hirschfeldt [23], and Dzhafarov and Mummert [18]. There is a deep
connection between computability theory and reverse mathematics (see Shore [31]).
Recent years have seen a flurry of activity also at the interface of reverse math-
ematics and Weihrauch reducibility (see, e.g., [15], [19], [21], [24]). The study of
pigeonhole principles in reverse mathematics has a long history, with seminal works
by Paris and Kirby [29], Hirst [25], and many others. Our paper is inspired by re-
cent work of Belanger, Chong, Wang, Wong, and Yang [1], who showed that the
existence of certain highly random binary sequences can be axiomatized in terms
of weak pigeonhole principles. These give rise to the principles (m ̸,→n), that we
introduce below and investigate here under Weihrauch reducibility.
We begin by stating precisely what we will mean, throughout, by problems.
Definition 1.1.
(1) An instance-solution problem (or just problem) P consists of a nonempty
set of instances, and for each instance x, a nonempty set of solutions to x.
When discussing multiple problems, we may qualify the above by referring
to P-instances and P-solutions.
(2) The set of instances of P is denoted dom(P), and the set of solutions to
x ∈dom(P) is denoted by P(x).
While quite general, we will only be concerned in problems whose instances and
solutions are (or can be coded/represented by) elements of a “standard space” like
NN (i.e., the set of functions from N →N). This includes a great many kinds of
objects. For starters, using any standard pairing function we may encode ordered
pairs of numbers (x, y) by a single number, denoted ⟨x, y⟩. (See, e.g., [33], p. 3.) We
can then extend this to ordered sequences of arbitrary finite length in the obvious
way. Thus, in particular, we can code functions f : Nn →N for any n ≥1, and

We now define a reducibility notion which, when restricted to finite problems,
exactly agrees with so-called strong Weihrauch reducibility; we discuss this further
in Section 3.
The advantage of using a separate definition here is that we can
forego, for now, needing to explicitly mention computability theory.
Definition 1.3. Let P and Q be finite problems.
(1) P is reducible to Q, written P ≤Q, if there exist functions Φ, Ψ with domain
and co-domain (possibly proper subsets of) N such that Φ(x) ∈dom(Q)
whenever x ∈dom(P), and Ψ(y) ∈P(X) whenever y ∈Q(Φ(x)).
(2) If P ≤Q and Q ≤P, we say that P and Q are equivalent, and write P ≡Q.
It is clear that ≤forms a preorder (i.e., it is reflexive and transitive).
The key part of the definition is that the “backward” function, Ψ, is not allowed
to make use of the starting P-instance, x. We have the following basic results.
Proposition 1.4. If m′ ≥m > n ≥n′ ≥2, then (m′ ̸,→n′) ≤(m ̸,→n).
Proof. Given f : m′ →n′, restrict it to m and regard it as a function from m to n.
Each solution to f ↾m : m →n is also a solution to f : m′ →n′. More formally, let
Φ : N →N be the function that, given as input (a code for) a function f : m′ →n′,
outputs (a code for) f ↾m (and is, for example, undefined on other inputs). Then
Φ takes instances of (m′ ̸,→n′) to instances of (m ̸,→n). Let Ψ : N →N be the
identity function. Then Φ and Ψ witness that (m′ ̸,→n′) ≤(m ̸,→n), as was to be
shown.
□
When proving that a reduction holds, we will typically forego the formal defi-
nition of Φ and Ψ as in the second part of the above proof, and instead directly
convert between instances and solutions, as in the first part. When proving a sepa-
ration, i.e., that a reduction does not hold, we will usually need to work with Φ and
Ψ explicitly. In such cases, given an instance f : m →n of (m ̸,→n), or a solution
{i, j} to some such f, we will write Φ(f) and Ψ({i, j}) for simplicity, even though
formally Φ and Ψ are being applied to the numerical codes of these objects.

2. Relationships between (m ̸,→n) and idk
In this section we demonstrate a surprising and deep connection between the
problems (m ̸,→n) and certain well-known problems in finite combinatorics. This
is expressed using the following identity problem on k elements.
Definition 2.1. For each k ≥1, the problem idk has instances j ∈{1, . . . , k},
where each instance j has solution set {j} (i.e., it has the unique solution j).
Although idk may appear to be a completely trivial problem, it is not so in our
context. To see this, suppose for instance that idk ≤P, say via Φ and Ψ as in
Definition 1.3. Then every solution to the P-instance Φ(j) must directly encode
the number j. This is because, as noted earlier, Ψ does not have access to what j
is, and so can only rely on queries to the P-solution. In this way we gain insight
about the coding power of the problem P, particularly if we can show that idk ≤P
for some k but not all. As we show below, characterizing what k, m, and n satisfy
idk ≤(m ̸,→n) actually turns out to be a difficult problem.

Definition 3.1. For each m > n ≥2, the problem (m ̸,→n)′ has instances all

The terminology and notation come from computability theory, where one can form,
for each set X, its (Turing) jump, X′. This is defined as the set of all (codes for)

4. Lifting reductions
In this section we prove Theorem 3.4, which largely consists of combining results
from the literature. In order to state said results, we first need to define the jump
of an arbitrary problem.
Definition 4.1. Given a problem P whose instances and solutions are elements of
NN, its jump P′ is the problem whose instances are sequences (ps)s∈N in NN which
converge to some P-instance, with solutions being P-solutions to lims ps.
There is an important distinction between this definition and the specific jump
problems defined in the previous section. Namely, in a P′-instance (ps)s∈N, it need
not be the case that each ps is itself a P-instance; this only has to be true of the
limit. This presents an apparent conflict of notation. However, for all the problems
we have considered and will consider in this paper, the two definitions are equivalent
up to strong Weihrauch reducibility. Thus, for all our intents and purposes we can
treat them as being the same. In particular, we have:

• the jump of (m ̸,→n) in the sense of Definition 4.1 is strongly Weihrauch
equivalent to (m ̸,→n)′ in the sense of Definition 3.1.
