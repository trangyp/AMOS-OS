Abstract
We introduce Flashback, a reversible string decomposition that repeatedly peels the max-
imal leading and trailing character runs from a sentinel-wrapped input, recording each pair as
one bilateral token. Decomposition and reconstruction both run in O(n) time and space. Our
central result is a run-pairing theorem: Flashback is equivalent to pairing the first run of the
string with the last, the second with the second-to-last, and so on. This gives an exact token
count of 1 + ⌈r/2⌉for a string with r maximal runs, and matches a lower bound that holds for
any admissible bilateral run-peeling scheme. From the run-pairing theorem the main structural
properties follow as corollaries: the irreducible peeling kernel uses at most two symbols; palin-
dromes are precisely the strings whose run-length encoding is symmetric with an odd number
of runs; the image of the decomposition admits an explicit finite-state characterisation; and
changing one run length rewrites exactly one content token.

Introduction
Most string decompositions process the input from one end to the other. Lempel–Ziv [3, 6, 7] parses
left-to-right against a dictionary of previously seen substrings; the Burrows–Wheeler Transform [1]
permutes characters to cluster identical symbols; run-length encoding walks the string once and
collapses adjacent duplicates. Each of these captures something real (repetition, clustering, local
homogeneity), but none exposes the outside-in structure of a string: the way a string’s boundary
runs can be peeled away, layer by layer, to reveal an inner core.
We study one such decomposition. Flashback wraps the input in sentinels and, at each step,
removes the maximal run from each end at once, recording the two peeled runs as a single bilateral
token together with the split between them. The companion procedure F−1 reconstructs the string
by nesting the tokens from the inside out. The algorithm is deterministic, runs in O(n) time and
space, and is exactly reversible.
The algorithm is short; the structural theory it opens up is the point of this paper.
Once
the decomposition is phrased at the run level, a single observation drives most of what follows:
Flashback is equivalent to pairing the first run of the string with the last, the second with the
second-to-last, and so on. From that one identification the token count, the irreducible kernel, a
palindrome test, a description of the image of F, and an exact edit-locality theorem all fall out as

Preliminaries
We work with finite strings over an alphabet Σ. For s ∈Σ∗with |s| = n, we write s[i..j] for the
inclusive 1-indexed substring and s[i..j) for its half-open counterpart (empty when i > j).
Definition 2.1 (Maximal runs). The leading run of a non-empty string w = w1 · · · wm is its longest
prefix of a single repeated symbol; the trailing run is its longest suffix of a single repeated symbol.
Both are uniquely determined and have length ≥1.
Definition 2.2 (Sentinel-wrapped string). Fix two symbols @, $ /∈Σ. The sentinel-wrapped form
of s is ˆs = @ · s · $, of length n + 2. The sentinels guarantee that at depth 0 the leading and trailing
runs are distinct length-one runs.
Definition 2.3 (Bilateral token). A bilateral token is a pair τ = (σ, p) with σ ∈Σ+ (the concate-
nation of a front run and a back run) and p ∈N0 the split position: σ[1..p] is the front, σ[p+1..|σ|]
the back. A token is terminal when p = 0. We write τ as σ_p; e.g. (CFF, 1) is CFF_1.
Definition 2.4 (Decomposition operators). F(s) denotes the token sequence produced by Flashback-
Decompose(s), and F−1(T) the string recovered by Flashback-Reverse(T).
3
The Flashback Algorithm
Flashback consists of two procedures: a decomposition F that turns a string into a token sequence,
and a reconstruction F−1 that inverts it exactly.
3.1
Decomposition
The idea is simple. We wrap the input string in two sentinel characters, and then repeatedly remove
the maximal runs at the two ends, emitting each pair as a single token. The sentinels @ and $ are
there only to make the algorithm uniform: without them a string that already begins and ends with
the same character would need a special case.

Concretely: on an active span, find the leading run and the trailing run; concatenate them into
a symbol string and record the split position (the length of the leading run); then recurse on the

and back runs together cover it.

A few remarks. The first token is always (@$, 1): because @ and $ are distinct and do not appear
in Σ, they are always peeled at depth 0. Peel is tail-recursive (each call makes at most one recursive
call, as its last action), so the procedure converts trivially to a loop (see Section A.1). Finally, every
character of ˆs is consumed (placed into a token’s symbol string) exactly once across all levels; the
total number of character inspections remains O(n) as we show in Section 5.
3.2
Reconstruction
Reconstruction is the mirror image. We allocate an output buffer and walk the token list from
outside in. For each token we write the front run at the current position, recurse to fill the gap, and
then write the back run after the inner result has been filled. Because each character lands directly
in its final slot, the total work is Θ(n).
In words: each token τi = (σi, pi) denotes a nested concatenation σi[1..pi] ∥(inner result) ∥σi[pi+1..],
with the innermost token returned verbatim. The algorithm above realises this in-place by writing
each character directly into its final buffer slot, so the total number of character writes is n + 2
(Theorem 4.5) and no string is ever copied. A terminal token (p = 0) can only appear as the last
element of T (Theorem 4.6).
We prove that decomposition and reconstruction are exact inverses, i.e. that F−1(F(s)) = s for
every s, in Theorem 4.2.

Structural Analysis
The algorithm described so far is short, but its real content is structural: Flashback acts on the run-
level shape of a string, not on individual characters. Once we make this observation precise in the
run-pairing theorem below, most other properties of the decomposition follow almost mechanically:
kernel size, palindromes, edit locality, and the image of F are all corollaries of the same pairing
identity.
The rest of the section is organised around that theorem: first its statement, then a
matching lower bound, and finally the downstream consequences.

• Termination. If the active span consists of a single run or two adjacent runs, emit one terminal

• Peeling step. Otherwise let L be the length of the span’s leading run and R the length of its
trailing run. Choose any integers x ∈{1, . . . , L} and y ∈{1, . . . , R}, emit the token formed

middle.

Theorem 6.4 (Greedy optimality). Every admissible bilateral run-peeling decomposition of s uses
at least ⌈r/2⌉content tokens, and Flashback attains this minimum.
Proof. The idea is to track how many of the original RLE runs of s the active span still intersects
as peeling proceeds. Let N denote that count; initially N = r.
Step 1: each non-terminal step decreases N by at most 2. A peeling step removes a prefix of
length x ≥1 from the current leading run and a suffix of length y ≥1 from the current trailing
run. Advancing the left endpoint of the span by x positions moves it across at most one original
run boundary, so at most one original run falls out of the span on the left; symmetrically on the
right.
Step 2: at termination, N ≤2. The termination rule fires only when the active span is one run
or two adjacent runs, hence intersects at most two original RLE runs.
Step 3: arithmetic. Suppose the decomposition emits t content tokens in total. The last is the
terminal token, so there are exactly t −1 non-terminal steps. By Steps 1 and 2,

Palindromes.
Flashback recovers a classical fact about run-length encoding: a string s is a
palindrome if and only if r is odd and its RLE is symmetric (aj = ar+1−j and mj = mr+1−j for

pairing theorem; we mention it because in Flashback terms it has a clean form: K(s) is a single run
and every non-terminal token has matching front and back symbols with equal-length pairs.

6.5
Image Characterisation
We close by identifying which token sequences actually arise. The constraints are all local: each
content token is a pair of runs, the terminal is one or two runs, and consecutive depths must alternate
symbols on each side. These conditions can be checked in a single pass, so membership in Im(F) is
decidable in linear time.
Theorem 6.9 (Valid token sequences). Let T = [(@$, 1), (σ1, p1), . . . , (σk−1, pk−1)] be a candidate
token sequence with k ≥2 and all non-sentinel characters drawn from Σ. For each non-terminal
depth 1 ≤d ≤k −2, write
ad = front symbol of τd = σd[1],
cd = back symbol of τd = σd[|σd|].
Then T lies in the image of F if and only if the following conditions hold.
1. Token form. For each non-terminal depth 1 ≤d ≤k −2:
• pd ≥1 and |σd| −pd ≥1 (both the front part σd[1..pd] and the back part σd[pd + 1..|σd|]
are non-empty);
• the front part is a single run of ad, and the back part is a single run of cd.
2. Terminal form. pk−1 = 0 and σk−1 is either a single run am or two adjacent runs aℓcb with
a ̸= c.
3. Alternation (only when k ≥3):
• Interior: for 1 ≤d ≤k −3, ad+1 ̸= ad and cd+1 ̸= cd.
• Boundary: the first character of σk−1 differs from ak−2, and the last character of σk−1
differs from ck−2.
When k = 2, only conditions (1) and (2) apply. Moreover, F(F−1(T)) = T for every valid T.

7
Related Work
Run-length encoding.
RLE replaces each maximal run ak with the pair (a, k). Theorem 6.2
shows that Flashback is, in a precise sense, a bilateral pairing of the RLE: it pairs the first run with
the last, the second with the second-to-last, and so on. Where RLE processes runs left-to-right,
Flashback processes them outside-in, capturing the nesting structure that RLE discards. The token
count k = 1 + ⌈r/2⌉is determined entirely by the number of runs r.
Lempel–Ziv decompositions.
The LZ76 factorisation [3] and its descendants LZ77 [6]/LZ78 [7]
parse left-to-right, greedily extending each factor against a dictionary of previously seen substrings.
LZ exploits repetitive structure across positions; Flashback exploits bilateral boundary structure.
The two are complementary: LZ76 produces O(n/ log n) factors for random strings [3], while Flash-
back produces Θ(n) tokens. Flashback is not a compression scheme.
Burrows–Wheeler Transform.
The BWT [1] is a reversible permutation that clusters identical
characters.
It does not produce variable-length tokens.
Flashback produces an ordered token
sequence with split positions that directly encode reconstruction.
Bidirectional macro schemes.
Storer and Szymanski [5] introduced bidirectional macro schemes,
where substrings may reference each other in both directions. Computing the smallest such scheme
is NP-hard. Flashback uses no references: each token is self-contained.
Lyndon factorisation.
The Lyndon factorisation [2, 4] decomposes a string into a non-increasing
sequence of Lyndon words in linear time. It is based on lexicographic properties and produces a
sequential factorisation; Flashback’s tokens encode bilateral boundary structure with an explicit
nesting.
8
Conclusion
Flashback is a small, deterministic decomposition that runs in O(n) time and space and is exactly
reversible. Once phrased at the run level, it turns out to be bilateral pairing of the run-length
encoding (Theorem 6.2), and that single observation is what carries the rest of the paper: the
1 + ⌈r/2⌉token count, the matching lower bound over all admissible bilateral run-peeling schemes
(Theorem 6.4), the two-symbol kernel, the palindrome test, and the image characterisation all follow
as corollaries. One less expected property is token-level edit locality: under a skeleton-preserving
run-length change, exactly one content token is rewritten (Theorem 6.8). We see Flashback primarily
as a structural tool for reasoning about run-level symmetry rather than as a competitor to existing
string-compression or indexing schemes.
