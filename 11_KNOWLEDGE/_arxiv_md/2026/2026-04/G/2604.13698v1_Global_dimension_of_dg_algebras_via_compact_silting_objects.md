GLOBAL DIMENSION OF DG ALGEBRAS VIA COMPACT SILTING OBJECTS
PANAGIOTIS KOSTAS
Abstract. We introduce a notion of global dimension for a triangulated category relative to a compact
silting object. We prove that the finiteness of this dimension is an intrinsic property of the triangulated
category itself and, therefore, independent of the choice of the silting object. Focusing on the setup
of connective differential graded (dg) algebras, we analyse the behaviour of global dimension under dg
algebra homomorphisms and establish explicit bounds. This allows us to deduce a bound for the global
dimension of certain dg quiver algebras. We also relate the regularity of the big singularity category of
a proper connective dg algebra to the finiteness of its global dimension.
1. Introduction
The global dimension of a ring is an important invariant in representation theory and algebraic ge-
ometry. It is known that the global dimension is not preserved under derived equivalences (see [8]), but
its finiteness is, i.e. given a triangle equivalence D(R) ≃D(S) of derived categories of rings R and S,
then gl. dim R < ∞if and only if gl. dim S < ∞. This can be understood via a very general construction
from [16]; for a compactly generated triangulated category T, we may consider the “right far-away or-
thogonal” of the compact objects Tc, in order to define (Tc)←→

Db(Mod-R) = Kb(Proj-R), i.e. that gl. dim R is finite. Since the global dimension of rings is not a derived
invariant, this approach cannot be used in order to assign a specific number that measures the finiteness
of global dimension for a triangulated category; some non-intrinsic choices have to be made.
Our first aim in this paper is to define the global dimension of a compactly generated triangulated
category T relative to a compact silting object (when it exists). The main result of this paper, proved in

mentioned above, that the global dimension of A is a property intrinsic to D(A). We accompany this
section with several other criteria for detecting finite global dimension (some of which are necessary in
order to compare with [19,24]), see (2.2) for a summary.
In [16, Proposition 5.9(iii)] it is shown that Kac(Inj-Λ), where Λ is an Artin algebra, is regular (in the
sense of [16, Definition 5.7]) if and only if gl. dim Λ < ∞. In Section 3 we prove the analogous result for
proper connective dg algebras, see Corollary 3.4.
Investigating the behaviour of the global dimension of a finite dimensional algebra in terms of its
Gabriel quiver (and the relations) has been an active field of research, see the survey [12]. In the dg
world, much less seems to be known in this direction. We list some of these instances below.
• Smoothness for certain graded gentle algebras (and with trivial differential) was investigated

• Explicit smooth algebras were constructed in [22, Subsection 4.3], using twisted tensor products.

2. Global dimension for connective dg algebras
We remind that a t-structure on a triangulated category T is a torsion pair (U, V) on T (i.e. a pair
of subcategories satisfying U = ⊥V, U⊥= V and T = U ∗V) such that U[1] ⊆U. The heart of this
t-structure is defined as the intersection H := U ∩V[1] (and it is an abelian category [3]).
Example 2.1. (Silting objects) An object M of a (small) triangulated category D is called a silting
generator if HomD(M, M[> 0]) = 0 and thick(M) = D.
We say that an object M of a compactly
generated triangulated category T is a compact silting object if it is a silting generator of Tc. We then know
from [13, Theorem 2.1] that the pair (M ⊥>0, M ⊥≤0) is a t-structure of T whose heart is M ⊥̸=0 =: HM.
We introduce a notion of projective dimension of objects in a triangulated category, relative to a heart
of a given t-structure. Similar considerations have appeared in [4, Appendix B] and in [24].
Definition 2.2. Let T be a triangulated category and (U, V) a t-structure in T with heart H.
• The projective dimension relative to H of an object x of T, denoted by pdimH x, is defined to
be the minimum n for which
HomT(x, y[>n]) = 0
for all y ∈H. If no such n exists, then pdimH x = ∞.
• The global dimension of T relative to H, denoted by gl. dim HT, is defined as the minimum n for
which pdimH x ≤n for every object x in the heart H. If no such n exists, then gl. dimH T = ∞.
The projective dimension of an object can in principle be negative, but it is always nonnegative for
objects in the aisle, since HomT(U, H[< 0]) = 0. For T = D(R), the derived category of a ring R, we have
gl. dimH T = gl. dim R, where H ≃Mod-R is the heart of the canonical t-structure in D(R).
Recollection 2.3. Let A be a connective dg algebra over a commutative ring k (i.e. Hn(A) = 0 for all
n > 0). Then A is a silting object in T = D(A) and therefore it induces a t-structure (A⊥>0, A⊥≤0).
There is an equivalence H ≃Mod-H0(A), where H is the heart of the t-structure above; explicitly we
may assume that An = 0 for n > 0 and then, there is a canonical morphism of dg algebras A →H0(A)
which induces a functor D(H0(A)) →D(A). This functor restricts to an equivalence Mod-H0(A) →H;
see [1, Section 2.1] for details.
The following example of relative global dimension is the main object of study in this paper.
Definition 2.4. The global dimension of a connective dg algebra A is defined to be the global dimension
of D(A) relative H ≃Mod-H0(A). For an object x of D(A), we simply denote pdimH x by pdimA x.
Remark 2.5. We will later observe, see Remark 2.17, that the definition of global dimension for connec-
tive dg algebras, as in Definition 2.4, agrees with the definition given in [19, Theorem 5.1]. Note, however,
that the two notions of projective dimensions used here and in [19] differ; for a connective dg algebra A
and any integer n, we have pdimA A[n] = n while using the definition from [19,25], the dg module A[n]
has projective dimension zero.
We now observe the following property of projective dimension.
Lemma 2.6. Let T be a triangulated category and (U, V) a t-structure in T with heart H. Then for any
triangle x →y →z →x[1] of T, the inequality pdimH y ≤max{pdimH x, pdimH z} holds.
Proof. This follows immediately by applying HomT(−, h) to the given triangle, for any h ∈H.
□
