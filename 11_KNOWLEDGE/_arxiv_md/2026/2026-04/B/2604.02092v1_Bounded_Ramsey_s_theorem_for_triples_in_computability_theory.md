Abstract
We study a restriction of Ramsey’s theorem for 2-coloring of triples,
in which homogeneous sets for color 1 are of bounded size (BRT3
2). We
prove that the computational content of this statement is very close to
Ramsey’s theorem for pairs (RT2
2), in that it satisfies the same known
computability-theoretic upper bounds, but that BRT3
2 is not computably-
reducible to RT2
2, even when allowing multiple applications of RT2
2.

Introduction
In this article, we study a bounded version of Ramsey’s theorem for triples from
the viewpoint of reverse mathematics and computable reductions. Ramsey’s
theorem is a fundamental theorem in combinatorics at the origins of Ramsey
theory. Given a set X ⊆N and n ∈N, we write [X]n for the collection of all
unordered n-tuples over X. For every n, k ≥1, Ramsey’s theorem for n-tuples
and k-colors (RTn
k) states that every coloring f : [N]n →{0, . . . , k −1} admits
an infinite set H ⊆N such that f uses exactly one color i on [X]n. We then say
that H is f-homogeneous (for color i).
In the same way that most applications of Borel determinacy require only
low levels in the Borel hierarchy, many applications of Ramsey’s theorem in
other areas of mathematics involve degenerate colorings. For instance, Ramsey’s
theorem for transitive colorings is used in a factorization theorem in automata
theory [18]. In this article, we study another restriction of Ramsey’s theorem
for 2-colorings, in which the homogeneous sets of color 1 are of bounded size.
Statement (Bounded Ramsey’s theorem). BRTn
2,ℓis the statement “Every col-
oring f : [N]n →2 which has no f-homogeneous set for color 1 of size ℓhas an
infinite f-homogeneous set for color 0.” BRTn
2 is the statement ∀ℓBRTn
2,ℓ.

1.1
Reverse mathematics and computable reductions
Reverse mathematics is a foundational program started by Harvey Friedman [8],
whose goal is to find optimal axioms to prove ordinary theorems.
It uses
the framework of subsystems of second-order arithmetic, with a base theory
RCA0 capturing “computable mathematics.” More precisely, RCA0 is composed
of Robinson’s arithmetic together with the Σ0
1-induction scheme and the ∆0
1-

introduction to reverse mathematics.
Structures in the language of second-order arithmetic are of the form M =

Stability and cohesiveness
In order to better understand the computational strength of Ramsey’s theorem
for pairs, Cholak, Jockusch and Slaman [3] decomposed RT2

cohesive versions. A coloring f : [N]n+1 →k is stable if for every ⃗x ∈[N]n,
limy f(⃗x, y) exists. The limit coloring of f is the coloring g : [N]n →k defined
by g(⃗x) = limy f(⃗x, y).
As mentioned, Shoenfield’s limit lemma forms a bridge between stable Ram-
sey’s theorem for computable colorings of (n + 1)-tuples and Ramsey’s theorem
for ∆0

bounded counterparts of these statements.

As explained in Section 1.2, the computability-theoretic analysis of BRT3

closely related to the one of BRT2

translating upper bounds from the Erd˝os-Moser theorem to BRT3

property is a collection of sets W ⊆P(N) which is downward-closed under
Turing reducibility.
Definition 2.1. A problem P preserves a weakness property W if for every
set Z ∈W and every Z-computable P-instance X, there is a P-solution Y to X
such that Y ⊕Z ∈W. Moreover, P strongly preserves W if the restriction to
Z-computable P-instances is replaced by arbitrary P-instances.
Many basis theorems studied in reverse mathematics can be formulated as
preservations for families of weakness properties.
Example 2.2. A problem P admits cone avoidance if for every set Z, every
set C ̸≤T Z and every Z-computable P-instance X, there is a P-solution Y to X
such that C ̸≤T Y ⊕Z. Equivalently, P admits cone avoidance if it preserves
WC = {Z : C ̸≤T Z} for every set C.
The Erd˝os-Moser theorem [7] is a statement from graph theory about finding
transitive sub-tournaments. A tournament is an oriented complete graph, and
it is transitive if it contains no cycle. In our situation, it is more convenient
to formulate it in terms of transitive colorings of pairs. Given a coloring f :
[N]2 →2, a set H ⊆N is f-transitive if for every x, y, z ∈H with x < y < z, if
f(x, y) = f(y, z), then f(x, y) = f(x, z).
