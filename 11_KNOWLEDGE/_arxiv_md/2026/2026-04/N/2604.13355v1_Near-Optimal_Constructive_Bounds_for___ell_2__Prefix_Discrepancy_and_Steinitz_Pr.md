Abstract
A classical result of Steinitz from 1913 [Ste13], answering an earlier question of Riemann and
L´evy (e.g., [L´ev05]), states that for any norm ∥· ∥in Rd and any set of vectors v1, · · · , vn ∈Rd
satisfying Pn
i=1 vi = 0, there exists an ordering π : [n] →[n] such that every partial sum along
this order is bounded by O(d), i.e.,
 Pt
i=1 vπ(i)
 ≤O(d) for all t ∈[n].
Steinitz’s bound is tight up to constants in general, but for the ℓ2 norm ∥· ∥2, it has been
conjectured that the best bound is O(
√
d). Almost a century later, a breakthrough work of Ba-
naszczyk [Ban12] gave a bound of O(
√
d+√log n) for the ℓ2 Steinitz problem, matching the con-
jecture under the mild assumption that d ≥Ω(log n). Banaszczyk’s result is non-constructive,
and the previous best algorithmic bound was O(√d log n), due to Bansal and Garg [BG17].
In this work, we give an eﬃcient algorithm that matches the conjectured O(
√
d) bound for the
ℓ2 Steinitz problem under the slightly worse, yet still polylogarithmic, condition of d ≥Ω(log7 n).
As in prior work, our result extends to the harder problem of ℓ2 preﬁx discrepancy.
We employ the framework of obtaining the desired ordering via a discrete Brownian motion,
guided by a semideﬁnite program (SDP). To obtain our results, we use the new technique of
“Decoupling via Aﬃne Spectral Independence”, proposed by Bansal and Jiang [BJ26] to achieve
substantial progress on the Beck-Fiala and Koml´os conjectures, together with a “Global Interval
Tree” data structure that simultaneously controls the deviations for all preﬁxes.

Introduction
The Steinitz problem is a fundamental question in combinatorial discrepancy theory that studies
how well one can control the discrepancy of partial sums of vectors under permutations. Formally,
given a norm ∥· ∥and a set of vectors v1, · · · , vn ∈Rd satisfying ∥vi∥≤1 for each i ∈[n]1 and
P
i∈[n] vi = 0, the Steinitz problem asks for the smallest number S(∥· ∥), depending only on the
norm ∥· ∥, such that there exists an ordering π : [n] →[n] for which all partial sums along this
ordering are at most S(∥·∥), i.e., maxt∈[n]
 P
i∈[t] vπ(i)
 ≤S(∥·∥). This was originally a question of
Riemann and L´evy [L´ev05] from the early 1900s, and it has later found many surprising applications
in areas such as graph theory [AB86], integer programming [BMMP12, DFG12, EW19, JR18], and
scheduling [B´ar81, Sev94]. We refer readers to the surveys [Hal89, Sev94, B´ar08] for more details
on the history and applications of the Steinitz problem.
A classical result of Steinitz [Ste13] showed that S(∥·∥) ≤2d, regardless of the norm. Subsequently,
this bound was improved to 1.5d in [B´ar81] and then further to slightly better than d [GS80, Ban87].
In particular, the proof by Grinberg and Sevastyanov in [GS80] uses a clever iterated rounding
argument, which also implies an eﬃcient algorithm for ﬁnding a good ordering π.
The above bound of O(d) is the best possible up to constants for general norms, e.g., S(∥·∥1) ≥d/2.
But for the ℓ2 norm, the best lower bound is only S(∥· ∥2) ≥Ω(
√

bound is known for ℓ2, it was conjectured that Θ(

discuss more on algorithmic aspects of discrepancy theory in Section 1.3). On the algorithmic front,
[HS14] gave a constructive proof of O(

O(√d log n) due to Bansal and Garg [BG17]. Unlike Banaszczyk’s result, these algorithmic bounds
don’t match the conjectured bound for ℓ2 Steinitz in any regime, and it is a natural open question
to algorithmically attain Banaszczyk’s bound for this problem (e.g., see [BDGL18]).

Our Approach in a Nutshell
We view the given vectors v1, · · · , vn ∈Rd as a matrix A ∈Rd×n whose jth column is vj. Denote
by Ai ∈Rn its ith row. Throughout, we use v(ℓ) to denote the ℓth entry of a vector v and log
means logarithm to the base 2. We always use i ∈[d] to index rows of A, and j ∈[n] for columns,
and use P ⊆[n] to denote an arbitrary preﬁx whose discrepancy we will bound.

Similar to prior works, our algorithm starts with x0 = 0n and evolves a fractional coloring xt ∈
[−1, 1]n using carefully chosen random tiny increments ∆xt. As in [BG17], to handle all preﬁxes,
our algorithm maintains a sliding window Wt ⊆[n] containing the ﬁrst 10d alive columns j for
which xt(j) has not yet reached ±1, and ensures that (1) ∆xt is supported only on Wt, and (2)
the discrepancy update of the full sliding window is 0, i.e., P

Roughly speaking, prior algorithms [BDG19, BG17, BLV22] choose the increment ∆xt to be O(1)-
spectrally independent, which ensures that the discrepancy ϕP

preﬁx discrepancy — subgaussianity ensures that each row preﬁx discrepancy |ϕP

The main bottleneck for Bansal-Garg’s bound is that while each ϕP

may have arbitrarily correlations, and this is why a row-wise analysis is needed to control ϕP

standard concentration inequalities would give an additive deviation, and recover Banaszczyk’s non-
constructive O(d + √d log n) bound. Although it is clearly impossible to achieve full independence

[BJ26] to ensure that the change in preﬁx discrepancy ∆ϕP

this weaker form of independence turns out to be suﬃcient for an additive ℓ2 discrepancy bound
on ϕP

Nonetheless, the use of aﬃne spectral independence posts a technical challenge — the independence
degrades as one controls more rows/preﬁxes. Naively, at each time t, one needs to control d rows
for each of the |Wt| = 10d preﬁxes in the sliding window, but including all these Θ(d2) row-preﬁx
pairs would result in too weak of an independence to even improve upon the Bansal-Garg bound.
To bypass this issue, we only enforce aﬃne spectral independence for a carefully chosen set of o(d)
preﬁxes in Wt called ASI-guarded preﬁxes. To maintain this set of ASI-guarded preﬁxes dynamically
and to bound the discrepancies of the remaining unguarded preﬁxes, we design a Global Interval
Tree data structure to simultaneously control their additive deviations.

Combinatorial Discrepancy.
Combinatorial discrepancy theory is a well-studied topic with
many connections and applications to both mathematics and computer science, and we refer readers
to the textbooks [Cha00, Mat09, CST14]. A classical question in combinatorial discrepancy is the
following vector balancing problem: given a norm ∥·∥and vectors v1, · · · , vn ∈Rd, the goal is to ﬁnd
a coloring x ∈{±1}n to minimize disc∥·∥(v1, · · · , vn) := minx∈{±1}n
 Pn
i=1 xivi

easier than preﬁx discrepancy, as one only bounds the total signed sum. For instance, for the ℓ2
norm, a classical result of B´ar´any and Grinberg [BG81] shows that disc∥·∥2(v1, · · · , vn) ≤O(
√
d)
when each ∥vi∥2 ≤1 and this bound is tight up to constants.
ℓ∞Discrepancy and Algorithmic Aspects. While our focus here is on ℓ2 discrepancy, we
remark that ℓ∞discrepancy is also very natural, and its study has led to many interesting techniques
and developments in discrepancy theory. A seminal result of Spencer [Spe85] (and independently,
Gluskin [Glu89]) shows that if each ∥vi∥∞≤1 and d = n, then disc∥·∥∞(v1, · · · , vn) ≤O(√n). This
beats the O(√n log n) bound for a random coloring, and is optimal up to constants.
When each ∥vi∥2 ≤1, the long-standing Koml´os conjecture, generalizing a seminal conjecture of
Beck and Fiala [BF81], asserts that disc∥·∥∞(v1, · · · , vn) ≤O(1). For the Koml´os problem, Spencer
[Spe85] gave an O(log n) bound. This was improved to O(√log n) by Banaszczyk [Ban98]. His
results for preﬁx discrepancy and Steinitz problems in [Ban12] are crucially based on this earlier
work.
While the above approaches for ℓ∞discrepancy have become prominent in discrepancy theory, these
methods were originally non-constructive and did not give an eﬃcient algorithm for ﬁnding a good
coloring. Following a breakthrough of Bansal [Ban10], many elegant algorithms have been developed
that matches these non-constructive bounds [BS13, HSS14, LM15, DGLN16, Rot17, LRR17, ES18,
BDGL18, BDG19, ALS21, BLV22, JSS23, PV23, HSSZ24, BJ25b], leading to surprising applications
in many diﬀerent areas (e.g., see the excellent survey [Ban22]). Interestingly, they also provide new
insights into discrepancy theory and lately, building on top of these algorithmic developments,
Bansal and Jiang [BJ25a, BJ26] gave an improved O((log1/4 n) · poly(log log n)) bound for the
Koml´os problem and almost resolved the Beck-Fiala conjecture.
ℓ∞Preﬁx Discrepancy. The ℓ∞preﬁx discrepancy problem, where the objective is to bound
maxt∈[n] ∥Pt
i=1 xivi∥∞, is also well-studied. When each ∥vi∥∞≤1, it was conjectured that the
correct bound should be Θ(
√

and this bound was later matched algorithmically in [BG17].
The case where each ∥vi∥2 ≤1 (i.e., the preﬁx version of Koml´os problem) is more elusive. The best
non-constructive bound is O(√log n) [Ban12], while the best algorithmic bound is only O(log n)
[ALS21]. It was asked in [BJM+22] whether the Koml´os conjecture generalizes to this preﬁx setting,
i.e., whether the best bound is O(1), but there is no clear consensus on this question.

2.1
Algorithmic Framework: SDP-Guided Walk with A Sliding Window
As in many previous discrepancy algorithms [BG17, BDG19, BLV22, Ban24, BJ25a, BJ26], our
algorithms start with x0 = 0n, and evolve a fractional coloring xt ∈[−1, 1]n over time using tiny
random increments, until some ﬁnal coloring in {±1}n is reached. The time t will range from 0 to
n, and is updated in discrete increments of size dt. We will set dt = 1/poly(n) so that the algorithm
runs in polynomial time, but it is useful to view dt as inﬁnitesimally small.
Sliding Window and Coloring Update. At each time t, a column j ∈[n] is alive if |xt(j)| ≤
1 −1/(2nd), and is called dead otherwise. Notice that rounding a dead column to either 1 or −1
incurs a negligible O(1/(nd)) discrepancy per column, and thus will be ignored henceforth. Let
Wt ⊆[n] be the ﬁrst 10d alive columns, which we will refer to as the sliding window. The columns in
Wt will be called active, and alive columns not contained in Wt are called dormant. The algorithm
will only update the coloring xt(j) for j ∈Wt, and ensures that the discrepancy update of the
whole sliding window is 0.
Speciﬁcally, at time t, the algorithm chooses a random vector ut ∈RWt satisfying E[ut] = 0,

will be speciﬁed later).6 The coloring xt is updated to xt+dt = xt + dxt with

Concluding Remarks
Our constructive bounds for ℓ2 preﬁx discrepancy and Steinitz problems match the conjectured
bounds when d ≥polylog(n), where the polylog factors are larger than those in Banaszczyk’s non-
constructive results (where he only requires d ≥log n). Below, we brieﬂy explain the several reasons
for this loss in our current analysis and mention some related open problems.

(a) First, in the TGlobal data structure, we lower bound the average interval size by Ω(s/ log n)
(even though the base intervals have size s), which results in an extra log n factor in the
number of intervals we need to maintain; we also upper bound the size of the error set by
O(s log n). Both these log n factors are due to the global binary tree having depth Θ(log n).
Nonetheless, as the sliding window has size |Wt| = O(d), it may be possible to reduce these
