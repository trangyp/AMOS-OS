Abstract
The Strongly Connected Steiner Subgraph (SCSS) problem is a well-studied network
design problem that asks for a minimum subgraph that strongly connects a given set of
terminals.
In this paper, we present several new algorithmic and complexity results for
SCSS.
As our main result, we show that SCSS can be solved in time 17twnO(1) on directed
graphs with n vertices when a tree decomposition of the underlying graph of width tw
is provided. This improves over a natural twO(tw) nO(1) time algorithm, and is the first
algorithm with this kind of running time for a problem involving strong connectivity.
Second, we give an exact exponential-time algorithm that solves SCSS in 2nnO(1) time,
improving the known bounds for general directed graphs.
Finally, we investigate kernelization with respect to vertex cover. We prove that SCSS
does not admit a polynomial kernel when parameterized by the size of a vertex cover, unless
the polynomial hierarchy collapses. In contrast, we show that the closely related Strongly
Connected Spanning Subgraph problem does admit a polynomial kernel under the same
parameterization.

Introduction
The Steiner Tree problem is one of the earliest and most fundamental problems in combina-
torial optimization: Given an undirected graph G = (V, E) along with a set T ⊆V of terminals,
the objective is to find a subgraph of G with the minimum number of edges that connects all the
terminals with each other. Accordingly, the problem is called Steiner Tree since this graph
can be assumed to be a tree. The parameterized complexity of the problem has been studied
already since the 1970s, when Dreyfus and Wagner showed that the problem can be solved in
O∗(3|T|) time,1 and hence proved it to be fixed parameter tractable when parameterized by the
number of terminals. Parameterized by the number of vertices of G, there is an O∗(1.36n)-time
algorithm [18].
Another important parameter for Steiner Tree is the treewidth of the input graph G,
which measures how tree-like G is.
A simple dynamic programming algorithm (cf e.g. [12,
Section 7.3.3]) shows that an instance of Steiner Tree can be solved in O∗(twtw) time when
a tree decomposition of G of width tw is given.2 The twtw dependency here comes from the
apparent need to store the connectivity pattern of partial solutions. However, in [14] it was shown
that storing all such patterns is not needed and that, somewhat surprisingly, this running time

Directed and undirected generalizations of Steiner Tree, such as Directed Steiner
Network, Group Steiner Tree, and Steiner Forest, have also been studied extensively
under these parameters. Examples include Steiner Forest parameterized by treewidth or
vertex cover [16], Group Steiner Tree parameterized by treewidth [10], and Directed
Steiner Tree parameterized by the treewidth of the solution network [17].
The most direct directed analogue of Steiner Tree is the following problem:
Strongly Connected Steiner Subgraph (SCSS)
Input: A directed graph D = (V, A), set of terminals T, and integer t.
Question: A set X ⊆A such that |X| ≤t and for each u, v ∈T there is a uv-path formed
by arcs of X.
We are interested in finding out which results that hold for Steiner Tree translate to the
directed setting of SCSS (and its variants). Since a solution of SCSS need not be a tree, the
problem is typically more complex than its undirected counterpart. Recall that, Steiner Tree
is FPT, whereas SCSS is W[1]-hard [23] and hence probably not FPT. On the positive side,
the problem can be solved in nO(|T|) time, i.e., it is XP parameterized by |T|.
The complexity of SCSS has been studied extensively from several perspectives. For ex-
ample, in the setting of planar graphs, parameterized sub-exponential time algorithms are
known for the problem [11, 17]. From the approximation point of view, there is an O(log2 n)-
approximation algorithm for SCSS, and this is tight in the sense that it is hard to approximate
with factor O(log2−ε n) [24].
Problems Related to SCSS.
To place our results in context, we also describe three
related problems. See Figure 1 for the relationships among them. First, setting T = V in
SCSS, we obtain the following problem:
Strongly Connected Spanning Subgraph (SCSpS)
Input: A directed graph D = (V, A), and an integer t.
Question: A set X ⊆A such that |X| ≤t and (V, X) is strongly connected.
An instance of SCSpS is automatically a NO-instance if D is not strongly connected. If we
relax the requirement that D itself be strongly connected, we obtain the following problem:
Minimum Equivalent Graph (MEG)
Input: A directed graph D = (V, E), and an integer t.
Question: A set X ⊆E such that |X| ≤t and for each uv-path in D, there is a uv-path in
(V, X).
The problem is well-motivated, since one often wants to preserve all connectivity properties
while working with a sparser network. We refer to [2, Chapter 12] for more information on
SCSpS and MEG. It is shown in [2, Section 2.3] that a given instance (D, t) of MEG can be
solved in polynomial time provided that, for each strongly connected component Ci of D, one
is given a minimum-cardinality spanning subdigraph of D[Ci]. Hence an O∗(cn)-time (respec-
tively, O∗(ctw)-time) algorithm for SCSpS implies an O∗(cn)-time (respectively, O∗(ctw)-time)
algorithm for MEG.
In [20] it was shown that SCSpS (and hence, MEG) can be solved on n-vertex graphs in time
O(24ωnmn), where ω denotes the matrix multiplication constant. A randomized O∗(4n)-time
algorithm is given in [15].
We will show that our methods can also be used to address 2-connectivity constraints in
undirected graphs via the following problem:

1.1
Our results.
Treewidth Parameterization.
We first study the complexity of SCSS parameterized
by the treewidth of the underlying undirected graph. In light of the aforementioned surprisingly
efficient method that deals with undirected connectivity [8, 14], it is natural to wonder whether
a similar approach can be used to deal with strong connectivity as well. We show that, at least
for SCSS, this is indeed the case:
Theorem 1. There is a Monte Carlo algorithm that solves SCSS in O∗(17tw) time, where tw
is the treewidth of the underlying undirected graph of D.
As with the method of [14], our general idea can be applied to many problems and settings.
We expect that it also works for other local problems augmented with a strong connectivity
constraint.
To prove Theorem 1 we use the characterization that a directed graph D is strongly con-
nected if and only if, for an arbitrarily chosen vertex r, there exist both an in-branching and
an out-branching in D that are rooted at r. This characterization has been used in previous
related works as well [1, 20], but these works were only able to get 2O(n)-time algorithms. To
obtain our algorithm, we combine this characterization with the methods from [14] in a more
efficient, but still highly non-trivial, way.
Using the mentioned reductions, we obtain the following direct consequence of Theorem 1:
Corollary 1. There is a Monte Carlo algorithm that solves SCSpS, MEG and 2-ECSS in
O∗(17tw) time, where tw is the treewidth of the underlying undirected graph.

Exact Exponential Time Algorithm.
SCSS generalizes the problem of detecting a
Hamiltonian cycle in a directed graph. Improving exact exponential-time algorithms for Hamil-
tonian cycle is an active line of research; in particular, one seeks algorithms running in 1.999n
time on n-vertex graphs (see e.g. [6]).
Motivated by this line of work and the previously
mentioned exact exponential-time algorithms for Steiner Tree and MEG, we study exact
exponential-time algorithms for SCSS. Concretely, we prove the following:
Theorem 2. SCSS can be solved in O∗(2n) time.
While Theorem 1 used a characterization of strongly connected digraphs in terms of in/out-
branchings, Theorem 2 crucially relies on a characterization in terms of ear decompositions.
This is used in combination with a dynamic programming algorithm (over subsets of the vertex
set) and the fast subset convolution method from [5].
As before, we can use the aforementioned reductions to obtain the following corollary:
Corollary 2. The SCSpS, MEG and 2-ECSS problems on n-vertex graphs can be solved in
O∗(2n) time.
Our result not only significantly improves the previously mentioned O(24ωnmn)-time algo-
rithm for MEG from [20], but is also arguably much simpler.
Kernelization parameterized by Vertex Cover.
Finally, we investigate the complex-
ity of these problems under parameterization by the vertex cover of the input graph. Param-
eterization by the vertex cover of a graph is a popular topic in parameterized complexity. For
example, in [16] the authors studied the complexity of Steiner Forest parameterized by the
vertex cover of the input graph. We study the kernelization complexity of these problems, fol-
lowing earlier work on variants of the Traveling Salesperson Problem [7, 30]. Concretely,
we show:
Theorem 3. SCSpS admits a quadratic kernel parameterized by the vertex cover of the un-
derlying undirected graph, but SCSS does not admit a polynomial kernel parameterized by the
vertex cover of the underlying undirected graph unless NP ⊆coNP/poly.
The kernel is proved using matching arguments (via the expansion lemma from [19]) to
exploit the fact that, for every vertex outside the independent set, both an incident out-arc
and an incident in-arc must be selected. The conditional impossibility of a polynomial kernel
is proven via a reduction to Set Cover parameterized by the universe size.
Organization.
In Section 2 we prove Theorem 1. In Section 3 we prove Theorem 2, and
in Section 4 we prove Theorem 3. In Section 5 we provide directions for further research, and
in the Appendix A we give the postponed reduction.

The treewidth tw(T) of a tree decomposition T is the size of the largest bag of T minus one,
and the treewidth of a graph G is the minimum treewidth over all tree decompositions of G.
Dynamic programming algorithms on tree decompositions are often presented on nice tree
decompositions which were introduced by Kloks [26]. We present a slightly refined definition of
a nice tree decomposition of directed graphs from [14].
Definition 2 (Nice Tree Decomposition of Directed Graphs). A nice tree decomposition of a
directed graph is a tree decomposition with one special bag z called the root with β(z) = ∅and
in which each bag is one of the following types:
Leaf bag: a leaf x of T with β(x) = ∅.
Introduce vertex bag: an internal vertex x of T with one child vertex y for which β(x) =
β(y) ∪{v} for some v /∈β(y). This bag is said to introduce v.
Introduce arc bag: an internal vertex x of T labeled with arc from u to v with one child
bag y for which u, v ∈β(x) = β(y). This bag is said to introduce arc (u, v).
Forget bag: an internal vertex x of T with one child bag y for which β(x) = β(y) \ {v} for
some v ∈β(y). This bag is said to forget v.
Join bag: an internal vertex x with two child vertices l and r with β(x) = β(l) = β(r).
We additionally require that every arc is introduced exactly once.

Characterization via In-branching and Out-branching.
Definition 4. Given a directed graph D = (V, A) and a set of terminal vertices T, a Steiner
in-branching (respectively, out-branching) is a weakly connected subgraph B = (VB, AB) of D
that satisfies the following:
• T ⊆VB.
• There exists a unique vertex r ∈VB, called root, with out-degree (respectively, in-degree)
0.
• Every other vertex w ∈VB \ {r} has out-degree (respectively, in-degree) exactly 1.
We further call a subgraph eB a relaxed Steiner in-branching (respectively, out-branching) if it
satisfies the above degree conditions but is not necessarily weakly connected.
Given a directed graph D = (V, A) and terminals T ⊆V , we fix an arbitrary vertex r ∈T.
Definition 5. A Steiner in-branching Bin and a Steiner out-branching Bout are compatible if
they span the same vertex set, i.e., V (Brin) = V (Brout), and are both rooted at r.
We note that a solution of SCSS can always be decomposed to a pair of compatible Steiner
in-branching and out-branching.
2.2
Cut & Count
We first provide a high-level overview of our approach. In general, we assign random weights
over edges such that we can isolate a minimum-weight solution with constant probability. Then
we define a superset of solutions that can be locally computed, and we augment each candidate
solution with consistent cuts to distinguish true solutions.
The locality property makes it
possible to count the number of solutions modulo 2 efficiently, where isolation further plays a
role to decide the existence of a solution.

4.2
No Kernel for SCSS
Our goal is to show that SCSS, parameterized by the size of a vertex cover, does not admit a
polynomial kernel. In fact, we prove a stronger statement: it does not even admit a polynomial
compression.
Definition 11 (Polynomial compression, Definition 1.5 of [21]). Let Q ⊆Σ∗× N be a param-
eterized problem. A polynomial compression for Q is a polynomial-time algorithm that, given
an instance (x, k), outputs a string y ∈Σ∗such that (x, k) ∈Q ⇐⇒y ∈L for some language
L ⊆Σ∗, and |y| ≤p(k), for some polynomial p.
In other words, a polynomial compression reduces an instance of a parameterized problem to
an equivalent instance of some problem whose size is bounded polynomially in the parameter.
Since a polynomial kernel is a special case of a polynomial compression, ruling out polynomial
compressions also rules out polynomial kernels.
To transfer compression lower bounds, we use polynomial parameter transformations.
Definition 12 (Polynomial parameter transformation (PPT), Definition 19.1 of [21]). Let
Q, Q′ ⊆Σ∗× N be parameterized problems.
A polynomial parameter transformation from
Q to Q′ is a polynomial-time algorithm that maps any instance (x, k) of Q to an instance
(x′, k′) of Q′ such that
(x, k) ∈Q ⇐⇒(x′, k′) ∈Q′ and k′ ≤p(k), for some polynomial p.
The importance of PPT reductions lies in their ability to propagate lower bounds.
Lemma 7 (Theorem 19.2 of [21]). Let Q and Q′ be parameterized problems such that Q ≤ppt Q′.
If Q does not admit a polynomial compression unless NP ⊆coNP/poly, then neither does Q′.
Therefore, to prove that SCSS parameterized by vertex cover does not admit a polynomial
kernel, we show that there is a PPT reduction from Set Cover parameterized by the universe
size. In order to prove this, we make use of the fact that Set Cover parameterized by the
universe size does not have a polynomial compression (See [29] or Theorem 19.5 in [21]).

Future Research Directions
In this paper we gave new algorithms for SCSS and related problems. We believe there are
ample directions for further research and outline some of them now.
First of all, it is natural to investigate how well our method works for problems involv-
ing p-edge-connectivity, which can be approached with a similar characterization via in/out-
branchings [1]. For example, how fast can the p-ECSS problem be solved parameterized by the
treewidth (see [1] for a problem definition)?
Another natural question is to get ”Strong ETH-tight” algorithms for SCSS. Something
that has been achieved for many natural problems (see e.g. [28]).
Open Question 1. Find a O∗(ctw) time algorithm for SCSS and a proof that a O∗((c −ε)tw)
time algorithm for any ε > 0 refutes the Strong Exponential Time Hypothesis.
A probably easier version of Question 1 is obtained by replacing tw with the pathwidth of
the graph. To attack this question, we believe the following combinatorial question is central:
Open Question 2. Let (V, A) be a complete directed graph and let A1, . . . , Aℓ⊆A and
B1, . . . , Bℓ⊆A such that (V, Ai ∪Bj) is strongly-connected if and only if i = j. How large
can ℓbe in terms of |V |?
The quantity ℓabove coincides with the largest induced matching of the compatibility matrix
associated with the SCSS problem (see e.g. [32] for definitions), and it is natural to conjecture
a close connection of it with the complexity of SCSS parameterized by pathwidth:
Conjecture 1. If ℓ= θ(c|V |) in Question 2, then SCSS can be solved in (c + 1)pw time and
not in (c + 1 −ϵ)pw, assuming SETH.
Note that, in the above conjecture the +1 is because vertices can also not participate in the
solution.
In the 2VCSS problem one is given an undirected graph and seeks a subgraph with minimum
number of edges that is 2-vertex connected. We leave the following problem open:

Open Question 3. Can the 2-VCSS problem be solved in O∗(cO(tw)) time?
Finally, it is natural to further study the exact exponential time complexity of the problems
studied in this paper.
Open Question 4. Can 2-ECSS be solved in O∗((2 −ε)n) time, for some ε > 0?
Since 2-ECSS generalizes the Hamiltonicity problem on undirected graphs, such an al-
gorithm probably needs randomization and algebraic techniques such as the ones from [4].

Reducing 2-ECSS to SCSpS
Lemma 8. An instance (G = (V, E), t) of the 2-ECSS problem can be reduced to an equivalent
instance of the SCSpS problem (D = (V, A), t) by adding for each edge {u, v} ∈E with the two
arcs (u, v) and (v, u) to A.

Proof. If G is not 2-edge connected, then the instance is trivially a no-instance, so assume
that G is 2-edge connected. The forward direction follows from Robbins’ theorem: every 2-
edge connected spanning subgraph admits a strongly connected orientation. For the converse
direction, consider a minimum strongly connected spanning subdigraph of D whose underlying
undirected graph has the minimum number of bridges.
If the underlying undirected graph
has a bridge e, then both orientations of e must be used. Since the original graph is 2-edge
connected, there is another edge crossing the same cut. Replacing one orientation of e by a
suitable orientation of that edge preserves strong connectivity and decreases the number of
bridges, a contradiction. Hence the graph is bridgeless, that is, 2-edge connected.
