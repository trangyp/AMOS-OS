Abstract
Reduced parameters [BKW, JCTB ’26; BKRT, SODA ’22] are defined via contraction se-
quences. Based on this framework, we introduce the reduced component max-leaf, denoted by
cml↓, where component max-leaf is the maximum number of leaves in any spanning tree of
any connected component. Reduced component max-leaf is strictly sandwiched between clique-
width and reduced bandwidth, it is bounded in unit interval graphs, and unbounded in planar
graphs. We design polynomial-time algorithms for problems such as Maximum Independent
Set, Maximum Clique, Maximum Induced d-Regular Subgraph, and Induced Dis-
joint Paths in graphs given with a contraction sequence witnessing low cml↓, unifying and
extending tractability results for classes of bounded clique-width and unit interval graphs.
We get the following collapses in sparse classes of bounded cml↓: bounded maximum degree
implies bounded treewidth, whereas Kt,t-subgraph-freeness implies strongly sublinear treewidth;
we show the latter, more generally, for classes of bounded reduced cutwidth. We establish the
former result by showing that graphs with bounded cml↓admit balanced separators dominated
by a bounded number of vertices. In contrast, there are graphs G of arbitrarily large girth and
treewidth Θ(|V (G)|1/2) such that cml↓(G) ⩽3.
We then showcase an application of the reduced parameters to establishing non-transducibility
results. We prove that for most reduced parameters p↓(including reduced bandwidth), the fam-
ily of classes of bounded p↓is closed under first-order transductions. We then answer a question
of [BKW ’26] by showing that the 3-dimensional grids have unbounded reduced bandwidth. As
the class of planar graphs (or any class of bounded genus) has bounded reduced bandwidth
[BKW ’26], this reproves a recent result [GPP, LICS ’25] that planar graphs do not first-order
transduce the 3-dimensional grids.

Introduction
Contraction sequences1 associate n-vertex graphs with sequences of n graphs of ever smaller vertex
count, called red graphs. Twin-width [14] is the first parameter to be defined via contraction se-
quences, as the largest maximum degree of the red graphs, minimized over all contraction sequences.
The so-called reduced parameters, introduced in [15, 13], generalize the link between maximum de-
gree ∆and twin-width: For any graph parameter p, reduced-p, denoted by p↓, is the largest p
over all red graphs of the contraction sequence, minimized among all contraction sequences. Every
graph admits a contraction sequence where each red graph consists of a star and isolated vertices.
So, p↓is only relevant when bounded p implies bounded maximum degree. The interesting reduced
parameters are thus less general than twin-width.2 We denote it by p ⊏q if every class of bounded
q has bounded p, but not vice versa.
If p = ⋆is the size of a largest connected component, then p↓is tied to clique-width [13, 2].
Thus, by the Courcelle–Makowsky–Rotics theorem [20] monadic second-order logic (with modular
counting) can be efficiently model-checked in classes of bounded ⋆↓, whereas first-order model
checking is tractable in classes of effectively3 bounded ∆↓, i.e., twin-width [14]. This suggests the
following line of work:
For parameters p with ∆⊏p ⊏⋆, design polynomial algorithms for a strict superset of
the problems definable in first-order logic on graphs of effectively bounded p↓.
Arguably the easiest-to-formulate graph problem that cannot be expressed in first-order logic is
Maximum Independent Set, which on graph G seeks maxX⊆V (G) |X| subject to the formula
∀x, y ∈X, ¬E(x, y). It is thus reasonable to expect that the superset contains this problem.
There are two main families of graphs with bounded twin-width on which Maximum Inde-
pendent Set remains NP-hard: planar graphs [14, 31] and f(n)-subdivisions of n-vertex graphs
with 2 log n ⩽f(n) ⩽nO(1) [4, 11]. In the work explicitly introducing the reduced parameters [15],
the focus is on reduced bandwidth. The main result is that planar graphs have bounded reduced
bandwidth; so do (⩾n)-subdivisions of n-vertex graphs. Since many problems, like Maximum
Independent Set, remain NP-hard on planar graphs, the parameter p we consider cannot be as
general as bandwidth.
An attempt is stretch-width [10], which, while strictly speaking not a reduced parameter, is
strongly inspired by this framework. Classes of bounded stretch-width generalize those of bounded
clique-width, and fittingly do not contain the class of planar graphs or of polynomial subdivisions.
However it is currently open whether Maximum Independent Set can be solved in polynomial
time in every class of bounded stretch-width (even with a witness of low stretch-width). Partial
results comprise a 2 ˜O(n4/5)-time algorithm, and a polynomial-time algorithm when the maximum
degree is also bounded.
In this paper, we introduce the component max-leaf parameter, denoted by cml, the least
integer k such that every spanning tree of every connected component has at most k leaves, and
its reduced counterpart cml↓. Connected graphs have bounded component max-leaf if and only
if they are subdivisions of graphs of bounded size (see for instance [47, Theorem 4.7]). We have
bandwidth ⊏cml ⊏⋆, which sets cml↓in the “right” regime.

Since graphs of twin-width at most 2 have bounded cml↓, unit interval graphs—which have twin-
width at most 2 [12] and unbounded clique-width—testify that cml↓is strictly more general than
clique-width. We actually prove that unit interval graphs have unbounded stretch-width, which
is consistent with the conjecture that classes of bounded stretch-width have at most logarithmic
clique-width [10] (as there are n-vertex unit interval graphs with clique-width Ω(√n)).
We show in Theorem 3.4 that every graph G with cml↓(G) = k admits a balanced separator
dominated by at most k(k + 2) vertices. This implies that every graph G with maximum degree ∆
and cml↓(G) = k has treewidth O(∆k2). Since planar graphs of arbitrarily large treewidth admit
arbitrarily large subdivided walls or their line graphs as induced subgraphs [1, Theorem 1.1], this
establishes the following fact.
Theorem 1.1. A class of planar graphs has bounded treewidth if and only if it has bounded cml↓.
We exhibit weakly sparse (i.e., without Kt,t subgraph for some fixed integer t) classes of bounded
cml↓and polynomially large treewidth. More precisely, for every positive integer g, there is an
infinite family of n-vertex graphs G of girth at least g and treewidth Θg(√n) such that cml↓(G) ⩽3.
On the other hand, we show that weakly sparse classes of bounded cml↓(even of bounded reduced
cutwidth) have polynomial expansion. Thus, their n-vertex subgraphs have treewidth O(nβ) for
some constant β < 1. This answers a question in [15].
Theorem 1.2. Weakly sparse classes of bounded reduced cml↓(even of bounded reduced cutwidth)
have polynomial expansion.
Exponential subdivisions of grids have unbounded cml↓by Theorem 1.1, but bounded stretch-
width [10]. This gives the other direction for the incomparability of cml↓and stretch-width. We
show that these parameters are also incomparable to mim-width [46], another (moderate) general-
ization of clique-width lending itself to algorithmic meta-theorems [18, 7, 6].
Theorem 1.3. Reduced component max-leaf, stretch-width, and mim-width are all incomparable.
We then design polynomial-time algorithms on graphs of effectively bounded cml↓for a family of
problems containing Maximum Independent Set. Fix some finite set σ of non-negative integers.
Let σ-Neighborhood be the problem, given a graph G, of finding a maximum-cardinality subset
S ⊆V (G) such that every v ∈S has a number of neighbors in S that is in σ. Setting σ = {0}
defines Maximum Independent Set, while σ = {1} defines Maximum Induced Matching.
This framework was first proposed by Telle and Proskurowski [45].
Theorem 1.4. There is an algorithm that, given an n-vertex graph G and a contraction sequence
witnessing that cml↓(G) ⩽t, solves σ-Neighborhood on G in time nO(tα2) with α = max(σ).
Bonnet et al. [12] proved that Maximum Independent Set can be solved in polynomial
time on graphs of twin-width at most 2, provided that a contraction sequence of width 2 is given
as part of the input.
Since graphs of twin-width at most 2 have reduced component max-leaf
at most 2, Theorem 1.4 generalizes this result. Bui-Xuan, Telle, and Vatshelle [18] showed that
the σ-Neighborhood problem is polynomial time solvable on classes of effectively bounded mim-
width, for any finite or cofinite set σ.
We also consider a connectivity problem, namely the Induced Disjoint Paths problem, where,
given a set of pairs, the task is to find a set of paths connecting the pairs such that no two paths
share a vertex or have adjacent vertices. This problem is known to be polynomial-time solvable on
classes of effectively bounded mim-width [33]. We obtain a polynomial-time algorithm for classes of
effectively bounded cml↓. Using this algorithm together with a simple reduction (see [33]), one can
solve in polynomial time H-Induced Subdivision Containment, that is, the problem of finding
an induced subdivision of a fixed graph H.

Let N denote the set of positive integers. For an integer n, let [n] denote the set of all positive

Given two graph parameters p, q, we write p ⊑q if there is a function f such that for every
graph G, p(G) ⩽f(q(G)). Then, p, q are tied if p ⊑q and q ⊑p, and incomparable if both p ⊑q
and q ⊑p fail. We write p ⊏q when p ⊑q holds but q ⊑p does not, and may say that q is larger
than p.
For two disjoint subsets X and Y of vertices of a graph G,

• X is anti-complete to Y in G if for all x ∈X, y ∈Y , x is not adjacent to y,
• X and Y are homogeneous in G if X is complete or anti-complete to Y in G.

2.2
Max-leaf and component max-leaf
The max-leaf of a connected graph G, denoted by ml(G), is the minimum k such that every
spanning tree of G has at most k leaves. Although we will not use this fact directly, it follows from

a result of Zickfeld [47, Theorem 4.7] that a connected graph G has bounded max-leaf if and only
if G has bounded maximum degree and a bounded number of vertices with degree different from 2,
or in other words if and only if G is a subdivision of a graph of bounded size.
The component max-leaf of G, denoted by cml(G), is the minimum k such that every connected
component of G has max-leaf at most k. We consider that the 1-vertex graph counts as a tree with
one leaf, so that when G is an edgeless graph, cml(G) = 1.

induced subgraphs of a graph with small component max-leaf. The next two properties are crucial
to establish the runtime of these algorithms.
Lemma 2.1. Let G be a graph with component max-leaf t, and let H be a connected subgraph of G.
Then |NG(V (H))| ⩽t.
Proof. For the sake of contradiction, assume that |NG(V (H))| ⩾t + 1. Let T be a spanning tree
of H. Let T ′ be a subgraph obtained from T by adding, for each vertex v ∈NG(V (H)), an edge
between v and its neighbor in T. Since each vertex in NG(V (H)) is attached to T by a single
edge, T ′ is still a tree. Moreover, each vertex in NG(V (H)) is a leaf in T ′. Hence, T ′ has at least
t + 1 leaves. Finally T ′ can be extended to a spanning tree of the connected component of G
containing H, which must still have at least t + 1 leaves, a contradiction.
Note that when taking H to be a single vertex, Lemma 2.1 shows that a graph G with cml(G) = t
has maximum degree at most t.

2.3
Bandwidth and cutwidth
The bandwidth of a graph G is the minimum k ∈N∪{0} such that there is an ordering v1, . . . , vn of
V (G) satisfying |i −j| ⩽k for every edge vivj ∈E(G). The cutwidth of a graph G is the minimum
k ∈N ∪{0} such that there is an ordering v1, . . . , vn of V (G) satisfying that for each i ∈[n −1],
there are at most k edges between {vj : j ∈[i]} and V (G) \ {vj : j ∈[i]}.

First-order formulas on graphs are formulas constructed from quantifiers ∀x, ∃y on vertices,

Conclusion
We provide polynomial-time algorithms for σ-Neighborhood and Induced Disjoint Paths on
classes of effectively bounded cml↓. We may consider other problems. Telle and Proskurowski [45]
considered a more general problem called the (σ, ρ)-Problem, in which it is further required
that, for every vertex v outside a desired set S, the number of neighbors of v in S belongs to ρ.
Dominating Set is such a problem, which is (Min) (N, N \ {0})-Problem. Also, the Feedback
Vertex Set and 3-Coloring problems are natural candidates to consider.
We suspect that
Dominating Set and 3-Coloring are NP-hard on some classes of effectively bounded reduced
component max-leaf. On the other hand, it seems more plausible that the Feedback Vertex Set
problem admits a polynomial-time algorithm on classes of graphs with effectively bounded reduced
component max-leaf.
They can be solved in polynomial time on classes of effectively bounded
mim-width [18, 34, 8].
Gartland and Lokshtanov [29, Conjecture 1.4.2] conjectured that 3-Coloring and (tw ⩽
r, ψ)-Max Weighted Induced Subgraph, which generalizes Feedback Vertex Set, are
polynomial-time solvable on classes that exclude a fixed planar graph H as an induced minor.
By Corollary 3.5, every class of bounded cml↓excludes some wall as an induced minor. Thus,
showing that 3-Coloring is NP-hard on some class of graphs with effectively bounded reduced
component max-leaf would refute the above conjecture for 3-Coloring.
The Disjoint Paths problem asks for a set of vertex-disjoint paths connecting given pairs,
without requiring that there are no edges between the paths. Since it is known to be NP-hard on
interval graphs [37], we cannot expect to solve it in polynomial time on classes of bounded mim-
width. However, the class of interval graphs has unbounded reduced component max-leaf. Thus,
it remains open whether the Disjoint Paths problem can be solved in polynomial time on classes
of graphs with effectively bounded cml↓.
Our algorithms are all based on assuming that a contraction sequence is given. We ask whether
there is an XP-time (or even an FPT-time) approximation algorithm that, given a graph G and an
integer d, either outputs a contraction sequence of cml↓(G) ⩽f(d) for some function f or correctly
reports that cml↓(G) > d. For twin-width, Berg´e, Bonnet, and D´epr´es [5] showed that deciding
whether a graph has twin-width at most 4 is NP-complete, which rules out the possibility of an
XP-time exact algorithm for testing whether the twin-width is at most k.
