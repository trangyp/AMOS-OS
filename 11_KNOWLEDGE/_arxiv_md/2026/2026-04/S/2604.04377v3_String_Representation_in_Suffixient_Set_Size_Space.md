Abstract
Repetitiveness measures quantify how much repetitive structure a string contains and serve as param-
eters for compressed representations and indexing data structures. We study the measure χ, defined as
the size of the smallest suffixient set. Although χ has been studied extensively, its reachability, whether
every string w admits a string representation of size O(χ(w)) words, has remained an important open
problem. We answer this question affirmatively by presenting the first such representation scheme. Our
construction is based on a new model, the substring equation system (SES), and we show that every
string admits an SES of size O(χ(w)).
1
Introduction
Repetitiveness measures aim to quantify how much repetitive structure a string contains.
They offer a
unified way to compare strings and to reason about the space usage of compressed representations. Beyond
repetitiveness measures that arise directly from compression techniques, such as LZ-style parsing [16] and the
run-length encoded Burrows–Wheeler transform [2], repetitiveness measures that are not derived from any
specific compression technique have been proposed, notably string attractors [8] and normalized substring
complexity [10]. These measures are widely used to analyze the size of existing compressed representations
and indices, and they provide convenient parameters for stating space bounds for both representations and
indexing data structures [12].
Reachability is a central notion for assessing the power of a repetitiveness measure. A repetitiveness
measure f is reachable if there exists a representation scheme that, for every string w, encodes w in O(f(w))
machine words, i.e., O(f(w) log |w|) bits. If f is reachable, then it can be used directly as a compressed
representation. If f is not reachable, then f will strictly lower-bound the space of any universal representation
scheme for some (infinite) subset of strings.
Recently, suffixient sets [5] have been proposed as a repetitiveness measure not derived from any particular
compression scheme.
They were first introduced to support efficient random access and related queries
together with compressed indexing in small space, and have since been studied in the context of space-
efficient string indexes [3]. Owing to a one-to-one correspondence with super-maximal right extensions, the
size of the smallest suffixient set, denoted by χ, can be computed in linear time in the text length, and it
has attracted attention as an easily computable repetitiveness measure [4, 14].
Existing results already place χ among the central repetitiveness measures [14]. For example, it is known
that χ(w) ≤2r(w) for every string w, where r is the number of runs in the Burrows–Wheeler transform [2],

the same size, SES provides a unifying framework for several standard compression schemes that are known
to be expressible as BMS.

Preliminaries
Let Σ be an alphabet of size σ. An element of Σ is called a character. A string w of length |w| = n over the
alphabet Σ is a sequence w[1] · · · w[n] of characters where w[i] ∈Σ for all 1 ≤i ≤n.
For any two strings x and y, we denote by xy = x[1] · · · x[|x|]y[1] · · · y[|y|] the concatenation of x and y.
For any string x, we denote by xR = x[|x|] · · · x[1] its reversal. If w = xyz holds for some strings x, y, z ∈Σ∗,
then x, y, and z are called a prefix, a substring, and a suffix of w, respectively. For 1 ≤i ≤j ≤n, we denote
by w[i..j] = w[i] · · · w[j] the substring of w from position i to j, and w[i..j) = w[i..j −1]. For convenience
w[i..j] is the empty string when j < i. We will assume that the string w is terminated by an end of string
symbol denoted by $, which does not occur elsewhere in the string. For every string w, we denote by σ(w)
the number of distinct characters appearing in w, including the special character $.
For any x ∈Σ∗and c ∈Σ, xc is a right extension in w if xc is a substring of w and for some c′ ̸= c,
xc′ is also a substring of w. A right extension in w is super-maximal if it is not a proper suffix of another
right extension in w. The set of all right extensions and super-maximal right extensions in w is denoted by
RE(w) and SRE(w), respectively.
Existing work establishes a one-to-one correspondence between smallest suffixient sets and super-maximal
right extensions [3, 4]. Using the notation of Navarro et al. [14], we adopt the following definitions.
Definition 1. For a string w of length n, a set S ⊆[1..n] is a suffixient set for w if for every right extension
x ∈RE(w) there exists j ∈S such that x is a suffix of w[1..j].
Definition 2. For a string w of length n, a set S ⊆[1..n] is a smallest suffixient set for w if there exists
a bijection pos : SRE(w) →S such that every super-maximal right extension x ∈SRE(w) is a suffix of
w[1..pos(x)].
The repetitiveness measure χ is defined as χ(w) = |SRE(w)|. By the above definition, χ(w) is exactly
the size of a smallest suffixient set for w.

Substring Equation System
A substring equation system specifies constraints of two types on an unknown string w of length n: substring
equalities of the form w[i..i + ℓ−1] = w[j..j + ℓ−1], and character assignments of the form w[k] = c. There
exists an O(n)-time algorithm that decides satisfiability and uniqueness of a substring equation system and,
if the system is satisfiable, outputs a string w ∈Σn satisfying all constraints [7]. When the satisfying string
is unique, the system can be viewed as a compact representation of the string. We formalize the substring
equation system as follows.
Definition 3 (Substring equation system (SES)). An instance of a substring equation system for a string
w ∈Σn is a triple (n, Eq, Ch), where n is the length of w, Eq is a finite set of substring-equality constraints,
and Ch is a finite set of character-assignment constraints.
Each element of Eq is a triple (i, j, ℓ) with
1 ≤i, j ≤n and 1 ≤ℓ≤n −max{i, j} + 1, representing the equation w[i..i + ℓ−1] = w[j..j + ℓ−1]. Each
element of Ch is a pair (k, c) with 1 ≤k ≤n and c ∈Σ, representing the equation w[k] = c. We say that
(n, Eq, Ch) represents w if w satisfies all constraints in Eq and Ch and w is the unique string in Σn satisfying
them. The size of the system is defined as |Eq| + |Ch|.
Note that without loss of generality, we can assume that ℓ≥2 for any (i, j, ℓ) ∈Eq.
Analogously to other compression-based repetitiveness measures, we define s(w) as the minimum size of
an SES that represents w.
SES can be seen as a flexible way of expressing copy–paste constraints between substrings.
In this
sense, they generalize classical directed copy–paste representations such as bidirectional macro schemes
(BMS). BMS first fixes a parsing into phrases and gives each copied phrase one directed pointer to a source
interval, whereas SES specifies only substring-equality constraints. Accordingly, SES does not require an
explicit partitioning of the string into phrases, and its constraints are stated as undirected equalities between
substrings. In particular, every valid BMS can be converted into an SES of the same size.
Theorem 4. For every string w ∈Σn and every valid bidirectional macro scheme for w with k phrases,
there exists a substring equation system (SES) of size k that represents w.

Proof. Let f1 · · · fk be a valid bidirectional macro scheme for w. For each phrase fi, let [ai..bi] be its interval
in w. If fi is stored explicitly as a character c, then we add the character constraint (ai, c) to Ch. Otherwise
fi is represented by a pointer (p, ℓ) with ℓ= bi−ai+1, meaning that w[ai..bi] = w[p..p+ℓ−1]; in this case we
add the substring-equality constraint (ai, p, ℓ) to Eq. Let (n, Eq, Ch) be the resulting SES. By construction,
w satisfies all constraints and the size of the SES is |Eq| + |Ch| = k.
It remains to show that the string satisfying all constraints is unique. Consider the transition function τ
induced by the macro scheme. Every substring-equality constraint (at, p, ℓ) implies that for each 0 ≤q < ℓ
we have τ(at + q) = p + q, while every character constraint (at, c) corresponds to τ(at) = ⊥. Because the
macro scheme is valid, the directed graph on positions induced by τ is acyclic and every position reaches
some position with τ = ⊥. Take any topological order of this graph. In this order, each position either has an
explicit character constraint fixing its value, or it is constrained to be equal to a position that appears earlier
in the order. Thus, by induction along the order, the character at every position is uniquely determined.
Hence, (n, Eq, Ch) represents w.
The inequality s(w) ≤b(w) follows immediately from Theorem 4. Conversely, it is currently unclear
whether every SES can be transformed into a bidirectional macro scheme of comparable size.
To recapitulate, SES defines an undirected referencing graph where the nodes are the positions in the
string, and edges are explicit equivalences specified by the equations. On the other hand, the edges of BMS
are directed, where each position (that is not an explicit phrase) has an edge pointing to a source position.
We may also consider a directed version of SES, where each “equation” is directed as in BMS. It is easy to
see that smallest size s′(w) of such a directed SES that represents a string w is within a constant factor of
s(w): any directed SES can trivially be made undirected, and any undirected SES can be made directed by
making two directed “equations” per undirected equation.
A directed SES can be viewed as a relaxed version of BMS where: 1) phrases need not be a partition
of the original string, but may overlap, implying that a position may have multiple sources as long as they
are consistent, and 2) there can by cycles in the referencing graph, as long as there is a directed spanning
forest where positions corresponding to elements in Ch are roots. We conjecture that SES, and therefore
such relaxed version of BMS is strictly more powerful than the standard BMS, i.e., there exists an infinite
family of strings {wn}n≥1 such that s(wn) = o(b(wn)) as n →∞.
On the other hand, it can be shown that s(w) is lower bounded by γ(w) for every string w, within a
constant factor.
Theorem 5. For every string w, γ(w) ≤4s(w).
Proof. Given any (including a smallest) SES that represents a string w, consider the set of positions S
consisting of the positions corresponding to each element of Ch, and the four endpoints of the two substrings
for each substring equation in Eq. By construction, |S| = 4|Eq| + |Ch|. We claim that S is a string attractor
of w, which implies γ(w) ≤4s(w).
Consider an occurrence of a substring x of w, that does not contain any position in S. Next, consider all
occurrences of x that are implied by the substring equations, i.e., the closure of occurrences of x obtained by
substring equations that contain the corresponding occurrences of x. If none of these occurrences contain a
position in S, this implies that none of the symbols in all the copies of x can be recovered, contradicting that
the SES represents w. Therefore, at least one occurrence of x must contain a position in S, and therefore,
S is a string attractor of w.

String Representation Based on Suffixient Sets
In this section, we propose the first string representation scheme that uses O(χ(w)) machine words for every
string w.
Our strategy proceeds in three steps. We start by defining a position-equivalence relation based on super-
maximal right extensions, which are in one-to-one correspondence with the elements of a smallest suffixient
set. We then show that the resulting equivalence classes correspond to the distinct characters in the text,
and thus their number is σ(w) ≤χ(w). Finally, we encode the relation using O(χ(w)) substring-equality
constraints and σ(w) character assignments, obtaining an SES of total size O(χ(w)) representing w.
We first define an equivalence relation ≡χ over positions [1..n] of w ∈Σn as follows:
Definition 10 (position equivalence by suffixient sets). For any pair of super-maximal right extensions yxc
and zxc′ where y, z ∈Σ∗, c, c′ ∈Σ, and x ∈Σ+ is the longest common suffix of yx and zx, let w[i..i+|x|−1]
be the occurrence of x in the leftmost occurrence of yxc in w, and let w[i′..i′ + |x| −1] be the occurrence of
x in the leftmost occurrence of zxc′ in w. Then, i + k ≡χ i′ + k for all 0 ≤k < |x|.
Intuitively, Definition 10 declares positions equivalent when they lie in the common-suffix part of the
leftmost occurrences of two super-maximal right extensions, ignoring the final extending character. Note
that in the above definition, we have chosen the leftmost occurrence of each super-maximal right extension
to simplify the exposition, but the choice can be arbitrary.
Lemma 11. If u = w[i..i + |u| −1] is a right extension with a unique occurrence, then there exists 1 ≤j ≤i
such that w[j..i + |u| −1] is a super-maximal right extension.
Proof. Let j be the smallest value such that w[j..i + |u| −1] = xu is a right extension.
If xu is not a
super-maximal right extension, there must be some other right extension v = yxu having xu as a proper

Lemma 13. For any repeating substring u of w and any pair of occurrences u = w[i..i + |u| −1] = w[i′..i′ +
|u| −1], i + k ≡χ i′ + k for all 0 ≤k < |u|.
Proof. Proof by induction on the length of u in decreasing order. Let u be a longest repeating substring of
w. Then w[i + |u|] ̸= w[i′ + |u|], and both w[i..i + |u|] and w[i′..i′ + |u|] are right extensions that have a
unique occurrence in w.
It follows from Theorem 11 that for some 1 ≤j ≤i, 1 ≤j′ ≤i′, w[j..i + |u|] and w[j′..i′ + |u|] are super-
maximal right extensions. Since their occurrences are unique, they are leftmost occurrences. Therefore, it
holds that i + k ≡χ i′ + k for all 0 ≤k < |u| by Theorem 10.
Now, suppose that the statement holds for any repeating substring longer than u. Let uc = w[i..i + |u|]
and uc′ = w[i′..i′ +|u|]. If c = c′, then uc = uc′ is a repeating substring longer than u and thus i+k ≡χ i′ +k
for all 0 ≤k ≤|u| holds from the induction hypothesis. Otherwise, c ̸= c′ and thus uc and uc′ are right
extensions. If the occurrence of both uc and uc′ are unique, then Theorem 11 again implies that uc and
uc′ respectively occur as suffixes of uniquely occurring super-maximal right extensions (which are leftmost
occurrences) and therefore i + k ≡χ i′ + k for all 0 ≤k < |u| by Theorem 10.
If uc is a repeating substring, then by the induction hypothesis the following holds: for any occurrence
uc = w[i′′..i′′ + |u|], we have i + k ≡χ i′′ + k for all 0 ≤k ≤|u|. In particular, this applies to the occurrence
of uc in the leftmost occurrence of a super-maximal right extension that has uc as a suffix, whose existence
follows from Theorem 12. The same argument applies to uc′. Therefore, by Theorem 10 and transitivity,
i + k ≡χ i′ + k holds for all 0 ≤k < |u|.
As a result, the following statement holds immediately by applying Theorem 13 to substrings of length
1.
Corollary 14. For any string w ∈Σn and any i, j ∈[1..n], we have i ≡χ j ⇐⇒w[i] = w[j]. In particular,
the equivalence classes of ≡χ are in one-to-one correspondence with the distinct characters of w, and thus
the number of classes is σ(w).
We are now ready to prove that χ is reachable.
Theorem 15. For any string w, there exists an O(χ(w))-word representation (an SES of size O(χ(w)), and
hence s(w) ∈O(χ(w))) which can be computed in linear time assuming a linearly sortable alphabet.
Proof. We first show that ≡χ can be represented by an O(χ(w)) size SES for w.
By Corollary 14, the equivalence classes of ≡χ coincide with the character classes of w. Thus, it suffices
to store (i) the equivalence relation ≡χ itself and (ii) a mapping from each equivalence class to its character,
which can be done by storing one representative position (e.g., the leftmost occurrence) for each character.
Since σ(w) ≤χ(w), this mapping takes O(χ(w)) words, so it remains to show that ≡χ can be represented
in O(χ(w)) space.
The equivalence relation can be encoded as a reverse compacted trie of the following set of strings:
{xR | xc ∈SRE(w), c ∈Σ}, where each node corresponding to xR stores the leftmost occurrences of the
super-maximal right extensions {xc | xc ∈SRE(w), c ∈Σ}, and each edge is labeled by its length. Figure 2
shows an example of this trie representation. It is clear that the size of the trie is O(χ). For any two
super-maximal right extensions yxc and zxc′, the positions corresponding to the respective occurrences of x
in the leftmost occurrences of yxc and zxc′ can be determined from the information in the nodes, and the
lengths of the paths. Thus, the equivalence relation can be retrieved.
7


## Page 8


We next show how to encode this trie as an SES. Fix an arbitrary ordering of children at each trie node,
and consider the resulting depth-first traversal order according to this child ordering. In that order, list all
super-maximal right extensions by visiting each node and collecting the extensions associated with that node.
For each consecutive pair in the list, we add one substring-equality constraint as in Definition 10, using the
common-suffix substring induced by the lowest common ancestor of the corresponding nodes. This produces
exactly χ(w) −1 substring-equality constraints. We also add σ(w) character-assignment constraints, one for
each distinct character. Figure 3 shows an example of the resulting SES.
It remains to argue that these constraints induce the same position equivalence as ≡χ. Take any two
entries in the list and consider the common suffix x determined by their lowest common ancestor. Among
entries between them in list order, every adjacent pair yields a constraint whose associated common suffix
has x as a suffix. Therefore, by applying transitivity along this chain of adjacent pairs, the induced position-
equivalence relation makes corresponding positions in the two occurrences of x equivalent. In other words,
corresponding positions in the two occurrences of x belong to the same equivalence class. Hence the SES
implies all equalities of ≡χ. Thus, we obtain an SES of size χ(w) −1 + σ(w) ∈O(χ(w)) that represents w.
Finally, we analyze the time complexity for constructing the SES representation. SRE can be computed
in linear time [4]. Furthermore, the reverse compacted trie is essentially a sub-tree of the suffix tree of wR$,
where the suffix tree is truncated and pruned below the positions in the suffix tree corresponding to xR with
xc ∈SRE(w) for some x and c. The suffix tree can be computed in linear time [6], all the positions of xR
in the suffix tree can be identified in linear time (e.g. Lemma 7.2 of [9]), and the pruning can be done in
linear time by a simple depth-first traversal. The conversion from the reverse compacted trie to an SES is
also another depth-first traversal and can be done in linear time.

5
Conclusion
In this paper, we proved the reachability of χ by presenting the first string representation scheme that
encodes any string in O(χ(w)) words. To establish this result, we focused on substring equation systems
(SES) and showed that every string admits an SES of size O(χ(w)). An important direction for future work
is to clarify the exact gap between BMS and equality-based representations. Two natural open questions
are whether there exist strings with s(w) ∈o(b(w)) and whether there exist strings with χ(w) ∈o(b(w)).
In particular, establishing the existence of strings with s(w) ∈o(b(w)) would show that SES is a genuinely
stronger compression scheme than BMS, and would further underscore the importance of studying SES.
