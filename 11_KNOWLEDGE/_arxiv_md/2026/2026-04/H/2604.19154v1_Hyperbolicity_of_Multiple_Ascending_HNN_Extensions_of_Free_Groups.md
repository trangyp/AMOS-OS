Abstract. Bestvina-Feighn-Handel show that for finitely many generic and
independent hyperbolic automorphisms φ1, · · · , φr of Fn, the resulting exten-
sion Fn ⋊Fr is hyperbolic. This paper generalizes the above statement to the
case where φ1, · · · , φr are hyperbolic non-surjective endomorphisms of Fn. In
our case the output is a multiple HNN extension associated to a graph with
one vertex and r edges. All edge and vertex groups are isomorphic to Fn.

1. Introduction
Thurston [14] proved that the interior of the mapping torus Mf of a hyper-
bolic surface S with homeomorphism f : S →S admits a finite-volume hyperbolic
structure if and only if f is isotopic to a pseudo-Anosov homeomorphism.
Motivated by Thurston’s result, Bestvina and Feighn showed that if G is a word-
hyperbolic group and φ : G →G is a hyperbolic automorphism, then the associated
mapping torus G⋊φZ is word-hyperbolic [1]. Subsequently, Brinkmann proved that
atoroidal automorphisms of free groups—namely, automorphisms with no nontrivial
periodic conjugacy classes are hyperbolic [5].
Later Patrick Reynolds [13] established that every irreducible, non-surjective
endomorphism of a free group admits a train track representative with no illegal
turns. Based on this, Mutanguha proved that if φ : Fn →Fn is an irreducible,
non-surjective endomorphism such that Fn ⋊φ Z contains no subgroup isomorphic

2.1. Outer endomorphisms. Let φ, ψ : Fn →Fn be two endomorphisms of the

φ = ιg ◦ψ, where ιg(x) = gxg−1. From now on an outer endomorphism means
an endomorphism up to this equivalence. Here we take Fn to be a free group with

2.2. Train tracks. Let Γ be a finite graph without valence-one vertices (such a
graph is called a core graph) and with a marking Rn →Γ, where Rn denotes a
rose with n edges. The marking identifies π1(Γ) with Fn, and hence any homotopy
equivalence Γ →Γ determines an outer automorphism of Fn.
A map f : Γ →Γ is a topological representative of φ ∈Out(Fn) if f sends
vertices to vertices, is locally injective on the interiors of edges, and the induced
homomorphism f∗: Fn →Fn represents the outer class φ.
Given a topological representative f : Γ →Γ, fix an ordering of edges and
define the transition matrix A(f) by letting A(f)ij be the number of times edge ei
appears in the image of ej (in either direction). Such a matrix is a non-negative
integral matrix and is irreducible if for all i, j there exists N(i, j) > 0 such that the
(i, j)-entry of A(f)N(i,j) is positive.
A proper subgraph is called a forest if all its components are nontrivial con-
tractible graphs (that is, trees). We define irreducibility for graph maps as follows:
Definition 2.3. A topological representative f : Γ →Γ is irreducible if Γ contains
no nontrivial f-invariant subgraph. Equivalently, f is irreducible if and only if its
transition matrix A(f) is irreducible.
Definition 2.4 (Train track). Let Γ be a connected finite core graph without
valence-two vertices. A graph map f : Γ →Γ is a train track if it maps ver-
tices to vertices and all iterates of f are locally injective on the interiors of edges.
We call a train-track map f : Γ →Γ expanding if it is not a homeomorphism;
equivalently, the transition matrix is irreducible and has a real eigenvalue λf > 1.
The λf is the Perron-Frobenius eigenvalue.
Bestvina-Handel [4] showed that irreducible automorphisms admit train track
representatives; the argument adapts to irreducible endomorphisms. See also [7] or
Theorem 2.8 in [11].
Theorem 2.1. If φ : Fn →Fn is an irreducible endomorphism, then φ can be rep-
resented by an irreducible train track map. The irreducible train track is expanding
iff φ has infinite-order.
For irreducible non-surjective endomorphisms one gets a special train track rep-
resentative. The next result is due to Reynolds ( [13, Corollary 5.5]) and can also
be found in [12].
Theorem 2.2. Let φ : Fn →Fn be a non-surjective irreducible endomorphism.
Then there is a train track representative f : Γ →Γ which has no illegal turns.
2.3. Expansive maps. For an automorphism φ : G →G and any k > 0, every
x ∈G has some y with φk(y) = x. This can fail for non-surjective endomorphisms.
For irreducible non-surjective endomorphisms a stronger property holds.
Definition 2.5 (Expansive, [13]). Let B be a basis of Fn and φ : Fn →Fn an
endomorphism. We say φ is expansive with respect to B if for any K > 0 there
exists M > 0 so that for any x ∈Fn \ {e} we have ∥φm(x)∥B ≥K whenever
m ≥M.
The expansive property is independent of the generating set chosen. There is a
dichotomy for irreducible endomorphisms ( [13, Proposition 3.11]).
Proposition 2.1. Let φ : Fn →Fn be an irreducible endomorphism. Then either
φ is an automorphism or φ is expansive.

2.7. Hyperbolic endomorphisms. It is a well-known result that given an atoroidal
automorphism of a free group φ : Fn →Fn, the extension Fn∗φ is hyperbolic ([5]).
We have a similar result when we have endomorphisms which says:
Theorem 2.3 ([10]). Let φ : Fn →Fn be fully irreducible, non-surjective endo-
morphism. The following are equivalent:
(1) Fn∗φ is word-hyperbolic.
(2) Fn∗φ has no BS(1, d) subgroups for d ≥1.
(3) There are no k, d ≥1 and nontrivial g ∈Fn with [φk(g)] = [gd]([x] denoting
conjugacy class of x).
(4) If f : Γ →Γ is a locally injective train track representative then f is (λ, n)-
hyperbolic and some pull-back stabilises.
Definition 2.16 (Hyperbolic endomorphism). A fully irreducible non-surjective
endomorphism φ : Fn →Fn is hyperbolic if it satisfies any (hence all) of the
above conditions.
