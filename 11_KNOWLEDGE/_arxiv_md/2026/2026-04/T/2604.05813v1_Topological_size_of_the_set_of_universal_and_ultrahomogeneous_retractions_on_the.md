TOPOLOGICAL SIZE OF THE SET OF UNIVERSAL AND
ULTRAHOMOGENEOUS RETRACTIONS ON THE URYSOHN SPACE
J. BĄK, J. GARBULIŃSKA-WĘGRZYN, M. POPŁAWSKI
Abstract. In this paper, we investigate the set U(U) of universal and ultrahomoge-
neous 1-Lipschitz retractions acting on the Urysohn space as the subspace of the space
R(U) of all 1−Lipschitz retractions defined on the Urysohn space. Especially, we study
Borel complexity and density U(U) in R(U). In order to do that, we introduce a new
extension property (UR∗) that is equivalent to the universality and ultrahomogeneity of
a retraction, and a new pointwise retract topology.
1. Introduction
The space X is universal, if it contains an isometric copy of every complete separable
metric space. Urysohn in [10] constructed a complete separable metric space (U, dU) that
is universal. A more famous example of a universal space is C([0, 1]).
A map f : X →Y is a 1−Lipschitz if its Lipschitz constant
Lip(f) = sup
x̸=y

d(x, y)
≤1.
Urysohn’s universal metric space U was characterized in [10] as being, up to isometry,
the unique Polish metric space with the following extension property:
(U) for any finite metric space X and any isometry f : X0 →U, where X0 ⊆X, there
exists an isometry ¯f : X →U extending f ( ¯f ↾X0= f).
An analogous extension property holds for the rational Urysohn space (U0, dU0), equipped
with the metric dU0 inherited from U, as well as for any rational metric space X.
Michal Doucha investigated in [4] the concepts of universality and ultrahomogeneity in
a context of retractions defined on the Urysohn space.
Definition 1.1. We say that a 1-Lipschitz retraction U : U →U[U] is universal, if for
every separable metric space X and for every 1-Lipschitz retraction R: X →R[X] there
exists an isometry i: X →U such that for every x ∈X we have
i ◦R(x) = U ◦i(x)
and
dist(x, R[X]) = dist(i(x), U[U]).
Definition 1.2. [Remark 2.9, [4]] (U, U, U[U]) is ultrahomogenous if satisfy the following
property: let A1, A2 ⊆U be two finite subsets that are isomorphic, i.e. there exists an
isometry i : A1 →A2 such that
• for every x ∈A1 we have i ◦U(x) = U ◦i(x),
• for every x ∈A1 we have dist(x, U[U]) = dist(i(x), U[U]).
Then i extends to an autoisometry I : U →U with
• for every x ∈U we have I ◦U(x) = U ◦I(x),
• for every x ∈U we have dist(x, U[U]) = dist(I(x), U[U]).
