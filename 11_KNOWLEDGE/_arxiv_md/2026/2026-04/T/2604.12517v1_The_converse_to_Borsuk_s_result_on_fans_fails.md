The converse to Borsuk’s result on fans fails
Benjamin Vejnar∗†
Department of Mathematical Analysis
Faculty of Mathematics and Physics, Charles University
Prague, Czechia
E-mail: vejnar@karlin.mff.cuni.cz
April 15, 2026
Abstract
A fan is an arc-wise connected hereditarily unicoherent continuum with exactly one
branching point. By a result of Borsuk, every fan is a 1-dimensional continuum that
can be expressed as the union of a family of arcs, each pair of which intersects in the
branching point. In this paper, we prove that the converse does not hold by providing
a more general result.
1
Introduction
A dendroid is an arc-wise connected hereditarily unicoherent continuum, and a fan is a den-
droid with exactly one branching point. In 1954, while proving the fixed point property
for dendroids, Borsuk proved that every dendroid is hereditarily decomposable [2]. Conse-
quently, the topological dimension of any dendroid is one (see e.g. [4]). In the same paper,
Borsuk proved that the closure of any injective continuous image of a ray in any dendroid
is an arc. It follows that every fan can be expressed as the union of arcs, each pair of which
intersects in a distinguished point. In 1963, Borsuk defined a broom to be a compact 1-
dimensional space X that can be expressed as the union of a family L consisting of arcs,
such that any two distinct arcs K, L ∈L intersect only in a point t ∈X [3]. While proving
that there is a countable broom (i.e., L is countable) which cannot be embedded into the
plane, he noted that a countable broom is always a fan. Nothing is mentioned about the
case when L is uncountable. It is natural to ask:
Question 1. Is every broom a fan?
This question was explicitly stated in [1, Problem 3.4], where the authors proved that a
broom with some additional properties is a fan. The question is also rephrased in [10]. The
aim of this paper is to provide a negative answer to Question 1 by proving a more general
result:
Theorem 2. Let C be the Cantor set and T be a continuum for which there is a continuous
surjective map f : C →T where |f −1(t)| ≤2, t ∈T, and |f −1(t)| = 2 only for countably
many points t ∈T.
Then, there exists a 1-dimensional continuum X with a point t ∈X and a family L
consisting of arcs in X such that
• K ∩L = {t} for every pair of distinct arcs K, L ∈L,
• t is an end-point of every L ∈L,
• X contains a homeomorphic copy of T.

Preliminaries
We denote ω = {0, 1, . . . } and N = {1, 2, . . . }. We use indices s ∈ω<ω, i.e. s = (s0, . . . , sn−1)
is a finite sequence of non-negative integers. We denote by |s| the length of s. Note that s
can also be an empty sequence. Also, if |s| = 1 we identify s with s0.
A continuum is a nonempty, compact, connected, metrizable topological space. A simple
closed curve is any space homeomorphic to the unit circle, and an arc is any space homeo-
morphic with [0, 1]. A continuum is hereditarily unicoherent, provided that the intersection
of two subcontinua is either empty or a continuum. A dendroid is an arc-wise connected,
hereditarily unicoherent continuum. A simple triod with top point t is a continuum that
can be expressed as a union of three arcs, each pair of which intersects exactly in {t} and
t is an end-point of each of these arcs. We use [11] as a standard reference for notions in
Continuum theory.
A topological space is 0-dimensional if it has a base formed by sets that are open and
closed at the same time. A space is 1-dimensional if it is not 0-dimensional and has an open
base formed by sets with a 0-dimensional boundary. See [6] for more on Dimension theory
in topology.
Every dendroid is a 1-dimensional continuum. A point in a dendroid is called a branching
point if it is the top of a simple triod contained in it (see [4]). A fan is a dendroid with
exactly one branching point. For an exposition on fans, see the paper by J. J. Charatonik
[5]. We use the terminology of Borsuk for the notion of a broom:
Definition 4. A 1-dimensional continuum X is called a broom if there is a point t ∈X and
a family L consisting of arcs in X such that
• |L| ≥3,
• X = S L,
• K ∩L = {t}, for every pair of distinct arcs K, L ∈L.
• the point t is an end-point of every L ∈L.
It can be easily seen that if we drop the last condition, we get an equivalent notion. The
reason to include it is that in the last section we state a question about the uniqueness of the
family L in a broom. Let us note that the name “phan” is used in [1] instead of a broom.
The following result is usually referred to as the Countable sum theorem for topological
dimension [6, Theorem 1.5.3]. We will be using it only in the case n = 1.
Lemma 5. The countable union of at most n-dimensional closed sets is at most n-dimensional.

Proof of Theorem 2
For the readers convenience, we describe the proof of Theorem 2 in the case T = [0, 1] and
using a special choice of f. The proof of the full result is presented at the end of this section.
Notation
Let I = [0, 1] and C ⊆I be the standard Cantor set. Denote by f : C →I the Cantor map,
i.e. the map for which f(P 2ai/3i) = P ai/2i, where ai ∈{0, 1}. This is at most a 2-to-1
map. Denote by D the collection of all dyadic numbers in (0, 1). The set D is countable, so
we can enumerate it as {dn : n ∈N}. Then f −1(dn) is a two point set, and we fix an, bn ∈C
with f −1(dn) = {an, bn}, n ∈N. On the other hand, f −1(d) is a singleton for d ∈I \ D.

The Cantor fan F
Let F be the cone over C, i.e., F is the quotient of C ×I where C ×{1} is pushed to a point,
which will be called t. The continuum F is usually called a Cantor fan with top point t. For
c ∈C and a < b ∈I, we denote by Ic[a, b] the set {c} × [a, b]; analogously, we use Ic[a, b)
for intervals open from the right side, i.e., {c} × [a, b), etc. We will also shorten Ic = Ic[0, 1]
and identify these sets with their images under the quotient map C × I →F.
The continuum Y (see Figure 1)
Now, consider the quotient Y of F, where two points (a, 0), (b, 0) ∈F are identified if and
only if f(a) = f(b). Let q : F →Y be the quotient map. Also denote B = q(C × {0}),
which is an arc in Y .
The continuum Z as a quotient of Y (see Figure 2)
Define Z as a quotient of Y in the following way. Identify the arc B with the arc q(I0) by
the homeomorphism that maps q(c, 0) to q(0, f(c)), c ∈C. Let p : Y →Z be the quotient
map. Denote A = p(B).
The compact space W
We define an indexing set
Λ = {s ∈ω<ω : s ̸= ∅, s0 ̸= 0} = N × ω<ω.
The form of this indexing set reflects the fact that once we produce our final space X as a
quotient of W, we will need N many gluings in the first steps, and in the additional steps,
we will always need one more space corresponding to the index s whose last entry is zero.
Let Zs = Z for s ∈Λ. Let W be the disjoint union of Y and all the Zs, topologized in
such a way that Zs, s ∈Λ, forms a null sequence converging to the point t. In other words,
the disjoint sum S{Zs : s ∈Λ} (which is a non-compact, locally compact, separable space)
is compactified by the one point t ∈Y . Thus, W is clearly a compact space. As we want Zs,
s ∈Λ, to be disjoint copies of Z in W, we adopt the notation of ps : Y →Zs, ts = ps(q(t)),
As = ps(B) for the corresponding objects in Zs, in order to distinguish them.
The space X as a quotient of W (see Figure 3)
Fix real numbers rn ∈(0, 1), n ∈N, converging to 1.
First, identify in W every arc
q(Ibn[rn, 1]) with the arc An ⊆Zn using a homeomorphism, say hn, that maps q(t) to tn,
n ∈N.
Consequently, for every s ∈Λ and n ∈N, identify in W the arc psq(Ibn[rn, 1]) with the
arc As⌢n ⊆Zs⌢n by a homeomorphism, say hs⌢n, of these arcs that maps ts to ts⌢n.

The family of arcs L
We describe the family of arcs L = S{Ls : s ∈Λ ∪{∅}}. We will proceed in different ways
for s = ∅and s ∈Λ.
The family L∅of arcs in Y
Let L∅consist of all the arcs in Y of the form q(Ic), whenever c ∈C \ {an, bn : n ∈N} (i.e.
f −1(f(c)) is a singleton.) We also add to L∅all the arcs q(Ian ∪Ibn[0, rn]), n ∈N.
The family Ls of arcs in Zs
Fix s ∈Λ, |s| = n, n ∈N. Let Ls consist of all the arcs in Zs of the form psq(Ic), whenever
c ∈C \ {0, 1, an, bn : n ∈N} (i.e. f −1f(c) is a singleton and c ̸= 0 and c ̸= 1). Add
to this family Ls all the arcs of the form psq(Ian ∪Ibn[0, rn]). Finally, add one more arc
psq(I1[0, 1/2]). Note that psq(I1[0, 1]) is a simple closed curve, not an arc! This is why this
exception with c = 1 is crucial.
Verification that everything works
The restrictions u|Y as well as u|Zs, s ∈Λ, are injective. Hence, we can consider Y and Zs
as subspaces of W. The same applies to every L ∈L. We just note that Y ∩Zn = An and
Zs ∩Zs⌢n = As⌢n.
The space X is a quotient of a compact metric space W by an upper semi-continuous
decomposition, since An converges to {t}. Thus, X is a compact metrizable space. Since
moreover t ∈Y ∩T
s∈Λ Zs, the space X is a continuum.
The space X is covered by L
Let x ∈X. We can suppose that x ̸= t. Distinguish two cases and subcases. First, if x ∈Y ,
then either a) x ∈S L∅or b) x ∈An, for some n ∈N, but x is not an end-point of An. In
the b) case, x is contained in an arc from Ln. Second, if x ∈Zs for some s ∈Λ, then either
a) x ∈S Ls or b) x ∈As⌢n for some n ∈ω, and x is not an end-point of As⌢n. In the b)
case, we also get that x is contained in an arc from Ls⌢n.
Distinct arcs from L intersect in t only
We need to verify first that K ∩L = {t} for distinct K, L ∈L. Clearly, if we have distinct
K, L ∈Ls, s ∈Λ, then K ∩L = {t}. This simply holds also in the case of s = ∅.

The continuum X has dimension 1
The Cantor fan F is well known to be 1-dimensional. The continuum Y can be expressed as a
countable union of homeomorphic copies of the Cantor fan and the arc B. Hence, by Lemma
5, Y is 1-dimensional. Similarly, the continuum Z is a countable union of homeomorphic
copies of F, and thus it is 1-dimensional as well. Finally, X is a countable union of u(Y )
and u(Zs), s ∈Λ, which are homeomorphic copies of Y or Z. Hence, again by Lemma 5, we
get that X is 1-dimensional.
The continuum X contains simple closed curves
The union q(Ian) ∪q(Ibn) is a simple closed curve for every n ∈N.
Generalizing the whole proof for arbitrary T and f
We can modify the whole construction as follows. Keep the space Z as it is, but modify the
construction of Y naturally by using a continuum T for which there is a continuous surjective
map f : C →T where f −1(t) is nondegenerate only for countably many points t ∈T, and
in these cases |f −1(t)| = 2. Note that the dimension of T is 1 by [6, Problem 1.7.F c)].
Then we can analogously define the space Y = Yf as a quotient of the Cantor fan F by the
identification of points (a, 0), (b, 0) ∈F whenever f(a) = f(b). Proceed in the construction
in the same vein by defining W and X using Yf and Z. In this way, the construction yields
a broom that contains T.

Concluding remarks and questions
Remark 6. By [13], the Sierpi´nski triangle T is a continuous image of the Cantor set under
a continuous surjective map f, such that the preimages of points are of cardinality at most
two, and only countably many points have a preimage of cardinality exactly two. Thus,
Theorem 2 can be applied to the Sierpi´nski triangle T and a map f. See also [12] for other
spaces of this kind.
Remark 7. By the classical Moore plane decomposition theorem, every upper semi-continuous
decomposition of the plane, whose classes are continua that do not separate the plane, is
homeomorphic to the plane. It follows from the Moore theorem that both spaces Y and
Z from Section 3 can be realized in the plane (for the case T = [0, 1]).
The argument
uses a decomposition whose nontrivial classes are arcs (the dashed arcs in Figures 1 and 2),
which clearly do not separate the plane. Consequently, W is embeddable into the plane as
well. However, the gluing towards the space X suggests that the continuum X cannot be
embedded into the plane.
Question 8. Is every planar broom a fan?
Remark 9. It is well known that every family of disjoint simple triods in the plane is
countable. Disjoint families of simple triods in every broom X obtained by Theorem 2 are
countable because every triod in X that does not contain the point t must intersect an arc
As, s ∈Λ, in a subarc. However, we can easily construct a broom with an uncountable family
of disjoint simple triods. Just start with any broom X with the top point t constructed in
Theorem 2. We know that there is a simple triod S ⊆X \ {t}. Let C denote the Cantor
set. Then consider the quotient of C × X where C × {t} is pushed to a point. This quotient
space is clearly a broom, and {{c} × S : c ∈C} is an uncountable family of disjoint triods.
Remark 10. Let X be any broom from Theorem 2 and let L, L′ be two families of arcs
witnessing that X is a broom. Then L = L′. The same is true for every fan X.
Question 11. Does there exist a broom X and distinct families L, L′ of arcs in X, both
wittnesing that X is a broom?
Remark 12. A space is said to have the fixed point property, if every continuous selfmap has
a fixed point. Note that the fixed point property is preserved by retracts. By [9, Theorem 1,
p.354] (see also [8, Proposition 2.4]), every simple closed curve contained in a 1-dimensional
continuum X is a retract of X. Since all the brooms constructed in Theorem 2 contain
simple closed curves, none of them has the fixed point property. This is in contrast to the
fact that dendroids have the fixed point property.
Question 13. Does there exist a broom with the fixed point property, that is not a fan?
In [1], a continuum X is called a Carolyn pan if there is a point t ∈X and a family L
consisting of arcs in X, such that
• K ∩L = {t} for distinct arcs K, L ∈L,
• X = S L,
• for every continuum C ⊆X \ {t} there is L ∈L, such that C ⊆L.
We give a negative answer to [1, Problem 4.17] by the following theorem.
Theorem 14. The space X obtained by Theorem 2 is not a Carolyn pan.
Proof. Note that X contains simple closed curves, so it is not a fan. Suppose for contradiction
that X is a Carolyn pan. Note that X is 1-dimensional. Since every 1-dimensional Carolyn
pan is a fan by [1, Theorem 4.15], we get a contradiction.
An alternative self-contained proof of the theorem is as follows. Suppose for contradiction
that X is a Carolyn pan. Hence, there is t ∈X and a family L as in the definition. Notice
that X contains a simple closed curve S ⊆X with t ∈S. Then S \ {t} contains arcs Cn
whose both end-points approach t as n →∞, t /∈Cn, and C1 ⊆C2 ⊆. . . . Choose L ∈L
with C1 ⊆L.
Clearly, for sufficiently large n ∈N, Cn is not a subset of L.
This is a
contradiction with X being a Carolyn pan.
