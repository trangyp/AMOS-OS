Abstract
It has been shown that, regarding a terminating right-linear overlay term rewrite system (TRS),
any rewrite sequence ending with a normal form can be simulated by the innermost reduction. In
this paper, using this simulation property, we show that for a right-linear overlay TRS, there is
no infinite minimal dependency-pair chain if and only if there is no infinite innermost minimal
dependency-pair chain. This implies that a right-linear overlay TRS is terminating if and only if it
is innermost terminating.

Introduction
Termination is not only one of the most important properties but also one of the most
investigated research topics in the field of term rewriting. Termination is sometimes assumed
for target rewrite systems, e.g., rewriting induction [8] requires given TRSs to be terminating.
Thus, many powerful tools have been developed and are still improved (cf. termCOMP [3]).
Innermost termination is, in general, weaker than termination in the sense that termination
implies innermost termination. Viewed in this light, in proving innermost termination, we
can use sufficient conditions for termination, together with those for innermost termination,
some of which are weaker than the corresponding ones for termination. For example, in
applying the narrowing processor in the dependency pair (DP) framework [4, 5] to a DP
problem (P, R, e),1 if e = t, then right-linearity is required to a transformed DP in P, and
otherwise, right-linearity is not required (cf. [5, Definition 28]). The reduction pair processor
based on “usable rules” requires “Ce-compatibility” for DP problems with t but not for those
with i (cf. [5, Theorem 17]). On the other hand, for a class of TRSs, for which termination
and innermost termination coincide, we can use innermost-termination proving techniques
in order to prove termination. Therefore, this class of TRSs is very interesting from both
theoretical and implementation perspectives.
The known maximum class of TRSs, for which termination and innermost termination
coincide, is the class of locally confluent overlay TRSs, i.e., a locally confluent overlay TRS
is terminating if and only if it is innermost terminating [6]. Being an overlay system is
a syntactic property of TRSs, but local confluence is not, while there are some syntactic
sufficient conditions for local confluence of TRSs, e.g., orthogonality. Note that to show
local confluence, we sometimes first prove termination and then joinability of critical pairs.
Therefore, it must be worthwhile to detect classes of TRSs, for which innermost termination
implies termination.
In this paper, we show that for a right-linear overlay TRS, there is no infinite minimal
dependency-pair chain if and only if there is no infinite innermost minimal dependency-pair

Our main result is based on the proof of the following claim: Regarding a terminating
right-linear overlay TRS, any rewrite sequence ending with a normal form can be simulated
by the innermost reduction [9]. To prove our main goal “innermost termination implies
termination”, given an infinite rewrite sequence of an innermost-terminating right-linear
overlay TRS R, we would like to show the existence of an infinite innermost rewrite sequence
of R. Unfortunately, for this approach, we cannot use the result in [9], which only performs
for finite rewrite sequences ending with normal forms. On the other hand, for a (possibly
infinite) minimal (P, R)-chain, all terms in the chain are terminating w.r.t. R. Thus, using
an auxiliary lemma for the main result in [9], we show that for a finite minimal (P, R)-chain
of length n, there exists an innermost minimal (P, R)-chain of length n, provided that R ∪P
is a right-linear overlay system. Note that the length of a (P, R)-chain is defined by the
number of DPs included. Using this auxiliary property, our proof for the main result proceeds
by contradiction as follows:
1. Assume that there is no infinite innermost minimal (P, R)-chain and there is an infinite
minimal (P, R)-chain starting with a term s#;
2. let n be the maximum length of innermost minimal (P, R)-chain starting with s#;
3. for a finite minimal (P, R)-chain of length n + 1, which starts with s#, we show that
there exists an innermost minimal (P, R)-chain of length n + 1, which starts with s#;
4. this contradicts the assumption about n.
Regarding our main result on dependency-pair chains, we do not assume that a given
TRS R is innermost terminating. Thus, the result provides a DP processor that converts a
given DP problem (P, R, t) to (P, R, i) if R ∪P is a right-linear overlay system. In the DP
framework [4, 5], some DP processors, such as the narrowing processor, transform DPs to
rewrite rules that are not DPs of given TRSs. To use the switching processor mentioned
above in the DP framework, we do not restrict P in our main result to be sets of DPs of
given TRSs, and P is assumed to be a non-collapsing right-linear TRS such that R ∪P is an
overlay system.

Preliminaries
In this section, we briefly recall some syntactic properties of TRSs and some essential results
on innermost rewriting and dependency pairs. Familiarity with basic notions and notations
on term rewriting [2, 7] is assumed.
A term t is said to be terminating w.r.t. a TRS if there is no infinite rewrite sequence of
the TRS, which starts from t. A rewrite rule ℓ→r is called right-linear if the right-hand
side r is linear. Rewrite rule ℓ→r is called non-collapsing if the right-hand side r is not a
variable. A TRS R is called right-linear if all rewrite rules in R are right-linear. TRS R is
called non-collapsing if all rewrite rules in R are non-collapsing. TRS R is said to have an
inner-overlap if there exist rewrite rules ℓ→r and ℓ′ →r′ in R such that a renamed proper
non-variable subterm s of ℓ—Var(s) ∩Var(ℓ′) = ∅—is unifiable with ℓ′. TRS R is called an
overlay system if R has no inner-overlap.

From Innermost Termination to Termination
In this section, for a right-linear overlay TRS R over a signature Σ, we show the following
main claim: For a set P of DPs such that R ∪P is a right-linear overlay TRS, there is no
infinite minimal (P, R)-chain if and only if there is no infinite innermost minimal (P, R)-chain

4
Conclusion
In this paper, we first showed that for a right-linear overlay TRS R and a set P ⊆DP(R),
there is no infinite minimal (P, R)-chain if and only if there is no infinite innermost minimal
(P, R)-chain. Then, using the claim, we showed that a right-linear overlay TRS is terminating
if and only if it is innermost terminating. Local confluence is not a syntactic property, while
there are some syntactic sufficient conditions (e.g., orthogonality) for local confluence. On
the other hand, both right-linearity and being overlay systems are syntactic properties, and
hence it is not so expensive to decide whether a given TRS is a right-linear overlay system.
A future work is an empirical evaluation of the results in this paper.
