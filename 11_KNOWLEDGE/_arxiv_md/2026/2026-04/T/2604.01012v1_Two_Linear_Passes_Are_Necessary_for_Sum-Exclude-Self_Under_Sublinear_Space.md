Two Linear Passes Are Necessary for Sum-Exclude-Self Under
Sublinear Space
Andrew Au
Independent Researcher
Corresponding author: cshung@gmail.com
Abstract
We prove that any algorithm computing the sum-exclude-self
of an unsigned d-bit integer array of length n under sublinear
space must perform two linear passes over the input. More
precisely, the algorithm must read at least n−1 input elements
before any output cell receives its final value, and at least n−
⌊t/d⌋additional elements thereafter, where t = o(nd) bits is
the working memory size. This gives a total of 2n−1−⌊t/d⌋
element reads. A trivial modification of the standard two-pass
algorithm achieves this bound exactly for all practical input
sizes. The proof uses this toy problem as a worked example to
demonstrate the choke-point technique for proving sublinear-
space lower bounds.
Keywords: sum-exclude-self; sublinear space; streaming
lower bound; choke-point technique; information-theoretic
lower bound.

n −1 input elements before any output cell receives its final

The standard two-pass algorithm’s 2n reads nearly matches
this lower bound; for d = 32 and n ≤231, the gap is just 2
reads.
Rather than claiming this problem is practically difficult,
we use it as a toy example that isolates the choke-point
technique—passing the identity function through an infor-
mation bottleneck created by sublinear memory—without the
machinery being obscured by problem complexity.
1.1
Model of Computation
The algorithm reads input elements from In and writes output
elements to Out, maintaining at most t = o(nd) bits of work-
ing memory between any read or write operation. The input
array In is read-only. The output array Out is write-only: the
algorithm may write to any output cell at any time (and may
overwrite previously written values), but may never read from
Out. This prevents the algorithm from using output storage
as additional working memory. Arithmetic is performed over
the integers Z with no overflow. We assume n ≥2 through-
out; the case n = 1 is trivial since Out[0] = 0 for every
input.
The d-bit input restriction is essential: The input do-
main {0, . . . , 2d−1}n carries nd bits of information (2nd dis-
tinct inputs). This finite, measurable domain is what makes
the information-theoretic lower bound possible. Without this
boundedness, the input domain Zn is infinite and carries no
finite bit measure, so no analogous counting argument ap-
plies. The d-bit restriction applies only to input storage, not
to intermediate values or outputs.

First Pass Lower Bound
Definition 2.1. For each output cell Out[i], the final write
is the last write to that cell during the algorithm’s execution.
Since the algorithm is correct, each final write produces the
correct output value.
The first pass is the time interval from the start of the algo-
rithm until immediately before the earliest final write to any
output cell.
Lemma 2.2. During the first pass, the algorithm must read
at least n −1 elements of In.

tradiction, that the earliest final write occurs after A has read
at most n −2 distinct input positions. Let S be the set of
indices read, so |S| ≤n −2, and let i be the index receiving

Second Pass Lower Bound
Definition 3.1. The second pass is the interval from the ear-
liest final write to the end of execution.
3.1
Setup
Let T denote the space of all possible working memory states
at the start of the second pass; each state is at most t bits, so
|T| ≤2t. Let u be the maximum number of bits read from

i.e., at least n −⌊t/d⌋elements.

5
Discussion
This toy problem demonstrates five key ingredients of the
choke-point technique:
1. Operational pass definitions based on output boundaries
rather than syntactic passes;
2. Finite d-bit input domain enabling cardinality arguments
while keeping arithmetic over Z to avoid overflow com-
plications;
3. Explicit reconstruction showing the output space can re-
cover the input;
4. Choke point bit budget forcing information from input to
pass through limited memory;
5. Read quantization converting the bit lower bound to an
element lower bound.
These ingredients generalize broadly to proving lower
bounds for problems under limited working memory.
