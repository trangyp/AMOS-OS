1. INTRODUCTION
Let f : X →X be a self map. The pair (X, f) becomes an open dynamical system
by designing a subset Y of the phase space X as a hole. There are two topical contents
about the studying of open dynamical systems: the escape rate and the size of the set of the
points that survives from the holeY. In 1979, Pianigiani and Yorke [14] posed the problem
about the survivor set and how to characterize the limiting distributions for a ball staying
in a given measurable set on the table with a small hole. Then in 1986, Urba´nski [19,20]
introduced the Hausdorff dimension and the topological entropy of K(t) for C2-expanding
and orientation preserving map g: S2 →S2 and proved that they are both continuous
functions. He also showed that the set of bifurcation parameter is homeomorphic to the
Cantor set and has zero Lebesgue measure. After the work of Urba´nski, Kalle, Kong,
Langeveld and Li[12] considered this situation for the β-transformation with 1 < β ≤2.
In the following, we use Tβ to represent the β-transformation, which is defined to be
Tβ(x) = βx(mod1) for x ∈[0,1). In 2020, Agarwal was concerned with the Hausdorff
dimension of the survivor set Wβ(a,b) = {x ∈[0,1): T k

0 ≤a < b ≤1 vary with β ≥2 being an integer. Other results on the survivor set of
β-transformations can be found in [2,8,10,17] among others.
