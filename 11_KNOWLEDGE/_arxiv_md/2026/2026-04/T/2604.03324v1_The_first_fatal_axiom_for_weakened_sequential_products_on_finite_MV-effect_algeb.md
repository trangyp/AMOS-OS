Abstract
We study total binary operations on effect algebras obtained by truncating the Gudder–
Greechie axiom package for a sequential product. The point is not to reprove the known
nonexistence of non-Boolean full sequential products on finite chains, but to determine,
axiom by axiom, where finite MV-effect algebras first fail. We prove two structural facts
valid on every effect algebra. First, the operation
σE(a, b) =
(
0,
a = 0,
b,
a ̸= 0,
satisfies (S1)–(S3), so (S3) is never fatal by itself. Second, any operation satisfying (S1)–
(S4) already has the right-unit property a ◦1 = a, even without (S5). From this we derive
a local obstruction theorem: if an effect algebra contains an atom of finite isotropic index
at least 2, then it admits no (S1)–(S4) operation. Consequently, a finite MV-effect algebra
admits such an operation if and only if it is Boolean. In this precise sense, (S4) is the first
fatal axiom on finite MV-effect algebras.
On the constructive side, let Eu = [0, u] ⊆Zr be the simplicial interval representation
of a finite MV-effect algebra. We show that additive maps Eu →Ev are exactly the
restrictions of positive group homomorphisms Zr →Zs, equivalently maps x 7→Mx given
by nonnegative integer matrices with Mu ≤v. This yields a complete classification of
(S1)+(S2) operations by row-wise subunital matrices. We then solve the first genuinely
higher-rank (S1)–(S3) problem: on the rank-two Boolean algebra B2 = E(1,1) ∼= C2

such operations are classified and there are exactly 34. Thus the finite-chain collapse at
(S3) is a rank-one boundary phenomenon, whereas on finite MV-effect algebras the sharp
threshold for nonexistence occurs exactly at (S4).

Introduction
Effect algebras, introduced by Foulis and Bennett [1], provide an algebraic framework for
unsharp quantum events. Gudder and Greechie [2] defined a sequential product on an effect
algebra in order to abstract sequential measurement; a standard motivating example is
the Lüders product A ◦B = A1/2BA1/2 on Hilbert-space effects. Since then, most of the
literature has continued to work with the full sequential-effect-algebra axiom package, or
with stronger settings such as operator, convex, or normal sequential effect algebras; see for
instance [3, 6, 7, 8]. In the present paper we keep the same five Gudder–Greechie axioms
(S1)–(S5), but we study what happens when only the initial segment (S1)–(Sk) is imposed.

Known finite nonexistence results already settle the full-axiom picture in the rank-one
direction. In particular, chain-finite sequential effect algebras are Boolean [5], so a paper
devoted only to finite chains would amount to a clean but essentially known reproof. The
novelty of the present work is therefore not a new full-sequential-product nonexistence theorem
for finite chains or finite MV-effect algebras. Rather, the goal is to determine the axiom
threshold at which finite MV-effect algebras first collapse, and to identify how the chain
phenomenon changes in higher rank.
The first main contribution is structural and negative.
We show that the universal

any (S1)–(S4) operation already satisfies the right-unit law a ◦1 = a, although that law is
usually viewed as a standard consequence of the full axioms. From this we derive a local
obstruction theorem: if an effect algebra contains an atom of finite isotropic index at least 2,
then no (S1)–(S4) operation can exist. Specializing to finite MV-effect algebras, we obtain
the main threshold statement of the paper: (S1)–(S3) are always realizable, but (S4) already
forces Booleanity. In short, (S4) is the first fatal axiom on finite MV-effect algebras.
The second main contribution is constructive. A finite MV-effect algebra is a simplicial
interval Eu = [0, u] ⊆Zr and hence a finite product of finite chains [4]. In this representation
we classify all additive maps Eu →Ev by nonnegative integer matrices M with Mu ≤v. This
should be read as candidate-space infrastructure rather than as the sole novelty claim: it turns
the weakened sequential-product problem into an explicit combinatorial classification of left
translations. Using that framework, we classify all (S1)+(S2) operations on finite MV-effect
algebras and then solve the first genuinely higher-rank case at the (S3) stage. Namely, on the
rank-two Boolean algebra B2 = E(1,1) ∼= C2
1, we classify all (S1)–(S3) operations and show
that there are exactly 34. This exact low-rank classification makes the rank-one/higher-rank
contrast concrete: the chain collapse at (S3) is exceptional, whereas higher rank already
admits many additional candidates before (S4) is imposed.
To avoid misunderstanding, we stress once more what is and is not claimed here. We
do not claim novelty for the standard simplicial-interval coordinatization of finite MV-effect
algebras, and we do not claim a new full-SEA Booleanity theorem. The novelty lies in the
weakened-axiom regime: a sharp cutoff at (S4), a local obstruction theorem that applies to
arbitrary effect algebras, and an exact higher-rank (S1)–(S3) classification on B2.
Main contributions.
1. A universal (S1)–(S3) model on every effect algebra and a derivation of the right-unit

2. A finite-isotropic-atom obstruction theorem, yielding the threshold theorem that a finite

3. A matrix classification of additive maps on finite MV-effect algebras, hence a complete

4. An exact classification of (S1)–(S3) operations on B2 = E(1,1), with the sharp count 34.

Lemma 2.1. In Eu, the atoms are exactly e1, . . . , er, and ord(ei) = ui for every i.
Proof. Each ei is nonzero. If 0 ≤x ≤ei, then every coordinate of x except possibly the ith is
zero, and the ith coordinate is either 0 or 1; hence x ∈{0, ei}. So each ei is an atom.
Conversely, let x = (x1, . . . , xr) ∈Eu be nonzero. Choose an index i with xi > 0. Then
ei ≤x. If x is an atom, this forces x = ei. Thus the atoms are exactly the ei.
Finally, nei exists in Eu exactly when n ≤ui, because nei = (0, . . . , 0, n, 0, . . . , 0). Hence
ord(ei) = ui.

Proposition 3.1 (A universal (S1)–(S3) operation). For every effect algebra E, the binary

Proof. Fix a ∈E. If a = 0, then b 7→σE(a, b) is the zero map, hence additive. If a ̸= 0, then
b 7→σE(a, b) is the identity map, hence additive. Therefore (S1) holds.
Since 1 ̸= 0, we have σE(1, b) = b for every b ∈E, so (S2) holds.
Finally, suppose σE(a, b) = 0. If a = 0, then σE(b, a) = σE(b, 0) = 0. If a ̸= 0, then the
definition of σE forces b = 0, and again σE(b, a) = σE(0, a) = 0. Thus σE(a, b) = σE(b, a)
whenever σE(a, b) = 0, which is exactly (S3).
Remark 3.2. Proposition 3.1 shows that (S3) alone never yields a nonexistence theorem. Any
first-failure result must therefore use at least (S4).
The next theorem is the basic structural step behind the obstruction theorem.
Theorem 3.3 (Right unit from (S1)–(S4)). Let E be an effect algebra and let ◦be an (S1)–(S4)

a ◦1 = a
(a ∈E).

By positivity, this implies a ◦0 = 0.
Applying (S2) with a = 0 gives 1 ◦0 = 0. Hence (S3) yields
0 ◦1 = 1 ◦0 = 0.
Now let b ∈E be arbitrary. Since 1 = b ⊕b′, axiom (S1) applied to the left translation by 0

Finite isotropic atom obstruction and the first fatal axiom
We now turn the right-unit law into a general obstruction.
Theorem 4.1 (Finite isotropic atom obstruction). Let E be an effect algebra. Assume that E
contains an atom p with finite isotropic index
2 ≤ord(p) < ∞.
Then E admits no (S1)–(S4) operation.
Proof. Assume toward a contradiction that ◦is an (S1)–(S4) operation on E. Put
n := ord(p) ≥2,
q := (np)′.
Then np ⊕q = 1.
By Theorem 3.3,
p = p ◦1 = p ◦(np ⊕q) = p ◦(np) ⊕(p ◦q).
Repeated use of (S1) gives p ◦(np) = n(p ◦p), so
p = n(p ◦p) ⊕(p ◦q).
(4.1)
Hence p ◦p ≤p. Since p is an atom, either p ◦p = 0 or p ◦p = p.
Suppose p ◦p = p. Then (4.1) implies np = n(p ◦p) ≤p. Because n ≥2, the element 2p
exists and satisfies 0 < 2p ≤np ≤p. Since p is an atom, this forces 2p = p. But then
p = p ⊕p,
contradicting cancellation. Therefore
p ◦p = 0.
(4.2)
From the trivial equality p ◦p = p ◦p we have p | p, so axiom (S4) gives p | p′. Using (4.2)
and Theorem 3.3, we obtain
p = p ◦1 = p ◦(p ⊕p′) = (p ◦p) ⊕(p ◦p′) = 0 ⊕(p ◦p′) = p ◦p′.
Since p | p′, this yields
p′ ◦p = p.
(4.3)
Now apply Theorem 3.3 to p′ and use 1 = np ⊕q:
p′ = p′ ◦1 = p′ ◦(np ⊕q) = p′ ◦(np) ⊕(p′ ◦q) = n(p′ ◦p) ⊕(p′ ◦q).
By (4.3), this becomes

Hence np ≤p′, so (n + 1)p = np ⊕p exists. This contradicts the maximality of n = ord(p).
Therefore no (S1)–(S4) operation exists on E.

Proposition 4.3. Let E be a finite effect algebra with a unique atom p. Then every element
of E is of the form kp for a unique k ∈{0, 1, . . . , ord(p)}, and hence E is the finite chain
{0, p, 2p, . . . , ord(p)p = 1}.
In particular, if ord(p) ≥2, then E admits no (S1)–(S4) operation.
Proof. Let x ∈E be nonzero. Because E is finite, the interval [0, x] has a minimal nonzero
element, hence an atom. By uniqueness of atoms, that atom is p, so p ≤x. Thus every
nonzero x can be written as x = p ⊕x1. If x1 ̸= 0, the same argument gives p ≤x1, so
x1 = p ⊕x2. Iterating and using finiteness, we obtain x = kp for some k ≥1. Uniqueness of k
follows from cancellation.
Taking x = 1 shows that 1 = np for some n, necessarily n = ord(p). Hence E is exactly
the displayed chain. The final claim follows from Theorem 4.1 when n ≥2.
We now specialize to finite MV-effect algebras.
Theorem 4.4 (Threshold theorem for finite MV-effect algebras). Let E be a finite MV-effect
algebra. The following are equivalent:
(i) E is Boolean;
(ii) E admits an (S1)–(S4) operation;
(iii) E admits a sequential product.
In particular, for finite MV-effect algebras the first fatal axiom is (S4).
Proof. The implication (iii)⇒(ii) is immediate. If E is Boolean, then the meet operation
a ◦b := a ∧b is a sequential product [2], so (i)⇒(iii).
It remains to prove (ii)⇒(i).
Write E ∼= Eu for some u = (u1, . . . , ur) ∈Nr
>0.
By
Lemma 2.1, the atoms are e1, . . . , er and ord(ei) = ui. If some ui ≥2, then Theorem 4.1
forbids the existence of an (S1)–(S4) operation. Therefore every ui = 1, so E ∼= E(1,...,1),
which is a finite Boolean algebra.
Finally, Proposition 3.1 shows that every effect algebra, hence every finite MV-effect
algebra, admits an (S1)–(S3) operation. Therefore (S4) is indeed the first fatal axiom in this
class.
Remark 4.5. Theorem 4.4 is the paper’s main finite-MV cutoff statement. It is strictly finer
than the known full-sequential-product Booleanity results: it identifies the exact stage in the
weakened axiom hierarchy at which non-Boolean finite MV-effect algebras fail.

0 = 0 ◦1 = (0 ◦x) ⊕(0 ◦x′).

B(x) := q ◦x.
By (S1), both A and B are additive. By (S2), the row at 1 is the identity map.
We claim that A and B are nonzero. If A = 0, then in particular p ◦1 = 0, so (S3) gives
1 ◦p = p ◦1 = 0,
contradicting (S2). Hence A ̸= 0. The same argument shows B ̸= 0.

Conversely, assume that A and B are nonzero additive maps satisfying (6.1), and define ◦

the row at 1 is the identity.
It remains to prove (S3). Suppose that a ◦b = 0.
If a = 0, then b ◦a = b ◦0 = 0 because every additive map sends 0 to 0. If a = 1, then
b = 1 ◦b = a ◦b = 0, so again b ◦a = 0. Thus only a ∈{p, q} needs attention.
If b = 0, then b ◦a = 0 as above. If b = 1, then a ◦1 is either A(1) or B(1), and this is
nonzero because A and B are nonzero additive maps on B2. Hence the case b = 1 cannot
occur under the assumption a ◦b = 0.
If (a, b) = (p, p) or (q, q), then b ◦a = a ◦a = 0 trivially. If (a, b) = (p, q), then A(q) = 0,
so (6.1) gives B(p) = 0, hence
b ◦a = q ◦p = B(p) = 0.
The case (a, b) = (q, p) is symmetric. Therefore a ◦b = 0 always implies b ◦a = 0, so (S3)
holds.
For the counting statement, note that a nonzero additive map A is determined by an
orthogonal pair (u, v) = (A(p), A(q)) ̸= (0, 0). There are exactly three such pairs with v = 0,
namely
(p, 0), (q, 0), (1, 0),
and exactly five such pairs with v ̸= 0, namely
(0, p), (0, q), (0, 1), (p, q), (q, p).
Likewise, a nonzero additive map B is determined by an orthogonal pair (s, t) = (B(p), B(q)) ̸=
(0, 0); there are three possibilities with s = 0 and five with s ̸= 0. Condition (6.1) matches the
two zero-patterns, so the total number of operations is
3 · 3 + 5 · 5 = 34.

Finite chains as the rank-one boundary case
We now return to the original chain computation and place it inside the general theory. The
point of this section is not to recover a new full-sequential-product nonexistence theorem,
but to identify finite chains as the rank-one boundary case of the broader finite-MV picture
developed above.
For n ≥1, write
Cn = {0, e, 2e, . . . , ne = 1}
with partial addition (ie) ⊕(je) = (i + j)e whenever i + j ≤n. Identifying ie ↔i, this is
exactly E(n).
By Remark 5.3, the additive self-maps of Cn are exactly the zero map and the identity
map. Hence Corollary 5.4 immediately recovers the first stage of the chain computation: there
are exactly 2n operations on Cn satisfying (S1) and (S2).

is special to rank one.
