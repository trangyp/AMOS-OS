Quadratic Assignment and VC Dimension
Anatole Dahan, Martin Grohe, Daniel Neuen, Tomáš Novotný

Abstract
We present an additive εn2-approximation algorithm for the Graph Edit Distance prob-
lem (GED) on graphs of VC dimension d running in time nO(d/ε2). In particular, this
recovers a previous result by Arora, Frieze, and Kaplan [Math. Program. 2002] who gave
an εn2-approximation running in time nO(log n/ε2).
Similar to the work of Arora et al., we extend our results to arbitrary Quadratic Assignment
problems (QAPs) by introducing a notion of VC dimension for QAP instances, and giving
an εn2-approximation for QAPs with bounded weights running in time nO(ε−2(d+log ε−1)).
As a particularly interesting special case, we further study the problem ε-GI, which entails
determining if two graphs G, H over n vertices are isomorphic, when promised that if they are
not, their graph edit distance is at least εn2. We show that the standard Weisfeiler–Leman
algorithm of dimension O(ε−1d log(ε−1)) solves this problem on graphs of VC dimension d.
We also show that dimension O(ε−1 log n) suffices on arbitrary n-vertex graphs, while k-WL
fails on instances at distance Ω(n2/k).

Introduction
Computing the distance between two graphs is a notoriously hard algorithmic problem [2, 16,
20, 25]. One of the most natural distance measures is the graph edit distance, defined to be
the minimum number of edges that have to be flipped (added or deleted) in one of the graphs
to make it isomorphic to the other graph (assuming both graphs have the same number of vertices).
Grohe, Rattan, and Woeginger [20] proved that the problem of computing the edit distance
between two graphs of the same order (denoted by GED in the following) is NP-hard even
if both input graphs are trees, and Arvind, Köbler, Kuhnert, and Vasudev [2] proved that
there is no PTAS for GED unless P = NP. However, there is a very interesting and nontrivial
upper bound. Arora, Frieze, and Kaplan [1] give an additive approximation algorithm for GED
running in quasipolynomial time: given ε > 0 and two graphs G, H of order n, the algorithm
approximates the edit distance up to an additive error of εn2 in time nO(ε−2 log n). Note that
such an approximation is only interesting in the dense regime of graphs with Ω(n2) edges.
We parametrise the edit-distance problem by the VC dimension of the input graphs, where
we define the VC dimension of a graph G to be the VC dimension of the neighbourhood set
system NG := {NG(v) | v ∈V (G)}. As our first main result, we show that edit distance of graphs
of bounded VC dimension can be approximated up to an additive error of εn2 in polynomial time.
Theorem 1.1. There is an algorithm that, given ε > 0 and n-vertex graphs G, H of VC dimension
at most d, outputs a bijection φ: V (G) →V (H) with cost(φ) ≤δedit(G, H)+εn2 in time nO(ε−2d).
Here, δedit(G, H) denotes the graph edit distance between G and H, and cost(φ) denotes
the number of edge mismatches between G and H under the bijection φ. Note that the al-
gorithm interpolates smoothly between this case of bounded VC dimension and Arora et al.’s

While VC dimension has played an important role in algorithmic geometry at least since
the late 1980s (see, for example, [29]), graph algorithms exploiting bounded VC dimension have
only started to appear fairly recently [7, 13, 14, 26]. In this context, it is worth mentioning that
the monadically dependent graph classes, conjectured to be the limit for the fixed-parameter
tractability of first-order model checking, can be defined in terms of bounded VC dimension of set
systems definable in first-order logic (see, for example, [11, Conjecture 1]). However, all these
results and the conjecture are based on more general set systems than just the neighbourhood
set system NG. We are not aware of algorithmic results just exploiting a bounded VC dimension
of NG. However, many other graph parameters that have received a lot of attention in the graph
theory literature, such as maximum degree, tree width, clique width [8], twin width [5] or merge
width [12], can be bounded in terms of VC dimension, so algorithms for graph classes of bounded
VC dimension also apply to classes where any one of these parameters is bounded.

Going back to graphs, a particularly interesting special case of GED is the robust graph
isomorphism problem. For every ε > 0, consider the following promise problem ε-GI: given two
n-vertex graphs G, H such that either G and H are isomorphic or G and H have edit distance
at least εn2, decide if G and H are isomorphic. Note that this is a version of robust graph
isomorphism for the dense regime. For the sparse regime where the promise is that the edit
distance is either 0 or at least ε(n+m), where m denotes the number of edges of the input graph,
the problem has been studied by O’Donnell, Wright, Wu, and Zhou [31], and they obtained
various hardness results.
It is an open problem whether ε-GI can be solved in polynomial time for every fixed ε > 0;
we remark that O’Donnell et al.’s lower bounds [31] do not yield direct insights for the dense
regime. It follows from [1] that ε-GI can be solved in time nO(ε−2 log n), slightly improving over
Babai’s quasi-polynomial isomorphism test [4] (which solves the problem without making use
of the promise). More generally, Theorem 1.1 implies that ε-GI can be solved in time nO(ε−2d)
on graphs of VC dimension at most d. Observe that this regime is interesting since the restriction
of (exact) graph isomorphism is known to be hard (as hard as the general graph isomorphism
problem) for graph classes of bounded expansion and bounded twin width, both of which implies
bounded VC dimension.
We show that both runtime bounds can be slightly improved, and in fact this can be achieved
by a much simpler algorithm than for Theorem 1.1. The Weisfeiler-Leman (WL) algorithm,
going back to [36], is a simple combinatorial algorithm originally designed as an (incomplete)
isomorphism test, and which is commonly used for isomorphism testing (see, e.g., [4, 6, 18,
24]). Additionally, it has recently received a lot of attention due to a number of surprising
connections with combinatorial optimisation [3, 19, 28], graph homomorphisms [15, 9], and even
machine learning [30, 35, 37]. We prove that the O(ε−1d log(ε−1))-dimensional WL algorithms
solves ε-GI on graphs of VC dimension d. Also, for general n-vertex graphs, we show that
O(ε−1 log n)-dimensional WL algorithm solves ε-GI. Since the k-dimensional WL algorithm
can be implemented in time O(k2nk+1 log n) [23], this implies that ε-GI can be solved in time
nO(ε−1d log(ε−1)) on graphs of VC dimension at most d, and in time nO(ε−1 log n) on general graphs.
Our upper bound on the WL dimension are in stark contrast to well-known results stating
that the Ω(n)-dimensional WL algorithm is necessary to solve graph isomorphism [6]. In fact,
the Ω(n) lower bound for the WL dimension even holds for graphs of maximum degree 3 [6],
which in particular have constant VC dimension. For coloured graphs, we also give an upper
bound of O(ε−1s) on the WL dimension of ε-GI, where s denotes the maximum colour class size.
Again, this is contrasted by the fact that Ω(n)-WL is necessary to solve graph isomorphism
on graphs of colour class size 4 [6].
We complement these results by a lower bound stating that stating that for every ε there is
a k = Ω(ε−1) such that k-dimensional WL does not solve ε-GI. Moreover, for graphs of bounded
VC dimension and for graphs of bounded colour class size, we obtain tight polynomial bounds:
the smallest k such that k-WL solves ε-GI on these respective classes is polynomial in ε.

can be approximated in quasipolynomial time. As a result, they obtain a quasipolynomial time

optimal solution can be approximated up to an additive error of εn2 in time nO(B2ε−2(d+log Bε−1))
(Theorem 4.5). Because the reduction from the GED problem to QAP preserves VC dimension
(see Lemma 3.6), this result yields an algorithm approximating GED up to an additive error of εn2
for graphs of VC dimension bounded by d, which runs in time nO(ε−2d) (proving Theorem 1.1).

Robust Graph Isomorphism and Weisfeiler-Leman Algorithm
A particularly interesting special case of GED is the robust graph isomorphism problem. This
is a promise problem, where we are given two graphs G, H, which are promised to be either
isomorphic or have large edit distance, and the task is to decide which of the two options holds.
Formally, for a fixed ε > 0, we consider the promise problem ε-GI defined as follows:
ε-GI
Input: Two n-vertex graphs G, H.
Promise: Either G ∼= H or δedit(G, H) ≥εn2.
Question: Is G ∼= H?
By Theorem 1.1 the problem ε-GI can be solved in time nO(ε−2d) on graphs of VC dimension
at most d. Still, the algorithm is fairly complicated relying on, e.g., advanced rounding methods
in the proof of Lemma 4.1.
In this section, we show that, for the special case of ε-GI, we can instead use the Weisfeiler-
Leman algorithm. For k ≥1, the k-dimensional Weisfeiler-Leman algorithm (k-WL) is a standard
heuristic in the context of graph isomorphism testing (see, e.g., [4, 6, 18, 24]) which tries to
distinguish between two input graphs by propagating information on the local structure of k-tuples
of vertices. In their seminal work, Cai, Fürer and Immerman [6] show that dimension Ω(n)
is required for WL to distinguish between all non-isomorphic pairs of n-vertex graphs G, H
(in particular, k-WL is an incomplete isomorphism test for every k ≥1). However, the graph
pairs constructed by Cai, Fürer and Immerman only have small edit distance, and thus are not
a valid input for ε-GI (and the same holds for other known constructions). In the following, we
show that much better upper bounds on the WL dimension can be achieved if we are guaranteed
that the inputs graphs have large edit distance.

6
Concluding Remarks
We identified VC dimension as a key parameter governing the runtime of additive approximation
algorithms for the graph edit distance problem and the quadratic assigment problem: for a fixed
approximation error ε the runtime is nOε(d), where d is an appropriately defined VC dimension
of the input instance. Though we did not discuss them here except briefly in Remark 4.8, similar
results can be obtained for related assignement problems (see [1]).
To solve the robust graph isomorphism problem, which may be viewed as a special case
of graph edit distance, we can even use the Oε(d)-dimensional WL algorithm, which implies
that for all graphs the Oε(log n)-dimensional WL algorithm suffices to solve ε-GI, whereas exact
graph isomorphism requires WL dimension Ω(n).
The question whether for every ε there is a polynomial time algorithm solving ε-GI remains
open. We believe this a natural and interesting question that has received surprisingly little
attention. Related to this is the question whether for all ε there is a k (not depending on
the order n of the input graphs or their VC dimension d) such that k-WL solves ε-GI. Note that
our lower bound says that for every k there is an ε such that k-WL does not solve ε-GI.
