QUANDLES FROM GAUGE TRANSFORMATIONS
RYO HAYAMI
Abstract. In this paper, we investigate a quandle structure induced by an augmented rack
arising from a gauge transformation group. We construct a quandle from a principal bundle
and its discrete generalization. When we see a group as a (discrete) principal bundle over
a point, this quandle becomes equivalent to the generalized Alexander quandle for its inner
automorphism. Moreover, we construct a Lie and Noether quandle structure from a smooth
gauge transformation.

1. introduction
Racks and quandles are algebraic axiomatizations of the Reidemeister moves, which can be
regarded as generalizations of the conjugation of groups.
The definition of racks and quandles is summarized as follows.
Definition 1. A set X with a binary operation ◁: X × X →X is a rack if it satisfies
(1)
(x ◁y) ◁z = (x ◁z) ◁(y ◁z)
for all x, y, z ∈X (this relation is called self-distributivity) and the map −◁x : X →X is
bijective. When a rack (X, ◁) satisfies
(2)
x ◁x = x
for all x ∈X, we say that (X, ◁) is a quandle.
When X is a topological space and ◁is
continuous, (X, ◁) is called a topological quandle.
When X is a smooth manifold and ◁is
smooth, (X, ◁) is called a smooth quandle.
For quandles (X, ◁X) and (Y, ◁Y ), a quandle morphism is a map f : X →Y such that
f(x1 ◁X x2) = f(x1) ◁Y f(x2)
for all x1, x2 ∈X. When f is bijective, we say that f is a quandle isomorphism. A quandle
morphism between topological quandles which is a homeomorphism and a quandle morphism
between smooth quandles which is a diffeomorphism are also called a quandle isomorphism.

For a group G, the conjugation g1 ◁g2 = g−1
2 g1g2 satisfies the conditions of quandles. This
quandle (G, ◁) is called a conjugation quandle. (When we want to focus on the rack structure,
we call (G, ◁) a conjugation rack.) When G is a topological (resp. Lie) group, its conjugation
quandle becomes a topological (resp. smooth) quandle.
Although quandles were first introduced in a purely algebraic setting[1], topological quandles
introduced in [2] and smooth quandles introduced in [3] are also important research subjects
now. The relation between racks and quandles is summarized in [4]. In particular, there is a
process for making a quandle (X, ◁ι) from a given rack (X, ◁).
An important class of racks is an augmented rack, whose rack structure arises from the
conjugation rack of a group[5].
Definition 2. Let G be a group and act on a set X with a right action. We say that X with
a map Θ : X →G is an augmented rack if
(3)
Θ(x · g) = g−1Θ(x)g
holds for all g ∈G and all x ∈X.
When G is a topological group and act on a topological space X by homeomorphisms and Θ
is continuous, we say that (G, X, Θ) is an augmented topological rack. When G is a Lie group
and act on a smooth manifold X by diffeomorphisms and Θ is smooth, we say that (G, X, Θ)
is an augmented smooth rack.
For an augmented rack (X, G, Θ), X becomes a rack via
x ◁y := x · Θ(y).
When the augmented rack is topological (resp.smooth), the induced rack becomes a topological
(resp.smooth) rack.
The aim of this paper is to investigate racks and quandles which are given by gauge trans-
formations or their topological or set-theoretical analog.
A gauge transformation is defined as a fiber-preserving automorphism of a principal bundle.
Let π : P →M be a principal bundle over a smooth manifold M whose structure group is a
Lie group G. For the study of geometry of a gauge theory, we have to comupute the group of
the gauge transformations of P. The group of gauge transformations is defined as
Gauge(P) := {ϕ ∈Diff(P)|∀p ∈P, ∀g ∈G, π(ϕ(p)) = π(p), ϕ(p) · g = ϕ(p · g)}.
An important property of the group of gauge transformations is that this group is isomorphic
to
C∞(P, G)G := {f ∈C∞(P, G)|f(p · g) = g−1f(p)g}
with a group structure defined by the pointwise multiplication.
We can see that (P, G, C∞(P, G)G) is an augmented smooth rack. From this, we can define
the structure of a smooth rack. With a little more effort, we can associate a smooth quandle
structure on P with a gauge transformation on P.
The above discussion can be applied even without the smooth setting.
Therefore, if we
replace the smooth structure with the general topological structure or simply set-theoretical
structure, we obtain the topological or set-theoretical analog of quandles from (set-theoretical
of topological analog of) gauge transformations. We define and study these quandles, which
we call them gauge quandles.
Treating a group as a principal bundle over a point, we can construct a gauge quandle
structure on the group. We show that this quandle is equivalent to a generalized Alexander

In the smooth setting, by choosing a gauge transformation defining a smooth gauge quandle,
we can make an optional quandle-like structure which is called a Lie quandle. A Lie quandle
was introduced in [6] as a formulation of observables in a physical theory. We show that we
can construct a Lie quandle from gauge quandles parametrized by a real number and that this
Lie quandle, which we call a parametrized gauge quandle, is a Noether quandle, which is a
formulation of Noether’s theorem.
These results would connect the theory of principal bundles and gauge theories with the
theory of quandles.
Remark 3. There is a left self-distributive structure which is expressed as
x ▷(y ▷z) = (x ▷y) ▷(x ▷z)
and in some literatures racks and quandles are defined with this structures. We adopt the right
self-distributive structure because a principal bundle is usually defined with a right action. We
can easily modify the discussions in this paper to match the left self-distributive structure.
2. Quandles from (discrete) gauge transformations
In this section, we define a rack and a quandle structure from (a discrete or topological
generalization of) a gauge transformation.
First, we prepare a discrete version of a principal bundle.
Definition 4. Let P and M be sets and let G be a group. We say that P is a discrete principal
bundle over M whose structure group is G if there is a surjective map π : P →M and a right
action of G on P
P × G →P, (p, g) 7→p · g
which satisfies the conditions.
• For each m ∈M, there is a bijection ψm : π−1(m)
∼
−→G.
• For each p ∈π−1(m), G acts on p ∈π−1(m) freely and transitively, and they satisfy
π(p · g) = π(p) = m and ψm(p · g) = ψm(p)g.
When P and M is topological spaces, G is a topological group, π is continuous and there
is a local trivialization, it becomes an ordinary principal bundle. When P and M is smooth
manifolds, G is a Lie group, π is smooth and the local trivialization is smooth, it becomes a
smooth principal bundle.
Next, we define a discrete and topological generalization of a gauge transformation group.
Definition 5. We define a discrete gauge transformation group of a discrete principal bundle
as
Gauge(P) = {ϕ ∈Aut(P)|π ◦ϕ(p) = π(p), ϕ(p · g) = ϕ(p) · g}
where p ∈P and g ∈G.
Similarly, we define a topological gauge transformation group of a principal bundle as
Gauge(P) = {ϕ ∈Homeo(P)|π ◦ϕ(p) = π(p), ϕ(p · g) = ϕ(p) · g}
where p ∈P and g ∈G.

In the smooth setting, the topological gauge transformation group becomes an ordinary
gauge transformation group. When there is no risk of confusion, we will simply use the word
”gauge transformation group” in the all setting.
We consider the discrete case. Define the group of maps
Map(P, G)G := {f ∈Map(P, G)|f(p · g) = g−1f(p)g}
whose group structure is defined by the pointwise multiplication. Then, the map
Map(P, G)G →Gauge(P), f 7→ϕf

Note that ϕ−1

By the definition of Map(P, G)G, we can see that (P, G, Map(P, G)G) is an augmented rack.
Thus a gauge transformation ϕf on P defines a rack structure on P via
p1 ◁p2 := p1 · f(p2).
Next, we define a quandle structure on P. There is a general procedure to make quandles
from racks[4]. We apply this procedure to augmented racks.
Let (X, ◁) be a rack. Let ι : X →X be a map given by ι(x) ◁x = x and define a new binary
operation ◁ι : X × X →X by x ◁ι y := ι(x) ◁y. It is shown in [4] that (X, ◁ι) is a quandle. We
say that (X, ◁ι) is the quandle associated to (X, ◁).
Let (X, G, Θ) be an augmented rack. Then X has a rack product given by
(4)
x ◁y := x · Θ(y).
for all x, y ∈X. We consider the quandle associated to an augmented rack.
First, we find the ι : X →X which satifies ι(x) ◁x = x. For an augmented rack, the rack
structure is x ◁y = x · Θ(y). Therefore, if we define ι(x) := x · Θ(x)−1, we have
ι(x) ◁x = x · Θ(x)−1 · Θ(x) = x · eG = x
where eG is a unit of G and we can see that ι(x) ◁x = x. Thus we can conclude that the
quandle assocaited to the augmented rack (X, G, Θ) is (X, ◁ι) where
x ◁ι y = x · Θ(x)−1Θ(y).

f ∈Map(P, G)G define a gauge transformation ϕf of P. Then P has a rack structure via
p1 ◁f p2 : = p1 · f(p1)−1f(p2)
= ϕ−1

map, and the induced gauge quandle is
x1 ◁f x2 = x1 · e−1e = x1.
This quandle is called a trivial quandle.

4. future directions
Although our construction can be applied for discrete principal bundle, there are many ex-
amples of quandles with topological or smooth structures from topological or smooth principal
bundles.
If we replace Map(P, G)G with Map(P, X)G with (G, X, Θ) be an augmented rack, P has
another rack structure called a crossed module of racks[7]. The induced quandle would be
worth studying.
An important structure with the self-distributivity which is not discussed in this paper is a
Lie rack, which was introduced in [8] as an integrated object of a Leibniz algebra. The theory
around Lie racks may encounter gauge quandles in a generalized gauge theories.
The physical meaning of a parametrized gauge quandle is still ambiguous. Maybe it would
be useful for understanding line operators in gauge theories.
