ABSTRACT: The 2015 ﬁxed point result on rs-relational metric spaces due to Alam
and Imdad [J. Fixed Point Th. Appl., 17 (2015), 693-702] is equivalent with the classical
Banach Contraction Principle [Fund. Math., 3 (1922), 133-181]. This is also valid for the
1961 statement in metric spaces due to Edelstein [Proc. Amer. Math. Soc., 12 (1961),
7-10], or the 2005 ﬁxed point result in quasi-ordered metric spaces obtained by Nieto and
Rodriguez-Lopez [Order, 22 (2005), 223-239].
AMS SUBJECT CLASS [2020]: 47H10 (Primary), 54H25 (Secondary).
KEYWORDS:
Relational metric space; monotone application; ﬁxed point; global
strongly Picard operator; Banach Contraction Principle.
1. Introduction
Let X be a nonempty set. Call the subset Y of X, almost singleton (in short:
asingleton), provided [y1, y2 ∈Y implies y1 = y2]; and singleton if, in addition,
Y is nonempty; note that in this case, Y = {y}, for some y ∈X. Take a metric
d : X × X →R+ := [0, ∞[ over X; as well as a selfmap T ∈F(X). [Here, for
each couple (A, B) of nonempty sets, F(A, B) denotes the class of all functions
from A to B; when A = B, we write F(A) in place of F(A, A)]. Denote Fix(T ) =
{x ∈X; x = T x}; each point of this set is referred to as ﬁxed under T . The basic
existence and uniqueness criteria involving such points are to be discussed along
with some precise concepts. These, essentially, are suggested by the developments
in Rus [23, Ch 2, Sect 2.2]; and consist in three (distinct) stages, described as below.
(St-1) The uniqueness context is ultimately based on the general convention
(uni) We say that T is ﬁx-asingleton, if Fix(T ) is an asingleton;
and ﬁx-singleton, if Fix(T ) is a singleton.
(St-2) The convergence context consists of two metrical concepts:
(pic-1)
We say that T is a Picard operator (modulo d) when, for each
x ∈X, the sequence T Nx := (T nx; n ≥0) is d-Cauchy; and global Picard
operator (modulo d) when, in addition, T is ﬁx-asingleton
(pic-2) We say that T is a strongly Picard operator (modulo d) when, for
each x ∈X, the sequence T Nx is d-convergent with limn(T nx) ∈Fix(T );
and global strongly Picard operator (modulo d) when, in addition, T is ﬁx-

(St-3) The contractive setting consists in certain predicative type constructions
involving the data (X, d; T ); and has the general structure
(contr) (∀x, y ∈X): Π1(d; x, y) =⇒Π2(d; T Nx, T Ny);
where Π1, Π2 are propositional constructions.

3. Functional reflexive case
Let (X, d) be a metric space. Further, take a reﬂexive relation (R) on X; then,
(X, d, R) will be referred to as a relational metric space.

(i) T is (d, R; ϕ)-contractive, for some ϕ ∈F0(in, re; Bro)(R+)
