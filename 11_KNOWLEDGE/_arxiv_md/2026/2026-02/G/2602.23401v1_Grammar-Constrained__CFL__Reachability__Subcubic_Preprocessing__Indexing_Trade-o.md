Grammar-Constrained (CFL) Reachability:
Subcubic Preprocessing, Indexing Trade-offs,
and Structured Decoding Semantics
Faruk Alpay∗
Levent Sarioglu†
Abstract
We study grammar-constrained reachability (CFL reachability / context-free path queries)
in directed edge-labeled graphs, where a pair (s, t) is accepted iff there exists a path whose
trace belongs to LG(S) for a fixed context-free grammar G. We tighten the baseline cubic-time
saturation index for Chomsky normal form (CNF) grammars and then add four extensions: (i) a
nontrivial subcubic preprocessing class (linear grammars on sparse graphs) with explicit proof
and index construction; (ii) an alternative index that changes trade-offs via shared witness DAG
compression and optional dynamic support on a restricted class (bidirected Dyck reachability);
(iii) a new decomposition lemma (terminal-anchored normalization plus propagation accounting)
used to derive the subcubic bound; and (iv) a formal application shift to single-path semantics
(shortest accepted path), which changes the algorithmic objective and motivates a distance-aware
index for structured decoding. We validate the practical relevance of the linear grammar class
empirically: an analysis of 9,558 real-world JSON schemas from JSONSchemaBench [13] shows
that 8.4% fall into the strictly linear class under our conversion, with non-linearity overwhelmingly
attributable to variable-length array types—a finding that informs when the subcubic regime
applies in grammar-constrained neural decoding.
Executive Summary
This manuscript presents a concise algorithms/data-structures treatment of validation-gated reacha-
bility (CFL reachability / context-free path queries). It (a) states the problem and the standard
saturation index precisely under a CNF assumption, (b) establishes a provably better preprocessing
bound for a meaningful grammar/graph class (linear CFGs on sparse graphs), (c) defines a second
index with different trade-offs (compressed witnesses and optional dynamic edge updates on a
restricted Dyck/bidirected class), (d) introduces a formal application variant (single-path semantics:
shortest accepted path) that changes the algorithmic objective and motivates a distance-aware
index, and (e) provides an empirical grammar-class census over 9,558 real-world JSON schemas to
quantify the prevalence of the linear subclass in practice. Side-by-side tables of preprocessing/s-
pace/query/witness/update costs, pseudocode for all indices, and proof sketches for the key claims
are provided.

1.2
CFGs and CNF
Definition 1.2 (CFG). A context-free grammar is G = (N, Σ, P, S) where N is a finite set of
nonterminals, Σ terminals, P productions, and S ∈N start symbol. Write LG(A) for the language
generated by A. Let |N| be the number of nonterminals and |P| the number of productions.
Definition 1.3 (CNF). A CFG is in Chomsky normal form if each production is A →BC, A →a,
or (optionally) S →ε, with A, B, C ∈N and a ∈Σ.
1.3

Definition 1.4 (Validation-gated instance and query). A validation-gated instance is H = (G, G)
with common alphabet Σ. For s, t ∈V , define the (boolean) query
CFRH(s, t) = ∃path π : s ⇝t such that tr(π) ∈LG(S).
Definition 1.5 (Nonterminal relations). For each A ∈N, define RA ⊆V × V by
(u, v) ∈RA ⇐⇒∃π : u ⇝v with tr(π) ∈LG(A).

Correctness and complexity
Theorem 2.2 (Correctness of SatIndex). After Algorithm 1, for all A ∈N and u, v ∈V ,
MA[u, v] = 1 ⇐⇒(u, v) ∈RA.
Proof. We prove soundness and completeness.
Soundness. Consider the first time an entry MA[u, v] is set to 1. If it is created by a rule
A →a and an edge (u, v) with λ(u, v) = a, then the length-one path (u, v) witnesses (u, v) ∈RA.
If it is created by the optional rule S →ε on the diagonal, then the empty path at u witnesses
(u, u) ∈RS. Otherwise, MA[u, v] is created by some rule A →BC and a split vertex m with
MB[u, m] = 1 and MC[m, v] = 1 already present. By induction on the time of insertion, there exist
paths π1 : u ⇝m and π2 : m ⇝v with traces in LG(B) and LG(C), respectively. Concatenating
yields a path π = π1 · π2 from u to v whose trace lies in LG(A) by the rule A →BC. Thus every
true entry corresponds to some valid witness path, so MA[u, v] = 1 implies (u, v) ∈RA.
Completeness. Suppose (u, v) ∈RA. Then there is a path π : u = v0 ⇝vk = v with trace
w ∈LG(A). Fix a CNF derivation tree for A ⇒∗w and induct on its height. If the height is 1,
then either A →a with w = a or (only for A = S) A →ε with w = ε; the initialization step inserts
the corresponding entry. Otherwise, the root rule is A →BC and w = w1w2 where B ⇒∗w1 and
C ⇒∗w2. Let |w1| = ℓand let m = vℓbe the vertex on π after the first ℓedges; then the prefix
path u ⇝m has trace w1 and the suffix path m ⇝v has trace w2. By the induction hypothesis, the
algorithm eventually inserts MB[u, m] = 1 and MC[m, v] = 1. When the later of these two entries is
dequeued, the rule A →BC is applied and MA[u, v] is inserted. Since the queue runs to exhaustion,
every such (u, v) is eventually added, so (u, v) ∈RA implies MA[u, v] = 1.
Combining soundness and completeness proves the claim.
Theorem 2.3 (Baseline preprocessing/space/query bounds). Algorithm 1 runs in O(|P| · n3) time
and uses O(|N| · n2) space for matrices plus O(|N| · n2) witness records. Queries are answered in
O(1) by reading MS[s, t].
Proof. Let B be the set of binary productions A →BC. The initialization over terminal rules
inserts at most one entry per pair (A, u, v), so it costs O(|P|m) time by scanning labeled edges (or
O(m) after grouping edges by label), and the optional S →ε initialization costs O(n). Both are
dominated by the main saturation loop.
Each queue element (X, i, j) corresponds to a newly inserted matrix entry, hence there are at
most |N|n2 dequeues. Fix a binary rule A →BC ∈B. Consider the set of triples
TA→BC = {(i, j, k) ∈V 3 : MB[i, j] = 1 and MC[j, k] = 1}.
When (B, i, j) is dequeued, the algorithm iterates over all k with MC[j, k] = 1 and inspects exactly
the triples in TA→BC whose left part is (i, j); when (C, j, k) is dequeued, it iterates over all h with
MB[h, j] = 1 and inspects the triples whose right part is (j, k). Thus each triple in TA→BC is
processed at most twice (once from the left and once from the right). Since |TA→BC| ≤n3, the total
work charged to rule A →BC is O(n3), and summing over all binary rules yields O(|P|n3) time.
The constant-time checks/updates (MA and witness insertion) are subsumed in this bound.
For space, each A ∈N stores a boolean matrix MA ∈{0, 1}n×n and a constant-size witness
per true entry, for O(|N|n2) space each; the queue and any row/column lists fit within the same
asymptotic bound. Finally, queries are answered in O(1) by reading MS[s, t].

A Subcubic Preprocessing Class: Linear Grammars on Sparse
Graphs
This section implements extension (1): a nontrivial grammar/graph class with provably subcubic
preprocessing, assuming sparse graphs m = O(n).
3.1
Linear grammars and terminal-anchored normal form
CNF is not a linear-normal-form; therefore I separate the baseline CNF assumption (Sections 1–2)
from the linear-grammar subclass used for the improved bound.
Definition 3.1 (Linear CFG). A CFG is linear if each production has at most one nonterminal on
the right-hand side. Equivalently, productions are of the form A →xBy or A →x where x, y ∈Σ∗
and A, B ∈N.
Definition 3.2 (Terminal-anchored linear normal form (TALNF)). A linear grammar is in TALNF
if each production is one of:
A →a,
A →aB,
A →Ba,
S →ε,
where a ∈Σ and A, B ∈N.
Lemma 3.3 (Terminal-anchored normalization). Every linear CFG G can be transformed into an
equivalent TALNF grammar G′ in time O(|P|) and size O(|P|), preserving the generated language.
Proof. Write productions in the linear form A →xBy or A →x with x, y ∈Σ∗. First eliminate
ε-productions except possibly S →ε, and remove unit rules A →B by the standard unit-closure
procedure; for linear grammars this preserves linearity and takes O(|P|) time with at most constant-
factor size increase. Henceforth, no A →B rules remain and only S →ε may persist.

An Alternative Index: Shared Witness DAG Compression and
Optional Dynamics
This section implements extension (2): a new index with different trade-offs. The core idea is to
share repeated witness substructures across queries and optionally output compressed traces.
4.1
Shared-witness DAG representation
Definition 4.1 (Witness DAG nodes). A witness DAG is a rooted DAG whose nodes are of three
kinds:
Edge(u, v),
Eps(u),
Concat(p, q),
where p, q are witness nodes. A node denotes a (possibly empty) path; semantics are: Edge(u, v)
denotes the single edge (u, v); Eps(u) the empty path at u; Concat(p, q) concatenation.
Definition 4.2 (SWDIndex). Given any index that produces witnesses (baseline or linear),
SWDIndex replaces per-entry witness records by pointers into a hash-consed global witness DAG,
sharing identical subwitnesses. Query returns a pointer to a DAG root.

Theorem 4.3 (Space bound and extraction modes). Let T be the number of true entries across all
MA matrices. SWDIndex uses O(T) root pointers plus O(W) DAG nodes where W ≤O(T) and
each node is created at most once by hash-consing. It supports: (i) explicit path extraction in time
linear in output length; and (ii) compressed trace output in time O(DAG-size of the returned root).
Proof. We prove the space bound and the two extraction guarantees.
Space. Each true matrix entry stores only a root pointer, so there are T such pointers overall.
When a witness is created by the underlying index (baseline or linear), SWDIndex converts it into
a DAG node using the canonical constructors Edge(u, v), Eps(u), and Concat(p, q). Hash-consing
ensures that each constructor on the same arguments is materialized at most once. Thus the number
of DAG nodes created is at most the number of distinct constructor attempts, which is O(T).
Therefore total space is O(T) root pointers plus O(W) DAG nodes with W ≤O(T).
Explicit extraction. To output a concrete witness path from a root r, recursively expand nodes:
output the single edge for Edge(u, v), output nothing for Eps(u), and for Concat(p, q) output the
expansion of p followed by the expansion of q. Each output edge is emitted exactly once, so the
running time is linear in the explicit path length.
Compressed trace output. Let Dr be the sub-DAG reachable from r and topologically order
its nodes. Assign a fresh nonterminal Xx to each node x and emit: Xx →λ(u, v) for Edge(u, v),
Xx →ε for Eps(u), and Xx →XpXq for Concat(p, q). By induction over the topological order, Xx
derives exactly the trace denoted by x, hence Xr derives the trace of the witness. The number of
rules is |Dr| and the construction is linear in |Dr|, giving the stated bound.

A New Application Constraint: Single-Path Semantics (Shortest
Accepted Path)
This section implements extension (4): a formal application variant where I am not merely answering
existence, but producing one accepted path—specifically the shortest accepted path in number of
edges. This changes the index from boolean closure to distance-aware closure.
5.1
Single-path semantics
Following the path-based semantics viewpoint, define:
Definition 5.1 (Shortest accepted path problem). Given H = (G, G) and nodes s, t, define

For linear grammars in TALNF, shortest accepted path can be indexed in subcubic preprocessing
on sparse graphs.
Definition 5.2 (LinDistIndex). Assume G is TALNF. LinDistIndex stores, for each nonterminal
A and pair (u, v), the minimum path length DA[u, v] ∈N ∪{∞} such that A ⇒∗tr(π) for some

The dynamic programming rules mirror the boolean ones, replacing ∨by min and concatenation
by +1 for terminal-anchored steps. One can compute DA by a multi-source relaxation process on a
derived dependency graph whose relaxations are terminal-anchored and therefore admit O(|P|·m·n)

Theorem 5.3 (Subcubic preprocessing for shortest witnesses (linear, sparse)). If G is TALNF and
m = O(n), then LinDistIndex can be built in O(|P| · n2) time and O(|N| · n2) space, and returns
a shortest accepted path witness in time linear in the witness length.
Proof. We define an implicit unweighted dependency graph H whose nodes are triples (A, u, v) with
A ∈N and u, v ∈V . There is a directed edge in H for each terminal-anchored production and
graph edge:
• For every production A →aB and every graph edge u a−→x, include an edge (B, x, v) →(A, u, v)
for every v ∈V .
• For every production A →Ba and every graph edge x a−→v, include an edge (B, u, x) →(A, u, v)
for every u ∈V .
In addition, we treat terminal rules and S →ε as sources: if A →a and u a−→v, then (A, u, v) is a
source with distance 1; and if S →ε, then (S, u, u) is a source with distance 0.
Correctness.
We show that for every A, u, v, the shortest-path distance in H from the sources
to (A, u, v) equals DA[u, v]. First, any TALNF derivation for A can be read as a sequence of
terminal-anchored steps. If the derivation uses A →a, it corresponds to the source (A, u, v) with
length 1. If the derivation uses A →aB, then the witness path in G begins with a single edge
u a−→x followed by a path witnessing (B, x, v), and thus corresponds to a single edge in H from
(B, x, v) to (A, u, v) plus the inductive derivation for (B, x, v). The case A →Ba is symmetric, and
S →ε yields distance 0 on the diagonal. Therefore any accepted path yields a walk in H of the
same length, so DA[u, v] is at most the shortest-path distance.
Conversely, any path in H from a source to (A, u, v) corresponds to a sequence of terminal-
anchored derivation steps that prepend or append exactly one terminal edge at each step. Concate-
nating the corresponding graph edges yields a path π : u ⇝v whose trace is derived from A, and
the length of π equals the length of the path in H. Thus the shortest-path distance in H is at most
DA[u, v], proving equality and hence correctness.
Algorithm and time bound.
All edges in H have unit weight, so the distances are computed
by a multi-source BFS. We do not materialize H; instead, when a node (B, x, v) is dequeued, we
generate its outgoing edges on the fly by scanning Ina(x) for each rule A →aB and Outa(v) for
each rule A →Ba, exactly as in Algorithm 3, but performing relaxations on D. Each node (A, u, v)
is settled at most once by BFS, and a parent pointer stored at the first time it is discovered.
Fix a production A →aB. For a fixed x, (B, x, v) can be dequeued for at most n choices of v,
and each such dequeue scans Ina(x) once. Thus the total work charged to this rule is

7
Empirical Grammar-Class Census
The subcubic bound of Theorem 3.6 applies only when the constraining grammar is linear. A
natural question is how often this condition holds for grammars arising in practice. We answer this
by converting a large corpus of real-world JSON schemas into context-free grammars and classifying
each as linear or general.
7.1
Dataset and conversion procedure
We use JSONSchemaBench [13], a publicly available collection of 9,558 JSON schemas drawn
from GitHub repositories, the JSON Schema Store, Kubernetes configurations, Snowplow event
definitions, and Washington Post content models. The benchmark spans ten sub-datasets of varying
structural complexity and is the same corpus used to evaluate constrained-decoding frameworks
such as XGrammar, Outlines, and llama.cpp [14].
Each JSON schema is converted to a context-free grammar by a deterministic structural mapping.
Object types with fixed properties are modeled as chained productions (each carrying at most one
nonterminal continuation), preserving linearity. Array types with a variable-length items constraint
produce a self-referential repetition rule with two nonterminal symbols on the right-hand side, which
is inherently non-linear. Union types (oneOf, anyOf) and recursive references ($ref) are handled by
fresh nonterminals and alternatives. The conversion is purely structural: it faithfully represents the
branching and nesting dictated by the schema without introducing or suppressing any grammatical
complexity.

7.4
Implications for structured decoding
The class split and size gap visualized in Figures 2–3 directly inform when grammar-constrained
decoding can benefit from a linear+sparse index: the linear cluster is small but structurally coherent
and tends to be much smaller in schema size, which favors preprocessing and distance-aware
decoding.
The 8.4% linear share may appear small, but it represents a structurally well-defined and
practically meaningful slice of the schema landscape: schemas that describe flat records, configuration
entries, fixed-field API responses, and similar structures where no variable-length list is present.
For these schemas, the subcubic preprocessing of LinIndex (Theorem 3.6) and the distance-aware
LinDistIndex (Theorem 5.3) apply directly.
For the remaining 91.6%, the cubic baseline (SatIndex) governs worst-case preprocessing.
However, the empirical data reveal that non-linearity is overwhelmingly caused by a single, well-
understood pattern (variable-length arrays), raising the question of whether a targeted relaxation—for
instance, bounding maximum array length or treating bounded repetition as a finite unrolling—could
bring a larger fraction of practical schemas into a subcubic-amenable class. We leave the formal
development of such bounded-repetition extensions to future work.

Conclusion
We present a tightened, submission-ready treatment of validation-gated reachability (CFL reach-
ability / context-free path queries): (1) a baseline CNF saturation index with explicit witnesses,
(2) a provably subcubic preprocessing class (linear grammars on sparse graphs) with an explicit
propagation proof, (3) an alternative indexing trade-off via shared witness DAG compression and an
optional dynamic restricted-class index, (4) a formal application shift to single-path (shortest-witness)

semantics with a distance-aware linear+sparse index, and (5) an empirical grammar-class census
over 9,558 real-world JSON schemas showing that 8.4% fall into the linear class, with non-linearity
predominantly caused by variable-length array types. The empirical analysis both validates the
practical relevance of the linear subclass and identifies bounded-repetition relaxation as a concrete
direction for extending subcubic coverage.
