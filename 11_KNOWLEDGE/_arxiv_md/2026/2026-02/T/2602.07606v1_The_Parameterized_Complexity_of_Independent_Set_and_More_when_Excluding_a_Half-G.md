Abstract
A theorem of Ding, Oporowski, Oxley, and Vertigan implies that any sufficiently large twin-free
graph contains a large matching, a co-matching, or a half-graph as a semi-induced subgraph. The sizes
of these unavoidable patterns are measured by the matching index, co-matching index, and half-graph
index of a graph. Consequently, graph classes can be organized into the eight classes determined by
which of the three indices are bounded.
We completely classify the parameterized complexity of Independent Set, Cliqe, and Dominat-
ing Set across all eight of these classes. For this purpose, we first derive multiple tractability and hard-
ness results from the existing literature, and then proceed to fill the identified gaps. Among our novel
results, we show that Independent Set is fixed-parameter tractable on every graph class where the
half-graph and co-matching indices are simultaneously bounded. Conversely, we construct a graph
class with bounded half-graph index (but unbounded co-matching index), for which the problem is
W[1]-hard.
For the W[1]-hard cases of our classification, we review the state of approximation algorithms.
Here, we contribute an approximation algorithm for Independent Set on classes of bounded half-
graph index.

Introduction
Independent Set, Cliqe, and Dominating Set are three of the most fundamental NP-hard graph prob-
lems. From the parameterized perspective, all three are intractable on general graphs as well: Independent
Set and Cliqe are W[1]-complete [12], and Dominating Set is W[2]-complete [11] when parameterized
by the solution size. This motivates identifying structural restrictions under which these problems become
tractable.
A natural approach is to forbid certain bipartite patterns in the adjacency relation. Given two disjoint
vertex sets A = {a1, . . . , at} and B = {b1, . . . , bt}, we can ask: what are the canonical ways to organize
the edges between them? The three patterns we will be interested in are the following:
• the matching Mt:
aibj ∈E ⇔i = j
(equality)
• the co-matching Ct:
aibj ∈E ⇔i ̸= j
(inequality)
• the half-graph Ht:
aibj ∈E ⇔i ≤j
(order)
In some sense, these three patterns form the fundamental building blocks of complexity, as made pre-
cise in the following theorem proven independently by Ding et al. [10, Cor. 2.4], Alekseev [1, Thm. 3], and
Gravier et al. [23, Thm. 2]. (See also [28] for polynomial bounds in graphs of bounded VC-dimension.)
Theorem 1 ([10, 1, 23]). There exists a function Q : N →N such that every bipartite graph without twins
and with at least Q(h) vertices on one side contains a matching, co-matching, or half-graph of order h as an
induced subgraph.
With a bit of work, the bipartite statement extends to general graphs. Two vertices u, v in a graph G
are twins if N(u) \ {v} = N(v) \ {u}. This is an equivalence relation (see, e.g., [32, Lemma 1]), and we
call its classes the twin classes. The neighborhood diversity of G, introduced by Lampis [32], is the number
of twin classes of G. Each class induces either a clique or an independent set, and between any two classes
the adjacency is either complete or empty. Thus, graphs of small neighborhood diversity are extremely
simple. The interesting case is when neighborhood diversity is large: then one of the three patterns must
appear in G in a semi-induced way. Formally, a bipartite graph H appears semi-induced in G if there exist
A, B ⊆V (G) such that the bipartite subgraph between A and B is isomorphic to H. The matching index,
co-matching index, and half-graph index of G are the maximum orders of semi-induced matchings, co-
matchings, and half-graphs, respectively. For general graphs, Theorem 1 therefore implies the following
corollary (see Section A).
Corollary 1. There exists a function Q : N →N such that every graph with neighborhood diversity at
least Q(h) has either matching index, co-matching index, or half-graph index at least h.
A graph class has bounded matching/co-matching/half-graph index if the corresponding parameter is
bounded by a constant across all graphs in the class. We also call these classes matching-, co-matching-,
and half-graph-free. This yields a natural classification of graph classes into eight cases, depending on
which combination of the three indices is bounded.

Known entries.
When all three indices are bounded, neighborhood diversity is bounded, and all three
problems are polynomial-time solvable [32]. More generally, when the matching index is bounded, every
branch decomposition has bounded mim-width (maximum induced matching width), yielding polynomial-
time algorithms for Independent Set and Dominating Set [6]. These results account for the PTime
entries in Table 1.
For parameterized complexity, Fabiański et al. [20] show that Dominating Set is FPT on classes
that are simultaneously half-graph-free and co-matching-free. On general graphs, Independent Set and
Cliqe are W[1]-hard and Dominating Set is W[2]-hard [8].
New entries.
Several hardness entries use previously known reductions, but the connection to the pat-
tern indices had not been made explicit. For instance, it is known that Independent Set [35] and Dom-
inating Set [36] are W[1]-hard on unit square graphs; we observe that these graphs have bounded co-
matching index (Corollary 2). In such cases, we cite both the original hardness result and our observation
connecting it to the pattern indices.
Our main new tractability result is that Independent Set is FPT on classes that are simultaneously
half-graph-free and co-matching-free (Theorem 4). We obtain this via indiscernibility-based methods in-
spired by [16]: in such graphs, long vertex sequences arise where outside vertices connect to almost all
or almost none of the sequence elements, enabling efficient reduction rules. Note that Independent Set
and Dominating Set are NP-hard on planar graphs [21], which are co-matching-free and half-graph-free,
justifying the use of FPT algorithms.

Contribution 2: Approximation
Dominating Set admits an O(log n)-approximation via the greedy algorithm [29], while Independent
Set and Cliqe are notoriously hard to approximate: PCP-based results rule out n1−ε-approximations
under standard assumptions [26]. To obtain even better approximation guarantees for Dominating Set,
one may consider the VC-dimension of the graph’s neighborhood set system. On graphs of bounded VC-
dimension, ε-net methods yield an O(log k)-approximation [5]. But bounded VC-dimension does not yield
comparable improvements for Independent Set or Cliqe: for instance, d-dimensional box graphs have
VC-dimension O(d2) [22], but no O(logd−1 n)-approximation is known for Independent Set [7].
We show that bounding the pattern indices does yield non-trivial approximations: Given a graph G,
we show how to compute ...
1. ...in time O(n2h+2) an independent set of size k1/h,
(Theorem 3)
2. ...in time O(n3 log(n)) an independent set of size log2c+2(k) −2,
(Corollary 4)
where h is the half-graph index of G, c is the co-matching index of G, and k is the size of the largest
independent set in G. The first result is based on a novel branching algorithm with branching depth
bounded by the half-graph index. The second result is an algorithmic utilization of an argument by Gyárfás
to show χ-boundedness of graph classes excluding an induced path [25].
Related work
We highlight three connections of our work. See Figure 1 for a diagram of relevant notions.
Connections to sparsity theory.
The biclique index of a graph is the maximum t such that Kt,t appears
semi-induced. Accordingly, a class is biclique-free if its biclique index is bounded. Biclique-free graph
classes are extremely general sparse graph classes, as they generalize planar graphs, graphs of bounded
degeneracy, minor-free graphs, and nowhere dense graph classes. However, from the perspective of our
three target problems, the biclique-free regime is largely under control. Independent Set and Cliqe are
FPT and polytime solvable, respectively, for trivial reasons: Any Kr contains K⌊r/2⌋,⌊r/2⌋semi-induced, so
the clique number is bounded by a class-dependent constant. By Ramsey-type arguments, bounded clique
number implies the existence of unbounded independent sets, and therefore Independent Set is FPT. Also
Dominating Set has been proven to be FPT on biclique-free classes [41].
To go beyond sparse classes, the community considered classes that are simultaneously half-graph-free
and co-matching-free (also called the semi-ladder-free classes). Semi-ladder-freeness generalizes biclique-
freeness, but also includes dense classes such as map graphs [20] or more generally all graph classes that
can be encoded by existential positive first-order formulas in nowhere dense classes [33]. Fabiański et
al. [20] and Guillemot [24] showed that Dominating Set is FPT even on all semi-ladder-free classes.
Guillemot [24] asked whether tractability can be extended to classes that are just half-graph-free (and not
necessarily co-matching-free). It is natural to ask the same question for classes that are just co-matching-
free (and not necessarily half-graph-free). Our work answers both questions negatively.
The progressive exploration approach of Fabiański et al. [20] also applies to Independent Set, albeit
for this problem, they could only achieve tractability in a strict subfragment of semi-ladder-freeness. Our
FPT algorithm for semi-ladder-free classes (Theorem 4) generalizes their results.

Connections to width measures.
Eiben et al. [19] introduced a unifying framework for width measures
based on the notion of F-branchwidth. In this framework, the same patterns we studied (half-graphs,
co-matchings, and matchings) appear as forbidden semi-induced subgraphs between the sides of a cut
in branch decompositions. Building on this framework, in [2], the width measure cham-width (“chain-
anti-matching-width”) was defined, which measures the co-matching and half-graph indices across cuts.
Classes of bounded cham-width strictly generalize semi-ladder-free classes. It was asked in [2] whether
Independent Set is FPT on classes of bounded cham-width. Our FPT algorithm for semi-ladder-free
classes gives hope for a positive answer.
Connections to model theory.
The half-graph pattern has strong ties to model theory, where its ab-
sence characterizes stable theories. Monadically stable classes are those in which all relations definable
in first-order logic with colors are half-graph-free. The first-order model checking algorithm for monad-
ically stable classes implies fixed-parameter tractability of Independent Set, Cliqe, and Dominating
Set [13, 15] on these classes. The requirement of half-graph-freeness for all first-order definable relations
excludes many natural graph classes. It is therefore natural to ask whether tractability can be extended to
classes where only the plain adjacency relation is half-graph-free. Our hardness results (Theorems 2 and 5)
show that edge-level half-graph-freeness alone does not suffice for tractability of the three considered
problems, justifying the necessity of the stronger assumptions used in stability theory.

Hardness of Independent Set for half-graph-free classes
In this section, we prove the existence of a graph class that has bounded half-graph index, but on which the
Independent Set problem is W[1]-hard. We will do this by providing a reduction from the Grid Tiling
problem that does not create large half-graphs. Our reduction is inspired by a reduction from [4] between
the same two problems. We note that the Independent Set instances created in [4] have unbounded
half-graph index but bounded co-matching index (see also Section 7 for a different reduction for the co-
matching case). Conversely, the instance that we create will have bounded half-graph index but unbounded
co-matching index. As we later show in Section 5, this tradeoff is unavoidable under standard complexity
assumptions, since Independent Set is FPT on every class that has simultaneously bounded half-graph
and co-matching index.
The Grid Tiling problem was introduced in [37]. Its input consists of integers k, n ∈N and a collec-
tion S containing a non-empty set of tiles Sπ ⊆[n] × [n] for each grid cell π ∈[k]2. The goal is to decide
whether there exists a selection of tiles s(π) ∈Sπ for all π ∈[k]2 such that:
• The tiles s(π) and s(π▶) have the same first component
for all cells π = (i, j) ∈[k −1] × [k] and π▶:= (i + 1, j); and
• The tiles s(π) and s(π▽) have the same second component
for all cells π = (i, j) ∈[k] × [k −1] and π▽:= (i, j + 1).
See Table 2 for an example instance. It is known that Grid Tiling is W[1]-hard parameterized by the grid
size k [8, Thm. 14.28].
