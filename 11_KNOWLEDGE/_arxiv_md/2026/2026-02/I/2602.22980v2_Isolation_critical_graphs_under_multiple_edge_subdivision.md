KARL BARTOLO, PETER BORG, MAGDA DETTLAFF, MAGDALENA LEMA´NSKA,
AND PAWE L ˙ZYLI´NSKI
Abstract. This paper introduces the notion of an (ι, q)-critical graph. The
isolation number of a graph G, denoted by ι(G) and also known as the vertex-
edge domination number of G, is the size of a smallest subset D of the vertex
set of G such that the subgraph induced by the set of vertices that are not in
the closed neighbourhood of D has no edges. A graph G is (ι, q)-critical if every
subdivision of q edges of G gives a graph whose isolation number is greater
than ι(G), and G has q −1 edges such that subdividing them gives a graph
whose isolation number is ι(G). We show that an (ι, q)-critical graph exists
for every integer q ≥1. We prove that if G is a connected m-edge non-star
graph, then G is (ι, q)-critical for some q ≤m −1. We show that this bound
is best possible. We provide a general characterization of (ι, 1)-critical graphs
as well as a constructive characterization of (ι, 1)-critical trees, demonstrating
that (ι, 1)-criticality can be checked in linear time for trees.
AMS Subject Classification: 05C05, 05C35, 05C69.
Keywords: isolation number, edge subdivision, critical graphs.
1. Introduction
Let G = (V (G), E(G)) be a connected graph of order n = |V (G)| ≥1 and
size m = |E(G)| ≥0. For S ⊆V (G), let N[S] denote the closed neighbourhood
of S (the set of vertices in S and their neighbours).
A subset D of V (G) is a
dominating set of G if V (G) = N[D] [33, 35], and γ(G) denotes the size of a smallest
dominating set of G.
The concept of isolation arises by relaxing the condition
V (G) = N[D]. It was introduced by Caro and Hansberg in [19] and then extensively
studied in [6, 7, 8, 9, 10, 11, 12, 14, 15, 21, 29, 32, 39], from different perspectives,
to mention just a few.
Concretely, let F be a set of graphs.
We say that D
is an F-isolating of G if no subgraph of G −N[D] is a copy of a graph in F.
The F-isolation number of G, denoted by ι(G, F), is the size of a smallest F-
isolating set of G.
If F = {F}, then we may replace F by F in the defined
terms and notation. If F = {K2}, then the terms F-isolating set and F-isolation
number, and the notation ι(G, F), are abbreviated to isolating set, isolation number,
and ι(G), respectively.
An isolating set is also called a vertex-edge dominating
set [13, 18, 37, 38, 40, 41, 42, 44, 49, 50]. An isolating set of G of size ι(G) will be
called a minimum isolating set of G or an ι(G)-set. Note that D is a dominating set
of G if and only if it is a K1-isolating set of G (that is, G −N[D] has no vertices).
Thus, γ(G) = ι(G, K1).

the subdivision vertex, is the operation that yields the graph Ge with V (Ge) =

Background. The concept of critical graphs in domination has a long history with
numerous operations that alter a graph in small ways (for standard domination,
see for example [1, 16, 17, 27, 45, 46, 47, 48]). The idea of q-criticality for the
domination number with respect to subdivision of edges was introduced recently by
Dettlaff et al. in [26] (for additional results related to the effect of edge subdivision
on the domination number of a graph, see for example [2, 4, 28, 30]). Recall that
a graph G is (γ, q)-critical if γ(GA) > γ(G) for each A ⊆E(G) with |A| = q, and
γ(GA′) = γ(G) for some A′ ⊆E(G) with |A′| = q −1. The paper [26] discusses
some general properties of (γ, q)-critical graphs and characterizes the (γ, |V (T)|−1)-
critical trees T as well as some classes of (γ, k)-critical trees for k ∈{2, 3}.

3. Graphs which are (ι, q)-critical
We consider two different perspectives on tackling the existence of (ι, q)-critical
graphs, the first one stated as follows.
Given an integer q ≥1, can we find a
connected graph which is (ι, q)-critical? To answer this question, we require the
following definition.
A d-wounded spider St,t−d is the graph formed by subdividing t−d ≤t−1 edges
of a star K1,t, t ≥2 (d is a number of edges that we do not subdivide; d ≥1).
Proposition 3.1. If T is a d-wounded spider St,t−d, then T is (ι, d + 1)-critical.
Proof. Let S be a copy of K1,t, let x be the central vertex of S, and let v1, . . . , vt ∈
V (S) \ {x}. To obtain a copy T of the d-wounded spider St,t−d, simply subdivide
xvi with subdivision vertex ui for every i ∈[t] \ [d]. Note that ι(T) = 1.
Consider now the set A = {xvi : i ∈[d]}. The set {x} is an isolating set of T and
TA. Therefore, q ≥d. Let A′ be a set of d + 1 edges of T. Note that A′ contains
at least one edge in E(T) \ A. Thus, diam(TA′) = 5. Hence, ι(TA′) > 1 = ι(T).
Therefore, T is (ι, d + 1)-critical.

4. (ι, 1)-critical graphs
In this section, we focus on various characterizations of (ι, 1)-critical graphs.
4.1. The general case. The first characterization follows a similar pattern for the
characterization of (γ, 1)-critical graphs in [43], given below.
Theorem 4.1. [43] A graph G is (γ, 1)-critical if and only if every γ(G)-set is a
2-packing.
This approach for (ι, 1)-critical graphs requires another layer of intricacy to en-
capsulate a similar characterization due to the added difficulty imposed by the
isolated vertices obtained from the deletion of the closed neighbourhood of a min-
imum isolating set of an (ι, 1)-critical graph. We begin by providing a definition
which is the crux of this approach.
Definition 4.2. If G is a graph, A, B and C are non-empty sets that partition
V (G),
(i)
A ∪C and B are independent sets of G,
(ii)
N(A) = B = N(C),
(iii)
A is a 3-packing of G, and
(iv)
no vertex in A is a leaf of G,
then we say that (A, B, C) is a critical tripartition of G.

4.3. Algorithmic aspects. In 2025, Chen et al. [20] gave a linear time algorithm
for determining a minimum isolating set of a tree (among other interesting algo-
rithmic results). On the other hand, a set D is a unique isolating set of a tree
T if and only if each vertex v ∈D has at least two private edges e, f such that
dT (v, e) = dT (v, f) = 1 and dT (e, f) = 2 [44]. Therefore, once we compute any
minimum isolating set of a tree T in linear time, we can verify in linear time whether
T has a unique ι(T)-set, which is a necessary condition for T to be (ι, 1)-critical.
Suppose that D is a unique minimum isolating set of T. Since, for a given graph
G and three non-empty sets A, B and C that partition V (G), we can verify in linear
time whether (A, B, C) is a critical tripartition of G (keeping in mind Theorem 4.4)
we immediately obtain the following corollary.

Corollary 4.11. Given an n-vertex tree T, it can be verified in linear time whether
T is (ι, 1)-critical or not.
By the same arguments, for any n-vertex graph G, if we can enumerate all
ι(G)-sets in time T(n), then we can verify in O(T(n) · n) time whether G is (ι, 1)-
critical. Recall that in 2008, Fomin et al. [31] gave an O(1.7159n) time algorithm
for enumerating all minimal dominating sets of an n-vertex graph, thereby showing
that the maximum number of minimal dominating sets of such a graph is at most
1.7159n. On the other hand, for several classes of graphs, there exist better upper
bounds, see for example [5, 22, 23]. To the best of our knowledge, there is no such
general result for enumerating all minimal isolating sets of a graph.
