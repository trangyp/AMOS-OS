Abstract
We consider the single-source shortest paths problem on a directed graph with real-
valued (possibly negative) edge weights and solve this problem in n2+o(1) time by refining
the shortcutting procedure introduced in Li, Li, Rao, and Zhang (2026).
1
Introduction
We consider the problem of computing single-source shortest paths on weighted directed graphs.
Despite its long history, the past few years have witnessed exciting breakthroughs for this prob-
lem in multiple different settings. When all edge weights are non-negative, the classic Dijkstra’s
algorithm solves the problem in O(m+n log n) time, which has been improved for sparse graphs
to O(m log2/3 n) [DMM+25]. When edge weights are integral (but possibly negative), the prob-
lem was solved in ˜O(m) time1 [BNWN25] and m1+o(1) time [CKL+25], with the latter solving
the more general problem of minimum-cost flow.
In the general case of real-valued edge weights, the 70-year-old Bellman-Ford algorithm was
the fastest until the recent breakthrough ˜O(mn8/9) time algorithm of Fineman [Fin24]. Subse-
quent work has refined Fineman’s approach [HJQ25, HJQ26, QT26], improving the runtime to
˜O(mn0.696 + (mn)0.850). Li, Li, Rao, and Zhang [LLRZ26] recently introduced a new approach
for the problem. Their algorithm adds shortcut edges to the graph to reduce the number of
negative edges along shortest paths by a constant factor. By iterating this procedure, they can
compute the shortest paths in the shortcutted graph using an O(1)-hop shortest path algorithm.
The bottleneck of the algorithm in [LLRZ26] was the ˜O(n2.5) time required to construct
the shortcut edges added in each iteration. We refine their shortcut construction to obtain our
n2+o(1) algorithm2. Along the way, we develop a stronger version of the betweenness reduction
technique used in all prior works on the topic, which we believe may be of independent interest.
Theorem 1. There is a randomized algorithm for single-source shortest paths on real-weighted
directed graphs which runs in n2+o(1) time.

Preliminaries
All graphs G = (V, E) in this paper are directed and have (possibly negative) real edge weights.

the set of negative vertices. For a vertex u ∈V , we define Nout(u) = {v ∈V : (u, v) ∈E} and

Like prior work, we heavily rely on a subroutine for efficiently computing single-source
shortest paths with few negative edges. For a positive integer h called the hop bound, define
the h-negative hop distance dh(s, t) as the minimum weight (s, t)-path with at most h negative
edges. Given a source vertex s, we can compute dh(s, t) for all other t ∈V in O(h(m + n log n))
using a hybrid of Dijkstra and Bellman-Ford [DI17].
Also like prior work, our algorithm makes use of potential functions ϕ : V →R that reweight
the graph, where each edge (u, v) has new weight wϕ(u, v) = w(u, v) + ϕ(u) −ϕ(v). The key
property of potential functions is that for any vertices s, t ∈V , all (s, t)-paths have their weight
shifted by the same additive ϕ(s) −ϕ(t). A potential ϕ is valid if wϕ(u, v) ≥0 for all edges
(u, v) with w(u, v) ≥0, i.e., it does not introduce any new negative edges.
2.1
Copies of Vertices
In our algorithm, we will build graphs Gτ from the original input graph G = (V, E), by adding
vertices and edges. Vertices in Gτ are classified into two categories: a base vertex and a copy
of some base vertex. The set of base vertices V0 is initialized as V0 = V and the set of copy
vertices is initially empty. Throughout the algorithm, we will add new base vertices and copies
of base vertices. Suppose we have c copies of each base vertex v ∈V0. The original vertex is
denoted v0 and the copies are labeled vi for i ∈[c]. We maintain the following invariants:
(I1) each copy vi is associated with a shift δ(vi) ∈R, with δ(v0) = 0 for all v ∈V0.
(I2) every edge (ui, vj) ∈Gτ satisfies ω(ui, vj) ≥dGτ (u0, v0) + δ(vj) −δ(ui)
These invariants formalize what it means for an added vertex to be a copy of a base vertex.
The shift δ(vi) represents how much “higher” the copy vi is relative to the base vertex v0, where
distances to higher vertices are larger. This is formalized in the constraints on the edge weights
in (I2), which also guarantees that shortest path distances aren’t decreased by adding copies.
When we add a base vertex to the graph, we will prove that invariants are maintained.
When we add a copy of base vertices, we will define a shift and apply the following claim:
Claim 2. Consider graph Gτ satisfying (I1)–(I2). For any base vertex v ∈V0, suppose one
adds a new copy vnew of v with shift δ(vnew) ∈R to Gτ, along with the following edges:
• For each u ∈V , let C(u, v) = {vi : ω(u, vi) + δ(vnew) −δ(vi) ≥0}. If C(u, v) ̸= ∅, add
edge (u, vnew) of weight ω(u, vnew) = minvi∈C(u,v) ω(u, vi) + δ(vnew) −δ(vi).
• For each w ∈V , let C(v, w) = {vi : ω(vi, w) + δ(vi) −δ(vnew) ≥0}. If C(v, w) ̸= ∅, add
edge (vnew, w) of weight ω(vnew, w) = minvi∈C(v,w) ω(vi, w) + δ(vi) −δ(vnew).
Then invariants (I1) and (I2) are still satisfied in the resulting graph.
Proof. Invariant (I1) is still satisfied since the new vertex vnew has an associated shift δ(vnew).
Next, we need to verify Invariant (I2) for edges incident to vnew. For an in-edge (ui, vnew), the
weight is ω(ui, vnew) = ω(ui, vj) + δ(vnew) −δ(vj) for some vj ∈C(ui, v) by definition in the
claim statement. But by Invariant (I2), we know w(ui, vj) ≥dGτ (u0, v0) + δ(vj) −δ(ui). Thus,
we have ω(ui, vnew) ≥dGτ (u0, v0) + δ(vnew) −δ(ui), as required by Invariant (I2). The proof
for out-edges (vnew, wj) is symmetric.

During an iteration of our algorithm, we will compute a valid reweighting ϕτ, which may
cause a negative edge in Gτ to become non-negative. However, even if a negative edge in Gτ
is non-negative after the reweighting ϕτ, we will still call this edge negative through the rest of
the iteration and count it towards hops in h-hop shortest paths. Following prior work, we refer
to this as freezing the set of negative edges before applying a reweighting.
In an iteration, we also add imaginary negative edges to the graph. The heads of imaginary
negative edges will not be considered a negative vertex, and will not be included in N, but will
still be counted towards hops in h-hop shortest paths. This distinction is important when we
apply betweenness reduction: hop-distance will be measured with respect to all negative edges
but betweenness is only measured with respect to real ones (via the set N).

proceeds over L = Θ(log k) iterations. In each iteration, we add some nodes and edges to the
graph in order to decrease the number of negative edges on shortest paths. Let Gτ = (Vτ, Eτ)

We now give our algorithm for Theorem 9.
The high level approach is the same as in
[LLRZ26]. First, we apply a reweighting to the graph to reduce the betweenness for every pair
of vertices. In the reweighted graph, we compute forward and backward searches from each
negative vertex such that every vertex in the backward search can negatively reach every vertex
in the forward search using few hops. Finally, we add shortcut edges between the backward and
forward searches for each negative vertex to decrease the number of hops needed in a shortest
path by a constant factor. To implement this strategy more efficiently than [LLRZ26], we need
to strengthen each of the steps, as we see next.
4.1
Stronger Betweenness Reduction
In this section, we define a stronger notion of betweenness and show how to compute a reweight-
ing which reduces strong betweenness. Informally, the weak betweenness of s, t ∈V is the num-
ber of vertices v such that there is an 2h-hop negative path from s to t through v (actually, it
requires dh(s, v)+dh(v, t) < 0). Strong betweenness relaxes the condition, allowing the negative
path to start and end at arbitrary vertices s′, t′, as long as the path goes through s and t.
Definition 10. For a pair (s, t) ∈V × V and a subset N ⊆V , its h-hop strong betweenness,
denoted SBWN(s, t), is the number of vertices v ∈N for which there exist s′, t′ ∈V satisfying
dh(s′, s) + dh(s, v) + dh(v, t) + dh(t, t′) < 0.
We remark that strong betweenness is defined with respect to a set of vertices N ⊆V . In
our paper, this will always be the set of negative vertices N in the original graph, hence the
notation, so the dependence N is often left implicit. We emphasize that N need not contain the
endpoint of every negative edge in the graph. Indeed, we will be applying betweenness reduction
on a graph with additional negative edges, but with the original set of negative vertices N.
