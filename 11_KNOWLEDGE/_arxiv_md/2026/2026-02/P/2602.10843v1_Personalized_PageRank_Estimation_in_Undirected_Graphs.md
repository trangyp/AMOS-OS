Personalized PageRank Estimation in Undirected Graphs
Christian Bertram∗and Mads Vestergaard Jensen†
BARC, University of Copenhagen‡
Abstract
Given an undirected graph G = (V, E), the Personalized PageRank (PPR) of t ∈V with
respect to s ∈V , denoted π(s, t), is the probability that an α-discounted random walk starting
at s terminates at t. We study the time complexity of estimating π(s, t) with constant relative
error and constant failure probability, whenever π(s, t) is above a given threshold parameter
δ ∈(0, 1). We consider common graph-access models and furthermore study the single source,
single target, and single node (PageRank centrality) variants of the problem.
We provide a complete characterization of PPR estimation in undirected graphs by giving
tight bounds (up to logarithmic factors) for all problems and model variants in both the worst-
case and average-case setting. This includes both new upper and lower bounds.
Tight bounds were recently obtained by Bertram, Jensen, Thorup, Wang, and Yan [4] for
directed graphs. However, their lower bound constructions rely on asymmetry and therefore do
not carry over to undirected graphs. At the same time, undirected graphs exhibit additional
structure that can be exploited algorithmically.
Our results resolve the undirected case by
developing new techniques that capture both aspects, yielding tight bounds.

Introduction
Estimation of Personalized PageRank (PPR) is a standard tool for ranking vertices in a graph.
Given an undirected graph G = (V, E) with n vertices, the PPR π(s, t) of a target t ∈V with
respect to a source s ∈V is defined as the probability that an α-discounted random walk starting
at s terminates at t. An α-discounted random walk is a random walk which in each step terminates
with probability α, and otherwise moves to a uniformly random neighbor. Following prior work, we
assume α to be a constant [13, 16]. If we choose the source s uniformly at random, the probability
of terminating at t is π(t) = P
s π(s, t)/n, which is referred to as the PageRank centrality of t.
This global ranking notion is the quantity studied in the seminal work of Page, Brin, Motwani,
and Winograd [12] in the context of ranking web pages. These PageRank problems have been
extensively studied for undirected graphs, with some of the most important results in [4, 10, 11,
14, 15]. PageRank also has numerous applications in information retrieval [8, 12], recommendation
systems [7, 9], machine learning [2, 3], and graph partitioning [1, 5].
In this work, we study the computational complexity of estimating π(s, t). Concretely, for an
approximation threshold δ ∈(0, 1], we require an estimate of π(s, t) that is within a constant relative
error whenever π(s, t) > δ, with constant failure probability. If instead π(s, t) ≤δ, we only require
an additive error of O(δ). We formalize this estimation requirement later in the introduction. We
further consider the following query problems from the litterature:
• Single pair: Given a pair (s, t) ∈V 2, estimate π(s, t),
• Single source: Given a source s ∈V , estimate π(s, t) for each target t ∈V ,
• Single target: Given a target t ∈V , estimate π(s, t) for each source s ∈V , and
• Single node: Given a vertex t ∈V , estimate π(t).
We measure the computational complexity in the standard adjecency-list model [4, 16], where the
algorithm can access the input graph only through an oracle supporting the query DEG(v) to obtain
the degree of v and NEIGH(v, i) to obtain the i-th neighbor of v, each in constant time. These queries
can only be applied to vertices given in the input or returned by previous queries. Following the
literature, we also consider extensions of this model in which the algorithm additionally has access
to any subset of the following queries: JUMP() which returns a uniformly random vertex [13, 16],
NEIGH-SORTED(v, i) which returns the i-th neighbor of v when neighbors are ordered by degree
in increasing order [4, 15], and ADJ(u, v) which tests whether uv ∈E [4]. In the literature, the
adjacency-list model with JUMP is referred to as the graph access model [16].
We also consider average-case complexity, in the following sense. For the single pair problem,
this measure the expected running time when (s, t) is drawn uniformly at random from V 2. For
the single source, single target, and single node problems, this measures the expected running time
under a uniformly random choice of the designated source or target vertex, respectively.
Note
that the graph is still “worst-case” and that the algorithm must still be correct (with constant
probability) for every source/target.
Recently, all of the above problems and model variants were studied for directed graphs, where
tight bounds were established in [4]. A main goal of this work is to understand how these bounds
change in the undirected setting. In [4], they provide lower bounds that exploit asymmetry, and
these do not directly carry over to undirected graphs. In contrast, undirected graphs satisfy the
reversibility property [10], which relates π(s, t) and π(t, s), by the identity
d(s)π(s, t) = d(t)π(t, s),

landscape of (Personalized) PageRank estimation in undirected graphs, and shows how the different
query types affect the computational complexity. This could be important when deciding which
queries to support when designing an application programming interface (API) for large graphs.
Lower bounds.
We construct tight lower bounds for all problems and model variants. Before
this work, only basic folklore lower bounds existed [4], together with a tight lower bound for the
single node problem [14] in the bare adjacency-list model. Our lower bounds are inspired by the
directed lower bound constructions of [4], which in turn are inspired by the directed single node
construction of [16]. As their constructions are asymmetric, they do not directly carry over to
undirected graphs. For each Personalized PageRank problem, we give an undirected hard instance
with tunable parameters that can be set to match the different model variants. This construction
is more complex than in [4], since the undirected setting requires additional parameters.
Upper bounds.
We provide four main new upper bounds. Let us briefly present the novel ideas
behind each of them. Some of them build on existing algorithms, which we modify or combine to
get tight bounds. Table 2 summarizes prior upper bounds together with our new ones.
Single node algorithm [Theorem 3.1.1].
The previous best single node algorithm is known
as backwards monte carlo [14] and runs in O(m1/2) time. It works by generating α-discounted
random walks from t and then using the reversibility property (1) to get an estimate for π(t).
This is tight in all models except when we have access to all queries JUMP, NEIGH-SORTED, and
ADJ, in which case, we improve the running time to O(n1/2).
This is the first application of
this query combination in undirected graphs. The main observation is that we can treat high-
degree and low-degree neighbors of t (separated efficiently using NEIGH-SORTED) differently. For
low-degree neighbors we can efficiently compute their contribution to π(t) using backwards monte
carlo. For high-degree neighbors, backwards sampling becomes too costly, and instead we estimate
their contribution to π(t) by moving to a random vertex using JUMP and walking from there. The
intuition is that high-degree vertices have a higher probability of being hit by a random walk. To
check if we actually hit a high-degree neighbor, we use the ADJ query.

2.2
Monte Carlo Sampling
Arguably, the simplest way of solving the single source problem is by generating multiple indepen-
dent α-discounted random walks starting at the source vertex, and estimate π(s, u) for each u ∈V
by the fraction of walks that end at u. This is known as Monte Carlo sampling [6]. A small relative
error is required only when π(s, u) > δ, so standard Chernoff bounds imply that O(1/δ) walks are
sufficient to achieve a constant relative error with constant success probability. Since the expected
length of an α-discounted walk is 1/α = O(1), this method solves the single source problem in time
O(1/δ). In Section A.1, we give an algorithm for sampling an α-discounted walk from a vertex u,
RandomWalk(G, u, α), in expected time O(1/α).
In a similar way, we can also solve the single target problem by generating multiple independent
α-discounted random walks starting at the target vertex (known as backwards Monte Carlo sam-
pling) [14]. This gives estimates ˆπ(t, u) of π(t, u) for every u ∈V . Using the reversability property
stated in Theorem 2.1.1, this also gives estimates ˆπ(u, t) = ˆπ(t, u)d(u)/d(t) of π(u, t). A small
relative error is required only when π(u, t) > δ, or equivalently when π(t, u) > δd(u)/d(t) = δ′.
Standard Chernoff bounds imply that O(1/δ′) = O(d(t)/δ) walks are sufficient to achieve a constant
relative error with constant success probability. The worst-case complexity is O(d(t)/δ) = O(n/δ),
and averaged over all targets t, the complexity is O(d/δ).

2.4
Power Method
The local pushing algorithm BacwardsPush [11], introduced above, works by pushing only from
vertices v whose residual exceeds the threshold rmax. If we instead run BacwardsPush in a global
manner, where we push at every vertex synchronously over L rounds, we get the standard power
method for PageRank [12]. Each round takes O(m) time, since we push across every edge twice.
Let ri(v) be the residual at vertex u after i rounds. In one round, the residual value is scaled
by a factor of (1 −α), implying that ri(u) ≤(1 −α)i for every u ∈V . Hence, after L = log1−α cδ =
O(log 1/δ) rounds, we have rL(u) ≤cδ for every u ∈V . By the same argument as in Section 2.3,
this suffices to solve the single target problem. The total running time is O(mL) = ˜O(m).
Similarly, one can run a forward variant that starts with all probability mass at the source and
applies the same synchronous updates, thereby solving the single source problem in time ˜O(m).

Theorem 3.3.1. Consider the adjacency-list model. There exists an algorithm solving the single

Overview.
The algorithm is a modified version of the standard BacwardsPush [11]. Instead of
starting with all probability mass at the target t, we will distribute the probability mass among
the neighbors of t, but ignoring all neighbors with degree larger than O(1/δ). In that way, on
average, we avoid a lot of pushes on these expensive high-degree vertices, reducing the asymptotic
time complexity. We show that this only introduces an additive error of at most O(δ). Specifically,
we show that the worst-case running time is O(ht/δ + d(t)) where ht is the number of neighbors of
t with degree at most O(1/δ). The d(t) comes from the initial scan of neighbors to distribute the
probability mass. Importantly, P
t ht ≤O(n/δ) since each vertex can contribute at most O(1/δ)
to this sum, giving an average running time of O((1/δ)2 + d).
Note that the worst-case time
complexity is the same as BacwardsPush, as a target t can have ht = d(t), resulting in a time
complexity of O(d(t)/δ). Furthermore, if the NEIGH-SORTED is available, then we can distribute the
initial probability mass in time ht, and we can remove the d term from the average time complexity.
