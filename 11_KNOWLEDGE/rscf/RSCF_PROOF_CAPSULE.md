# RSCF Proof Capsule

For consequential claims maintain:

```yaml
claim:
class:
premises:
evidence:
provenance:
scope:
regime:
freshness:
dependencies:
causal_level:
competing_hypotheses:
falsifiers:
sensitivity:
confidence_ceiling:
decision_implication:
invalidation_descendants:
```

## Reuse gate
Reuse only if dependencies, scope, regime, freshness, and provenance validity remain compatible.

## Selective invalidation
When a premise fails, invalidate only descendant claims that depend on it.
