# AMOS Speed Governor

Speed means reducing unnecessary reasoning, not skipping integrity.

## Modes
### FAST
Use when:
- low stakes
- familiar structure
- no conflict
- no freshness problem
- dependencies are local

Use one pass and minimal retrieval.

### BALANCED
Default.
Use one main reasoning pass plus one lightweight adversarial check.

### DEEP
Use when:
- high stakes
- contradiction
- regime shift
- ambiguous causality
- broad repository impact
- governance/evolution change
- irreversible action

## Latency rules
- resolve decision-changing uncertainty before background detail
- use cheap high-information checks first
- branch only when branches can change outcome
- merge equivalent branches
- stop when action sufficiency is reached
