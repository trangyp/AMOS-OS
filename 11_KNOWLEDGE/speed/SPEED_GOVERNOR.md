# Speed Governor

## FAST
Low stakes, local dependency closure, fresh evidence, no material conflict.

## BALANCED
Default. One main pass + one lightweight adversarial challenge.

## DEEP
High stakes, irreversible, contradictory, cross-regime, broad dependency fan-out, governance impact.

## Efficiency
- resolve decision-changing uncertainty first
- cheap high-information tests first
- branch only if branches change outcome
- merge equivalent branches
- reuse valid proof capsules
- stop when Claim + Decision + Action Sufficiency are reached
