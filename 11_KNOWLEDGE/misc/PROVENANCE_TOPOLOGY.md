# Provenance Topology

## Provenance graph
`P = (Sources, Evidence, Transformations, Claims, Edges)`

Track:
source identity, parent/ancestor, version/hash, acquisition time, transformation chain, environment, scope, revocation, independence.

## Independence
Independent confirmation must be demonstrated, not assumed.

Multiple descendants of one origin count as correlated support.

Do not increase confidence merely because the same root claim is repeated by:
- mirrors
- summaries
- agents
- reposts
- copied datasets
- benchmark reports sharing the same harness/fixture
