# Execution Harness

Use executable checks instead of prose when a claim can be tested.

Loop:
`Model -> Execute -> Observe -> Compare -> Repair -> Re-execute`

Maintain:
- command
- environment
- input state
- output state
- hashes
- tests
- failure traces
- parent run
- replay status

Execution evidence outranks speculative implementation reasoning for actual observed behavior.
