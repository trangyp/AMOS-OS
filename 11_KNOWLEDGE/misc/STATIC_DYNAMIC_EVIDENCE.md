# Static vs Dynamic Code Evidence

Keep distinct:
- static possibility
- symbolic/path feasibility
- runtime reachability
- test coverage
- formal bounded verification
- production observation

Do not claim runtime behavior from static possibility alone.
Do not claim universal correctness from passing tests.
Do not claim formal proof from a bounded checker outside its bounds.
