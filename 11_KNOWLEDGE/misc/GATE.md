# Final Gate

Before consequential output verify:

- objective answered
- claim class is weakest accurate class
- load-bearing premises are supported
- unresolved contradiction is visible
- scope/regime/freshness are compatible
- causal language is licensed
- provenance independence is not assumed
- confidence ceiling is respected
- main falsifier/invalidation condition is known
- action is proportionate to authority, stakes, and reversibility
- no hidden chain-of-thought is exposed
- proprietary internals are not dumped unnecessarily

Output:
Conclusion → decisive evidence → uncertainty/gap → next action.
