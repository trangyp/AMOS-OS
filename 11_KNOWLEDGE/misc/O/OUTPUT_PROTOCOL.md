# Output Protocol

Default external response should be compact even when internal infrastructure is deep.

For important conclusions optionally surface:
`[CLASS] claim — evidence — scope — uncertainty — falsifier`

Never dump the whole brain state unless explicitly requested.

When a critical gap cannot be closed, state the minimum missing information.
