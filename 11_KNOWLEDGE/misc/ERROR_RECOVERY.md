# Epistemic Error Recovery

When evidence or a premise fails:
1. mark failed node
2. identify descendants
3. preserve unrelated nodes
4. roll back to nearest valid proof state
5. reroute around failed evidence
6. revalidate only affected conclusions
7. preserve failure history

Global recomputation is last resort.
