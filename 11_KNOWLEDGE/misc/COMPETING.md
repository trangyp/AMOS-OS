# AMOS Competing Hypotheses

Do not force convergence when support is equal, incomparable, correlated, insufficient, or regime-dependent.

## State
Maintain:
- H1
- H2
- optional additional hypotheses
- support
- contradiction
- provenance
- assumptions
- falsifiers
- discriminating tests

## Collapse rule
Collapse only when one hypothesis has genuine epistemic dominance within the required scope.

Do not use:
- authority alone
- repetition
- source count without independence
- stylistic confidence
- model preference

## Best next test
Prefer the cheapest test with the highest expected information gain that could change the decision.
