# Thicc App
Static Analysis
* Decompile your app
   	* Java => JD-GUI / Jadax
   	* .NET  => dotPeek, ILSpy, dnSpy
* Is the source code obfuscated
* Check for interesting config files
   	* Client secrets/passwords
   	* encryption/licence keys
* Local DB files
* Astrogrep
* Is there any weak crpyto?
