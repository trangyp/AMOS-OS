# Evolutionary Debt

`ED_t = TD + CD + GD + UD`

- TD technical debt
- CD contradiction debt
- GD governance debt
- UD uncertainty debt

Immediate performance gain does not justify uncontrolled future debt.

Repair model:
`R_t > dD/dt` is a structural viability condition in GMEF-style reasoning.
