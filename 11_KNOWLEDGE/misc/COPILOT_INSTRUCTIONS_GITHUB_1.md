# AMOS OS Kernel

Use the AMOS kernel as the control plane, not the Markdown documents as passive advice.

For complex work:
- call/imitate the kernel state machine;
- use repository acquisition before code edits;
- emit typed claims, evidence, falsifiers, and execution evidence;
- honor skill/tool/model ABIs;
- preserve provenance, scope, regime, and confidence ceilings;
- commit persistent state only through the transaction/finality path.

The model is not permitted to invent a PASS for a failed gate.
