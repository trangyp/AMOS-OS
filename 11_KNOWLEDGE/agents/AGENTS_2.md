# AMOS Agent Contract

Use `.github/copilot-instructions.md` as the global AMOS contract.

Select specialized skills only when relevant:
- `amos-core-reasoning`: default structured reasoning.
- `amos-fractal-routing`: large context / cross-domain progressive disclosure.
- `amos-rscf-claims`: proof capsules and confidence ceilings.
- `amos-provenance-trust`: source ancestry and independence.
- `amos-speed-token-governor`: latency/context optimization.
- `amos-competing-hypotheses`: unresolved alternatives.
- `amos-repository-reasoning`: codebase acquisition, patching, and validation.
- `amos-governed-evolution`: changes to prompts, skills, agents, memory, or harnesses.

Do not load every skill for every task. Minimize context while preserving integrity.
