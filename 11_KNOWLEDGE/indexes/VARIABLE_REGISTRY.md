# Universal Variable Registry

## Core Khung Trang state
`S(t) = { B, C, K, L, M, H, Λ, E, μ, σ, F, R, D, I, Q, ε, Π, Ξ, Γ, Ω, Ψ }`

## Canonical symbolic roles used in source
- `L/M/H`: low/foundation, mediator/system, high/governing scale
- `E`: entropy or entropy proxy depending domain
- `Λ`: lacunarity / structured gap proxy
- `μ`: mutation
- `σ` / `Σ`: selection / persistence-adaptation operator depending equation
- `R` / `P`: repair depending source notation
- `I`: integrity
- `Q`: quality / viability quantity depending equation
- `T2`: independent cross-validation gate in Trang ∅ source
- `ξ`: stochastic perturbation / variation
- `C`: constraint / selection operator in some source equations
- `F`: mutation/generation operator in some source equations
- `Π, Ξ, Γ, Ω, Ψ`: higher-order operators defined within the source architecture, not universal mathematical constants.

## Collision rule
Never assume same symbol means same variable across modules.
Bind every equation to:
`symbol -> semantic role -> units/domain -> scope -> source -> status`.
